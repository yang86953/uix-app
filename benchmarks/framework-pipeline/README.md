# Rust 真实框架帧管线模拟

同构模拟 4096 个持久 UI 节点的事件、动画、dirty 扫描、增量布局、绘制录制、
damage 合并、语义快照和提交校验。它测量 CPU 侧框架管线，不包含 GPU 驱动和 I/O。

```powershell
cargo run --release
```

## 2026-07-27 同机对照

环境：AMD Ryzen 7 7700、Windows x64、Rust 1.96.0、Clang 22.1.0、V 0.5.2。
每项执行 7 轮并取中位数，三种实现的最终 checksum 完全一致。

| 工作负载 | Zig ReleaseFast | Rust | C++23/Clang | V 安全数组 | V `direct_array_access` |
|---|---:|---:|---:|---:|---:|
| 常规交互 | 2.388 µs/帧 | 2.598 µs/帧 | 2.876 µs/帧 | 8.594 µs/帧 | 4.835 µs/帧 |
| 高变更交互 | 6.350 µs/帧 | 6.842 µs/帧 | 7.412 µs/帧 | 20.874 µs/帧 | 10.566 µs/帧 |

该结果只比较预分配、数据导向的 CPU 框架管线。它不包含 GPU、字体塑形、系统窗口、
真实组件业务、跨线程同步和 I/O，不能直接当作完整应用帧时间。V 的
`direct_array_access` 会关闭标注函数内的数组边界检查，属于需要额外证明索引安全的
显式性能选择。Zig 使用已知最大节点数的固定容量命令缓冲区；其他三版使用预分配
动态数组，因此小幅差距同时包含容器实现差异。
