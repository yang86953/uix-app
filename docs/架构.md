# 架构

> 分层、主循环、托管与图形硬约束（不含用法与排期）。

## 分层

依赖只能向下，未列边禁止：

| 域 | 允许依赖 |
|----|----------|
| `core` | — |
| `native` | `core` |
| `draw` | `core`, `native` |
| `ui` | `core`, `native`, `draw` |
| `data` | `core` |
| `app` | `core`, `native`, `draw`, `ui`, `data` |

- OS 能力经 `native::traits`；禁上层 `use native::backends::*`
- `#[cfg(OS)]` 仅：`native/backends/`、`native/graphics/**/platform/`、`native/factory/`
- `draw` ↛ `ui`/`app`；`ui` 不碰 backend；业务回调不进组件 struct；`data` 不进热路径
- 图形初始化：`draw::engine::bootstrap → native::factory`（recipe 为单位）
- 公开入口：`uix::prelude::*`

## 主循环

<a id="主循环要点"></a>

三态：`DeepIdle` / `RegisteredActive` / `Active`（无 LightIdle）。

- 无事件 / 失效 / 已注册活动 → DeepIdle + blocking `wait_event`
- wake ∈ {OS, invalidation, registered work, queue, 生命周期}
- 一窗 Active ≠ 他窗 Active；进程 wake ≠ 全窗 Active
- Active 帧：UiEvent+同步 semantic → due work → `post_to_ui` → AppState semantic → Effect → **一次** reconcile → 按需 layout → 按需 present
- 禁：固定 interval 探活；DeepIdle 下 `tick_effects`；未 register 的周期工作；无条件 layout/render/present
- 脏区尽量窄到 rect / Composite / 节点

无真实窗口 / GPU 时：主循环与托管语义须能被单元 / 集成测试驱动验证（不依赖真机 present）。测试仅在 `src/tests`；业务模块不挂载、不内联测试。

## 托管与多窗

<a id="托管与多窗"></a>

每窗一个 `WindowSession`，自有 `ActiveWorkRegistry`。注册项包括：

| 种类 | 进入 RegisteredActive 的条件 | 退出 |
|------|------------------------------|------|
| Timer / AppTimer | `run_after` / `run_interval` 等已登记且未到期清空 | due 执行完或 handle cancel/drop |
| Animation | 节点动画仍在跑并由 registry 登记 | 动画结束 unregister |
| ImeSession | 焦点在可文本输入节点并 start IME | blur / stop IME |

- `post_to_ui` / 窗级定时只入**目标** session；不把他窗拉成 Active
- 浮层：`WidgetTree` 内 `OverlayStack` 管叠层与焦点陷阱；不单独作为跨窗 wake 源
- 语义事件在 Active 帧与 UiEvent 同步路径派发；不另开轮询线程

## 图形

<a id="图形-api与帧提交硬约束"></a>

`GraphicsBackend` = API 请求（非 OS 别名）。轴：`RasterMode` × `PresentMode` × API；按 recipe 装配。

解析：builder > 环境变量 > Settings > 默认 **Vulkan**。禁跨 API 偷换；仅显式 `Auto` 可跨 API probe。registry 只陈述能力（可含 Planned stub），不替 App 选 API。

```text
App / WindowSession
  → resolve GraphicsBackend
  → bootstrap（recipe | Auto 候选）
  → GraphicsDevice（可按 adapter/API 共享；线程亲和）
  → WindowSurface（每窗；logical / drawable / DPR）
  → FrameEncoder（单一有序、API 中立）
  → Presenter::present() -> Result<PresentOutcome, GraphicsError>
```

- **帧提交**：一帧一条命令序列（clear / native / CPU segment / offscreen）；禁双画序；每帧至多一个 `Presenter`；成功指标仅在提交成功后记。initialize / resize / make-current / begin-end-frame / present → typed `Result`；失败帧保留 dirty。
- **绘制与提交解耦**：GPU 主路径绘制全帧（不裁剪绘制，消除 dirty-rect 绘制裁剪的脏数据风险），present 提交窄 damage（按真实 dirty_region）；software 回退保留 dirty-rect 绘制裁剪省 CPU 像素，present 同窄 damage。
- **IR**：`FrameRasterOp` = `FillRect`（SrcOver）、`FillRectAdditive`、`ScrollCopy`。后两者 destination-dependent，须 Native / 参考执行器落地；优先 readback → 参考语义 apply → replace `upload_surface_pixels`，缺任一侧 typed `NotImplemented`；禁透明 CPU segment + SrcOver 冒充；圆角 Additive 同理拒绝。
- **回退**：缺实现 / Planned stub → typed 失败后 Software/CPU；禁称「平台永久不支持」。unsupported → 有界 CPU segment（保 blend/clip/crop/scissor，只上传 damage）；禁近似冒充支持。
- **恢复**：surface rebuild → recipe rebuild → 同 API 下一 recipe → Software；仅 `Auto` 可跨 API；`OutOfMemory` 禁静默回退。
- **滚动帧**：`begin_frame` 先清 dirty 区、encoder 后执行，故 `ScrollCopy` 读到的是已清空像素而非上一帧；render_frame 须把滚动视口并入清/绘区（非仅 exposed strip），由 paint 重新生成偏移内容。`ScrollCopy` 仍为 IR 能力，但当前不经 render_frame 发出。
- **所有权与生命周期**：`draw` 不持有 GL/D3D/Vulkan/Metal 对象；context 只经 factory；bootstrap 收 `NativeSurfaceHandle`。原生 context / 图形引擎 / 渲染后端：生命周期边界仅为 `try_shutdown`（无 void `shutdown`）；`ThreadBoundGraphicsContext` 的 Drop 在错线程时 leak 内层，禁错线程 native teardown；`RenderSession` / `WindowSession` 保留 concrete `shutdown()` 作 Drop 便利并内部调用 `try_shutdown`。
