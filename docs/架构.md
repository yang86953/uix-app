# 架构

> 分层、主循环、托管与图形硬约束（不含用法与排期）。附能力（测试 / Agent）见文末。

## 分层

依赖只能向下，未列边禁止：

| 域 | 允许依赖 |
|----|----------|
| `core` | — |
| `native` | `core` |
| `draw` | `core`, `native` |
| `ui` | `core`, `native`, `draw` |
| `data` | `core` |
| `app` | `core`, `native`, `draw`, `ui`, `data` |

- OS 能力经 `native::traits`；禁上层 `use native::backends::*`
- `#[cfg(OS)]` 仅：`native/backends/`、`native/graphics/**/platform/`、`native/factory/`
- `draw` ↛ `ui`/`app`；`ui` 不碰 backend；业务回调不进组件 struct（语义 handler、paint renderer、虚拟子项 factory 随节点以 `ComponentId` 登记，reconcile / remove / root reset 同步清理）；`Form` 自定义 validator 只在应用侧 `FormValidatorTable` 按 `FormValidatorKey` 解析；`data` 不进热路径
- 图形初始化：`draw::engine::bootstrap → native::factory`（recipe 为单位）
- 公开入口：`uix::prelude::*`

## 主循环

<a id="主循环要点"></a>

事件循环三态（无 LightIdle）；surface 可用性是正交的逐窗状态：

| 轴 | 状态 | 含义 |
|----|------|------|
| `LoopState` | `DeepIdle` / `RegisteredActive` / `Active` | 无待办并阻塞；等待已登记 deadline / frame callback；已有可立即执行工作 |
| `SurfaceState` | `Renderable` / `Suspended(reason)` / `Recovering { retry_at, attempt }` | 可提交；等待 expose / 非零 extent / surface 恢复；按 typed 原因有界重试 |

### 必须

- `DeepIdle`：无待处理事件、queue、due work、reconcile，也无 outstanding frame request / recovery deadline。`Suspended` 窗的 dirty 不算可立即执行工作。
- wake ∈ {OS / 生命周期、queue、due deadline、frame opportunity、recovery / availability deadline}；一窗 wake / Active 不得把他窗拉成 Active。
- **事件轮次**：批量 drain UiEvent + 同步 semantic → due 非视觉工作 → `post_to_ui` → AppState semantic → Effect；只合并 dirty / reconcile，并为该窗申请至多一个 frame request。
- **帧轮次**：收到 `FrameOpportunity { request_token, frame_time, target_present_time? }` 后，消费截至该点的最后一次 root → **一次** reconcile → 按需 layout → paint → 至多一次 present。成功才消费 dirty；提交后仍有动画 / dirty 才申请下一次。
- frame request：one-shot、可合并、逐窗所有；`request_token = surface_generation + request_id`；原生回调只可完成完全相同的 outstanding token。fallback / surface 变化 / suspend 消费或取消 token 后，不能取消 OS 对象的 backend 必须抑制迟到回调。
- 动画保持 open registration，全窗只维护一个下一帧请求；`dt` 来自 frame opportunity 单调时间。`Suspended` 时取消视觉 deadline、冻结动画，恢复首帧 `dt = 0`，不补跑隐藏帧；业务时间继续由 Timer 表达。
- `Hidden` / `Minimized` / zero extent → `Suspended`：保留 dirty 与 animation registration，取消视觉 deadline，不 layout / paint / present。`WindowHide` / `WindowShow` 是逐窗生命周期信号；视觉阶段前复核真实可见性。延迟首显在第一次成功 present 前豁免；可用性信号只解除匹配的 suspend reason；`TerminalFailure` 为吸收态，普通 suspend / resume / surface change 与迟到 failure 均不得降级或重开 frame request，只能随窗口 session 重建。
- `SurfaceLost` / `OutOfDate` / `WouldBlock` → `Recovering` 或等待生命周期信号；重试有界并以 deadline 登记；持续失败不得因 retained dirty 形成 Active busy loop。`DeviceLost` 走同 API recipe → Software FSM；`OutOfMemory` 直接进入无 deadline 的 `TerminalFailure`，不静默回退，也不接受普通生命周期恢复。
- 脏区尽量窄到 rect / Composite / 节点；同帧多个滚动视口分别登记 viewport + delta，统一并入 dirty / clear，保留到提交成功；禁用单槽「最后滚动覆盖」。

### 禁止

固定 16ms / interval 探活；DeepIdle 下 `tick_effects`；未 register 的周期工作；无 frame opportunity 的视觉推进；无条件 layout / render / present。

### 平台帧机会与遮挡

实现上述必须项时，平台须遵守：

- **登记时序**：Wayland 在当前提交前登记 [`wl_surface.frame`](https://wayland.freedesktop.org/docs/html/apa.html#protocol-spec-wl_surface)。Windows：先登记 token，对应帧 present 成功后才交给逐窗惰性 DWM worker（UI 线程外 [`DwmFlush`](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/nf-dwmapi-dwmflush)，私有消息回送 exact token）。macOS：惰性 [`NSWindow.displayLink`](https://developer.apple.com/documentation/appkit/nswindow/displaylink%28target%3Aselector%3A%29)，请求只预置 token，exact present 成功后解除暂停；一次 callback 立即再暂停。静态窗不创建原生节拍；失败 / 拥塞 / 取消 / 销毁保留 deadline fallback 并丢弃迟到 callback（macOS 取消已提交请求或销毁须先 `invalidate`）。
- **遮挡 ≠ 帧机会**：DWM / display link / `wl_surface.frame` 均不等于逐窗遮挡。遮挡须用本窗独立 compositor / window-server 能力。
- **Windows DXGI bitblt**：普通 `Present` 返回 [`DXGI_STATUS_OCCLUDED`](https://learn.microsoft.com/en-us/windows/win32/direct3ddxgi/dxgi-status) → 该窗 `Suspended(Occluded)`，不触发 rebuild；仅登记 100 ms→1 s 有界 availability deadline，到期 [`Present(…, DXGI_PRESENT_TEST)`](https://learn.microsoft.com/en-us/windows/win32/direct3ddxgi/dxgi-present) 探测，仍遮挡只重登记 deadline。`test_present` 默认 typed unsupported；仅能产生 `GraphicsOccluded` 的实现才进入探测。D3D12 flip model 不返回该状态，不得宣称支持或轮询。
- **macOS**：[`windowDidChangeOcclusionState:`](https://developer.apple.com/documentation/appkit/nswindowdelegate/windowdidchangeocclusionstate%28_%3A%29?language=objc) 只 wake 目标窗；视觉阶段前重读当前 [`occlusionState`](https://developer.apple.com/documentation/appkit/nswindow/1419321-occlusionstate?language=objc)。Visible 未设置 → `Suspended(Occluded)`（无探测 deadline）；Visible 只解除精确 `Occluded`，恢复首帧 `dt = 0`。默认 `Unknown` 不得解除其他 backend 的 typed suspension。
- **Wayland buffer**：提交至 `wl_buffer.release` 期间 busy；只 acquire free buffer，双 busy → typed `WouldBlock` 并保留 dirty，禁覆写 compositor 仍在读的 buffer。当前 xdg-shell 绑定不足以接收 [`xdg_toplevel.state.suspended`](https://github.com/wayland-mirror/wayland-protocols/blob/main/stable/xdg-shell/xdg-shell.xml)（须 v6+）；不得用 frame / activation 冒充遮挡。
- **Wayland clipboard**：receive / send fd 与 display / wake 同一次阻塞 `poll`；nonblocking；单轮 read / 全部 send 各 64 KiB 预算；`WouldBlock` 保留累积状态；核对 fd 身份；`set_selection` 只用真实 press serial，禁伪造 `0`。

无真实窗口 / GPU 时：主循环与托管语义须能被单元 / 集成测试验证（不依赖真机 present），至少覆盖 one-shot 合并、可变 frame timestamp、隐藏动画零唤醒、失败不忙循环与恢复后 retained dirty。测试仅在 `src/tests`；业务模块不挂载、不内联测试。

## 托管与多窗

<a id="托管与多窗"></a>

每窗一个 `WindowSession` 与配对 `WindowDriver`：session 自有 `ActiveWorkRegistry`，driver 自有 `FrameScheduler` 与 `SurfaceState`。

| 种类 | 进入 RegisteredActive | 退出 |
|------|----------------------|------|
| Timer / AppTimer | 已登记且未到期清空 | due 执行完或 cancel/drop |
| Animation | open-register；`Renderable` 时全窗合并一次下一帧 | 结束 unregister；`Suspended` 仅停帧 |
| ImeSession | 焦点在可文本输入节点并 start | blur / stop |
| FrameRequest / Recovery | 本窗 dirty / animation 已申请 callback，或 typed 恢复登记了 deadline；同类至多一个 outstanding | 消费 / 成功提交 / `Suspended` / terminal |

- `post_to_ui` / 窗级定时只入**目标** session
- Timer cancel/drop 移除 pending 后必须 wake 重算 deadline，使可回 DeepIdle
- Frame cancel/callback 必须带 `WindowId` + generation；迟到只能丢弃
- Wayland：compositor 确认态、`maximized` / `fullscreen` 归每个 `WaylandWindowOps`；configure 只同步配对 `WindowState`。每个存活 `wl_surface` 登记 `WindowId`；seat 分跟踪 pointer / keyboard focus；事件与 text-input 只投递已验证目标；session generation 丢弃旧对象迟到回调
- macOS：`NSWindow` `isReleasedWhenClosed = false`，初始 `+1` 归 `MacosWindowOps`，图形 shutdown 后 close 并恰好 release 一次；delegate / content view 的 Rust context 存 raw pointer ivar，`dealloc` 回收一次。事件从 `NSEvent.window` / delegate 解析 `WindowId`；IME owner = `WindowId` + native view identity + generation
- 每窗 IME 归 `WindowSession`；共享原生输入只一个 owner。`Tab` / `Shift+Tab` 只遍历有效可见可接收事件节点；隐藏含焦点子树须统一 `FocusOut` 并同帧注销 IME
- `WindowDriver` 是逐窗事件后 work → animation / effect → 单次 reconcile → layout → paint → present 的唯一实现；主循环只 wait / 路由，副窗容器只集合 / 生命周期
- 浮层：`WidgetTree` 内 `OverlayStack`；不单独作跨窗 wake 源
- 语义事件在 Active 帧与 UiEvent 同步路径派发；不另开轮询线程
- Clipboard 只在事件 / due work 词法作用域注入；组件不得保存 platform 指针

## 图形

<a id="图形-api与帧提交硬约束"></a>

`GraphicsBackend` = API 请求（非 OS 别名）。轴：`RasterMode` × `PresentMode` × API；按 recipe 装配。

解析：builder > 环境变量 > Settings > 默认 **Vulkan**。禁跨 API 偷换；仅显式 `Auto` 可跨 API probe。registry 只陈述能力（可含 Planned stub），不替 App 选 API。

```text
App / WindowSession
  → resolve GraphicsBackend
  → bootstrap（recipe | Auto 候选）
  → GraphicsDevice（可按 adapter/API 共享；线程亲和）
  → WindowSurface（每窗；logical / drawable / DPR）
  → FrameEncoder（单一有序、API 中立）
  → Presenter::present() -> Result<PresentOutcome, GraphicsError>
```

- **帧提交**：一帧一条命令序列；禁双画序；每帧至多一个 `Presenter`；成功指标仅提交成功后记。initialize / resize / make-current / begin-end-frame / present → typed `Result`；失败帧保留 dirty。透明 CPU segment 只收 source-independent op；Additive / Scroll 等目标相关 op 在录制边界 typed 拒绝。
- **绘制与提交解耦**：GPU 主路径可绘全帧；仅当 damage 外最终像素不变且 backend 已证明 present coherency 时才提交窄 damage，否则 Full。software 回退可保留 dirty-rect 绘制裁剪，同受 coherency 门控。
- **damage**：UI dirty 为 logical top-left；提交按 DPR / transform 转 drawable，min `floor`、max `ceil`、裁到 extent。resize / DPR / orientation / `currentTransform` / surface generation 改变后首帧强制 Full。Vulkan incremental present 相对 `currentTransform`；Wayland 优先 [`damage_buffer`](https://wayland.freedesktop.org/docs/html/apa.html#protocol-spec-wl_surface)；禁直接 `as i32` 截断。
- **present coherency**：typed `FullOnly` / `RetainedBuffer` / `TrackedSwapchain`；`PresentDamageTracker` 只在成功 present 后提交 signature 与 history。缺 identity / history / generation / transform / 修复能力一律 Full；当前仅 Windows GDI retained DIB 放行窄提交，GPU swapchain、PixelUpload、Wayland 仍为 `FullOnly`。
- **IR**：`FrameRasterOp` = `FillRect`（SrcOver）、`FillRectAdditive`、`ScrollCopy`。后两者须 Native / 参考执行器；优先 readback → 参考 apply → replace upload；缺任一侧 typed `NotImplemented`；禁透明 CPU segment + SrcOver 冒充；圆角 Additive 同理拒绝。
- **回退**：缺实现 / Planned stub → typed 失败后 Software/CPU；禁称「平台永久不支持」。unsupported → 有界 CPU segment；禁近似冒充。
- **恢复**：surface rebuild → recipe rebuild → 同 API 下一 recipe → Software；仅 `Auto` 可跨 API；`OutOfMemory` 禁静默回退。resize 失败仍记住最新目标 extent。backend 不得把 `DeviceLost` / `SurfaceLost` / OOM 抹成 `NotImplemented`。
- **滚动帧**：`begin_frame` 先清 dirty 区，故 `ScrollCopy` 读到的是已清空像素；render_frame 须把滚动视口并入清/绘区。`ScrollCopy` 仍为 IR 能力，当前不经 render_frame 发出。
- **所有权**：`draw` 不持有 GL/D3D/Vulkan/Metal 对象；bootstrap 收 `NativeSurfaceHandle`。共享 `GraphicsDevice` 以 adapter / API / queue family / thread affinity 为 key；每个新 `WindowSurface` 仍须查询该 queue 的 present support，不兼容则该窗另建 recipe。生命周期边界为 `try_shutdown`（无 void `shutdown`）；`ThreadBoundGraphicsContext` 错线程 Drop 时 leak 内层，禁错线程 native teardown。

## 附：大模型控制协议

<a id="大模型控制协议"></a>

产品附能力（开发预览），不改变主路径应用写法。协议名 `uix.agent.v1`。自动化 JSON 快照是独立测试接口，不是本协议双向传输层。用法 → [`使用.md`](使用.md#附agent-bridge开发预览)；缺口 → [`进度`](进度.md#附能力不计-p6)。

### 边界与组成

- `Agent Bridge`：显式启用、仅限本机同一 OS 用户的进程级端点；请求始终带 `window_id`。不是 TCP、跨机器远控、UIA / 读屏桥；不提供 shell、任意 Rust 调用、文件或网络访问。
- 内置组件自动提供语义与动作；自定义组件复用 `AccessibilityRole` / `AccessibilityState`。`.automation_id` 可选；无则用窗口 generation 内 opaque `node_id`。
- 三层：语义树、动作执行器、传输。`TestApp` 与真窗 Bridge 共用前两层；传输差异不得进入组件。
- v1 不负责截图或 GPU readback；提供 logical client bounds 供与语义节点对齐。

### 启用、发现与传输

- 双门禁：`agent-control` feature + `App::enable_agent_control()`；任一未开不登记窗口、不建端点 / 线程 / 描述文件 / wake。仅 GUI 原生窗口与图形引擎创建成功后生效。
- Discovery：Windows `%LOCALAPPDATA%\uix-agent`；Linux / macOS `$XDG_RUNTIME_DIR/uix-agent-<uid>`（缺则系统临时目录）。描述 `uix-<pid>.json` 含 schema、pid、endpoint、随机 token、`ready`；端点成功后原子公布；退出删除。token 不进日志。
- 传输：Windows Named Pipe（owner-only DACL、拒远端）；Linux / macOS UDS（目录 `0700`、socket / 描述 `0600`，accept 后核 peer uid）。不监听 TCP / UDP。
- Wire：UTF-8 JSON Lines，单条 ≤ 4 MiB。首条必须带 token 的 `hello`；未知 schema / message / action typed 拒绝。监听与 wait 阻塞休眠；关闭 self-wake 并取消连接 I/O。

### 会话与消息

每请求含 `schema: "uix.agent.v1"`、`request_id`、`type`；响应带回 `request_id` 与 `ok`。v1 仅五种（除 `hello` 外须已认证）：

| `type` | 请求 | 成功响应 |
|--------|------|----------|
| `hello` | token、客户端信息 | 协议版本、进程信息、能力上限 |
| `list_windows` | — | `window_id`、generation、标题、可见 / 可呈现、revision |
| `snapshot` | `window_id` | 完整语义树、revision、`presented_revision` |
| `perform` | `window_id`、generation、可选 `expected_revision`、action；节点动作另含 target | settle 后 revision 与 `settled`；敏感输入不回显 |
| `wait` | `window_id`、generation、`after_revision` 或待呈现 revision、timeout | change / presented / closed；到期 typed `timeout`（在 Bridge 等待，不轮询 UI） |

无增量补丁、查询语言或长期订阅。连接内串行；并发用多连接（≤ 8）。同窗动作容量 64 FIFO；跨窗互不排序。

[`agent_bridge.rs`](../src/app/agent_bridge.rs)：进程窗口目录与 list / snapshot / perform / wait；只登记 live window。[`agent_protocol.rs`](../src/app/agent_protocol.rs)：认证、framing、wire。[`native/agent_transport/mod.rs`](../src/native/agent_transport/mod.rs)：同用户 byte stream、发现、取消。后两者不引用 `WidgetTree`。

`hello` 返回 request types、语义 / 窗口动作、key names / modifiers 与硬上限；客户端按响应协商，不依赖未声明动作。

```json
{"schema":"uix.agent.v1","request_id":"r1","type":"perform","window_id":1,"generation":3,"expected_revision":12,"target":{"automation_id":"counter.increment"},"action":{"kind":"invoke"}}
{"schema":"uix.agent.v1","request_id":"r1","ok":true,"type":"perform","window_id":1,"generation":3,"revision":13,"presented_revision":12,"settled":true}
{"schema":"uix.agent.v1","request_id":"r2","type":"perform","window_id":1,"generation":3,"action":{"kind":"press_key","key":"enter","modifiers":["ctrl"]}}
{"schema":"uix.agent.v1","request_id":"r3","type":"perform","window_id":1,"generation":3,"action":{"kind":"click_at","x":120.0,"y":48.0}}
```

### 语义树与定位

- 快照含 `window_id`、generation、单调 `revision`、`presented_revision`、节点树。节点：opaque `node_id`、可选 `automation_id`、parent、role、name / description、可公开 value、state、可选 `selection`、bounds、`visible_bounds`、`actions`。`selection`：options、零基 selected / disabled、multiple、expanded。
- state：visible、enabled、focused、selected、checked、expanded、read-only、password / sensitive、modal。bounds：窗口客户区 logical top-left；协议层不猜 DPR / 屏幕坐标。
- `node_id` 仅同 generation 有效；跨启动稳定定位只用 `automation_id`。target 恰含二者之一；缺失 / 重复 / 过期 → typed `node_not_found` / `ambiguous_target` / `stale_window` / `stale_revision`。
- password / sensitive value 永不出现在快照、响应或日志；可向其发文本，成功响应不回显。

### 动作与执行语义

- 节点优先：`invoke`、`focus`、`set_value`、`insert_text`、`select`、`toggle`、`increment`、`decrement`、`scroll`；未声明 → `unsupported_action`。窗口级兜底（无 target）：`press_key`、`click_at`（logical client + 真实 hit-test）。
- `actions` 由真实能力生成；执行器只能执行列表中的动作。`Radio` / `Segmented` / 单选 `Select` 才声明 `select`（零基十进制索引）；多选只公开状态。文本 action 的 Debug / error 不携带 payload。
- 动作经目标 `WindowSession` 正常 semantic / `SystemEvent` 路径；禁 IPC 线程直接改 Widget / State / 绘制树。
- 每窗容量 64 命令入口；空 → 非空才 wake 一次。UI 轮次中、主线程任务之后、AppState / Effect 之前 FIFO drain；snapshot 是 settle 屏障。
- 动作后 State → Effect → reconcile → 必要 layout，最多 32 settle 轮次。`settled: true` 不表示 Timer / 动画 / I/O / present 完成；视觉 dirty 仍只申请本窗至多一个 frame request。视觉证据用 `wait` 等到 `presented_revision >= revision`；不可呈现 → typed `not_presentable`，禁忙重试。
- `WindowSemanticState` opt-in：成功 present 才推进 `presented_revision`；snapshot / wait 本身不触发 layout / paint / present。

### 错误、安全与资源

- typed error 至少：`unauthorized`、`unsupported_schema`、`invalid_request`、`window_not_found`、`stale_window`、`stale_revision`、`node_not_found`、`ambiguous_target`、`unsupported_action`、`invalid_value`、`not_interactable`、`blocked`、`did_not_settle`、`not_presentable`、`timeout`、`app_closed`、`internal`
- 上限：消息 4 MiB、文本 64 KiB、连接 8、每窗队列 64、settle 32、wait 30 s；越界失败不得拖垮应用
- 除 transport worker 外无轮询线程；无客户端时主循环 DeepIdle；一窗 revision / present 不发布他窗快照
- 审计只记结果码与耗时；token、输入文本、password / sensitive 不记录
