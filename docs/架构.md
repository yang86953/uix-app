# 架构

> **接口**：本文档是架构系统的路由索引，按 `core → platform → graphics → ui → data → app` 六层（系统）组织。每层内按模块分解，模块内列出组件。依赖：[产品](产品.md)。导出：各模块详设 → `架构/` 子目录。

## 适用线索

当需要理解"UIX 内部怎么分层、每层有哪些模块、模块间怎么协作"时，从本文档进入。

## 概念层级

```
系统（src/{core,platform,graphics,ui,data,app}/）
  ├── 模块（子目录或主文件）
  │     └── 组件（struct / trait / fn）
  └── 模块
        └── 组件
```
