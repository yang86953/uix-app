# 架构

> 分层、主循环、图形硬约束（不含用法与排期）。

## 分层

依赖只能向下，未列边禁止：

| 域 | 允许依赖 |
|----|----------|
| `core` | — |
| `native` | `core` |
| `draw` | `core`, `native` |
| `ui` | `core`, `native`, `draw` |
| `data` | `core` |
| `app` | `core`, `native`, `draw`, `ui`, `data` |

- OS 能力经 `native::traits`；禁上层 `use native::backends::*`
- `#[cfg(OS)]` 仅：`native/backends/`、`native/graphics/**/platform/`、`native/factory/`
- `draw` ↛ `ui`/`app`；`ui` 不碰 backend；业务回调不进组件 struct；`data` 不进热路径
- 图形初始化：`draw::engine::bootstrap → native::factory`（recipe 为单位）
- 公开入口：`uix::prelude::*`

## 主循环

<a id="主循环要点"></a>

三态：`DeepIdle` / `RegisteredActive` / `Active`（无 LightIdle）。

- 无事件 / 失效 / 已注册活动 → DeepIdle + blocking `wait_event`
- wake ∈ {OS, invalidation, registered work, queue, 生命周期}
- 一窗 Active ≠ 他窗 Active；进程 wake ≠ 全窗 Active
- Active 帧：UiEvent+同步 semantic → due work → `post_to_ui` → AppState semantic → Effect → **一次** reconcile → 按需 layout → 按需 present
- 禁：固定 interval 探活；DeepIdle 下 `tick_effects`；未 register 的周期工作；无条件 layout/render/present
- 脏区尽量窄到 rect / Composite / 节点

## 图形

<a id="图形-api与帧提交硬约束"></a>

`GraphicsBackend` = API 请求（非 OS 别名）。轴：`RasterMode` × `PresentMode` × API；按 recipe 装配。

解析：builder > 环境变量 > Settings > 默认 **Vulkan**。禁跨 API 偷换；仅显式 `Auto` 可跨 API probe。registry 只陈述能力（可含 Planned stub），不替 App 选 API。

```text
App / WindowSession
  → resolve GraphicsBackend
  → bootstrap（recipe | Auto 候选）
  → GraphicsDevice（可按 adapter/API 共享；线程亲和）
  → WindowSurface（每窗；logical / drawable / DPR）
  → FrameEncoder（单一有序、API 中立）
  → Presenter::present() -> Result<PresentOutcome, GraphicsError>
```

- 一帧一条命令序列（clear / native / CPU segment / offscreen）；禁双画序；每帧至多一个 `Presenter`；成功指标仅在提交成功后记
- initialize / resize / make-current / begin-end-frame / present → typed `Result`；失败帧保留 dirty
- 恢复：surface rebuild → recipe rebuild → 同 API 下一 recipe → Software；仅 `Auto` 可跨 API；`OutOfMemory` 禁静默回退
- `draw` 不持有 GL/D3D/Vulkan/Metal 对象；context 只经 factory；bootstrap 收 `NativeSurfaceHandle`
- 缺实现 / Planned stub → typed 失败后 Software/CPU；禁称「平台永久不支持」
- unsupported → 有界 CPU segment（保 blend/clip/crop/scissor，只上传 damage）；禁近似冒充支持
