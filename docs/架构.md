# 架构

[← 返回文档中心](README.md)

> **范围**：本文用于查找 UIX 的逻辑职责、执行映射、组件契约与关键不变量。通用规范唯一依据 code/smc 的 SMC v2.0（外部规范；本仓库采用摘要见 架构/SMC采用.md）；版本和全仓范围见 [SMC 架构采用](架构/SMC采用.md)，旧知识库不再是现行权威。UIX 的具体边界由[系统列表](架构/系统列表.md)持有，进程内订阅由[路由清单](架构/路由清单.md)登记，各专题持有具体设计。产品公开边界以[产品文档](产品.md)为准。

UIX 作为 Rust 原生跨平台应用框架，由 app、data、ui、graphics、platform 与 diagnostics 等系统共同承担完整应用运行边界；不能只把 ui 组件树视为框架本体。Rust 应用逻辑通过稳定的跨系统契约驱动界面、窗口、调度、数据和平台能力，具体操作系统实现只在 platform、graphics 与 composition root 边界内组合。

## 阅读规则

- System、Module、Component 表示职责、可选组织边界和实现能力；执行、资源所有权与逻辑角色分别设计，不与目录、文件、类型、进程或部署单元强制一一对应。
- 除非正文明确写“已实现”或“当前映射”，架构正文描述的是必须收敛到的目标边界，不应据此推断当前源码路径或迁移完成度。
- 当前源码路径只用于定位实现和迁移线索，不自动成为公开 API 或兼容性承诺。
- 依赖、实例所有权与生命周期、同步可用性、异步因果是不同关系；不得用一张调用流图替代全部关系。
- 带时点的迁移进度不在仓库内设账目；完成度以实际代码、公开 API 测试结果与各专题文档事实所有者为准。

规范入口固定为 `外部 SMC 规范检出`。规范检出与 Cargo 声明不一致时先比较版本；不可回退到旧知识库摘要。文档仅放在本工作区，源码保留 Cargo 采用元数据、契约配置及实际验证代码。

下表只汇总跨 System 的内部实现映射，要求本身仍由链接的架构正文持有。内部调度、缓存、damage、渲染计划和增量阶段不属于公开 API，不建立项目测试；只有能从公开入口观察的行为才进入外部消费者测试。

| 要求 | 事实所有者 | 当前实现映射 |
|---|---|---|
| 无工作时深度休眠，禁止固定 tick | [event-loop](架构/app/event-loop.md) | `src/app/event_loop/event_loop.rs`、`src/app/window/frame_scheduler.rs` |
| 活动源按需登记，暂停取消视觉 deadline，恢复首帧重基 | [animation](架构/ui/animation.md) | `src/app/queues/active_work_registry.rs`、`src/app/window/frame_scheduler.rs` |
| 字段分级失效与局部 damage 成功提交 | [layout](架构/ui/layout.md)、[damage](架构/core/damage.md) | `src/ui/coordination/widget_patch.rs`、`src/ui/widget_runtime/widget/tree_dirty.rs`、`src/core/damage/mod.rs` |
| retained 主目标与滚动 `TextureMove` 复用 | [presentation](架构/platform/presentation.md)、[graphics backend](架构/graphics/backend.md) | `src/draw/backend/gpu/`、`src/draw/renderer/scene_pipeline/` |
| 虚拟列表有界物化，稳定窗口不重复 renderer/reconcile | [virtualization](架构/ui/virtualization.md) | `src/ui/virtualization/`、`src/ui/coordination/tree_dynamic/mod.rs` |
| UIX Lang 跨请求复用未变化阶段 | [编译器架构](uix-lang/设计/编译器架构.md) | `uix-lang-compiler/src/compiler_session.rs`、`uix-lang-lsp/src/session.rs` |

历史性能决策目录已移除，不补造A/B证据。当前优化的必要结论与引用归项目任务（内部历史记录，不作为公开版本说明），原始测量留对应源码target；上表仅持有长期契约。
