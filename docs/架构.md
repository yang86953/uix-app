# 架构导航

> **本骨架适用于任意项目**。硬约束 → [`AGENTS.md`](../AGENTS.md)。**禁止通读** `docs/`。
>
> **AI 阅读契约**：`AGENTS.md` → 本表定位 → **只开 1–3 篇**（本仓 P6 ≤4，优先 `#dN` / 源码）。进度 → [`进度.md`](进度.md)；裁决 → [`决策.md`](决策.md) `#dN`。

## 通用目录结构

```text
AGENTS.md              # AI 落地契约 + 硬约束
README.md              # 人类入口
demo/README.md         # demo 操作（可留）

docs/
  产品.md              # 愿景 / 目标 / 范围（需求验收表可并入）
  决策.md              # 持久裁决（#dN）
  进度.md              # 计划 + 证据 + 门禁
  问题.md              # 缺陷 / 风险 / 待决
  架构.md              # 本页：如何读文档、任务→落地路径
```

> **约定**：根目录只放通用层。本仓不单开 `需求.md`（仍薄，并入 `产品.md`）。**禁止**再建 `docs/领域/` 或平行技术百科；编程细节 → `AGENTS` 硬约束 + `#dN` + 源码。

## 应用作者入口（薄）

入口：`use uix::prelude::*;`（[#69](决策.md#d69)）。门面裁决 → [#178](决策.md#d178)–[#180](决策.md#d180)。

| 步 | 做什么 |
|----|--------|
| 1 | 理解 [#105](决策.md#d105)：有触发才工作；空闲 DeepIdle |
| 2 | `State::new` + `label` / `map_text` + `button(…).on_click(&state, …)`；优先 `State::update`（[#180](决策.md#d180)） |
| 3 | `column((…)).gap(12).padding(16)`；见 [README 示例](../README.md#示例) |
| 4 | `App::new().title(…).root(\|\| …).run()`；周期更新用 `run_interval`（[#132](决策.md#d132)） |
| 5 | 自定义 Widget → `component!`；异质长列表才 `views!`；多 capture 才 `semantic_handler!` |

全栈边界（[#166](决策.md#d166)）：客户端 = `ui` + `app` + `data`（Settings KV opt-in）；网络/同步不在当前范围。后台回 UI 只走 `post_to_ui`。
