# 表单校验

[← 返回架构 索引](../架构.md)

> 分类：表单校验  
> 权威范围：表单字段、规则激活、依赖校验与提交模型

## Form 校验模型

`Form` widget 只负责布局配置，不持有字段值、规则或业务闭包。`Form::field(...).build()` 生成可克隆的应用侧共享 `FormModel`：字段当前值与不可变 schema / 初始值分离，以 type-erased immutable handle 组装 typed `Values`；`initial_values` 批量预置同类型字段，字段级 `initial` 可覆盖并保留具体类型，`default` 仅作兼容别名。`IntoFormValue` 同时提供供文本规则读取的稳定投影，`HashSet<String>` 投影按排序后的选项逐行连接而 typed handle 仍保留集合。内置、inline custom 与字段依赖规则按声明顺序同步执行，每字段止于第一条错误；`depends_on` 读取依赖源 typed 值，`depends_on_with_values` 保留当前字段文本与整表 typed 快照。默认 `OnSubmit`（公开兼容常量 `Submit`）由 `validate()` / `submit()` 激活；`OnChange` / `OnBlur` 分别由 `set_value()` / `blur()` 激活。字段一旦由其触发边界激活，后续值变化持续重验，避免修改后保留过期错误。`reset()` 原子恢复全部模型初始值、关闭规则激活并清空错误，再调用已登记且类型匹配的受控 State reset binding。错误集合由单一 State 发布，只有内容变化才请求所属根 View reconcile；依赖源变化后以访问集对直接与传递依赖各重验一次，循环不会重复执行。

`FormItem` 由一套共享几何同时驱动 render、子节点 measure 与 arrange：非空 help 占用底部 16px 并增加自然高度，剩余主区再按 Vertical 的标签行或 Horizontal / Inline 的标签槽分配给控件；受限 frame 只压缩这些区域而不生成负尺寸。外层 frame clip 约束状态条和全部文字，标签另在 label slot 内裁剪，帮助文字另在 help row 内裁剪；因此长标签不会覆盖控件，帮助文字不会覆盖子节点，Inline 与另外两种布局使用一致的状态渲染路径。`Form::gap` 在入口把负数及非有限值归一为 0，measure 与 arrange 始终读取同一有效间距。

`input_item`、`select_item`、`input_number_item`、`checkbox_item`、`switch_item`、`slider_item`、`rate_item`、`radio_item`、`segmented_item` 与 Picker item 在应用侧把已声明 schema 组合为 `FormItem + controlled component`：绑定入口按字段名登记类型匹配的 State reset closure，构建期读取外部 State，Change / FocusOut 事件把文本、集合、布尔、数值、日期、时间或颜色 typed 值同步到共享 model，错误 State 控制字段状态与内联首错文本。单值控件各绑定一个字段；`date_range_picker_item` 以一个共享 `FormItem` 绑定两个独立 Date 字段，Change 同步两值、FocusOut 激活两字段，聚合项按起止顺序呈现第一条错误，并让两字段共享同一焦点句柄。组件自身继续负责区间归一、步进、离散评分、组语义、禁用选项导航、日期粒度、范围排序与禁用日期；表单适配不复制这些规则。除文本 Input 与双字段日期范围的专用路径外，其他组件共用一条 typed Change / Blur / FocusHandle 绑定路径。每个已绑定字段复用一个 typed `FocusHandle`；`submit()` 失败登记首错 focus-and-reveal 请求，不直接遍历或操作 `WidgetTree`，目标窗消费命令时再由通用 viewport 契约执行最小滚动。绑定与 reset 闭包仍只保存在应用侧 `FormModel`，validator 也不会进入 component struct；此路径不新增 timer、FrameOpportunity 或跨窗工作。

`Form::list(...).build()` 生成应用侧 `FormListModel`：schema 中的不可变规则按行共享，字段值与错误逐行独立；`FormListItemId` 单调分配且删除后不复用。列表只用一个 `State<Vec<FormListItemId>>` 表达结构；`render_rows()` 构建期读取该 State，并把稳定 ID 写为 keyed child。增删只触发所属根 View 的一次结构 reconcile，未删除行按 key 复用；字段校验不触发树遍历、绘制、timer、FrameOpportunity 或跨窗 wake。
