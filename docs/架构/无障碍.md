## 无障碍

<a id="无障碍"></a>

框架从当前 WidgetTree 按需生成语义树（`AccessibilitySnapshot`），供测试 `TestApp`、Agent Bridge 以及未来读屏桥消费；不登记轮询或额外帧。

### 语义标注

- View 通过 `.role(AccessibilityRole)`、`.accessible_name(...)`、`.accessibility_state(...)` 与 `.aria("aria-*", value)` 覆写显式字段；未覆写字段继续从组件实时快照派生
- 内置组件自带默认 role（如 `Button`→`Button`、`Input`→`TextBox`）
- `AccessibilityRole::None` 将节点及其子树排除出语义树

#### AccessibilityRole

框架定义 22 种常用语义角色与一个排除角色 `None`：

| 角色 | 对应组件 |
|------|----------|
| `Button` | Button, FloatButton, ThemeToggle |
| `TextBox` | Input, InputNumber（单行） |
| `Checkbox` | Checkbox |
| `Switch` | Switch |
| `Slider` | Slider, RangeSlider |
| `SpinButton` | InputNumber（步进） |
| `RadioGroup` | Radio, Segmented |
| `Combobox` | Select, AutoComplete, Cascader, TreeSelect, DatePicker, TimePicker, ColorPicker |
| `Dialog` | Modal |
| `Alert` | Alert, Notification, Message |
| `ProgressBar` | ProgressBar |
| `Table` | Table |
| `TabList` | Tabs |
| `List` | List, Menu |
| `Tree` | Tree |
| `Menu` | Dropdown |
| `Navigation` | Navigation, Anchor, Breadcrumb, Steps, Pagination |
| `Image` | Avatar, Image, QRCode |
| `Text` | Label, Typography, RichText |
| `Status` | Badge, Tag, ResultView |
| `Group` | 表单项、具名内容组 |
| `Generic` | Container, Grid, Space, Divider 等布局组件 |
| `None` | 装饰节点；节点及子树不进入语义树 |

#### AccessibilityState

每个语义节点附带运行时状态：

| 字段 | 类型 | 说明 |
|------|------|------|
| `disabled` | `bool` | 是否禁用 |
| `checked` | `Option<bool>` | 勾选状态（Checkbox/Switch） |
| `expanded` | `Option<bool>` | 展开状态（Collapse/Tree/Select 下拉） |
| `selected` | `Option<bool>` | 选中状态（Menu/Nav/Tabs 当前项） |
| `value_text` | `Option<String>` | 当前值文本（Input/Select/RangeSlider） |
| `value_now` / `value_min` / `value_max` | `Option<f64>` | 当前数值及范围（Slider/RangeSlider/ProgressBar） |
| `multiline` / `password` / `required` | `bool` | 文本输入与表单状态 |

#### AriaAttribute

`AriaAttribute::new(name, value)` 保存一个静态属性名与字符串值；`.aria(name, value)` 按名称覆盖。组件状态自动派生以下常用属性，自定义 View 还可追加 `aria-description`、`aria-level`、`aria-placeholder`、`aria-live` 等属性：

| 属性 | 来源 |
|------|------|
| `aria-label` | `AccessibilitySnapshot::name` |
| `aria-disabled` / `aria-checked` / `aria-expanded` / `aria-selected` | `AccessibilityState` |
| `aria-valuetext` / `aria-valuenow` / `aria-valuemin` / `aria-valuemax` | `AccessibilityState` 的值与范围 |
| `aria-multiline` / `aria-required` | 输入与表单状态 |

### 焦点链

- `Tab` / `Shift+Tab` 遍历有效可见可接收事件的语义节点
- 无当前焦点时分别从首项 / 末项开始
- 浮层内受 `OverlayStack` focus trap 约束——焦点不逃逸到浮层外的节点
- `WidgetTree` 将逻辑焦点与键盘焦点视觉分离：非右键指针按下切换为 pointer modality，只隐藏 action / selection 控件的额外焦点环而不清除逻辑焦点；下一次 `KeyDown`、语义 `focus` 或 `FocusHandle` 请求恢复 keyboard-visible modality 并窄标脏当前焦点。右键不改变该模态，文本编辑控件仍按自身编辑态保留边框与光标
- 普通 `FocusIn` / `FocusOut` 仍按目标与冒泡处理；交互包装器通过 `EventHandler::on_focus_within` 观察整个子树，只在焦点跨越子树边界时收到通知，子树内切换不重复开关状态
- 零布局占位的浮动控件以 `hit_test_frame` 作为语义可见边界；已提升为浮层的节点不再受内容祖先 viewport 裁剪，确保视觉、命中与自动化边界一致
- 隐藏含焦点子树须统一 `FocusOut` 并同帧注销 IME

### 安全

- password / sensitive 字段永远不出现在语义快照、Agent Bridge 响应或日志
- 语义快照挂在事件/due work/帧轮次末尾，内容变化才改写；不注册额外 timer/线程/端口
