## 动画

<a id="动画"></a>

UIX 提供泛型逐帧动画系统，由主循环统一推进 `dt`（秒），窗口不可呈现时自动暂停。

### Animated\<T\> —— 声明式单值过渡

`Animated<T>` 复用 `State<T>` 发布当前插值，但不是布局节点。root capture 只收集被 `value()` / `progress()` / `is_finished()` 读取的 source，`WidgetTree` 以 sidecar 保存它们；同一 source 至多绑定一个 tree scope，其他窗口只观察共享值，不重复推进。

运行中的 source 进入所属窗口既有 `ActiveWorkRegistry`，与 widget animation 共用 one-shot frame request 和 frame opportunity `dt`。采样写入 State 后，主循环在同一帧消费 reconcile 请求，再 layout / paint / present；这避免零 `dt` immediate frame 抢占已登记的下一帧。完成或暂停在本轮登记同步时取消 open registration；root 移除 source 后，最多消费已经 outstanding 的一次帧机会再取消旧 id。`Suspended` 期间不采样、不 reconcile、不 layout / paint / present，恢复首帧仍以 `dt = 0` 重基。

延迟 source 在等待期登记 `ActiveWorkKind::Animation(id) -> deadline`，不进入 open animation 集合，也不申请连续帧；deadline 到期且窗口可呈现时才合并一个 immediate frame，再切换为 open registration。暂停、停止、完成或 root 移除通过受管 source 同步立即撤销旧 deadline；零时长过渡也只在正延迟到期后提交终值。窗口不可呈现时把 pending deadline park 为无 deadline 登记并阻塞等待，不采样、不 reconcile、不 layout / paint / present；恢复后的可呈现帧复核 source，未到期则恢复 deadline，已到期则从 `dt = 0` 启动。

当前公开面包含固定时长、typed 单值 / 多属性聚合 keyframe 与 Spring 过渡、固定时长延迟启动、pause / resume / stop / restart / reverse、普通固定时长的 `loop_count` / `loop_forever` / `loop_alternate`、一次性 `on_finish` / `set_on_finish`、Style 字段及 visual-only offset / scale 的 typed `*_animated(&Animated<T>)` 绑定，以及有限时间线的并行 / 串行 / stagger `AnimationGroup`。循环跨越大 `dt` 时按算术折算轮次与当前 leg，不逐轮迭代；`loop_count(0)` 直接提交终值，无 frame registration。keyframe 与 Spring 是单次播放并在每次替换时清除旧循环模式。

声明式完成回调归属于一份 `AnimatedPlayback`，clone 不复制；自然完成时 `AnimatedInner::advance` 在 playback mutex 内原子取走 callback，随后先发布终值、释放锁，再执行 `FnOnce`，因此回调可安全读取或控制同一 `Animated` 而不重入死锁。有限循环只在全部 plays 结束后消费；`stop` 提交终值但保留 callback，`restart` 后仍可自然触发；替换 playback 会连同旧 callback 一起丢弃；绑定已完成或无 playback 的 source 时在调用线程同步触发。自然推进发生在 source 所属窗口的 UI 帧，但 `Animated` 句柄可跨线程配置，所以 callback 仅要求 `Send + 'static`，不得被视为任意线程直访 `WidgetTree` 的授权边界。

View 的 `opacity_animated` / `bg_animated` / `color_animated` / `width_animated` / `height_animated` / `radius_animated` 只在 root build 内调用 source `value()` 并写入对应 Style 字段；capture 仍按 `ComponentId` 去重，adapter 不创建 wrapper 节点或新 timer。动画帧发布 State 后触发原 root reconcile，节点复用与 paint / layout 分类沿用同名静态样式 setter。

`offset` / `scale` 及对应 animated binding 写入节点 visual transform，不改变 layout frame；局部矩阵按“以 layout frame 中心缩放，再应用 offset”构造，并与祖先 transform、滚动位移按实际绘制顺序组合。paint、hit-test、空间事件本地化、文本选区、语义 frame / visible bounds 与 damage 均消费同一组合链；不可逆的零 scale 不命中。变换变化同时登记旧 / 新 visual subtree bounds，并增加 tree version 使 LayerTree 重建；变换子树禁用 Picture 缓存，变换路径上的滚动禁用 scroll-copy composite，保守退回 Paint。

普通 View 的 `enter_animation(AnimationConfig)` 在节点首次 build 时创建一次 `TransitionPlayer`，不包 wrapper、不触发布局，也不在同 key reconcile 时重启。`leave_animation(AnimationConfig)` 使声明树已移除的节点进入有界 pending-removal：保留原节点、子树和布局槽直至过渡完成，但立即清理指针 / 焦点并退出命中、语义、Timer、组件动画和浮层管理；完成后删除节点并请求布局。同 key 完成前重新出现会取消 pending-removal、复用原 ID 并恢复终态；enter 中转 leave 从当前 opacity / offset / scale 接续。零 duration 直接删除，不登记帧；pending-removal 即使不可见也会推进到完成，不泄漏保留节点。

节点 opacity 在 LayerTree 中与祖先 opacity 相乘，offset / scale 进入上述统一 visual transform；活动期禁用该子树 Picture 缓存，每帧登记旧 / 新 visual subtree damage。新节点或新离场即使在本帧 reconcile 后才出现，也会在帧末同步 animation registration，避免依赖下一次外部事件唤醒。

容器的 `stagger_enter(interval, config)` 只给直接子节点排程：首次 build 对全部子节点编号，后续 reconcile 仅对本轮新 mount 的节点从 0 编号，复用节点不重启或改写既有 deadline。首项登记 open animation，后续项登记绝对 deadline；等待期保持过渡起值且不进入连续帧集合，deadline 到期转为 open，迟到量作为首个 `dt` 一次消费。零时长延迟项到点提交终态；View 过渡与 `Animated<T>` deadline 共同由窗口 managed animation registration 托管，组件自身动画仍保持独立 open work，不因 View 过渡完成而被误取消。

`AnimationGroupItem` 以 type-erased control 保存异构 `Animated<T>`，但不复制状态与播放器；组构造时按 `ComponentId` 拒绝重复 source，再从子项原始起点重排 deadline。并行项 offset 为零、串行项 offset 累加前项 duration、stagger 第 n 项 offset 为 `n * interval`，显式 `delay` 由零副作用的有限 source 表达；总时长统一取最大 `offset + duration`。组自身不登记 frame work，`progress()` / `is_finished()` capture 全部子 source，播放控制以同一 `Instant` 批量作用于子项，因此每个真实 source 仍至多一份逐窗 registration；有限 counted loop 的内部组进度包含已完成轮次，不改变公开 `Animated::progress()` 的当前 leg 语义。等待 deadline 迟到时把超期量作为本次 `dt` 交给播放器，大步进可跨过多个 offset 且不 busy retry。空组、重复 source、既有延迟、无 playback、Spring 与无限循环无法证明有限总时长，构造时返回 typed `AnimationGroupError`，不做静默降级。

`KeyframeAnimation<T>` 在构建时校验有限 offset，裁到 `[0, 1]` 后稳定排序，重复 offset 保留最后声明；缺失边界由首末值补齐，`Animated<T>` 缺失 0 时改用当前值。采样以“起点 keyframe 的 easing”推进到下一点，利用有序 offset 二分定位分段；同一 FrameOpportunity 只做一次 O(log n) 采样，大 `dt` 直接裁到 duration 终态。空序列与非有限 offset 返回 typed `KeyframeError`，不会替换现有 playback；完成、暂停或 root 移除沿用 source registration 的 inactive 路径。

`keyframe!` 只生成一个应用侧结构体、同可见性构造器与 fieldwise `Animatable` 实现，不生成播放器或运行时注册。`lerp` 以同一采样进度推进全部字段，`delta` 取各字段绝对 delta 最大值；因此 `Animated<Generated>` 仍只有一个 `ComponentId` work source、一份 State 和一条错误 / 播放控制边界，Spring 完成也要求所有字段进入阈值。字段缺失或非 `Animatable` 是编译错误，不存在运行时部分属性回退。

Spring 只替换 source 内的采样器，不增加调度类型：`SpringAnimation<T>` 对归一化位移使用欠阻尼 / 临界阻尼 / 过阻尼解析解，初始速度以整段距离每秒表达。每次采样用 `Animatable::delta` 的绝对值把归一化速度换算到实际值空间；实际位移与实际速度同时低于 `Spring` 的静止阈值后精确提交终值并关闭 open registration。解析解不按小步循环积分，大 `dt` 仍为 O(1)；暂停立即 inactive，恢复后继续累计物理时间，窗口 Suspended 仍由既有首帧 `dt = 0` 规则重基。

### Animation\<T\> —— 泛型插值

`Animation::new(from, to, duration)` 创建从 `from` 到 `to` 的插值动画，类型参数 `T: Animatable`。

| 方法 | 作用 |
|------|------|
| `update(dt)` | 推进时间，返回当前插值 |
| `value()` | 只读当前插值，不推进 |
| `is_finished()` / `progress()` | 查询完成状态与进度 [0,1] |
| `pause()` / `resume()` | 暂停 / 继续 |
| `restart()` | 回到起始位置并继续播放 |
| `stop()` | 跳到终态并停止，不触发完成回调 |
| `reverse()` | 交换 from/to 并重新播放 |
| `easing(e)` | 设置缓动曲线 |
| `on_finish(FnOnce)` | 下一次推进到终态时触发一次 |

非正 `duration` 归一为零，并在首次 `update()` 时到达终态。完成回调要求 `Send + 'static`；`Animation` 克隆体共享同一个一次性回调，任一克隆体先完成后其余克隆体不再重复触发。

内置 `Animatable` 实现：`f32`、`f64`、`Color`、`Point`、`Rect`。`Animation<f32>` / `Animation<f64>` 额外提供 `fade_in(duration)` 和 `fade_out(duration)` 便捷构造。

`SpringAnimation::new(from, to, Spring)` 提供同一组值读取与 pause / resume / stop / restart / reverse 控制；`Spring::bouncy()`、`gentle()`、`snappy()` 与 `critical()` 提供预设，`custom()` 可设置 stiffness、damping、mass、初始 velocity 和双静止阈值。非有限或非正的收敛参数保留原配置，避免产生永不衰减的公开实例。一次性 `on_finish` 与 `Animation<T>` 保持相同的 clone 共享语义。

`KeyframeAnimation::new(frames, duration)` 提供相同的值读取、播放控制与一次性回调；`Keyframe<T>::easing` 属于从当前点出发的分段。反向播放以 `1 - progress` 对同一曲线采样，保持正向轨迹的时间反演；stop 提交当前方向的终点。

### Easing —— 缓动曲线

`Easing` 枚举将 `t ∈ [0,1]` 映射到缓动值：

| 变体 | 说明 |
|------|------|
| `Linear` | 线性 |
| `QuadIn` / `QuadOut` / `QuadInOut` | 二次方 |
| `CubicIn` / `CubicOut` / `CubicInOut` | 三次方 |
| `QuartIn` / `QuartOut` / `QuartInOut` | 四次方 |
| `BackIn` / `BackOut` | 弹性（超出后回弹） |
| `Bounce` | 分段弹跳缓出，输出保持 [0,1] |
| `Elastic` | 衰减振荡缓出，允许短暂越过终值 |
| `CubicBezier(x1,y1,x2,y2)` | 自定义三次贝塞尔（牛顿法 + 二分法回退） |

公开链式写法使用 `Easing::linear`、`ease_in/out/in_out`、`cubic_in/out/in_out`、`bounce`、`elastic` 这些关联常量；`Easing::cubic_bezier(...)` 构造自定义曲线。`sample(t)` 会收敛输入范围，但 Back / Elastic 的输出可越过 [0,1] 以形成回弹。

antd 5 预设：`antd_default()`（`cubic-bezier(0.25,0.1,0.25,1)`）、`antd_in()`、`antd_out()`、`antd_in_out()`。

### AnimationConfig / TransitionPlayer —— 进出场过渡

借鉴 antd 的 Modal / Drawer / Notification 等浮层 enter + leave 动画模式：

- `AnimationConfig` 只通过 `fade_in/out`、`slide_in/out`、`zoom_in/out` 构造，持续时间统一归一到非负值；应用不直接拼内部枚举字段
- `slide_in/out(Placement, duration)` 以 `Top / Bottom / Left / Right`（含角落变体归并到上下方向）表达视觉来源 / 去向；通用位移为 24 logical px，组件预设可在内部按自身尺寸收紧
- `TransitionPlayer` 是组件内部的单次播放器，将配置分解为 opacity / offset / scale 三路 `Animation<T>`，完成后停止登记帧工作
- 内建预设覆盖 Modal zoom、Drawer slide、Tooltip / Popover fade 与 Collapse fade；公开组件只接收 `AnimationConfig`

**enter 动画**：节点挂载或浮层打开时播放。**leave 动画**：关闭前播放，`finished` 后由 `OverlayStack` 移除节点。

### 帧驱动与暂停

- 动画由主循环每帧 `dt` 推进；widget 通过 `WidgetAnimation::update_animation(dt)` 生命周期钩子传播，`Animated<T>` source 由 tree sidecar 推进
- 每窗 `ActiveWorkRegistry` 只登记仍返回 active 的动画节点 / source；事件、reconcile 或失效发生时发现新动画，稳定逐帧阶段只推进已登记 id，不遍历整棵树——这是动画系统的核心节省机制：100 个已完成动画零开销，只有活跃动画才消耗帧预算
- **Suspended 时冻结**：窗口不可呈现时所有动画暂停，恢复首帧 `dt = 0` 重基，避免时间跳跃导致动画瞬切到终态。隐藏窗口不跑动画——同样是「用最少资源」：不可见时不消耗 CPU
- 动画完成（`is_finished() == true`）后从 registry 取消登记，不再触发帧请求
