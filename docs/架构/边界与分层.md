# 边界与分层

[← 返回架构 索引](../架构.md)

> 分类：边界与分层  
> 权威范围：模块边界、依赖方向与跨层不变量

## 分层

依赖只能向下，未列边禁止：

| 域 | 允许依赖 |
|----|----------|
| `core` | — |
| `native` | `core` |
| `draw` | `core`, `native` |
| `ui` | `core`, `native`, `draw` |
| `data` | `core` |
| `app` | `core`, `native`, `draw`, `ui`, `data` |

- OS 能力经 `native::traits`；禁上层 `use native::backends::*`
- `#[cfg(OS)]` 仅限 `native/` 层；上层（`core`/`draw`/`ui`/`data`/`app`）禁止
- `draw` ↛ `ui`/`app`；`ui` 不碰 backend；业务回调不进组件 struct（语义 handler、paint renderer、虚拟子项 factory 随节点以 `ComponentId` 登记，reconcile / remove / root reset 同步清理）；`Form` 自定义 validator 只由应用侧 `FormModel` 持有；`data` 不进热路径
- 资源句柄（`BitmapHandle`、`WidgetId`、`ImageHandle`）采用 **generation 槽位复用** 而非引用计数：句柄 = `(slot_index, generation)`，释放时槽位标记为空并递增 generation，新分配复用同槽位时旧句柄自动失效。这比 `Arc` 省去原子操作开销，比原始指针安全——是「用最少资源」在资源生命周期上的核心机制
- 运行时是原生窗口 + 原生绘制；**禁 WebView / 嵌入式浏览器作为 UI 或呈现运行时**
- 图形初始化：`draw::engine::bootstrap → native::factory`（recipe 为单位）
- 公开入口：`uix::prelude::*`
- View 样式链只写入节点唯一 `Style`；水平 / 垂直 padding 保留另一轴，阴影进入同一盒模型绘制，不在组件内复制视觉字段
- `State` / `Computed` 的 `map` / `map_opt` 在根 View 构建期捕获底层 State 依赖并绑定结构 reconcile；`map_text` 走 DynamicLabel 的窄 Paint 绑定。Computed 缓存命中不得跳过依赖捕获。reconcile 的核心机制是 **keyed diff**：同类型、同 key 的节点保留身份和运行态（滚动位置、光标、动画进度），只 patch 变化的属性；类型或 key 不同才销毁重建。这比全树重建节省一个数量级的 CPU，是「局部状态只更新依赖节点」的引擎基础。
- `canvas(width, height, paint)` 仅提供固定 logical measure + render，无子节点 / 事件能力；绘制期读取的 State / Computed 在共享 ScenePaint 边界绑定到本节点 dirty rect，变化只产生窄 Paint，不注册每帧工作
- controlled Input 以绑定的 `State<String>` 为外部真值：构建期读取绑定结构 reconcile，编辑事件同步回写；内建 patch 比较运行值，值变化才重置文本 / 光标并发 Layout + Paint，同值重建保留运行态。`textarea` / `password` 工厂只声明模式，`max_length` 按 Unicode 字符限制用户输入；绑定值不进入公开 config snapshot
- controlled Checkbox / Switch 以绑定的 `State<bool>` 为外部真值：构建期读取触发结构 reconcile，点击或键盘切换同步回写，绘制期依赖只绑定本节点 Paint。非受控 `default_checked` 仅是初值，无关 reconcile 不覆盖用户运行值；两种模式均不轮询
- controlled Select 以选项文本作为外部真值：单选是 `State<String>`，多选是 `State<HashSet<String>>`；普通选项或 `SelectOptionGroup` 组内选项都按声明顺序映射为稳定索引，组标题不进入选择索引。构建期绑定 reconcile，点击 / 键盘更改同步回写，绘制期只绑定本节点 Paint。`searchable()` 仅在聚焦后接收 `TextInput`，按大小写不敏感的包含关系过滤并保留原选项索引；`loading(true)` 保留当前值，以一行逐帧旋转器替换候选并暂停选项提交，关闭加载后恢复同一组选项。查询、弹层、过渡、加载相位与滚动均是实例运行态，无关 reconcile 保留且不登记独立 timer，过滤收窄时 damage 仍覆盖有上限的原弹层。非受控 `default_selected` 仅是初始索引
- Table 的 `sortable` / `selection` / `bordered` / `virtual_scroll` / `size` 是声明式配置：`size(width, height)` 固定视口，溢出行只在表体内滚动且表头保持可见；表级排序覆盖所有列，列级排序可单独开启，点击只切换方向并发 `Change`，数据顺序由调用方重建；复选框列仅在 selection 开启时参与 measure / hit-test / paint。虚拟滚动关闭时保持完整行遍历，开启后按固定 `virtual_row_height` 只遍历 viewport 与有界 overscan；两者滚动都只产生 body Composite，不注册逐帧工作。固定视口、排序方向、有效范围内的单选 / 多选行在同配置 reconcile 中保留
- `Table::data(Vec<R>, row_key)` 在 View build 边界把泛型行按 `TableDataColumn<R>` 投影为既有文本行；重复业务 key 在建树前返回 `TableDataError`。`bind(...).render(...)` 的 typed 行与 View factory 只进入按 `ComponentId` 管理的 render sidecar，`Table` component 仅保存文本、row key 与 View 列索引，paint / event / snapshot 不执行业务闭包。普通表物化全部 View 单元格，虚拟表只物化当前 viewport + overscan 行窗；子节点 key 由 row key + column index 组成，reconcile 重排复用仍在窗口内的节点。组件同时按 row key 重映射 selected / checked / expanded 索引；legacy `TableRow` 使用索引字符串作为隐式 key。结构化快照发布文本 rows、row_keys 与 view_columns。View 单元格 frame 保持 content 坐标，纵向偏移由 compositor 与 hit-test 共享的 viewport transform 应用；物化窗口不变时不复制 row key / View 列、不重跑 factory、不触发布局，只提交 body composite-copy。虚拟窗口变化时才 reconcile 子树并布局、保守重绘，同时消费已被重绘覆盖的滚动增量，避免后续稳定滚动重放过期位移
- Table 列布局在每次 paint / hit-test 时划分 left / middle / right：固定列按声明顺序锚定两侧，只有 middle 应用有界水平偏移并裁在剩余视口。`TableColumn::resizable(true)` 在叶表头右边缘提供半宽 4 logical 的优先命中区；拖动期间直接更新同一列几何并请求 View 单元格重排，宽度下限为 32 logical，PointerLeave、移出叶表头或失焦恢复起始宽度。释放后的运行时宽度进入结构化快照，并在新旧列均保持 resizable 时跨 reconcile 保留；关闭能力则采用新声明宽度。纵向滚动沿用 Composite；横向偏移会改变固定区与中间区的叠放关系，coherency 未覆盖该组合时退回本 Table Paint，不提交整表像素搬移
- Table 的 `column_groups` 在构建期扁平化为叶列与稳定范围元数据，排序、行数据和固定列继续只索引叶列。存在分组时表头增为两层：具名范围分占上下层，`TableColumnGroup::column` 的独立列跨两层；分组范围进入结构化快照，reconcile 仍按叶列位置保留可排序运行态
- Table 展开 factory 不进入组件 struct，而是按 `ComponentId` 存在 `RenderHandlerTable`；展开时只物化当前行的一个普通 View 子树，应用 reconcile 复用同类型 / 同 key 节点，折叠或换根随节点生命周期清理。子树以表体为 clip，并复用 body 的 viewport scroll transform；paint 不调用 factory
- Tree 将当前展开路径深度优先展平为稳定 key 行，28 logical 行高、虚拟滚动、键盘显露与指针命中共享同一可见索引。每行按实际 frame 为有上限的层级缩进、勾选槽、Lucide 展开槽、图标槽和标题槽分配非负几何；深层/长标题按 Unicode 单行省略并与行背景、焦点框一起裁在真实视口内。指针只在同一二维目标内完成按下与释放后选择、勾选或展开，移出、`PointerLeave`、`FocusOut` 取消未完成动作，hover 目标不变时不重复失效；滚轮只在真实 frame 内生效。展开/折叠仅在可见行数变化时发出一次 Layout 请求。相同节点配置 reconcile 按 key 保留选择、勾选、展开与滚动位置并清除未完成指针动作；Tree 无障碍值发布当前可见选中节点的标题与一基位置，不把业务 key 当作用户文案
- RichText 的 measure 使用估算字符度量，paint 使用真实字体 advance；真实布局缓存以内容、字体配置、实际宽度和解析后的主题正文色为键，主题切换不会复用旧色字形。折行字形、连续文字 run、选择/链接背景、代码复制按钮与二维命中共享相对 frame 坐标，绘制和可交互复制区统一裁在归一化实际 frame 内。链接与代码复制使用稳定 segment 目标，只有同一目标内完成按下与释放才提交；移出、`PointerLeave`、`FocusOut` 或 reconcile 清除未完成动作。默认正文色在 paint 时解析 `color_text`，显式 `.color(...)` 保持调用方颜色。不轮询
- Bar / Line / Pie 与高级图表的 `responsive(true)` 按轴消费父级有界最大尺寸；ScrollView 等未约束轴以 `f32::MAX` 表示无界时回退图表声明尺寸或固有尺寸，禁止把无界哨兵写入 frame / content bounds。有限父约束变化只触发正常布局与重绘，不登记轮询
- Alert 以归一化实际 frame 统一计算状态强调线、图标、消息、说明和关闭槽；消息与说明各保持单行并按 Unicode 省略，正文使用主题 `color_text`，状态色仅承担背景、强调线和图标语义，全部绘制与关闭反馈统一裁在 frame 内。关闭槽仅在同一目标内完成指针按下与释放后提交，移出、`PointerLeave`、`FocusOut`、外部释放或 reconcile 取消未完成动作；`Enter` / `Space` 使用匹配键盘释放，`Escape` 直接关闭。关闭后 measure 返回零尺寸并请求一次布局，运行态 visibility 不被无关 reconcile 重开；无障碍 Alert 名称发布消息，非空说明发布为 value text。不轮询
- Drawer 的遮罩面板尺寸先归一化并收敛到真实 surface，四个 placement 共用有限非负 panel 几何；48 logical header、可选 footer、正文 body、标题/extra/关闭槽和内容子树共享裁剪边界，标题与 extra 在关闭槽前 Unicode 单行省略。闭合态发布 Button + `expanded=false` 并仅在匹配 PointerUp / KeyUp 后打开；父布局拉伸时，96×32 触发器的绘制与 hit-test 共同居中。打开态发布 Dialog + `expanded=true`，关闭槽同目标完整释放才关闭，移出、失焦或交互几何改变的 reconcile 取消未完成动作，Escape 仍由最上层 Drawer overlay 优先处理。遮罩、z-index 1000 和 focus trap 沿用统一 OverlayEntry；进出场继续只在注册动画期间请求帧。不轮询
- controlled Slider 以 `State<f64>` 为外部真值：构建期读取并按 inclusive range 约束显示，拖动、方向键与语义增减同步回写，绘制期依赖只绑定本节点 Paint；非受控 `default_value` 仅是初值，无关 reconcile 保留运行值。区间、步进与公开快照统一使用 `f64`；指针按区间起点取最近步进网格，方向键从离格值进入对应方向的相邻网格，结果按起点与步长的小数精度归一。`marks(Vec<(f64, label)>)` 只保留区间内有限值，按数值排序并由后项覆盖重复值；刻度点与 thumb 共用轨道映射，活动色由当前值决定，不参与 step 或命中。相邻刻度中点划分互不覆盖的标签裁切单元，marks 配置为三档固有高度追加 18 logical 标签带；受限布局只绘制剩余标签高度，标签带不扩大交互框。`.tooltip(TooltipPlacement)` 只在左键拖动捕获期间以 thumb 为锚点显示当前 `f64` 文本，复用 Tooltip 的四方向气泡、箭头与 z-index 1100 overlay；移动 damage 同时覆盖前后气泡，释放后清除旧气泡，不改变固有尺寸、step 或命中区。绘制与命中使用本次实际控件框：受限高度按名义高度等比缩放轨道和滑块半径，极窄宽度把半径封顶到半宽；轨道、thumb、marks 与标签裁在组件 frame 内，拖动提示作为 overlay 绘制。框外按下不启动拖动，已捕获拖动跨过 `PointerLeave` 后保持到 `PointerUp`。不轮询
- `Slider::range` 返回独立 `RangeSlider`，以 start / end 两个 `State<f64>` 分别托管下界与上界 thumb；绘制、指针映射、区间起点步进网格、小数精度收敛、三档尺寸和受限裁切与单值 Slider 同源。指针按轨道距离激活最近 thumb，重叠时按指针所在侧选择，方向键操作最近一次激活 thumb；start 不得越过 end，end 不得越过 start，反向外部值显示为 start 收敛到 end 而不交换 State 身份。双值 Change、公开快照和无障碍 `value_text` 使用稳定 `start..end`，`value_now` 发布当前激活 thumb；reconcile 保留激活、拖动与 hover 运行态并只替换声明配置和绑定。框外按下不启动拖动，捕获拖动跨 `PointerLeave` 保持到释放。不轮询
- Upload 的原生 `FileDrop` 与程序化 `try_add_file` 共用 accept、max_count 和可选 `max_size(bytes)` 过滤；一次拖放再由 multiple 限制本批接收数。真实存在的普通文件通过 metadata 读取字节数并写入 `UploadFile::size`，同时把原路径保存在 `source_path`；大于上限或目录时拒绝，无法读取 metadata 的合成路径为兼容程序化队列按未知大小 0 接收且不保存预览路径。被拒绝项不入队、不发 Change；成功拖放只发布本批实际入队文件。`dragger()` 保持完整 100 logical 拖放区；`show_upload_list` 只控制文件列表的布局与绘制，不改变队列。可见列表每项使用 32 logical 行展示文件名、格式化字节数、进度、状态与右侧移除槽；`preview_image(true)` 仅对带真实路径且能由共享 `ImageService` 解码的文件生成 24×24 logical、cover 裁切的圆角缩略图，解码失败或非图片稳定回退文件图标，不改变行高。`manual(true)` 下，`upload()` 只把调用时仍为 Pending 的项原子转为 Uploading，并返回该次应用侧传输批次；已派发项、完成项和失败项不会重复进入后续批次，非手动模式调用返回空批次。该方法不执行 I/O，应用服务消费返回的 `UploadFile` 后用 `update_progress` / `complete_file` 回写结果。移除槽按最近实际宽度命中，成功移除发布 `<文件名>:removed` Change 并请求重排。程序化增删、清空、max_count 截断及列表显隐沿同一有界 layout request 收敛；reconcile 保留既有队列并同步预览与手动配置。除显式图片预览外组件不读取文件内容，且从不执行传输。不轮询
- controlled Rate 以 `State<u32>` 为外部真值：构建期按离散评分上限约束显示，点击、方向键与语义增减同步回写，绘制期依赖只绑定本节点 Paint；非受控 `default_value` 仅是初值，无关 reconcile 保留运行值。普通模式一个数值单位对应一星，`allow_half` 模式一个单位对应半星，公开快照与无障碍 `value_max` 使用同一单位。半选字符由左右两个 clip 分别绘制活动色与空态色，不用容器背景擦除；默认字符保持每星 24 logical 的 Medium 格宽，显式自定义字符按 Unicode 可见宽度扩大格宽。绘制与命中共用本次实际控件框，受限高度同步缩放字号和格宽，框外指针不改变值，所有文字与焦点图形均裁在控件框内。不轮询
- controlled DatePicker 以 `State<Date>` 为外部真值：构建期读取触发结构 reconcile，选日同步回写，绘制期读取只绑定本节点 Paint；非受控 `default_value` 仅是初值，无关 reconcile 保留选值、弹层开闭与浏览月份。禁用谓词只在命中测试/绘制中求值，Week / Month / Quarter 先归一到周一/月初/季初再提交。触发框按实际高度相对名义尺寸缩放文字、内边距与图标，文字区在图标前单独裁切，全部触发绘制再裁在实际框内。共享月历面板至少 160 logical 宽，月份标题按实测文字宽度居中，左右 32 logical 边缘同时作为导航图标与命中区，星期标题行与六行 30 logical 日期网格分别布局，绘制与命中共用同一几何。打开状态注册为 z-index 900 的 Popover overlay，边界覆盖触发框与月历，避免后绘制兄弟覆盖或截获弹层点击；FocusIn、hover 清除和无关按键分别维护焦点重绘、旧高亮重绘与事件冒泡，快照导出格式化日期及 `expanded` 供无障碍 / Agent 读取。不轮询
- DateRangePicker 复用同一日历面板，以两个 `State<Date>` 为外部真值；首击仅保留组件内 pending 起点，hover 把 pending 与当前命中排序为绘制预览，次击排序后回写双 State，reconcile 保留弹层、浏览月份与未完成选择。预设在构建期解析为起止值，点击与普通范围共用禁用端点和提交路径；预设 footer 与每个 24 logical 行分别裁切，长标签不扩大浮层 damage。触发框按实际高度相对名义尺寸缩放范围文字、内边距与图标，文字区在图标前单独裁切；打开状态注册为 z-index 900 的 Popover overlay，边界覆盖触发框、月历和全部预设行，避免后绘制兄弟覆盖或截获点击。FocusIn、hover 清除和无关按键分别维护焦点重绘、旧预览重绘与事件冒泡，快照发布稳定范围文本及 `expanded`。无逐帧工作
- controlled TimePicker 以 `State<Time>` 为外部真值，`value_configured` 单独区分未配置值与有效的 `00:00`；指针选中单列时保留另一列并立即回写，键盘以活动列维护小时 / 分钟高亮并在 Enter 时合并提交。小时和分钟分别使用 24 / 60 个 32 logical 行及独立滚动位置，打开时把当前值居中到 200 logical 高视口，滚轮只改变指针所在列，绘制、hover 与点击使用同一行索引。触发框按实际高度相对名义尺寸缩放文字、内边距与时钟图标，文字区在图标前单独裁切；弹层至少 120 logical 宽，两列标签按实测文字宽度居中并整体裁切。打开状态注册为 z-index 900 的 Popover overlay，边界覆盖触发框和弹层；FocusIn、PointerLeave 与无关按键分别维护焦点、恢复已提交高亮及事件冒泡，快照发布 `HH:MM` 与 `expanded`。无逐帧工作
