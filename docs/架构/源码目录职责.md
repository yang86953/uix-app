# `src` 目录职责

`src/lib.rs` 是 crate 组合根，`src/prelude.rs` 是常用公开入口集。`src` 下的九个顶层目录按领域责任划分；物理路径用于实现导航，不改变既有公开 Rust 模块路径。

| 顶层域 | 职责 | 主要功能组 |
|---|---|---|
| `app` | 应用 System 的组装、生命周期、主循环与窗口会话 | `application/lifecycle` 运行时，`event_loop` 主循环，`window/presentation_bridge` 呈现桥接，`window/window_driver` 窗口驱动，`agent` 自动化接入，`queues` 私有队列契约 |
| `bus` | 模式外的进程内类型化事件分发基础设施 | 订阅、发布与订阅生命周期 |
| `core` | 不属于单一 System 的稳定基础值与失败契约 | `damage` 损伤区域，`error` 类型化错误，`geometry` 基础几何，`identity` 稳定身份 |
| `data` | 冷路径数据服务与持久化边界 | `settings` 设置模型、验证与存取 |
| `diagnostics` | 运行时观察、有界报告与恢复协调 | `reporting` 报告构造/留存/发射，`recovery` 恢复订阅，`crash` 崩溃报告，`pending` 失败队列 |
| `draw` | Drawing System：图形命令、资源、场景与渲染执行 | `geometry` 几何，`painting` 绘制编码/录制，`raster` 光栅化，`renderer` 渲染调度，`resources/font/{service,text/backends}` 字体与文本，`scene` 场景，`backend/{cpu,gpu/execution}` 后端执行，`backend/frame_plan*` 设备计划，`backend/rhi_renderer*` 通用 RHI lowering 与帧所有权 |
| `native` | platform System 的 crate 私有 concrete OS/API Adapter 与内部装配 | `backends/{linux,macos,windows}` 按 OS 分组，其中继续按 `host/windowing/presentation` 分类；`presentation/graphics/{vulkan,d3d11,opengl}` 实现中立 RHI/Surface 合同；`factory` 只登记原生图形 recipe |
| `platform` | 面向应用的稳定跨平台合同、门面与唯一组合根 | `host` 主机能力，`windowing` 窗口/输入合同，`presentation/rhi` 通用图形合同，`runtime` 平台运行时句柄；`composition_root.rs` 唯一选择、创建和注入 concrete native backend |
| `ui` | UI System：声明式 View、组件运行时、布局、通用主题与中性原语 | `coordination` 跨 UI Module 协调，`widget_runtime` 组件实例/状态，`theme/painting` 主题绘制，`event/text_selection` 事件与文本选择，`accessibility/actions` 语义动作，`layout` 布局值与算法，`view` 声明式入口，`primitives` 中性容器、文本、滚动和 Unicode 编辑；具体控件在独立 `uix-widgets` 包 |

`platform` 与 `native` 两个物理目录共同构成 platform 层：前者拥有中立合同和唯一组合根，后者只拥有 concrete adapter 与内部装配；差异不得反向泄漏到 `app`、`ui`、`draw`。

## 兼容与保留路由

- `#[path]` 只把既有逻辑模块名路由到新的物理目录；`ui::__private`、公开宏展开路径和 feature/cfg 门控继续使用原名。
- `ui/widgets/other` 及 `other/misc` 只保留历史兼容路由；实现已物理归入 `display`、`containers`、`general` 和 `input`。
- `native/windowing/shared` 仍为 Linux、macOS 和 Windows 窗口 Adapter 共用的单一实现组。它同时承载窗口状态、IME 事件与生命周期契约，未在没有行为改动的前提下硬分。
- `platform` 已按公开能力整理，本次冻结其物理布局。`core`、`bus`、`data` 也保留已清晰的现有结构。
