# UIX 的 SMC 架构采用

本项目声明采用 SMC v2.0，范围为全部自有 Rust 代码。精确采用标识以
[Cargo.toml](../../Cargo.toml) 的 `workspace.metadata.smc` 为准，当前
`spec_revision = 84a99b0166f68b60ca9bf996199748d300acacb2`。
该外部规范未随本仓库发布；本页说明项目自身的组织决定，不复制或重新授权外部规范。

- App 负责应用组合根、生命周期、窗口和服务装配；platform/native 拥有系统资源。
- ui 拥有界面状态、布局和语义投影；draw/graphics 负责绘制和提交。
- data 和 diagnostics 各自持有持久化与失败恢复责任。
- 编译器、运行时、CLI、LSP、derive、示例与编辑器扩展遵循同一声明范围。
- 模块按变化原因和状态/资源责任划分；固定的进程内执行可以直接调用，不为形式统一引入多层对象或事件总线。
- 权限、容量、所有权、订阅注销和资源回收是实际实现边界，不由目录命名或历史验收替代。

具体边界见[系统列表](系统列表.md)、[路由清单](路由清单.md)及[源码目录职责](源码目录职责.md)。
验证按真实变更与风险选取；本页不是全部平台、功能或测试通过的状态表。
采用文档在本仓库维护，内部工作记录不承担公开产品事实。
