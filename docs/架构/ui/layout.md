## 模块定位

layout 模块（`src/ui/layout/`）负责计算每个组件节点的位置和尺寸。分两阶段：**measure**（自底向上确定尺寸）→ **layout**（自顶向下分配位置）。通过 scratch 缓冲复用、快照复用和增量失效控制内存与性能。
