## 内容摘要

UIX 提供完整的 App 开发能力：界面组件库、类型安全表单、数据展示、动画、浮层、统一图形 API、多窗口、平台能力、键值存储与国际化。

明确**不做**：网络/同步、WebView 运行时、远程控制、远程日志上传、独立 UI 脚本语言。
