# 教程 —— 从零搭建一个待办应用

本教程用一个完整的 TODO 应用带你走完 UIX 的核心概念：State、View 组合、事件、表单、列表和布局。

> 前置：已按[快速开始](快速开始.md)配好 `Cargo.toml`。

## 1. 最小骨架

```rust uix-compile=tutorial-step1
use uix::prelude::*;

fn main() {
    App::new()
        .title("待办")
        .size(400, 500)
        .root(|| label("Hello, TODO!").font_size(24.0))
        .run();
}
```

## 2. 用 State 管理数据

把待办列表存到 `State` 中——UIX 的响应式基石：

```rust uix-compile=tutorial-step2
let todos = State::new(vec![
    "学习 UIX".to_string(),
    "写一个应用".to_string(),
]);

// 读取
println!("当前有 {} 条待办", todos.get().len());

// 写入
todos.update(|list| list.push("部署上线".to_string()));
```

## 3. 组合 View：输入框 + 列表 + 按钮

```rust uix-compile=tutorial-step3
use uix::prelude::*;

fn main() {
    let todos = State::new(vec![
        "学习 UIX".to_string(),
        "写一个应用".to_string(),
    ]);
    let input_text = State::new(String::new());

    App::new()
        .title("待办")
        .size(400, 500)
        .root(move || {
            let input_for_add = input_text.clone();
            let todos_for_rows = todos.clone();
            column((
                // 输入区
                row((
                    input()
                        .placeholder("输入待办事项")
                        .value(&input_text)
                        .flex_grow(1.0),
                    button("添加").primary()
                        .on_click(&todos, move |list| {
                            let text = input_for_add.get();
                            if !text.is_empty() {
                                list.update(|items| items.push(text));
                                input_for_add.set(String::new());
                            }
                        }),
                )).gap(8.0),

                // 列表
                todos.map(move |list| {
                    column(list.iter().enumerate().map(|(i, item)| {
                        let todos = todos_for_rows.clone();
                        row((
                            label(format!("{}. {}", i + 1, item)).flex_grow(1.0),
                            button("完成").on_click(&todos, move |list| {
                                list.update(|l| { l.remove(i); });
                            }),
                        ))
                        .gap(8.0)
                        .padding_v(4.0)
                    }).collect::<Vec<_>>())
                }),
            ))
            .gap(16.0)
            .padding(16.0)
        })
        .run();
}
```

此时你应该能添加和完成待办事项了。

## 4. 图片预览与浮层

如果你的 TODO 需要附件预览，加上 `Image` 组件：

```rust uix-compile=tutorial-step4
Image::new(320.0, 200.0)
    .src("assets/screenshot.png")
    .alt("截图预览")
    .radius(8.0);
```

点击图片会弹出模态预览——浮层由框架自动管理，详见[反馈](反馈.md)。

## 5. 多窗口：把详情拆到独立窗口

```rust uix-compile=tutorial-step5
App::new()
    .on_start(|handle| {
        let _detail_win = handle.open_window(
            WindowConfig::new("详情", 300, 200, || {
                label("这里是详情窗口")
            })
        );
    })
    .root(|| label("主窗口"))
    .run();
```

## 6. 加入动画

让"完成"按钮点击后待办项淡出：

```rust uix-compile=tutorial-step6
// 在 component! 中集成动画
component! {
    pub struct FadingTodo {
        text: String,
        fade: Animation<f32>,
    }

    @new -> Self {
        Self {
            text: String::new(),
            fade: Animation::new(1.0, 0.0, 0.3).easing(Easing::ease_out),
        }
    }

    render => (&self, frame: Rect, ctx: &mut PaintContext) {
        // 从动画读取当前透明度
        let alpha = self.fade.value();
        ctx.fill_rect(frame, Color::WHITE.with_alpha((alpha * 255.0) as u8), None);
        ctx.draw_text(&self.text, Point::new(frame.x + 8.0, frame.y + 4.0),
            Color::BLACK.with_alpha((alpha * 255.0) as u8), 14.0);
    }

    update_animation => (&mut self, dt: f64) -> bool {
        self.fade.update(dt);
        !self.fade.is_finished()
    }
}
```
