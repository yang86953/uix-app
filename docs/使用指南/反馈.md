# 浮层与反馈

框架自动维护 `OverlayStack`，应用不手管层级。

## Modal

```rust uix-compile=modal-overlay
Modal::show(|ctx| {
    let cancel_ctx = ctx.clone();
    let confirm_ctx = ctx;
    column((
        label("确认删除？").font_size(18.0),
        row((
            button("取消").on_click_fn(move || cancel_ctx.close()),
            button("确认").danger().on_click_fn(move || {
                // 执行删除
                confirm_ctx.close();
            }),
        )).gap(8.0),
    ))
    .gap(16.0)
})
.title("提示")
.width(400.0);
```

`Modal::show` 打开 overlay 并把闭包返回的 `View` 作为普通内容子树；默认隐藏内置 footer，由内容自行声明操作按钮。`ModalContext` 可 clone，`ctx.close()` 应在该子树的事件回调中调用，只关闭持有此 context 的 Modal，并先播放现有 leave transition。需要直接构造底层组件时，用 `Modal::new("标题").visible(true)` 声明初始打开状态。

## Drawer

```rust uix-compile=drawer-overlay
tree! { Drawer::new("详情")
    .placement(DrawerPlacement::Right)
    .size(480.0, 640.0)
    .show() => [
    label("抽屉内容"),
]};
```

闭合态内置触发器是可聚焦 Button，指针或 `Enter` / `Space` 必须完成匹配释放才打开；父布局拉伸 frame 时，96×32 的触发视觉与命中区域共同居中。打开后切换为 Dialog 语义并由 Drawer overlay 约束 Tab 焦点。关闭按钮同样只在同一目标内完整释放后提交，移出、失焦或外部释放会取消，`Escape` 关闭最上层 Drawer。`.size(width, height)` 会把非有限/负尺寸归零，并把遮罩 Drawer 收敛到实际 surface；标题与 `extra` 各自在关闭槽前单行省略，面板、header/footer、关闭反馈和内容子树统一裁在实际区域内。`footer_visible(true)` 目前只提供本地化确认按钮的视觉槽，业务提交仍应放在内容子树中绑定真实 Button。

## Message / Notification

```rust uix-compile=message-notification
let messages = Message::new().placement(Placement::BottomLeft);
let message_handle = messages.handle();
let saved = message_handle.success("保存成功");
messages.error("保存失败");
message_handle.dismiss(saved); // 启动该项离场动画

let notifications = Notification::new().placement(Placement::TopRight);
let notification_handle = notifications.handle();
let updated = notification_handle.info("更新完成", "已更新到 v2.0");
notifications.warning("空间不足", "请清理缓存后重试");
notification_handle.dismiss(updated);
```

`Message` 默认置顶居中，`Notification` 默认置于右上角；二者共享 `Placement`，可选 `Top`、`Bottom`、`Left`、`Right` 及四个角。`add(...)`、`success/info/warning/error(...)` 返回稳定 ID；handle 可在组件交给 View 后继续增删队列。`MessageItem` / `NotificationItem` 的 `duration_ms = 0` 表示持续展示，直到 `dismiss(id)`、`clear()` 或关闭按钮触发离场。其他项在进入动画完成后开始计时，持有期间不申请动画帧，只登记最近一个到期 timer。

队列始终约束在所属窗口的 logical 客户区内，底部放置时整组向上避让；空队列不占布局，也不拦截命中。后台线程不直接操作组件 handle；用目标窗 `AppHandle::post_to_ui` 回到 UI 线程（详见[定时与异步](定时与异步.md#跨线程回-ui)）。`AppHandle::notify_error` 使用目标窗口自己的通知队列；返回的 ID 可交给 `dismiss_notification(id)`，不会唤醒或修改其他窗口。

## Popover / Tooltip

```rust uix-compile=popover-tooltip-popconfirm
tree! { Popover::new("弹出内容").trigger(PopoverTrigger::Click) => [
    Button::new("详情"),
]};

tree! { Tooltip::new("提示文字").trigger(TriggerMode::Hover) => [
    Button::new("悬停查看"),
]};

tree! { Popconfirm::new().title("确定删除？") => [
    Button::new("删除").danger(),
]};
```

三类组件都是交互包装器：子 View 负责展示，包装器接管其指针命中区域并执行 click / hover 触发；选择 focus 触发时，包装器观察整个子树的焦点边界，同一包装器内切换子控件不会关闭重开，焦点离开或已聚焦子树移除时才关闭。Tooltip 的单行气泡按 12 logical、Unicode 宽字符和 16 logical 横向 padding 计算自然宽度，绘制、overlay bounds 与 damage 使用同一尺寸，CJK 文本不会按 UTF-8 字节数放大。`Popconfirm` 只响应鼠标左键；自身可用 Tab 聚焦，关闭时按 Enter / Space 打开，打开后用 Left / Right / Home / End 选择确认或取消，按 Enter / Space 执行，按 Escape 或让焦点离开整个包装器则关闭。确认后弹层关闭并发出载荷为 `"confirm"` 的 `SemanticKind::Submit`，可在返回的 View 上用 `.on_submit(...)` 执行业务动作；取消或点击外部只关闭弹层。

## 进度与加载

```rust uix-compile=progress-loading
ProgressBar::new().progress(0.65).round(false); // 65%，方角
ProgressBar::new().indeterminate();             // 不确定进度
ProgressBar::new().progress(0.8).circle();       // 圆形进度
Spin::new().large();                             // 大号加载旋转
Skeleton::new().size(320.0, 48.0);               // 骨架占位
```

确定进度把 `0.0..=1.0` 暴露为 `ProgressBar` 的 `value_now/min/max`；不确定进度只保留 role，不伪造当前值或范围。非有限 progress 收敛为 0，有限值裁到该区间；负数或非有限宽高收敛为 0，小尺寸圆形进度也不会产生负半径。

`Skeleton` 提供 `Rect`、`Circle` 与两行 `Text` 三种静态占位形态。`.size(width, height)` 的负数或非有限尺寸收敛为 0；布局继续约束时，圆角、圆形半径以及 Text 的行高与间距都按实际 frame 重新计算，并统一裁在该 frame 内。

## FocusTrap —— 焦点陷阱

Modal 和 Drawer 自动启用焦点陷阱：Tab / Shift+Tab 仅在浮层内可聚焦节点间循环，无法逃逸到底层视图。

手动使用时：

```rust uix-compile=manual-focus-trap
tree! { FocusTrap::new().active(true) => [
    Input::new("用户名"),
    Button::new("提交"),
]};
```

框架自动收集子树的 `focusable_ids`，并在 Tab 键事件中调用 `next_focus()` 按深度优先顺序循环。

## 浮层类型

框架内部通过 `OverlayStack` 管理浮层层级。`OverlayKind` 枚举定义浮层类别：

| 变体 | 对应组件 | 默认行为 |
|------|----------|----------|
| `Modal` | `Modal` | modal + dismiss_on_outside + focus_trap |
| `Drawer` | `Drawer` | modal + dismiss_on_outside + focus_trap |
| `Popover` | `Popover` | 点击外部关闭 |
| `Tooltip` | `Tooltip` | hover 触发 |
| `ContextMenu` | — | 右键菜单 |
| `Message` | `Message` | 自动消失 |
| `Notification` | `Notification` | 自动消失 |
| `Custom` | 自定义 | 无预设行为 |

`OverlayEntry` 可通过 `managed()` 标志交由框架自动清理（默认所有内置浮层均为 managed），也可设为 `false` 手动管理生命周期。

## Alert

```rust uix-compile=alert-feedback
Alert::new("注意")
    .description("这是一条提示信息")
    .show_icon(true)
    .closable();
```

`.closable()` 让关闭按钮进入 Tab 顺序；指针必须在关闭区内完成按下与释放才会提交，移出、失焦或在外部释放会取消。聚焦后 `Enter` / `Space` 也在匹配释放时提交，`Escape` 可直接关闭；关闭会隐藏当前 Alert、触发布局回收并发出载荷为 `"closed"` 的 `SemanticKind::Change`。`show_icon(false)` 可隐藏状态图标；需要复用同一实例时可调用 `open()` / `close()`，应用 reconcile 不会把用户已经关闭的运行态重新打开。消息与说明各保持单行并在实际宽度内按 Unicode 省略，所有状态色、图标、文字、关闭反馈和焦点框统一裁在实际 frame；无障碍名称发布消息，非空说明发布为可访问值。

## FloatButton

```rust uix-compile=float-button
let create = FloatButton::new("+")
    .tooltip("新建")
    .badge(3)
    .size(44.0)
    .position(12.0, 8.0)
    .reserve_layout_space(true);
```

`FloatButton` 默认保持零布局占位，以 `.position(x, y)` 设置相对槽位左上角的视觉偏移，并由[浮层栈](#浮层类型)提升绘制层级；需要内联预览或为锚点保留空间时显式设置 `.reserve_layout_space(true)`，此时按钮进入普通布局与绘制顺序。真实按钮区域参与命中、脏区与语义边界。组件默认进入 Tab 顺序，点击或按 `Enter` / `Space` 触发普通 `SemanticKind::Click`，可在返回的 View 上直接链 `.on_click(...)`；tooltip 在 hover 或键盘聚焦时显示。`FloatButtonBackTop::new()` 只提供箭头与文案预设，滚动动作仍通过 `.on_click(...)` 绑定应用持有的滚动 `State`，配合 [BackTop](布局.md#affix-backtop-sider) 使用。
