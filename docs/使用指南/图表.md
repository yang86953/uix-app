# 图表

图表组件支持静态展示和动态数据。数据通过 `State` 驱动时，修改 State 后框架自动重绘图表：

```rust uix-compile=dynamic-chart
let data = State::new(vec![
    BarData::new("Q1", 120.0, Color::hex("#1677ff")),
    BarData::new("Q2", 200.0, Color::hex("#52c41a")),
]);

// 在 App::root 中绑定
BarChart::new()
    .data(data.get())
    .width(400.0)
    .height(300.0);

// 业务代码中更新数据
data.update(|d| d.push(BarData::new("Q3", 150.0, Color::hex("#faad14"))));
```

三种图表的使用示例：

```rust uix-compile=charts
// 柱状图
BarChart::new()
    .data(vec![
        BarData::new("Q1", 120.0, Color::hex("#1677ff")),
        BarData::new("Q2", 200.0, Color::hex("#52c41a")),
        BarData::new("Q3", 150.0, Color::hex("#faad14")),
    ])
    .width(400.0)
    .height(300.0);

// 折线图
LineChart::new()
    .data(vec![
        LineData::new("Jan", 100.0),
        LineData::new("Feb", 150.0),
        LineData::new("Mar", 130.0),
    ])
    .width(400.0)
    .height(300.0)
    .dot_radius(4.0);

// 饼图
PieChart::new()
    .data(vec![
        PieData::new("产品A", 40.0, Color::hex("#1677ff")),
        PieData::new("产品B", 30.0, Color::hex("#52c41a")),
        PieData::new("产品C", 30.0, Color::hex("#faad14")),
    ])
    .size(300.0)
    .donut(0.55);
```

`BarChart` 以零线同时承载正值与负值；显式 `max_value(...)` 作为正向轴上限，超出部分裁在绘图区内。数据中的非有限值按 0 绘制，非法宽高回到自动尺寸，最终测量仍服从父级 `Constraints`。图表以 `Image` 角色进入无障碍树，并用各数据项的 label / value 提供结构化值文本。

`LineChart` 会绘制单个数据点而不是把单点序列当成空图；`auto_min(true)` 使用数据下界，默认下界为 0，`max_value(...)` 可固定上界。非有限数据按 0 映射，`line_width(...)` / `dot_radius(...)` 会规范化非法几何值；折线图同样服从父级约束并以 label / value 暴露无障碍值文本。

`PieChart` 只把有限正值计入扇区和总量，零值、负值及非有限值不会生成非法角度；有空间时会在右侧绘制 label / 百分比图例。`donut(...)` 接受 0～0.9 的半径比例，非法尺寸与圆环比例回到安全默认；无障碍值文本只包含实际参与绘制的扇区。
