# 数据展示

## Label

```rust uix-compile=label-text
Label::new("主标题\n辅助说明")
    .font_size(14.0)
    .selectable();
```

`Label` 用于短文本和调用方显式分行的文本：固有尺寸会按最长一行、中日韩宽字符、样式或物理单位字号、padding 与完整行数测量，后继布局不会压到已绘制的第二行或后续行。`font_size` 的非有限值、零或负数回到默认 12 logical，测量与绘制使用同一归一结果。默认不进入文字拖选；调用 `.selectable()` 后支持拖选、`Ctrl+A` 与 `Ctrl+C`。`Label` 不按可用宽度自动折行；需要自动折行、标题层级或文字装饰时使用 [`Typography::paragraph`](#typography)。

## Card

```rust uix-compile=card-actions
Card::new()
    .title("账户")
    .actions(vec!["保存", "取消"])
    .child(Label::new("账户设置"));
```

`Card` 未指定尺寸时采用 200×120 logical 默认尺寸，显式尺寸、padding 与 `flex_grow` 会规范化非有限或负值。非空 action footer 自动进入 Tab 顺序；鼠标点击或 `Left` / `Right`、`Home` / `End` 选择操作，`Enter` / `Space` 以 action 文本发出 `SemanticKind::Submit`。当前操作可由 `focused_action()`、`action_labels()` 或 `SnapshotFields::Card::focused_action` 读取；Card 以标题命名的 `Group` 角色进入无障碍树。

## Avatar

```rust uix-compile=avatar-image
let user = Avatar::new("Ada")
    .src("assets/avatar.png")
    .size(48.0);
let fallback = Avatar::new("AL").square(true);
```

`src` 在首次绘制时通过共享图片服务加载并缓存；圆形 Avatar 会先居中裁成正方形并写入透明圆形遮罩，图片失败时继续显示 `text` 首字母，不要求应用维护加载状态。`square(true)` 使用方形图片区域。`size` 只接受有限正值，非法值回到 32 logical；Avatar 以 `text`（为空时依次使用 `src`、`"Avatar"`）命名的 `Image` 角色进入无障碍树。

## Badge

```rust uix-compile=badge-status
let synced = Badge::new()
    .status(BadgeStatus::Success)
    .text("已同步");
let overflow = Badge::new().count(120).max(99);
let notice = Badge::new().dot().text("新消息");
```

`status(...)` 与 `dot()` 都可用 `.text(...)` 在圆点右侧显示状态文字，该文字同时作为 `Status` 无障碍名称；普通胶囊同时设置 count 与 `.text(...)` 时，文字在视觉、固有尺寸和语义名称中优先。胶囊文字按 11 logical、圆点右侧文字按 13 logical 及 Unicode 宽字符估算自然宽度；计数会暴露实际 `value_now`，视觉超过 `max` 时按实际显示的 `max+` 量宽。负数 count 收敛到 0，`max` 至少为 1；零计数默认不绘制也不进入语义树，使用 `.show_zero(true)` 才显示。像素或物理单位 offset 转换后的非有限分量在绘制时按 0 处理，避免徽标因非法坐标消失。

## Image

```rust uix-compile=image-preview
let product = Image::new(320.0, 200.0)
    .src("assets/product.png")
    .alt("产品正面图")
    .fallback("图片加载失败")
    .radius(8.0)
    .fit(true);

let thumbnail_only = Image::new(96.0, 96.0)
    .src("assets/avatar.png")
    .alt("用户头像")
    .preview(false);
```

`preview` 默认开启：图片进入 Tab 顺序，点击或聚焦后按 `Enter` / `Space` 会在当前窗口内打开真实图片预览；按 `Escape`，或点击预览层任意位置即可关闭。预览层是模态浮层，只阻止所属窗口的底层交互；`.preview(false)` 保持普通静态图片语义。`is_preview_open()` 可读取运行态，也可用 `open_preview()` / `close_preview()` 显式控制；应用 reconcile 会保留已打开的预览，除非下一次配置关闭 `preview`。

`alt(...)` 是图片的无障碍名称：加载成功后不会额外绘成框外标题；加载失败时优先在图片边界内显示 `fallback(...)`，否则显示 `alt`，长文字会在实际可用宽度内换行。缩略图、占位内容、焦点和预览提示都裁剪在实际 frame 内；`radius(...)` 同时作用于背景和按物理像素生成的位图圆角，`fit(true)` 的等比居中与 `fit(false)` 的拉伸填满均保持该圆角。

## ResultView

```rust uix-compile=result-view
let failure = ResultView::new(ResultType::Error)
    .title("保存失败")
    .subtitle("请检查网络后重试")
    .extra_text("重试");
```

未设置 `extra_text` 时，`ResultView` 是不进入 Tab 顺序的状态展示；设置后，额外操作区成为具名 `Button`，点击或按 `Enter` / `Space` 触发普通 `SemanticKind::Click`，可在返回的 View 上链 `.on_click(...)` 执行业务动作。操作区以外的结果页不吞掉指针事件。

图标、标题、副标题和操作区按实际 frame 自适应排列并整体裁剪；窄尺寸优先保留标题与副标题各一行，长按钮文字按 Unicode 字符边界省略。操作区的绘制与命中使用同一实时几何，指针必须在按钮内完成按下和释放才会提交。未显式设置标题时，当前 locale 的默认结果标题会同时用于视觉与无障碍名称；404 / 403 / 500 的默认说明作为状态值发布。

## Table

### 数据行格式

简单数据可继续使用 `TableRow = Vec<String>`，单元格顺序与 `columns` 一一对应：

```rust uix-compile=table-features
let users: Vec<TableRow> = vec![
    vec!["Ada".into(), "28".into(), "Admin".into()],
    vec!["Bob".into(), "35".into(), "User".into()],
];

let expandable = Table::new()
    .columns(vec![
        TableColumn::new("姓名", 120.0),
        TableColumn::new("年龄", 80.0),
        TableColumn::new("角色", 100.0),
    ])
    .rows(users.clone())
    .expandable(48.0, |row| {
        column((
            label(format!("姓名: {}", row.first().map_or("", String::as_str))),
            label(format!("年龄: {}", row.get(1).map_or("", String::as_str))),
        )).padding(12.0)
    })
    .sortable(true)        // 所有列头可切换排序方向
    .selection(true)       // 显示行复选框与表头全选
    .bordered(true);
```

业务结构体使用 `Table::data(rows, row_key)`；key 必须唯一，列通过 `bind` 投影文本，也可继续链 `render` 物化任意 `View`：

```rust uix-compile=table-typed-rows
struct UserRow {
    id: u64,
    name: String,
    age: u32,
    online: bool,
}

let users = vec![
    UserRow { id: 10, name: "Ada".into(), age: 28, online: true },
    UserRow { id: 20, name: "Grace".into(), age: 35, online: false },
];

let typed = Table::data(users, |user| user.id.to_string())
    .expect("row keys must be unique")
    .columns(vec![
        TableColumn::new("姓名", 120.0).bind(|user: &UserRow| user.name.clone()),
        TableColumn::new("年龄", 80.0).bind(|user: &UserRow| user.age.to_string()),
        TableColumn::new("状态", 80.0)
            .bind(|user: &UserRow| {
                if user.online { "在线" } else { "离线" }.to_string()
            })
            .render(|user: &UserRow| {
                embed(Badge::new()
                    .status(if user.online { BadgeStatus::Success } else { BadgeStatus::Default })
                    .text(if user.online { "在线" } else { "离线" }))
            }),
    ])
    .selection(true)
    .virtual_scroll(true);
```

重复 key 返回 `TableDataError::DuplicateRowKey`，不会构建歧义表格。typed 行只在 View build 时执行文本投影，组件仍保存可绘制、可快照的文本；`render` 工厂由框架在组件外托管，普通表物化全部配置单元格，启用 `virtual_scroll(true)` 后只物化 viewport 与 overscan 内的行。单元格以 row key + 列索引参与 reconcile，业务重排会复用仍在窗口内的同一子节点；含 View 单元格的滚动采用布局与重绘，不使用尚未证明一致性的 composite-copy。

reconcile 后 `selected_row` 与 `checked_rows` 按 key 重新映射，排序重建或业务重排不会把状态粘到另一条数据。`selected_row_key()` / `checked_row_keys()` 可直接读取业务身份；`SnapshotFields::Table` 同时包含 `rows`、`row_keys` 与 `view_columns`。普通 `TableRow` 使用行索引字符串作为隐式 key，保持原有索引语义。

### 自定义单元格渲染

`TableColumn::bind` 的文本是确定性绘制 / 快照值；链式 `render` 后该列改由返回的普通 `View` 呈现，因此可以使用 `button(...)`、通过 `embed(...)` 嵌入 Badge 等组件，或返回带 State / Effect 的组合子树。工厂接收原始 typed 行，不需要按列索引反查字符串。

### 其余功能

```rust uix-compile=table-fixed-grouped-virtual
let users: Vec<TableRow> = vec![
    vec!["Ada".into(), "28".into(), "Admin".into()],
    vec!["Bob".into(), "35".into(), "User".into()],
];

// 固定列（宽表必备）
let fixed = Table::new()
    .columns(vec![
        TableColumn::new("姓名", 120.0).fixed(Fixed::Left),
        TableColumn::new("年龄", 80.0),
        TableColumn::new("操作", 100.0).fixed(Fixed::Right),
    ])
    .rows(users.clone());

// 列分组（多级表头）
let grouped = Table::new()
    .column_groups(vec![
        TableColumnGroup::new("基本信息", vec![
            TableColumn::new("姓名", 120.0),
            TableColumn::new("年龄", 80.0),
        ]),
        TableColumnGroup::column(TableColumn::new("部门", 100.0)),
    ])
    .rows(users.clone());

// 虚拟滚动 + Table（万级数据）
let virtualized = Table::new()
    .columns(vec![
        TableColumn::new("姓名", 120.0),
        TableColumn::new("年龄", 80.0),
        TableColumn::new("角色", 100.0),
    ])
    .rows(users)
    .size(320.0, 240.0)
    .virtual_scroll(true)
    .virtual_row_height(32.0);
```

`size(width, height)` 固定表格视口；数据超过高度时仅表体滚动，表头保持可见。`sortable(true)` 让全部列参与排序交互，也可仅对某列使用 `TableColumn::sortable(true)`；点击依次切换 `Asc → Desc → None` 并发出 `SemanticKind::Change`，调用方据此更新 `.rows(...)`。`selection(true)` 的复选框多选与普通行点击的单选状态彼此独立。宽表收到横向 `Wheel` 时自动滚动中间列，`Fixed::Left` / `Fixed::Right` 列保持贴边。排序方向、固定位置、`selected_row`、`checked_rows` 均可从 `SnapshotFields::Table` 读取。

列标题、分组标题、文本单元格和自定义空态均在各自真实可见区域内按 Unicode 字符边界单行省略；列区、表体、边框和焦点框继续统一裁在实际 frame 内，短于表头的受限 frame 不会绘制或命中虚假的首行。`TableColumn::new`、`.size(...)`、`.row_height(...)` 与 `.virtual_row_height(...)` 会规范化非法几何：负数 / 非有限列宽和视口尺寸收敛为 0，有限非正行高收敛为 1，非有限行高回退默认 28 logical。typed `DataTable` 与 expandable `TableBuilder` 使用相同规则。

## List / Tree

```rust uix-compile=list-tree
List::new()
    .items(vec!["Ada", "Alan", "Grace"])
    .header("成员")
    .footer("共 3 人")
    .size(ControlSize::Large)
    .bordered(true);

SelectableList::new()
    .items(vec![
        SelectableItem::new("ada", "Ada"),
        SelectableItem::new("alan", "Alan"),
        SelectableItem::new("grace", "Grace"),
    ])
    .active(1)
    .header_button("Add")
    .footer("3 items")
    .row_height(32.0);

Tree::new(vec![
    TreeNode::new("项目", "project").children(vec![
        TreeNode::new("src", "src"),
        TreeNode::new("tests", "tests"),
    ]),
]);
```

`List` 的 header、item、footer 与 load-more 保持对应尺寸档的固定单行高度；可用宽度不足时按 Unicode 字符边界省略，并统一裁剪在实际 frame 内。空数据优先使用 `ConfigProvider` 配置的 empty factory，未配置时回退到内置 `Empty`。静态列表以 header 作为 `List` 无障碍名称，并在 `value_text` 中发布全部 item 文本。

`List::size(...)` 同时控制 header、数据行和 footer 的行高，三者按 `Small = 32`、`Medium = 40`、`Large = 48` 参与测量与绘制；`.load_more(...)` 是额外的 40px 展示槽，不随数据行尺寸变化。

非空 `SelectableList` 默认进入 Tab 顺序。聚焦后，`Up` / `Down` 移动当前行，`Home` / `End` 跳到首尾，`Enter` / `Space` 重新激活当前行；键盘移动会自动滚动以露出当前项。点击或键盘激活行会发出以 item id 为载荷的 `SemanticKind::Change`，当前项可由 `selected_id()`、`selected_text()` 或 `SnapshotFields::SelectableList::active_index` 读取。指针必须在同一行内完成按下与释放才提交，横向越出实际 frame、行间空隙和 footer 均不命中；头部按钮遵循相同完整点击序列，并以按钮文本发出 `SemanticKind::Submit`，无数据时也可用 `Enter` / `Space` 激活它。header、行与 footer 的文字按 Unicode 字符边界单行省略，图标、文字、背景、分隔线与焦点框统一裁在归一化后的实际 frame 内；受限高度只绘制并命中真实可见的列表视口。非受控列表 reconcile 时按 item id 保持当前选择，业务重排不会把选择粘到另一项。

`Tree` 默认进入 Tab 顺序。聚焦后，`Up` / `Down` 在当前可见节点间移动并跳过禁用项，`Right` 展开节点或进入子树，`Left` 折叠节点或回到父级；`Space` 切换可勾选节点，多选模式下 `Enter` 切换当前节点的选择状态。键盘移动会自动滚动以露出当前节点。选择或勾选变化发出以节点 key 为载荷的 `SemanticKind::Change`；`SnapshotFields::Tree` 提供 `selected_key`、`selected_keys`、`expanded_keys`，每个 `SnapshotTreeNode` 的 `checked` 反映当前勾选状态。

## Collapse

```rust uix-compile=collapse
Collapse::new()
    .panels(vec![
        CollapsePanel::new("账户信息", "姓名与联系方式").expanded(),
        CollapsePanel::new("安全设置", "密码与双重验证"),
    ])
    .accordion();
```

非空 `Collapse` 默认进入 Tab 顺序。`Up` / `Down` 在面板标题间移动，`Home` / `End` 跳到首尾；`Enter` / `Space` 切换当前面板，`Right` 展开，`Left` 折叠。`.accordion()` 保证至多展开一个面板；若初始配置含多个展开项，仅保留第一个。展开变化发出以面板索引为载荷的 `SemanticKind::Change`；当前标题索引和展开项可由 `focused_header()`、`expanded_indices()` 或 `SnapshotFields::Collapse::{ focused_header, panels }` 读取，其中每个 `SnapshotCollapsePanel::expanded` 都是实际状态。

## Calendar / Carousel

```rust uix-compile=calendar-carousel
let calendar = Calendar::new()
    .default_date(Date::new(2026, 7, 15))
    .cell_size(40.0)
    .year_jump(false);

tree! { Carousel::new().show_dots(true).show_arrows(true).size(560.0, 190.0) => [
    label("第一屏"),
    label("第二屏"),
]};
```

`Calendar` 默认进入 Tab 顺序。方向键按一天或一周移动焦点，`Home` / `End` 跳到当月首日或末日，`PageUp` / `PageDown` 切换月份，`Enter` / `Space` 提交日期；`.year_jump(true)` 会让标题箭头和翻页键改为按年跳转。`.default_date(...)` 与 `.default_displayed(...)` 只设置初始值，选择后发出 `YYYY-MM-DD` 载荷的 `SemanticKind::Change`；当前状态可由 `selected_date()`、`displayed_month()` 或 `SnapshotFields::Calendar` 读取。

`Carousel` 的直接子节点就是幻灯片；同一时刻只给当前项分配实际布局，非当前项及其整棵子树由父级可见性 gate 隐藏并归零布局，因此不会残留绘制、命中或焦点候选。`.size(width, height)` 设置首选视口尺寸，最终仍服从父级约束；不设置时固有尺寸为 300×200 logical。子项不少于两个时 Carousel 进入 Tab 顺序，只有其自身聚焦时方向键才循环切换，`Home` / `End` 跳到首尾；箭头和圆点在交互式幻灯片之上仍优先接管对应指针区域。变化发出以零基索引为载荷的 `SemanticKind::Change`。`current_index()`、`slide_count()` 与 `SnapshotFields::Carousel::{ current, slide_count }` 返回运行态。

## 时间轴

```rust uix-compile=timeline
Timeline::new()
    .items(vec![
        TimelineItem::new("2024-01-01").description("项目启动"),
        TimelineItem::new("2024-03-15").description("首次发布").color(Color::green()),
        TimelineItem::new("2024-06-01").description("v2.0 上线"),
    ])
    .pending(true)
    .reverse(false);
```

`pending(true)` 在末尾增加一行待处理节点，该行会计入组件测量高度并与上一节点连接；`reverse(true)` 只反转已完成节点，待处理节点仍保留在末尾。

## 描述列表 / 标签

```rust uix-compile=descriptions-tags
Descriptions::new()
    .items(vec![
        DescriptionsItem::new("用户名", "Ada Lovelace").span(2),
        DescriptionsItem::new("邮箱", "ada@example.com"),
        DescriptionsItem::new("角色", "管理员"),
    ])
    .column(3)
    .bordered(true);

let role = Tag::new("管理员")
    .color(TagColor::Info)
    .checkable(true)
    .default_checked(true)
    .closable();
```

`DescriptionsItem::span(n)` 占用当前行的 `n` 列，超出剩余列宽时整项移到下一行；`span(0)` 按 1 列处理，超过 `.column(...)` 的值收敛到整行。测量高度使用同一装箱结果，跨列项不会与下一项重叠或溢出组件边界。

可勾选 Tag 点击主体或按 `Enter` / `Space` 切换，依次发出载荷为 `"checked"` / `"unchecked"` 的 `SemanticKind::Change`；关闭区、`Delete` 或 `Escape` 会隐藏可关闭 Tag 并发出 `"closed"`。`is_checked()` / `is_visible()` 读取运行态，`set_checked(...)`、`open()` / `close()` 可直接控制；应用 reconcile 保留用户已经切换或关闭的状态。仅可关闭且不可勾选时，`Enter` / `Space` 也执行关闭。Tag 的自然宽度按 Unicode 宽字符、字号和固定动作区计算：勾选区增加 14 logical，可关闭区增加 20 logical；关闭符号使用 Lucide `x` 图标，不依赖正文字体是否包含该符号。`.font_size(...)` 的非有限值、零或负数统一回到默认 12 logical，测量与绘制一致。

## RichText

```rust uix-compile=rich-text-links
let article = RichText::new()
    .content(vec![
        RichTextSegment::Text {
            content: "查看 ".into(),
            style: RichTextStyle::default(),
        },
        RichTextSegment::Link {
            content: "使用指南".into(),
            url: "https://example.test/guide".into(),
        },
        RichTextSegment::NewLine,
        RichTextSegment::Code {
            content: "cargo run".into(),
        },
    ])
    .font_size(14.0);
```

文本、代码和链接共用同一字符级布局，按可用宽度自动折行；选择背景、命中与绘制不会在折行后偏离。含有效 URL 的 `RichText` 自动进入 Tab 顺序，鼠标点击链接，或用方向键 / `Home` / `End` 选择后按 `Enter` / `Space`，都会以 URL 发出 `SemanticKind::Submit`，导航策略由应用决定。`focused_link()` 返回当前链接的显示文本与 URL。拖选支持 `Ctrl+A` / `Ctrl+C`，代码段的复制按钮通过系统剪贴板复制内容；结构化快照与无障碍状态同步报告当前链接。

## QRCode

```rust uix-compile=qrcode
QRCode::new("https://example.com/order/42")
    .size(192.0)
    .error_level(2);
```

`QRCode` 使用标准 QR 编码矩阵并保留四模块 quiet zone，不叠加会破坏扫描的 logo。`error_level(0..=3)` 依次对应 L / M / Q / H，超出范围时收敛到 H；`module_count()` 返回不含 quiet zone 的矩阵边长。普通内容构建后 `is_valid()` 为 true；内容超过标准容量时组件显示明确错误态，`encoding_error()` 返回具体原因而不 panic。

## Typography

```rust uix-compile=typography-styles
let note = Typography::paragraph("发布说明与迁移步骤")
    .mark()
    .strong()
    .underline()
    .copyable(true);
```

`heading` / `text` 使用单行语义尺寸，`paragraph` 会按父级可用宽度折行并把对应行数计入测量高度；显式换行会保留，中日韩宽字符按宽字测量，常见中西文闭合标点不会单独落在行首。`mark`、`code`、`underline`、`delete` 与 `strong` 直接参与像素绘制；文本拖选支持 `Ctrl+A` / `Ctrl+C`。`copyable(true)` 会预留复制按钮并进入 Tab 顺序，点击按钮或聚焦后按 `Enter` / `Space` 会把完整内容写入[剪贴板](响应式基础.md#剪贴板)，同时发出载荷为 `"copied"` 的 `SemanticKind::Submit`。`disabled(true)` 禁止选择与复制并退出 Tab 顺序。

需要更复杂的富文本（链接、代码段、混合样式）时使用 [RichText](#richtext)。

## Transfer

```rust uix-compile=transfer
Transfer::new()
    .source(vec![
        TransferItem { key: "read".into(), title: "Read".into(), selected: false },
        TransferItem { key: "write".into(), title: "Write".into(), selected: false },
    ])
    .target(vec![
        TransferItem { key: "review".into(), title: "Review".into(), selected: false },
    ]);
```

`source(...)` / `target(...)` 设置初始成员，应用 reconcile 会保留用户已经移动的运行态。非空 `Transfer` 自动进入 Tab 顺序：`Left` / `Right` 切换列表，`Up` / `Down`、`Home` / `End` 移动当前行，`Space` 勾选，`Enter` 把当前列表的勾选项移到另一侧；鼠标行与中间按钮执行同一操作。成员移动发出以当前 target key（逗号分隔）为载荷的 `SemanticKind::Change`；`source_items()`、`target_items()` 与 `SnapshotFields::Transfer` 均返回实时成员和勾选状态。
