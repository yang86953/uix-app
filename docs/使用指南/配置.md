# 配置

## Settings

```rust uix-compile=settings-service
App::new()
    .settings("app.settings.json")  // 可选；相对路径以可执行文件目录为基准
    .on_start(|handle| {
        let Some(settings) = handle.resolve::<SettingsService>() else {
            return;
        };
        let theme: Option<String> = settings.get("theme");
        settings.set("theme", "dark");
        if let Err(error) = settings.save() {
            eprintln!("save settings failed: {error}");
        }
    })
    .run();
```

KV 模型；文件是 key 唯一、key/value 均为字符串的严格 flat JSON，非法格式返回 typed `FormatError`。默认不读盘（opt-in），`path` 必须非空；`AppHandle` 解析出的 Clone 共享同一应用状态。`set` / `remove` / `clear` 只改内存，`save` 显式落盘且要求此前已由 `.settings(path)` 或 `load(path)` 配置路径，否则返回 typed `InvalidState`。落盘通过已同步 temp + backup 可恢复替换；下次 load 会恢复中断前的已提交版本并清理 sidecar；不进 UI 热路径。

### 类型化读写

> 设计目标。当前仅支持 `get(key) -> Option<String>` 和 `set(key, value)`；建议增加类型化方法：

```rust
// 当前：所有值都是字符串
let theme: Option<String> = settings.get("theme");
settings.set("theme", "dark");

// 设计目标：类型安全读
let count: Option<i32> = settings.get_typed("count");    // 自动 parse
settings.set_typed("count", 42i32);                       // 自动序列化
let count: i32 = settings.get_typed_or("count", 0);       // 带默认值
let count: i32 = settings.require_typed("count")?;        // 不存在或类型错时 Err

// 设计目标：批量读写结构体
#[derive(serde::Serialize, serde::Deserialize)]
struct AppPrefs {
    theme: String,
    window_width: f64,
    recent_files: Vec<String>,
}

let prefs = settings.get_struct::<AppPrefs>();   // Option<AppPrefs>
settings.set_struct(&prefs)?;                     // 整结构体序列化写入
settings.update_struct(|p: &mut AppPrefs| {        // 读-改-写
    p.theme = "dark".into();
});
```

## 图形后端

```rust uix-compile=graphics-backend
App::new()
    .graphics_backend(GraphicsBackend::Vulkan)        // 默认
    // .graphics_backend(GraphicsBackend::D3D11)
    // .graphics_backend(GraphicsBackend::Auto)       // 自动选择最佳
    .run();
```

失败 typed 诊断后回 Software/CPU；禁静默换 GPU API；仅 `Auto` 可跨 API。

应用始终传 logical 窗口尺寸。若自定义 `GraphicsEngine` 的 `Canvas2D` 使用 drawable physical pixels，须覆盖 `logical_extent()` 返回精确 logical viewport；不得用 `canvas / DPR` 分别反推宽高。

## CLI 模式

适合无 GUI 的脚本或服务场景。CLI 模式下不创建窗口，`on_start` 中的逻辑直接执行：

```rust uix-compile=cli-mode
App::new()
    .mode(AppMode::CLI)
    .on_start(|_| {
        println!("命令行模式运行");
    })
    .run();
```
