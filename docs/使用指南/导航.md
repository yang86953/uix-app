# 导航

## Menu

```rust uix-compile=menu-navigation
Menu::new()
    .items(vec![
        MenuItem {
            key: "home".into(),
            label: "首页".into(),
            icon: "home".into(),
            disabled: false,
        },
        MenuItem {
            key: "settings".into(),
            label: "设置".into(),
            icon: "settings".into(),
            disabled: false,
        },
    ])
    .active_key("home")
    .mode(MenuMode::Vertical);
```

`Menu` 默认进入 Tab 顺序。水平模式使用 `Left` / `Right`，垂直模式使用 `Up` / `Down`；导航会循环并跳过禁用项，未设置活动项时从对应方向的第一个可用项开始。选择变化发出以 item key 为载荷的 `SemanticKind::Change`；当前值可由 `get_active_key()` 或 `SnapshotFields::Menu::active_key` 读取。

## Navigation

侧边栏导航，内含标题、导航项列表与版本号：

```rust uix-compile=navigation-sidebar
Navigation::new("MyApp")
    .item("首页", "home")
    .item("设置", "settings")
    .active_index(0)
    .width(220.0)
    .compact(true)             // 紧凑模式（仅图标，无文字）
    .show_version(false);
```

可直接放入 `column`/`row`，无需 `build` 或手工 `into_node`。

`Navigation` 与 `NavGroup` 生成的每个 `NavItem` 都进入 Tab 顺序，聚焦后使用 `Enter` / `Space` 激活；变化发出以导航索引为载荷的 `SemanticKind::Change`。共享选中索引可从 `active()` 读取，单项可用 `is_active()` 或 `SnapshotFields::NavItem::active` 判断；重复激活当前项不发重复事件。标准与 `compact` 模式使用同一交互契约。

### NavGroup

管理一组导航项的共享选中状态：

```rust uix-compile=navigation-group
NavGroup::new()
    .item("首页", "home")
    .item("设置", "settings")
    .active_index(0);
```

## Pagination

```rust uix-compile=pagination
Pagination::new(200, 20)
    .current(2)
    .show_total(true)
    .show_size_changer(true)
    .page_size_options(vec![10, 20, 50, 100]);
```

`Pagination` 默认进入 Tab 顺序。`Left` / `Right` 或 `PageUp` / `PageDown` 前后翻页，`Home` / `End` 跳到首尾；启用尺寸切换后，`Up` / `Down` 或点击"条/页"区域按配置项循环。未显式设置 `page_size_options` 时默认使用 10/20/50/100，零值与重复项会被规范化。页码变化的 `SemanticKind::Change` 载荷仍是页码文本，page size 变化载荷为 `page_size=<值>`；当前状态可由 `get_current()`、`get_page_size()` 或 `SnapshotFields::Pagination::{current,page_size}` 读取。

## Steps / Breadcrumb / Anchor

```rust uix-compile=steps-breadcrumb-anchor
Steps::new(vec![
    Step::new("填写信息").description("录入收货地址"),
    Step::new("确认订单").description("核对商品与金额"),
    Step::new("完成支付"),
])
    .current(1)
    .vertical();

Breadcrumb::new()
    .items(vec![
        BreadcrumbItem::new("首页"),
        BreadcrumbItem::new("用户管理"),
        BreadcrumbItem::new("详情").active(),
    ])
    .separator(">");

Anchor::new(vec![
    AnchorItem::new("基本信息", "section-1"),
    AnchorItem::new("高级设置", "section-2"),
]);
```

`Steps` 默认横向，可用 `.vertical()` 改为纵向；横向使用 `Left` / `Right`，纵向使用 `Up` / `Down` 切换当前步骤，二者都支持 `Home` / `End`。变化发出以步骤索引为载荷的 `SemanticKind::Change`，当前值可由 `get_current()` 或 `SnapshotFields::Steps::{ current, direction }` 读取；标题与 `description` 在两种方向都会绘制。

非空 `Breadcrumb` 默认进入 Tab 顺序。点击条目或使用 `Left` / `Right`、`Home` / `End` 切换当前项，`Enter` / `Space` 重新激活当前项；变化发出以标题为载荷的 `SemanticKind::Change`。当前项可由 `active_index()`、`active_title()` 或 `SnapshotFields::Breadcrumb::items` 中的 `active` 标记读取；`.separator(...)` 同时控制测量、绘制与命中区域中的分隔符。

非空 `Anchor` 默认进入 Tab 顺序。`Up` / `Down` 移动当前锚点，`Home` / `End` 跳到首尾，`Enter` / `Space` 重新激活当前项；变化发出以 href 为载荷的 `SemanticKind::Change`。当前项可由 `active_index()`、`active_href()` 或 `SnapshotFields::Anchor::active_index` 读取；调用方仍可用 `set_positions(...)` 注入内容位置，再以 `update_active(scroll_y)` 同步滚动高亮。

## Tabs / Segmented

```rust uix-compile=tabs
Tabs::new()
    .tabs(vec![
        Tab { label: "标签1".into(), key: "tab-1".into() },
        Tab { label: "标签2".into(), key: "tab-2".into() },
    ])
    .active(0);
```

`Tabs` 默认进入 Tab 顺序。聚焦后，`Left` / `Right` 循环切换，`Home` / `End` 跳到首尾页签；变化发出以 tab key 为载荷的 `SemanticKind::Change`。当前页签可由 `active_index()` / `active_key()` 或 `SnapshotFields::Tabs::active_index` 读取。

## Dropdown

```rust uix-compile=dropdown
Dropdown::new("操作")
    .items(vec!["编辑", "删除", "导出"]);
```

`Dropdown` 默认进入 Tab 顺序。`Enter` / `Space` 开启或选择，`Up` / `Down` 循环高亮，`Home` / `End` 跳到首尾，`Escape` 关闭；失焦时自动关闭。鼠标与键盘选择都会发出以选项文本为载荷的 `SemanticKind::Change`。当前选择可由 `selected_index()` / `current_value()` 读取，`SnapshotFields::Dropdown` 同时提供 `open`、`selected_index` 与 `highlighted_index`。

## 页面路由

UIX 没有内置路由——页面切换就是响应式 View 组合。核心模式：一个 `State<String>` 或 `State<usize>` 记录当前页面，`App::root` 根据它切换展示内容。

```rust
use uix::prelude::*;

fn main() {
    let current_page = State::new("home".to_string());
    let nav_page = current_page.clone();

    App::new()
        .title("My App")
        .size(800, 600)
        .root(move || {
            row((
                // 侧边导航
                Navigation::new("MyApp")
                    .item("首页", "home")
                    .item("设置", "settings")
                    .item("关于", "about")
                    .width(220.0)
                    .on_change(&nav_page, |page, event| {
                        if let Some(payload) = event.change_payload() {
                            page.set(payload.to_string());
                        }
                    }),

                // 页面内容
                current_page.map(|page| match page.as_str() {
                    "home" => home_page(),
                    "settings" => settings_page(),
                    "about" => about_page(),
                    _ => label("404"),
                }).flex_grow(1.0),
            ))
        })
        .run();
}

fn home_page() -> impl View { label("首页").font_size(24.0).padding(24.0) }
fn settings_page() -> impl View { label("设置").font_size(24.0).padding(24.0) }
fn about_page() -> impl View { label("关于").font_size(24.0).padding(24.0) }
```

### 类型化路由

> 设计目标。用枚举替代字符串，编译期保证页面名拼写正确：

```rust
#[derive(Clone, PartialEq)]
enum Page { Home, Settings, About }

let current_page = State::new(Page::Home);

// 导航组件绑定枚举
Navigation::new("MyApp")
    .item("首页", Page::Home)
    .item("设置", Page::Settings)
    .item("关于", Page::About)
    .active_page(&current_page);

// 内容区按枚举分发
current_page.map(|page| match page {
    Page::Home => home_page(),
    Page::Settings => settings_page(),
    Page::About => about_page(),
});
```

### Tabs 路由

页签切换同理——Tabs 的变化载荷是 tab key，直接写入 State，再用 `map_opt` 分发：

```rust
let active_tab = State::new("tab-1".to_string());

column((
    Tabs::new()
        .tabs(vec![
            Tab { label: "列表".into(), key: "tab-1".into() },
            Tab { label: "详情".into(), key: "tab-2".into() },
        ])
        .active_key(&active_tab),

    active_tab.map_opt(|key| match key.as_str() {
        "tab-1" => Some(list_view()),
        "tab-2" => Some(detail_view()),
        _ => None,
    }),
))
