# 动画

UIX 提供两层动画 API：**声明式**（描述"什么在动"）和**指令式**（手动推进帧）。声明式 API 覆盖 90% 的场景，只在自定义 `component!` 中才需要指令式。**勿用 [`run_interval`](定时与异步.md#定时器) 模拟帧动画。**

> 声明式 API 为设计目标，指令式 API 已可用。

---

## Animated\<T\> —— 声明式动画值

`Animated<T>` 是一个自驱动的响应式动画值。你只需要声明目标值和过渡参数，框架自动推进帧、处理暂停/恢复、调用完成回调。

```rust
use uix::prelude::*;
use uix::animation::{Animated, Spring, Timeline, AnimationGroup, keyframe};
```

### 创建与配置

```rust
// 基础：从当前值动画到目标值
let anim = Animated::new(0.0_f64)
    .to(100.0, 0.5, Easing::ease_out)
    .delay(0.2);                     // 延迟 0.2 秒启动

// 弹簧物理动画
let spring = Animated::new(Point::new(0.0, 0.0))
    .to_spring(Point::new(200.0, 300.0), Spring::bouncy());

// 颜色动画
let color = Animated::new(Color::RED)
    .to(Color::BLUE, 1.0, Easing::ease_in_out);

// 尺寸动画
let size = Animated::new(Size::new(100.0, 100.0))
    .to(Size::new(200.0, 200.0), 0.4, Easing::cubic_out);
```

### 读取值

```rust
// 在 View 构造中直接绑定——框架自动在值变化时重绘
label("animated")
    .x(anim.value())                    // 读取当前值
    .opacity(anim.progress() as f32);    // 读取进度 [0, 1]

// 在 component! 的 render 中读取
render => (&self, frame: Rect, ctx: &mut PaintContext) {
    let pos = self.pos_anim.value();
    ctx.fill_circle(pos.x, pos.y, 20.0, Color::RED);
}
```

### 控制播放

```rust
anim.pause();                           // 暂停（保留进度）
anim.resume();                          // 继续
anim.stop();                            // 跳到终态并停止
anim.restart();                         // 从头开始

// 反向播放：交换起止值，不改变 easing 和 duration
let mut reversed = anim.reverse();

// 循环
anim.loop_forever();                    // 无限循环（正向）
anim.loop_alternate();                  // 来回往复
anim.loop_count(3);                     // 播放 3 次后停止
```

### 回调

```rust
let anim = Animated::new(0.0)
    .to(1.0, 0.3, Easing::ease_out)
    .on_start(|| println!("动画开始"))
    .on_finish(|| println!("动画完成"))
    .on_update(|value| {
        // 每 1/60 秒左右触发一次
        // 适合做非绘制副作用（如更新外部数据）
    });
```

### 完整 API 参考

| 方法 | 说明 |
|------|------|
| `Animated::new(initial_value)` | 创建并设定初值 |
| `.to(target, duration_secs, easing)` | 线性过渡到目标值 |
| `.to_spring(target, spring_config)` | 弹簧物理过渡 |
| `.delay(secs)` | 启动前等待 |
| `.value()` | 当前插值 |
| `.progress()` | 进度 [0, 1] |
| `.is_finished()` | 是否到达终点 |
| `.pause()` / `.resume()` | 暂停 / 继续 |
| `.stop()` | 跳到终点并停帧 |
| `.restart()` | 从初值重播 |
| `.reverse()` | 交换起止值重播 |
| `.loop_forever()` | 无限循环 |
| `.loop_alternate()` | 来回往复 |
| `.loop_count(n)` | 播放 n 次 |
| `.on_start(fn)` | 启动回调 |
| `.on_finish(fn)` | 完成回调 |
| `.on_update(fn)` | 每帧回调 |

## Spring —— 弹簧物理动画

弹簧动画不按固定时长播放，而是根据物理参数自然衰减到终点。适合需要"手感"的交互（按钮回弹、拖拽释放、列表边缘效果）。

### 预设

```rust
Spring::bouncy()   // 弹跳感强，适合趣味交互
Spring::gentle()   // 柔和平滑，适合入场动画
Spring::snappy()   // 快速响应，适合按钮反馈
Spring::linear()   // 临界阻尼，不震荡，最快到达
```

### 自定义参数

```rust
Spring::custom()
    .stiffness(200.0)    // 刚度（默认 170），越大回弹越快、震荡频率越高
    .damping(15.0)       // 阻尼（默认 20），越小震荡越久
    .mass(1.0)           // 质量（默认 1），越大惯性越大
    .velocity(0.0)       // 初始速度，正值朝向目标、负值背离目标
```

| 预设 | stiffness | damping |
|------|-----------|---------|
| `bouncy` | 170 | 12 |
| `gentle` | 120 | 18 |
| `snappy` | 300 | 25 |
| `linear` | 170 | 40 |

```rust
// 按钮点击回弹
let scale = Animated::new(1.0_f32)
    .to_spring(0.95, Spring::snappy());

// 列表项入场（依次弹出）
let offset = Animated::new(Point::new(0.0, 50.0))
    .to_spring(Point::new(0.0, 0.0), Spring::bouncy());

// 自定义手感
let custom_spring = Spring::custom()
    .stiffness(100.0)
    .damping(10.0)
    .mass(2.0);
```

## Keyframe —— 关键帧动画

定义多个时间点的状态，框架自动插值中间帧。

```rust
// 声明关键帧属性
let kf = keyframe! {
    opacity: f32,
    offset_y: f32,
    scale: f32,
}

// 脉冲动画：缩放到 1.2 再回到 1.0
let pulse = Animated::keyframes([
    (0.0, kf.opacity(1.0).offset_y(0.0).scale(1.0)),
    (0.5, kf.opacity(1.0).offset_y(0.0).scale(1.2)),
    (1.0, kf.opacity(1.0).offset_y(0.0).scale(1.0)),
])
    .duration(0.6)
    .easing(Easing::ease_in_out);

// 弹入：从下方淡入
let slide_up = Animated::keyframes([
    (0.0, kf.opacity(0.0).offset_y(30.0).scale(1.0)),
    (0.6, kf.opacity(0.8).offset_y(-5.0).scale(1.0)),  // 过冲
    (1.0, kf.opacity(1.0).offset_y(0.0).scale(1.0)),   // 归位
])
    .duration(0.5)
    .easing(Easing::ease_out);

// 读取各属性
slide_up.opacity().value()    // 当前透明度
slide_up.offset_y().value()   // 当前 Y 偏移
slide_up.scale().value()      // 当前缩放
```

`keyframe!` 宏编译时生成属性结构体，保证类型安全。属性支持所有 `Animatable` 类型。

## AnimationGroup —— 编排

把多个动画组合成并行动画或串行动画。

```rust
// 并行：同时淡入 + 滑入
let enter = AnimationGroup::parallel(vec![
    Animated::new(0.0_f32).to(1.0, 0.3, Easing::ease_out),
    Animated::new(Point::new(0.0, 20.0)).to(Point::new(0.0, 0.0), 0.3, Easing::ease_out),
]);

// 串行：先淡入，等 0.1 秒，再放大
let sequence = AnimationGroup::sequential(vec![
    Animated::new(0.0_f32).to(1.0, 0.3, Easing::ease_out),
    AnimationGroup::delay(0.1),
    Animated::new(1.0_f32).to(1.1, 0.2, Easing::ease_out),
]);

// 错开：子动画依次延迟 stagger 秒启动
let staggered = AnimationGroup::stagger(
    children_animations,
    0.05,  // 每个子动画比前一个晚 0.05 秒
);
```

## View 属性动画

对任意 View 的属性启用声明式动画过渡——属性值变化时自动插值。

```rust
use uix::prelude::*;
use uix::animation::Animated;

// 单个属性
label("hover me")
    .bg_animated(state, 0.3, Easing::ease_out)       // 背景色过渡
    .opacity_animated(state, 0.3, Easing::ease_out)   // 透明度过渡
    .scale_animated(state, 0.3, Spring::bouncy())     // 缩放弹簧动画
    .offset_animated(state, 0.3, Easing::ease_out)    // 位移过渡

// 等价于：绑定 Animated 值
let bg = Animated::new(Color::WHITE)
    .to(Color::hex("#E8F4FD"), 0.3, Easing::ease_out);
label("hover me").bg(bg.value());
```

### 可用属性方法

| 方法 | 动画类型 | 适用场景 |
|------|----------|----------|
| `.opacity_animated(state, dur, easing)` | `f32` | 淡入淡出 |
| `.bg_animated(state, dur, easing)` | `Color` | 背景色过渡 |
| `.color_animated(state, dur, easing)` | `Color` | 文字色过渡 |
| `.scale_animated(state, dur, spring)` | `f32` | 缩放 |
| `.offset_animated(state, dur, easing)` | `Point` | 位移 |
| `.size_animated(state, dur, easing)` | `Size` | 尺寸变化 |
| `.width_animated(state, dur, easing)` | `f32` | 宽度变化 |
| `.height_animated(state, dur, easing)` | `f32` | 高度变化 |
| `.radius_animated(state, dur, easing)` | `f32` | 圆角变化 |
| `.border_animated(state, dur, easing)` | `Color` | 边框色过渡 |

## 列表动画

列表增删项时自动播放进出场动画。

```rust
// 每个子项的入场动画
column(items.iter().map(|item| {
    label(item)
        .enter_animation(AnimationConfig::fade_in(0.2))
        .leave_animation(AnimationConfig::fade_out(0.15))
}))

// 错开入场：第二项晚 0.05 秒，第三项晚 0.10 秒...
column(items.iter().map(|item| label(item)))
    .stagger_enter(0.05, AnimationConfig::slide_in(Placement::Bottom, 0.3));
```

## 浮层进出场动画

[反馈](反馈.md) 中的 Modal / Drawer / Popover / Message / Notification 支持可配置的 enter + leave 两段式动画：

```rust uix-compile=overlay-animations
// Modal 弹出/关闭
Modal::show(|_| label("Modal content"))
    .enter_animation(AnimationConfig::fade_in(0.2))
    .leave_animation(AnimationConfig::fade_out(0.15));

// Drawer 滑入/滑出
Drawer::new("设置")
    .placement(DrawerPlacement::Right)
    .show()
    .enter_animation(AnimationConfig::slide_in(Placement::Right, 0.25))
    .leave_animation(AnimationConfig::slide_out(Placement::Right, 0.2));

// Popover 从触发点右侧滑入
Popover::new("详情")
    .placement(PopoverPlacement::Right)
    .enter_animation(AnimationConfig::slide_in(Placement::Right, 0.15))
    .leave_animation(AnimationConfig::fade_out(0.1));
```

`AnimationConfig` 预设：

| 方法 | 效果 |
|------|------|
| `AnimationConfig::fade_in(duration)` | 淡入（opacity 0→1） |
| `AnimationConfig::fade_out(duration)` | 淡出（opacity 1→0） |
| `AnimationConfig::slide_in(placement, duration)` | 方向滑入（含位移 + 淡入） |
| `AnimationConfig::slide_out(placement, duration)` | 方向滑出（含位移 + 淡出） |
| `AnimationConfig::zoom_in(duration)` | 缩放弹出（scale 0.8→1 + 淡入） |
| `AnimationConfig::zoom_out(duration)` | 缩放收起（scale 1→0.8 + 淡出） |

## Easing —— 缓动曲线

```rust uix-compile=easing-curves
// 基础
let linear = Easing::linear;
let ease_in = Easing::ease_in;          // quad in
let ease_out = Easing::ease_out;        // quad out
let ease_in_out = Easing::ease_in_out;  // quad in-out

// 加强
let cubic_in = Easing::cubic_in;
let cubic_out = Easing::cubic_out;
let cubic_in_out = Easing::cubic_in_out;

// 弹性
let bounce = Easing::bounce;   // 弹跳缓出
let elastic = Easing::elastic; // 弹性缓出

// Ant Design 5 主题曲线（与 CSS 中 cubic-bezier 一致）
let antd_default = Easing::antd_default(); // (0.25, 0.1, 0.25, 1)
let antd_in      = Easing::antd_in();      // (0.42, 0, 1, 1)
let antd_out     = Easing::antd_out();     // (0, 0, 0.58, 1)
let antd_in_out  = Easing::antd_in_out();  // (0.42, 0, 0.58, 1)

// 自定义三次贝塞尔
let custom = Easing::cubic_bezier(0.25, 0.1, 0.25, 1.0);
```

## 指令式动画（自定义组件底层 API）

声明式 API 内部也使用这套底层机制。在自定义 `component!` 中直接使用时：

```rust uix-compile=component-animation-fade
component! {
    pub struct FadingBox {
        opacity: f32,
    }

    render => (&self, frame: Rect, ctx: &mut PaintContext) {
        ctx.fill_rect(frame, Color::rgba(0, 0, 255, (self.opacity * 255.0) as u8), None);
    }

    update_animation => (&mut self, dt: f64) -> bool {
        self.opacity = self.fade.update(dt) as f32;
        !self.fade.is_finished()
    }

    dirty_bounds => (&self) -> Option<Rect> {
        // 返回本帧变化的区域，不覆写时使用组件 frame
        None
    }

    // 私有动画状态
    fade: Animation<f64> = Animation::new(0.0, 1.0, 0.3).easing(Easing::ease_out),
}
```

## 场景速查

| 需求 | API |
|------|-----|
| 透明度淡入 | `Animated::new(0.0).to(1.0, 0.3, Easing::ease_out)` |
| 弹入效果 | `Animated::new(0.0).to_spring(1.0, Spring::bouncy())` |
| 按钮按下回弹 | `scale_animated(state, 0.15, Spring::snappy())` |
| 列表逐项入场 | `.stagger_enter(0.05, AnimationConfig::fade_in(0.3))` |
| 多步关键帧 | `Animated::keyframes([...]).duration(0.6)` |
| 并行动画 | `AnimationGroup::parallel(vec![a, b])` |
| 串行动画 | `AnimationGroup::sequential(vec![a, delay, b])` |
| 弹窗进场 | `Modal::show(...).enter_animation(AnimationConfig::zoom_in(0.2))` |
| 循环呼吸灯 | `Animated::new(0.3).to(1.0, 1.0, Easing::ease_in_out).loop_alternate()` |
| 自定义组件动画 | `component!` + `update_animation` + `Animation<T>` |
