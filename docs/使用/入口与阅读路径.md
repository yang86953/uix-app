## 阅读路径

**新手**：从教程开始，跟着写一个应用，再查响应式基础了解原理。

**用过类似框架**：直接看响应式基础 → 组件 → 组件速查，把 UIX 当 Ant Design 用。

**遇到问题**：按分类查对应文档，或搜组件速查定位。

## 理想使用方式

按产品定义，UIX 的理想用法是**写一套 Rust 声明式代码，直接跑在原生窗口上**：

```rust uix-compile=app-minimal
use uix::prelude::*;

fn main() {
    App::new()
        .title("My App")
        .size(800, 600)
        .root(|| column((label("Hello"), button("World"))))
        .run();
}
```

- 界面就是 Rust，没有第二门语言（Rust 优先）。
- 空闲必须真休眠，不做多余绘制（资源优先）。
- 上层代码不感知平台差异（原生优先）。
- 出错有类型，恢复有路径（容错可观测）。

四个原则的完整定义见[定位与原则](../产品/定位与原则.md)。
