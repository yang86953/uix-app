## 阅读路径

**新手**：推荐从 [uix-lang 快速开始](../uix-lang/指南/快速开始.md) 的当前可编译 View 开始，再阅读 [uix-lang 教程](../uix-lang/指南/教程.md) 的完整应用目标设计；需要运行完整应用时使用[教程](教程.md)的 Rust 写法。

**用过类似框架**：直接看响应式基础 → 组件 → 组件速查，把 UIX 当 Ant Design 用。

**遇到问题**：按分类查对应文档，或搜组件速查定位。

## 理想使用方式

按产品定义，界面描述支持两种方式，推荐用 **uix-lang**（`.uix` 文档，编译时转换为 Rust，见[语言规范](../uix-lang/README.md)）。公开 `uix!` 已可生成已登记子集的 `ViewNode`；以下 Rust 声明式写法继续承担完整应用 / 窗口生命周期和尚未登记能力，也是 uix-lang 的底层表示：

```rust uix-compile=app-minimal
use uix::prelude::*;

fn main() {
    App::new()
        .title("My App")
        .size(800, 600)
        .root(|| column((label("Hello"), button("World"))))
        .run();
}
```

- 界面用 uix-lang 描述，编译时转换为 Rust，没有第二门运行语言（Rust 优先）。
- 空闲必须真休眠，不做多余绘制（资源优先）。
- 上层代码不感知平台差异（原生优先）。
- 出错有类型，恢复有路径（容错可观测）。

四个原则的完整定义见[定位与原则](../产品/定位与原则.md)。
