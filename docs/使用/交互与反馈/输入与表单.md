# 输入与表单

[← 返回使用索引](../../使用.md)

> **接口**：声明 UIX 输入与表单的公开用法——输入控件、选择器、日期时间、校验、FormItem 与动态列表。依赖：[响应式基础](../入门/响应式基础.md)、[事件](事件.md)。导出：表单架构 → [架构 · 表单](../../架构/ui/form.md)。

## 文本输入

`Input` 负责单行、多行和密码场景。业务状态持有已提交值；IME 预编辑、选区、光标与组合文本属于输入会话，不应被业务代码拆开模拟。

密码模式只负责屏幕呈现、输入语义与敏感快照边界，不等于加密存储。提交后的密码仍由应用 `State` 和业务逻辑持有；不得写入普通 Settings、日志、错误文本或非必要剪贴板，持久化凭据应使用应用选择的专用凭据存储。

- 指针命中、`Left` / `Right`、`Home` / `End`、Shift 选区、`Backspace` 与 `Delete` 都以 Unicode 扩展字素簇为最小编辑单元；组合音标、emoji ZWJ/肤色序列和 Indic 连写内部不会出现光标或选择边界。
- 单行和多行输入复用 OpenType shaping 与 UAX #9 视觉顺序计算命中、光标和选区几何；逻辑索引仍按源文本字符顺序保存，RTL 不改变复制或删除范围。
- `max_length` 继续按 Unicode 标量限制值长度，但截断点必须是完整字素簇边界；剩余预算不足以容纳整个组合序列时不会插入残缺序列。

```rust uix-compile=input-basic
use uix_app::prelude::*;

let text = State::new(String::new());

input()
    .placeholder("请输入")
    .value(&text)
    .flex_grow(1.0);

// 多行（textarea / password 是关联构造）
Input::textarea().rows(4).value(&text);

// 密码
Input::password().value(&text);
```

## 数值输入

`InputNumber`、`Slider`、`RangeSlider` 与 `Rate` 必须显式声明范围、步长和精度。非法文本保留为编辑态，只有通过解析与约束的值才进入业务状态。

```rust uix-compile=input-number
use uix_app::prelude::*;

let n = State::new(50i32);

embed(InputNumber::new()
    .value(&n)
    .min(0.0)
    .max(100.0)
    .step(5.0)
    // 精度同时约束提交值量化与固定小数位显示，运行时上限为 15。
    .precision(0));

// 滑块：拖动期间显示当前值提示
embed(Slider::new(0.0..=100.0)
    // 使用区间中点作为初始值
    .default_value(50.0)
    // 顶部空间不足时提示自动翻转并约束到窗口内
    .tooltip(TooltipPlacement::Top));

// 滑块：拖动选择区间（组件，直接 embed）
embed(RangeSlider::new(0.0..=100.0).step(5.0));
```

`Slider::tooltip` 的方向是优先位置，不是越界承诺；拖动提示与反馈 `Tooltip` 复用同一 logical surface 约束，靠近窗口边缘时选择越界更少的主轴方向，超长值文字裁在最终气泡内。

## 开关与勾选

`Checkbox`、`Radio`、`Switch` 与 `Segmented` 使用受控状态。禁用态不触发 Change，键盘与指针路径产生相同语义结果。

```rust uix-compile=input-choice
use uix_app::prelude::*;

let checked = State::new(false);

embed(Checkbox::new("记住我").checked(&checked));
embed(Radio::new()
    .options(["管理员", "普通用户"])
    .default_selected(0));
embed(Switch::new()
    // 为无文字开关提供可读的无障碍名称
    .label("启用通知")
    .checked(&checked));
```

`Radio` 使用方向键移动并选中当前项，`Home` / `End` 跳到首尾；当前焦点与选中项共享同一事实，因此 `Space` 不创建第二套确认状态。`Switch::label` 为无文字开关提供无障碍名称。`Upload` 获得焦点后使用 `Enter` / `Space` 走与指针相同的标准 Click 语义，调用方可在点击处理器中请求文件选择。

## 选择器

`Select` 支持单选、多选与搜索；选项用稳定 key 表示身份，显示文案不是身份。弹层的焦点、滚动与关闭由框架管理。

选择器靠近窗口边缘时会按当前逻辑表面自动横向收敛、上下翻转或缩短视口；滚轮、键盘定位、自定义选项、命中与绘制使用同一最终矩形。应用无需自行计算弹层方向，但自定义选项内容仍应适应框架给出的受约束宽高。

```rust uix-compile=input-select
use uix_app::prelude::*;

let selected = State::new("cn".to_string());

embed(Select::new()
    .options(["中文", "English"])
    .value(&selected));
```

## 日期时间与颜色

`DatePicker`、`DateRangePicker`、`TimePicker` 与 `ColorPicker` 在提交前验证范围。格式化和本地化只影响显示，不改变保存值。

`DatePicker`、`DateRangePicker`、`TimePicker` 与 `ColorPicker` 打开后都会把面板限制在当前窗口逻辑表面内：底边空间不足时翻到上方，两侧都不足时按较大可用空间缩高，窄窗口会收窄面板而不保留自然最小宽度。日期标题、星期、单元格、月份导航与命中区域使用同一实际面板比例，`DateRangePicker` 的可选预设页脚也按同一纵向比例参与布局和命中。`TimePicker` 保持小时/分钟选项 32px 行高，通过缩小滚动视口适应表面；滚轮、键盘显露和点击均使用实际视口，因此末项仍可到达。`ColorPicker` 的固定 8 列、24 色预设网格会从最终面板矩形同步缩放内边距、色块槽位和选中标记，绘制与点击共享同一映射；面板与触发器保留 4px 间隙，关闭动画期间也继续受表面约束。窗口 resize 时旧面板区域会自动重绘，业务侧无需保存或修正弹层坐标。

```rust uix-compile=input-date
use uix_app::prelude::*;

let date = State::new(Date::new(2026, 7, 31));
embed(DatePicker::new().value(&date));

let time = State::new(Time::new(14, 30));
embed(TimePicker::new().value(&time));

let color = State::new(Color::hex("#1677ff"));
embed(ColorPicker::new().value(&color));
```

## 级联与自动完成

`Cascader`、`TreeSelect`、`AutoComplete` 与 `Mentions` 将输入状态、候选状态和已选结果分开；异步候选必须丢弃过期响应。

`Cascader` 打开后会把多列弹层限制在当前窗口逻辑表面内：下方不足时翻到上方，两侧都不足时按较大可用空间缩高；多列自然总宽超过窄表面时，各列在最终宽度内等分。绘制、点击、滚动与键盘显露使用同一实际列宽和视口，无需业务侧手工修正边缘位置。

`TreeSelect` 同样把树弹层限制在当前窗口逻辑表面内：底边空间不足时可翻到上方，两侧都不足时按较大可用空间缩高，窄窗口会收窄弹层而不是保留 200px 最小宽度。点击、虚拟滚动、键盘显露与重绘使用同一实际视口；树节点展开或候选变化时也会基于当前表面重算，无需业务侧缓存弹层坐标。

`AutoComplete` 的候选弹层也会限制在当前窗口逻辑表面内：底边不足时翻转，两侧不足时缩高，窄窗口自动收窄。点击、滚轮、键盘显露与绘制使用同一实际视口；连续输入过滤候选时，当前弹层按新行数调整，同时自动清理过滤前的旧弹层区域，业务侧无需手动刷新或保存弹层坐标。

`Mentions` 的 `@` 候选弹层遵循同一表面约束：底边不足时翻转，两侧不足时缩高，窄窗口自动收窄。点击、滚轮、键盘显露与绘制复用同一实际视口；光标前的活动查询连续过滤候选时，当前弹层会按新行数调整并自动清理旧区域，不影响光标后的正文，也不需要业务侧保存弹层坐标。

## 表单

`Form` / `FormItem` 持有字段真值、校验状态、提交和重置。同步与异步校验均以字段版本关联，旧校验结果不得覆盖新输入；动态行使用稳定字段 key。

```rust uix-compile=form-basic
use uix_app::prelude::*;

// FormItem 声明字段：label + name + 校验；Form 负责布局
embed(tree! {
    Form::new().label_width(86.0).gap(8.0).layout(FormLayout::Vertical) => [
        tree! { FormItem::new("用户名").name("user").required(true).help("必填") => [
            Input::new("请输入用户名").into_node(),
        ]},
        tree! { FormItem::new("密码").name("password").required(true).help("至少 8 位") => [
            Input::password().into_node(),
        ]},
    ]
});
```

`FormItem::new(label)` 支持 `.name(key)`、`.required(bool)`、`.status(ValidateStatus)`、`.help(text)`、`.label_width(w)` 与 `.layout(FormLayout)`；`Form::new()` 支持 `.label_width()`、`.gap()`、`.layout()`。字段真值与校验状态由 FormItem 持有。

## 上传

`Upload` 管理本地文件选择与队列状态，不代表 UIX 提供网络上传服务。网络传输、重试与服务端协议由应用负责。

`.drag(true)` 让 `Upload` 消费落在自身或其后代命中区域内的 `FileDrop`，按单批候选执行 `accept`、`max_size`、`multiple` 与 `max_count` 门禁；至少一个文件通过时，组件只提交一次受控 `files` 状态并发布一次类型化 `UploadChange::Added`。全部候选被拒绝时不改写队列；应用显式调用 `queue_files` 时可从 `UploadQueueResult::rejected` 读取逐项原因。文件选择按钮仍由应用在标准 Click 处理器中调用 `Platform::open_files`，选中的 owned 路径再交给 `queue_files`，组件不会隐式启动文件对话框。

应用创建的主窗口、运行时次窗口和公开 `Window` 默认请求平台文件拖放能力。Windows 使用原生 `WM_DROPFILES`；Wayland 需要 compositor 提供 `wl_data_device`，只接受 Copy 的 `text/uri-list` 本地文件 URI。稳定不支持的平台以 `Errc::NotImplemented` 降级为无拖放窗口，不影响点击选择文件；其他启用或传输失败保持 typed error，不以空文件列表伪装成功。

`accept`、扩展名、声明大小和数量门禁只筛选队列候选，不验证文件内容安全，也不保证路径在随后读取时仍指向同一文件。应用实际处理前仍需重新打开并校验权限、大小、格式与内容；不得仅凭扩展名执行文件。网络传输、凭据、重试、服务端响应和隐私告知完全由应用负责。

## 推荐用法

按产品定义（Rust 优先、容错可观测）：

```rust uix-compile=form-model
use uix_app::prelude::*;

// 类型化表单由业务模型驱动，提交后得到类型化结果。
#[derive(Clone, Default)]
struct ProfileForm {
    name: String,
    age: u8,
    level: String,
    accepted: bool,
    channel: String,
    notifications: bool,
    volume: f64,
}

// 校验字段之间的完整业务约束。
fn validate_profile(profile: &ProfileForm) -> Result<(), String> {
    // 示例要求启用通知前先接受协议。
    (!profile.notifications || profile.accepted)
        .then_some(())
        .ok_or_else(|| "启用通知前必须接受协议".to_string())
}

let model = State::new(ProfileForm::default());
let form = Form::model(&model)
    .field("name", |v| &mut v.name, FormInputItem::new("name").required(true))
    .field("age", |v| &mut v.age, FormInputNumberItem::new("age").min(0.0).max(120.0))
    .field("level", |v| &mut v.level, FormSelectItem::new("level").label("等级").options(["初级", "中级", "高级"]).required(true))
    .field("accepted", |v| &mut v.accepted, FormCheckboxItem::new("accepted").field_label("协议确认").label("我已阅读并同意").required(true))
    .field("channel", |v| &mut v.channel, FormRadioItem::new("channel").label("通知渠道").options(["邮件", "短信"]).required(true))
    .field("notifications", |v| &mut v.notifications, FormSwitchItem::new("notifications").label("启用通知").required(true))
    .field("volume", |v| &mut v.volume, FormSliderItem::new("volume", 0.0..=100.0).label("音量").step(5.0))
    // 字段规则通过并组装候选模型后执行全模型规则。
    .model_rule(validate_profile)
    .on_submit_typed(|profile: ProfileForm| {
        // 校验通过后回调；业务错误经 Err(String) 上抛
        println!("提交：{} / {}", profile.name, profile.age);
        Ok(())
    })
    .build();

embed(column((
    form.view(),
    button("提交").on_click_fn(move || { let _ = form.submit_typed(); }),
)));
```

- 字段真值、校验状态与提交由 Form 持有，业务代码不维护两份状态；提交回调直接拿到类型化结果 `ProfileForm`。
- `Form::model(&State<M>)` 绑定业务模型，`.field(name, accessor, item)` 按投影声明字段，`.on_submit_typed` 在全部校验通过后触发，`Err(String)` 上抛。
- `.model_rule(fn(&M) -> Result<(), String>)` 追加全模型规则；字段规则先执行，随后按登记顺序校验候选模型，失败时不写回 State 且不触发提交回调。UIX 对应 `rules={[validate_profile, validate_access]}`，只接受编译期函数标识符数组。
- UIX 可直接声明 `<FormSelectItem field="level" label="等级" options={level_options} rules="required" searchable />`；宏生成同一类型化字段 accessor，候选集合与交互配置仍交给公开运行时 builder。
- UIX 可用 `<FormCheckboxItem field="accepted" label="协议确认" text="我已阅读并同意" rules="required" />` 投影 `bool` 成员；`label` 属于表单字段，`text` 属于复选框控件，必选规则要求值为 `true`。
- UIX 可用 `<FormRadioItem field="channel" label="通知渠道" options={channel_options} rules="required" vertical />` 投影 `String` 成员；候选集合、分组名与布局配置交给公开运行时单选组 builder。
- UIX 可用 `<FormSwitchItem field="notifications" label="启用通知" rules="required" disabled={notifications_locked} />` 投影 `bool` 成员；开关没有说明文字子节点，必选规则要求值为 `true`。
- UIX 可用 `<FormSliderItem field="volume" label="音量" min="0" max="100" step={volume_step} />` 投影 `f64` 成员；范围与步长复用 `Slider` 的有限数值契约，静态反向范围和非正步长在宏展开期拒绝。
- `form.submit()` 执行字段与全模型规则并组装 `M`（不写回共享 State）；`submit_typed()` 写回模型并触发回调；校验失败不覆盖模型与已输入内容，`reset()` 恢复模型当前值。
- 同步与异步校验按字段版本关联，过期结果不覆盖新输入。
- 动态行使用稳定字段 key，行增删不破坏其他行的校验与焦点。
