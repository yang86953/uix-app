# 快速开始

添加依赖（`Cargo.toml`）：

```toml
[dependencies]
uix = { path = "../uix-app" }
```

当前 crate 设为 `publish = false`，尚未发布到 crates.io；`path` 请改成应用仓库到本仓库的实际相对路径。发布后改用 crates.io 版本号。

第一个应用：

```rust uix-compile=quick-start-hello
use uix::prelude::*;

fn main() {
    App::new()
        .title("Hello UIX")
        .size(400, 300)
        .root(|| label("Hello, world!").font_size(32.0))
        .run();
}
```

带交互的计数器：

```rust uix-compile=quick-start-counter
use uix::prelude::*;

fn main() {
    let count = State::new(0);

    App::new()
        .title("计数器")
        .size(360, 200)
        .root(move || {
            column((
                count.map_text(|n| format!("{n}")).font_size(48.0),
                row((
                    button("-1").on_click(&count, |c| c.update(|v| *v -= 1)),
                    button("+1").primary().on_click(&count, |c| c.update(|v| *v += 1)),
                )).gap(8.0),
            ))
            .gap(16.0)
            .padding(24.0)
        })
        .run();
}
```
