## 添加依赖

```toml
[dependencies]
uix = { path = "../uix-app" }
```

当前 crate 设为 `publish = false`，按 `yangyanhui` 专有、仅限内部授权使用的方式交付，不发布到 crates.io，也不对外分发源码或二进制；`path` 请改成已授权内部应用仓库到本仓库或内部 `.crate` 解包目录的实际相对路径。交付物与平台 / feature 边界见[交付与许可](../产品/交付与许可.md)。

## 第一个应用

> **推荐方式**：界面用 [uix-lang](../uix-lang/README.md)（`.uix` 文档）描述，编译时自动转换为 Rust；Rust 声明式 API 同样受支持，已登记能力语义一一对应。公开 `uix!` 已可生成 `ViewNode`，当前可编译子集见 [uix-lang 快速开始](../uix-lang/指南/快速开始.md#当前可编译的第一个-view)；以下 Rust 写法继续承担完整应用 / 窗口生命周期和尚未登记能力，也是 uix-lang 的底层表示。

```rust uix-compile=quick-start-hello
use uix::prelude::*;

fn main() {
    App::new()
        .title("Hello UIX")
        .size(400, 300)
        .root(|| label("Hello, world!").font_size(32.0))
        .run();
}
```

## 带交互的计数器

```rust uix-compile=quick-start-counter
use uix::prelude::*;

fn main() {
    let count = State::new(0);

    App::new()
        .title("计数器")
        .size(360, 200)
        .root(move || {
            column((
                count.map_text(|n| format!("{n}")).font_size(48.0),
                row((
                    button("-1").on_click(&count, |c| c.update(|v| *v -= 1)),
                    button("+1").primary().on_click(&count, |c| c.update(|v| *v += 1)),
                )).gap(8.0),
            ))
            .gap(16.0)
            .padding(24.0)
        })
        .run();
}
```

## 理想使用方式

```rust uix-compile=quick-start-typed-route
use uix::prelude::*;

// 类型化页面切换 + 组件组合（已落地 API 的理想组合）
#[derive(Clone, PartialEq)]
enum Page { Home, Settings }

impl std::fmt::Display for Page {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.write_str(match self {
            Self::Home => "home",
            Self::Settings => "settings",
        })
    }
}

fn app_root(theme: &Theme, page: &State<Page>) -> ViewNode {
    column((
        embed(Navigation::<Page>::new("我的应用")
            .item("首页", Page::Home)
            .item("设置", Page::Settings)
            .active_page(page)
            .build(theme.tokens())),
        page.map(|p| match p {
            Page::Home => home_view(),
            Page::Settings => settings_view(),
        }),
    ))
}
```

```rust uix-compile=route-display-derive
// Display derive 免除手写 impl，路由定义更紧凑（E-06 已落地）
#[derive(Clone, PartialEq, Display)]
enum Page { Home, Settings }
```

要点：

- 状态用 `State<T>` 持有，界面由状态驱动，不手工操作 DOM 或绘制队列。
- 组合优先：先用小组件拼出页面，需要私有状态/精细事件时再升级为 `component!`（见[组件](组件.md)）。
- 平台能力、图形后端、窗口生命周期由框架托管（见[不必做](不必做.md)）。
