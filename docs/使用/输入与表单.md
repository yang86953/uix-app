# 输入与表单

[← 返回使用 索引](../使用.md)

> **接口**：声明 UIX 输入与表单的公开用法——输入控件、选择器、日期时间、校验、FormItem 与动态列表。依赖：[响应式基础](响应式基础.md)、[事件](事件.md)。导出：表单架构 → [架构 · 表单校验](../架构/ui/form-validation.md)。

## 文本输入

`Input` 负责单行、多行和密码场景。业务状态持有已提交值；IME 预编辑、选区、光标与组合文本属于输入会话，不应被业务代码拆开模拟。

```rust uix-compile=input-basic
use uix::prelude::*;

let text = State::new(String::new());

input()
    .placeholder("请输入")
    .value(&text)
    .flex_grow(1.0);

// 多行（textarea / password 是关联构造）
Input::textarea().rows(4).value(&text);

// 密码
Input::password().value(&text);
```

## 数值输入

`InputNumber`、`Slider`、`RangeSlider` 与 `Rate` 必须显式声明范围、步长和精度。非法文本保留为编辑态，只有通过解析与约束的值才进入业务状态。

```rust uix-compile=input-number
use uix::prelude::*;

let n = State::new(50i32);

embed(InputNumber::new()
    .value(&n)
    .min(0.0)
    .max(100.0)
    .step(5.0));

// 滑块：拖动期间显示当前值提示
embed(Slider::new(0.0..=100.0)
    // 使用区间中点作为初始值
    .default_value(50.0)
    // 顶部空间不足时提示自动翻转并约束到窗口内
    .tooltip(TooltipPlacement::Top));

// 滑块：拖动选择区间（组件，直接 embed）
embed(RangeSlider::new(0.0..=100.0).step(5.0));
```

`Slider::tooltip` 的方向是优先位置，不是越界承诺；拖动提示与反馈 `Tooltip` 复用同一 logical surface 约束，靠近窗口边缘时选择越界更少的主轴方向，超长值文字裁在最终气泡内。

## 开关与勾选

`Checkbox`、`Radio`、`Switch` 与 `Segmented` 使用受控状态。禁用态不触发 Change，键盘与指针路径产生相同语义结果。

```rust uix-compile=input-choice
use uix::prelude::*;

let checked = State::new(false);

embed(Checkbox::new("记住我").checked(&checked));
embed(Radio::new()
    .options(["管理员", "普通用户"])
    .default_selected(0));
embed(Switch::new().checked(&checked));
```

## 选择器

`Select` 支持单选、多选与搜索；选项用稳定 key 表示身份，显示文案不是身份。弹层的焦点、滚动与关闭由框架管理。

选择器靠近窗口边缘时会按当前逻辑表面自动横向收敛、上下翻转或缩短视口；滚轮、键盘定位、自定义选项、命中与绘制使用同一最终矩形。应用无需自行计算弹层方向，但自定义选项内容仍应适应框架给出的受约束宽高。

```rust uix-compile=input-select
use uix::prelude::*;

let selected = State::new("cn".to_string());

embed(Select::new()
    .options(["中文", "English"])
    .value(&selected));
```

## 日期时间与颜色

`DatePicker`、`DateRangePicker`、`TimePicker` 与 `ColorPicker` 在提交前验证范围。格式化和本地化只影响显示，不改变保存值。

```rust uix-compile=input-date
use uix::prelude::*;

let date = State::new(Date::new(2026, 7, 31));
embed(DatePicker::new().value(&date));

let time = State::new(Time::new(14, 30));
embed(TimePicker::new().value(&time));

let color = State::new(Color::hex("#1677ff"));
embed(ColorPicker::new().value(&color));
```

## 级联与自动完成

`Cascader`、`TreeSelect`、`AutoComplete` 与 `Mentions` 将输入状态、候选状态和已选结果分开；异步候选必须丢弃过期响应。

## 表单

`Form` / `FormItem` 持有字段真值、校验状态、提交和重置。同步与异步校验均以字段版本关联，旧校验结果不得覆盖新输入；动态行使用稳定字段 key。

```rust uix-compile=form-basic
use uix::prelude::*;

// FormItem 声明字段：label + name + 校验；Form 负责布局
embed(tree! {
    Form::new().label_width(86.0).gap(8.0).layout(FormLayout::Vertical) => [
        tree! { FormItem::new("用户名").name("user").required(true).help("必填") => [
            Input::new("请输入用户名").into_node(),
        ]},
        tree! { FormItem::new("密码").name("password").required(true).help("至少 8 位") => [
            Input::password().into_node(),
        ]},
    ]
});
```

`FormItem::new(label)` 支持 `.name(key)`、`.required(bool)`、`.status(ValidateStatus)`、`.help(text)`、`.label_width(w)` 与 `.layout(FormLayout)`；`Form::new()` 支持 `.label_width()`、`.gap()`、`.layout()`。字段真值与校验状态由 FormItem 持有。

## 上传

`Upload` 管理本地文件选择与队列状态，不代表 UIX 提供网络上传服务。网络传输、重试与服务端协议由应用负责。

## 理想使用方式

按产品定义（Rust 优先、容错可观测）：

```rust uix-compile=form-model
use uix::prelude::*;

// 类型化表单：业务模型驱动，提交即得类型化结果（E-01 已落地）
#[derive(Clone, Default)]
struct ProfileForm {
    name: String,
    age: u8,
    level: String,
}

let model = State::new(ProfileForm::default());
let form = Form::model(&model)
    .field("name", |v| &mut v.name, FormInputItem::new("name").required(true))
    .field("age", |v| &mut v.age, FormInputNumberItem::new("age").min(0.0).max(120.0))
    .field("level", |v| &mut v.level, FormSelectItem::new("level").options(["初级", "中级", "高级"]))
    .on_submit_typed(|profile: ProfileForm| {
        // 校验通过后回调；业务错误经 Err(String) 上抛
        println!("提交：{} / {}", profile.name, profile.age);
        Ok(())
    })
    .build();

embed(column![
    form.view(),
    button("提交").on_click(move |_| { let _ = form.submit_typed(); }),
]);
```

- 字段真值、校验状态与提交由 Form 持有，业务代码不维护两份状态；提交回调直接拿到类型化结果 `ProfileForm`。
- `Form::model(&State<M>)` 绑定业务模型，`.field(name, accessor, item)` 按投影声明字段，`.on_submit_typed` 在全部校验通过后触发，`Err(String)` 上抛。
- `form.submit()` 只校验并组装 `M`（不写回共享 State）；`submit_typed()` 写回模型并触发回调；校验失败不覆盖模型与已输入内容，`reset()` 恢复模型当前值。
- 同步与异步校验按字段版本关联，过期结果不覆盖新输入。
- 动态行使用稳定字段 key，行增删不破坏其他行的校验与焦点。
