## 文本输入

```rust uix-compile=text-inputs
let text = State::new(String::new());

// 单行
input()
    .placeholder("请输入用户名")
    .value(&text);

// 多行
Input::textarea()
    .placeholder("请输入描述")
    .value(&text)
    .rows(5)
    .max_length(500);

// 密码
Input::password()
    .placeholder("请输入密码")
    .value(&text);
```

- **绑定**：`.value(&State<String>)` controlled 模式，输入事件立即回写 State，外部 `set` 自动 reconcile；业务读取 `text.get()`，不从组件实例维护第二份值
- **模式**：`Input::textarea()` / `Input::password()` 直接声明模式
- **行数**：`.rows(n)`（≥ 1）；Textarea 把 CRLF / CR 统一为 LF，并保留末尾换行产生的空白行参与高度、光标和点击命中
- **长度限制**：`.max_length(n)`（按 Unicode 字符而非 UTF-8 字节计数）
- **前缀/后缀**：`.addon_before(...)` / `.addon_after(...)` 按 Unicode 可见文字扩展固有宽度
- **清除**：`.clearable(true)` 在有值时预留独立清除槽，聚焦或悬停后可点击清空并正常发布值变化
- **图标槽位**：前后图标、清除、密码可见性与搜索图标各占独立槽位
- **密码光标**：密码隐藏态的光标与 IME 预编辑按掩码文字位置显示
- **尺寸**：S / M / L 三档，通过 `.size(ControlSize::Small)` 设置
- **search 变体**：`Input::search()` — 带搜索图标，Enter 触发搜索
- **input group**：`InputGroup::new()` — 把前后附加文本接入一个输入框，不增加额外 Widget 状态
- **status**：`.status(InputStatus::Error)` — 带彩色边框和错误信息

```rust uix-compile=input-search-group-status
let search = Input::search().placeholder("搜索...");
let grouped = InputGroup::new()
    .addon_before("https://")
    .input(Input::new("域名"))
    .addon_after(".com");
let invalid = Input::new("邮箱")
    .status(InputStatus::Error)
    .message("格式不正确");
```

## 选择器

```rust uix-compile=single-select
let selected = State::new(String::new());
let options  = vec!["选项 A", "选项 B", "选项 C"];

Select::new()
    .options(&options)
    .value(&selected)
    .placeholder("请选择");
```

```rust uix-compile=multiple-select
// 多选
use std::collections::HashSet;

let options = vec!["选项 A", "选项 B", "选项 C"];
let selected_set = State::new(HashSet::new());

Select::multiple()
    .options(&options)
    .value(&selected_set); // State<HashSet<String>>
```

```rust uix-compile=searchable-select
// 可搜索
let selected = State::new(String::new());
let options = vec!["选项 A", "选项 B", "选项 C"];

Select::searchable()
    .options(&options)
    .value(&selected);
```

- **绑定**：单选 `State<String>`，多选 `State<HashSet<String>>`；选项文本就是外部真值（非索引），用户选择立即回写
- **非受控**：只需初始选中索引时用 `default_selected(index)`
- **可搜索**：`Select::searchable()` — 聚焦后直接输入，大小写不敏感的包含关系过滤；`Backspace` 修改查询，方向键只移动过滤结果中的高亮项，`Enter` 才提交并关闭（浏览候选不提前改写绑定 State）；查询只属于组件运行态，不写入绑定 State
- **多选**：`Select::multiple()` — `Enter` / `Space` 切换当前高亮项且保持下拉打开；已选标签的关闭槽可直接移除对应值
- **值不在选项中**：显示 placeholder
- **空态**：空选项或搜索无结果时，下拉保留一行本地化空态
- **下拉翻转**：空间不足时自动翻到控件上方，作为浮层覆盖普通兄弟内容
- **文本裁切**：长选项、搜索文字与多选标签在箭头槽之前裁切，箭头和标签关闭图标始终保持独立命中区
- **选项分组**：`SelectOptionGroup::new("组名", options)` — 下拉菜单中的分组选项
- **loading**：`.loading(true)` — 下拉菜单中显示加载旋转器
- **自定义选项**：`.render_option(|opt| view)` — 自定义选项内容的渲染

```rust uix-compile=select-groups-loading
let selected = State::new(String::new());
let fruit_options = ["苹果", "梨"];
let vegetable_options = ["胡萝卜", "西兰花"];

Select::new()
    .option_groups([
        SelectOptionGroup::new("水果", fruit_options),
        SelectOptionGroup::new("蔬菜", vegetable_options),
    ])
    .value(&selected)
    .loading(true);
```

加载态保留当前值和下拉尺寸，以旋转器替换候选项；期间不会提交选项。切回 `loading(false)` 后按原分组顺序恢复搜索、键盘与指针选择。

```text
// 目标写法
select.render_option(|opt| view! { /* 自定义渲染 */ });
```

## 开关与勾选

```rust uix-compile=boolean-and-choice-inputs
let checked   = State::new(false);
let selected  = State::new(String::new());
let options = vec!["选项 A", "选项 B", "选项 C"];

Checkbox::new("同意协议").checked(&checked);
Switch::new().checked(&checked);
Radio::group("group1", &options, &selected);
Segmented::new(&options).value(&selected);
```

**Checkbox**：
- `checked(&State<bool>)` 以外部 State 为真值并在用户切换时回写
- 非受控初值：`default_checked(bool)`
- 自然宽度按 `ControlSize` 对应 12 / 13 / 14 logical 标签字号估算 Unicode 宽字符
- 只有非空标签才在勾选框后保留间距，无标签写法只占勾选框自身宽度

**Switch**：
- `checked(&State<bool>)` / `default_checked(bool)` 同上
- S / M / L 固有尺寸：28×24 / 40×32 / 52×40 logical
- 轨道高：16 / 22 / 28 logical；圆形滑块在轨道内保持 2 logical 的对称内边距

**Radio**：
- `Radio::group(name, options, &State<String>)` 创建具名受控单选组
- 链式写法：`Radio::new().group_name(...).options(...).value(&state)`
- `default_selected(index)` 非受控初值；`current_value()` / `current_index()` 读取
- 横向组自然宽度按各选项 Unicode 可见文本估算，CJK 不按 UTF-8 字节数放大
- 键盘或语义聚焦后，当前选中项显示独立外焦点环；方向键越过首尾选项时从另一端继续

**Segmented**：
- `Segmented::new(options).value(&State<String>)` 使用相同的选项文本契约
- `disable_option(index)` 标记的项会被点击、方向键和语义选择跳过
- 组件默认进入 Tab 顺序并显示焦点框；方向键首尾循环
- `default_selected(index)` / `current_value()` / `current_index()` 读取；options 重排时按当前选项文本保留运行选择
- S / M / L 高度：24 / 32 / 40 logical
- 实际布局宽度与固有宽度不同时，各段按固有宽度比例共同填满 frame；绘制与命中使用同一组宽度，不会留下不可点击尾部或挤出可见区
- 整体或单项禁用时，当前选中块仍保持可辨

## 数值输入

```rust uix-compile=numeric-inputs
let num    = State::new(0i32);
let val    = State::new(50.0f64);
let rating = State::new(3u32);

InputNumber::new().value(&num).min(0.0).max(100.0).step(1.0);
Slider::new(0.0..=100.0).value(&val);
Rate::new().count(5).value(&rating);
```

**InputNumber**：
- `value(&State<T>)` 托管标准整数或浮点数（`InputNumberValue` 覆盖的类型）
- 接收系统 `TextInput` / IME commit 与粘贴中的 ASCII 数字、负号和小数点
- `Enter` 或失焦提交；无法解析的缓冲恢复为上一个有效值
- 数值按可往返文本显示，不会把超过两位的小数静默改写
- `Up` / `Down` 及右侧步进按钮先提交当前合法缓冲，再按 `step` 立即回写；按现值与步长的小数精度收敛常见二进制浮点尾差
- 整数 State 先将结果四舍五入，再同步组件显示
- 外部越界值按 `min` / `max` 显示且构建过程不改写 State，下一次用户操作会回写合法值
- 三档固有宽度：80 logical 文本主体加同高度方形步进区
- `default_value(T)` 非受控初值；`.placeholder(...)` 占位文本；`current_value()` 返回当前缓存值
- **formatter**：`.formatter(|v| format!("{v} %"))` 只改变非编辑态显示与无障碍文本；聚焦后仍编辑可解析的原始数字，State、`current_value()` 与 Change 不带格式化字符
- **keyboard**：`.keyboard(false)` — 禁用键盘输入，仅保留步进按钮

```rust uix-compile=input-number-pointer-only
let amount = State::new(10.0f64);

InputNumber::new()
    .value(&amount)
    .min(0.0)
    .max(100.0)
    .keyboard(false);
```

关闭 keyboard 后不接收实体按键、系统 `TextInput` 或粘贴，也不显示文本光标；指针步进按钮和无障碍 Increment / Decrement 仍按 `step` 回写。

```rust uix-compile=input-number-formatter
let input_number = InputNumber::new()
    .default_value(50.0f64)
    .formatter(|value| format!("{value} %"));
let _ = input_number;
```

**Slider**：
- `RangeInclusive<f64>` 声明区间；`value(&State<f64>)` 在拖动、方向键或语义增减时回写
- `.step(f64)` 网格从区间起点对齐，指针取最近网格；方向键从离格值进入对应方向相邻网格
- 常见十进制步长按区间起点与步长的小数精度收敛，不累积可见的二进制尾差
- 外部越界值按区间端点显示，下一次用户操作会回写合法值
- `default_value(f64)` 非受控初值
- S / M / L 固有尺寸：200×24 / 200×32 / 200×40 logical；配置 marks 后追加 18 logical 标签带
- **marks**：`.marks(vec![(0.0, "0%"), (50.0, "50%"), (100.0, "100%")])` 在轨道映射位置绘制刻度和标签；区间外或非有限值忽略，重复值以后项标签覆盖；marks 不改变 step、值或命中区
- **tooltip**：`.tooltip(TooltipPlacement::{Top, Bottom, Left, Right})` 以 thumb 为锚点，仅在左键拖动期间显示当前值；提示不改变布局、step 或命中区
- **range**：`Slider::range(...).start(&s).end(&e)` 返回 `RangeSlider`，两个 `State<f64>` 分别托管起止 thumb；指针操作最近 thumb，方向键操作最近一次激活 thumb，二者不得交叉
- Range Slider 沿用区间起点 step 网格、小数归一和 S / M / L 尺寸；外部 `start > end` 时显示值把 start 收敛到 end，不交换两个 State 的身份

```rust uix-compile=slider-marks
let slider = Slider::new(0.0..=100.0)
    .marks(vec![(0.0, "0%"), (50.0, "50%"), (100.0, "100%")]);
let _ = slider;
```

```rust uix-compile=slider-tooltip
let slider = Slider::new(0.0..=100.0).tooltip(TooltipPlacement::Top);
let _ = slider;
```

```rust uix-compile=slider-range
let start = State::new(20.0f64);
let end = State::new(80.0f64);
let slider = Slider::range(0.0..=100.0)
    .step(5.0)
    .start(&start)
    .end(&end);
let _ = slider;
```

**Rate**：
- `value(&State<u32>)` 托管评分；点击、方向键与语义增减立即回写
- 组件默认进入 Tab 顺序并显示焦点框
- 外部超出当前模式上限的值按上限显示，下一次用户操作会写回合法值
- `default_value(u32)` / `current_value()` / `.clearable()` 允许再次点击当前值清零
- `allow_half()` — State 的一个单位表示半星（`count(5)` 最大值为 `10`）
- 默认五颗星 S / M / L 固有尺寸：96×24 / 120×32 / 144×40 logical
- `.character(...)` 自定义 Unicode 文本

## 日期、时间与颜色

```rust uix-compile=date-time-color-inputs
let date  = State::new(Date::today());
let time  = State::new(Time::now());
let color = State::new(Color::RED);

DatePicker::new().value(&date);
TimePicker::new().value(&time);
ColorPicker::new().value(&color);

// 范围选择
let (start, end) = (State::new(Date::today()), State::new(Date::today()));
DateRangePicker::new()
    .start(&start).end(&end)
    .presets(vec![
        ("今天",     PresetDate::today()),
        ("本周",     PresetDate::this_week()),
        ("本月",     PresetDate::this_month()),
        ("最近 7 天", PresetDate::last_days(7)),
    ])
    .disabled_date(|d| d.weekday().is_weekend()); // 周末禁用

// 其他选择模式
DatePicker::new().mode(PickerMode::Week); // 周 / Month 月 / Quarter 季
```

**DatePicker**：
- `State<Date>` 为外部真值，用户选日立即回写；`Date::today()` 返回当前 UTC 日期
- `default_value(Date)` 非受控初值；`.placeholder(...)` 占位文本
- `disabled_date` 回调禁止命中日期提交
- `PickerMode::Week` / `Month` / `Quarter` 分别把周一、月初、季初写回 State
- S / M / L 固有尺寸：160×24 / 160×32 / 160×40 logical
- 打开后月历至少保持 160 logical 宽，月份标题、星期标题与六行日期互不重叠；浮层覆盖后续兄弟内容
- 键盘聚焦显示焦点框，快照与无障碍状态通过 `expanded` 反映开闭

**DateRangePicker**：
- `start` / `end` 两个 `State<Date>`；第一次命中只建立待选起点，第二次命中按日期排序后一次提交范围，禁用端点不会提交
- `default_range(start, end)` 非受控初值
- `PresetDate::today()` / `this_week()` / `this_month()` / `last_days(n)` 在组件构建时按当前 UTC 日期生成稳定范围
- 范围快照与无障碍值：`YYYY-MM-DD / YYYY-MM-DD`
- S / M / L 固有尺寸：280×24 / 280×32 / 280×40 logical
- 月历与预设 footer 作为同一浮层覆盖后续兄弟内容

**TimePicker**：
- `State<Time>` 为外部真值；分钟列提供 `00`–`59` 的每一分钟
- 打开时小时列与分钟列分别滚到当前值；滚轮只滚动指针悬停的列
- 键盘：`Left` / `Right` 切换列，`Up` / `Down` 移动高亮，`Enter` 一次提交两列，`Escape` 关闭
- `Time::now()` 返回当前 UTC 时间精确到分钟；`Time::new(hour, minute)` 收敛到 `23:59`
- `default_value(Time)` / `.placeholder(...)` / `current_value()`；`00:00` 是有效值而非空值
- S / M / L 固有尺寸：120×24 / 120×32 / 120×40 logical
- 弹层至少 120 logical 宽，两列文字居中；浮层覆盖后续兄弟内容

**ColorPicker**：
- `State<Color>` 为外部真值，选中预设色时立即回写
- 键盘：`Left` / `Right` 逐项移动，`Up` / `Down` 跨行移动，`Home` / `End` 到首尾，`Enter` / `Space` 提交，`Escape` 关闭
- `default_value(Color)` / `current_value()`；未配置时从 `Color::default()`（黑色）开始
- S / M / L 固有尺寸：24×24 / 32×32 / 40×40 logical
- 带 alpha 的颜色在棋盘格上合成，不会显示成空白
- 24 个预设按 8×3 色板排列，当前预设用随底色明暗切换黑白的勾标记
- 打开和关闭动画期间色板作为浮层覆盖后续兄弟内容

## 级联与自动完成

```rust uix-compile=cascader-and-suggestions
let tree_data = vec![
    TreeNode::new("北京", "beijing").children(vec![
        TreeNode::new("朝阳", "chaoyang"), TreeNode::new("海淀", "haidian"),
    ]),
    TreeNode::new("上海", "shanghai").children(vec![
        TreeNode::new("浦东", "pudong"), TreeNode::new("静安", "jingan"),
    ]),
];

let cascader_options = vec![
    CascaderOption::new("北京", "beijing").children(vec![
        CascaderOption::new("朝阳", "chaoyang"),
        CascaderOption::new("海淀", "haidian"),
    ]),
];

let cascader = Cascader::new(cascader_options, "请选择地区");
let tree_select = TreeSelect::new().nodes(tree_data).placeholder("请选择节点");
let mentions = Mentions::new("请输入 @ 用户").options(vec!["Ada", "Alan", "Grace"]);
let autocomplete = AutoComplete::new().options(vec!["Ada", "Alan", "Grace"]);
```

`Cascader::selected()` 返回当前标签和值路径；`TreeSelect::value()` / `value_key()`、`Mentions::value()` 与 `AutoComplete::value()` 返回各组件当前缓存值。

**AutoComplete**：
- 真实文本输入目标：点击按实测字形宽度定位光标；`Left` / `Right` / `Home` / `End` 移动光标；`Backspace` / `Delete` 在光标处按 Unicode 字符编辑；系统 `TextInput` / IME commit 与粘贴插入当前位置
- 查询按大小写不敏感的包含关系过滤，输入查询或提交候选都会发出 Change
- `Up` / `Down` 在候选中循环并自动滚入视口；`Enter` 提交；`Escape` 或失焦关闭弹层
- 候选弹层至少 200 logical 宽、每行 28 logical、最高 280 logical，支持滚轮；无匹配项仍显示本地化空态
- 触发框固有尺寸 200×32 logical
- `.value()` 始终返回当前已键入文本或最终候选值；长查询会水平滚动以保持光标可见

**Mentions**：
- 真实文本输入目标，光标定位与编辑方式同 AutoComplete
- 光标前最后一个 `@` 到光标之间没有空白时形成活动查询，按大小写不敏感的包含关系过滤
- `Enter` 或点击会把光标所在的完整 `@query` 替换为 `@候选 `，保留前后正文并把光标留在插入空格之后
- `Escape` 或失焦只关闭建议而不丢文本
- 候选弹层规格同 AutoComplete；触发框固有尺寸 200×32 logical
- `.value()` 返回当前完整正文；长正文会水平滚动以保持光标可见

**TreeSelect**：
- `Down` / `Enter` / `Space` 打开
- `Up` / `Down` 在扁平树中循环并跳过 `TreeNode::disabled(true)`；`Home` / `End` 到首尾可用节点；`Enter` / `Space` 提交
- 叶子或分支节点都可提交，发出稳定 node key 的 Change
- 弹层至少 200 logical 宽、最高 280 logical；层级通过缩进表达
- 触发框固有尺寸 200×32 logical
- `.value()` / `.value_key()` 同步返回当前标题和 key

**Cascader**：
- `Down` / `Enter` / `Space` 打开
- `Up` / `Down` 在当前层循环并跳过禁用项；`Home` / `End` 到首尾；`Right` / `Enter` / `Space` 进入子级或提交叶子；`Left` 返回父级；`Escape` 关闭
- 指针选择分支时保留全部祖先列并在右侧展开下一列，选择叶子后才关闭并发出以 `/` 连接 value 路径的 Change
- 每列滚轮位置相互独立；每列至少 200 logical 宽、视口高 200 logical
- 触发框固有尺寸 120×32 logical

- **search**：`.searchable(true)` 接收系统 TextInput / IME commit 与粘贴，按大小写不敏感的完整 label 路径过滤叶子；结果以单列完整路径呈现，可用 `Up` / `Down`、滚轮、指针与 `Enter` 选择，提交时写入完整 value 路径并发出 Change

## 上传

```rust uix-compile=upload-config
let mut upload = Upload::dragger()
    .accept(".jpg,.png,.pdf")
    .multiple(true)
    .max_count(10)
    .max_size(5 * 1024 * 1024)
    .show_upload_list(true)
    .preview_image(true);
assert!(upload.try_add_file("report.pdf"));
upload.update_progress(0, 0.5);
let queued = upload.files();
```

- **过滤**：`accept` 声明允许的扩展名，`multiple` 控制一次拖放可接收文件数，`max_count` 限制队列数量，`max_size(bytes)` 按真实文件 metadata 的字节数设置含上限；Windows 原生 `FileDrop` 会把命中组件且符合全部过滤条件的真实文件加入队列
- **大小语义**：超限文件和目录不入队、不发 Change；成功入队的真实文件在 `UploadFile::size` 记录字节数，并在 `source_path` 保留原路径。无法读取 metadata 的合成路径为兼容程序化队列按未知大小 0 接收且 `source_path` 为 `None`
- **读取队列**：`files()` 读取当前队列；`try_add_file` 返回 `false` 表示类型、数量或已知大小限制拒绝了文件（兼容的 `add_file` 忽略该返回值）
- **进度**：`update_progress` / `complete_file` 更新展示状态，成功完成会把进度归一为 `1.0`
- **拖拽区**：`Upload::dragger()` 创建完整拖放区域，带图标和提示文本；等价的低层配置是 `Upload::new().drag(true)`
- **上传列表**：`.show_upload_list(true)` 显示文件名、字节大小、进度、状态和移除按钮；点击移除按钮会缩短列表并发出 `<文件名>:removed` Change，`.show_upload_list(false)` 只隐藏列表、不清空队列
- **移除**：`remove_file` 返回被移除项，`clear_files` 清空队列；两者在列表可见时同步请求重排
- **预览**：`.preview_image(true)` 对有真实路径且可解码的本地图片显示 24×24 logical 圆角缩略图；非图片、解码失败或合成路径保持通用文件图标，列表行高不变
- **注意**：除显式图片预览外，组件只读取文件 metadata；组件不执行传输，实际上传 I/O 仍由应用服务负责
- **手动上传**：`.manual(true)` — 文件仅入队，通过 `.upload()` 调用触发上传
- **校验**：`.accept(".jpg,.png").max_size(5 * 1024 * 1024)` — 文件类型与字节上限

```text

    .accept(".jpg,.png")
    .manual(true);
upload.upload(); // 手动触发上传
```

## 表单

### 基础表单

字段校验闭包直接定义，返回 `Result<(), String>`：

```rust uix-compile=form-validation
let form = Form::new()
    .field("user", "用户名")
        .default("")
        .required("请输入用户名")
        .custom(|v| if v.len() < 3 {
            Err("至少 3 个字符".into())
        } else { Ok(()) })
    .field("email", "邮箱")
        .default("")
        .required("请输入邮箱")
        .validate_email("邮箱格式不正确")
    .field("age", "年龄")
        .default(0i32)
        .validate_range(1..=120, "年龄范围 1-120")
    .build();

match form.validate() {
    Ok(values) => {
        if let (Some(user), Some(email)) = (
            values.get::<String>("user"),
            values.get::<String>("email"),
        ) {
            println!("submit: {user} <{email}>");
        }
    }
    Err(errors) => {
        for error in &errors {
            eprintln!("{}: {}", error.field(), error.message());
        }
    }
}
```

- **声明字段**：`.field(name, label)` 声明一个表单字段，后接校验链
- **初始值**：`.initial(...)` 设置字段初始值；`.default(...)` 是兼容别名
- **校验规则**：`.required(msg)` / `.validate_email(msg)` / `.validate_range(...)` / `.custom(|v| ...)` 等声明式规则
- **构建**：`.build()` 返回 `FormModel`
- **校验**：`form.validate()` 返回 `Ok(Values)` 或 `Err(Vec<FieldError>)`，通过 `values.get::<T>("field")` 获取 typed 值
- **reset**：`form.reset()` 恢复全部声明初始值、清除已激活错误，并同步类型匹配的已绑定 `State`
- **scroll to error**：`form.scroll_to_first_error()` 聚焦首错，并请求支持显露的祖先 viewport 滚动到该字段；`submit()` 失败时自动执行
- **initial values**：`Form::new().initial_values(map)` 批量设置同类型初始值，`.field(...).initial(value)` 逐字段保留 typed 初始值；字段局部值优先

```rust uix-compile=form-reset-and-initial-values
use std::collections::HashMap;

let user = State::new("张三".to_string());
let age = State::new(25_i32);
let form = Form::new()
    .initial_values(HashMap::from([("user", "张三".to_string())]))
    .field("user", "用户名")
        .required("请输入用户名")
    .field("age", "年龄")
        .initial(25_i32)
        .validate_range(1_i32..=120_i32, "年龄范围 1-120")
    .build();

let fields = column((
    form.input_item("user", &user),
    form.input_number_item("age", &age),
));

form.set_value("user", "");
let _ = form.validate();
let _ = form.scroll_to_first_error();
form.reset();
```

### FormItem —— 声明式字段绑定

字符串、选项、布尔与标准数值字段可直接绑定为对应的 `FormItem + controlled component` View：

`FormItem` 的 `Horizontal`、`Vertical` 与 `Inline` 三种布局共用同一组标签、控件和帮助区几何。非空 `help` 会为字段自然高度增加 16px，不再覆盖子控件；标签与帮助文字分别裁剪在标签槽和字段边界内，`Inline` 也会呈现 success / warning / error 状态条与帮助文字。通过下方 `FormModel` 绑定方法生成字段时，item 会继承 `Form` 的 `layout` 与 `label_width`；直接组合 `Form + FormItem` 时，应在各 `FormItem` 上显式设置相同的 `.layout(...)` / `.label_width(...)`。

```rust uix-compile=form-input-item
use std::collections::HashSet;

let email = State::new(String::new());
let age = State::new(18i32);
let plan = State::new(String::new());
let channels = State::new(HashSet::new());
let accepted = State::new(false);
let notifications = State::new(true);
let volume = State::new(50.0_f64);
let rating = State::new(3_u32);
let delivery = State::new("标准".to_string());
let density = State::new("舒适".to_string());
let form = Form::new()
    .field("email", "邮箱")
        .default("")
        .required("请输入邮箱")
        .validate_email("格式不正确")
        .validate_trigger(Trigger::OnBlur)
    .field("age", "年龄")
        .default(18i32)
        .validate_range(18..=120, "年龄范围 18-120")
        .validate_trigger(Trigger::OnChange)
    .field("plan", "方案")
        .default("")
        .required("请选择方案")
        .validate_trigger(Trigger::OnBlur)
    .field("channels", "渠道")
        .default(HashSet::new())
        .required("请至少选择一个渠道")
        .validate_trigger(Trigger::OnChange)
    .field("accepted", "条款")
        .default(false)
        .custom(|value| if value == "true" { Ok(()) } else { Err("请接受条款".into()) })
        .validate_trigger(Trigger::OnChange)
    .field("notifications", "通知")
        .default(true)
    .field("volume", "音量")
        .default(50.0_f64)
        .validate_range(0.0..=100.0, "音量范围 0-100")
        .validate_trigger(Trigger::OnChange)
    .field("rating", "评分")
        .default(3_u32)
        .validate_range(1..=5, "评分范围 1-5")
        .validate_trigger(Trigger::OnBlur)
    .field("delivery", "配送")
        .default("标准")
        .required("请选择配送方式")
    .field("density", "密度")
        .default("舒适")
    .build();

let content = column((
    form.input_item("email", &email)
        .map(|item| item.placeholder("name@example.com").show_error(true)),
    form.input_number_item("age", &age)
        .map(|item| item.min(0.0).max(120.0).step(1.0)),
    form.select_item("plan", &plan)
        .map(|item| item.options(["基础版", "专业版"]).searchable()),
    form.select_item("channels", &channels)
        .map(|item| item.options(["邮件", "短信", "站内信"])),
    form.checkbox_item("accepted", &accepted)
        .map(|item| item.label("我已阅读并接受")),
    form.switch_item("notifications", &notifications),
    form.slider_item("volume", &volume, 0.0..=100.0)
        .map(|item| item.step(5.0)),
    form.rate_item("rating", &rating)
        .map(|item| item.count(5).clearable()),
    form.radio_item("delivery", &delivery)
        .map(|item| item.options(["标准", "加急"]).group_name("delivery")),
    form.segmented_item("density", &density)
        .map(|item| item.options(["紧凑", "舒适", "宽松"]).disable_option(2)),
));

let submitted = form.submit();
```

**字段绑定 API**（返回类型均包裹在 `Option<View>` 中，可直接放入 `column` / `row`）：

| 绑定方法 | 返回类型 | State 类型 |
|---------|---------|-----------|
| `input_item(field, &state)` | `FormInputItem` | `State<String>` |
| `select_item(field, &state)` | `FormSelectItem<T>` | `State<String>` 或 `State<HashSet<String>>` |
| `input_number_item(field, &state)` | `FormInputNumberItem<T>` | 整数或浮点数（`InputNumberValue`） |
| `checkbox_item(field, &state)` | `FormCheckboxItem` | `State<bool>` |
| `switch_item(field, &state)` | `FormSwitchItem` | `State<bool>` |
| `slider_item(field, &state, range)` | `FormSliderItem` | `State<f64>` |
| `rate_item(field, &state)` | `FormRateItem` | `State<u32>` |
| `radio_item(field, &state)` | `FormRadioItem` | `State<String>` |
| `segmented_item(field, &state)` | `FormSegmentedItem` | `State<String>` |

各绑定 item 均可继续设置对应组件的专有属性：

- **Select**：`options`、`optgroups`、`searchable`、`placeholder`、`size`、`disabled`；选项文本就是 typed 真值；多选集合向文本规则投影时先排序再以换行连接，`Values::get::<HashSet<String>>()` 返回原始集合
- **InputNumber**：`placeholder`、`min`、`max`、`step`、`size`、`disabled`
- **Checkbox**：`label` 设置复选框自身说明；`size`、`disabled`、`show_error`
- **Switch**：`size`、`disabled`、`show_error`
- **Slider**：`step`、`size`，区间由 Slider 归一
- **Rate**：`count`、`allow_half`、`clearable`、`character`、`size`、`disabled`；启用半星后 State 的一个单位仍表示半星
- **Radio**：`options`、`group_name`、`vertical`、`size`、`disabled`；未指定组名时使用字段名
- **Segmented**：`options`、`disable_option`、`size`、`disabled`；禁用选项跳过规则由原组件负责

> 布尔值的规则文本为 `"true"` / `"false"`，"必须开启" 应使用 `.custom(...)`，`.required(...)` 只判断文本是否为空不会拒绝 `false`。

**Date / Time / Color 绑定**：

```rust uix-compile=form-picker-items
let date = State::new(Date::new(2026, 7, 16));
let range_start = State::new(Date::new(2026, 7, 16));
let range_end = State::new(Date::new(2026, 7, 20));
let time = State::new(Time::new(9, 30));
let color = State::new(Color::blue());
let form = Form::new()
    .field("date", "日期")
        .default(Date::new(2026, 7, 16))
    .field("range_start", "开始日期")
        .default(Date::new(2026, 7, 16))
    .field("range_end", "结束日期")
        .default(Date::new(2026, 7, 20))
        .depends_on_with_values("range_start", |_, values| {
            let start = values.get::<Date>("range_start").copied().unwrap_or_default();
            let end = values.get::<Date>("range_end").copied().unwrap_or_default();
            (start <= end).then_some(()).ok_or_else(|| "结束日期不能早于开始日期".to_string())
        })
    .field("time", "时间")
        .default(Time::new(9, 30))
    .field("color", "颜色")
        .default(Color::blue())
    .build();

let pickers = column((
    form.date_picker_item("date", &date)
        .map(|item| item.placeholder("选择日期").mode(PickerMode::Date)),
    form.date_range_picker_item("range_start", &range_start, "range_end", &range_end)
        .map(|item| item.label("日期范围").placeholder("选择日期范围")),
    form.time_picker_item("time", &time)
        .map(|item| item.placeholder("选择时间")),
    form.color_picker_item("color", &color),
));
```

- `date_picker_item` → `FormDatePickerItem`；支持 `placeholder`、`mode`
- `time_picker_item` → `FormTimePickerItem`；支持 `placeholder`
- `color_picker_item` → `FormColorPickerItem`
- `date_range_picker_item(start_field, &start, end_field, &end)` → `FormDateRangePickerItem`；两个字段共享一个 `FormItem`，分别保留规则和 typed `Date`，Change / Blur 同步作用于两者
- Date 文本投影为 `YYYY-MM-DD`，Time 为 `HH:MM`，Color 为 `#RRGGBBAA`；`Values` 仍以 `Date` / `Time` / `Color` 返回

**运行时行为**：
- 输入修改同时回写 State 与 `FormModel`；`OnChange` 立即校验，`FocusOut` 激活 `OnBlur`
- 字段经 Blur 或 Submit 激活后，后续修改会持续重验
- 错误状态自动 reconcile 为红色字段状态和首条内联文本；`show_error(false)` 只隐藏文本不清除错误状态
- `submit()` 执行整表校验并返回 typed `Values` 或有序 `Vec<FieldError>`；失败时通过字段 `FocusHandle` 请求聚焦首错，并让支持显露的祖先 viewport 滚动到目标
- `reset()` 恢复模型初始值并清除激活状态；通过表单绑定方法登记且类型匹配的外部 `State` 同步恢复，控件无需逐项维护
- `FormModel::clone()` 共享值、错误与焦点句柄，可安全移入同一 UI 线程的事件闭包

### 表单联动

表单与普通 View 组合使用；提交按钮的回调可捕获 `form.clone()` 后调用 `submit()`，业务层只处理成功 values 或错误列表。字段依赖与动态列表仍沿用现有模型 API。

### 校验触发时机

```rust uix-compile=form-validation-triggers
let form = Form::new()
    .field("email", "邮箱")
        .default("")
        .required("请输入邮箱")
        .validate_email("格式不正确")
        .validate_trigger(Trigger::OnBlur)    // 失焦即校验
    .field("username", "用户名")
        .default("")
        .required("必填")
        .validate_trigger(Trigger::OnChange)  // 输入即校验
    .build();

form.set_value("username", "Ada"); // 执行 username 的 OnChange 规则
form.set_value("email", "ada@example.test");
form.blur("email");                 // 执行 email 的 OnBlur 规则
let visible_errors = form.errors();
```

- `Trigger::OnBlur` — 失焦（`FocusOut`）时触发校验
- `Trigger::OnChange` — 每次输入变更时立即校验
- `Trigger::Submit` / `Trigger::OnSubmit` — 仅在整表 `validate()` / `submit()` 时校验
- `set_value(field, value)` 以编程方式设置值并触发对应 trigger
- `blur(field)` 手动触发失焦校验
- `errors()` 返回当前可见错误
```rust uix-compile=form-submit-trigger
let form = Form::new()
    .field("name", "姓名")
        .initial("")
        .required("请输入姓名")
        .validate_trigger(Trigger::Submit)
    .build();

form.set_value("name", "");
let before_submit = form.errors();
let submitted = form.submit();
```

### 字段间依赖校验

被依赖字段变更后级联校验：

```rust uix-compile=form-dependent-validation
let form = Form::new()
    .field("password", "密码")
        .default("")
        .required("请输入密码")
    .field("confirm", "确认密码")
        .default("")
        .depends_on_with_values("password", |v, deps| {
            let Some(pwd) = deps.get::<String>("password") else {
                return Err("缺少密码字段".into());
            };
            if v != pwd { Err("两次密码不一致".into()) } else { Ok(()) }
        })
    .build();
```

- `.depends_on(source_field, closure)` 直接把依赖源的 typed 值传给一参数闭包
- `.depends_on_with_values(source_field, closure)` 把当前字段文本与整表 typed `Values` 传给高级闭包
- 依赖源经 `set_value()` 变化后，直接和传递依赖各按声明顺序重验一次
- 循环依赖由访问集截断，不会递归忙循环
- 提交校验时，依赖闭包读取的是本轮一致快照；依赖字段缺失或 typed 类型不匹配会形成当前字段错误

```rust uix-compile=form-typed-dependency
let form = Form::new()
    .field("province", "省份")
        .initial("浙江")
    .field("city", "城市")
        .initial("杭州")
        .depends_on("province", |province: &String| {
            ["浙江", "江苏"].contains(&province.as_str())
                .then_some(())
                .ok_or_else(|| "暂不支持该省份".to_string())
        })
    .build();

let values = form.validate();
```

### 动态表单（Form::List）

增删表单行：

```rust uix-compile=dynamic-form-list
let mut list = Form::new()
    .list("items", |items| {
        items
            .field("name", "名称").default("").required("必填")
            .field("qty", "数量").default(1i32).validate_range(1..=100, "1-100")
    })
    .build();

if let Ok(item_id) = list.add_item() { // ID 耗尽时返回 typed FormListError
    list.set_value(item_id, "name", "主机");
}
let rows = column(list.render_rows(|item_id, index| {
    label(format!("第 {} 行 · {}", index + 1, item_id.get()))
}));
list.remove_item(0);
```

- `.list(name, |items| { ... })` 声明可增删的列表字段
- `add_item()` 新增一行（ID 耗尽时返回 `FormListError`）
- `remove_item(index)` / `clear()` 删除行
- `render_rows(closure)` 在 View 构建期读取列表结构，按 `FormListItemId` 为每行写入稳定 key
- 增删只更新结构 State，自动请求所属根 View reconcile，未删除行保留组件实例
- 字段值和校验结果逐行隔离
- `validate()` 成功返回 `FormListValues`，失败按当前行顺序、再按字段声明顺序返回 `Vec<FormListFieldError>`
