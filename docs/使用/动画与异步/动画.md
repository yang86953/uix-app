# 动画

[← 返回使用索引](../../使用.md)

> **接口**：声明 UIX 动画系统的公开用法——Animated、Animation、Spring、Keyframe 与动画组。依赖：[响应式基础](../入门/响应式基础.md)。导出：动画架构 → [架构 · 动画系统](../../架构/ui/animation.md)。

UIX 提供两层动画 API：声明式 `Animated<T>` 绑定普通 View 属性，指令式 `Animation<T>` 用于自定义 `widget!`。两者都由逐窗 frame opportunity 推进；**勿用 [`run_interval`](定时与异步.md#定时器) 模拟帧动画。**

带 `uix-compile` 的 Rust fence 是外部 consumer 持续编译的公开写法。

## 已落地示例

```rust uix-compile=animation-animated
use uix_app::prelude::*;

// 声明式过渡：从 0 到 1，0.3 秒，ease_out
let fade = Animated::new(0.0_f32)
    .to(1.0, 0.3, Easing::ease_out);

// 弹簧动画
let bounce = Animated::new(0.0_f32)
    .to_spring(1.0, Spring::default());

// 关键帧
let pulse = Animated::new(0.0_f32)
    .to_keyframes(vec![
        Keyframe::new(0.0, 0.0),
        Keyframe::new(0.5, 1.0).easing(Easing::ease_in_out),
        Keyframe::new(1.0, 0.0),
    ], 1.2);
```

```rust uix-compile=animation-bind
use uix_app::prelude::*;

let opacity = Animated::new(0.0_f32).to(1.0, 0.4, Easing::ease_out);
let view_opacity = opacity.clone();

// 在 root 中读取 value() 绑定属性；框架自动登记帧推进
column((
    label("淡入内容").opacity(view_opacity.value()),
))
.gap(8.0);
```

```rust uix-compile=animation-widget
use uix_app::prelude::*;

// 指令式：组件内部持有 Animation<T>，由 update_animation 推进
widget! {
    pub struct PulseRing {
        pub time: f32,
    }
    @new -> Self { Self { time: 0.0 } }

    measure => (&self, constraints: Constraints) -> Size {
        constraints.clamp(Size::new(48.0, 48.0))
    }

    dirty_rect => (&self, frame: Rect) -> Rect {
        let cx = frame.x + frame.w * 0.5;
        let cy = frame.y + frame.h * 0.5;
        Rect::new(cx - 24.0, cy - 24.0, 48.0, 48.0)
    }

    update_animation => (&mut self, dt: f64) -> bool {
        self.time += dt as f32;
        true
    }

    render => (&self, frame: Rect, ctx: &mut PaintContext) {
        let phase = (self.time * 1.5).sin() * 0.5 + 0.5;
        let r = 6.0 + phase * 16.0;
        let color = ctx.tokens().color_primary();
        ctx.stroke_circle(
            frame.x + frame.w * 0.5,
            frame.y + frame.h * 0.5,
            r, color, 3.0,
        );
    }
}
```

## UIX 语言关键帧

UIX 文档可以直接声明 `@keyframes`，并在基础样式类或静态内联样式中使用固定顺序简写：

```uix
@keyframes reveal {
  from {
    width: 24px;
    opacity: 0;
    color: rgb(20, 30, 40);
    backgroundColor: rgba(10, 20, 30, 0.5);
  }
  to {
    width: 80px;
    opacity: 1;
    color: rgb(240, 240, 240);
    backgroundColor: rgb(30, 40, 50);
  }
}

revealCard {
  animation: reveal 600ms ease-in-out 50ms 2 alternate both;
}

<Text class="revealCard">声明式动画</Text>
```

完整顺序是 `name duration timing-function delay iteration-count direction fill-mode`，省略尾部字段时使用 `0s ease 0s 1 normal none`。首批支持 `width`、`height`、`borderRadius`、`opacity`、`color`、`backgroundColor`；具体值和组合限制见[UIX 样式属性 · animation](../../uix-lang/参考/样式属性.md#61-animation)。

宏会为每个动画字段建立组件私有 `Animated<T>`，首次挂载启动、同身份 reconcile 复用，并由既有逐窗 frame opportunity 推进。不要在 `:hover`、`:disabled`、`:checked` 或 `setStyle` 分支里启动 `animation`；这些状态切换使用下述 `transition`。

## UIX 状态过渡

基础样式用固定顺序 `property duration timing-function delay` 声明状态变化的平滑插值：

```uix
card {
  opacity: 1;
  backgroundColor: rgb(10, 20, 30);
  transition: all 250ms ease-in-out 50ms;
}

card:hover {
  opacity: 0.5;
  backgroundColor: rgb(30, 40, 50);
}

<Text class="card">平滑卡片</Text>
```

省略尾部字段时使用 `0s ease 0s`。首批支持 `all` 或单独选择 `width`、`height`、`borderRadius`、`opacity`、`color`、`backgroundColor`；首次挂载直接显示最终值，后续 `:hover` / `:disabled` / `:checked` 或 `setStyle` 目标变化才会原位 retarget。同一节点不可同时声明 `animation` 与 `transition`，固定尺寸和具体颜色限制见[UIX 样式属性 · transition](../../uix-lang/参考/样式属性.md#62-transition)。

## 生命周期与调度

- 动画只有在存在活动源时才登记逐窗 frame opportunity；完成、取消、卸载或窗口暂停后立即释放登记。
- `Animated<T>` 适合属性绑定，`Animation<T>` 适合组件内部状态机；二者不把时钟暴露给 painter。
- Spring 与 Keyframe 必须处理中途 retarget、零时长、不可插值值和拓扑变化。
- 离场动画持有的是受控租约，不得让已卸载组件继续接收业务事件。
- reduced-motion 时缩短或跳过非必要过渡，但保留最终状态与操作反馈。

这些调度、离场清理和 reduced-motion 原则持续有效；实际 API 以 Rust 版为准。

## 推荐用法

```rust uix-compile=animation-enter
use uix_app::prelude::*;

// 进场动画：声明式绑定，首次挂载时播放
label("淡入标题")
    .enter_animation(AnimationConfig::fade_in(0.3));

// 离场动画：keyed 移除时保留节点播放离场
label("离场内容")
    .leave_animation(AnimationConfig::fade_out(0.2));

// 列表交错入场：子项依次进场
column((
    label("A").enter_animation(AnimationConfig::slide_in(Placement::Bottom, 0.25)),
    label("B").enter_animation(AnimationConfig::slide_in(Placement::Bottom, 0.25)),
))
.stagger_enter(0.05, AnimationConfig::fade_in(0.25));
```

```rust uix-compile=animation-transition
use uix_app::prelude::*;

// Transition 直接绑定 View 属性，语义更紧凑
column((
    label("列表").enter(Transition::fade_in(0.3)),
    items.map(|list| column(
        list.iter().enumerate().map(|(i, item)| {
            label(item).enter(Transition::stagger(0.05 * i as f64, Transition::slide_up(0.25)))
        }).collect::<Vec<_>>(),
    )),
))
```

按产品定义（资源优先）：

- 动画只在活动时登记帧推进；空闲不消耗 CPU（资源优先）。
- 动画值只绑 View 属性，不在 painter 中推进时钟。
- 离场动画结束才清理句柄与订阅，不残留不可达操作。
- reduced-motion 下缩短或跳过非必要过渡，但保留最终状态与操作反馈。
