# 不必做

[← 返回使用索引](../../使用.md)

> **接口**：声明 UIX 框架自动托管、调用方不应手工干预的事项。依赖：无。导出：无。（终端使用文档）

以下操作由框架自动处理，手动干预会破坏框架调度：

- 不手写 `request_redraw` / vsync 申请
- 不手写探活定时器
- 不直接操作框架内部 registry / `OverlayStack`
- 不枚举内部 graphics recipe，不持有 raw window / surface / GPU 对象；平台服务和硬件信息只通过 `uix::platform::Platform` 的具体方法消费
- 不为各桌面 OS 写两套上层 UI
- 不用 `run_interval` 模拟帧动画（替代方案：[动画系统](../动画与异步/动画.md)）
- 界面描述优先用 uix-lang（推荐方式，编译时转换为 Rust，见 [uix-lang 快速开始](../../uix-lang/指南/快速开始.md)）；Rust 声明式 API 为支持方式，二者语义一一对应，不混写第二门运行语言

## 理想边界

按产品定义（资源优先、原生优先），以下事项同样不需要应用操心，全部由框架托管：

- 窗口 DPI 换算与缩放
- 焦点链与浮层层级（OverlayStack）
- 动画帧调度与离场清理
- 滚动容器状态（偏移、视口、overscroll）
- 组件卸载清理（任务、订阅、捕获）
- 错误收集与崩溃记录：不手写全局 panic hook 或重复收集错误；框架安装绑定 runtime 的 panic hook，报告有界、脱敏（见[运行保障](../框架设施/运行保障.md)）

如果业务代码需要做这些事，通常说明用法偏离了理想方式——先检查是否用了正确的组件或配置入口。
