# 软件动态扩展（P1：无界面最小闭环）

[← 返回使用索引](../使用.md)

> **接口**：声明运行时软件扩展的公开用法与限制。依赖与生命周期语义见[目标设计](../../架构/app/extensions.md)；引擎证据与兼容矩阵见[引擎取证](../../架构/app/extensions-engine.md)。

## 适用线索

需要在已运行的应用中装载用 Scheme（R7RS-small 受限宿主环境）编写的新命令、规则或业务逻辑，且不重启宿主、不创建窗口时，以本文为准。动态界面、事件订阅与热替换属后续阶段，本文不含。

## 前置条件

- 构建启用 Cargo feature `extensions`（默认关闭；未启用时本模块不进入编译图，使用方不承担解释器成本）。
- 宿主应用显式创建 `ExtensionHost` 并注入所需业务端口；扩展不能凭脚本获得未注入的能力。
- 扩展包由两部分组成：S 表达式清单与 `.scm` 源文件集，均以内存快照交给宿主（文件系统装载属应用责任）。

## 执行步骤：装载并调用一个文本转换扩展

```rust
use uix::app::extensions::{
    ExtensionHost, ExtensionPackage, ExtensionValue,
};

// 1. 构造包：清单 + 源文件（真实应用从磁盘或网络通道取得并冻结）。
let manifest = r#"
(uix-extension
  (schema-version 1)
  (id "text-tools")
  (version "0.1.0")
  (language r7rs-small)
  (entry "main.scm"))
"#;
let source = r#"
(define count 0)
(register-command! "shout"
  (lambda (text)
    (set! count (+ count 1))
    (string-upcase text)))
(register-command! "uses"
  (lambda () count))
"#;
let package = ExtensionPackage::from_parts(
    manifest.to_string(),
    [("main.scm".to_string(), source.to_string())]
        .into_iter()
        .collect(),
)?;

// 2. 准备（独立候选环境中求值入口、暂存命令）并激活（发布为活动代）。
let mut host = ExtensionHost::new();
let prepared = host.prepare(&package)?;
assert_eq!(prepared.commands(), ["shout", "uses"]);
let receipt = host.activate(prepared)?;
assert_eq!(receipt.extension_id, "text-tools");

// 3. 类型化调用：扩展状态在调用间保留（同一实例串行复用）。
let outcome = host.call_command(
    "text-tools",
    "shout",
    &[ExtensionValue::Text("hello".to_string())],
)?;
assert_eq!(outcome, ExtensionValue::Text("HELLO".to_string()));
let uses = host.call_command("text-tools", "uses", &[])?;
assert_eq!(uses, ExtensionValue::Int(1));

// 4. 停止：撤销注册并释放实例。
host.deactivate("text-tools")?;
```

## 宿主端口（受控业务能力）

清单 `capabilities` 声明所需能力名；`ExtensionHost::with_port` 注入实现。实际可调用能力 = 清单声明 ∩ 宿主已注入端口；声明了宿主没有的能力在 `prepare` 即被 `Incompatible` 拒绝。端口签名 `Fn(&[ExtensionValue]) -> Result<ExtensionValue, String>`：入参是跨边界 owned 值，返回值同样受限；闭包、环境与 continuation 不离开引擎。

```rust
use std::sync::Arc;

let host = ExtensionHost::new().with_port(
    "documents-query",
    Arc::new(|arguments: &[ExtensionValue]| {
        // 只读业务端口示例：按 key 返回文档文本。
        match arguments.first() {
            Some(ExtensionValue::Text(key)) if key == "intro" => {
                Ok(ExtensionValue::Text("UIX 扩展示例文档".to_string()))
            }
            _ => Err("未知文档".to_string()),
        }
    }),
);
```

脚本侧直接按能力名调用：`(documents-query "intro")`。

## 取消与资源

- `host.cancel_handle(id)` 返回跨线程安全的取消令柄；下一次求值检查点以 `Cancelled` 终止。
- 默认资源边界（可在 `ExtensionHostConfig` 调整）：准备 5 s、单次命令 1 s 墙钟；燃料 5×10⁶ 步；存活堆 4 MiB。超限分别返回 `Timeout` / `Quota`，不可被脚本捕获。
- 引擎在安全点执行标记-清扫回收：循环 pair、闭包-环境互引等不可达环会被断开释放；实例停用时执行关闭清扫。

## 可观察失败

`ExtensionError` 为类型化结果（不经过日志冒充处置）：

| 错误 | 触发 |
|---|---|
| `Package` | 清单结构、未知字段、入口缺失、路径逃逸、大小超限 |
| `Parse` | 源码读取失败 |
| `Incompatible` | schema / 语言不受支持、声明能力无对应端口、同 ID 重复激活 |
| `ScriptFailure` | 脚本 `error` / 未捕获 `raise`，携带 write 形式摘要 |
| `UnknownExtension` / `UnknownCommand` | 未激活、已卸载或命令不存在 |
| `Argument` | 跨边界值类型不符（NaN/Inf、非严格列表、超大精确整数等） |
| `Quota` / `Timeout` / `Cancelled` | 资源边界 |
| `HostFailure` | 端口自身失败 |
| `EnginePoisoned` | 引擎 panic 后实例弃用 |

## 动态 UI：挂载位、事件与异步端口（P2）

窗口应用经 `spawn_worker` 进入 UI 模式：引擎整体存活在独立执行线程，
UI 线程只投递命令与消费 owned 声明，layout / paint / 命中路径无解释器。

### 扩展侧：`(uix ui)` 与 `(uix tasks)` 库

```scheme
;; 声明是 tagged list：属性为 (名 值) 对，容器其余子项为子节点。
(submit-ui! 'panel                          ; 挂载位（应用白名单授权）
  (list 'column (list 'key "root") (list 'pad 8.0) (list 'gap 6.0)
        (list 'text (list 'key "title") "点击次数: 0")
        (list 'button (list 'key "btn") (list 'on-click 'on-increment) "增加")
        (list 'input (list 'key "field") (list 'on-change 'on-field-change) "")
        (list 'list (list 'key "items") (list "甲" "乙"))))

(register-handler! "on-increment"            ; 面板事件处理（ui-event 命名空间）
  (lambda () (submit-ui! 'panel (next))))

(call-async "documents-analyze" (list "intro")  ; 异步端口：立即返回
  (lambda (request result)                       ; 终态回调（代际校验）
    (submit-ui! 'panel (with-status result))))
```

支持的节点：`column` / `row`（pad、gap、bg）、`text`（color、size）、
`input`（placeholder、on-change、reset）、`button`（on-click、disabled）、
`list`（字符串项）。提交点全量校验：未知节点 / 字段、重复 key、深度
>16、节点 >512、文本 >4KiB、列表 >256 项拒绝并保留原树。

### 应用侧：挂载位与声明交付

```rust
use uix::app::extensions::{ExtensionHost, UiProjector, UiUpdate};
use uix::prelude::*;

let (updates_tx, updates_rx) = std::sync::mpsc::channel();
let host = ExtensionHost::new()
    .with_mount("panel")                       // 开放挂载位（能力 mount-panel）
    .with_port(/* 同步端口 */)
    .with_async_port("documents-analyze", /* Arc<Fn(u64, &[ExtensionValue], AsyncCompletion)> */)
    .with_ui_sink(Arc::new(move |update| { let _ = updates_tx.send(update); }));
let handle = host.spawn_worker();              // 引擎进入执行线程

// 投影器：声明 → ViewNode；事件闭包只发送（on_change / on_click_fn）。
let projector = UiProjector::new("panel-ext", receipt.generation, handle.event_sender());
App::new().on_start(move |app_handle| {
    // 桥：sink（扩展线程）→ post_to_ui（窗口 owner thread）
    //     UiUpdate::Applied { node, revision, .. } → 更新声明快照 + revision State
}).root(move || {
    revision.get();                            // 修订 State 驱动 scoped 重建
    projector.lock().unwrap().project("panel", &current_declaration)
})
```

- `UiUpdate::Applied { mount, extension, generation, revision, node }` /
  `Rejected { mount, extension, reason }`：回执区分「已接收 / 已应用」；
  GPU 呈现由 `perform` 的 `presented_revision` 另行确认。
- 事件闭包携带提交代；停用后的陈旧事件稳定拒绝，不写入新代。
- 输入草稿按稳定 key 保留（声明值变更不覆盖编辑中内容，`(reset #t)`
  显式重置）；同 key 同类型节点沿 UIX reconcile 原位复用。
- `automation_id` 为 `<扩展>/<挂载位>/<key...>`，Agent 与 TestApp 按此定位。

### 服务扩展点

`(register-service! "name" proc)` 登记版本化服务实现；宿主经
`call_service`（同步）或 `ExtensionUiHandle::call_service`（worker 模式）
调用，语义与命令一致（`UnknownCommand` 拒绝未登记名）。

`examples/extension_panel.rs`（`--features extensions,agent-control`）：

## 热替换、状态迁移与撤权（P3）

### 替换协议

```rust
// 准备候选（独立引擎求值；准备期无外部效果）。
let candidate = host.prepare(&package_v2)?;
// 以预期活动代替换：门控（命令串行化）→ 静止点导出 → 候选导入 →
// 提交新代 → 旧代关闭清扫。
let receipt = host.replace(candidate, expected_generation)?;
// receipt.migrated 标记是否执行了状态迁移；generation 递增不复用。
```

- 提交前失败（候选语法、迁移抛错、schema 不一致、冲突代）丢弃候选，
  旧代保留并继续接收；`expected_generation` 不符返回 `StaleGeneration`。
- worker 模式（`ExtensionUiHandle::replace`）同语义；在途异步终态经
  代际校验丢弃，不写入新代、不重放外部效果。
- 界面应用：替换回执后调用 `UiProjector::update_generation(new)` 切换
  事件代际；草稿库随投影器保留，兼容输入沿合同延续。

### 状态迁移合同

- 清单 `state-schema-version`：双方为 0 视为无状态（跳过迁移）；
  非零且版本一致时，`(register-state-export! proc)`（无参，返回跨边界
  owned 兼容值）与 `(register-state-import! proc)`（单参）必须同时
  注册，否则替换被拒绝（禁止静默清空）。
- 迁移路径下准备期暂存的初始声明被丢弃：**迁移过程拥有状态解释权**，
  由其在导入后以新状态重新 `submit-ui!`（或保持旧界面至新声明到达）。
- 导出与迁移只允许纯计算；闭包、环境与 continuation 不进入快照。

### 撤权与终态

- `host.revoke(id)`：撤权后新调用返回 `CapabilityDenied`，面板事件与
  异步终态丢弃；已发生或不能取消的效果由宿主收尾。实例保留至
  `deactivate`（状态可观察）。
- 卸载终态：`deactivate` 返回 `TeardownReceipt` 后实例已排空并释放
  （关闭清扫断开全部环引用）；重复停用返回 `UnknownExtension`。

## 适用限制

- 语言是「R7RS-small 实现中的受限宿主环境」：文件 / 进程 / 时钟 / 网络 / REPL 库拒绝，多值、异常、lazy、bytevector、内存字符串端口开放；完整矩阵见[引擎取证](../../架构/app/extensions-engine.md)。
- 同步 `ExtensionHost` 非线程安全：实例串行求值，仅取消令柄可跨线程；窗口应用用 `spawn_worker`（引擎移入执行线程，`spawn_worker` 前不得已装载实例）。
- 脚本域内部运行时错误（未绑定变量、类型不符）不可被 `guard` 捕获，直接终止当次调用；配额 / 取消 / 超时同样不可捕获；面板事件处理失败静默终止本次调用（不中断宿主）。
- `with-exception-handler` 的 handler 以子机器调用，handler 内 continuation 逃逸语义受限（矩阵已登记）。
- 首期单窗基线：多窗口事务请求拒绝；`activate` 遇同 ID 活动实例仍直接拒绝（升级走 `replace`）。
- 持久化可选协议（跨进程崩溃恢复）不在本阶段；进程内热替换不承诺崩溃恢复。
