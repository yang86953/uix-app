## 线程模型

`Platform::new()` 是唯一公开入口，必须在进程主线程调用，并把该线程固定为 owner thread：

```text
let mut platform = Platform::new()?;
```

`Platform` 不可克隆或跨线程移动。公开方法全部同步；信息结果拥有其数据，可以离开 `Platform` 生命周期保存。不使用全局 `current()`，也不通过其他层的 handle 获取。

## 系统硬件

基础查询不会加载 GPU driver。每一项直接使用现有 `Result` 表达成功或失败：

```text
use uix::platform::Platform;

fn print_hardware(platform: &Platform) {
    match platform.os_info() {
        Ok(os) => println!(
            "{} {}",
            os.name(),
            os.version().unwrap_or("<version unavailable>"),
        ),
        Err(error) => eprintln!("OS query failed: {error}"),
    }

    match platform.cpu_info() {
        Ok(cpu) => println!(
            "{} / {} logical CPUs",
            cpu.architecture(),
            cpu.logical_cores(),
        ),
        Err(error) => eprintln!("CPU query failed: {error}"),
    }

    match platform.memory_info() {
        Ok(memory) => println!(
            "{} / {} bytes available",
            memory.available_bytes(),
            memory.total_bytes(),
        ),
        Err(error) => eprintln!("memory query failed: {error}"),
    }
}
```

每次调用只采集请求的类别，不缓存、不预取其他类别；需要时间戳时由调用方在调用前后记录 `SystemTime`。

## GPU adapter

GPU 枚举按具体图形 API 显式进行，可能同步加载 driver 并阻塞：

```text
use uix::core::Result;
use uix::platform::graphics::{
    GpuDeviceType,
    GraphicsBackend,
};
use uix::platform::Platform;

fn print_vulkan_gpus(platform: &Platform) -> Result<()> {
    let adapters = platform.gpu_adapters(GraphicsBackend::Vulkan)?;
    for adapter in adapters.iter() {
        let kind = match adapter.device_type() {
            GpuDeviceType::Discrete => "discrete",
            GpuDeviceType::Integrated => "integrated",
            GpuDeviceType::Virtual => "virtual",
            GpuDeviceType::Software => "software",
            GpuDeviceType::Unknown => "unknown",
            _ => "future",
        };

        println!(
            "{:?}: {} ({kind}), driver={:?}",
            adapter.backend(),
            adapter.name().unwrap_or("<unnamed>"),
            adapter.driver(),
        );
    }

    Ok(())
}
```

返回值是 owned `GpuAdapterInfo`，可保存和跨线程读取，但只是本次枚举的描述信息，不是稳定 ID，也不能传回 platform 打开设备。成功但没有 adapter 时返回空数组。

同一物理 GPU 可能分别出现在 Vulkan、D3D12 或 Metal 查询中。adapter 被枚举到也不保证它适用于任意窗口 surface。

## 原生服务

独立公开面只包含 OS-known directory 与系统通知：

```text
use std::path::PathBuf;
use uix::core::Result;
use uix::platform::services::{
    SpecialDir,
    SystemNotification,
};
use uix::platform::Platform;

fn show_download_ready(platform: &mut Platform) -> Result<PathBuf> {
    let downloads = platform.special_dir(SpecialDir::Downloads)?;
    platform.show_notification(SystemNotification::new(
        "下载完成",
        downloads.display().to_string(),
    ))?;
    println!("downloads: {}", downloads.display());
    Ok(downloads)
}
```

目录不存在时仍可返回 OS 约定路径；该方法不负责创建目录。平台不支持系统通知时返回 `Errc::NotImplemented`，权限拒绝和 OS 失败仍是 `Err(Error)`。

剪贴板和原生文件对话框依赖窗口、seat 或受信任输入 activation，不属于这个可独立创建的公开面。这里不预先发布 activation token、异步 request 或 completion callback。

## 不公开的对象

- backend registry、recipe 与 probe callback
- 可由调用方实现的 platform / service / graphics trait
- native event loop、window owner、presenter 与 graphics context
- platform clipboard / file-dialog service 与输入 activation 对象
- `wgpu::Adapter`、`Device`、`Queue`、`Surface`
- GPU / display ID、generation、handle 与 lease
- Vulkan / D3D / Metal / OpenGL 对象
- raw window / display / surface handle
- renderer fallback、逐窗图形状态与恢复状态机
- auto、偏好排序和 fallback 等图形选择策略

普通文件读写、timer 和 console 分别使用 `std::fs`、调用方调度设施与日志 / `std::io`，platform 不重复提供。
