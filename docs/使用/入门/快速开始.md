# 框架快速开始

[← 返回使用索引](../../使用.md)

本页从 `uix-app` 自身能力开始，不依赖具体组件库。当前源码只有一个 Cargo package；使用相邻源码目录时固定配套提交，历史发行包不能代替当前源码的 API。

## 选择能力

仅使用状态时，应用的 Cargo.toml 可写：

```toml
[dependencies]
uix-app = { path = "../uix-app", default-features = false, features = ["reactive"] }
```

```rust
use uix_app::ui::State;

fn main() {
    let count = State::new(0);
    count.update(|value| *value += 1);
    assert_eq!(count.get(), 1);
}
```

需要布局时选择 `layout`，CPU 绘制选择 `graphics`，无窗口 View 选择 `ui`。完整列表见 [框架能力](../../架构/框架能力拆分.md)。

## 窗口应用

窗口应用使用 `application`，并显式选择目标图形后端。以下为 Linux/OpenGL 源码依赖：

```toml
uix-app = { path = "../uix-app", default-features = false, features = ["application", "opengles"] }
```

Windows 可选 `d3d11`，macOS 可选 `metal`。`App::new()` 组装宿主，通过 `.root(...)` 提供 View，通过 `.run()` 驱动生命周期。View 可由自定义实现或应用选定的组件库提供；框架自身提供 [自定义 View](../界面构建/组件.md) 与 [绘制闭包](../界面构建/绘制.md)。

原生应用需要目标平台开发依赖，正文使用系统字体或应用显式字体包。构建成功不替代窗口、输入与图形呈现的实际验证。

## 本仓库可运行示例

| 验证内容 | 命令 |
| --- | --- |
| 状态、派生值和订阅释放 | `cargo run --no-default-features --features reactive --example reactive` |
| 实际布局坐标 | `cargo run --no-default-features --features layout --example layout` |
| CPU 像素绘制 | `cargo run --no-default-features --features graphics --example offscreen` |
| 无窗口 View 与语义事件 | `cargo run --no-default-features --features test-harness --example headless_ui` |

这些例子各自只消费所属框架能力。无窗口语义事件通过不代表指针命中或目标平台呈现通过。

## UIX 与交付

语言编译入口在 [UIX 快速开始](../../uix-lang/指南/快速开始.md)，严格源码选择在 [按需编译](../../架构/使用方按需编译.md)。应用分别声明 UIX 源、Rust 使用根和动态候选，由框架统一计算依赖与资源闭包。

出现错误时保留类型化失败与诊断，按 [故障排查](故障排查.md) 和 [运行保障](../框架设施/运行保障.md) 定位。
