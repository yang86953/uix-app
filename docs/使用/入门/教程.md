# 教程 —— 从零搭建一个待办应用

[← 返回使用索引](../../使用.md)

> **接口**：声明 UIX 从零构建完整应用的连续公开教程。依赖：[快速开始](快速开始.md)。导出：各主题的详细用法。

> **推荐方式**：界面用 uix-lang 描述，见 [uix-lang 教程](../../uix-lang/指南/教程.md)（`<App>` 根与 `uix_app!` 已可编译）；本页为当前可运行的 Rust 声明式 API 教程，也是 uix-lang 的底层表示。

本教程用一个完整的 TODO 应用带你走完 UIX 的核心概念：State、View 组合、事件、表单、列表、样式、动画与持久化。

> 前置：已按[快速开始](快速开始.md)配好 `Cargo.toml`。

## 1. 最小骨架

```rust uix-compile=tutorial-step1
use uix::prelude::*;

fn main() {
    App::new()
        .title("待办")
        .size(400, 500)
        .root(|| label("Hello, TODO!").font_size(24.0))
        .run();
}
```

## 2. 用 State 管理数据

把待办列表存到 `State` 中——UIX 的响应式基石：

```rust uix-compile=tutorial-step2
let todos = State::new(vec![
    "学习 UIX".to_string(),
    "写一个应用".to_string(),
]);

// 读取
println!("当前有 {} 条待办", todos.get().len());

// 写入
todos.update(|list| list.push("部署上线".to_string()));
```

## 3. 组合 View：输入框 + 列表 + 按钮

```rust uix-compile=tutorial-step3
use uix::prelude::*;

fn main() {
    let todos = State::new(vec![
        "学习 UIX".to_string(),
        "写一个应用".to_string(),
    ]);
    let input_text = State::new(String::new());

    App::new()
        .title("待办")
        .size(400, 500)
        .root(move || {
            let input_for_add = input_text.clone();
            let todos_for_rows = todos.clone();
            column((
                // 输入区
                row((
                    input()
                        .placeholder("输入待办事项")
                        .value(&input_text)
                        .flex_grow(1.0),
                    button("添加").primary()
                        .on_click(&todos, move |list| {
                            let text = input_for_add.get();
                            if !text.is_empty() {
                                list.update(|items| items.push(text));
                                input_for_add.set(String::new());
                            }
                        }),
                )).gap(8.0),

                // 列表
                todos.map(move |list| {
                    column(list.iter().enumerate().map(|(i, item)| {
                        let todos = todos_for_rows.clone();
                        row((
                            label(format!("{}. {}", i + 1, item)).flex_grow(1.0),
                            button("完成").on_click(&todos, move |list| {
                                list.update(|l| { l.remove(i); });
                            }),
                        ))
                        .gap(8.0)
                        .padding_v(4.0)
                    }).collect::<Vec<_>>())
                }),
            ))
            .gap(16.0)
            .padding(16.0)
        })
        .run();
}
```

此时你应该能添加和完成待办事项了。

## 4. 美化界面：背景、圆角与间距

用 `.bg()`、`.radius()`、`.padding()`、`.gap()` 让 TODO 应用看起来更精致：

```rust uix-compile=tutorial-step4
// 给整体容器一个浅色背景和圆角
column((label("待办应用"),))
    .bg(Color::hex("#F5F7FA"))
    .radius(12.0)
    .padding(20.0)
    .gap(12.0);

// 每行待办做成卡片
row((
    label("1. 示例待办").flex_grow(1.0),
    button("完成")
        .primary()
        .radius(4.0),
))
.bg(Color::WHITE)
.radius(8.0)
.padding_h(12.0)
.padding_v(8.0)
.gap(8.0);

// 输入框也可以加圆角
input()
    .placeholder("输入待办事项")
    .radius(6.0);
```

- `.bg(color)` — 设置背景色，支持 `Color::WHITE`、`Color::hex("#F5F7FA")` 等
- `.radius(f32)` — 统一圆角半径
- `.padding(top, right, bottom, left)` 或 `.padding(all)` / `.padding_v(v)` / `.padding_h(h)` — 内边距
- `.gap(f32)` — 子元素之间的间距

把这些样式加到第 3 步的完整应用中，你的 TODO 就有了现代卡片式外观。更多颜色和布局选项见[布局](../界面构建/布局.md)。

## 5. 加入动画：用 Animated 淡入淡出

`Animated<T>` 是声明式动画值——创建在 root 外，在 root 中读 `value()` 绑定到 View 属性：

```rust uix-compile=tutorial-step5
use uix::prelude::*;

fn main() {
    // 创建淡入动画：从 0 过渡到 1，持续 0.3 秒，ease_out 缓出
    let fade = Animated::new(0.0_f32)
        .to(1.0, 0.3, Easing::ease_out);

    let view_fade = fade.clone();

    App::new()
        .title("动画待办")
        .size(300, 200)
        .root(move || {
            column((
                label("待办列表").font_size(18.0),
                // 透明度由动画值驱动——框架逐帧推进，不阻塞 UI
                column((
                    label("学习 UIX 动画").opacity(view_fade.value()),
                ))
                .gap(8.0),
            ))
            .gap(12.0)
            .padding(24.0)
        })
        .run();
}
```

- `Animated::new(0.0).to(1.0, 0.3, Easing::ease_out)` — 构造并启动过渡
- `.value()` — 读取当前插值，框架自动登记帧推进
- `.opacity(f32)` — 将透明度绑定到 View

更高级的用法（弹簧动画、关键帧、交错入场）见[动画](../动画与异步/动画.md)。

## 6. 数据持久化：用 Settings 保存待办

`SettingsService` 提供 KV 持久化——配置 `.settings(path)` 后，在 `on_start` 中加载数据，修改后调用 `.save()` 落盘：

```rust uix-compile=tutorial-step6
use uix::prelude::*;
use uix::data::SettingsService;

fn main() {
    let todos = State::new(Vec::<String>::new());
    let todos_for_load = todos.clone();
    // 用 State 槽承接容器里的设置服务，供界面闭包落盘时取用
    let services = State::new(None::<SettingsService>);
    let services_for_load = services.clone();

    App::new()
        .title("待办")
        .size(400, 500)
        .settings("todos.json")           // 指定持久化文件
        .on_start(move |handle| {
            // 从磁盘加载已保存的待办
            if let Some(settings) = handle.resolve::<SettingsService>() {
                // 克隆一份给界面闭包；Clone 与容器内实例共享同一状态
                services_for_load.set(Some(settings.clone()));
                if let Some(saved) = settings.get("todo_list") {
                    // Settings 存的是字符串，这里按行拆分恢复列表
                    let loaded: Vec<String> = saved
                        .lines()
                        .filter(|l| !l.is_empty())
                        .map(|l| l.to_string())
                        .collect();
                    todos_for_load.set(loaded);
                }
            }
        })
        .root(move || {
            // TODO 界面（同第 3 步）：修改待办后用上面存入的服务落盘
            //   if let Some(settings) = services.get() {
            //       settings.set("todo_list", todo_text.join("\n"));
            //       let _ = settings.save();
            //   }
            // 不要在回调里重新 SettingsService::new()：那会得到与容器
            // 脱钩的独立实例，写入不会进入应用共享的设置状态
            column(()).padding(16.0)
        })
        .run();
}
```

- `.settings("todos.json")` — 在 `run()` 前加载指定文件
- `handle.resolve::<SettingsService>()` — 在应用边界获取 SettingsService 实例（Clone 共享同一应用状态）
- 用 `State` 槽把克隆传入界面闭包，回调里取回后直接 `set`/`save`；不要在回调里 `SettingsService::new()`——那会创建与容器脱钩的独立实例
- `.get(key)` / `.set(key, value)` — 读写字符串；另有 `.get_typed` / `.set_typed` 处理标量
- `.save()` — 显式落盘，需先通过 `load(path)` 或 `.settings(path)` 配置路径

详细用法参考[配置](../框架设施/配置.md)。

## 7. 推荐用法：结构化待办

对真实应用，待办条目标记为独立类型，列表用稳定 key 渲染，持久化用类型化读写：

```rust uix-compile=tutorial-virtualized-todo uix-feature=settings-serde
use uix::prelude::*;

// 类型化待办 + 稳定 key + 类型化持久化（结构体编解码需启用 settings-serde feature，见[配置](../框架设施/配置.md#类型化读写)）
#[derive(Clone, PartialEq, serde::Serialize, serde::Deserialize)]
struct Todo {
    id: u64,
    text: String,
    done: bool,
}

// 渲染：按业务 key 稳定映射，虚拟化只物化可视区行
// render 闭包是 'static：用 State 克隆在闭包内读取，不借用外部变量
fn virtualized_todo_view(
    // 接收由业务所有者持有的待办状态。
    todos: &State<Vec<Todo>>,
    // 接收与待办业务 key 同步的完成状态句柄。
    done_flags: &State<Vec<State<bool>>>,
) -> ViewNode {
    // 克隆待办句柄供两个 'static 渲染闭包捕获。
    let render_todos = todos.clone();
    // 克隆完成状态集合句柄供行渲染闭包捕获。
    let render_done_flags = done_flags.clone();
    // 构造只物化可视区行的公开虚拟滚动节点。
    embed(VirtualScroll::new()
        // 使用当前待办快照声明虚拟列表长度。
        .item_count(render_todos.get().len())
        // 声明稳定行高。
        .item_height(40.0)
        // 可变列表先按业务 id 建立协调与组件私有状态共用的身份。
        .render_keyed({
            // 为 key 闭包保留独立 State 句柄。
            let keyed_todos = render_todos.clone();
            // 每次请求时读取当前业务 id。
            move |index| keyed_todos.get()[index].id
        }, move |index| {
            // 先取得拥有型快照，避免借用临时 Vec。
            let snapshot = render_todos.get();
            // 克隆当前条目供返回 View 持有文本。
            let todo = snapshot[index].clone();
            // 克隆当前行的受控完成状态句柄。
            let done = render_done_flags.get()[index].clone();
            // 组合受控复选框与待办文本。
            row((
                // 把 Checkbox 组件嵌入当前行。
                embed(Checkbox::new("").checked(&done)),
                // 文本节点持有当前条目的拥有型字符串。
                label(todo.text),
            ))
        })
        // 完成虚拟滚动组件构建。
        .build())
// 结束虚拟待办 View 构造函数。
}

// 持久化：结构体按 key 编解码，失败不覆盖旧值；settings 来自 on_start 中的 resolve
fn persist_todos(settings: &SettingsService, todos: &State<Vec<Todo>>) -> Result<(), Error> {
    settings.set_struct("todos", &todos.get())?;
    let _restored: Vec<Todo> = settings.require_struct("todos")?;
    Ok(())
}
```
