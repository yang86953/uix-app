# 框架能力使用路径

[← 返回使用索引](../../使用.md)

本教程按可独立消费的能力组织。先完成 [快速开始](快速开始.md)，再逐步加入所需能力；每一步使用本仓库自己的例子。

## 状态

阅读并运行 [reactive](../../../examples/reactive.rs)。它持有 `State`、派生 `Computed`、驱动 `Effect` 并释放订阅，也演示向外部刷新端口发送通知。状态本身不需要 View 树或绘制器。

## 布局

阅读并运行 [layout](../../../examples/layout.rs)。它输入父矩形和子项首选尺寸，再检查 Flex 实际输出的位置。增加 UI 前先区分首选尺寸、约束与最终分配空间；详细规则由 [布局机制](../界面构建/布局.md) 维护。

## 绘制

阅读并运行 [offscreen](../../../examples/offscreen.rs)。它在 CPU 表面写入像素，不创建窗口。需要把自定义图形放进 View 时使用 [绘制闭包](../界面构建/绘制.md#canvas)；图像帧、字体和资源同样由框架图形能力持有。

## View 与事件

阅读并运行 [headless_ui](../../../examples/headless_ui.rs)。自定义 `View` 返回节点，测试宿主完成布局并执行语义动作。业务状态、节点身份、语义调用与原始输入分别处理，完整合同见 [自定义 View](../界面构建/组件.md) 和 [事件](../交互与反馈/事件.md)。

## 应用宿主

最后通过 `application` 组装窗口、平台服务和事件循环，选择目标后端。把已验证的 View 交给 `App`，由应用拥有线程、外部服务与关闭顺序。窗口资源边界见 [多窗口](../导航与窗口/多窗口.md)，异步结果回投见 [定时与异步](../动画与异步/定时与异步.md)。

实际原生验证关注窗口创建、输入、布局、呈现和关闭。无窗口测试只证明它覆盖的行为。
