## 阅读路径

**新手**：推荐从 [uix-lang 快速开始](../../uix-lang/指南/快速开始.md) 的当前可编译 View 开始，再阅读 [uix-lang 教程](../../uix-lang/指南/教程.md) 的完整应用写法；需要对照 Rust 写法时看[教程](教程.md)。

**熟悉声明式 UI**：先看[响应式基础](响应式基础.md)，再看[组件](../界面构建/组件.md)与[组件速查](../界面构建/组件速查.md)，随后按任务进入布局、表单、导航或数据展示专题。

**接入既有项目**：先看[快速开始](快速开始.md)的依赖与 feature，再把既有业务、领域状态和服务保留在 Rust 组合根，通过 props、State 与类型化回调连接界面；随后核对[平台能力](../框架设施/平台能力.md)、[配置](../框架设施/配置.md)和[运行保障](../框架设施/运行保障.md)。

**遇到问题**：从[使用索引](../../使用.md)按能力域查找；组件名已知时直接使用[组件速查](../界面构建/组件速查.md)。平台或硬件完成度不在仓库文档中猜测，以 Gitea 的当前记录为准。

## 推荐入口

按产品定义，界面描述支持两种方式，推荐用 **uix-lang**（`.uix` 文档，编译时转换为 Rust，见[语言规范](../../uix-lang/README.md)）。公开 `uix!` 已可生成已登记子集的 `ViewNode`，`uix_app!` 已可把 `<App>` 根文档组装成现有 `App` builder；以下 Rust 声明式写法用于最小应用与尚未登记能力，也是 uix-lang 的底层表示：

```rust uix-compile=app-minimal
use uix::prelude::*;

fn main() {
    App::new()
        .title("My App")
        .size(800, 600)
        .root(|| column((label("Hello"), button("World"))))
        .run();
}
```

- 界面优先用 uix-lang 描述，编译时转换为 Rust；需要未登记能力时使用 Rust 声明式 API（Rust 优先）。
- 空闲必须真休眠，不做多余绘制（资源优先）。
- 上层代码不感知平台差异（原生优先）。
- 出错有类型，恢复有路径（容错可观测）。
- 非传递必需的能力通过显式 feature 按需选择（使用方按需编译）。

五条原则的完整定义见[定位与原则](../../产品/定位与原则.md#原则)。
