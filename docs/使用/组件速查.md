# 组件速查

[← 使用索引](../使用.md)

> **接口**：声明 UIX 全部 110+ 内置组件的分类速查映射。依赖：各分类使用文档。导出：每个组件名 → 对应详细使用文档的链接。

## 适用线索

当需要"查找某个内置组件的用法文档入口"时，本组件是快速索引。

## 权威范围

本组件提供组件名到详细用法页面的映射。各组件的权威用法以对应分类文档为准。

> 详见各分类文档：[布局](布局.md) · [输入](输入与表单.md) · [展示](数据展示.md) · [反馈](反馈.md) · [导航](导航.md) · [图表](图表.md)

## 通用

| 组件 | 说明 |
|------|------|
| [`Button`](样式与主题.md#语义样式) | 按钮，支持 primary / danger / ghost 等语义样式 |
| `Icon` | Lucide 图标，按名称渲染单个字形；所有应用可见图标都**必须**使用该组件，不得用 Unicode / ASCII 符号、本地化字符、普通文本组件或独立手绘图形代替；框架紧凑槽位同样复用 `Icon` 的嵌入绘制入口，控件自身几何例外见[架构约束](../架构/图形.md#图形) |
| [`Label`](数据展示.md#label) | 短文本标签，支持多行和文本选择 |
| [`FloatButton`](反馈.md#floatbutton) | 浮动操作按钮，带 tooltip、badge 与自定义定位 |
| [`Typography`](数据展示.md#typography) | 排版组件，标题、段落、标记、下划线、可复制 |
| `Divider` | 分割线，可选标签文字与虚线样式 |
| `Space` | 弹性容器，为子节点提供统一间距 |
| [`ThemeToggle`](样式与主题.md#themetoggle-主题切换按钮) | 内置亮色/暗色主题切换开关 |
