# 导航

[← 返回使用索引](../../使用.md)

> **接口**：声明 UIX 导航组件的公开用法——Menu、MenuBar、Navigation、Pagination、Steps、Tabs 与路由。依赖：[响应式基础](../入门/响应式基础.md)、[布局](../界面构建/布局.md)。导出：无。（终端使用文档）

## Menu

```rust uix-compile=menu-navigation
Menu::new()
    .items(vec![
        MenuItem {
            key: "home".into(),
            label: "首页".into(),
            icon: "home".into(),
            children: vec![],
            disabled: false,
        },
        MenuItem {
            key: "settings".into(),
            label: "设置".into(),
            icon: "settings".into(),
            children: vec![],
            disabled: false,
        },
    ])
    .active_key("home")
    .mode(MenuMode::Vertical);
```

`Menu` 默认进入 Tab 顺序。水平模式使用 `Left` / `Right`，垂直模式使用 `Up` / `Down`；导航会循环并跳过禁用项，未设置活动项时从对应方向的第一个可用项开始。方向键移动即更新活动项并发出以 item key 为载荷的 `SemanticKind::Change`，因此 `Enter` 不再建立第二套选择或激活状态；当前值可由 `get_active_key()` 或 `SnapshotFields::Menu::active_key` 读取。

```rust uix-compile=nav-menu-advanced
// 嵌套子菜单
MenuItem::new("系统").children(vec![
    MenuItem::new("用户"),
    MenuItem::new("角色"),
]);

// 内联垂直模式，始终展开
Menu::new().mode(MenuMode::Inline);

// 受控选中项
let selected_keys = vec!["home".to_string()];
Menu::new().selected_keys(&selected_keys);

// 受控子菜单展开
let open_keys = vec!["system".to_string()];
Menu::new().open_keys(&open_keys);

// 菜单项图标
MenuItem::new("首页").icon("home");
```

## Navigation

侧边栏导航，内含标题、导航项列表与版本号：

```rust uix-compile=navigation-sidebar
let theme = Theme::antd_light();
let sidebar = Navigation::new("MyApp")
    .item_with_icon("首页", "home", "home")
    .item_with_icon("设置", "settings", "settings")
    .active_index(0)
    .width(220.0)
    .compact(true)             // 紧凑模式（仅图标，无文字）
    .show_version(false);
let sidebar_view = embed(sidebar.build(theme.tokens()));
```

`Navigation::item(label, key)` 的第二参数是路由 key；需要图标时用 `item_with_icon(label, key, icon)`。侧栏是复合组件，使用与应用相同的 `Theme` tokens 构建后通过 `embed` 放入 `column` / `row`。

`Navigation` 与 `NavGroup` 生成的每个 `NavItem` 都进入 Tab 顺序，聚焦后使用 `Enter` / `Space` 激活；`Navigation` 项的变化载荷是 key，`NavGroup` 的独立项默认仍以索引文本为 key。共享选中索引可从 `active()` 读取，`Navigation::active_key()` 返回 typed key；单项可用 `nav_key()`、`is_active()` 或 `SnapshotFields::NavItem::{ key, active }` 判断。重复激活当前项不发重复事件，标准与 `compact` 模式使用同一交互契约。

```rust uix-compile=nav-collapse-advanced
// 受控折叠状态
let sidebar_collapsed = State::new(false);
Navigation::<String>::new("MyApp")
    .collapsed(&sidebar_collapsed);

// 折叠变化回调
Navigation::<String>::new("MyApp")
    .on_collapse(|_collapsed| {});
```

### NavGroup

管理一组导航项的共享选中状态：

```rust uix-compile=navigation-group
// NavGroup：构建一组 NavItem，由调用方映射进视图
let group_items = NavGroup::new()
    .item("首页", "home")
    .item("设置", "settings")
    .active_index(0)
    .build();
embed(column(group_items.into_iter().map(embed).collect::<Vec<_>>()));
```

## Pagination

```rust uix-compile=pagination
Pagination::new(200, 20)
    .current(2)
    .show_total(true)
    .show_size_changer(true)
    .page_size_options(vec![10, 20, 50, 100]);
```

`Pagination` 默认进入 Tab 顺序。`Left` / `Right` 或 `PageUp` / `PageDown` 前后翻页，`Home` / `End` 跳到首尾；启用尺寸切换后，`Up` / `Down` 或点击"条/页"区域按配置项循环。未显式设置 `page_size_options` 时默认使用 10/20/50/100，零值与重复项会被规范化。页码变化的 `SemanticKind::Change` 载荷仍是页码文本，page size 变化载荷为 `page_size=<值>`；当前状态可由 `get_current()`、`get_page_size()` 或 `SnapshotFields::Pagination::{current,page_size}` 读取。

```rust uix-compile=nav-pagination-advanced
// 简洁模式：仅上一页/下一页
Pagination::new(200, 20).simple(true);

// 显示跳转输入框
Pagination::new(200, 20).show_jumper(true);

// 自定义总数模板
Pagination::new(200, 20).total_template(|total, range| {
    format!("第 {}-{} 条 / 共 {total} 条", range.start, range.end)
});
```

## Steps / Breadcrumb / Anchor

```rust uix-compile=steps-breadcrumb-anchor
Steps::new(vec![
    Step::new("填写信息").description("录入收货地址"),
    Step::new("确认订单").description("核对商品与金额"),
    Step::new("完成支付"),
])
    .current(1)
    .vertical();

Breadcrumb::new()
    .items(vec![
        BreadcrumbItem::new("首页").link("/"),
        BreadcrumbItem::new("用户管理").link("/users"),
        BreadcrumbItem::new("详情").link("/users/detail").active(),
    ])
    .separator(">");

Anchor::new(vec![
    AnchorItem::new("基本信息", "section-1"),
    AnchorItem::new("高级设置", "section-2"),
]);
```

`Steps` 默认横向，可用 `.vertical()` 改为纵向；横向使用 `Left` / `Right`，纵向使用 `Up` / `Down` 切换当前步骤，二者都支持 `Home` / `End`。变化发出以步骤索引为载荷的 `SemanticKind::Change`，当前值可由 `get_current()` 或 `SnapshotFields::Steps::{ current, direction }` 读取；标题与 `description` 在两种方向都会绘制。

```rust uix-compile=nav-steps-advanced
// 步骤状态
Step::new("完成").status(StepStatus::Finish);
Step::new("进行中").status(StepStatus::Process);
Step::new("等待").status(StepStatus::Wait);
Step::new("失败").status(StepStatus::Error);

// 点击切换步骤
let steps = vec![Step::new("A"), Step::new("B")];
Steps::new(steps).clickable(true);

// 圆点进度样式
let steps = vec![Step::new("A"), Step::new("B")];
Steps::new(steps).dot(true);

// 自定义步骤图标
Step::new("支付").icon("credit-card");

// 步骤切换回调
let steps = vec![Step::new("A"), Step::new("B")];
Steps::new(steps).on_step(|_index, _step| {});
```

非空 `Breadcrumb` 默认进入 Tab 顺序。点击条目或使用 `Left` / `Right`、`Home` / `End` 切换当前项，`Enter` / `Space` 重新激活当前项；变化优先发出非空 `link` 作为 `SemanticKind::Change` 载荷，未设置链接的旧条目回退到标题。当前项可由 `active_index()`、`active_title()`、`active_link()` 或 `SnapshotFields::Breadcrumb::items` 中的 `active` 标记读取；reconcile 按稳定 `link` 保持选择，旧的空链接条目才按标题回退。`.last_active()` 安全地落实 UIX 的末项当前页契约，`.separator(...)` 同时控制测量、绘制与命中区域中的分隔符。

```rust uix-compile=nav-breadcrumb-advanced
// 面包屑图标
BreadcrumbItem::new("首页").icon("home");

// 超出折叠为下拉
Breadcrumb::new().max_items(3);
```

非空 `Anchor` 默认进入 Tab 顺序。`Up` / `Down` 移动当前锚点，`Home` / `End` 跳到首尾，`Enter` / `Space` 重新激活当前项；变化发出以 href 为载荷的 `SemanticKind::Change`。当前项可由 `active_index()`、`active_href()` 或 `SnapshotFields::Anchor::active_index` 读取；reconcile 按非空稳定 href 保持选择，href 序列改变时使旧位置缓存失效。调用方仍拥有真实滚动状态和动作：用 `set_positions(...)` 注入内容位置，以 `update_active(scroll_y)` 同步滚动高亮，或在 UIX 中用 `@change` 处理 href 并驱动自己的滚动容器。

```rust uix-compile=nav-anchor-advanced
// 锚点偏移
let items = vec![AnchorItem::new("首页", "home")];
Anchor::new(items.clone()).target_offset(16.0);

// 墨球指示器动画
Anchor::new(items.clone()).show_ink(true);

// 滚动检测边界
Anchor::new(items.clone()).bounds(100.0);

// 自定义滚动容器（非 window）
Anchor::new(items).container(|| ());
```

`.container(...)` 生成的单一容器由当前 `Anchor` 实例以固定身份拥有。父级声明重建或替换工厂时，框架采用最新工厂输出，同时保留该容器的 `WidgetId` 与组件私有 state；工厂返回的根节点不得再设置 `.key(...)`，该键由框架保留以保证运行时身份与状态身份一致。后续声明省略 `.container(...)`、真实移除 `Anchor`、替换根节点或关闭窗口时，容器的 State 绑定、Effect 与动画来源会随子树释放；离场动画尚未完成时重新声明容器，则复用同一实例并取消离场。

## Tabs / Segmented

```rust uix-compile=tabs
Tabs::new()
    .tabs(vec![
        Tab { label: "标签1".into(), key: "tab-1".into(), icon: "".into() },
        Tab { label: "标签2".into(), key: "tab-2".into(), icon: "".into() },
    ])
    .active(0);
```

`Tabs` 默认进入 Tab 顺序。聚焦后，`Left` / `Right` 循环切换，`Home` / `End` 跳到首尾页签；变化发出以 tab key 为载荷的 `SemanticKind::Change`。当前页签可由 `active_index()` / `current_key()` 或 `SnapshotFields::Tabs::{ active_index, active_key }` 读取。非受控 Tabs reconcile 时按 key 保持选择，而不是盲目沿用旧索引。

```rust uix-compile=nav-tabs-advanced
// 标签位置
Tabs::new().tab_position(TabPosition::Top);
Tabs::new().tab_position(TabPosition::Left);

// 可编辑标签（新增/关闭）
Tabs::editable()
    .on_add(|_key| {})
    .on_close(|_key| {});

// 溢出滚动而非换行
Tabs::new().scrollable(true);

// 标签图标
Tab::new("标签").icon("star");
```

## Dropdown

```rust uix-compile=dropdown
Dropdown::new("操作")
    .items(vec!["编辑", "删除", "导出"]);
```

`Dropdown` 默认进入 Tab 顺序。`Enter` / `Space` 开启或选择，`Up` / `Down` 循环高亮，`Home` / `End` 跳到首尾，`Escape` 关闭；失焦时自动关闭。鼠标与键盘选择都会发出以选项文本为载荷的 `SemanticKind::Change`。当前选择可由 `selected_index()` / `current_value()` 读取，`SnapshotFields::Dropdown` 同时提供 `open`、`selected_index` 与 `highlighted_index`。

```rust uix-compile=nav-dropdown-advanced
// 子菜单与分割线
Dropdown::new("操作").items(vec![
    DropdownItem::new("编辑"),
    DropdownItem::divider(),
    DropdownItem::new("更多").children(vec![
        DropdownItem::new("导入"),
        DropdownItem::new("导出"),
    ]),
]);

// 禁用项
DropdownItem::new("删除").disabled(true);

// 选项图标
DropdownItem::new("导出").icon("download");

// 触发模式
Dropdown::new("操作").trigger(TriggerMode::Hover);
Dropdown::new("操作").trigger(TriggerMode::ContextMenu);
```

## MenuBar

```rust uix-compile=menu-bar
MenuBar::new().keyed_menus(vec![
    MenuBarMenu::from_text("文件", "file")
        .item(MenuBarItem::from_text("新建任务", "file-new-task").icon("plus"))
        .item(MenuBarItem::divider())
        .item(MenuBarItem::from_text("打开工作区…", "file-open-workspace")),
    MenuBarMenu::from_text("视图", "view")
        .item(MenuBarItem::from_text("设置", "view-settings")),
]);
```

`MenuBar` 是横向顶级菜单入口条：入口行与每个入口的下拉弹层全部由组件内核自绘。点击入口展开下拉，再点同入口收起；已开状态下点击或悬停其他入口直接切换。`Enter` / `Space` 打开首个菜单或选择高亮条目，`Up` / `Down` 循环高亮，`Left` / `Right` 切换相邻入口，`Escape` 与点击外部关闭。选择条目后发布以条目稳定 key 为载荷的 `SemanticKind::Change`；声明层通过 `@change` 观察拥有型 String key（`$event.value`）。当前打开入口可由 `open_index()` 读取，`SnapshotFields::MenuBar` 同时提供 `menus`、`open_index` 与 `highlighted_index`。keyed 数据门禁要求入口 key 全栏唯一、条目 key 菜单内唯一，被拒绝身份经 `diagnostics()` 暴露。分隔线（`MenuBarItem::divider()`）与禁用项（`.disabled(true)`）不参与选择。入口前景与悬停/打开背景可由统一样式（`color`、`backgroundColor:hover`、`backgroundColor:active`）覆盖，弹层视觉保持组件私有。

## 页面路由

UIX 没有内置路由——页面切换就是响应式 View 组合。`Navigation::active_page` 直接双向绑定 `State<K>`：构建期读取当前 key 并登记 reconcile，用户激活项时写回同一 State；不存在于导航项中的外部值表现为无选中项。

### 类型化路由

同一 `Navigation<K>` 的 item key 与 `State<K>` 必须是同一种类型。`K: Display` 的文本只跨出到语义事件与快照，不参与应用内分发；路由枚举可用 `#[derive(Display)]` 免除手写实现（`Home` → `home`，`UserProfile` → `user-profile`）：

```rust uix-compile=typed-navigation-route
#[derive(Clone, PartialEq)]
enum Page { Home, Settings, About }

impl std::fmt::Display for Page {
    fn fmt(&self, formatter: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        formatter.write_str(match self {
            Self::Home => "home",
            Self::Settings => "settings",
            Self::About => "about",
        })
    }
}

fn routed_view(theme: &Theme, current_page: &State<Page>) -> ViewNode {
    row((
        embed(
            Navigation::new("MyApp")
                .item("首页", Page::Home)
                .item("设置", Page::Settings)
                .item("关于", Page::About)
                .active_page(current_page)
                .show_version(false)
                .build(theme.tokens()),
        ),
        current_page.map(|page| match page {
            Page::Home => label("首页"),
            Page::Settings => label("设置"),
            Page::About => label("关于"),
        }),
    ))
}
```

### Tabs 路由

字符串 tabs 在声明完 `.tab(...)` 后用 `.active_key(&State<String>)` 绑定；枚举 key 用 `Tabs::controlled` 一次传入同类型项，避免字符串与枚举的双份映射：

```rust uix-compile=typed-tabs-route
#[derive(Clone, PartialEq)]
enum TabPage { List, Detail }

impl std::fmt::Display for TabPage {
    fn fmt(&self, formatter: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        formatter.write_str(match self {
            Self::List => "list",
            Self::Detail => "detail",
        })
    }
}

fn tabbed_view(active_tab: &State<TabPage>) -> ViewNode {
    column((
        embed(Tabs::controlled(
            [("列表", TabPage::List), ("详情", TabPage::Detail)],
            active_tab,
        )),
        active_tab.map(|key| match key {
            TabPage::List => label("列表内容"),
            TabPage::Detail => label("详情内容"),
        }),
    ))
}
```

## 推荐用法

按产品定义（Rust 优先、原生优先）：

```rust uix-compile=navigation-typed-route
use uix::prelude::*;

// 路由即 State，导航项与页面切换共享同一类型化 key
#[derive(Clone, PartialEq, Display)]
enum Route { Home, Workspace, Settings }

let route = State::new(Route::Home);

App::new()
    .root(move || {
        row((
            embed(Navigation::new("UIX")
                .item("首页", Route::Home)
                .item("工作台", Route::Workspace)
                .item("设置", Route::Settings)
                .active_page(&route)
                .build(theme.tokens())),
            route.map(|r| page_for(r)),
        ))
    })
    .run();
```

- 页面切换就是响应式 View 组合，`Navigation::active_page` 双向绑定同一 `State<K>`。
- 菜单项、标签页、面包屑的选中态都由稳定 key 驱动，不靠显示文案或旧索引。
- 键盘导航（Tab 顺序、方向键、Home/End）由框架托管，业务不重复实现。
