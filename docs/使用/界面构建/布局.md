# 布局

[← 返回使用索引](../../使用.md)

> **接口**：声明 UIX 布局系统的公开用法——column/row 容器、Flex 伸缩、Grid（含响应式）、Splitter、Affix/Sider、ScrollView 和 VirtualScroll。依赖：[响应式基础](../入门/响应式基础.md)。导出：布局引擎架构 → [架构 · 布局引擎](../../架构/ui/layout.md)。

## 容器

| 容器 | 行为 |
|------|------|
| `column` | 子项沿纵轴排列；内容高度优先，剩余空间按显式伸缩规则分配 |
| `row` | 子项沿横轴排列；交叉轴对齐与溢出策略由容器统一决定 |
| Flex | 支持主轴/交叉轴对齐、间距、grow、shrink 与 basis |
| Grid | 支持固定、内容自适应、比例和响应式列；轨道尺寸由内容需求与父级可用空间共同解析 |
| Splitter | 用指针或键盘调整相邻面板比例，并保持最小尺寸 |
| ScrollView | 持有滚动偏移、视口和内容范围，不把滚动状态藏在业务组件中 |
| VirtualScroll | 只物化可见区附近项目，以稳定 key 复用行状态 |

## Flex 的边界行为

- `overflow_content` 保留自然主轴尺寸，并冻结 `flex_grow` / `flex_shrink`；主轴分布、交叉轴对齐、gap、反向方向、wrap 和逐项 `align_self` 仍生效。
- 实际主轴小于自然内容时，Center / End 分别保留一半 / 全部负剩余空间，Start 与 Space* 保持起点及基础 gap；零尺寸 bootstrap 不应用负偏移。
- 交叉轴对齐先扣除两侧 margin。零交叉轴 bootstrap 由自然外尺寸撑开，Stretch 不会把内容压成零；固定尺寸空 Flex 保留父级分配尺寸，固有/溢出主轴则收敛为零。
- 反向方向按实际容器主轴镜像；单行 `overflow_content` 在零主轴 bootstrap 时按自然内容长度镜像。物理 margin 始终附着原侧。
- 启用 wrap 但没有实际分行时，结果与 non-wrap 一致。形成多行后，正交叉轴剩余空间由 Stretch 在保留固定行 gap 后分配，逐项 `align_self` 只覆盖本项。
- 单行和多行 Stretch 都受子项 `min_size` / `max_size` 约束。达到上限的子项停止拉伸；行盒仍保留已分配空间。
- 零主轴尺寸子项仍算一个项目并参与 gap/换行；有限负 gap 可以产生声明式重叠，但不能让自然内容范围遗漏任一可见子项。
- Row/Column 的轴转置和 Reverse 的物理镜像必须保持 frame、margin 与内容尺寸账本一致，不能因分支不同产生另一套语义。

## Margin 与内容范围

- 正右/下 margin 进入内容范围；负尾侧 margin 只缩短兄弟推进和换行占用，不裁剪当前子项自身的可见末端。
- 多行内容范围取全部行盒和子项的最远可见末端，而不是最后一行末端；滚动容器因此仍能到达较高的前行或较宽的前列。
- `Container` 与 `Space` 让子项 margin 参与占位；无固定尺寸的容器由完整外尺寸撑开。

## 复合组件的一致几何

- `RichText` 测量缓存绑定有效宽度；宽度变化立即使旧行高、行坐标、选择和代码复制命中失效，绘制在同一宽度下重建真实字体几何。
- `Notification` 的 384px 是设计上限而非强制宽度；先保留窗口两侧各 24px 留白再封顶，绘制、浮层、damage 与命中共用同一矩形。
- `Table` 的视觉层级为选择列 → Middle → Left → Right → 展开控件；分组表头、合并单元格、固定列、选择、展开和调整句柄的命中遵循同一最终层级与裁剪。跨固定区的自定义 View 只拥有一个状态子树，多个可见片段不能产生重复状态或穿透命中。
- 移除最后一个直接子项时，Container/Space/Affix 立即清除内容占位，ScrollView 同步归零范围与偏移，Carousel 清除幻灯片数量，不等待下一轮空布局。

## Grid

```rust uix-compile=layout-grid
use uix::prelude::*;

// 按列轨道声明布局，子项用 tree! 包裹
embed(tree! { Grid::new()
    .columns(vec![GridTrack::Fr(1.0), GridTrack::Fr(2.0)])
    .gap(8.0) => [
        label("1fr"),
        label("2fr"),
    ]
});

// 响应式 24 栅格：断点列宽声明式表达
embed(Grid::responsive()
    .cols(vec![
        Col::new().span(24).sm(12).md(8).lg(6),
        Col::new().span(24).sm(12).md(8).lg(6),
    ])
    .gap(4.0));
```

- `GridTrack::Px` 固定尺寸，`Auto` 采用子项有限外尺寸，`Fr` 分配扣除固定/Auto/gap 后的剩余空间；纯 Auto 网格不为填满父容器而膨胀。
- span 先扣除 gap 和已知轨道，再把缺口分给覆盖的 Auto。span 同时覆盖 Auto 与部分 Fr 时，只能在父级容量内协调；没有 Auto 或覆盖全部 Fr 时保留作者权重。
- `Grid::justify(...)` 对齐整组列轨，单元格内对齐是独立通道；Stretch 只扩展 Auto 轨道，不拉伸子项。`.align_self(...)` 只覆盖本项，并在扣除 margin 后求解。
- `Grid::responsive()` 提供 24 栅格断点列宽。
- 放置资源有硬上限：每轴最多 4096 条轨道、稠密账本最多 65,536 个单元格。超限 span 收敛到可地址窗口；自动放置无完整空闲矩形时保留零 frame，不重叠或无界扩行伪造成功。

## Splitter

```rust uix-compile=layout-splitter
use uix::prelude::*;

// 可拖拽分割面板：声明面板数与最小尺寸（widget，直接 embed）
embed(Splitter::new()
    .panels(2)
    .min_size(0, 120.0)
    .vertical(false));
```

Splitter 用指针或键盘调整相邻面板比例，并保持最小尺寸；方向可用 `.vertical(true)` 切换。

## Affix / BackTop / Sider

```rust uix-compile=layout-affix
use uix::prelude::*;

// 固钉：滚动越过阈值后固定在视口（子节点包裹）
embed(ViewNode::new(
    Affix::new(12.0).scroll_y(180.0),
    vec![button("回到操作").into()],
));

// 回到顶部：滚动高度超过阈值后显示
embed(BackTop::new().visibility_height(400.0));
```

应用壳组件：`Sider`（可折叠侧边栏）、`Header`（顶部）、`Content`（主内容）、`Footer`（底部）通过 `Layout` 组合成标准应用骨架。

## 滚动

```rust uix-compile=layout-scroll
use uix::prelude::*;

// 滚动容器：内容超出时出现滚动条
scroll(column(
    (0..100).map(|i| label(format!("行 {i}"))).collect::<Vec<_>>(),
))
.height(300.0);

// 虚拟滚动：只物化可视区行
embed(VirtualScroll::new()
    .item_count(100_000)
    .item_height(24.0)
    .render(|index| label(format!("行 {index}")).height(24.0))
    .build());
```

- ScrollView 持有偏移、视口和内容范围；纵向/双向按纵列、横向按单行排布。四侧 margin 参与内容范围，非滚动轴填充先扣 margin；双轴最大滚动距离按扣除对侧滚动条沟槽后的真实视口计算。
- VirtualScroll 单次最多物化 4096 行，可见内容优先于 overscan。NaN、无穷、零或负行高/viewport 返回空窗口，不写入非法 frame。
- 可变行高以 `.item_height(...)` 为未知项估算，`.variable_height()` 接受实测值，`.measurement_version(...)` 使旧缓存失效。
- `.render(...)` 使用绝对索引身份，只适合顺序不可变数据，renderer 不得另设行根 key。排序、插入或删除数据必须使用 `.render_keyed(...)`，业务 key 在全集内唯一稳定，并同时约束节点与组件私有状态。
- 大数据集一律虚拟化；静止且范围/数据/测量未变化时不产生持续工作。

## 保留的布局约束

这些约束与实现语言无关，并与 Rust `layout` / `virtualization` 架构一致：

- 所有公开布局值使用 logical 坐标；DPI 换算留在窗口与呈现边界。
- 子项测量先收窄约束再返回有限尺寸；NaN、无穷和负尺寸不得进入后续布局。
- 固有内容测量只回答内容需求，不绕过父级约束。
- 溢出、裁剪、嵌套滚动与 overscroll 必须由最近的容器明确拥有。
- 虚拟列表以业务稳定 key 保留可变数据的状态；绝对索引后备 key 只用于顺序不可变的数据，当前窗口内的局部位置不能替代身份。
- 声明更新只改变 `Label` 颜色或 `Container`/`Grid` 背景等纯视觉字段时只重绘；文本、尺寸、盒模型、Flex/Grid 属性、轨道或可见性变化会重新布局。其余内建组件、`Unknown` 与 `Custom` 快照显式采用保守 Layout + Paint；只有公开行为具备外部消费者证据后才收窄，完整矩阵见[架构布局失效分类](../../架构/ui/layout.md#失效分类矩阵)。

公开 API 测试完成度见 [仓库状态账目](../../../TODO.md)；内部布局算法和性能不建立项目测试。

## 推荐用法

按产品定义（资源优先、Rust 优先），推荐布局写法：

```rust uix-compile=layout-app-shell
use uix::prelude::*;

// 应用壳 + 响应式栅格 + 虚拟化大列表
fn app_shell() -> ViewNode {
    row((
        embed(Sider::new(200.0).collapsible(true)),
        column((
            embed(Header::new(48.0).title("工作台")),
            embed(Content::new().child(
                Grid::responsive()
                    .cols(vec![
                        Col::new().span(24).sm(12).md(8).lg(6),
                        Col::new().span(24).sm(12).md(8).lg(6),
                        Col::new().span(24).sm(12).md(8).lg(6),
                    ])
                    .children(cards()),
            )),
        )).flex_grow(1.0),
    ))
}
```

- 布局状态（滚动偏移、折叠、splitter 比例）由框架/组件持有，业务代码不复制一份。
- 大数据集一律虚拟化：VirtualScroll 以 4096 行硬上限物化可视区，长列表不整棵渲染。
- 响应式断点声明式表达，不在业务代码里做平台/尺寸 ifdef。
