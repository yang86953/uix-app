# 布局机制

[← 返回使用索引](../../使用.md)

`uix-app` 的 `layout` 能力提供尺寸约束、盒模型、Flex 与 Grid 求解，不依赖原生窗口、字体或具体控件。布局结果使用 logical 坐标；DPI 转换在呈现边界执行。

## 独立使用

输入为父级 `Rect` 和 `LayoutChild`，输出包含子项位置与内容尺寸。[布局示例](../../../examples/layout.rs) 直接调用 `FlexLayout::row().layout(...)` 并检查实际坐标：

```sh
cargo run --no-default-features --features layout --example layout
```

## 测量与盒模型

测量返回有限的首选尺寸；父约束、min/max、margin、border 和 padding 共同限定最终盒子。宽高使用 border-box，margin 由父布局消费一次。`flex_basis` 与首选尺寸分开表达，不应为了伸缩把两个方向的内容尺寸都清零。

## Flex 的边界行为

- `overflow_content` 保留自然主轴尺寸，并冻结 `flex_grow` / `flex_shrink`；主轴分布、交叉轴对齐、gap、反向方向、wrap 和逐项 `align_self` 仍生效。
- 实际主轴小于自然内容时，Center / End 分别保留一半 / 全部负剩余空间，Start 与 Space* 保持起点及基础 gap；零尺寸 bootstrap 不应用负偏移。
- 交叉轴对齐先扣除两侧 margin。零交叉轴 bootstrap 由自然外尺寸撑开，Stretch 不会把内容压成零；固定尺寸空 Flex 保留父级分配尺寸，固有/溢出主轴则收敛为零。
- 反向方向按实际容器主轴镜像；单行 `overflow_content` 在零主轴 bootstrap 时按自然内容长度镜像。物理 margin 始终附着原侧。
- 启用 wrap 但没有实际分行时，结果与 non-wrap 一致。形成多行后，正交叉轴剩余空间由 Stretch 在保留固定行 gap 后分配，逐项 `align_self` 只覆盖本项。
- 单行和多行 Stretch 都受子项 `min_size` / `max_size` 约束。达到上限的子项停止拉伸；行盒仍保留已分配空间。
- 零主轴尺寸子项仍算一个项目并参与 gap/换行；有限负 gap 可以产生声明式重叠，但不能让自然内容范围遗漏任一可见子项。
- Row/Column 的轴转置和 Reverse 的物理镜像必须保持 frame、margin 与内容尺寸账本一致，不能因分支不同产生另一套语义。

## Margin 与内容范围

- 正右/下 margin 进入内容范围；负尾侧 margin 只缩短兄弟推进和换行占用，不裁剪当前子项自身的可见末端。
- 多行内容范围取全部行盒和子项的最远可见末端，而不是最后一行末端；滚动容器因此仍能到达较高的前行或较宽的前列。
- 布局宿主应让子项 margin 参与占位；无固定尺寸的盒子由完整外尺寸撑开。

## Grid 求解

固定轨道、内容自适应轨道和比例轨道共同分配有限空间；span、gap 与 margin 都参与同一尺寸账本。每轴最多 4096 条轨道，稠密放置账本最多 65,536 个单元格；没有可用位置的子项保留有限空结果，不重叠或无界扩容。

## UI 集成

`ui` 将求解结果用于 View 树测量、子项位置与事件几何。布局与重绘失效由字段语义区分；自定义 payload 缺少更细分类时保守请求布局与重绘。框架不依靠具体组件的视觉名称推断更新类型。

详细不变量见 [layout 架构](../../架构/ui/layout.md)，坐标与约束值见 [几何](../../架构/core/geometry.md)。
