# 样式与主题

[← 返回使用索引](../../使用.md)

> **接口**：声明 UIX 样式系统与主题管理的公开用法——语义样式、细粒度样式链、色板体系、主题切换和自定义主题。依赖：[响应式基础](../入门/响应式基础.md)。导出：设计令牌架构 → [架构 · 绘制几何](../../架构/graphics/geometry.md)，主题与配置 → [架构 · 主题](../../架构/ui/theme.md)。

## 语义样式

业务代码优先选择 primary、success、warning、danger、muted 等语义值，而不是硬编码颜色。组件状态从主题的组件令牌派生，默认、hover、pressed、focus、disabled 与 error 必须保持可辨识。

```rust uix-compile=style-semantic
use uix::prelude::*;

label("主要文字").color(ColorValue::Neutral(NeutralRole::Text));
button("保存").primary();
button("危险").danger();
Tag::new("成功").color(TagColor::Success);
```

## 细粒度样式

尺寸、间距、边框、圆角、字体与背景可由 View 样式链覆盖。局部覆盖只作用于当前节点或显式子树 Provider，不反向修改全局主题。

```rust uix-compile=style-chain
use uix::prelude::*;

column((label("卡片"),))
    .bg(ColorValue::Neutral(NeutralRole::BgContainer))
    .border(1.0, ColorValue::Neutral(NeutralRole::BorderSecondary))
    .radius(8.0)
    .box_shadow(Some(
        BoxShadowDef::new(Color::from_rgba(0, 0, 0, 40), 8.0, 0.0, 2.0)
            .with_spread(1.0),
    ))
    .padding(16.0)
    .gap(8.0);
```

`BoxShadowDef::new(color, blur, offset_x, offset_y)` 保持零 spread；需要扩张或内缩阴影基准盒时追加 `.with_spread(value)`。正值向外扩张，负值向内收缩；内缩耗尽宽度或高度时不绘制阴影。UIX Lang 使用 `boxShadow: h-offset v-offset blur [spread] color` 的等价语法。

## 色板与设计令牌

主题拥有颜色、排版、间距、圆角、阴影、动效与组件默认值；graphics 只消费解析后的绘制值，不反向拥有 UI 语义令牌。令牌类型位于 `uix::ui::theme`（`Theme`、`DesignTokens`、`TokenPatch`、`ThemeTokens` trait 族），`draw` 层不暴露主题类型。

## ThemeToggle 主题切换按钮

```rust uix-compile=theme-toggle
use uix::prelude::*;

// 声明式切换按钮：ThemeToggle 内置亮色/暗色切换
embed(ThemeToggle::new().dark(is_dark));

// 应用级切换：AppHandle 设置全局主题
let handle = ...;
handle.set_theme(Theme::antd_dark());
```

`ThemeToggle` 切换亮色/暗色主题，实际主题状态由 Provider/应用配置持有。切换后重算受影响子树并请求必要帧，不由业务代码手工遍历组件。`AppHandle::set_theme(theme)` 是跨窗口广播的权威入口（`palette-only` 只重绘使用语义色的节点）。

## 自定义主题

自定义主题以完整基础主题加窄覆盖构建。项目测试只从公开主题 API 的外部消费者观察对比度、焦点可见性、禁用态和错误态，不测试主题内部实现。

```rust uix-compile=theme-custom
use uix::prelude::*;

// 组件令牌窄覆盖：在 ConfigProvider 子树内对 Button 调整主色与圆角
embed(ConfigProvider::new()
    .widget_tokens::<Button>(TokenPatch {
        color_primary: Some(Color::hex("#722ed1")),
        border_radius: Some(10.0),
        ..TokenPatch::default()
    })
    .child(|| button("紫色按钮").primary())
    .build());
```

保留语义令牌、子树继承、状态完整性和公开 API 测试边界。

## 推荐用法

```rust uix-compile=theme-custom-app
use uix::prelude::*;

// 自定义主题：从基色生成 DesignTokens，再注入 App
let theme = Theme::new(DesignTokens::from_primitives(ThemePrimitives {
    primary: Color::hex("#722ed1"),
    ..ThemePrimitives::antd_light()
}, false));

App::new()
    .theme(theme)
    .follow_system_theme(true)   // 系统明暗变化自动跟随
    .root(app_root)
    .run();

// 组件侧：颜色一律来自令牌，不写死
render => (&self, frame: Rect, ctx: &mut PaintContext) {
    ctx.fill_rect(frame, ctx.tokens().color_primary_bg(), None);
}
```

```rust uix-compile=theme-custom-seed
// 通过 PrimaryHue 声明式切换品牌色种子，主题自动生成色板。
App::new()
    .theme(Theme::custom(
        ThemePrimitives::antd_light().with_brand_primary(PrimaryHue::Purple),
    ))
    .follow_system_theme(true)
    .root(app_root)
    .run();
```

- 业务代码只写语义值，主题负责具体外观；换肤不修改业务组件。
- 自定义主题用窄覆盖构建，不整套复制。
- 主题切换后只重绘受影响的语义色节点，不做全量重绘。
