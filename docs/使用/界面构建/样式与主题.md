# 样式与主题机制

[← 返回使用索引](../../使用.md)

`uix-app` 维护通用样式值、显式差异、交互状态解析与主题上下文。具体组件的配色预设、按钮外观和图标资源不属于本页范围。

## 样式值与显式差异

`Style` 保存布局和视觉值。需要表达“清除为零、false、none 或 auto”时使用 `StyleDiff` / `DeclaredStyleSet`；完整值的默认值推断不能替代显式声明。框架按声明顺序合并字段，并结合 default、hover、pressed、focus、disabled、error 等状态解析最终样式。

[样式规范](../../uix-lang/规范/样式与主题.md) 维护语言层叠加规则，[样式属性](../../uix-lang/参考/样式属性.md) 维护属性语法和映射。View 样式只修改指定节点；统一子树上下文通过 Provider 明确建立。

## 主题上下文

`Theme`、`ThemeTokens` 和 Provider 把语义令牌提供给 UI。绘制层消费解析后的颜色、尺寸与字体，不反向持有组件风格。框架的默认主题与通用样式能在没有组件库的情况下使用。

`AppHandle::set_theme` 由应用层发布主题变化；颜色与几何变化分别请求必要重绘和布局。组件库可以通过公开主题与应用扩展接口安装自己的预设，框架不内置特定组件的按钮样式。

## 文字度量

`fontSize` 是 logical 像素中的 em 尺度，不是字形墨迹高度。字体后端按 units-per-em 换算度量与栅格比例；回退字体保持同一 em 尺度。字形实际宽高仍由字体和内容决定。

显式行高用于测量和绘制；未指定时通用文本默认行盒为字号的 1.5 倍。相同字号与行高使用一致的行盒和基线规则，矩形居中不意味着不同字号共享 alphabetic baseline。字体选择与集合面索引由 [绘制](绘制.md#字体集合与系统回退) 维护。

## 几何与失效

宽高、内外边距、字体度量或布局约束变化会重新布局；纯颜色等视觉变化可只重绘。动态文本在父级最终分配的内容宽度内测量，不绕过有限约束。样式解析、测量、绘制、命中与语义 bounds 消费同一几何结果。

相关设计见 [主题架构](../../架构/ui/theme.md) 和 [布局机制](布局.md)。
