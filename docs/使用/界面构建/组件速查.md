# 框架接口速查

[← 返回使用索引](../../使用.md)

本页只列框架自身入口。具体按钮、输入、图表、表单等组件不属于 `uix-app` 的接口清单。

| 任务 | 框架入口 | 说明 |
| --- | --- | --- |
| 状态与派生值 | `State`、`Computed`、`Effect` | [响应式基础](../入门/响应式基础.md) |
| 声明与自定义内核 | `View`、`ViewNode`、`widget!` | [自定义 View](组件.md) |
| 有限几何与排布 | `Constraints`、`FlexLayout`、`LayoutEngine` | [布局](布局.md) |
| 自定义绘制与像素输入 | `canvas`、`PaintContext`、`FrameImage` | [绘制](绘制.md) |
| 样式与主题上下文 | `Style`、`StyleDiff`、`Theme` | [样式与主题](样式与主题.md) |
| 窗口应用 | `App`、`AppHandle`、`DiContainer` | [应用架构](../../架构/app/application.md) |
| UIX 语言与工具 | `lang::build::Builder`、`CompilerSystem`、`uix` | [语言入口](../../uix-lang/README.md) |

精确编译能力见 [框架能力拆分](../../架构/框架能力拆分.md)。
