# 自定义 View 与控件内核

[← 返回使用索引](../../使用.md)

本页维护 `uix-app` 的 `View`、`ViewNode` 与 `widget!` 自定义实现入口。启用 `ui` 即可构建无窗口视图；需要窗口应用时启用 `application` 和目标图形后端。

## 自定义 View

`View::build(self)` 返回声明式 `ViewNode`。业务状态由调用方持有，视图读取状态并登记回调；持久实例、布局和事件路由由框架维护。

## `widget!`

需要私有状态、精细事件、动画或资源租约时使用完整组件。组件在挂载时登记资源，在更新时保留稳定身份，在卸载时取消任务、事件捕获、动画与订阅。

```rust uix-compile=widget-full
use uix_app::prelude::*;

widget! {
    pub struct Counter { pub count: u32 }
    @new -> Self { Self { count: 0 } }

    measure => (&self, constraints: Constraints) -> Size {
        constraints.clamp(Size::new(120.0, 36.0))
    }

    on_event => (&mut self, event: &SystemEvent) -> EventResult {
        match event {
            SystemEvent::PointerDown { .. } => {
                self.count += 1;
                EventResult::Handled
            }
            _ => EventResult::NotHandled,
        }
    }

    render => (&self, frame: Rect, ctx: &mut PaintContext) {
        let bg = ctx.tokens().color_primary_bg();
        let color = ctx.tokens().color_primary();
        ctx.fill_rect(frame, bg, None);
        ctx.draw_text(
            &format!("Count: {}", self.count),
            Point::new(frame.x + 8.0, frame.y + 8.0),
            color,
            14.0,
        );
    }
}
```

`widget!` 支持 `@new` 构造与 `measure` / `on_event` / `render` / `dirty_rect` 等生命周期与能力方法；能力由框架按方法名自动登记（布局 / 渲染 / 事件 / 生命周期 / 动画）。

## 挂载与释放

组件值描述声明输入；订阅、事件回调、捕获、动画与异步结果必须绑定所属树和实例身份。卸载时释放相应租约，旧代际结果不再更新新实例。自定义内核只登记绘制意图，不创建第二套窗口或呈现循环。
