# 终端

[← 返回使用索引](../../使用.md)

> **接口**：声明 UIX 终端组件的公开用法——滚动输出缓冲、语义着色输出行、提示符输入行与命令历史，以及 Linux 上可运行真实交互式 shell 的 PTY 会话与 VT 屏幕组件。依赖：[数据展示](数据展示.md)（行模型与展示组件共性）、[响应式基础](../入门/响应式基础.md)、[定时与异步](../动画与异步/定时与异步.md)（会话唤醒）。导出：无。

## Terminal

终端组件是一个**命令行视图**：上部为可滚动、可虚拟化的输出缓冲区，底部为固定的提示符输入行。命令的执行、解释与回显全部属于应用域——组件只负责收集提交、维护输入草稿与历史，并在提交时通知应用。

前置条件：启用默认包含的 `terminal` capability。执行步骤：用输出行集合与提示符构造组件并注册命令回调。预期结果：应用获得一个可滚动、可输入的终端视图；每次回车提交后回调收到完整命令文本。

```rust uix-compile=terminal-basic
use uix::prelude::*;

embed(
    Terminal::new()
        .lines(vec![TerminalLine::text("UIX 控制台就绪")])
        .prompt("$ ")
        .on_command(|_command| {
            // 命令执行在应用域；组件不回显、不解释命令。
        }),
);
```

## 输出行与语义着色

一行输出是按声明顺序拼接的文本段集合（`TerminalLine`），每段可携带一个语义颜色（`TerminalColor`）。颜色只表达语义（成功、警告、错误、信息、主色、弱化），具体色值由主题 token 解析，不在公开 API 中出现。

```rust uix-compile=terminal-styled
use uix::prelude::*;

embed(
    Terminal::new().lines(vec![
        TerminalLine::new()
            .push("[build] ")
            .styled("done", TerminalColor::Success)
            .push(" in 1.2s"),
        TerminalLine::new()
            .styled("warning:", TerminalColor::Warning)
            .push(" 未指定输出目录"),
        TerminalLine::new()
            .styled("error:", TerminalColor::Error)
            .push(" 清单缺失，构建终止"),
    ]),
);
```

- `TerminalLine::plain()` 返回拼接全部文本段后的纯文本，语义快照与无障碍摘要使用同一份文本。
- 行与文本段都是拥有型值：应用每帧重建或经运行时方法替换输出缓冲，组件不持有应用回调之外的输出权威。

## 命令提交与历史

输入行支持完整的字符级编辑：方向键移动光标、`Home`/`End` 跳转行首行尾、`Backspace`/`Delete` 删除、粘贴在光标处插入；控制字符被拒绝。`↑`/`↓` 在已提交命令的历史中漫游（最近 100 条，超出丢弃最旧），`Escape` 清空草稿。

回车提交当前草稿；**空命令不提交**，也不产生事件。提交后组件依次：清空草稿并入历史、调用 `on_command` 回调、发出 `submit` 语义事件（载荷即命令文本）。

```rust uix-compile=terminal-command
use uix::prelude::*;

// 运行期方法直接替换提示符与输出缓冲；历史与草稿属于组件运行态。
let mut console = Terminal::new().prompt("$ ");
console.set_prompt("# ");
console.set_lines(vec![TerminalLine::text("缓冲已重建")]);
let _ = console.history(); // 已提交命令按顺序保存
```

## 滚动与跟随

输出缓冲默认**跟随底部**：应用追加输出后视图自动停留在最新行。用户向上滚动后立即停止跟随，回到底部后恢复跟随。滚动经虚拟化只物化可见行，输出行数不改变组件的内在尺寸。

默认尺寸为 420×280；可通过 Rust View 的 `width`、`height`、`flex_grow`、`flex_shrink`、`margin` 与 `align_self` 调整布局，UIX 标签对应 `width`、`height`、`flexGrow`、`flexShrink`、`margin` 与 `alignSelf` 公共属性。尺寸更新保留草稿、历史及跟随状态。只替换输出文字、颜色或文本段时重绘终端，不改变组件固有尺寸；空文本段会被跳过，后续文本继续显示。

## 声明式用法

uix-lang 已登记 `<Terminal>` 标签：`data` 必须是可迭代 `TerminalLine` 的 Rust 表达式，`prompt` 接受字符串；组件是叶节点，不接受子树。属性映射与生成契约见 [uix-lang · 展示组件](../../uix-lang/参考/组件/展示组件.md#terminal-终端)。

## 可见失败与适用限制

- 命令终端 `Terminal` **不是终端模拟器**：不创建 PTY、不执行命令、不解析 ANSI 转义序列；把命令文本落成输出行是应用的责任。真实交互式 shell 见下文[真实会话](#真实会话terminalsession-与-terminalscreen)。
- 输出缓冲由应用拥有，组件不做上限裁剪；长期会话必须由应用自行截断历史输出。
- 空命令回车不产生回调与语义事件；需要"回车即回显空行"的应用应在自己的输入处理中补齐。
- 提交回调在 UI 线程同步执行，回调内不得做阻塞 IO；长命令应转交异步任务（见[定时与异步](../动画与异步/定时与异步.md)）。
- 关闭 `terminal` capability 后，组件、行模型与 prelude 导出一并消失，声明式 `<Terminal>` 在编译期被拒绝。

## 真实会话：TerminalSession 与 TerminalScreen

真实终端由三个职责组成，互相不越界：

- **会话**（`TerminalSession`）：唯一拥有子进程、PTY 文件描述符与生命周期。只能经 `TerminalSession::spawn` 显式创建——**视图构建与 reconcile 不会隐式创建进程**；所有克隆 drop 后自动完成 fd 关闭、SIGHUP、读线程 join 与子进程回收（`waitpid`）。
- **终端状态**（VT 屏幕网格）：会话内部经 vte 状态机把字节流解析为行列网格；跨读取边界的 UTF-8 由解析器内部缓冲处理。应用经 `rows()`（`TerminalRow` 着色段快照）、`cursor()`、`screen_size()` 读取投影。
- **UI 展示**（`TerminalScreen` 组件）：把网格按列绘制并转发原始按键；**没有本地输入行、草稿与历史**——回显与编辑全部由 PTY 中的程序完成，不会重复回显。

前置条件：Linux 平台且启用默认包含的 `terminal` capability；其他平台 `spawn` 返回 `NotImplemented` 类型化失败。执行步骤：显式 spawn（提供输出唤醒回调）→ 在回调回到 UI 线程后调用 `pump()` 消费输出 → 用 `TerminalScreen::new(&session)` 投影。预期结果：一个可输入、可滚出彩色与中文输出的真实 shell 视图。

```rust uix-compile=terminal-live-session
use uix::prelude::*;

// 显式启动交互式 shell；读取线程经 post_to_ui 唤醒应用侧 pump。
fn spawn_session(handle: &AppHandle) -> Result<TerminalSession, uix::core::Error> {
    let wakeup = handle.clone();
    let mut config = TerminalSessionConfig::default();
    config.on_output = Some(std::sync::Arc::new(move || {
        wakeup.post_to_ui(|| {
            // 应用在 UI 线程调用 session.pump() 消费新输出。
        });
    }));
    TerminalSession::spawn(&config)
}

// 视图只投影已存在的会话；构建视图不创建进程。
fn live_view(session: &TerminalSession) -> ViewNode {
    embed(TerminalScreen::new(session))
}
```

### 读写、尺寸与退出

- 读取不阻塞 UI：专职读线程 poll PTY，字节进入共享缓冲（上限 8 MiB，超出丢弃最旧）并经 `on_output` 唤醒；应用在 UI 线程 `pump()` 消费。无事件循环的测试可直接轮询 `pump()`。
- 写入（`write`）非阻塞：键盘流量即时写入；PTY 缓冲满返回 `WouldBlock`（输入被丢弃），会话退出后返回 `InvalidOperation`。
- 网格尺寸：组件按帧尺寸换算列行并自动 `resize()`（TIOCSWINSZ + SIGWINCH）；应用也可以显式调用。初始列行由配置给出，子进程首屏 `stty size` 即正确。
- 退出：子进程退出后读线程观察到 EOF 并收割退出码，`pump()` 把 `status()` 更新为 `Exited { code }`（被信号终止时 `code` 为 `None`）；组件在网格上方叠加一条退出状态带。`exit` 后继续输入只会得到 `InvalidOperation`。

```rust uix-compile=terminal-live-query
use uix::prelude::*;

fn inspect_and_drive(session: &TerminalSession) -> Result<(), uix::core::Error> {
    // 按键字节与文本直接写入 PTY。
    session.write(b"ls --color=auto\r")?;
    // 显式同步窗口网格尺寸。
    session.resize(100, 30)?;
    // 屏幕投影：行快照、光标与网格尺寸。
    let rows: Vec<String> = session.rows().iter().map(TerminalRow::plain).collect();
    let (row, column) = session.cursor();
    let (cols, lines) = session.screen_size();
    let running = matches!(session.status(), TerminalSessionStatus::Running);
    let _ = (rows, row, column, cols, lines, running);
    Ok(())
}
```

### 按键与输入

`TerminalScreen` 获得焦点后把按键编码转发给 PTY：Enter→`\r`、Backspace→`\x7f`、Tab→`\t`（焦点在终端上时 Tab 是子进程输入，不做应用焦点导航）、方向/Home/End/PageUp/PageDown/Insert/Delete/F1-F12→标准 xterm 转义序列、Ctrl+字母/数字→控制字节（Ctrl+C 即 `\x03` 中断、Ctrl+D 即 `\x04`）、Alt 前缀用 ESC 表达、Shift+Tab 为 `\x1b[Z`。可打印字符（含中文与标点）经文本输入事件按 UTF-8 原样写入；控制组合后平台附带的文本会被抑制。粘贴作为普通文本写入，不包裹 bracketed paste 标记。

### 支持的控制序列与限制

VT 屏幕支持：打印与自动换行（DECAWM）、CR/LF/BS/TAB、光标定位与移动（CUP/HVP、CUU/CUD/CUF/CUB、CHA、VPA、DECSC/DECRC、RI/IND/NEL）、擦除（ED、EL、ECH）、编辑（DCH、ICH、IL、DL）、滚动（SU、SD）、RIS 与 SGR 颜色（0/1/7/22/27、基础 16 色、90-107 亮色、38/48 的 256 色与直接色）。未实现的序列被吞掉并计入 `session.ignored_sequences()`。

明确不支持（本轮边界）：

- **交替屏与全屏程序**（1049 等）：Vim、top、less 等全屏终端程序依赖的交替屏缓冲未实现，显示会错乱。
- **滚动区域**（DECSTBM）与滚回缓冲：屏幕只有当前网格，没有 scrollback 历史与滚轮回看。
- **字符级组合序列**（零宽组合字符）按丢弃处理；制表按 8 列停靠。
- 网格按主字体测量列宽（非等宽字体下字符间可能留白或轻微重叠）；东亚宽字符占两列。
- 内核行规程的列计数与 VT 宽字符列存在固有偏差，长中文行末尾的 tab 停靠可能偏移数列。
- OSC（标题）、鼠标上报、bracketed paste、焦点上报等扩展模式被忽略。
