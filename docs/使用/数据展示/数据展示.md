# 数据展示

[← 返回使用索引](../../使用.md)

> **接口**：声明 UIX 数据展示组件的公开用法——Label、Table、Tree、RichText、Typography 等展示组件。依赖：[响应式基础](../入门/响应式基础.md)、[布局](../界面构建/布局.md)。导出：Table/Tree 架构 → [架构 · 组件系统](../../架构/ui/widget_runtime.md)。

## Label

短文本与多行文本的基础入口；可选择文本时必须保留键盘路径和语义名称。

```rust uix-compile=data-label
use uix_app::prelude::*;

label("短文本").font_size(14.0);
// 由 Label 的统一样式持有经过校验的行高倍率。
embed(Label::new("多行文本\n第二行").style(Style::default().with_line_height(LineHeight::factor(1.5).expect("行高倍率必须为正值"))));
```

## Avatar

头像支持图片、文字回退与方形裁剪；图片失败时回退内容仍需保持可读名称。

```rust uix-compile=data-avatar
use uix_app::prelude::*;

embed(Avatar::new("AL").size(40.0));
embed(Avatar::new("图片用户")
    .src("assets/")
    .square(true));
```

## Badge

徽标可显示计数、状态点或短文本，也可通过唯一 `child` 成为透明装饰器。零子节点保持独立叶行为；单子节点决定正常流尺寸，角标覆盖其右上角而不扩大布局，命中、焦点与状态仍由真实子 View 拥有。状态不能只靠颜色表达，超限计数使用明确上限表示。

```rust uix-compile=data-badge
use uix_app::prelude::*;

embed(Badge::new().count(5).color(BadgeColor::Red));
embed(Badge::new().count(120).max(99));  // 超限显示 "99+"
embed(Badge::new().count(5).child(button("通知"))); // 装饰真实按钮且不接管 Click
```

## Calendar / Carousel

Calendar 的选择值与当前显示月份分离；Carousel 的当前页用稳定索引/键维护，单页或隐藏控制器时不得残留不可达操作。

```rust uix-compile=calendar-basic
use uix_app::prelude::*;

embed(Calendar::new()
    .cell_size(22.0)
    .default_date(Date::new(2026, 7, 31)));
```

`default_date` 只设置非受控初值；需要由业务状态拥有选中日期时使用 `value(&State<Date>)`。用户提交会先回写状态，再发出载荷为 `yyyy-mm-dd` 的统一 Change 事件；外部状态更新在下一轮声明协调时同步选中日期和显示月份。构造器按最后调用者决定所有权：`default_date` 会清除先前的受控绑定。

```rust uix-compile=calendar-controlled
use uix_app::prelude::*;

let selected = State::new(Date::new(2026, 8, 15));
embed(Calendar::new().value(&selected));
```

选中日期与显示月份是两个事实。`default_displayed` 可以在 `default_date` 或 `value` 之后覆盖初始显示月份；受控值没有变化的协调会保留用户导航月份，只有外部日期实际改变才重新定位。`year_jump`、`cell_size`、`events` 与 `disabled_date` 分别配置导航跨度、日期格首选尺寸、拥有型事件快照和不可选择日期策略。

```rust uix-compile=calendar-policy
use uix_app::prelude::*;

let selected = State::new(Date::new(2026, 8, 15));
let events = vec![CalendarEvent::new(
    Date::new(2026, 9, 3),
    "产品发布",
    Color::BLUE,
)];
embed(Calendar::new()
    .value(&selected)
    .default_displayed(2026, 9)
    .cell_size(36.0)
    .year_jump(true)
    .events(events)
    .disabled_date(|date| date.day == 1));
```

`date_cell` 接收 `Fn(Date, CalendarCellInfo) -> View`，每次为一个当月日期返回真实 View。Calendar 仍是日期格子树的唯一运行时所有者：它用日期稳定 key 隔离组件私有状态，负责物化、布局、裁剪、协调和释放；工厂只读取拥有型 `Date` 与只读 `CalendarCellInfo`，不取得 Calendar 或 WidgetTree。

```rust uix-compile=calendar-date-cell
// 引入 Calendar、日期上下文与 View 公开契约。
use uix_app::prelude::*;

// 为一个日期构造自定义日期格 View。
fn calendar_date_cell(date: Date, info: CalendarCellInfo) -> ViewNode {
    // 根据只读上下文选择稳定状态标记。
    let marker = if info.is_selected { "●" } else if info.is_today { "今" } else { "" };
    // 返回由 Calendar 运行时拥有的真实 Label 子树。
    ViewNode::leaf(Label::new(format!("{marker}{}", date.day)))
}

// 把类型化工厂交给 Calendar 的公开扩展入口。
embed(Calendar::new().date_cell(calendar_date_cell));
```

图片组件明确加载、成功、失败与 fallback 状态；alt/语义名称不依赖图片是否成功解码。

## List / Tree

列表和树使用稳定业务 key，选择、展开、焦点与虚拟化状态不能绑定当前可见索引。Tree 同时保留层级、父子关系和键盘漫游语义。

List 的 `header_view`、`footer_view` 与 `load_more_view` 接收真实 View 子树。三个角色使用固定身份参与正常流布局和 reconcile，按钮等子 View 保留自己的事件、焦点与状态；原有 `header`、`footer`、`load_more` 文本构建器继续兼容。数据为空时，配置的 Empty 仍替换整个 List，不挂载这些插槽。

```rust uix-compile=data-list-slots
use uix_app::prelude::*;

embed(List::new()
    .items(vec!["待处理", "已完成"])
    .header_view(label("任务"))
    .footer_view(label("共 2 项"))
    .load_more_view(button("加载更多").on_click_fn(|| {})));
```

```rust uix-compile=data-tree
use uix_app::prelude::*;

embed(
    Tree::new(vec![
        TreeNode::new("root", "root").children(vec![
            TreeNode::new("child-a", "a"),
            TreeNode::new("child-b", "b"),
        ]),
    ])
    .checkable(true)
    .default_expand_all(true),
);
```

```rust uix-compile=tree-basic
use uix_app::prelude::*;

// 树基础：稳定 key + 层级父子关系
embed(Tree::new(vec![
    TreeNode::new("部门", "dept")
        .children(vec![TreeNode::new("成员", "member")]),
]));
```

## Table

表格列定义、行 key、排序/筛选状态和选择状态彼此分离。大数据集通过虚拟化限制物化范围；键盘焦点不能因行回收丢失业务身份。

```rust uix-compile=data-table-pagination
use uix_app::prelude::*;

embed(Table::new()
    .columns(vec![TableColumn::new("姓名", 200.0)])
    .rows(rows)
    .pagination(TablePagination {
        current: 1,
        total: 100,
        page_size: 10,
        on_change: |_page| {},
    })
    .build());
```

```rust uix-compile=data-table-row-click
use uix_app::prelude::*;

embed(Table::new()
    .columns(vec![TableColumn::new("姓名", 200.0)])
    .rows(rows)
    .on_row_click(|_row, _row_index| {
        // 行点击：同一行匹配释放（回调接收行数据与行索引）
    })
    .build());
```

```rust uix-compile=data-table-span
use uix_app::prelude::*;

// 合并单元格：行跨度由业务函数决定
embed(Table::new()
    .columns(vec![
        TableColumn::new("类别", 120.0).row_span(|row, _col| {
            if row[0] == "合并" { 2 } else { 1 }
        }),
        TableColumn::new("数值", 120.0),
    ])
    .rows(rows)
    .build());
```

`col_span` 按逻辑列声明确定覆盖关系，但绘制会使用每个覆盖列在当前视口中的真实物理位置。即使右固定锚点先声明、后续覆盖列固定在视觉左侧，普通文本合并单元格仍按 Middle → Left → Right 分片绘制完整联合范围，任一覆盖列的命中都会回落到同一锚点。自定义 View 单元格也只建立一个有状态子树并按完整联合矩形布局一次；布局阶段会记录 Middle、Left、Right 各区最终仍可见的片段，合成器在这些片段内重放同一子树，命中与指针捕获同样只接受实际片段，因此片段间隙不会误绘制或误命中。

## Transfer

穿梭框分别维护源列表、目标列表、搜索和受控选择；移动后以最新业务 key 快照重建两侧可见项。`searchable` 开启输入过滤，`render_item` 提供自定义行 View，`on_change` 在真实迁移后收到最新两侧列表与方向。

```rust uix-compile=data-transfer-advanced
// 引入穿梭框公开入口。
use uix_app::prelude::*;

// 声明源列表、目标列表并开启搜索。
let transfer = Transfer::new().source(vec![TransferItem::new("draft", "草稿")]).target(vec![TransferItem::new("published", "已发布")]).searchable(true);
// 自定义每一行的 View，并在迁移完成后接收最新列表。
let transfer = transfer.render_item(|item| label(item.title.clone())).on_change(|_source, _target, _direction| {});
// 将组件嵌入声明式 View 树。
embed(transfer);
```

## Watermark

水印在组件 frame 内平铺旋转文字；`font_size`、`opacity`、`rotate`、`gap` 与 `offset` 只改变绘制配置，不抢占内容布局和交互空间。

```rust uix-compile=data-watermark-advanced
// 引入水印公开入口。
use uix_app::prelude::*;

// 在内容区域上叠加低透明度、旋转并按间距平铺的水印。
embed(Watermark::new("内部资料").font_size(16.0).opacity(0.12).rotate(-20.0).gap(220.0, 160.0));
```

## 推荐用法

```rust uix-compile=data-table-model
use uix_app::prelude::*;

// 类型化行数据：稳定行 key + 列投影
#[derive(Clone, PartialEq)]
struct UserRow { id: u64, name: String, email: String }

let rows = vec![
    UserRow { id: 1, name: "Ada".into(), email: "ada@example.com".into() },
];

// Table::data 返回 Result：重复 row key 会给出 typed 错误，先解包再装配列
embed(Table::data(rows.clone(), |row| row.id.to_string())
    .expect("row key 必须唯一")
    .columns(vec![
        TableColumn::new("ID", 80.0).bind(|r: &UserRow| r.id.to_string()),
        TableColumn::new("姓名", 200.0).bind(|r: &UserRow| r.name.clone()),
        TableColumn::new("邮箱", 260.0).bind(|r: &UserRow| r.email.clone()),
    ])
    .build());
```

- 行身份（`Table::data` 的 row key）、列定义、排序/筛选/选择状态彼此分离，不互相耦合。
- `.bind(...).render(...)` 单元格的根节点身份与动态私有状态由框架按唯一 row key 和声明时逻辑列共同拥有；renderer 不得自行设置根 key。行排序或行重排后同一业务单元格复用状态，离开物化范围后按节点卸载生命周期释放。
- 展示组件只消费数据快照；大数据集通过 `.virtualized(true)` 限制物化范围（等价 `virtual_scroll`），`false` 时全量物化。
- 图标与颜色不做唯一语义载体，文字语义始终存在。

```rust uix-compile=data-table-virtualized
// 列渲染任意 View，并显式启用虚拟化。
embed(Table::data(rows.clone(), |row| row.id.to_string())
    .expect("row key 必须唯一")
    .columns(vec![
        TableColumn::new("状态", 120.0)
            .bind(|r: &UserRow| r.email.clone())
            .render(|r| embed(Tag::new(&r.name).color(TagColor::Success))),
    ])
    .virtualized(true)   // 大数据集只物化可视区
    .build());
```
