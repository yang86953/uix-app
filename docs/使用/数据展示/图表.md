# 图表

[← 返回使用索引](../../使用.md)

> **接口**：声明 UIX 图表组件的公开用法——基础与高级图表、响应式尺寸和交互配置。依赖：[响应式基础](../入门/响应式基础.md)、[布局](../界面构建/布局.md)。导出：无。（终端使用文档）

图表组件支持静态展示和动态数据。数据通过 `State` 驱动时，修改 State 后框架自动重绘图表：

```rust uix-compile=dynamic-chart
let data = State::new(vec![
    BarData::new("Q1", 120.0, Color::hex("#1677ff")),
    BarData::new("Q2", 200.0, Color::hex("#52c41a")),
]);

// 在 App::root 中绑定
BarChart::new()
    .data(data.get())
    .width(400.0)
    .height(300.0);

// 业务代码中更新数据
data.update(|d| d.push(BarData::new("Q3", 150.0, Color::hex("#faad14"))));
```

所有图表默认使用 `DATA_VISUALIZATION_PALETTE`（10 色分类色板）自动分配颜色；显式传入 `Color` 可覆盖单条数据。图表以 `Image` 角色进入无障碍树，并用各数据项的 label / value 提供结构化值文本。最终测量服从父级 `Constraints`，非法宽高回到自动尺寸。

## 柱状图

```rust uix-compile=bar-chart
BarChart::new()
    .data(vec![
        BarData::new("Q1", 120.0, Color::hex("#1677ff")),
        BarData::new("Q2", 200.0, Color::hex("#52c41a")),
        BarData::new("Q3", 150.0, Color::hex("#faad14")),
    ])
    .width(400.0)
    .height(300.0);
```

`BarChart` 以零线同时承载正值与负值；显式 `max_value(...)` 作为正向轴上限，超出部分裁在绘图区内。数据中的非有限值按 0 绘制。

### 分组与堆叠

```rust uix-compile=chart-bar-advanced
// 分组柱状图——多系列并排
BarChart::new()
    .grouped(true)
    .series(vec![
        ChartSeries::new("2024", vec![
            BarData::new("Q1", 100.0, Color::BLUE),
            BarData::new("Q2", 130.0, Color::BLUE),
        ]),
        ChartSeries::new("2025", vec![
            BarData::new("Q1", 120.0, Color::GREEN),
            BarData::new("Q2", 160.0, Color::GREEN),
        ]),
    ])
    .width(500.0)
    .height(300.0);

// 堆叠柱状图——多系列上下堆叠
BarChart::new()
    .stacked(true)
    .series(vec![
        ChartSeries::new("收入", vec![BarData::new("Q1", 100.0, Color::BLUE)]),
        ChartSeries::new("成本", vec![BarData::new("Q1", 40.0, Color::RED)]),
    ]);

// 横向柱状图
BarChart::new()
    .horizontal(true)
    .data(vec![BarData::new("长标签", 80.0, Color::BLUE)])
    .height(400.0);  // 横向时 height 决定条形总空间
```

- **分组**：`.grouped(true)` + `.series(...)` — 每组类别并排显示多根柱子
- **堆叠**：`.stacked(true)` + `.series(...)` — 同类别柱子上下堆叠；tooltip 显示各项和总量
- **横向**：`.horizontal(true)` — 适合长标签场景；类别标签在 Y 轴左侧
- **间距**：`.bar_gap(0.2)` — 组内柱子间距占柱宽比例；`.category_gap(0.3)` — 组间间距

## 折线图

```rust uix-compile=line-chart
LineChart::new()
    .data(vec![
        LineData::new("Jan", 100.0),
        LineData::new("Feb", 150.0),
        LineData::new("Mar", 130.0),
    ])
    .width(400.0)
    .height(300.0)
    .dot_radius(4.0);
```

`LineChart` 会绘制单个数据点而不是把单点序列当成空图；`auto_min(true)` 使用数据下界，默认下界为 0，`max_value(...)` 可固定上界。非有限数据按 0 映射，`line_width(...)` / `dot_radius(...)` 会规范化非法几何值。

### 多系列、面积与平滑

```rust uix-compile=chart-line-advanced
// 多条折线
let cpu_data = vec![LineData::new("Jan", 40.0), LineData::new("Feb", 60.0)];
let mem_data = vec![LineData::new("Jan", 30.0), LineData::new("Feb", 50.0)];
LineChart::new()
    .series(vec![
        ChartSeries::new("CPU", cpu_data.clone()),
        ChartSeries::new("内存", mem_data),
    ])
    .width(500.0)
    .height(300.0)
    .legend(LegendPosition::Top);

// 面积图——折线下方填充颜色
AreaChart::new()
    .data(vec![LineData::new("Jan", 100.0)])
    .fill_opacity(0.3)
    .width(400.0)
    .height(300.0);

// 堆叠面积图
AreaChart::new()
    .series(vec![ChartSeries::new("A", vec![LineData::new("Jan", 1.0)])])
    .stacked(true);

// 平滑曲线
LineChart::new()
    .data(vec![LineData::new("S1", 1.0), LineData::new("S2", 2.0)])
    .smooth(true)          // 使用 Catmull-Rom 样条代替直线段
    .dot_radius(0.0);      // 隐藏数据点，只显示曲线
```

- **多系列**：`.series(...)` 包含多条折线，自动按色板分配颜色
- **面积图**：`AreaChart` 将折线下方填充半透明色；支持 `.stacked(true)` 堆叠
- **平滑**：`.smooth(true)` 使用三次样条插值，适合连续数据如传感器、温度曲线
- **阶梯线**：`.step(true)` — 阶梯式连接（先横后纵 / 先纵后横），用于变化事件数据

## 饼图 / 环形图

```rust uix-compile=pie-chart
PieChart::new()
    .data(vec![
        PieData::new("产品A", 40.0, Color::hex("#1677ff")),
        PieData::new("产品B", 30.0, Color::hex("#52c41a")),
        PieData::new("产品C", 30.0, Color::hex("#faad14")),
    ])
    .size(300.0)
    .donut(0.55);
```

`PieChart` 只把有限正值计入扇区和总量，零值、负值及非有限值不会生成非法角度；有空间时会在右侧绘制 label / 百分比图例。`donut(...)` 接受 0～0.9 的半径比例。

```rust uix-compile=chart-pie-advanced
// 玫瑰图（南丁格尔图）——扇区半径与数值成正比
PieChart::new()
    .data(vec![PieData::new("A", 40.0, Color::BLUE)])
    .rose(true)
    .rose_style(RoseStyle::Radius);  // 或 RoseStyle::Area

// 半圆环——仪表盘风格
PieChart::new()
    .data(vec![PieData::new("完成", 68.0, Color::GREEN)])
    .size(200.0)
    .donut(0.7)
    .start_angle(180.0)     // 从左半弧开始
    .total(360.0);           // 只画 180° 半圆
```

- **玫瑰图**：`.rose(true)` — 每个扇区半径/面积与数值成正比，而非角度
- **角度控制**：`.start_angle(deg)` / `.end_angle(deg)` 支持任意圆弧（默认 0°→360°）
- **标签**：`.label_visible(true)` / `.label_position(LabelPosition::Outside)` 控制标签位置

## 散点图 / 气泡图

```rust uix-compile=chart-scatter
// 散点图——双变量分布
ScatterChart::new()
    .data(vec![
        ScatterData::new("A", 2.5, 6.3),
        ScatterData::new("B", 3.1, 5.8),
    ])
    .x_axis("宽度 (cm)")
    .y_axis("高度 (cm)")
    .width(400.0)
    .height(300.0);

// 多系列散点
let male_data = vec![ScatterData::new("A", 1.0, 2.0)];
let mem_data = vec![ScatterData::new("B", 2.0, 3.0)];
ScatterChart::new()
    .series(vec![
        ChartSeries::new("雄性", male_data),
        ChartSeries::new("雌性", mem_data),
    ])
    .legend(LegendPosition::Bottom);

// 气泡图——第三个维度用气泡大小表示
ScatterChart::new()
    .data(vec![
        BubbleData::new("中国", 1.4, 12.0, 80.0),   // (x, y, 气泡大小)
        BubbleData::new("美国", 0.33, 21.0, 50.0),

```

- **轴标签**：`.x_axis(label)` / `.y_axis(label)` 设置轴标题
- **气泡**：`BubbleData { label, x, y, size }` — 第四个字段控制气泡半径
- **点样式**：`.point_size(6.0)` / `.point_style(PointStyle::Circle | Diamond | Cross)`

## 雷达图

```rust uix-compile=chart-radar
// 雷达图——多维对比
RadarChart::new()
    .axes(vec![
        RadarAxis::new("速度", 0.0..=100.0),
        RadarAxis::new("力量", 0.0..=100.0),
        RadarAxis::new("耐力", 0.0..=100.0),
        RadarAxis::new("技巧", 0.0..=100.0),
        RadarAxis::new("协作", 0.0..=100.0),
    ])
    .series(vec![
        ChartSeries::new("选手A", vec![RadarData::new(85.0), RadarData::new(70.0), RadarData::new(90.0), RadarData::new(60.0), RadarData::new(75.0)]),
        ChartSeries::new("选手B", vec![RadarData::new(65.0), RadarData::new(85.0), RadarData::new(60.0), RadarData::new(80.0), RadarData::new(70.0)]),

// 圆形雷达
```

## 热力图

```rust uix-compile=chart-heatmap
// 热力图——矩阵颜色映射
Heatmap::new()
    .x_labels(vec!["周一", "周二", "周三", "周四", "周五"])
    .y_labels(vec!["0点", "6点", "12点", "18点"])
    .data(vec![
        HeatmapCell::new(0, 0, 12.0),  // (x索引, y索引, 值)
```

## 图表通用配置

所有图表组件共享以下配置方法：

| 方法 | 说明 |
|------|------|
| `.width(f32)` / `.height(f32)` | 固定宽高；未设置时由父布局约束 |
| `.bg(Color)` | 图表背景色 |
| `.padding(f32)` | 图表内边距（绘图区与边框间距） |
| `.legend(LegendPosition)` | 图例位置：`Top` / `Bottom` / `Left` / `Right` / `None` |
| `.tooltip(TooltipConfig)` | Tooltip 配置：触发方式、格式模板、自定义渲染 |
| `.title("标题")` / `.subtitle("副标题")` | 图表标题 |
| `.animation(AnimationConfig)` | 首次渲染动画：时长、缓动、 stagger |

### 响应式与交互

```rust uix-compile=chart-common
// 响应式图表——跟随容器尺寸自动调整
let revenue = vec![BarData::new("Jan", 100.0, Color::BLUE)];
BarChart::new()
    .data(revenue)
    .responsive(true);

// 图表交互：点击数据项、缩放
let timeseries = vec![LineData::new("Jan", 100.0)];
LineChart::new()
    .data(timeseries)
    .interactive(InteractionConfig {
        zoom: true,                     // 滚轮缩放 X 轴
        pan: true,                      // 拖拽平移
        crosshair: true,                // 十字准线
        on_click: Some(|_item| {}),
    })
    .brush(BrushConfig {                // 刷选区域
        enabled: true,
        on_select: Some(|_range| {}),
    });
```

- **响应式**：`.responsive(true)` — 每个有界轴继承父容器并在 resize 时自动重绘；ScrollView 的未约束轴保留图表声明尺寸
- **缩放**：`.interactive(InteractionConfig { zoom: true, .. })` — 鼠标滚轮缩放时间轴
- **刷选**：`.brush(...)` — 在图表上拖拽选择区域，用于联动过滤或下钻
- **十字准线**：`.interactive(InteractionConfig { crosshair: true, .. })` — 跟随鼠标显示精确值线
- **空状态**：无数据时显示 `Empty` 组件，可通过 ConfigProvider 自定义

## 推荐用法

按产品定义（资源优先、Rust 优先）：

```rust uix-compile=chart-state-driven
use uix_app::prelude::*;

// 图表由 State 驱动，语义色来自主题令牌
let series = State::new(vec![BarData::new("Q1", 120.0, Color::BLUE)]);

series.map(|data| {
    embed(BarChart::new()
        .data(data.clone())
        .responsive(true))          // 跟随容器尺寸，不写死宽高
});
```

```rust uix-compile=chart-empty-state
use uix_app::prelude::*;

// 空态 / 加载态由数据状态决定，不单独维护
series.map_opt(|data| (!data.is_empty()).then(|| chart_view(data)));
```

- 图表数据用 `State` 驱动，修改后框架自动重绘，不手工请求重绘。
- 优先 `.responsive(true)` 让图表继承容器约束，避免写死尺寸。
- 颜色默认走 `DATA_VISUALIZATION_PALETTE`；需要语义时用主题令牌。
- 空状态 / 加载态是数据状态，不是图表配置。
