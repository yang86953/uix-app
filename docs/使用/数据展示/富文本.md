# 富文本

[← 返回使用索引](../../使用.md)

> **接口**：声明 UIX 富文本的公开用法——混合排版、链接、代码段、选择与复制。依赖：[数据展示](数据展示.md)。导出：无。（终端使用文档）

混合排版文本、超链接与代码段并自动折行；链接键盘导航始终可用，普通文字选择需通过 `selectable(true)` 显式开启，默认关闭。

## 基本用法

```rust uix-compile=rich-text-basic
RichText::new()
    .content(vec![
        RichTextSegment::Text {
            content: "查看 ".into(),
            style: RichTextStyle::default(),
        },
        RichTextSegment::Link {
            content: "使用指南".into(),
            url: "https://example.test/guide".into(),
        },
        RichTextSegment::NewLine,
        RichTextSegment::Code {
            content: "cargo run".into(),
        },
    ])
    // 显式开启普通文字选择；默认值为 false。
    .selectable(true)
    .font_size(14.0);
```

## 段类型（RichTextSegment）

| 段 | 说明 |
|---|------|
| `Text { content, style }` | 普通文本，带独立 `RichTextStyle` 覆盖 |
| `Link { content, url }` | 超链接，自动交互色 + 下划线 |
| `Code { content }` | 内联代码，等宽字体 + 深色圆角背景 + 金色文字 |
| `Image { src, alt, width, height, fit, radius }` | `image-codecs` 下的本地图片原子；尺寸、适配和圆角可覆盖 |
| `ThematicBreak` | 零字符宽度的独立主题分隔线行 |
| `NewLine` | 强制换行 |

### RichTextStyle

Text 段可选的样式覆盖：

| 字段 | 类型 | 说明 |
|------|------|------|
| `bold` | `bool` | 粗体 |
| `italic` | `bool` | 斜体 |
| `underline` | `bool` | 下划线装饰 |
| `strikethrough` | `bool` | 删除线 |
| `font_size` | `Option<f32>` | 段级字号，覆盖默认值 |
| `color` | `Option<Color>` | 段级文字色 |
| `bg_color` | `Option<Color>` | 段级背景色（仅 Text 段） |

```rust uix-compile=rich-text-styles
RichText::new().content(vec![
    RichTextSegment::Text {
        content: "粗体".into(),
        style: RichTextStyle { bold: true, ..Default::default() },
    },
    RichTextSegment::Text {
        content: "红色删除线".into(),
        style: RichTextStyle {
            color: Some(Color::from_rgb(220, 50, 50)),
            strikethrough: true,
            ..Default::default()
        },
    },
])
```

## 从 Markdown 解析

`parse_rich_text()` 把 Markdown 文本直接转为 segment 列表，并让解析结果继续复用 RichText 的统一测量、折行和绘制路径：

```rust uix-compile=rich-text-parse
let segments = parse_rich_text(
    "**运行** `cargo build`，查看 [使用指南](https://example.test/guide)。"
);
// segments 自动包含带样式 Text、内联 Code 与 Link
RichText::new().content(segments);
```

- 围栏代码块（三个及以上连续反引号或波浪号）→ `RichTextSegment::Code`
- 围栏代码开闭标记要求位于行首；闭标记必须与开标记同类且长度不少于开标记，闭合后只接受 ASCII 空格、制表符或 CRLF 行结束；允许的尾随空白不进入可见段
- 更短、混用、带 Unicode 空白/其他后缀的候选闭标记保留在代码正文；未闭合围栏和行内连续标记保留为普通/内联文本，不吞掉后续内容
- 缩进代码块按四列 Markdown 缩进识别：ASCII 空格前进一列，制表符前进到下一个四列制表位；达到四列后去除一个缩进前缀并映射为 `RichTextSegment::Code`
- 连续缩进代码行合并为同一个代码段；两个代码行之间的 ASCII 空白行保留，块尾空白行交回普通换行解析；一至三列缩进和 Unicode 空白不启动代码块
- 内联反引号（`` ` ``）→ `RichTextSegment::Code`
- 连续反引号按相同长度匹配闭合 delimiter；代码正文中的较短反引号保持字面
- 内联代码正文首尾都有空格且并非纯空格时，各移除一个外围空格；单侧空格、额外空格和纯空格正文保持其余内容
- 行内链接（`[显示文本](https://example.test)`）→ `RichTextSegment::Link`
- 链接标签和目标支持转义分隔符及目标中的平衡圆括号，显示文本与 URL 会去除已识别的转义符；目标外围空白会被清理，清理与解码后的内部 Unicode 空白或控制字符会使完整候选保持字面文本，空格可使用百分号编码表达
- 尖括号 HTTP(S) 自动链接（`<https://example.test>`）→ `RichTextSegment::Link`；scheme 匹配忽略 ASCII 大小写，显示文本与目标保留原始 URL
- 自动链接内部不接受空白、控制字符或嵌套左尖括号；空目标、非 HTTP(S) scheme、未闭合或反斜杠转义输入保持普通文本
- 尖括号邮件自动链接（`<user@example.test>`）→ `RichTextSegment::Link`；显示原始邮箱，提交目标为 `mailto:user@example.test`
- 邮箱仅接受 ASCII local-part 与点分 domain：local-part 拒绝首尾/连续点号，domain label 拒绝空值、首尾连字符、下划线和超过 63 字节；Unicode、多个 `@`、空白、未闭合或转义输入保持普通文本
- 行首 ATX 标题（`#` 至 `######` 后接 ASCII 空格或制表符）映射为粗体 Text，支持以 ASCII 空格或制表符分隔、尾随的连续闭合井号，并沿用 Typography 的标题字号；Unicode 空白不参与起始或闭合语法，六级降级为五级字号
- Setext 标题使用“非空普通正文行 + 下一行纯 `=` 或 `-` 标记”，分别沿用 Heading1/Heading2 样式；标记允许 ASCII 空格/制表符外围空白且自身不可见，只按标记行是否换行保留一个块结束换行
- 主题分隔线要求整行至少三个 `-`、`*` 或 `_`，三种标记可混合并允许 ASCII 空格/制表符间隔与外围空白；它映射为 `RichTextSegment::ThematicBreak`，行首判定先于无序列表与内联强调，`===` 和含其他字符的候选保持字面文本
- `image-codecs` 开启时，`![alt](src)` 映射为 `RichTextSegment::Image`：alt 与目标支持反斜杠转义和平衡括号，alt/src 不能为空；首版只接受本地相对路径、Windows 盘符路径与文件系统路径，HTTP(S)、data URI 和其他 URI 完整保持普通文本。能力关闭时 Image 段类型与图片解析产出在编译期消失，源码保持普通文本
- ATX、列表、引用等已支持块级行不被 Setext 重新解释；正文后的纯 `---` 保持 Setext 优先，孤立 `---` 则成为主题分隔线
- 行首一级无序列表（`- `、`* `、`+ `）统一输出 `• ` 项目符号，正文继续解析内联样式；标记后只接受 ASCII 空格或制表符，其他 Unicode 空白保持普通文本
- 行首一级有序列表（1 至 9 位 ASCII 数字加 `. ` 或 `) `）保留作者使用的数字与标记前缀，正文继续解析内联样式；10 位及以上编号保持普通文本，标记后只接受 ASCII 空格或制表符，其他 Unicode 空白保持普通文本
- 行首一级引用（`> ` 或 `>` 后接制表符）统一输出 `│ ` 前缀，引用正文默认使用斜体；无空白分隔符时保持普通文本，嵌套列表和高级列表语法暂不承诺
- `**粗体**` / `__粗体__` → `RichTextStyle::bold`
- `*斜体*` / `_斜体_` → `RichTextStyle::italic`
- 斜体在统一 render 路径中以局部仿射倾斜绘制，保存并恢复外层画布状态，不影响相邻段
- `~~删除线~~` → `RichTextStyle::strikethrough`
- UIX 扩展 `++下划线++` → `RichTextStyle::underline`
- 源文本的 LF、CRLF 与孤立 CR 行结束统一生成一个 `RichTextSegment::NewLine`；回车不会作为可见字形进入布局或复制，空行也会保留
- 反斜杠可转义 Markdown 标点（如 `\*字面星号\*`、`\[字面方括号\]`），输出去掉转义符的普通文本
- 转义标记不会参与外层样式的闭合查找；连续偶数个反斜杠后，标记语义恢复
- 样式标记可双向嵌套（如 `**粗体 *斜体***` 或 `*斜体 **粗体***`）；同字符内层标记可独立闭合或与外层共享末尾 delimiter run，不成对的反引号或样式标记按普通文本处理
- 样式闭合标记前必须紧邻非空白正文；尾随空白的未闭合标记按普通文本保留
- 单词中的 `snake_case` 下划线和 `foo__bar__baz` 双下划线不会触发斜体或粗体

## 配置

- **`.font_size(f32)`** — 默认字号，未设置时 Text 段继承默认值
- **`.font_size_unit(PhysicalUnit)`** — 物理单位字号（优先级高于 `font_size`），跟随 DPI
- **`.color(Color)`** — 默认文字色，未调用时随主题 `color_text`；显式设置后固定

## 布局

声明式 `RichText` 的 `fontSize`、`fontFamily`、`lineHeight`、文字色、padding 及宽高应直接写在该节点上；普通父容器样式不自动继承。默认 flex grow 保持 1；需要按内容高度布局时设 `flexGrow={0}`。

- 文本、代码和链接共用同一字符级布局引擎，按可用宽度自动折行
- 连续同字体文本由 OpenType shaping 生成 glyph id、advance、二维 offset 与源文本 cluster；阿拉伯、Indic、组合符和 Latin ligature 不再按“一字符一字形”定位
- 字体回退以扩展字素簇为最小选择单位；同一组合序列不会被拆给不同字体，单个 shaping cluster 的多个字形也不会在自动折行时分到两行
- 每个显式段落按 UAX #9 的首个强字符解析基方向与嵌入级别；LTR、RTL、数字和中性字符可跨 Text、Code、Link 与字体回退边界组成统一视觉 run，视觉重排不改变逻辑源字符索引
- 自动断行使用默认 UAX #14 的 mandatory/allowed 机会，支持 CJK、标点禁则、NBSP、组合序列与 emoji ZWJ 序列；超长字母数字词仅在完整 shaping cluster 边界紧急回退
- 默认行高为 `font_size × 1.5`；叶节点声明的 `lineHeight` 可覆盖默认倍率，测量、文字基线与选择使用一致的行盒。详细兼容语义见[字号、行盒与控件排版契约](../界面构建/样式与主题.md#字号行盒与控件排版契约)。
- 主题分隔线占用一个默认行高，左右各留白 12px、在行盒内垂直居中，并使用主题 `color_text_quaternary`；它不产生可选择字形
- 内联图片是不可拆分的原子替换对象；加载前使用一个默认行高的正方形占位，文件读取与解码在后台执行，首帧不阻塞；固有像素尺寸就绪后按当前 DPI 换算并触发布局重排。仅覆盖 width 或 height 时保持固有比例，双轴覆盖时使用声明尺寸，fit=true 保持比例居中、false 拉伸填满
- Text 段的 `font_size` 同时参与行高和自然宽度测量；宽度约束变化会使缓存失效并重新折行
- 选择背景、链接高亮、代码复制区与文字绘制共享同一折行几何，不会偏离
- 全部内容统一裁在实际 frame 内，框外不可见

## 链接

- **Tab 顺序**：含有效 URL 的 RichText 自动进入 Tab 顺序（`tab_index = 1`）
- **鼠标**：在同一链接内完成按下与释放后提交；移出目标、`PointerLeave` 或失焦取消
- **键盘**：`FocusIn` 激活焦点，方向键 / `Home` / `End` 在链接间移动，`Enter` / `Space` 提交当前焦点链接
- **语义事件**：以 URL 发出 `SemanticKind::Submit`，导航策略由应用决定
- **状态**：`focused_link()` 返回 `Option<(&str, &str)>` —— 当前焦点链接的显示文本与 URL

## 代码段

- 代码段自动使用等宽字体、深色背景（`#28282D`）和金色文字（`#E6B464`），字号为默认的 0.9 倍
- 围栏代码内部换行保留在同一 `Code` 段中，CRLF 和孤立回车统一为 LF；measure、render 与复制按钮都按同一逻辑代码段处理
- 末尾可见字形旁显示 **复制按钮**（24×16），hover 时深色圆角背板 + copy 图标，按压时更深色
- 点击复制按钮将代码内容写入系统剪贴板

## 文字选择

- **鼠标拖选**：在非链接/非代码区域按下左键拖拽，释放后完成选择
- **全选**：`Ctrl+A` 选中全部文字
- **复制**：`Ctrl+C` 复制选中文字到系统剪贴板
- 选中区域以主题色半透明背景高亮
- RTL 或混排行中的拖选、命中和光标边界直接使用布局生成的视觉 run 与嵌入级别；一个逻辑连续选择跨双向 run 时可显示为多个不连续视觉高亮片段
- 普通文本、富文本和输入控件共享扩展字素簇边界模型；选择不会停在组合音标、emoji ZWJ/肤色序列或 Indic 连写内部，即使一个字素簇跨越多个富文本样式段也保持原子性
- 主题分隔线自身为零字符宽度、不可字符级选中；选区跨越该块时不复制 Markdown 标记，只由分隔线源码行输出一个换行
- 内联图片以完整 alt 作为逻辑字符跨度；命中图片两侧选择边界时保持原子几何，复制只输出所选 alt，不输出 Markdown 标记或本地 src
- 失焦自动清除选择

## 外部测量

`layout_rich_text_segments()` 可在非 RichText widget 中测量富文本尺寸：

```rust uix-compile=rich-text-layout
let segments = parse_rich_text("查看 `cargo test` 的输出");
let (height, char_count, max_width) = layout_rich_text_segments(
    &segments, 320.0, 14.0, Color::black(),
);
```

返回总高度、总字符数和最大行宽。

## 安全与资源边界

- Markdown / RichText 内容、链接目标、图片路径、代码文本和 alt 都按不可信数据处理。解析只建立显示结构，不代表内容已经消毒、链接可信或本地文件获得授权。
- 链接不会自动打开；`on_link(url)` 由应用验证 scheme、目标域、业务授权和是否需要用户确认后，再决定内部路由或调用系统浏览器。拒绝 `javascript:`、未知协议和不符合产品策略的外部目标。
- 本地图片沿 graphics `ImageService` 读取；应用仍须限制允许目录、文件大小、格式与像素预算，并处理符号链接、权限变化和读取时竞态。文档内容中的路径不能绕过应用文件访问策略。
- 复制操作会把选中文本或代码写入系统剪贴板；敏感文档应禁用选择/复制或在业务层确认，不能把剪贴板当作私密存储。
- 对外部大文本、超长代码、过多图片或深层结构设置输入与资源上限；截断或拒绝必须可观察，不能通过无界解析、布局或图片解码阻塞 UI owner。

## 推荐用法

按产品定义（Rust 优先、原生优先）：

```rust uix-compile=rich-text-on-link
// 从 Markdown 构建富文本，链接导航策略由应用决定。
let segments = parse_rich_text(markdown);

embed(RichText::new()
    .content(segments)
    .font_size(14.0)
    .on_link(|url| {
        // 应用决定打开方式：内部路由或系统浏览器
        open_internal(url);
    }));
```

- 混合排版优先用 `parse_rich_text` 从 Markdown 构建，避免手写 segment 列表。
- 链接激活时 `on_link(url)` 回调与 `SemanticKind::Submit` 语义事件同时触发；导航策略（内部路由 / 系统浏览器）由应用决定。
- 选择、复制、链接键盘导航由框架托管，业务不重复实现。

## 无障碍

- 仅含主题分隔线及其源码换行的 RichText 使用 `AccessibilityRole::Separator`；仅含一个内联图片及其源码换行时使用 `AccessibilityRole::Image` 并以 alt 命名；混合文档保持单一 `Text` 节点，图片只贡献 alt，且不朗读 Markdown 标记或 src
- 含链接时支持 Tab 焦点与键盘导航
- `focused_link()` 提供当前链接信息
- 结构化快照发布 segments、字号、颜色与焦点链接序数，供 Agent Bridge 读取
