## DI 容器

应用在组合根注册进程级服务，并在应用启动、路由或 handler 边界解析已知服务，再把完成当前职责所需的窄依赖显式传给 View 工厂或业务对象。组件、Module 与 Component 不在运行路径中自行查找容器；Module 私有实现不作为可解析服务暴露，窗口私有资源也不进入进程全局容器。

```rust uix-compile=framework-di
use uix::prelude::*;

// 组合根注册进程级单例服务
let mut container = DiContainer::new();
container.singleton(SettingsService::new());

// 应用边界按已知类型解析，再显式注入使用方；Clone 共享同一实例。
handle.resolve::<SettingsService>();
```

`AppHandle::resolve` 是应用组合/路由边界的公开入口，不是组件内的 Service Locator。若某个组件需要业务能力，优先传入窄 callback、trait 端口或只含必要字段的业务对象；不要把 `AppHandle`、`DiContainer` 或聚合全部服务的对象下传到整棵组件树。

## Provider 与配置继承

主题、Locale、尺寸和组件令牌沿 View 子树继承。最近 Provider 覆盖上层值；覆盖在子树卸载后随生命周期一起释放。

```rust uix-compile=framework-provider
use uix::prelude::*;

// LocaleProvider：子树语言覆写
embed(LocaleProvider::new(zh_cn())
    .child(|| column((
        label("中文界面"),
        embed(Empty::new().icon("inbox")),
    )))
    .build());

// ConfigProvider：子树尺寸 + 禁用态
embed(ConfigProvider::new()
    .widget_size(ControlSize::Large)
    .disabled(true)
    .child(|| column((
        button("继承 Large"),
        input().placeholder("继承禁用态"),
    )))
    .build());
```

```rust uix-compile=framework-overrides
use uix::prelude::*;

// 组件构造覆盖：Input 前后缀统一注入，业务页无需逐个传参
let mut overrides = WidgetOverrides::default();
overrides.input.prefix = Some("¥".to_string());

embed(ConfigProvider::new()
    .overrides(overrides)
    .child(|| input().placeholder("自动注入前缀"))
    .build());

// 组件令牌窄覆盖：只调整 Button 的主色与圆角
embed(ConfigProvider::new()
    .widget_tokens::<Button>(TokenPatch {
        color_primary: Some(Color::hex("#722ed1")),
        border_radius: Some(10.0),
        ..TokenPatch::default()
    })
    .child(|| button("紫色按钮").primary())
    .build());
```

## 国际化

组件内置文案从 Locale/资源表解析，业务内容由应用提供。格式化、方向和文字扩展属于显示层，不改变稳定 key 或业务值。

```rust uix-compile=framework-locale
use uix::prelude::*;

let locale = zh_cn();

App::new()
    .locale(locale)
    .root(move || {
        let locale = use_locale();
        column((
            label(format!("空态文案：{}", locale.empty_description)),
            embed(Empty::new().icon("inbox")),
        ))
    })
    .run();
```

## 尺寸与令牌

紧凑、默认和宽松密度由主题令牌表达。组件可以声明窄覆盖，但不得复制整套主题或直接依赖平台常量。

## 推荐用法

按产品定义（Rust 优先、原生优先）：

```rust uix-compile=framework-singleton
use uix::prelude::*;

// 组合根注册全局单例（App builder 入口）
App::new()
    .singleton(SettingsService::new())
    .root(main_view)
    .run();
```

```rust uix-compile=framework-services-i18n
// i18n 文案集中在资源表，组件按 key 读取文案。
register_translations(&[("common.save", "保存")]);
embed(LocaleProvider::new(locale)
    .child(|| label(t!("common.save")))
    .build());
```

- 服务注册与解析收敛在组合根或明确的应用路由边界；组件接收窄依赖，Module 私有实现不可解析。
- 子树覆盖（Locale / 尺寸 / 令牌）随生命周期释放，不反向改全局。
- 文案走资源表 + key，格式化只影响显示，不改变业务值。
- 密度由主题令牌表达，业务不复制整套主题。

## 保留边界

保留组合根、显式窄 DI、子树 Provider、可替换服务和生命周期释放原则；容器解析不能替代依赖声明。Rust 的实际注册与获取 API 以 `application`、`theme` 模块为准。
