# 测试驱动

[← 返回使用索引](../../使用.md)

> **接口**：声明 test-harness 的公开 UI 驱动入口——TestApp 的语义动作与系统事件注入。依赖：[快速开始](../入门/快速开始.md)。导出：无。（终端使用文档）

## 前置条件

- Cargo 依赖启用 `test-harness` feature（仅开发与测试环境，不进入发布构建）；
- 通过 `uix::ui::test_harness::TestApp` 构造无窗口应用：`TestApp::new((宽, 高), 根视图工厂)`。

## 语义动作

`snapshot()` / `text()` / `find()` 读取语义树；`click`、`focus`、`select`、`toggle`、`type_text`、`press_key`、`scroll`、`set_value` 等以 `automation_id` 驱动组件的语义行为。所有变更方法在动作前后各执行一次收敛（`settle`），收敛超过上限返回 `DidNotSettle`。

## 系统事件注入

语义动作无法覆盖的交互（文件拖放、指针序列等）经 `dispatch_system_event` 注入，返回树级分发结果：

```rust
use uix::prelude::*;

let result = app.dispatch_system_event(&SystemEvent::FileDrop {
    files: vec!["/tmp/evidence.png".to_owned()],
    position: upload_center,
})?;
assert_eq!(result, EventResult::Handled);
```

- **坐标空间**：`position` 使用应用内逻辑客户区坐标，与 `snapshot()` 的 `frame` / `visible_bounds` 同空间；TestApp 没有渲染表面，不涉及 device pixel ratio 换算。
- **可见失败**：`Handled` / `NotHandled` / `Bubbled` 原样返回；停止树（fail-stop）返回 `NotHandled("widget_tree")`；收敛超限返回 `AutomationError::DidNotSettle`。
- **适用限制**：视口变化使用 `resize()`（裸 `Resize` 事件不更新根 frame）；`Wheel` 的 delta 遵循组件层「正向下」归一化约定；拖拽手势由指针移动在树内合成，外部注入应使用 PointerDown → PointerMove → PointerUp 序列；键盘、文本与 FileDrop 族事件受窗口焦点门控，注入 `WindowBlur` 后会被拦截。
