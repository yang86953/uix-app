## 语义样式

优先语义，再覆盖细节：

```rust uix-compile=button-variants
button("保存").primary();       // 主色按钮
button("取消");                 // 默认按钮
button("删除").danger();        // 危险操作
```

可用语义：`.primary()` `.danger()` `.ghost()`；不追加语义方法时使用默认按钮样式。

`Button` 的固有宽度会按当前样式字号、宽字符和水平 padding 估算，长中日韩文字不会按窄拉丁字符压缩；绘制时再使用实际字体宽度居中。通过 `Style::with_font_size(...)` 设置的字号同时参与测量与绘制，非有限值、零或负数统一回到默认 14 logical。固定 `.width(...)` 或父布局约束仍可主动压缩按钮，调用方应为业务文案保留足够空间。

## 细粒度样式

```rust uix-compile=view-style-chain
label("Styled")
    .bg(Color::rgba(240, 240, 240, 255))  // 背景色
    .color(Color::BLACK)                   // 前景色（文本）
    .font_size(16.0)
    .radius(8.0)                           // 圆角
    .border(1.0, Color::gray())            // 边框
    .gap(12.0)                             // 子节点间距
    .padding(16.0)                         // 内边距（四边）
    .padding_h(16.0)                       // 水平内边距
    .padding_v(8.0)                        // 垂直内边距
    .margin(8.0)                           // 外边距
    .opacity(0.8)                          // 透明度
    .shadow(4.0, Color::rgba(0,0,0,40))   // 阴影
```

## 色板

框架公开 **12 个主色 × 每色 10 阶 = 120 色**、13 阶中性色、自定义色板生成、功能色阶和数据可视化分类色板。`DesignTokens` 另由主题基色推导，亮/暗切换时自动跟随：

```rust uix-compile=design-token-view
fn my_page(tk: &DesignTokens) -> impl View {
    column((
        // 文字层级
        label("标题").color(tk.color_text).font_size(18.0),
        label("次要").color(tk.color_text_secondary).font_size(14.0),
        label("辅助").color(tk.color_text_tertiary).font_size(12.0),
        label("禁用").color(tk.color_text_quaternary).font_size(12.0),

        // 语义色
        label("成功").color(tk.color_success),
        label("警告").color(tk.color_warning),
        label("错误").color(tk.color_error),
        label("信息").color(tk.color_info),

        // 主色
        label("强调").color(tk.color_primary),
    ))
    .gap(12.0)
    // 背景层级
    .bg(tk.color_bg_elevated)
    .radius(tk.border_radius)
    .border(1.0, tk.color_border_secondary)
}
```

在 `component!` 的 `render` 中通过 `ctx.tokens()` 获取：

```rust uix-compile=paint-context-tokens
fn read_paint_tokens(ctx: &mut PaintContext<'_>) {
    let primary = ctx.tokens().color_primary();
    let text    = ctx.tokens().color_text();
    let bg      = ctx.tokens().color_bg_container();
}
```

### 12 主色

| 索引 | 色名 | 基调 |
|------|------|------|
| 0 | Red | 红 |
| 1 | Volcano | 橙红 |
| 2 | Orange | 橙 |
| 3 | Gold | 金 |
| 4 | Yellow | 黄 |
| 5 | Lime | 青柠 |
| 6 | Green | 绿 |
| 7 | Cyan | 青 |
| 8 | Blue | 蓝（品牌主色） |
| 9 | Geekblue | 极客蓝 |
| 10 | Purple | 紫 |
| 11 | Magenta | 品红 |

`PrimaryHue::ALL` 保持上表顺序；`palette()` 返回 `ColorScale`，索引 0 最浅、9 最深，主色固定在索引 5。`shade()` 越界返回 `None`：

```rust uix-compile=primary-palette
let blue = PrimaryHue::Blue.palette();
let primary = blue.primary();                 // #1677ff
let lightest: Option<Color> = blue.shade(0);  // #e6f4ff
let all_ten: &[Color; 10] = blue.colors();
```

从任意品牌色生成同结构色板；输入 alpha 不参与推导，结果均为不透明色：

```rust uix-compile=generated-palette
let brand = generate_color_scale(Color::hex("#7c3aed"));
let brand_primary = brand.primary();
```

### 中性色

`NEUTRAL_PALETTE` 提供从白到黑的 13 阶显式中性色（索引 0–12），`shade()` 同样越界安全：

```rust uix-compile=neutral-palette
let surface = NEUTRAL_PALETTE.shade(2); // #f5f5f5
let ink = NEUTRAL_PALETTE.shade(12);    // #000000
```

主题令牌中的中性色另由 3 个基色派生——`bg`（底色）、`text`（文字基色）、`border`（边框基色），亮/暗模式下各自推算层级：

| 基色 | 派生令牌 |
|------|----------|
| `bg` | `color_bg_container` → `_elevated` → `_layout` → `_overlay` → `_spotlight` → `_mask` |
| `text` | `color_text` → `_secondary` → `_tertiary` → `_quaternary`（逐级降低 alpha） |
| `text` | `color_fill` → `_secondary` → `_tertiary` → `_quaternary`（逐级降低 alpha） |
| `border` | `color_border` → `_secondary` |

### 功能色与数据可视化

`functional_color_scale()` 从当前 `DesignTokens` 的实际功能色种子生成 10 阶色板，因此自定义主题不会退回默认色：

```rust uix-compile=functional-palette
let tk = DesignTokens::antd_light();
let success = tk.functional_color_scale(FunctionalColorRole::Success);
let warning = tk.functional_color_scale(FunctionalColorRole::Warning);
let error = tk.functional_color_scale(FunctionalColorRole::Error);
let info = tk.functional_color_scale(FunctionalColorRole::Info);
```

不依赖主题时可用 `FunctionalColorRole::Error.default_palette()`。离散图表按系列顺序使用 AntV 10 色分类色板：

```rust uix-compile=data-visualization-palette
let first_series = DATA_VISUALIZATION_PALETTE.color(0); // #5b8ff9
let chart_colors = DATA_VISUALIZATION_PALETTE.colors();
```

### View 令牌速查

```rust uix-compile=style-token-reference
let tokens = DesignTokens::antd_light();
let _ = (
    tokens.color_text, tokens.color_text_secondary, tokens.color_text_tertiary,
    tokens.color_bg_container, tokens.color_bg_elevated, tokens.color_border,
    tokens.color_fill, tokens.border_radius_sm, tokens.border_radius_lg,
);
```

所有令牌色实现了 `Color`，可与自定义 `Color::rgba()` / `Color::hex()` 混用：

```rust uix-compile=token-aware-style
// 主题感知底色 + 自定义强调色边框
let tk = DesignTokens::antd_light();
label("Token-aware")
    .bg(tk.color_bg_container)
    .border(2.0, Color::from_rgb(64, 150, 255));
```

## 主题

默认使用 Ant Design 风格亮色主题：

```rust uix-compile=app-theme
let _exit_code = App::new()
    .theme(Theme::antd_light())          // 默认
    // .theme(Theme::antd_dark())
    .follow_system_theme(true)           // 跟随系统
    .run();
```

运行时切换：

```rust uix-compile=runtime-theme-switch
let toggle = ThemeToggle::new(); // 内置切换开关组件

fn switch_to_dark(handle: &AppHandle) {
    let _ = handle.set_theme(Theme::antd_dark());
}
```

通过 `ctx.tokens()` 获取当前主题的设计令牌：

```rust uix-compile=current-theme-tokens
fn read_current_theme(ctx: &mut PaintContext<'_>) {
    let primary = ctx.tokens().color_primary();
    let text    = ctx.tokens().color_text();
    let bg      = ctx.tokens().color_bg_container();
    // ...
}
```

## ThemeToggle —— 主题切换按钮

内置暗色 ↔ 亮色主题切换按钮：

```rust uix-compile=theme-toggle
let toggle = ThemeToggle::new().dark(false); // 初始亮色

toggle.is_dark()  // 读取当前模式
```

`ThemeToggle` 默认进入 Tab 顺序；点击或聚焦后按 `Enter` / `Space` 会切换状态，并发出载荷为 `"dark"` 或 `"light"` 的 `SemanticKind::Change`。`.dark(...)` 只设置初始状态，后续 reconcile 保留用户运行态；`is_dark()` 与 `SnapshotFields::ThemeToggle::dark` 都返回当前状态。配合 `AppHandle::set_theme(...)` 或自定义主题逻辑使用。

## 自定义主题

从 `ThemePrimitives` 覆盖基色生成：

```rust uix-compile=custom-theme-primitives
let primitives = ThemePrimitives {
    primary: Color::hex("#722ed1"),   // 品牌主色
    success: Color::hex("#52c41a"),
    warning: Color::hex("#faad14"),
    error:   Color::hex("#ff4d4f"),
    info:    Color::hex("#722ed1"),   // 通常与 primary 一致
    bg:      Color::hex("#f5f5f7"),
    text:    Color::BLACK,
    border:  Color::hex("#e4e4e7"),
};
let custom = DesignTokens::from_primitives(primitives, false);

let _exit_code = App::new()
    .theme(Theme::new(custom))
    .run();
```

也可以传入 12 个主色种子（0-based 索引 8 即 Blue 为品牌主色）；其余色相通过 `PrimaryHue` / `ColorScale` 使用，不会存入 `DesignTokens`：

```rust uix-compile=custom-primary-seeds
let primary_seeds = PrimaryHue::ALL.map(PrimaryHue::primary);
let custom = DesignTokens::from_primaries(primary_seeds, false);
```

只换品牌色、保留其他默认值：

```rust uix-compile=custom-brand-primary
let custom = DesignTokens::antd_light()
    .with_brand_primary(Color::hex("#722ed1"));
```
