# 富文本

[← 返回使用 索引](../使用.md)

> **接口**：声明 UIX 富文本的公开用法——混合排版、链接、代码段、选择与复制。依赖：[数据展示](数据展示.md)。导出：无。（终端使用文档）

混合排版文本、超链接与代码段，自动折行，支持文字选择与键盘导航。

## 基本用法

```rust uix-compile=rich-text-basic
RichText::new()
    .content(vec![
        RichTextSegment::Text {
            content: "查看 ".into(),
            style: RichTextStyle::default(),
        },
        RichTextSegment::Link {
            content: "使用指南".into(),
            url: "https://example.test/guide".into(),
        },
        RichTextSegment::NewLine,
        RichTextSegment::Code {
            content: "cargo run".into(),
        },
    ])
    .font_size(14.0);
```

## 段类型（RichTextSegment）

| 段 | 说明 |
|---|------|
| `Text { content, style }` | 普通文本，带独立 `RichTextStyle` 覆盖 |
| `Link { content, url }` | 超链接，自动交互色 + 下划线 |
| `Code { content }` | 内联代码，等宽字体 + 深色圆角背景 + 金色文字 |
| `NewLine` | 强制换行 |

### RichTextStyle

Text 段可选的样式覆盖：

| 字段 | 类型 | 说明 |
|------|------|------|
| `bold` | `bool` | 粗体 |
| `italic` | `bool` | 斜体 |
| `underline` | `bool` | 下划线装饰 |
| `strikethrough` | `bool` | 删除线 |
| `font_size` | `Option<f32>` | 段级字号，覆盖默认值 |
| `color` | `Option<Color>` | 段级文字色 |
| `bg_color` | `Option<Color>` | 段级背景色（仅 Text 段） |

```rust uix-compile=rich-text-styles
RichText::new().content(vec![
    RichTextSegment::Text {
        content: "粗体".into(),
        style: RichTextStyle { bold: true, ..Default::default() },
    },
    RichTextSegment::Text {
        content: "红色删除线".into(),
        style: RichTextStyle {
            color: Some(Color::from_rgb(220, 50, 50)),
            strikethrough: true,
            ..Default::default()
        },
    },
])
```

## 从 Markdown 解析

`parse_rich_text()` 把 Markdown 文本直接转为 segment 列表，并让解析结果继续复用 RichText 的统一测量、折行和绘制路径：

```rust uix-compile=rich-text-parse
let segments = parse_rich_text(
    "**运行** `cargo build`，查看 [使用指南](https://example.test/guide)。"
);
// segments 自动包含带样式 Text、内联 Code 与 Link
RichText::new().content(segments);
```

- 围栏代码块（` ``` `）→ `RichTextSegment::Code`
- 内联反引号（`` ` ``）→ `RichTextSegment::Code`
- 行内链接（`[显示文本](https://example.test)`）→ `RichTextSegment::Link`
- `**粗体**` / `__粗体__` → `RichTextStyle::bold`
- `*斜体*` / `_斜体_` → `RichTextStyle::italic`
- `~~删除线~~` → `RichTextStyle::strikethrough`
- UIX 扩展 `++下划线++` → `RichTextStyle::underline`
- 源文本换行 → `RichTextSegment::NewLine`；空行也会保留
- 反斜杠可转义 Markdown 标点（如 `\*字面星号\*`、`\[字面方括号\]`），输出去掉转义符的普通文本
- 样式标记可嵌套（如 `**粗体 *斜体***`）；不成对的反引号或样式标记按普通文本处理
- 单词中的 `snake_case` 下划线不会触发斜体

## 配置

- **`.font_size(f32)`** — 默认字号，未设置时 Text 段继承默认值
- **`.font_size_unit(PhysicalUnit)`** — 物理单位字号（优先级高于 `font_size`），跟随 DPI
- **`.color(Color)`** — 默认文字色，未调用时随主题 `color_text`；显式设置后固定

## 布局

- 文本、代码和链接共用同一字符级布局引擎，按可用宽度自动折行
- 断行以空白 token 为单位，超长 token 逐字符回退
- 行高固定为 `font_size × 1.5`
- 选择背景、链接高亮、代码复制区与文字绘制共享同一折行几何，不会偏离
- 全部内容统一裁在实际 frame 内，框外不可见

## 链接

- **Tab 顺序**：含有效 URL 的 RichText 自动进入 Tab 顺序（`tab_index = 1`）
- **鼠标**：在同一链接内完成按下与释放后提交；移出目标、`PointerLeave` 或失焦取消
- **键盘**：`FocusIn` 激活焦点，方向键 / `Home` / `End` 在链接间移动，`Enter` / `Space` 提交当前焦点链接
- **语义事件**：以 URL 发出 `SemanticKind::Submit`，导航策略由应用决定
- **状态**：`focused_link()` 返回 `Option<(&str, &str)>` —— 当前焦点链接的显示文本与 URL

## 代码段

- 代码段自动使用等宽字体、深色背景（`#28282D`）和金色文字（`#E6B464`），字号为默认的 0.9 倍
- 围栏代码内部换行保留在同一 `Code` 段中；measure、render 与复制按钮都按同一逻辑代码段处理
- 末尾可见字形旁显示 **复制按钮**（24×16），hover 时深色圆角背板 + copy 图标，按压时更深色
- 点击复制按钮将代码内容写入系统剪贴板

## 文字选择

- **鼠标拖选**：在非链接/非代码区域按下左键拖拽，释放后完成选择
- **全选**：`Ctrl+A` 选中全部文字
- **复制**：`Ctrl+C` 复制选中文字到系统剪贴板
- 选中区域以主题色半透明背景高亮
- 失焦自动清除选择

## 键盘快捷键

| 按键 | 行为 |
|------|------|
| Tab | 进入/移出 RichText（含链接时） |
| ← / ↑ | 前一个链接 |
| → / ↓ | 后一个链接 |
| Home | 跳转到首个链接 |
| End | 跳转到末个链接 |
| Enter / Space | 提交当前焦点链接的 URL |
| Ctrl+A | 全选文字 |
| Ctrl+C | 复制选中文字到系统剪贴板 |

## 外部测量

`layout_rich_text_segments()` 可在非 RichText widget 中测量富文本尺寸：

```rust uix-compile=rich-text-layout
let segments = parse_rich_text("查看 `cargo check` 的输出");
let (height, char_count, max_width) = layout_rich_text_segments(
    &segments, 320.0, 14.0, Color::black(),
);
```

返回总高度、总字符数和最大行宽。

## 理想使用方式

按产品定义（Rust 优先、原生优先）：

```rust uix-compile=rich-text-on-link
// 从 Markdown 直接构建富文本，链接导航策略由应用决定（E-07 已落地）
let segments = parse_rich_text(markdown);

embed(RichText::new()
    .content(segments)
    .font_size(14.0)
    .on_link(|url| {
        // 应用决定打开方式：内部路由或系统浏览器
        open_internal(url);
    }));
```

- 混合排版优先用 `parse_rich_text` 从 Markdown 构建，避免手写 segment 列表。
- 链接激活时 `on_link(url)` 回调与 `SemanticKind::Submit` 语义事件同时触发；导航策略（内部路由 / 系统浏览器）由应用决定。
- 选择、复制、链接键盘导航由框架托管，业务不重复实现。

## 无障碍

- `AccessibilityRole::Text` 分类
- 含链接时支持 Tab 焦点与键盘导航
- `focused_link()` 提供当前链接信息
- 结构化快照发布 segments、字号、颜色与焦点链接序数，供 Agent Bridge 读取
