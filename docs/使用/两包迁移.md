# 两包迁移

此次源码调整将原控件库独立为 `uix-widgets`，UIX 语言、编译器、运行时、CLI 和 LSP 合并到 `uix-app`。
原 `uix-derive`、`uix-lang`、`uix-lang-compiler`、`uix-lang-runtime`、独立 CLI/LSP 包不再作为依赖入口。
本次不发布 crates.io；使用两个相邻源码仓库或相应 Git 依赖。

## Rust

包含按钮、输入框、布局容器、Ant Design 主题等具体控件的代码改用 `uix_widgets::prelude::*`。
框架自身的状态、View、事件、窗口与绘制仍可使用 `uix_app` 的公开接口。
`uix_app::ui::widgets`、具体表单/虚拟列表及主题预设迁到 `uix_widgets::ui`。
`App::with_widgets()`（引入 `WidgetLibraryAppExt`）安装所选主题、字体与反馈服务。
其他使用方仓库需要自行按此迁移；本次只修改这两个仓库。

## UIX

先安装框架 CLI：

```sh
cargo install --path ../uix-app --no-default-features --features lang-tools --bin uix --bin uix-lang-ls
```

使用方的构建依赖：

```toml
[dependencies]
uix-app = { path = "../uix-app", optional = true }
uix-widgets = { path = "../uix-widgets", optional = true }
[build-dependencies]
uix-app = { path = "../uix-app", default-features = false, features = ["lang-build"] }
```

`build.rs`：

```rust
fn main() -> Result<(), String> {
    uix_app::lang::build::Builder::from_env()?
        .compile("ui/main.uix", uix_app::lang::build::OutputKind::View)?;
    Ok(())
}
```

`src/main.rs` 使用 `uix_widgets::uix!("ui/main.uix")` 读取生成的 View。
`uix_app!`、`uix_items!`、`uix_module!` 分别对应 App、Items、Module 输出。
这些都是普通 `include!` 包装宏，只接收源文件路径；旧的内嵌源码过程宏写法需提取为 `.uix` 文件。
构建器从项目配置加载组件库；第三方或独立来源也可用 `Builder::library(path)` 显式登记。

在项目根配置 [uix.json](../架构/使用方按需编译.md)，然后执行 `uix build --release`。
CLI 查询支持 `--project`，LSP 按文档所在项目加载相同声明；核心编译器不内置官方控件生成器。

## 动态 UI

模块运行时的 `ViewKind` 是库定义字符串，官方五类模块投影合同归组件库声明，`ModuleView` 归组件库。
脚本扩展框架返回类型擦除的 `UiNode`；`WidgetUiNode` 与 `UiProjector` 在组件库。
宿主通过 `WidgetUiHostExt::with_widget_ui()` 登记库解析器；需要检查具体内容时使用 `UiNode::downcast_ref::<WidgetUiNode>()`。
正式构建必须事先声明相应动态单元，重载不能增加编译时没有选择的控件。

## 框架能力

`runtime` 总开关已移除，不提供旧开关兼容层。原完整运行时使用 `application`；
独立状态使用 `reactive`，独立布局使用 `layout`，CPU 绘制使用 `graphics`，
无窗口 UI 使用 `ui`，原生系统能力使用 `platform`。关闭 Cargo 默认功能后显式选择，
或在严格构建的 `rust` 中声明对应 `uix-app/<能力>`。

可移植模块入口改为 `uix_app::lang::modules`，脚本引擎改为 `uix_app::extensions`。
这两类执行引擎都不隐式启用窗口应用。框架能力闭包见[能力拆分](../架构/框架能力拆分.md)。

严格构建中，调用 `with_widgets()` 时声明 `uix-widgets/application`；
单独选用按钮等控件不会因此带入应用层。组件库不再从库根转导 `app`、`data` 模块，
窗口与配置接口直接从 `uix_app` 引用。

应用依赖注入容器统一使用 `uix_app::app::DiContainer`，与组件库的布局 `Container` 区分。
