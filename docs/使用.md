# 使用

> 怎样用 UIX 写应用（不必关心框架内部）。详细文档见 **[使用](使用/教程.md)**。

入口：`use uix::prelude::*`。可复制示例 → [README](../README.md#示例)；能力展示与可执行验收 → [`demo`](../demo/README.md)；导出一览 → [`prelude.rs`](../src/prelude.rs)。

> **当前状态**：Windows P6 功能基线已闭合，`0.0.1` 范围内 110 项已完成工作树定向实现与行为验证，但 0 / 110 项绑定 clean 冻结候选、候选全量门禁和逐项真窗 / 等价证据；版本仍未发布。可编译公开示例不替代真窗、硬件、长稳、性能与打包验收。准确 gate 和阻断项见[`0.0.1 首发计划`](进度.md#001-首发计划)。

## 阅读路径

**新手**：从教程开始，跟着写一个应用，再查响应式基础了解原理。

**用过类似框架**：直接看响应式基础 → 组件 → 组件速查，把 UIX 当 Ant Design 用。

**遇到问题**：按分类查对应文档，或搜组件速查定位。
