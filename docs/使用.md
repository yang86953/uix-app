## 快速开始

`Cargo.toml`：

```toml
[dependencies]
uix = "0.1"
```

第一个应用：

```rust
use uix::prelude::*;

fn main() {
    App::new()
        .title("Hello UIX")
        .size(400, 300)
        .root(|| label("Hello, world!").font_size(32.0))
        .run();
}
```

带交互的计数器：

```rust
use uix::prelude::*;

fn main() {
    let count = State::new(0);

    App::new()
        .title("计数器")
        .size(360, 200)
        .root(move || {
            column((
                count.map_text(|n| format!("{n}")).font_size(48.0),
                row((
                    button("-1").on_click(&count, |c| c.update(|v| *v -= 1)),
                    button("+1").primary().on_click(&count, |c| c.update(|v| *v += 1)),
                )).gap(8.0),
            ))
            .gap(16.0)
            .padding(24.0)
        })
        .run();
}
```

## 核心概念

### State —— 响应式状态

```rust
let count = State::new(0);       // 创建
count.set(5);                     // 写入
count.update(|v| *v += 2);       // 基于旧值更新
let val: i32 = count.get();      // 读取
```

写入 `State` 会标记受影响的视图，由框架合并为至多一次重绘。高频写入不自动节流——用 `run_interval` 或动画驱动周期性变化。

### Computed —— 派生状态

自动追踪依赖，惰性求值，仅在依赖变化时重算：

```rust
let first = State::new("Ada");
let last  = State::new("Lovelace");
let full  = Computed::new(move || format!("{} {}", first.get(), last.get()));

// 映射到视图
full.map_text(|s| s.clone()).font_size(20.0);
```

`map` / `map_text` / `map_opt` 将 `Computed<T>` 转为响应式 View：

| 方法 | 输入 | 输出 |
|------|------|------|
| `.map(\|v\| view)` | `T` → `impl View` | 依赖变化时重建子视图 |
| `.map_text(\|v\| format!(…))` | `T` → `String` | 常用简写 |
| `.map_opt(\|v\| Option<impl View>)` | `T` → `Option<impl View>` | 条件渲染 |

`map` / `map_opt` 放在 `App::root` 的构建闭包内，依赖变化时由框架请求结构 reconcile；`map_text` 只失效对应文本的绘制。

### Effect —— 副作用

依赖变化时执行（不产生视图）：

```rust
Effect::new(move || {
    log::info!("count 变为 {}", count.get());
    // 自动追踪 count
});
```

Effect 在事件轮次末尾、重绘之前批量执行。

### View —— 组合模型

所有界面元素实现 `View` trait，通过组合构建 UI 树：

```rust
// 条件渲染
show(visible, || label("可见内容"))

// 列表渲染（少量项目）
column(items.iter().enumerate().map(|(i, item)| {
    label(item).automation_id(format!("item-{i}"))
}))

// 大量列表 → VirtualScroll（见后文）
```

`Option<impl View>` 自动处理 `None`（不渲染）和 `Some(view)`（渲染）。

### Error —— 错误处理

所有框架 API 返回 `Result<T, Error>`。`Error` 为 typed 错误类型，含错误码、严重级别、消息及源链：

```rust
use uix::prelude::*;

// 创建错误
let err = Error::new(Errc::InvalidArgument, "输入不能为空");
let err = Error::not_found("config.json");
let err = Error::invalid_state("窗口已销毁");

// 设置严重级别
let fatal = err.set_severity(ErrorSeverity::Fatal);

// 链式错误（保留根因）
let root = Error::new(Errc::IoError, "磁盘满");
let wrapped = Error::new(Errc::WriteFailure, "写入失败").with_source(root);
println!("{}", wrapped.root_cause()); // 输出根因

// 匹配错误码
match err.code() {
    Errc::NotFound => { /* 处理未找到 */ }
    Errc::InvalidState => { /* 处理非法状态 */ }
    _ => {}
}
```

常用错误码：`InvalidArgument` / `NotFound` / `InvalidState` / `IoError` / `Timeout` / `NotImplemented` / `PlatformError` / `OutOfMemory`。

严重级别：`ErrorSeverity::Debug`（仅调试）/ `Info` / `Warning` / `Error` / `Fatal`（触发崩溃报告，写入 `uix_crash.log` 后终止进程）。

### DI 容器

框架内置轻量依赖注入容器，用于管理应用级单例服务：

```rust
use uix::prelude::*;

// 注册
let mut container = DiContainer::new();
container.singleton(42i32);
container.singleton("config_value".to_string());

// 解析（在 on_start 中通过 AppHandle）
handle.resolve::<SettingsService>();  // 框架已注册
handle.resolve::<i32>();              // 自定义注册

// has 检查
container.has::<f64>();               // false
```

框架预注册的服务：`SettingsService`、`FontService`、`ImageService`。自定义服务通过 `App.on_start` 中的 `handle` 注册。

### 国际化（Locale）

UIX 内置中英文国际化预设，覆盖 30+ 组件的文案（日历、分页、上传、弹窗等）。默认使用中文：

```rust
use uix::prelude::*;

// 全局设为英文
App::new()
    .locale(en_us())
    .root(|| app_view)
    .run();

// 子树覆写
LocaleProvider::new(zh_cn())
    .child(|| subtree_view)
```

| 函数 | 语言 |
|------|------|
| `zh_cn()` | 简体中文（默认） |
| `en_us()` | English |

在 `component!` 渲染中通过 `use_locale()` 读取当前生效的文案：

```rust
let loc = use_locale();
ctx.draw_text(loc.ok_text, pos, color, 14.0);
```

自定义 `Locale` 可直接构造结构体，覆盖所需字段即可。

### 剪贴板

从事件回调中读取或写入系统剪贴板：

```rust
// 写入
copy_to_clipboard("https://example.com");

// 读取
if let Some(text) = read_text_from_clipboard() {
    // 使用 text
}
```

仅在事件分发期间有效（受框架词法作用域托管）；无活动事件时为 no-op。

### ConfigProvider —— 组件级配置

借鉴 Ant Design 的 `ConfigProvider`（[antd 文档](https://ant.design/components/config-provider-cn)），UIX 支持组件树层级的配置继承——子树内所有组件自动获取上级配置，无需逐组件传参：

```rust
App::new()
    .config(Config::new()
        .component_size(Size::Middle)  // 全局默认尺寸
        .theme(Theme::antd_light())
    )
    .run();

// 子树覆写
ConfigProvider::new()
    .component_size(Size::Small)       // 仅此子树
    .render_empty(|| {
        column((icon("inbox").size(64.0), label("暂无数据"))).gap(8.0)
    })
    .child(|| compact_form)
```

### 组件尺寸系统

配合 `ConfigProvider`，Button、Input、Select、Table、DatePicker 等 10+ 组件支持统一的 `size()` 方法：

```rust
button("小").size(Size::Small)     // 紧凑型
button("中").size(Size::Middle)   // 标准（默认）
button("大").size(Size::Large)    // 宽松型
```

| Size | 高度 | 字号 | 内边距 |
|------|------|------|--------|
| `Small` | 24 | `font_size_sm` | `padding_xs` |
| `Middle` | 32 | `font_size` | `padding` |
| `Large` | 40 | `font_size_lg` | `padding_lg` |

映射值取自 `DesignTokens` 中 `control_height_sm` / `control_height` / `control_height_lg`，亮暗主题自动跟随。未显式传 `size()` 时继承 `ConfigProvider` 的 `component_size` 设定。

### 组件级令牌覆写

在 `ConfigProvider` 中按组件名覆写令牌，子树内该组件的默认配色跟随覆写：

```rust
ConfigProvider::new()
    .theme_override(|tokens| tokens
        .override_component("Button", |t| {
            t.color_primary = Color::hex("#00b96b");
            t.border_radius = 6.0;
        })
        .override_component("Table", |t| {
            t.color_bg_container = Color::hex("#fafafa");
        })
    )
    .child(|| app_content)
```

在 `component!` 的 `render` 中通过 `ctx.tokens()` 自动获取覆写后的值，无需额外处理。


## 组件

### 函数组件

最轻量：抽取函数返回 `impl View`：

```rust
fn user_card(name: &str, role: &str) -> impl View {
    column((
        label(name).font_size(16.0).font_weight(FontWeight::BOLD),
        label(role).font_size(12.0).fg(Color::gray()),
    ))
    .gap(4.0)
    .padding(12.0)
    .bg(Color::rgba(248, 248, 248, 255))
    .radius(8.0)
}
```

用于纯组合已有组件，无自定义绘制或事件。

### canvas —— 轻量自定义绘制

只需像素级绘制（无独立 measure / 事件），比 `component!` 更轻：

```rust
fn color_dot(color: Color, diameter: f32) -> impl View {
    canvas(diameter, diameter, move |frame, ctx| {
        let center = frame.center();
        ctx.fill_circle(center.x, center.y, diameter / 2.0, color);
    })
}
```

宽高使用 logical 像素并受父约束裁定。闭包只在该节点需要绘制时执行；其中读取 `State` / `Computed` 会自动绑定到本节点 Paint 脏区，无需手工请求 frame。需要独立 measure、事件或子节点时改用 `component!`。

### component! —— 完整自定义组件

需要 measure / render / on_event / 子节点时使用：

```rust
component! {
    /// 自定义进度环。
    pub struct ProgressRing {
        progress: f32,   // 0.0..1.0
        size: f32,
    }

    measure => (&self, constraints: Constraints) -> Size {
        constraints.clamp(Size::new(self.size, self.size))
    }

    render => (&self, frame: Rect, ctx: &mut PaintContext, _tree: &WidgetTree) {
        let color = ctx.tokens().color_primary();
        // 背景环
        let center = frame.center();
        ctx.stroke_circle(center.x, center.y, self.size / 2.0 - 4.0,
            color.with_alpha(51), 4.0);
        // 进度弧
        let end = self.progress * std::f32::consts::TAU;
        ctx.stroke_arc(center.x, center.y, self.size / 2.0 - 4.0,
            0.0, end, color, 4.0);
    }
}

// 使用
ProgressRing { progress: 0.65, size: 80.0 }
```

`component!` 自动生成 reconciliation 逻辑。可定义的方法：

| 方法 | 用途 |
|------|------|
| `measure` | 给定约束，返回尺寸 |
| `render` | 像素绘制（通过 `PaintContext`） |
| `build` | 返回子节点（`Vec<Box<dyn WidgetComponent>>`） |
| `on_event` | 接收 `SystemEvent`，返回是否消费 |
| `on_update` | 每帧调用，`dt` 为秒——在此推进 `Animation<T>` |
| `on_mount` | 首次挂载到树中 |
| `on_unmount` | 从树中移除前（清理资源） |
| `wants_continuous_pointer_move` | 是否接收逐帧 PointerMove（默认 false） |

### PaintContext 速查

`render` 方法通过 `ctx: &mut PaintContext` 绘制：

| 方法 | 说明 |
|------|------|
| `ctx.fill_rect(rect, color, radius)` | 填充矩形，可选圆角 |
| `ctx.stroke_rect(rect, color, lw, radius)` | 描边矩形 |
| `ctx.fill_circle(cx, cy, r, color)` | 填充圆形 |
| `ctx.stroke_circle(cx, cy, r, color, lw)` | 描边圆形 |
| `ctx.stroke_arc(cx, cy, r, lw, start_deg, end_deg, color)` | 描边圆弧（角度制） |
| `ctx.fill_path(path, color, fill_rule)` | 填充路径 |
| `ctx.stroke_path(path, color, options)` | 描边路径 |
| `ctx.draw_line(x1, y1, x2, y2, color, lw)` | 直线 |
| `ctx.draw_text(text, x, y, font_size, color)` | 文本 |
| `ctx.tokens()` | 获取当前主题 `DesignTokens`（颜色、字号等） |

坐标均相对于组件自身 frame 左上角。

含子节点的组件：

```rust
component! {
    pub struct Card {
        children: WidgetChildren,
    }

    build => (&self) -> Vec<Box<dyn WidgetComponent>> {
        self.children.take()
    }

    render => (&self, frame: Rect, ctx: &mut PaintContext, _tree: &WidgetTree) {
        ctx.fill_rect(frame, &Color::WHITE, Radius::new(8.0));
    }
}
```

### 指针移动优化

同一 hit 目标上连续 `PointerMove` 不每帧触发重绘——仅 hover 目标变化时标脏。需要逐帧 PointerMove 的组件（Slider、拖拽选区）应 opt-in：

```rust
component! {
    pub struct MySlider {
        min: f32,
        max: f32,
    }

    wants_continuous_pointer_move => (&self) -> bool { true }
}
```

虚拟列表（万级数据，只渲染可视区）：

```rust
VirtualScroll::new()
    .item_count(10_000)       // 数据总量
    .item_height(32.0)         // 每行固定高度（px）
    .size(320.0, 480.0)        // 视口尺寸
    .overscan(5)               // 可视区外预渲染行数（默认 5）
```

### 色板

框架内置仿 Ant Design 5 的色板体系——**12 个主色 × 每色 10 阶衍生色 = 共 120 色**。设计令牌 (`DesignTokens`) 由色板派生，亮/暗切换时自动跟随：

```rust
fn my_page(tk: &DesignTokens) -> impl View {
    column((
        // 文字层级
        label("标题").fg(tk.color_text).font_size(18.0),
        label("次要").fg(tk.color_text_secondary).font_size(14.0),
        label("辅助").fg(tk.color_text_tertiary).font_size(12.0),
        label("禁用").fg(tk.color_text_quaternary).font_size(12.0),

        // 语义色
        label("成功").fg(tk.color_success),
        label("警告").fg(tk.color_warning),
        label("错误").fg(tk.color_error),
        label("信息").fg(tk.color_info),

        // 主色
        label("强调").fg(tk.color_primary),
    ))
    .gap(12.0)
    // 背景层级
    .bg(tk.color_bg_elevated)
    .radius(tk.border_radius)
    .border(1.0, tk.color_border_secondary)
}
```

在 `component!` 的 `render` 中通过 `ctx.tokens()` 获取：

```rust
render => (&self, frame: Rect, ctx: &mut PaintContext, _tree: &WidgetTree) {
    let primary = ctx.tokens().color_primary();
    let text    = ctx.tokens().color_text();
    let bg      = ctx.tokens().color_bg();
}
```

#### 12 主色

| 索引 | 色名 | 基调 |
|------|------|------|
| 0 | Red | 红 |
| 1 | Volcano | 橙红 |
| 2 | Orange | 橙 |
| 3 | Gold | 金 |
| 4 | Yellow | 黄 |
| 5 | Lime | 青柠 |
| 6 | Green | 绿 |
| 7 | Cyan | 青 |
| 8 | Blue | 蓝（品牌主色） |
| 9 | Geekblue | 极客蓝 |
| 10 | Purple | 紫 |
| 11 | Magenta | 品红 |

每个主色含 10 阶衍生色（1–10），如 `blue-1`（最浅）到 `blue-10`（最深），共 120 色。

#### 中性色

中性色由 3 个基色派生——`bg`（底色）、`text`（文字基色）、`border`（边框基色），亮/暗模式下各自推算层级：

| 基色 | 派生令牌 |
|------|----------|
| `bg` | `color_bg` → `_container` → `_elevated` → `_layout` → `_overlay` → `_spotlight` → `_mask` |
| `text` | `color_text` → `_secondary` → `_tertiary` → `_quaternary`（逐级降低 alpha） |
| `text` | `color_fill` → `_secondary` → `_tertiary` → `_quaternary`（逐级降低 alpha） |
| `border` | `color_border` → `_secondary` |

#### View 令牌速查

```
文字层级:   color_text / _secondary / _tertiary / _quaternary
背景层级:   color_bg / _container / _elevated / _layout
语义色:     color_primary / _success / _warning / _error / _info
语义背景:   color_primary_bg / _success_bg / _warning_bg / _error_bg / _info_bg
边框:       color_border / _secondary
填充:       color_fill / _secondary / _tertiary
设计参数:   border_radius / _sm / _lg
```

所有令牌色实现了 `Color`，可与自定义 `Color::rgba()` / `Color::hex()` 混用：

```rust
// 主题感知底色 + 自定义强调色边框
view
    .bg(tk.color_bg_container)
    .border(2.0, Color::from_rgb(64, 150, 255))
```

#### 当前覆盖

框架已落地的部分：

- **品牌主色**：12 主色槽位已定义，当前以 Blue（索引 8）为品牌主色
- **基色推导**：5 个语义基色（primary / success / warning / error / info）+ 3 个中性基色（bg / text / border）自动推算亮/暗两套 DesignTokens
- **亮暗双模**：`antd_light()` / `antd_dark()` 预设，`with_brand_primary()` 快速换品牌色

对比 Ant Design 5 完整色彩体系，以下尚未提供（框架后续迭代补充）：

- **120 色色板数据**：12 主色 × 10 阶衍生色（如 `blue-0`~`blue-9`）未作为显式色板数组暴露
- **中性灰阶**：AD5 的 13 级灰阶（`gray-0`~`gray-12`）未提供，当前中性色通过 bg / text / border 三基色 + alpha / mix 动态推算
- **功能色阶**：success / warning / error / info 各仅有单色 + bg + border，无 10 阶功能色板（如 `success-0`~`success-9`）
- **色板生成 API**：给定任一主色自动生成 10 阶衍生色的工具未对用户暴露
- **数据可视化色板**：未提供

### 表单

字段校验闭包直接定义，返回 `Result<(), String>`：

```rust
let form = Form::new()
    .field("user", "用户名")
        .default("")
        .required("请输入用户名")
        .custom(|v| if v.len() < 3 {
            Err("至少 3 个字符".into())
        } else { Ok(()) })
    .field("email", "邮箱")
        .default("")
        .required("请输入邮箱")
        .validate_email("邮箱格式不正确")
    .field("age", "年龄")
        .default(0i32)
        .validate_range(1..=120, "年龄范围 1-120")
    .build();

match form.validate() {
    Ok(values) => {
        let user  = values.get::<String>("user").unwrap();
        let email = values.get::<String>("email").unwrap();
        // 提交
    }
    Err(errors) => {
        // errors: Vec<(field_key, error_message)>
        for (field, msg) in &errors {
            eprintln!("{field}: {msg}");
        }
    }
}
```

内置校验规则：

| 方法 | 说明 |
|------|------|
| `.required(msg)` | 非空 |
| `.validate_email(msg)` | 邮箱格式 |
| `.validate_range(0..=100, msg)` | 数值范围 |
| `.validate_length(2..=20, msg)` | 字符串长度 |
| `.validate_pattern(regex, msg)` | 正则 |
| `.custom(\|v\| Result<(), String>)` | 自定义逻辑 |

校验触发时机（默认 `OnSubmit`，可改为失焦/输入即校验）：

```rust
Form::new()
    .field("email", "邮箱")
        .default("")
        .required("请输入邮箱")
        .validate_email("格式不正确")
        .validate_trigger(Trigger::OnBlur)    // 失焦即校验
    .field("username", "用户名")
        .default("")
        .required("必填")
        .validate_trigger(Trigger::OnChange)  // 输入即校验
    .build();
```

字段间依赖校验（被依赖字段变更后级联校验）：

```rust
Form::new()
    .field("password", "密码")
        .default("")
        .required("请输入密码")
    .field("confirm", "确认密码")
        .default("")
        .depends_on("password", |v, deps| {
            let pwd = deps.get::<String>("password").unwrap();
            if v != pwd { Err("两次密码不一致".into()) } else { Ok(()) }
        })
    .build();
```

动态表单（`Form::List`——增删表单行）：

```rust
let list = Form::new()
    .list("items", |items| {
        items
            .field("name", "名称").required("必填")
            .field("qty", "数量").validate_range(1..=100, "1-100")
    })
    .build();
// list.add_item() / list.remove_item(index) → 自动 reconcile 子组件树
```

### 无障碍

通过 `AccessibilityRole`、`AccessibilityState` 和 `AriaAttribute` 为视图标注语义，框架自动生成语义树供屏幕阅读器和 Agent Bridge 消费：

```rust
view
    .role(AccessibilityRole::Button)
    .aria(AriaAttribute::Label, "提交表单")
    .aria(AriaAttribute::Description, "点击后将数据发送到服务器")

// 组件自带默认 role（Button→Button、Input→TextInput 等），通常无需手动设置
```

`AccessibilityState` 表示组件的当前语义状态，由组件属性自动派生：

| 字段 | 类型 | 来源示例 |
|------|------|---------|
| `disabled` | `bool` | `Button::new(...).disabled(true)` |
| `checked` | `Option<bool>` | `Checkbox::checked(&state)`、`Switch::checked(&state)` |
| `value_text` | `Option<String>` | `Select::value(&state)` 当前选中项 |
| `value_now` | `Option<f64>` | `Slider::value(&state)`、`ProgressBar::progress` |
| `value_min` / `value_max` | `Option<f64>` | `Slider::new(min..=max)`、`Rate::count` |
| `multiline` | `bool` | `Input::textarea()` |
| `password` | `bool` | `Input::password()`（敏感，不导出语义快照） |
| `required` | `bool` | `FormItem::new(...).required(true)` |

自定义组件通过 `SnapshotFields` 返回对应的 `AccessibilityState`；测试中可直接构造 `AccessibilitySnapshot`：

```rust
AccessibilitySnapshot::named(AccessibilityRole::Button, "提交")
    .with_state(AccessibilityState::disabled(true))
```

可用 role：`Button` / `TextInput` / `Checkbox` / `Radio` / `Switch` / `Slider` / `Link` / `Image` / `Heading` / `List` / `ListItem` / `Table` / `Tab` / `Dialog` / `Alert` / `ProgressBar` / `None`（不暴露给语义树）。

框架自动处理 `Tab` / `Shift+Tab` 键盘导航，浮层内受 focus trap 约束。password 等敏感字段自动排除出语义快照。

## 动画

UIX 提供泛型逐帧动画系统，由框架自动推进 `dt`（秒），窗口不可呈现时暂停、恢复首帧重基。**勿用 `run_interval` 模拟帧动画。**

### Animation\<T\> —— 泛型插值

`Animation::new(from, to, duration)` 创建从 `from` 到 `to` 的插值动画，支持任意 `Animatable` 类型（内置 `f32`、`f64`、`Color`、`Point`、`Rect`）。

```rust
let anim = Animation::new(0.0, 1.0, 0.3)  // from, to, seconds
    .easing(Easing::ease_out);
```

| 方法 | 作用 |
|------|------|
| `anim.value()` | 当前插值（不推进时间） |
| `anim.update(dt)` | 推进 `dt` 秒，返回当前插值 |
| `anim.is_finished()` | 是否已完成 |
| `anim.progress()` | 进度 [0, 1] |
| `anim.restart()` | 从起点重新播放 |
| `anim.stop()` | 跳到终态并停止 |
| `anim.pause()` / `anim.resume()` | 暂停 / 继续 |
| `anim.reverse()` | 交换 from/to 并重新播放 |
| `anim.on_finish(\|\| { ... })` | 完成回调（播放到终态时触发） |

用于视图属性：

```rust
label("淡入")
    .opacity(anim.value() as f32)

// 颜色动画
let color_anim = Animation::new(Color::RED, Color::BLUE, 0.5)
    .easing(Easing::ease_in_out);
circle().fill_color(color_anim.value())
```

### Easing —— 缓动曲线

```rust
// 基础
Easing::linear
Easing::ease_in          // quad in
Easing::ease_out         // quad out
Easing::ease_in_out      // quad in-out

// 加强
Easing::cubic_in
Easing::cubic_out
Easing::cubic_in_out

// 弹性
Easing::bounce           // 弹跳缓出
Easing::elastic          // 弹性缓出

// 自定义三次贝塞尔
Easing::cubic_bezier(x1, y1, x2, y2)
```

### 浮层进出场动画

Modal / Drawer / Notification / Message / Popover 支持 enter + leave 两段式动画，对标 antd：

```rust
// Modal 弹出/关闭
Modal::show(|| content)
    .enter_animation(AnimationConfig::fade_in(0.2))
    .leave_animation(AnimationConfig::fade_out(0.15))

// Drawer 滑入/滑出
Drawer::show(|| content)
    .enter_animation(AnimationConfig::slide_in(Placement::Right, 0.25))
    .leave_animation(AnimationConfig::slide_out(Placement::Right, 0.2))

// Notification 通知
Notification::open(
    NotificationItem::info("标题", "内容")
)
    .enter_animation(AnimationConfig::fade_in(0.15))
    .leave_animation(AnimationConfig::fade_out(0.1))

// Message 消息
Message::success("操作成功")
    .enter_animation(AnimationConfig::slide_in(Placement::Top, 0.2))
    .leave_animation(AnimationConfig::fade_out(0.15))
```

`AnimationConfig` 预设：

| 方法 | 效果 |
|------|------|
| `AnimationConfig::fade_in(duration)` | 淡入（opacity 0→1） |
| `AnimationConfig::fade_out(duration)` | 淡出（opacity 1→0） |
| `AnimationConfig::slide_in(placement, duration)` | 方向滑入（含位移 + 淡入） |
| `AnimationConfig::slide_out(placement, duration)` | 方向滑出（含位移 + 淡出） |
| `AnimationConfig::zoom_in(duration)` | 缩放弹出（scale 0.8→1 + 淡入） |
| `AnimationConfig::zoom_out(duration)` | 缩放收起（scale 1→0.8 + 淡出） |

`placement` 为 `Placement::Top | Bottom | Left | Right`，控制滑动方向。

leave 动画播放完毕后自动从 `OverlayStack` 移除节点；窗口 `Suspended` 时冻结。

### 自定义组件动画

在 `component!` 宏中通过 `on_update` 生命周期驱动 `Animation<T>`：

```rust
component! {
    pub struct FadeBox {
        animation: Animation<f32>,
    }

    fn on_update(&mut self, dt: f64) {
        self.animation.update(dt);
    }

    fn render(&self) -> impl View {
        container(self.children())
            .opacity(self.animation.value())
    }
}
```

## 多窗口

窗口客户区尺寸、布局、指针与 resize 都使用 logical 坐标；每窗 drawable 随所在显示器的 DPI 独立变化。应用无需监听 DPI 消息或手工缩放窗口内容。

在 `on_start` 中获取句柄：

```rust
App::new()
    .on_start(|handle| {
        // 打开第二个窗口
        let _win2 = handle.open_window(
            WindowConfig::new()
                .title("子窗口")
                .size(400, 300)
                .root(|| label("我是第二窗口"))
        );
    })
    .root(|| label("主窗口"))
    .run();
```

窗口间通信通过各自 `AppHandle`：

```rust
// 窗口 A
handle_a.run_after(Duration::from_secs(1), move || {
    // 向窗口 B 发消息
    handle_b.post_to_ui(|| { /* 更新 B 的状态 */ });
});
```

## 定时与异步

### 定时器

```rust
// 延时执行
let timer = handle.run_after(Duration::from_secs(2), || {
    // 2 秒后执行
});

// 周期执行
let timer = handle.run_interval(Duration::from_millis(100), || {
    // 每 100ms 执行
});

// drop 自动取消；需存活则 detach
timer.detach();       // 不受 drop 影响
timer.cancel();       // 显式取消
```

### 跨线程回 UI

从任意线程更新 UI 状态，只走 `post_to_ui`：

```rust
let handle_clone = handle.clone();
std::thread::spawn(move || {
    let result = heavy_computation();
    handle_clone.post_to_ui(move || {
        data.set(result);
    });
});
```

`post_to_ui` 绑目标窗口的 `WindowSession`，不会唤醒其他窗口。

## 测试

### TestApp —— 无窗测试

```rust
use uix::prelude::*;

#[test]
fn test_counter() {
    let count = State::new(0);
    let root_count = count.clone();

    let mut app = uix::ui::test_harness::TestApp::new((400.0, 300.0), move || {
        let count = root_count.clone();
        row((
            count.map_text(|n| format!("{n}")).automation_id("counter.label"),
            button("+1").on_click(&count, |c| c.update(|v| *v += 1)).automation_id("counter.inc"),
        ))
    });

    assert_eq!(count.get(), 0);

    app.click("counter.inc").unwrap();
    app.settle().unwrap();  // 有界等待直接 State 修改等 pending work

    assert_eq!(count.get(), 1);
    assert_eq!(app.text("counter.label").unwrap(), "1");
}
```

可用查询：`.snapshot()` `.text(id)`。可用操作：`.click(id)` `.type_text(id, "text")` `.press_key(KeyCode::Enter, KeyMod::NONE)` `.select(id, index)` `.invoke(id)`（通用语义动作）。动作完成时已自动 settle；直接修改 State 后可显式 `.settle()`。

所有操作走真实 semantic / `SystemEvent` 路径，受可见性与 modal 约束。

### ComponentHandle —— 组件句柄

通过 ID 获取组件的只读快照或发送事件，适用于跨组件交互与测试断言：

```rust
// 从 TestApp 获取
let app = TestApp::new((400, 300), || button("OK").automation_id("btn"));
let handle = app.handle("btn").unwrap();

// 从 AppState 获取
let app_state = app.app_state();
let handle = app_state.get_handle(component_id).unwrap();
```

查询方法：

| 方法 | 返回 | 适用组件 |
|------|------|----------|
| `.text()` | `Option<String>` | Button、Label |
| `.checked()` | `Option<bool>` | Checkbox、Switch |
| `.disabled()` | `Option<bool>` | Button、Input、Select 等 |
| `.numeric_value()` | `Option<f64>` | Slider、Progress、Rate、InputNumber |
| `.placeholder()` | `Option<String>` | Input、Select、DatePicker 等 |
| `.is_alive()` | `bool` | 是否仍在树中 |
| `.snapshot()` | `Option<ComponentConfigSnapshot>` | 完整快照 |
| `.accessibility()` | `Option<AccessibilitySnapshot>` | 无障碍信息 |

交互方法：

| 方法 | 说明 |
|------|------|
| `.invalidate()` | 标记重绘 |
| `.emit(event)` | 发送 `SemanticEvent`，返回 `EventResult` |

### AppState —— 跨线程组件状态

`AppState` 维护一份与 WidgetTree 同步的组件快照表，可在任意线程中通过 `ComponentHandle` 安全读取与交互：

```rust
// 从 App 获取（UI 线程）
let app_state = app.app_state();
let handle = app_state.get_handle(component_id);
let snapshot = app_state.get_snapshot(component_id);

// 从 AppHandle 获取（后台线程）
handle.post_to_ui(move || {
    let app_state = handle.app_state();
    // ...
});
```

测试中 `TestApp` 已内置 `AppState` 管理，通常无需手动创建。

### 快照类型

`ComponentConfigSnapshot` 提供组件的结构化只读表示：

- `.fields` → `SnapshotFields`（60+ 组件变体，含各组件特有字段）
- `.accessibility()` → `AccessibilitySnapshot`（role、state、aria）
- `.selection()` → `Option<SelectionSnapshot>`（选项列表、选中索引、禁用索引、多选/展开状态）

`SelectionSnapshot` 用于 Select、Cascader、TreeSelect 等选择类组件的选项状态只读。

### 真窗快照

设置环境变量 `UIX_AUTOMATION_DIR`，真窗运行时每窗输出 JSON 快照（`revision` / `presented_revision`），空闲不轮询。关闭写 `closed: true`。password 字段不导出。
