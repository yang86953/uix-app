# 使用

> 怎样用 UIX 写应用（不必关心框架内部）。

入口：`use uix::prelude::*`。可复制示例 → [README](../README.md#示例)；能力展示 → [`demo`](../demo/README.md)；导出一览 → [`prelude.rs`](../src/prelude.rs)。

> ⚠️ **Windows P6 gate 未闭合。** 下方为框架目标写法。已验证稳定：View + State + 组件声明式、布局、主题、多窗、定时器、`test-harness`、微软拼音 IME、Windows 前台系统 Tab、浮层 focus trap、隐藏/最小化及 D3D11 bitblt 遮挡休眠。验证中：图形 fault/recovery 与真机矩阵。详见[进度](进度.md)。

## 快速开始

`Cargo.toml`：

```toml
[dependencies]
uix = { path = "../uix-app" }
```

当前 crate 设为 `publish = false`，尚未发布到 crates.io；`path` 请改成应用仓库到本仓库的实际相对路径。

第一个应用：

```rust uix-compile=quick-start-hello
use uix::prelude::*;

fn main() {
    App::new()
        .title("Hello UIX")
        .size(400, 300)
        .root(|| label("Hello, world!").font_size(32.0))
        .run();
}
```

带交互的计数器：

```rust uix-compile=quick-start-counter
use uix::prelude::*;

fn main() {
    let count = State::new(0);

    App::new()
        .title("计数器")
        .size(360, 200)
        .root(move || {
            column((
                count.map_text(|n| format!("{n}")).font_size(48.0),
                row((
                    button("-1").on_click(&count, |c| c.update(|v| *v -= 1)),
                    button("+1").primary().on_click(&count, |c| c.update(|v| *v += 1)),
                )).gap(8.0),
            ))
            .gap(16.0)
            .padding(24.0)
        })
        .run();
}
```

## 核心概念

### State —— 响应式状态

```rust uix-compile=state-basics
let count = State::new(0);       // 创建
count.set(5);                     // 写入
count.update(|v| *v += 2);       // 基于旧值更新
let val: i32 = count.get();      // 读取
```

写入 `State` 会标记受影响的视图，由框架合并为至多一次重绘。高频写入不自动节流——用 `run_interval` 或动画驱动周期性变化。

### Computed —— 派生状态

自动追踪依赖，惰性求值，仅在依赖变化时重算：

```rust uix-compile=computed-full-name
let first = State::new("Ada");
let last  = State::new("Lovelace");
let full  = Computed::new(move || format!("{} {}", first.get(), last.get()));

// 映射到视图
full.map_text(|s| s.clone()).font_size(20.0);
```

`map` / `map_text` / `map_opt` 将 `Computed<T>` 转为响应式 View：

| 方法 | 输入 | 输出 |
|------|------|------|
| `.map(\|v\| view)` | `T` → `impl View` | 依赖变化时重建子视图 |
| `.map_text(\|v\| format!(…))` | `T` → `String` | 常用简写 |
| `.map_opt(\|v\| Option<impl View>)` | `T` → `Option<impl View>` | 条件渲染 |

`map` / `map_opt` 放在 `App::root` 的构建闭包内，依赖变化时由框架请求结构 reconcile；`map_text` 只失效对应文本的绘制。

### Effect —— 副作用

依赖变化时执行（不产生视图）：

```rust uix-compile=effect-dependency
let count = State::new(0);
let watched_count = count.clone();

Effect::new(move || {
    println!("count 变为 {}", watched_count.get());
    // 自动追踪 count
});
```

Effect 在事件轮次末尾、重绘之前批量执行。

### View —— 组合模型

所有界面元素实现 `View` trait，通过组合构建 UI 树：

```rust uix-compile=conditional-and-list
// 条件渲染
let visible = true;
let conditional = column(show(visible, label("可见内容")));

// 列表渲染（少量项目）
let items = ["Ada", "Alan", "Grace"];
let list = column(items.iter().enumerate().map(|(i, item)| {
    label(*item).automation_id(format!("item-{i}"))
}).collect::<Vec<_>>());

// 大量列表 → VirtualScroll（见后文）
```

`Option<impl View>` 自动处理 `None`（不渲染）和 `Some(view)`（渲染）。

### Error —— 错误处理

所有框架 API 返回 `Result<T, Error>`。`Error` 为 typed 错误类型，含错误码、严重级别、消息及源链：

```rust uix-compile=typed-errors
use uix::prelude::*;

// 创建错误
let err = Error::new(Errc::InvalidArgument, "输入不能为空");
let err = Error::not_found("config.json");
let err = Error::invalid_state("窗口已销毁");

// 设置严重级别
let fatal = Error::invalid_state("窗口已销毁").set_severity(ErrorSeverity::Fatal);

// 链式错误（保留根因）
let root = Error::new(Errc::IoError, "磁盘满");
let wrapped = Error::new(Errc::WriteFailure, "写入失败").with_source(root);
println!("{}", wrapped.root_cause()); // 输出根因
println!("{}", wrapped.what());       // 输出当前错误与完整原因链
println!("{}", wrapped.short_what()); // 单行简述，不展开原因链

// 匹配错误码
match err.code() {
    Errc::NotFound => { /* 处理未找到 */ }
    Errc::InvalidState => { /* 处理非法状态 */ }
    _ => {}
}
```

常用错误码：`InvalidArgument` / `NotFound` / `InvalidState` / `IoError` / `Timeout` / `NotImplemented` / `PlatformError` / `OutOfMemory`。

严重级别：`ErrorSeverity::Info` / `Warning` / `Error` / `Fatal`；`fatal(...)` 崩溃处理路径会写入 `uix_crash.log` 后终止进程，单独构造 `Fatal` 值不会自行终止。

### DI 容器

框架内置轻量依赖注入容器，用于管理应用级单例服务：

```rust uix-compile=app-singletons
use uix::prelude::*;

App::new()
    .singleton(42i32)
    .singleton("config_value".to_string())
    .on_start(|handle| {
        let number: Option<i32> = handle.resolve();
        let text: Option<String> = handle.resolve();
        // SettingsService 仅在调用 .settings(path) 后可解析
    });
```

自定义服务在运行前通过 `App::singleton` 注册；`AppHandle` 只负责解析。`SettingsService` 仅在 `.settings(path)` opt-in 后注册；字体与图片服务由图形运行时托管，不属于公开 DI 单例。

### 国际化（Locale）

UIX 内置中英文国际化预设，覆盖 30+ 组件的文案（日历、分页、上传、弹窗等）。默认使用中文：

```rust uix-compile=locale-provider
use uix::prelude::*;

fn app_view() -> ViewNode {
    label("English root")
}

// 全局设为英文
App::new()
    .locale(en_us())
    .root(app_view)
    .run();

// 子树覆写
LocaleProvider::new(zh_cn())
    .child(|| label("中文子树"));
```

| 函数 | 语言 |
|------|------|
| `zh_cn()` | 简体中文（默认） |
| `en_us()` | English |

在 `component!` 渲染中通过 `use_locale()` 读取当前生效的文案：

```rust uix-compile=locale-current
let loc = use_locale();
let ok_text: &str = loc.ok_text;
```

自定义 `Locale` 可基于预设覆写所需字段：

```rust uix-compile=locale-custom
let locale = Locale {
    ok_text: "确认",
    cancel_text: "返回",
    ..zh_cn()
};
```

### 剪贴板

从事件回调中读取或写入系统剪贴板：

```rust uix-compile=clipboard-event
// 写入
copy_to_clipboard("https://example.com");

// 读取
if let Some(text) = read_text_from_clipboard() {
    // 使用 text
}
```

仅在事件分发期间有效（受框架词法作用域托管）；无活动事件时为 no-op。

### ConfigProvider —— 组件级配置

借鉴 Ant Design 的 `ConfigProvider`（[antd 文档](https://ant.design/components/config-provider-cn)），UIX 支持组件树层级的配置继承——子树内所有组件自动获取上级配置，无需逐组件传参：

```rust uix-compile=config-provider
fn compact_form() -> ViewNode {
    input().placeholder("compact").build()
}

App::new()
    .config(Config::new()
        .component_size(ControlSize::Medium)
        .disabled(false))
    .root(|| {
        ConfigProvider::new()
            .component_size(ControlSize::Small) // 仅此子树
            .child(compact_form)
            .build()
    })
    .run();
```

`ConfigProvider` 只覆写显式设置的字段；其余字段继承外层 Provider 或 `App::config`。优先级为组件显式 setter > 最近 `ConfigProvider` > `App::config` > 框架默认。

### 组件尺寸系统

统一尺寸类型是 `ControlSize::{Small, Medium, Large}`。产品所列输入组件及 `List`、`Descriptions`、`Modal`、`Drawer` 均读取 Provider 默认值；组件显式 setter 可局部覆盖：

```rust uix-compile=config-sizes
Input::new("名称").size(ControlSize::Small);
Button::new("保存").size(ControlSize::Large);
InputNumber::new().size(ControlSize::Small);
Select::new().size(ControlSize::Large);
Checkbox::new("同意").size(ControlSize::Small);
Switch::new().size(ControlSize::Large);
Radio::new().size(ControlSize::Small);
Segmented::new(["日", "周"]).size(ControlSize::Large);
Slider::new(0.0..=100.0).size(ControlSize::Small);
Rate::new().size(ControlSize::Large);
DatePicker::new().size(ControlSize::Small);
DateRangePicker::new().size(ControlSize::Large);
TimePicker::new().size(ControlSize::Small);
ColorPicker::new().size(ControlSize::Large);
List::new().size(ControlSize::Medium);
Descriptions::new().size(ControlSize::Large);
Modal::new("详情").modal_size(ControlSize::Large);
Drawer::new("筛选").drawer_size(ControlSize::Small);
```

`disabled` 默认值当前由 `button()` / `Button`、`Input`、`Select`、`InputNumber` 读取。显式 `.disabled(...)` 同样优先于 Provider 默认值。

### 组件构造覆盖

`ComponentOverrides` 在组件构造时应用；局部 Provider 未设置 `overrides` 时继承外层值：

```rust uix-compile=component-overrides
fn payment_form() -> ViewNode {
    input().placeholder("amount").build()
}

let mut overrides = ComponentOverrides::default();
overrides.input.prefix = Some("¥".into());
overrides.input.suffix = Some("CNY".into());
overrides.select.allow_search = Some(true);

ConfigProvider::new()
    .overrides(overrides)
    .child(payment_form);
```

### 组件令牌与空态 View

`component_tokens::<T>` 用 typed `TokenPatch` 覆写指定组件类型；未设置字段继续读取当前子树主题。`render_empty` 接收 View factory，`List` / `Table` 在作为普通 View 直接组合且数据为空时自动调用：

```rust uix-compile=config-theme-empty
fn configured_empty(context: EmptyContext) -> impl View {
    label(format!("{} 暂无数据", context.component_name()))
}

ConfigProvider::new()
    .component_tokens::<Button>(TokenPatch {
        color_primary: Some(Color::rgba(22, 119, 255, 255)),
        border_radius: Some(8.0),
        ..TokenPatch::default()
    })
    .render_empty(configured_empty)
    .child(|| column((
        button("保存"),
        List::new(),
        Table::new(),
    )));
```

`embed(...)` 是直接嵌入底层 widget 的高级互操作入口，不执行 View 级空态替换；需要统一空态时直接组合 `List` / `Table` 或其 builder。


## 组件

### 函数组件

最轻量：抽取函数返回 `impl View`：

```rust uix-compile=function-component
fn user_card(name: &str, role: &str) -> impl View {
    column((
        label(name).font_size(16.0),
        label(role).font_size(12.0).color(Color::gray()),
    ))
    .gap(4.0)
    .padding(12.0)
    .bg(Color::rgba(248, 248, 248, 255))
    .radius(8.0)
}
```

用于纯组合已有组件，无自定义绘制或事件。

### canvas —— 轻量自定义绘制

只需像素级绘制（无独立 measure / 事件），比 `component!` 更轻：

```rust uix-compile=canvas-component
fn color_dot(color: Color, diameter: f32) -> impl View {
    canvas(diameter, diameter, move |frame, ctx| {
        let center = Point::new(frame.x + frame.w * 0.5, frame.y + frame.h * 0.5);
        ctx.fill_circle(center.x, center.y, diameter / 2.0, color);
    })
}
```

宽高使用 logical 像素并受父约束裁定。闭包只在该节点需要绘制时执行；其中读取 `State` / `Computed` 会自动绑定到本节点 Paint 脏区，无需手工请求 frame。需要独立 measure、事件或子节点时改用 `component!`。

### component! —— 完整自定义组件

需要 measure / render / on_event / 子节点时使用：

```rust uix-compile=component-progress-ring
component! {
    /// 自定义进度环。
    pub struct ProgressRing {
        progress: f32,   // 0.0..1.0
        size: f32,
    }

    measure => (&self, constraints: Constraints) -> Size {
        constraints.clamp(Size::new(self.size, self.size))
    }

    render => (&self, frame: Rect, ctx: &mut PaintContext) {
        let color = ctx.tokens().color_primary();
        // 背景环
        let center = Point::new(frame.x + frame.w * 0.5, frame.y + frame.h * 0.5);
        ctx.stroke_circle(center.x, center.y, self.size / 2.0 - 4.0,
            color.with_alpha(51), 4.0);
        // 进度弧
        let end = self.progress * std::f32::consts::TAU;
        ctx.stroke_arc(center.x, center.y, self.size / 2.0 - 4.0,
            0.0, end, color, 4.0);
    }
}

// 使用
ProgressRing { progress: 0.65, size: 80.0 }
```

`component!` 自动生成 reconciliation 逻辑。可定义的方法：

| 方法 | 用途 |
|------|------|
| `measure` | 给定约束，返回尺寸 |
| `child_overflow_expands_parent` | 子节点视觉溢出是否允许撑大本节点；默认 `true`，仅保留自身占位的定位容器返回 `false` |
| `render` | 像素绘制（通过 `PaintContext`） |
| `build` | 返回子节点（`Vec<Box<dyn WidgetComponent>>`） |
| `on_event` | 接收 `SystemEvent`，返回是否消费 |
| `scroll_delta_for_dirty` | 消费事件后返回本轮滚动像素差，启用 scroll_region Composite |
| `scroll_composite_viewport` | 可选地把像素移动限定到组件内的滚动视口；框架裁到组件 frame，未定义或无交集时安全使用完整 frame |
| `update_animation` | 推进动画并返回是否仍需下一帧；`dt` 为秒 |
| `dirty_bounds` | 返回本次动画变化的窄绘制区域 |
| `on_mount` | 首次挂载到树中 |
| `on_unmount` | 从树中移除前（清理资源） |
| `wants_continuous_pointer_move` | 是否接收逐帧 PointerMove（默认 false） |

### PaintContext 速查

`render` 方法通过 `ctx: &mut PaintContext` 绘制：

| 方法 | 说明 |
|------|------|
| `ctx.fill_rect(rect, color, radius)` | 填充矩形，可选圆角 |
| `ctx.stroke_rect(rect, color, lw, radius)` | 描边矩形 |
| `ctx.fill_circle(cx, cy, r, color)` | 填充圆形 |
| `ctx.stroke_circle(cx, cy, r, color, lw)` | 描边圆形 |
| `ctx.stroke_arc(cx, cy, r, start_rad, end_rad, color, lw)` | 描边圆弧（弧度制） |
| `ctx.fill_path(path, color, fill_rule)` | 填充路径 |
| `ctx.stroke_path(path, color, options)` | 描边路径 |
| `ctx.draw_line(x1, y1, x2, y2, color, lw)` | 直线 |
| `ctx.draw_text(text, Point::new(x, y), color, font_size)` | 文本（左对齐、顶部对齐） |
| `ctx.tokens()` | 获取当前主题 `DesignTokens`（颜色、字号等） |

坐标与传入的 `frame` 使用同一 logical 坐标系；绘制组件内容时从 `frame.x` / `frame.y` 起算，不要再次假定局部原点为 `(0, 0)`。

含子节点的组件：

```rust uix-compile=component-children
component! {
    pub struct Card {
        children: WidgetChildren,
    }

    build => (&self) -> Vec<Box<dyn WidgetComponent>> {
        self.children.take()
    }

    render => (&self, frame: Rect, ctx: &mut PaintContext) {
        ctx.fill_rect(frame, Color::WHITE, Some(Radius::uniform(8.0)));
    }
}
```

### 指针移动优化

同一 hit 目标上连续 `PointerMove` 不每帧触发重绘——仅 hover 目标变化时标脏。需要逐帧 PointerMove 的组件（Slider、拖拽选区）应 opt-in：

```rust uix-compile=component-pointer-move
component! {
    pub struct MySlider {
        min: f32,
        max: f32,
    }

    render => (&self, _frame: Rect, _ctx: &mut PaintContext) {
        let _range = self.min..=self.max;
    }

    wants_continuous_pointer_move => (&self) -> bool { true }
}
```

### ThemeToggle —— 主题切换按钮

内置暗色 ↔ 亮色主题切换按钮：

```rust uix-compile=theme-toggle
let toggle = ThemeToggle::new().dark(false); // 初始亮色

toggle.is_dark()  // 读取当前模式
```

`ThemeToggle` 默认进入 Tab 顺序；点击或聚焦后按 `Enter` / `Space` 会切换状态，并发出载荷为 `"dark"` 或 `"light"` 的 `SemanticKind::Change`。`.dark(...)` 只设置初始状态，后续 reconcile 保留用户运行态；`is_dark()` 与 `SnapshotFields::ThemeToggle::dark` 都返回当前状态。配合 `AppHandle::set_theme(...)` 或自定义主题逻辑使用。

### Grid

```rust uix-compile=grid-layout
grid([
    label("A"), label("B"), label("C"),
    label("D"), label("E"), label("F"),
])
    .columns(vec![GridTrack::Fr(1.0); 3])
    .gap(8.0);

// 响应式 Grid（容器 resize 自动按 logical 宽度重排）
tree! { Grid::responsive()
    .breakpoints(Breakpoints::antd())  // xs:0 sm:576 md:768 lg:992 xl:1200 xxl:1600
    .cols(vec![
        Col::new().span(24).sm(12).md(8).lg(6),  // 手机全宽 → 大屏 1/4
        Col::new().span(24).sm(12).md(8).lg(6),
        Col::new().span(24).sm(12).md(8).lg(6),
    ]) => [
    label("A"), label("B"), label("C"),
]};

// offset / order
let offset = Col::new().span(6).offset(6); // 右侧偏移
let ordered = Col::new().span(6).order(2); // 排序优先
```

响应式 Grid 固定使用 24 单元。`span` 与各断点覆盖值会约束到 `1..=24`，`offset` 会约束到本行剩余单元；未提供对应 `Col` 的子节点默认占满 24 单元。`order` 只改变视觉放置，树、事件与语义顺序仍按源码顺序。`grid(children).responsive().cols(...)` 提供同一套 View builder 写法。自定义断点用 `Breakpoints::new(sm, md, lg, xl, xxl)`，非有限、负数或非严格递增会返回 `BreakpointError`。

### Splitter

```rust uix-compile=splitter-layout
tree! { Splitter::new()
    .panels(2)
    .min_size(0, 180.0) => [
    label("Sidebar"),
    label("Content"),
]};
```

两个及以上面板时 `Splitter` 自动进入 Tab 顺序；`PageUp` / `PageDown` 切换当前手柄，横向用 `Left` / `Right`、纵向用 `Up` / `Down` 调整，`Home` / `End` 移到相邻面板允许的最小边界。指针拖拽或键盘调整都遵守 `.min_size(...)`，并发出以逗号分隔比例为载荷的 `SemanticKind::Change`；`ratios()` 和 `SnapshotFields::Splitter::ratios` 返回当前运行态，accessibility 将当前手柄暴露为 `slider`。

### Affix / BackTop / Sider

```rust uix-compile=page-layout-components
let scroll_offset = State::new(Point::new(0.0, 480.0));
let page_offset = scroll_offset.clone();

// 此闭包可直接作为 App::root(...) 的页面工厂。
let page = move || {
    let current = page_offset.get();
    column((
        scroll(column((
            label("Page header").height(240.0),
            embed(tree! { Affix::new(12.0).scroll_y(current.y) => [
                label("Sticky tools"),
            ]}),
            label("Page body").height(1000.0),
        )))
            .vertical()
            .size(640.0, 400.0)
            .scroll_offset(&page_offset),
        embed(
            BackTop::new()
                .visibility_height(400.0)
                .scroll_y(current.y),
        )
        .on_click(&page_offset, |offset| offset.set(Point::new(0.0, 0.0))),
    ))
};

tree! { Layout::new() => [
    tree! { Sider::new(240.0).collapsible(true) => [
        label("Menu"),
    ]},
    tree! { Content::new() => [
        label("Main area"),
    ]},
]};
```

`ScrollBuilder::scroll_offset(&State<Point>)` 与 `ScrollView::scroll_offset(...)` 都会双向绑定视口位置：滚轮、键盘和滚动条拖动回写实际 offset，外部 `State` 变化则在应用 reconcile 时更新视口。`Affix` 保留子树的自然占位，滚动越过其自然位置后将子树固定到最近视口的 `offset_top`；在页面工厂中用 `.scroll_y(current.y)` 读取同一状态即可，不直接改子节点 frame。`BackTop::scroll_y(offset.y)` 也使用该状态决定可见性；不高于阈值时它不参与布局、命中和 Tab 顺序，高于阈值后支持点击、`Enter` 与 `Space`。上例的点击处理把同一 `State` 归零，因此会真正滚回顶部。仅在直接持有组件实例时才需调用 `Affix::update_scroll(...)` 或 `BackTop::update_visibility(...)`；返回值都表示状态是否变化。

### 文本输入

```rust uix-compile=text-inputs
let text = State::new(String::new());

// 单行

    .placeholder("请输入用户名")
```

### 开关与勾选

```rust uix-compile=boolean-and-choice-inputs
let checked   = State::new(false);
let selected  = State::new(String::new());
let options = vec!["选项 A", "选项 B", "选项 C"];

Checkbox::new("同意协议").checked(&checked);
Switch::new().checked(&checked);
Radio::group("group1", &options, &selected);
Segmented::new(&options).value(&selected);
```

`checked(&State<bool>)` 以外部 State 为真值并在用户切换时回写；只需非受控初值时使用 `default_checked(bool)`。

`Radio::group(name, options, &State<String>)` 创建具名受控单选组：外部值按选项文本匹配，点击、方向键与语义选择立即回写，组名进入无障碍语义。链式写法可使用 `Radio::new().group_name(...).options(...).value(&state)`；只需非受控初值时使用 `default_selected(index)`，当前值与索引分别由 `current_value()`、`current_index()` 返回。

`Segmented::new(options).value(&State<String>)` 使用相同的选项文本契约；点击、方向键与语义选择会跳过 `disable_option(index)` 标记的项并立即回写。组件默认进入 Tab 顺序并显示焦点框，获得焦点后可直接用方向键选择。只需非受控初值时使用 `default_selected(index)`，当前值与索引同样由 `current_value()`、`current_index()` 返回。

### 数值输入

```rust uix-compile=numeric-inputs
let num    = State::new(0i32);
let val    = State::new(50.0f64);
let rating = State::new(3u32);

InputNumber::new().value(&num).min(0.0).max(100.0).step(1.0);
Slider::new(0.0..=100.0).value(&val);
Rate::new().count(5).value(&rating);
```

InputNumber 通过 `value(&State<T>)` 托管标准整数或浮点数，接收系统 `TextInput` / IME commit 与粘贴中的 ASCII 数字、负号和小数点；`Enter` 或失焦提交，无法解析的缓冲恢复为上一个有效值。`Up` / `Down` 及右侧步进按钮按 `step` 立即回写；整数 State 会先将结果四舍五入，再同步组件显示。外部越界值按 `min` / `max` 显示且构建过程不改写 State，下一次用户操作会回写合法值。只需非受控初值时使用 `default_value(T)`，占位文本用 `.placeholder(...)`，当前缓存值统一由 `current_value()` 返回。

Slider 使用 `RangeInclusive<f64>` 声明区间，`value(&State<f64>)` 以外部 State 为真值并在拖动、方向键或语义增减时回写。外部越界值按区间端点显示且构建过程不改写 State；下一次用户操作会回写合法值。只需非受控初值时使用 `default_value(f64)`。

Rate 通过 `value(&State<u32>)` 托管评分，点击、方向键与语义增减立即回写；组件默认进入 Tab 顺序并显示焦点框。外部超出 `count` 的值按上限显示，下一次用户操作会写回合法值。只需非受控初值时使用 `default_value(u32)`，当前缓存值由 `current_value()` 返回。启用 `allow_half()` 后，State 使用半星步数：`1` 表示半星、`2` 表示一星。

### 日期、时间与颜色

```rust uix-compile=date-time-color-inputs
let date  = State::new(Date::today());
let time  = State::new(Time::now());
let color = State::new(Color::RED);

DatePicker::new().value(&date);
TimePicker::new().value(&time);
ColorPicker::new().value(&color);

// 范围选择
let (start, end) = (State::new(Date::today()), State::new(Date::today()));
DateRangePicker::new()
    .start(&start).end(&end)
    .presets(vec![
        ("今天",     PresetDate::today()),
        ("本周",     PresetDate::this_week()),
        ("本月",     PresetDate::this_month()),
        ("最近 7 天", PresetDate::last_days(7)),
    ])
    .disabled_date(|d| d.weekday().is_weekend()); // 周末禁用

// 其他选择模式
DatePicker::new().mode(PickerMode::Week); // 周 / Month 月 / Quarter 季
```

基础 DatePicker 以 `State<Date>` 为外部真值，用户选日立即回写；`Date::today()` 返回当前 UTC 日期，年月日构造会归一到合法公历日期。只需非受控初值时使用 `default_value(Date)`，占位文本用 `.placeholder(...)`。`disabled_date` 禁止命中日期提交；Week / Month / Quarter 模式分别把周一、月初、季初写回 State，便于业务使用稳定代表值。

DateRangePicker 以 `start` / `end` 两个 `State<Date>` 为外部真值；第一次命中只建立待选起点，第二次命中按日期排序后一次提交范围，禁用端点不会提交。非受控初值用 `default_range(start, end)`。`PresetDate::today()` / `this_week()` / `this_month()` / `last_days(n)` 在组件构建时按当前 UTC 日期生成稳定范围；选择预设同样按起止端点执行禁用规则。范围快照与无障碍值统一为 `YYYY-MM-DD / YYYY-MM-DD`。

TimePicker 以 `State<Time>` 为外部真值，选中小时或分钟时立即回写；`Time::now()` 返回当前 UTC 时间并精确到分钟，`Time::new(hour, minute)` 将字段收敛到 `23:59` 内。只需非受控初值时使用 `default_value(Time)`，占位文本用 `.placeholder(...)`，当前缓存值由 `current_value()` 返回；`00:00` 是有效值而非空值。

ColorPicker 以 `State<Color>` 为外部真值，选中预设色时立即回写，外部更新会重绘色块并同步无障碍值。只需非受控初值时使用 `default_value(Color)`，当前缓存值由 `current_value()` 返回；未配置时从 `Color::default()`（黑色）开始。

```rust uix-compile=cascader-and-suggestions

    TreeNode::new("北京", "beijing").children(vec![
        TreeNode::new("朝阳", "chaoyang"), TreeNode::new("海淀", "haidian"),
```

`Cascader::selected()` 返回当前标签和值路径；`TreeSelect::value()` / `value_key()`、`Mentions::value()` 与 `AutoComplete::value()` 返回各组件当前缓存值。

`AutoComplete` 是真实文本输入目标：点击或聚焦后可接收系统 `TextInput` / IME commit 与粘贴，`Backspace` 修改查询，按大小写不敏感的包含关系过滤；`Up` / `Down` 移动候选，`Enter` 提交，`Escape` 或失焦关闭弹层。`.value()` 始终返回当前已键入文本或最终候选值。

`Mentions` 在最后一个 `@` 后按大小写不敏感方式过滤；查询字符会立即进入 `.value()`，失焦只关闭建议而不丢文本。`Up` / `Down` 移动候选，`Enter` 或点击提交，并把当前 `@query` 替换为 `@候选 `。

`Cascader` 可用 `Down` / `Enter` / `Space` 打开；`Up` / `Down` 在当前层跳过禁用项，`Right` / `Enter` 进入子级或提交叶子，`Left` 返回父级，`Escape` 关闭。`.selected()` 与结构化快照同步返回已选择的 label / value 路径。

```rust uix-compile=upload-config
    .multiple(true)
    .max_count(10);
```

`accept` 声明允许的扩展名，`multiple` 控制多选，`max_count` 限制队列数量；组件只维护上传队列展示，实际文件对话框、读取和传输由应用服务负责。

### 表单

字段校验闭包直接定义，返回 `Result<(), String>`：

```rust uix-compile=form-validation
let form = Form::new()
    .field("user", "用户名")
        .default("")
        .required("请输入用户名")
        .custom(|v| if v.len() < 3 {
            Err("至少 3 个字符".into())
        } else { Ok(()) })
    .field("email", "邮箱")
        .default("")
        .required("请输入邮箱")
        .validate_email("邮箱格式不正确")
    .field("age", "年龄")
        .default(0i32)
        .validate_range(1..=120, "年龄范围 1-120")
    .build();

match form.validate() {
    Ok(values) => {
        if let (Some(user), Some(email)) = (
            values.get::<String>("user"),
            values.get::<String>("email"),
        ) {
            println!("submit: {user} <{email}>");
        }
    }
    Err(errors) => {
        // errors: Vec<FieldError>
        for error in &errors {
            eprintln!("{}: {}", error.field(), error.message());
        }
    }
}
```

`.build()` 返回应用侧 `FormModel`，字段按声明顺序校验且每个字段只报告第一条失败。默认只有显式 `validate()` 才执行规则；字段改为 `OnChange` / `OnBlur` 后，分别由 `set_value()` / `blur()` 激活，当前结果通过 `field_error()` / `errors()` 读取。成功的 `Values::get<T>(field)` 要求 `T` 与 `.default(...)` 的存储类型一致（字符串字面量按 `String` 存储）。无需维护 validator key/table；自定义闭包不进入 widget component，也不产生 timer、frame callback 或绘制失效。

内置校验规则：

| 方法 | 说明 |
|------|------|
| `.required(msg)` | 非空 |
| `.validate_email(msg)` | 邮箱格式 |
| `.validate_range(0..=100, msg)` | 数值范围 |
| `.validate_length(2..=20, msg)` | 字符串长度 |
| `.validate_pattern(regex, msg)` | Rust regex；非法表达式按该字段失败 |
| `.custom(\|v\| Result<(), String>)` | 自定义逻辑 |

校验触发时机（默认 `OnSubmit`，可改为失焦/输入即校验）：

```rust uix-compile=form-validation-triggers
let mut form = Form::new()
    .field("email", "邮箱")
        .default("")
        .required("请输入邮箱")
        .validate_email("格式不正确")
        .validate_trigger(Trigger::OnBlur)    // 失焦即校验
    .field("username", "用户名")
        .default("")
        .required("必填")
        .validate_trigger(Trigger::OnChange)  // 输入即校验
    .build();

form.set_value("username", "Ada"); // 执行 username 的 OnChange 规则
form.set_value("email", "ada@example.test");
form.blur("email");                 // 执行 email 的 OnBlur 规则
let visible_errors = form.errors();
```

字段间依赖校验（被依赖字段变更后级联校验）：

```rust uix-compile=form-dependent-validation
let form = Form::new()
    .field("password", "密码")
        .default("")
        .required("请输入密码")
    .field("confirm", "确认密码")
        .default("")
        .depends_on("password", |v, deps| {
            let Some(pwd) = deps.get::<String>("password") else {
                return Err("缺少密码字段".into());
            };
            if v != pwd { Err("两次密码不一致".into()) } else { Ok(()) }
        })
    .build();
```

依赖源经 `set_value()` 变化后，直接和传递依赖各按声明顺序重验一次；循环依赖由访问集截断，不会递归忙循环。提交校验时，依赖闭包读取的是本轮全部字段的 typed `Values`。

动态表单（`Form::List`——增删表单行）：

```rust uix-compile=dynamic-form-list
let mut list = Form::new()
    .list("items", |items| {
        items
            .field("name", "名称").default("").required("必填")
            .field("qty", "数量").default(1i32).validate_range(1..=100, "1-100")
    })
    .build();

if let Ok(item_id) = list.add_item() { // ID 耗尽时返回 typed FormListError
    list.set_value(item_id, "name", "主机");
}
let rows = column(list.render_rows(|item_id, index| {
    label(format!("第 {} 行 · {}", index + 1, item_id.get()))
}));
list.remove_item(0);
```

`render_rows()` 在 View 构建期读取列表结构，并按 `FormListItemId` 为每行写入稳定 key；`add_item()` / `remove_item(index)` / `clear()` 只更新该结构 `State`，自动请求所属根 View reconcile，未删除行保留组件实例。字段值和校验结果逐行隔离；`validate()` 成功返回 `FormListValues`，失败按当前行顺序、再按字段声明顺序返回 `Vec<FormListFieldError>`。

### 原始指针、键盘与焦点

普通 View 可直接按事件族登记原始 `SystemEvent` handler。返回 `Handled` 会停止当前节点的组件处理和后续冒泡；返回 `NotHandled` / `Bubbled` 时继续走组件 handler 与父节点。带 `Capture` 后缀的写法在 root → target 捕获阶段执行：

```rust uix-compile=raw-view-events
let interactive = label("可交互区域")
    .focusable(true) // 默认进入 Tab 顺序；也可 .tab_index(2)
    .on_pointer(|event| match event {
        SystemEvent::PointerDown { pos, .. } => {
            println!("pointer: {}, {}", pos.x, pos.y);
            EventResult::Handled
        }
        _ => EventResult::NotHandled,
    })
    .on_key(|event| match event {
        SystemEvent::KeyDown { key: KeyCode::Enter, .. } => EventResult::Handled,
        _ => EventResult::NotHandled,
    })
    .on_focus(|event| {
        println!("focus: {:?}", event.kind());
        EventResult::NotHandled
    })
    .on_scroll(|event| {
        println!("scroll: {:?}", event.kind());
        EventResult::NotHandled
    });

let shell = column((interactive,)).on_key_capture(|event| {
    println!("subtree key: {:?}", event.kind());
    EventResult::NotHandled
});
```

`.on_pointer` / `.on_pointer_capture` 即显式选择接收命中范围内的连续 `PointerMove`；仅需要全部事件时用 `.on_event` / `.on_event_capture`。原始闭包在每次 reconcile 按声明整体替换，不重复登记。Tab / Shift+Tab 自动在 `focusable(true)` / 正 `tab_index` 节点间循环，浮层内受 focus trap 约束。

应用侧编程式 focus / blur 使用应用持有的 typed `FocusHandle`：

```rust uix-compile=focus-handle
let field_focus = FocusHandle::new();
let focus_from_button = field_focus.clone();
let blur_from_button = field_focus.clone();

let form = column((
    input().placeholder("邮箱").focus_handle(&field_focus),
    row((
        button("聚焦").on_click_fn(move || {
            if let Err(error) = focus_from_button.focus() {
                eprintln!("focus rejected: {error}");
            }
        }),
        button("失焦").on_click_fn(move || {
            if let Err(error) = blur_from_button.blur() {
                eprintln!("blur rejected: {error}");
            }
        }),
    )),
));
```

`.focus_handle(&handle)` 随 View build / reconcile 绑定节点；同一节点换 handle 或节点移除后，旧 handle 返回 `FocusHandleError::Unbound`。同一 handle 不得同时绑定多个存活节点或窗口，否则返回 `AmbiguousTarget`。`focus()` / `blur()` 可从后台线程登记到目标窗的 UI 轮次，`Ok(())` 表示命令已进入唯一存活目标的队列；目标隐藏或不接收事件时，UI 轮次消费命令但不强制聚焦。`blur()` 只在该 handle 的目标当前持有焦点时清除焦点，不影响同窗其他节点或其他窗口。

完整自定义组件仍可在 `component!` 的 `on_event` 中处理同一 `SystemEvent`；View handler 先运行，未处理时才进入组件 handler。

### 无障碍

框架从组件结构化快照派生 `AccessibilityRole`、`AccessibilityState` 与 `AriaAttribute`；Button、Input、Checkbox 等内置组件自带 role / name / state。普通 View 可只覆写显式字段，未覆写字段继续读取组件实时状态：

```rust uix-compile=accessibility-overrides
let submit = label("提交")
    .role(AccessibilityRole::Button)
    .accessible_name("提交表单")
    .accessibility_state(AccessibilityState {
        disabled: false,
        ..AccessibilityState::default()
    })
    .aria("aria-description", "验证后提交当前表单");

let decorative = column((label("仅视觉装饰"),))
    .role(AccessibilityRole::None); // 节点及子树不进入语义树
```

需一次性替换 role / name / state 时用 `.accessibility(AccessibilitySnapshot::named(...))`。相同名称的 `.aria(...)` 后值覆盖前值；`ComponentHandle::accessibility()`、`TestApp::snapshot()` 与 Agent Bridge 读取同一节点覆写。

`AccessibilityState` 表示组件的当前语义状态，由组件属性自动派生：

| 字段 | 类型 | 来源示例 |
|------|------|---------|
| `disabled` | `bool` | `Button::new(...).disabled(true)` |
| `checked` | `Option<bool>` | `Checkbox::checked(&state)`、`Switch::checked(&state)` |
| `value_text` | `Option<String>` | `Select::value(&state)` 当前选中项 |
| `value_now` | `Option<f64>` | `Slider::value(&state)`、`ProgressBar::progress` |
| `value_min` / `value_max` | `Option<f64>` | `Slider::new(min..=max)`、`Rate::count` |
| `multiline` | `bool` | `Input::textarea()` |
| `password` | `bool` | `Input::password()`（敏感，不导出语义快照） |
| `required` | `bool` | `FormItem::new(...).required(true)` |

自定义组件通过 `SnapshotFields` 返回对应的 `AccessibilityState`；测试中可直接构造 `AccessibilitySnapshot`：

```rust uix-compile=accessibility-snapshot
AccessibilitySnapshot::named(AccessibilityRole::Button, "提交")
    .with_state(AccessibilityState::disabled(true));
```

可用 role：`None` / `Generic` / `Alert` / `Button` / `Checkbox` / `Combobox` / `Dialog` / `Group` / `Image` / `List` / `Menu` / `Navigation` / `ProgressBar` / `RadioGroup` / `Slider` / `SpinButton` / `Status` / `Switch` / `Table` / `TabList` / `Text` / `TextBox` / `Tree`。`None` 不暴露该节点及其子树。

框架自动处理 `Tab` / `Shift+Tab` 键盘导航，浮层内受 focus trap 约束。password 等敏感字段自动排除出语义快照。

## 数据展示

### Table

```rust uix-compile=table-features
let users: Vec<TableRow> = vec![
    vec!["Ada".into(), "28".into(), "Admin".into()],
    vec!["Bob".into(), "35".into(), "User".into()],
];

let expandable = Table::new()
    .columns(vec![
        TableColumn::new("姓名", 120.0),
        TableColumn::new("年龄", 80.0),
        TableColumn::new("角色", 100.0),
    ])
    .rows(users.clone())
    .expandable(48.0, |row| {
        column((
            label(format!("姓名: {}", row.first().map_or("", String::as_str))),
            label(format!("年龄: {}", row.get(1).map_or("", String::as_str))),
        )).padding(12.0)
    })
    .sortable(true)        // 所有列头可切换排序方向
    .selection(true)       // 显示行复选框与表头全选
    .bordered(true);

// 固定列（宽表必备）
let fixed = Table::new()
    .columns(vec![
        TableColumn::new("姓名", 120.0).fixed(Fixed::Left),   // 左侧固定
        TableColumn::new("年龄", 80.0),
        TableColumn::new("邮箱", 200.0),
        TableColumn::new("操作", 100.0).fixed(Fixed::Right),  // 右侧固定
    ])
    .rows(users.clone());

// 列分组（多级表头）
let grouped = Table::new()
    .column_groups(vec![
        TableColumnGroup::new("基本信息", vec![
            TableColumn::new("姓名", 120.0),
            TableColumn::new("年龄", 80.0),
        ]),
        TableColumnGroup::column(TableColumn::new("部门", 100.0)),
    ])
    .rows(users.clone());

// 虚拟滚动 + Table（万级数据）
let large_dataset = users;
let virtualized = Table::new()
    .columns(vec![
        TableColumn::new("姓名", 120.0),
        TableColumn::new("年龄", 80.0),
        TableColumn::new("角色", 100.0),
    ])
    .rows(large_dataset)
    .virtual_scroll(true)            // 接入 VirtualScroll 作为 body 渲染后端
    .virtual_row_height(32.0);
```

`TableRow` 是 `Vec<String>`，单元格顺序与 `columns` 一一对应。`expandable(height, |row| view)` 仅为当前展开行构建一个普通 `View` 子树；该子树参与布局、命中测试、语义事件和 `State` 绑定，并在应用 reconcile 时按普通子节点复用。展开区跟随 body 滚动且裁切在表体内，绘制阶段不会重复执行 View factory。

`sortable(true)` 让全部列参与排序交互，也可仅对某列使用 `TableColumn::sortable(true)`；点击依次切换 `Asc → Desc → None` 并发出 `SemanticKind::Change`，调用方据此更新 `.rows(...)`。`column_groups()` 生成双层表头，具名组占上层、叶列占下层；`TableColumnGroup::column()` 声明跨两层的独立列。`selection(true)` 的复选框多选与普通行点击的单选状态彼此独立。宽表收到横向 `Wheel` 时自动滚动中间列，`Fixed::Left` / `Fixed::Right` 列保持贴边，不要求调用方同步偏移。`virtual_scroll(true)` 明确启用有界行遍历，`virtual_row_height()` 提供固定行高但不会隐式开启虚拟滚动；关闭时仍可滚动，只是不裁减行遍历范围。排序方向、固定位置、分组范围、`selected_row`、`checked_rows` 以及四个表级开关均可从 `SnapshotFields::Table` 读取；这些开关也可继续链在 `expandable(...)` 之后。

非空 `SelectableList` 默认进入 Tab 顺序。聚焦后，`Up` / `Down` 移动当前行，`Home` / `End` 跳到首尾，`Enter` / `Space` 重新激活当前行；键盘移动会自动滚动以露出当前项。点击或键盘激活行会发出以 item id 为载荷的 `SemanticKind::Change`，当前项可由 `selected_id()`、`selected_text()` 或 `SnapshotFields::SelectableList::active_index` 读取。头部按钮点击时发出以按钮文本为载荷的 `SemanticKind::Submit`；无数据时也可用 `Enter` / `Space` 激活它。footer 仅展示文本，不参与行命中。

`Tree` 默认进入 Tab 顺序。聚焦后，`Up` / `Down` 在当前可见节点间移动并跳过禁用项，`Right` 展开节点或进入子树，`Left` 折叠节点或回到父级；`Space` 切换可勾选节点，多选模式下 `Enter` 切换当前节点的选择状态。键盘移动会自动滚动以露出当前节点。选择或勾选变化发出以节点 key 为载荷的 `SemanticKind::Change`；`SnapshotFields::Tree` 提供 `selected_key`、`selected_keys`、`expanded_keys`，每个 `SnapshotTreeNode` 的 `checked` 反映当前勾选状态。

## 动画

UIX 提供泛型逐帧动画系统，由框架自动推进 `dt`（秒），窗口不可呈现时暂停、恢复首帧重基。**勿用 `run_interval` 模拟帧动画。**

### Animation\<T\> —— 泛型插值

`Animation::new(from, to, duration)` 创建从 `from` 到 `to` 的插值动画，支持任意 `Animatable` 类型（内置 `f32`、`f64`、`Color`、`Point`、`Rect`）。

```rust uix-compile=animation-basics
let anim = Animation::new(0.0, 1.0, 0.3)  // from, to, seconds
    .easing(Easing::ease_out);
```

| 方法 | 作用 |
|------|------|
| `anim.value()` | 当前插值（不推进时间） |
| `anim.update(dt)` | 推进 `dt` 秒，返回当前插值 |
| `anim.is_finished()` | 是否已完成 |
| `anim.progress()` | 进度 [0, 1] |
| `anim.restart()` | 从起点重新播放 |
| `anim.stop()` | 跳到终态并停止 |
| `anim.pause()` / `anim.resume()` | 暂停 / 继续 |
| `anim.reverse()` | 交换 from/to 并重新播放 |
| `anim.on_finish(\|\| { ... })` | 完成回调（播放到终态时触发） |

`on_finish` 接受 `FnOnce() + Send + 'static`，同一动画及其克隆体合计只触发一次；`stop()` 只跳到终态而不消费回调，之后 `restart()` 仍可正常完成并触发。非正持续时间归一为零，首次 `update()` 即完成。

用于视图属性：

```rust uix-compile=animated-view-properties
let anim = Animation::new(0.0, 1.0, 0.3);
label("淡入")
    .opacity(anim.value() as f32);

// 颜色动画
let color_anim = Animation::new(Color::RED, Color::BLUE, 0.5)
    .easing(Easing::ease_in_out);
label("颜色动画").color(color_anim.value());
```

### Easing —— 缓动曲线

```rust uix-compile=easing-curves
// 基础
let linear = Easing::linear;
let ease_in = Easing::ease_in;          // quad in
let ease_out = Easing::ease_out;        // quad out
let ease_in_out = Easing::ease_in_out;  // quad in-out

// 加强
let cubic_in = Easing::cubic_in;
let cubic_out = Easing::cubic_out;
let cubic_in_out = Easing::cubic_in_out;

// 弹性
let bounce = Easing::bounce;   // 弹跳缓出
let elastic = Easing::elastic; // 弹性缓出

// 自定义三次贝塞尔
let custom = Easing::cubic_bezier(0.25, 0.1, 0.25, 1.0);
```

这些小写名称是可直接传给 `.easing(...)` 的关联常量；`bounce` 保持在 [0,1] 内分段回弹，`elastic` 会短暂越过终值后衰减归位。所有曲线都固定经过起点 0 与终点 1。

### 浮层进出场动画

Modal / Drawer / Popover / Message / Notification 支持可配置的 enter + leave 两段式动画：

```rust uix-compile=overlay-animations
// Modal 弹出/关闭
Modal::show(|_| label("Modal content"))
    .enter_animation(AnimationConfig::fade_in(0.2))
    .leave_animation(AnimationConfig::fade_out(0.15));

// Drawer 滑入/滑出
Drawer::new("设置")
    .placement(DrawerPlacement::Right)
    .show()
    .enter_animation(AnimationConfig::slide_in(Placement::Right, 0.25))
    .leave_animation(AnimationConfig::slide_out(Placement::Right, 0.2));

// Popover 从触发点右侧滑入，关闭后再移出浮层栈
Popover::new("详情")
    .placement(PopoverPlacement::Right)
    .enter_animation(AnimationConfig::slide_in(Placement::Right, 0.15))
    .leave_animation(AnimationConfig::fade_out(0.1));

// Message / Notification 对队列中的每一项独立播放
Message::new()
    .enter_animation(AnimationConfig::slide_in(Placement::Top, 0.2))
    .leave_animation(AnimationConfig::fade_out(0.15));

Notification::new()
    .enter_animation(AnimationConfig::slide_in(Placement::Right, 0.2))
    .leave_animation(AnimationConfig::slide_out(Placement::Right, 0.15));
```

`AnimationConfig` 预设：

| 方法 | 效果 |
|------|------|
| `AnimationConfig::fade_in(duration)` | 淡入（opacity 0→1） |
| `AnimationConfig::fade_out(duration)` | 淡出（opacity 1→0） |
| `AnimationConfig::slide_in(placement, duration)` | 方向滑入（含位移 + 淡入） |
| `AnimationConfig::slide_out(placement, duration)` | 方向滑出（含位移 + 淡出） |
| `AnimationConfig::zoom_in(duration)` | 缩放弹出（scale 0.8→1 + 淡入） |
| `AnimationConfig::zoom_out(duration)` | 缩放收起（scale 1→0.8 + 淡出） |

`placement` 为 `Placement::Top | Bottom | Left | Right`，控制滑动方向。

Modal / Drawer / Popover 的 leave 动画播放完毕后自动从本窗 `OverlayStack` 移除节点；Message / Notification 则在逐项 leave 完成后删除该项，队列为空才移除 overlay。动画结束即注销帧工作，自动到期由 one-shot timer 唤醒；窗口 `Suspended` 时不推进视觉动画。slide damage 覆盖完整位移轨迹，仍只影响所属窗口。

### 自定义组件动画

自定义 `component!` 通过 `update_animation => (&mut self, dt: f64) -> bool` 推进 `Animation<T>`，并用 `dirty_bounds` 返回本帧实际 damage。仍需下一帧时返回 `true`；到达静止态立即返回 `false`，框架随即注销该节点的动画工作。绘制从 `animation.value()` 读取当前值，不使用 `run_interval` 模拟帧。

## 多窗口

窗口客户区尺寸、布局、指针与 resize 都使用 logical 坐标；每窗 drawable 随所在显示器的 DPI 独立变化。应用无需监听 DPI 消息或手工缩放窗口内容。

### 自定义标题栏

Windows 主窗调用 `.custom_title_bar(true)` 隐藏系统标题栏，再用普通 View 组合自己的标题栏。`window_drag_region` 把展示内容变成原生拖动区域；`window_control` 提供最小化、最大化 / 还原和关闭，外观仍完全由应用决定。仓库内 `cargo run --release --bin uix-demo` 默认运行同一模式，可直接查看完整组合：

```rust uix-compile=custom-title-bar
use uix::prelude::*;

fn title_bar() -> ViewNode {
    row((
        window_drag_region(
            label("My App")
                .font_size(14.0)
                .padding_h(12.0),
        )
        .flex_grow(1.0)
        .height(40.0),
        window_control_named(WindowControl::Minimize, "最小化窗口", label("—"))
            .width(46.0)
            .height(40.0)
            .bg_hover(Color::hex("#E5E7EB"))
            .bg_focus(Color::hex("#FFF4CE"))
            .bg_active(Color::hex("#D1D5DB")),
        window_control_named(WindowControl::MaximizeRestore, "最大化或还原窗口", label("□"))
            .width(46.0)
            .height(40.0)
            .bg_hover(Color::hex("#E5E7EB"))
            .bg_focus(Color::hex("#FFF4CE"))
            .bg_active(Color::hex("#D1D5DB")),
        window_control_named(WindowControl::Close, "关闭窗口", label("×"))
            .width(46.0)
            .height(40.0)
            .bg_hover(Color::hex("#E81123"))
            .bg_focus(Color::hex("#FFF4CE"))
            .bg_active(Color::hex("#C50F1F")),
    ))
    .height(40.0)
    .align(AlignItems::Center)
}

App::new()
    .title("My App")
    .size(900, 600)
    .custom_title_bar(true)
    .root(|| column((
        title_bar(),
        label("窗口内容").padding(24.0).flex_grow(1.0),
    )))
    .run();
```

拖动区可放普通展示内容，也可嵌入独立交互控件：命中子控件时由子控件处理，命中未处理输入的内容时才开始拖窗；左键双击同一区域会切换本窗最大化 / 还原，右键在同一区域按下并释放会显示本窗原生系统菜单。内层交互控件若处理右键，则保留自己的上下文菜单。拖窗、标题栏双击和原生系统菜单都不会改变正文中已有的键盘焦点，应用无需自行计时、计数、维护窗口状态或绘制系统菜单。窗口控制包装器自身接管鼠标与键盘，内部 View 只负责展示，不应再嵌套 `button` 等交互控件；即使误放，展示子树也不会形成可命中的嵌套控件或重复语义节点。`bg_hover` / `bg_focus` / `bg_active` 分别声明悬停、焦点与鼠标按住或 Enter / Space 激活期间的背景；按压优先于焦点，焦点未声明专用颜色时沿用当前悬停色或 `bg`。指针在控件外松开会取消动作，鼠标与键盘按下 / 松开不得交叉配对。`window_control` 自带英文无障碍名称；标题栏使用符号图标或需要本地化时，改用 `window_control_named` 显式命名。两者都只在语义树中暴露包装器自身这个可 `Invoke` 的具名 `Button`，调用仍走同一键盘事件与逐窗 `WindowAction` 路径。关闭动作进入正常窗口关闭事件，框架会先释放图形与窗口会话。最小化后本窗按既有 `Suspended` 规则停掉 layout / paint / present；还原只唤醒本窗。

副窗同样逐窗 opt-in：


## 定时与异步

### 定时器

```rust uix-compile=app-timers
use std::time::Duration;

fn schedule_work(handle: &AppHandle) {
    let detached = handle.run_after(Duration::from_secs(2), || {
        // 2 秒后执行
    });
    detached.detach(); // 不受 drop 影响

    let cancelled = handle.run_interval(Duration::from_millis(100), || {
        // 每 100ms 执行
    });
    cancelled.cancel(); // 显式取消
}
```

### 跨线程回 UI

从任意线程更新 UI 状态，只走 `post_to_ui`：

```rust uix-compile=background-post-to-ui
fn load_in_background(handle: &AppHandle, data: &State<u32>) {
    let handle_clone = handle.clone();
    let data = data.clone();
    std::thread::spawn(move || {
        let result = 42;
        handle_clone.post_to_ui(move || {
            data.set(result);
        });
    });
}
```

`post_to_ui` 绑目标窗口的 `WindowSession`，不会唤醒其他窗口。

```rust uix-compile=settings-service
App::new()
```

## 测试

### TestApp —— 无窗测试

应用的测试依赖需显式启用 feature：

```toml
[dev-dependencies]
uix = { path = "../uix-app", features = ["test-harness"] }
```

```rust uix-compile=test-app-counter uix-feature=test-harness
use uix::prelude::*;

#[test]
fn test_counter() {
    let count = State::new(0);
    let root_count = count.clone();

    let mut app = uix::ui::test_harness::TestApp::new((400.0, 300.0), move || {
        let count = root_count.clone();
        row((
            count.map_text(|n| format!("{n}")).automation_id("counter.label"),
            button("+1").on_click(&count, |c| c.update(|v| *v += 1)).automation_id("counter.inc"),
        ))
    });

    assert_eq!(count.get(), 0);

    assert!(app.click("counter.inc").is_ok());
    assert!(app.settle().is_ok()); // 有界等待直接 State 修改等 pending work

    assert_eq!(count.get(), 1);
    assert_eq!(app.text("counter.label").as_deref(), Ok("1"));
}
```

可用查询：`.snapshot()` `.text(id)`。可用操作：`.click(id)` `.type_text(id, "text")` `.press_key(KeyCode::Enter, KeyMod::NONE)` `.select(id, index)` `.invoke(id)`（通用语义动作）。动作完成时已自动 settle；直接修改 State 后可显式 `.settle()`。

所有操作走真实 semantic / `SystemEvent` 路径，受可见性与 modal 约束。

### ComponentHandle —— 组件句柄

通过 ID 获取组件的只读快照或发送事件，句柄可跨线程移动，适用于跨组件交互、后台查询与测试断言：

```rust uix-compile=component-handle
fn component_handle(handle: &AppHandle, component_id: ComponentId) -> Option<ComponentHandle> {
    handle.app_state().get_handle(component_id)
}
```

查询方法：

| 方法 | 返回 | 适用组件 |
|------|------|----------|
| `.text()` | `Option<String>` | Button、Label |
| `.checked()` | `Option<bool>` | Checkbox、Switch |
| `.disabled()` | `Option<bool>` | Button、Input、Select 等 |
| `.numeric_value()` | `Option<f64>` | Slider、Progress、Rate、InputNumber |
| `.placeholder()` | `Option<String>` | Input、Select、DatePicker 等 |
| `.is_alive()` | `bool` | 是否仍在树中 |
| `.snapshot()` | `Option<ComponentConfigSnapshot>` | 完整快照 |
| `.accessibility()` | `Option<AccessibilitySnapshot>` | 无障碍信息 |

交互方法：

| 方法 | 说明 |
|------|------|
| `.invalidate()` | 线程安全地登记重绘并唤醒所属窗口；失效句柄 no-op |
| `.emit(event)` | 线程安全地将 `SemanticEvent` 排入所属窗口；`Handled` 表示已入队，不表示回调已执行 |

### AppState —— 跨线程组件状态

`AppState` 维护一份与 `WidgetTree` 同步的组件快照表，可在任意线程中通过 `ComponentHandle` 安全读取与排队交互；组件注册 / 注销、事件回调与绘制仍只在所属窗口的 UI 线程发生：

```rust uix-compile=app-state-snapshots
fn read_from_app(app: &App, component_id: ComponentId) {
    let app_state = app.app_state();
    let handle = app_state.get_handle(component_id);
    let snapshot = app_state.get_snapshot(component_id);
}

fn read_in_background(handle: &AppHandle, component_id: ComponentId) {
    let app_state = handle.app_state();
    std::thread::spawn(move || {
        let snapshot = app_state.get_snapshot(component_id); // 直接读取线程安全快照
        if let Some(component) = app_state.get_handle(component_id) {
            component.invalidate(); // 只登记并唤醒；实际绘制仍在 UI 线程
        }
    });
}
```

`ComponentHandle` 不提供任意 State 修改；后台任务需要改业务 State 时仍用目标窗 `AppHandle::post_to_ui`。句柄的 `.emit(...)` 与 `.invalidate()` 只排队并唤醒所属 session，不会在调用线程执行组件回调、layout 或 paint。

`TestApp` 直接提供语义快照与动作 API，不公开 `.handle(...)` / `.app_state()`；需要 `ComponentHandle` 的集成路径从运行中 `AppHandle::app_state()` 获取。

### 快照类型

`ComponentConfigSnapshot` 提供组件的结构化只读表示：

- `.fields` → `SnapshotFields`（60+ 组件变体，含各组件特有字段）
- `.accessibility()` → `AccessibilitySnapshot`（role、state、aria）
- `.selection()` → `Option<SelectionSnapshot>`（选项列表、选中索引、禁用索引、多选/展开状态）

`SelectionSnapshot` 用于 Select、Cascader、TreeSelect 等选择类组件的选项状态只读。

### 真窗快照

设置环境变量 `UIX_AUTOMATION_DIR`，真窗运行时每窗输出 JSON 快照（`revision` / `presented_revision`），空闲不轮询。关闭写 `closed: true`。password 字段不导出。
