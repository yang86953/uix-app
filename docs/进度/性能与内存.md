| 内存 | 字形缓存由 8192 项 / 32 MiB 收敛为 **2048 项 / 8 MiB**；LayerTree 构建通过所有权转移消除 DisplayList 双 clone。Picture 在固定最低资格之上按预计重绘像素 / BGRA 保留字节全局排序，每棵 LayerTree 最多保留 **32 MiB** 离屏；同收益优先高总收益与既有句柄，场景变化后超预算旧缓存降级并进入 checked orphan sweep。Native GPU Picture 的 checked flush 与 swapchain restore 均成功后立即释放已上传 GPU RT 的 CPU soft staging；失败的未提交命令 / soft source 保留到 retry。ImageService、CPU Picture pool 与 Native GPU offscreen 槽均会回收连续尾部空槽。API-neutral recorder 不持有完整 CPU 主表面，主画布 scratch 初始 / resize / shutdown 为 1×1，首次 CPU draw 才扩大。recorder Picture 也改为每槽 1×1 scratch 加一份 committed encoder / image：IR 的 command、image、coverage 保留量不超过同尺寸 BGRA，超限在发布前物化且不与 IR 双持；destroy 释放 coverage `Arc`。1920×1080 recorder resize 不再分配未使用的 CPU 主表面，减少约 **7.91 MiB** | 主 swapchain canvas 为避免连续 soft 帧分配抖动，仍保留两次 soft-free present / 250ms 的安全 grace；未提交失败源不参与清理 |
| 图形中转 | 普通 SrcOver 矩形 / 圆角填充的整数 identity 几何与整数 clip 已走 Native IR，fill opacity 会反解为可精确恢复 CPU premultiplied 8-bit 源的 straight Color；D3D11 / D3D12 / OpenGL solid shader 以 premultiplied SrcOver 提交。主帧与 Picture 内合格字形把 opacity 按 CPU 同序量化到 straight alpha 后，以共享 `Arc<[u8]>` 进入 `BlitGlyphs` 与有界 R8 atlas；零 alpha 直接 no-op。透明底、完整或局部 source、整数 1:1 destination 的 Picture 在写区互不覆盖，或每个实际重叠区被 alpha=255 直角填充 / 不透明圆角填充保守 SDF 全覆盖内区的一块或多块无缝并集完整覆盖时会原子拼入父 encoder；父画布当前整数 offset 会先固化到 destination，整数目标 clip 会同步裁 source / destination，平移容器与目标裁剪下也保留 glyph coverage `Arc`、圆角原始几何及 image source 子段。缓存 DisplayList 和新绘 Picture 均不扩大 scratch、不产生 FrameEncoder soft tile。opaque-backed planner 覆盖非对称半径、clipped inner intersection、角部回退、四象限 cover union 与单像素缺口回退；D3D11 WARP、D3D12 WARP、Windows WGL 的圆角加 tiled-union、opacity-glyph Picture producer 真实读回逐通道误差不超过 1，fake executor 明确验证量化 alpha 与零 soft tile。直接 `CpuSegment` / `PictureBlit` 也会计入 soft-upload diagnostics。Picture 重绘失败保留旧 committed；resize 先创建 replacement，失败不先销毁旧缓存 | `ab_glyph` 仍在 CPU 生成 coverage；未被无缝不透明并集完整覆盖的量化重叠、缩放 / fractional source/destination/origin / 目标相关 blend 的 Picture、non-identity 或 fractional 几何、Picture 整体 / 其他 CPU 图元 opacity、GPU 模糊仍会中转。OpenGL EGL 仍缺 Wayland 真机像素证据——见[架构§图形](../架构.md#图形-api与帧提交硬约束) |
