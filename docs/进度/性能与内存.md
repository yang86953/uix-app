## 性能
- **已做**：Modal / Drawer 关闭子树残留、重新打开布局与全屏遮罩录制已修复；可读 retained CPU 后端的全屏 overlay 帧复用干净背景，只重放浮层。圆角填充 / 描边改为像素等价的边界扫描，整幅透明目标背景恢复走精确行拷贝。Table View 单元格采用 content 坐标；纵向虚拟窗口不变时不复制 row key / View 列、不重跑 factory 或布局，只提交表体 composite-copy，窗口变化才 reconcile、布局并保守重绘。Layout 收敛循环不再构造逆序遍历，扩展签名、已调整子节点集合、父子可见性变更表、收缩操作与 child-id 缓冲跨 pass 清空复用；top-down、viewport 与 parent-slot 只读阶段直接借用 children slice，不再逐容器复制 id；Table / VirtualScroll 动态子树刷新继续按原顺序分别重取快照，但三次全树 id 快照复用 layout order 容量。仍保留原有稳定性签名、动态刷新顺序、可见性同步时机与 10×3 收敛上限。1200×800 Windows Vulkan/NVIDIA + CPU raster 真窗连续开关 12 轮：Drawer 首 / 末 4 轮中位数 21.7 / 26.9ms（单次 76.6ms 离群），Modal 22.4 / 19.3ms；观察到的 backdrop 帧 `paint_cpu` 最大 11.7ms，未见累积
- **瓶颈**：端到端首帧仍受约 4–7ms layout 与偶发调度尖峰影响，尚不宣称稳定 60Hz；GPU-only / 不可读后端保守完整重绘，仍需跨后端 / 硬件复测

## 内存
- **已做**：字形缓存由 8192 项 / 32 MiB 收敛为 **2048 项 / 8 MiB**；LayerTree 构建通过所有权转移消除 DisplayList 双 clone，DisplayList 的完整操作序列以 COW `Arc<Vec<PaintOp>>` 共享，普通 clone 不复制 glyph / line 缓冲；Label 与 Input 还会直接移交只绘制一次的新布局，避免 recorder 再 clone。Picture 在固定最低资格之上按预计重绘像素 / BGRA 保留字节全局排序，每棵 LayerTree 最多保留 **32 MiB** 离屏；同收益优先高总收益与既有句柄，场景变化后超预算旧缓存降级并进入 checked orphan sweep。Native GPU Picture 的 checked flush 与 swapchain restore 均成功后立即释放已上传 GPU RT 的 CPU soft staging；失败的未提交命令 / soft source 保留到 retry。ImageService、CPU Picture pool 与 Native GPU offscreen 槽均会回收连续尾部空槽。API-neutral recorder 不持有完整 CPU 主表面，主画布 scratch 初始 / resize / shutdown 为 1×1，首次 CPU draw 才扩大。recorder Picture 也改为每槽 1×1 scratch 加一份 committed encoder / image：IR 的 command、image、coverage 保留量不超过同尺寸 BGRA，超限在发布前物化且不与 IR 双持；destroy 释放 coverage `Arc`。1920×1080 recorder resize 不再分配未使用的 CPU 主表面，减少约 **7.91 MiB**
- **瓶颈**：主 swapchain canvas 为避免连续 soft 帧分配抖动，仍保留两次 soft-free present / 250ms 的安全 grace；未提交失败源不参与清理

## 图形中转
- **已做**：
  - 普通 SrcOver 矩形 / 圆角填充的整数 identity 几何与整数 clip 已走 Native IR，fill opacity 会反解为可精确恢复 CPU premultiplied 8-bit 源的 straight Color
  - D3D11 / D3D12 / OpenGL solid shader 以 premultiplied SrcOver 提交
  - 主帧与 Picture 内合格字形把 opacity 按 CPU 同序量化到 straight alpha 后，以共享 `Arc<[u8]>` 进入 `BlitGlyphs` 与有界 R8 atlas；零 alpha 直接 no-op
  - 透明底、完整或局部 source、整数 1:1 destination 的 Picture 在写区互不覆盖，或每个实际重叠区被 alpha=255 直角填充 / 不透明圆角填充保守 SDF 全覆盖内区的一块或多块无缝并集完整覆盖时会原子拼入父 encoder；父画布当前整数 offset 会先固化到 destination，整数目标 clip 会同步裁 source / destination，平移容器与目标裁剪下也保留 glyph coverage `Arc`、圆角原始几何及 image source 子段
  - 缓存 DisplayList 和新绘 Picture 均不扩大 scratch、不产生 FrameEncoder soft tile
  - opaque-backed planner 覆盖非对称半径、clipped inner intersection、角部回退、四象限 cover union 与单像素缺口回退
  - D3D11 WARP、D3D12 WARP、Windows WGL 的圆角加 tiled-union、opacity-glyph Picture producer 真实读回逐通道误差不超过 1，fake executor 明确验证量化 alpha 与零 soft tile
  - 直接 `CpuSegment` / `PictureBlit` 也会计入 soft-upload diagnostics，并只在可见目标 tile 内参考光栅化，不再分配或扫描透明整帧中间表面
  - 父画布 opacity 非 1 的有限整数 Picture 映射会保留组后语义，以携带 `FrameOpacity` 的单个 `PictureBlit` 逐通道量化，主 scratch 不扩容且零 opacity 直接 no-op
  - 普通 `blit_image` 的整数 1:1 映射同样只保留可见 source crop 与当前 `FrameOpacity`；缩放或 fractional 映射保留精确 CPU fallback
  - Picture 重绘失败保留旧 committed；resize 先创建 replacement，失败不先销毁旧缓存
- **瓶颈**：
  - `ab_glyph` 仍在 CPU 生成 coverage
  - 未被无缝不透明并集完整覆盖的量化重叠、缩放 / fractional source/destination/origin / 目标相关 blend 的 Picture、non-identity 或 fractional 几何、Picture 整体 opacity 的物化 / 紧凑 tile 上传、缩放或 fractional 图片与其他 CPU 图元 opacity、GPU 模糊仍会中转
  - OpenGL EGL 仍缺 Wayland 真机像素证据——见[架构§图形](../架构.md#图形-api与帧提交硬约束)

## 圆形填充
- **已做**：identity / SrcOver 下，应用 offset 后外接正方形为 surface 内整数矩形且 clip 为整数矩形的 `fill_circle`，以等价均匀圆角正方形复用现有 `FillRoundedRect` / `FillRoundedRectClipped` 与 GPU SDF；当前 opacity 保持 CPU premultiplied 量化顺序，主 scratch 保持 1×1
- **瓶颈**：fractional 外接边界、变换或其他 blend 仍保留精确 CPU fallback；椭圆、扇形、路径与其他描边图元仍未包含

## 矩形与圆形描边
- **已做**：identity / SrcOver 下，应用 offset 后矩形为 surface 内整数几何、clip 为整数矩形、宽度有限正值且圆角合法的 `stroke_rect` 已保留为 `StrokeRoundedRects` IR，并按 CPU premultiplied 顺序折叠 opacity；外接正方形为同类整数几何的 `stroke_circle` 精确改写为四角半径等于圆半径的同一 IR，逐像素保持 CPU parity 且 recorder scratch 保持 1×1。同 clip 且保守可见 bounds 不相交的相邻描边受 2048 项、1M 像素与 4× 稀疏 union 上限约束后合批；D3D11 以一个既有 `GpuStrokeRect` batch 提交，无 `stroke_rects` capability 的后端仅光栅化并上传 batch 与 clip 的可见紧凑 tile，两者都不扩大 recorder scratch
- **瓶颈**：相交描边为保持 8-bit SrcOver 顺序而不合批；Picture 安全拼接暂不接受描边写区；fractional / transformed / target-dependent 描边继续精确 CPU fallback，路径描边与其他图元仍未包含

## 暂缓

- **瓶颈**：另行立项
