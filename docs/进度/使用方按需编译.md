## 当前结论

**状态：🔄 进行中（2026-08-04）。** ODC-01 锁定基线、ODC-02 首轮能力映射、`image-codecs`、`qrcode`、`form-pattern` 三个 capability 的正反公开面门禁，以及首个无调用点死依赖清理已建立，但 app/ui/draw/data 的整体能力分区与 backend/target/产物完整矩阵仍未完成，尚未满足完整的使用方按需编译契约。使用文档不得在总门禁通过前把本目标描述为已交付能力。

## 已有基础

- `ash`、`glow`、`khronos-egl`、`serde`、`serde_json` 中的一部分已是 optional dependency，并由 backend、`settings-serde` 或 `agent-control` feature 接入。
- Windows、Unix、Wayland 等平台依赖已有 target `cfg` 边界，非目标平台依赖不会无条件进入同一目标构建。

以上只说明存在基础设施，不等于使用方应用已经做到“只编译所用部分”。

## ODC-02 首轮能力映射

首轮事实盘点见[使用方按需编译能力映射](../架构/使用方按需编译能力映射.md)。当前结论是：backend、`settings-serde`、`agent-control`、`image-codecs`、`qrcode` 与 `form-pattern` 已有 feature 边界，但 app/ui/draw/data 的整体 capability 仍未独立裁剪；字体与基础绘制依赖仍需逐项判断，`tracing-subscriber` 已确认只归属演示程序并等待独立 feature 隔离。`raw-window-handle` 经源码调用点与反向依赖树核对后确认仅为主 crate 的无引用直接依赖，已删除且不再归入候选 capability。`image-codecs` 只裁剪第三方压缩格式解码与路径型公开方法，核心 RGBA 位图、裁剪、离屏和预加载句柄绘制仍属于基础契约；`form-pattern` 只裁剪正则规则，基础表单模型和非正则校验仍属于常驻能力。该状态不等于已完成使用方按需编译门禁。

## 实施顺序

1. **基线**：固定工具链、目标平台、clean-build 条件和三个代表性使用方应用，得到未经改造的编译与产物验证。
2. **能力图**：从第三方依赖和大体积组件开始划 capability feature，写明传递依赖与不兼容组合。
3. **编译隔离**：先 optionalize 专属依赖，再对 module 加 `cfg`；同 crate 隔离仍不足时才拆独立 crate。
4. **公开面收缩**：同步门面、`prelude`、示例和未启用能力的编译错误，不保留绕过 feature 的公开路径。
5. **使用方门禁**：执行最小、单能力、backend / target、全能力矩阵，检查依赖图、clean-build 计时与 release 产物。
6. **交付**：门禁通过后再修改使用文档和默认 feature 策略，并记录兼容性影响与迁移方式。

## 完成门禁

只有同时满足以下条件，状态才能改为“✅ 已完成”：

- 至少一个最小 GUI 使用方 fixture 能在关闭默认 feature 后，仅启用明确列出的能力完成 clean release build。
- 未选能力的专属依赖不出现在该 fixture 的 Cargo resolved graph 与构建日志中。
- 每个公开 capability feature 都有独立或声明组合的编译验证；默认、无默认、单 backend 与全能力矩阵通过。
- 至少选取图像/二维码、富文本/正则、Settings serde、Agent 和两个图形 backend 做“启用前后”产物对比，证明专属内容只在启用后出现。
- 使用方最小集与完整集在同条件下记录 clean-build 时间和 release 二进制大小；结论绑定工具链、target、feature 集与 commit。
- 使用文档明确说明 feature 选择、默认集合和迁移方式，不把运行时开关写成编译期裁剪。

## 风险

- Cargo feature 会在整个依赖图中合并；任一传递依赖重新启用能力，都会使其进入构建。
- 过细 feature 会放大组合数量与维护成本，过粗 feature 又无法减少编译成本；粒度必须用基线数据决定。
- 修改默认 feature 或条件导出属于使用方可见兼容性变化，实施时需单独评估版本与迁移策略。
- 二进制变小不能单独证明未用能力没有参与编译；必须同时检查 resolved graph、clean build 和产物。
