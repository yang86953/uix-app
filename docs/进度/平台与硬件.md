## Windows 图形现状

- 工作树分母为 92 项（87 Widget、3 Composite、2 Provider），包含 663 个声明状态；现有 wgpu 报告含 847 条证据行、329 张原图与 22 张联系表，标记为 `UNVERIFIED`。
- Windows build 26200、NVIDIA、96 DPI 下已有 `Auto → Vulkan`、强制 Vulkan与 Software 整体回退的工作树报告。Software 报告由测试夹具请求 Windows 不支持的 `metal` 后触发，不代表生产 `Auto` 的自然失败路径。
- `0.0.1` 的最低平台定义为 Windows 11 24H2 x64（build 26100），release 只含默认 `vulkan` feature；D3D11、D3D12、OpenGL / OpenGLES 与 Metal 不进入本版本交付构建。
- 144 / 192 DPI、AMD、Intel、最低 build 26100、真实 compositor occlusion、多窗与 DeviceLost 组合暂无当前报告。
- Vulkan 当前报告 `present_occlusion=unsupported`；现有最小化 / 隐藏恢复数据只反映窗口生命周期恢复。
