# 平台与硬件

> 跨平台、多硬件与 Agent 安全的活跃差距。总览见[进度](../进度.md)。

<a id="agent-附能力"></a>

| 类 | 项 | 依赖 / 边界 |
|----|-----|------|
| 跨平台 / 多硬件 | Windows Vulkan/NVIDIA 的 88 组件、412 状态逐组件视觉矩阵已闭合（旧基线）；Wayland fault / resize / parity / occlusion v6+、macOS / Wayland 真机及 AMD / Intel 同等视觉/图形矩阵未闭合；**新 wgpu 基线**上的组件视觉矩阵需重跑 | 仍需对应平台与硬件环境；本机仅 Windows/NVIDIA 可冒烟 |
| Agent 附能力 | AGENT-R1：Windows 当前 `TokenUser` SID 准入与合成异账号 SID 拒绝已有 Authz 证据；Linux / macOS 尚缺真实异 uid 进程拒绝路径 | 仍需双账号或隔离的异 uid 环境 |
