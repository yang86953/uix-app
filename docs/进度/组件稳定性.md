## 共享 LayoutEngine · 有限几何不变量

- **修复**：BoxModel、空 Flex/Grid 与病理测量输入可把非有限值、负尺寸或 `f32::MAX` 哨兵写入实际输出；共享入口现统一归一 frame、总尺寸、子测量、margin、border/padding、gap 与弹性因子。
- **规格**：实际坐标必须有限且不得为无界哨兵，实际尺寸必须有限非负；有限负坐标与 margin 保留既有语义，border/padding 和 Grid gap 收敛为非负；正常 Flex/Grid 精确几何不得因防御性归一化改变。
- **验证**：`7de6fcd8`；`cargo test --locked --test layout_invariants` 5/5，`cargo test --locked --test ui_public_api` 2/2，`cargo test --locked --lib` 97/97，`cargo check --locked --no-default-features --lib` 与 `cargo check --locked --all-features --all-targets` 均为 0 错误。修复前四个病理输入用例均可复现失败。
- **备注**：本条是跨组件布局审计的首批记录，不计入上方 42 项历史组件修复；完整 Flex/Grid 边界、measure/paint/hit-test 一致性、增量缓存及真窗视觉矩阵仍未闭合。

## 共享 FlexLayout · 弹性分配与换行边界

- **修复**：grow/shrink/Stretch 遇到 min/max 后只固定轮数重试或不再分配，可能留下尾部空白或整行越界；wrapped 在落实 min/max 前分行和计算行高，可能错分行或让相邻行重叠；零主轴 bootstrap 会把固有 wrapped 子项压成零；Center/End 未先扣非对称交叉轴 margin，单行总尺寸也漏记 margin。
- **规格**：min/max 先于分行生效；触顶/触底项冻结后，剩余空间持续交给仍可伸缩兄弟，全部到界才允许留白或溢出；无真实主轴约束时 wrapped 保持自然尺寸；对齐在扣除 margin 的可用交叉轴内计算，单行、多行、固有尺寸与反向镜像复用同一行账本。
- **验证**：`7e03fe41`；六个新增聚焦断言修复前失败；修复后 `cargo test --locked --test layout_invariants` 9/9、`cargo test --locked --lib ui::layout::flex::tests` 4/4、完整 lib 101/101、公开 API 2/2、使用门面 5/5，`cargo check --locked --no-default-features --lib` 与 `cargo check --locked --all-features --all-targets` 均为 0 错误。
- **备注**：常规无钳制路径保持线性遍历且不新增分配，只有子项实际触及 min/max 时进入至多“子项数加一”轮的有界再分配。本条仍不代表 Grid、Flex 其余方向/justify/align 组合、组件级布局、增量缓存或真窗矩阵已经闭合。

## 共享 GridLayout · 自动轨道与 span

- **修复**：`Auto` 与 `Fr` 被合并为弹性权重，导致纯 `Auto` 网格无条件填满容器、`Auto + Fr` 错分剩余空间；轨道解析未读取子项测量尺寸与 margin，跨多条 `Auto` 的子项也不会撑开 span。
- **规格**：`Auto` 在列/行轴分别取子项有限外宽/外高，`Px` 与 `Auto` 优先确定，正权重 `Fr` 仅分配剩余空间；不含正权重 `Fr` 的 span 先扣除已知轨道与内部 gap，再将缺口均分给所覆盖的 `Auto`。
- **验证**：`33721e4a`；三个列轴聚焦断言在修复前失败，修复后补入行轴对称覆盖；`cargo test --locked --test layout_invariants` 13/13、完整 lib 101/101、公开 API 2/2、使用门面 5/5，`cargo check --locked --no-default-features --lib` 与 `cargo check --locked --all-features --all-targets` 均为 0 错误。
- **备注**：显式超大 `grid_cell`/`row_span` 的资源风险已由下一批有界放置闭合；Grid/Flex 其余方向、justify/align/span 组合、组件级布局、增量缓存与真窗矩阵仍未闭合。

## 共享 GridLayout · 有界放置与资源预算

- **修复**：显式 `grid_cell`/`row_span` 可按请求行号直接扩张稠密 occupied、rows 与 positions，乘法/加法溢出与过量分配可在 frame 求解前发生；自动放置没有总行上限，且每次扩一行后会从头重扫 span 面积。
- **规格**：单轴最多 4096 条轨道、稠密占用账本最多 65,536 个单元格；超限轨道/cell/span 收敛到窗口边界，显式重叠保留，自动放置仍按行优先稠密回填，耗尽时留零 frame。二维前缀和让矩形占用查询为常数时间，扩行尝试至多一次。
- **验证**：`f2ccba05`；两个 5000 行级安全聚焦断言修复前失败，修复后补入 `usize::MAX`/`u32::MAX`、预算耗尽、行优先回填与 4608 组小矩阵穷举对照；公开布局契约 16/16、内部放置边界 6/6、完整 lib 107/107、公开 API 2/2、使用门面 5/5，`cargo check --locked --no-default-features --lib` 与 `cargo check --locked --all-features --all-targets` 均为 0 错误。
- **备注**：本条闭合 Grid 放置层的已知资源/算术风险，不代表 Grid/Flex 其余方向、justify/align/span 组合、组件级布局、增量缓存或真窗矩阵已闭合。

## 共享 Grid/FlexLayout · 逐项对齐与溢出方向

- **修复**：Grid 公开入口把子项 `align_self` 固定丢为 `None`，容器默认 Stretch 会覆盖逐项 End/Center；Flex 溢出路径忽略 justify，反向游标从错误起点继续递减，Center/End 也未先扣除非对称交叉轴 margin。
- **规格**：Grid 逐项交叉轴覆盖必须进入单元格求解；溢出 Flex 只保留自然主轴尺寸，不取消 justify、align、gap 或方向语义。正剩余空间复用标准分布函数，交叉轴在扣除两侧 margin 后对齐，反向方向先按逻辑顺序放置再沿容器主轴镜像。
- **验证**：`40e66b65`；Grid 覆盖、溢出交叉轴、反向与 justify 四个聚焦断言在修复前失败；修复后 `cargo test --locked --test layout_invariants` 20/20、完整 lib 107/107、公开 API 2/2、使用门面 5/5，`cargo check --locked --no-default-features --lib` 与 `cargo check --locked --all-features --all-targets` 均为 0 错误。
- **备注**：溢出路径没有新增主轴尺寸副本或增长/压缩阶段，只复用已有 justify 计算并原位镜像结果；Grid 其余 justify/span、Flex overflow 与 wrap/固有轴组合、组件级布局、增量缓存与真窗矩阵仍未闭合。
