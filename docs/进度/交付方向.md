## 未排期目标：性能与资源持续优化

**状态：📋 规划中（未排期）。** 在不牺牲正确性、稳定性、可恢复性和跨平台一致性的前提下，持续降低使用方应用的启动与首帧时间、输入响应和稳定帧成本，并减少 CPU、GPU、内存、线程、磁盘 I/O、缓存与空闲能耗。使用方的编译成本和 release 产物体积由[使用方按需编译](使用方按需编译.md)目标持有。

本条只确立长期优化方向，不代表已经立项或正在执行；当前不指定开始时间、执行顺序、量化预算或绑定版本。未来决定执行时，先为目标平台和代表性场景建立可复现基线，再单独确定预算、优先级与验收门禁。

## 更小 · 更快 · 更稳

### 更小：缩小内存占用

- **wgpu 基线**：生产 module graph 不再编译 D3D11/D3D12/OpenGL/Vulkan 的平行 UI raster 实现；一套 WGSL、四类 pipeline；一个按需扩容 vertex buffer、1024×1024 R8 与 RGBA8 字形 atlas 与 GPU offscreen RT 服务全部 adapter
- **实测**：Windows/NVIDIA release、1200×800、中文 Demo 首屏稳定 5 秒后，Vulkan working set 约 142 MiB、D3D12 working set 约 112 MiB；2026-08-01 内存批次（字体 mmap + 零复制）后 AMD RX 5700 空窗口 116.2 MiB / 默认首页 127.1 MiB（详见[性能与内存](性能与内存.md)）
- **已做**：字形缓存 LRU 2048 项/8 MiB、Picture 32 MiB 硬预算、DisplayList COW Arc 共享、主画布 scratch 1×1、Label/Input 直接移交单次绘制的新 glyph layout、1920×1080 resize 不再分配未用 CPU 主表面（约 −7.91 MiB）
- **瓶颈**：GPU 驱动/shader compiler 映射与中文字体常驻；wgpu 统一层本身有固定运行时开销
- **使用方构建**：目标是未选择且非传递必需的能力不进入应用编译图，已选择但不可达的代码不进入 release 产物；当前处于规划阶段，详见[使用方按需编译](使用方按需编译.md)
- **目标**：逼近同体量 GPU-only 框架内存水平，并让应用只承担实际选择能力的构建与产物成本

### 更快：降低每帧耗时

- **已做**：生产只有一个 `draw::Renderer`；相邻同类 op 在 API 中立层合批；`retained_framebuffer` 解锁绘制侧 partial dirty；多块脏区逐矩形 clear+clip 重绘；真实 Vulkan 首帧约 14.6 ms、稳定后采样帧约 4.7 ms
- **热路径 scratch 复用**：Layout 遍历复用扩展签名/已调整子节点集合；Flex/Grid/溢出流式不分配主轴尺寸副本；Overlay 新旧签名流式比较；Timer discovery 复用 route map
- **布局失效优化**：同节点 Layout 队列项去重但 revision 仍逐请求推进；向上传播复用每树祖先链缓冲
- **到期工作清退**：registry 在一次有序 retain 扫描中处理；动画注册原位同步不逐帧重建 desired map
- **瓶颈**：`ab_glyph` 仍是逐 Unicode 标量的 advance/kerning 与 CPU 轮廓提取；MSDF 多通道 atlas 已落地但大字号真机视觉矩阵未闭合
- **目标**：稳定 60Hz

### 更稳：跨平台真机现状

- **已有数据**：Windows 11 build 26200/NVIDIA/96 DPI release 真窗包含 Auto→Vulkan、强制 Vulkan、最小化/隐藏后恢复；device lost 与 uncaptured wgpu error 已接入 typed 恢复/日志边界
- **数据缺口**：最低支持 build 26100 实机、144/192 DPI、AMD、Intel、Wayland 和 macOS 暂无当前报告；92 项组件视觉矩阵（847 条证据/329 张原图）标记为 UNVERIFIED
- **目标**：四平台同等视觉/图形矩阵
