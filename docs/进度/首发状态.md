## 当前状态

`0.0.1` 是 UIX 的首个正式版本号，面向 Windows x64 内部使用，当前仍是**未发布**。版本号、公开 API 和可编译示例已经进入工作树，第 4～8 批 110 项已有定向实现与行为验证；当前证据仍来自工作树，144 / 192 DPI、AMD / Intel、长稳、性能和正式内部包没有当前报告。

产品范围与非目标以[产品](../产品.md)为准，公开写法以[使用](../使用.md)及其分卷为准，运行时与图形机制以[架构](../架构.md)为准。本页只记录版本状态、内部交付形态和功能范围。当前组件分母为工作树中的 92 项（87 Widget、3 Composite、2 Provider）；旧 wgpu 基线前的 88 组件 / 412 状态数字只属于其日期报告。

移动端、macOS、Wayland、Windows ARM64、网络 / 同步、读屏桥与 Agent 开发预览不属于本版本范围。`0.0.1` 是 `yangyanhui` 持有版权的闭源内部版本：保持 `publish = false`，不发布到 crates.io，不提供公开源码或对外二进制制品，仅限获授权的内部环境使用与分发。

### 内部交付形态

- **载体**：`uix-0.0.1-internal-win-x64.zip`，包含 release `uix-demo.exe`、内部源码包 `uix-0.0.1.crate`、`LICENSE`、`THIRD_PARTY_NOTICES.md`、`CHANGELOG.md`、`README.md` 与 `SHA256SUMS.txt`。不生成公开下载、安装器或公开符号包。
- **平台**：最低 Windows 11 24H2 x64（build 26100）；Windows ARM64 与旧版 Windows 不在支持范围。
- **release 配置**：默认 `vulkan` feature；`d3d11`、`d3d12`、`opengles`、`metal`、`settings-serde`、`agent-control` 与 `test-harness` 不进入交付构建。生产 `Auto` 对应 Vulkan → Software 整体回退。
- **当前证据**：Windows build 26200、NVIDIA、96 DPI 的工作树报告覆盖 `Auto → Vulkan`、强制 Vulkan、Software 整体回退和 92 项组件视觉矩阵，标记为 `UNVERIFIED`。AMD、Intel、144 / 192 DPI、长稳与正式内部包暂无当前报告。
