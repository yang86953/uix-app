# 原生平台层

> 分类：原生平台层
> 权威范围：native 公开面收口、硬件 API 与内部边界重构的活跃差距

目标契约见[架构 · 原生平台层](../架构/原生平台层.md)，目标写法见[使用 · 平台能力](../使用/平台能力.md)。

## 当前事实

- `native` 当前同时公开 factory、presenter、services、shared、traits 与 test harness；prelude 还重导出 `create_platform`。外部可到达 backend recipe、`IGraphicsContext`、`PlatformWindow`、`NativeSurfaceHandle`、窗口共享实现和 IME 队列辅助函数。
- `Platform` 以 14 个可变 getter 聚合窗口、事件循环、事件总线、输入和系统服务；它既是内部资源 owner，又表现为公开 service locator。
- 平台服务的失败语义不一致：剪贴板、光标、通知、timer 和显示查询缺少 typed `Result`；文件对话框用空 `String` / `Vec<String>` 混合取消与失败；路径统一为 UTF-8 `String`。
- 当前硬件公开数据只有 `MemoryInfo`、`OsInfo` 与 `DisplayInfo` 等零散类型。生产 wgpu 初始化会读取并记录选中 adapter 的名称、device type 和 driver，但没有公开 GPU inventory、backend build / runtime availability 或逐窗 active device snapshot。
- 现有 `GraphicsBackend` 同时包含选择策略 `Auto`、生产 backend 和 test-only D3D11；Windows 生产 registry 没有 D3D11 行。backend registry / recipe 却是默认公开面的一部分。
- `tests/native_public_api.rs` 只有两个允许路径测试，未定义禁止泄出的 API 清单。`src/native` 没有独立行为测试；`cargo test --lib` 主要充当 test-only module graph 的编译 canary。
- 重构前基线中，Windows 的纯 `--no-default-features` 与单 `opengles` library check 因 `graphics/platform/windows.rs` 的 `drawable_size` cfg 遗漏而失败；`all-features`、单 `d3d11` 与单 `d3d12` check 可通过。

## 活跃差距

| 差距 | 完成条件 |
|---|---|
| 公开 facade 尚未落地 | 新建 `uix::platform` 消费门面，只公开 capability、input、services、hardware、graphics 与 handle/request 值；`crate::native` 转为内部实现，默认 rustdoc 不再出现 backend SPI |
| PlatformHandle 执行模型缺失 | `AppHandle::platform()` 可用且无全局 current；App 级 completion queue 独立于 WindowSession，App 作用域请求可跨来源窗口关闭继续；request 激活前无副作用，受理前 Closed 与受理后 Cancelled 分离；慢操作可取消，成功注册的完成回调不内联并恰好投递一次 |
| 硬件与 GPU inventory 缺失 | OS / CPU / system memory / process memory / display 基础快照和 opt-in GPU adapter refresh 有 generation、逐类 Available / Unavailable / Failed 状态与外部契约测试 |
| 图形配置与当前设备混合 | `GraphicsBackend` 只表示实际 API；选择策略进入 `GraphicsOptions`；逐窗 runtime 可区分 GPU / Software、恢复与 fallback |
| 原生服务错误语义不足 | clipboard、dialog、notification、paths 使用 typed result、`PathBuf` 与显式 cancelled outcome |
| User activation 契约缺失 | 键盘 / 指针派发可产生 opaque、短期、窗口作用域 token；Wayland 等需要 compositor serial 的服务在 token 缺失 / 过期时 typed NotReady，不泄露或伪造 raw serial |
| 内部模块仍泄露 | factory、registry、presenter、graphics context、raw surface、shared、backend 和 IME/event helper 转为 crate-private |
| 类型归属倒置 | `ControlSize` / `ScrollDirection` 归 UI；FileService 归 app/data 便利层；native 只拥有 OS 能力 |
| cfg / 跨平台证据不足 | 修复无 feature / OpenGLES 基线；Windows feature 矩阵与 Windows GNU/MSVC、Linux、macOS 目标 check 通过 |

目录移动不是完成证据。每一阶段须以外部允许/拒绝 API 编译契约、feature matrix、typed 失败和现有主循环 / 图形恢复回归为准；Wayland / macOS 真机能力仍由[平台与硬件](平台与硬件.md)拥有。
