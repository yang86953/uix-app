# 原生平台层

[← 返回进度 索引](../进度.md)

> 分类：原生平台层
> 权威范围：platform 公开面、硬件 API 与 native 内部边界的活跃差距

目标契约见[架构 · 原生平台层](../架构/原生平台层.md)，目标写法见[使用 · 平台能力](../使用/平台能力.md)。

## 当前事实

- `native` 当前同时公开 factory、presenter、services、shared、traits 与 test harness；prelude 还重导出 `create_platform`。外部可到达 backend recipe、`IGraphicsContext`、`PlatformWindow`、`NativeSurfaceHandle`、窗口共享实现和 IME 队列辅助函数。
- 当前 `Platform` 是包含 14 个 getter 的公开 trait/service locator，调用方可以实现 OS SPI，也能取得内部可变子系统。
- 平台服务失败语义不一致：剪贴板、光标、通知、timer 和显示查询缺少 typed `Result`；文件对话框用空 `String` / `Vec<String>` 混合取消与失败；路径统一为 UTF-8 `String`。
- 现有 `OsInfo`、`MemoryInfo`、`DisplayInfo` 已有平台采集实现，但公开字段、失败兜底和类型边界不适合稳定 API。`MemoryInfo` 还混入 `usize` 进程内存。
- 生产 wgpu 初始化会读取 adapter 名称、device type、driver 和 limits，但只用于日志 / 校验，没有中立的公开 `GpuAdapterInfo`。
- 当前 `GraphicsBackend` 同时包含选择策略 `Auto`、生产 API 和非生产 D3D11；registry / recipe 又是默认公开面的一部分。
- `src/native` 的真实源码依赖方向基本向下，除注释外不依赖 `app`、`ui` 或 `draw`；但目录仍包含 shader、glyph atlas、blur 和 raster executor 等 renderer 实现。
- `tests/native_public_api.rs` 只有两个允许路径测试，没有拒绝内部 SPI 的 compile-fail 契约。
- Windows 的纯 `--no-default-features` 与单 `opengles` library check 因 `graphics/platform/windows.rs` 的 `drawable_size` cfg 遗漏而失败；`all-features`、单 `d3d11` 与单 `d3d12` check 可通过。

## 活跃差距

| 差距 | 完成条件 |
|---|---|
| 公开根错误 | `uix::platform` 只公开具体 `Platform` 与 services / hardware / graphics 值；`uix::native` 整体不可达 |
| 重复基础抽象 | 公开面直接使用 `core::Result/Error/Errc` 与 `Rect`；不存在 PlatformError、PlatformResult、hardware snapshot、request、cancellation、subscription、capability registry 或 completion queue |
| Platform 仍是 SPI | `Platform` 改为字段私有、`!Send + !Sync` 的具体类型，唯一入口为主线程上的 `Platform::new()`；同一时刻单实例、失败完整回滚、owner-thread Drop 且不重入用户代码；所有 `I*` trait 与 OS provider 变为 crate-private |
| 系统 DTO 不稳定 | `OsInfo`、`MemoryInfo`、`DisplayInfo` 原位修正，只新增 `CpuInfo`；OS / CPU / memory / displays 分别返回现有 `Result`，不增加 snapshot 或无消费者的 DisplayId |
| GPU 公开面缺失 | 按具体 `GraphicsBackend` 同步返回 owned `Box<[GpuAdapterInfo]>`；信息值只有稳定描述字段，不发布无消费者的 ID / handle / lease |
| 图形枚举混入策略 | `GraphicsBackend` 只表示实际 API；platform 不公开 Auto、options builder、power preference、CPU fallback、逐窗 runtime 或恢复状态 |
| 服务边界过宽 | 公开面只保留可独立完成的 OS-known directory 与 system notification；移除 timer、console、普通文件读取及 Temp / Current / Executable 路径包装；clipboard / dialog 保持 crate-private，不预埋 activation、callback 或 request API |
| 非平台实现滞留 | shader、glyph atlas、blur、raster command / executor 和 renderer recovery 不再属于 native；native 只保留 OS、输入、硬件、window/device/surface/presentation 边界 |
| 类型归属错误 | `ControlSize`、`ScrollDirection`、`StatusLevel`、toast、`FileService` 及其他非平台类型从 native 直接删除 |
| 公开证据不足 | allowlist 覆盖全部目标值并静态断言 owned info 为 `Clone + Send + Sync`；compile-fail 拒绝 `uix::native`、backend SPI、raw handle、context、厂商对象和默认构建下的 fake |
| cfg / 跨平台证据不足 | 修复无 feature / OpenGLES 基线；Windows GNU/MSVC、Linux、macOS target 与单 feature / all-features 矩阵通过 |

## 直接切换约束

- 目标实现一次性删除旧公开模块和重导出，不添加 deprecated alias、兼容 facade 或新旧 DTO 双轨。
- 不为保持旧调用路径而保留 factory、service trait、raw handle 或 test fake 的公开可达性。
- 本文只跟踪 platform/native 自身事实，不设计其他层的接入、迁移或调度策略。

目录移动不是完成证据。完成必须同时满足公开 allowlist、内部 denylist、typed 失败、线程亲和、FFI teardown、feature matrix 与目标平台构建。
