| ScatterChart | 待实现 | 散点图、气泡图(`BubbleData`)、多系列、自定义点样式 |
| RadarChart | 待实现 | 雷达图、多边形/圆形网格(`RadarShape`)、`.grid_levels()` |
| Heatmap | 待实现 | 热力图、颜色映射(`.color_range`)、日历模式(`.calendar_mode`) |
| FunnelChart | 待实现 | 漏斗图、对称漏斗(`FunnelShape::Symmetric`)、转化率显示 |
| WaterfallChart | 待实现 | 瀑布图、增加/减少/汇总柱(`WaterfallKind`)、横向 |

| Gauge | 待实现 | 仪表盘、半圆/全圆/细环(`GaugeType`)、分段色(`.range_colors`) |
