## 当前可证明基线（2026-07-22）

- `Cargo.toml` 与 lockfile 根包版本已是 `0.0.1`，但这只是版本元数据，不代表已经发布。
- `docs/使用/**/*.md` 有 214 个带唯一 `uix-compile` 的 Rust fence，目标 `text` fence 为 0；Markdown 清单按声明 feature 验证为 214 / 214 通过，其中 211 个基础、3 个 opt-in。
- 第 4～8 批 110 项已从 `uix::prelude` 公开，并完成配置消费、关键交互 / reconcile 与边界行为的定向回归；当前未发现仍然只保存配置而不形成约定行为的范围项。现有结果不包含 110 项逐项真窗数据。
- 图标已收敛为单一组件管线：应用 View 使用 `Icon::new(...)`，内置紧凑槽位使用 `Icon` 自有嵌入入口；图表数据标记和控件几何不计作图标。
- `Table` 的远程分页、行点击与合并单元格，以及 `Tree` 的搜索、拖放、懒加载与节点图标均进入测量、绘制、命中、回调和 reconcile 路径；Table 有 43 个、Tree 有 18 个定向测试，暂无逐项真窗数据。
- `Carousel` 的 autoplay、手动暂停 / 恢复、hover 暂停、Fade 动画 / 绘制、自定义双向箭头及 reconcile 已进入真实组件路径，并有 18 个定向测试；暂无逐项真窗数据。
- `ImageGroup` 已具备主图 / 缩略图导航、键盘、全 surface 模态预览、遮罩关闭、防穿透、语义与重复路径 reconcile，并有 11 个定向测试；暂无逐项真窗数据。
- `FloatButtonGroup` 已具备 Hover / Click / Focus / ContextMenu 展开、键鼠匹配与取消、动画布局、可见性 / 命中、语义及 reconcile，并有 11 个定向测试；暂无逐项真窗数据。
- `Calendar::date_cell` 已物化稳定日期子树并随月份 / 选中态刷新，`events` 以日期数据标记进入真实绘制；Calendar 相关 19 个测试通过。第 5、6、7、8 批也有定向行为回归。
- [0.0.1 功能账本](功能账本.md)覆盖 110 / 110 项，记录公开入口、实现位置、测试位置与当前工作树的 `targeted-verified` 状态。
