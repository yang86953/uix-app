## 当前仍未闭合的退出条件

定向实现收口后，G1 仍不能通过，原因已从“确认存在配置空壳”转为候选级证据未完成：

- 尚未在同一冻结候选上完成全 target / feature、严格 Clippy、全部自动化与文档门禁；任何集成失败都会重新打开对应条目。
- 110 项账本尚未绑定冻结候选 commit、候选全量结果和逐项真窗场景 / 等价集成报告；当前 0 / 110 项满足关闭条件。
- 当前工作树组件 QA 分母已重建为 92 项（87 Widget、3 Composite、2 Provider）；新 wgpu Vulkan 的 fail-closed 真窗矩阵已生成 847 / 847 PASS 证据行、329 张原始 PNG 与 22 张联系表，人工视觉 QA 未发现 P0 / P1。该分母和结果仍是 `UNVERIFIED`，须绑定 clean 冻结候选，不能据工作树截图关闭 gate。

若后续全量或真窗验证发现行为缺口，应在这里恢复为精确组件条目，不用“已有定向测试”掩盖失败。

## 发布环境证据

G1 逐项功能关闭后，组件发布仍须补齐：

- 冻结公开库存 × 适用状态在新 wgpu 基线上的浅色桌面、深色紧凑及独立交互证据；
- Windows x64 的三档 DPI、窗口生命周期、焦点 / 浮层 / 多窗及 DeviceLost 主路径；
- release feature 对应的硬件 / backend、长稳、性能与缺陷分级报告。

旧的 88 组件 / 412 状态报告只证明其日期和旧渲染基线，不能关闭当前 gate。证据格式、重开规则和其他发布阻断项见[0.0.1 首发计划](../进度.md#001-首发计划)。
