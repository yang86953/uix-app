## 全面布局检查

首批审计确认共享 BoxModel/Flex/Grid 在空子集、无界约束与病理数值下可能把非有限值、负尺寸或 `f32::MAX` 测量哨兵物化为实际输出；该批缺陷已由 `7de6fcd8` 修复并以五项布局契约测试闭合，当前没有遗留的同类已确认缺陷。

第二批审计确认 Flex 的 min/max 再分配、wrapped bootstrap、交叉轴 margin 对齐与单行行账本共有六个可复现失败；该批缺陷已由 `7e03fe41` 修复，并以九项公开布局契约及四项内部 Flex 边界测试闭合，当前没有遗留的同类已确认缺陷。

第三批审计确认 Grid 把 `Auto` 轨道当作等权 `1fr`、未从子项外尺寸解析自动列/行，且跨多条 `Auto` 的子项不会撑开 span；该批缺陷已由 `33721e4a` 修复，修复前三个列轴聚焦断言失败，修复后含行轴对称覆盖的十三项公开布局契约全部通过，当前没有遗留的同类已确认缺陷。

第四批审计已由 `f2ccba05` 闭合上述 Grid 放置资源/算术风险：单轴轨道与稠密单元格现有双重预算，超限 `grid_cell`/span 确定性收敛，自动放置无界扩行改为至多一次有界扩展与常数时间矩形查询。两个 5000 行级安全断言在修复前失败，修复后含整数极值、预算耗尽与穷举搜索对照的十六项公开布局契约及六项内部放置边界全部通过，当前没有遗留的同类已确认缺陷。

第五批审计确认 Grid 公开入口丢弃子项 `align_self`，Flex 溢出路径忽略 justify、错误处理反向游标，并在 Center/End 上重复叠加非对称交叉轴 margin；该批缺陷已由 `40e66b65` 修复。四个聚焦断言在修复前失败，修复后二十项公开布局契约全部通过，当前没有遗留的同类已确认缺陷。

Grid 其余 justify/span 组合、Flex overflow 与 wrap/固有轴组合、组件自有布局辅助、measure/paint/hit-test 一致性、增量缓存与真窗视觉矩阵仍在检查中；这些待核验范围不在发现证据前登记为活跃缺陷。


## 窗口布局

当前没有已确认仍活跃的窗口布局缺陷。

Windows Vulkan 真实窗口回归覆盖情况：
- 自定义标题栏贴合窗口顶边并铺满宽度
- 状态栏贴合窗口底边
- 原生客户区从 1200×800 调整为 1040×680 后，根视口与页面滚动视口同步重排
- 同场景的最大化/还原、最小化恢复和主题切换已通过

自定义标题栏路径：
- 以 `WM_NCCALCSIZE` 扩展客户区
- 外窗与客户区保持同尺寸
- 防止 `WS_THICKFRAME` 非客户区留白再次透出桌面

上述断言保留在 `agent_gui_windows` 与 Windows platform 回归中。

## 交互视觉

当前没有已确认仍活跃的交互视觉缺陷。

焦点视觉的模态区分：
- 指针模态：左键点击导航、菜单、按钮及同类 action / selection 控件时，保留逻辑焦点但不绘制额外焦点环
- 键盘模态：使用键盘、语义 `focus` 或 `FocusHandle` 聚焦时，显示焦点提示

Windows Vulkan 真实窗口回归包含两种模态的自动化与像素差异断言。
