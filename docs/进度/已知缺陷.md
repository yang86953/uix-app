## 窗口布局

当前没有已确认仍活跃的窗口布局缺陷。

Windows Vulkan 真实窗口回归已覆盖自定义标题栏贴合窗口顶边并铺满宽度、状态栏贴合窗口底边，以及原生客户区从 1200×800 调整为 1040×680 后根视口与页面滚动视口同步重排；同场景的最大化/还原、最小化恢复和主题切换也已通过。自定义标题栏路径另以 `WM_NCCALCSIZE` 扩展客户区，单元测试断言外窗与客户区同尺寸，防止 `WS_THICKFRAME` 非客户区留白再次透出桌面。上述断言保留在 `agent_gui_windows` 与 Windows platform 回归中。

## 交互视觉

当前没有已确认仍活跃的交互视觉缺陷。

焦点视觉现已区分指针与键盘模态：左键点击导航、菜单、按钮及同类 action / selection 控件时保留逻辑焦点但不绘制额外焦点环；随后使用键盘、语义 `focus` 或 `FocusHandle` 聚焦时仍显示焦点提示。Windows Vulkan 真实窗口回归保留了两种模态的自动化与像素差异断言；裸百分比不跨报告沿用，正式数值须绑定同一候选的证据报告。
