## 窗口布局

当前没有已确认仍活跃的窗口布局缺陷。

Windows Vulkan 真实窗口回归已覆盖自定义标题栏贴合窗口顶边并铺满宽度、状态栏贴合窗口底边，以及原生客户区从 1200×800 调整为 1040×680 后根视口与页面滚动视口同步重排；同场景的最大化/还原、最小化恢复和主题切换也已通过。上述断言保留在 `agent_gui_windows` 回归中，防止内容留白与 resize 不响应再次出现。

## 交互视觉

### 点击元素出现焦点边框

**描述**：点击导航按钮、菜单栏、按钮等时会出现一个边框。

**表现**：点击任意可交互元素（导航按钮、菜单项、按钮等）后，元素周围会绘制一个焦点/选中边框，影响视觉效果。

**影响范围**：所有可交互组件。

**复现**：启动应用，点击任意导航按钮、菜单栏或按钮，观察是否出现非预期边框。

**优先级**：低。
