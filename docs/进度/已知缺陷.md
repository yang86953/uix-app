## 全面布局检查

首批审计确认共享 BoxModel/Flex/Grid 在空子集、无界约束与病理数值下可能把非有限值、负尺寸或 `f32::MAX` 测量哨兵物化为实际输出；该批缺陷已由 `7de6fcd8` 修复并以五项布局契约测试闭合，当前没有遗留的同类已确认缺陷。

第二批审计确认 Flex 的 min/max 再分配、wrapped bootstrap、交叉轴 margin 对齐与单行行账本共有六个可复现失败；该批缺陷已由 `7e03fe41` 修复，并以九项公开布局契约及四项内部 Flex 边界测试闭合，当前没有遗留的同类已确认缺陷。

第三批审计确认 Grid 把 `Auto` 轨道当作等权 `1fr`、未从子项外尺寸解析自动列/行，且跨多条 `Auto` 的子项不会撑开 span；该批缺陷已由 `33721e4a` 修复，修复前三个列轴聚焦断言失败，修复后含行轴对称覆盖的十三项公开布局契约全部通过，当前没有遗留的同类已确认缺陷。

第四批审计已由 `f2ccba05` 闭合上述 Grid 放置资源/算术风险：单轴轨道与稠密单元格现有双重预算，超限 `grid_cell`/span 确定性收敛，自动放置无界扩行改为至多一次有界扩展与常数时间矩形查询。两个 5000 行级安全断言在修复前失败，修复后含整数极值、预算耗尽与穷举搜索对照的十六项公开布局契约及六项内部放置边界全部通过，当前没有遗留的同类已确认缺陷。

第五批审计确认 Grid 公开入口丢弃子项 `align_self`，Flex 溢出路径忽略 justify、错误处理反向游标，并在 Center/End 上重复叠加非对称交叉轴 margin；该批缺陷已由 `40e66b65` 修复。四个聚焦断言在修复前失败，修复后二十项公开布局契约全部通过，当前没有遗留的同类已确认缺陷。

第六批审计确认固有反向溢出沿零主轴镜像、零交叉轴 Stretch 压扁自然尺寸、Space 丢弃子项 margin，且 Container/Space 内容缓存漏记正尾侧 margin；该批缺陷已由 `e7ad9d55` 修复。两个公开与两个组件聚焦断言在修复前失败，修复后二十二项公开布局契约及两项组件缓存契约全部通过，当前没有遗留的同类已确认缺陷。

第七批审计确认 ScrollView 忽略子项 margin，导致兄弟推进、非滚动轴填充、首轮滚动条判断与内容范围不一致；双轴经典滚动条同时出现时，最大距离还会少算对侧 8px 沟槽。该批缺陷已由 `b5c4f152` 修复。三个聚焦断言在修复前失败，修复后四项内部 ScrollView 契约、二十二项公开布局契约及完整库测试全部通过，当前没有遗留的同类已确认缺陷。

第八批审计确认 VirtualScroll 在窗口变化和 renderer 更新时以 `set_children` 重建全部行，未声明 key 的行也没有确定身份；范围计算还会接受非有限度量，并让极大 viewport/overscan 物化整棵列表，总高度、滚动增量和行 frame 可溢出为非有限值。身份缺陷已由 `5b45c0d9` 以业务/绝对索引 key 的增量协调修复，资源与几何缺陷已由 `cca439f9` 以有限值规则和 4096 行硬预算修复；三项身份与四项病理资源断言修复前失败，修复后八项内部 VirtualScroll 契约及完整库测试全部通过，当前没有遗留的同类已确认缺陷。

第九批审计确认 `ViewAdapter` 将任意组件声明配置变化同时标记 Layout/Paint，导致 `Label` 颜色和 `Container` 背景等纯视觉更新触发无意义布局。该批缺陷已由 `32a5cbf6` 以双通道 patch 影响和 `Label`/`Container`/`Grid` 字段分类修复；两个纯视觉聚焦门禁修复前失败，修复后六项协调分类及完整库测试全部通过，未审计组件继续保守请求布局，当前没有遗留的同类已确认缺陷。

第十批审计确认树布局跳过空直接子集，使 Container/Space/Affix 的旧内容尺寸、ScrollView 的旧内容范围/偏移和 Carousel 的旧幻灯片数量无法依赖空布局分支清理。该批缺陷已由 `8530d29` 以直接子结构通知修复，建树、移除和声明重排统一同步组件派生状态；六项新增结构状态门禁、完整库测试与集成测试全部通过，当前没有遗留的同类已确认缺陷。布局 scratch 与遍历缓存审计未发现同类跨帧语义缓存：本轮存储会清空，遍历缓存受树版本约束，当前也没有跨帧 `LayoutOutput` 快照。

第十一批审计确认固有主轴在非零实际 frame 内按容器 justify 定位后仍按自然内容长度执行反向镜像，且 `overflow_content` 的独立流式路径完全忽略 wrap。该批缺陷已由 `b7f7e5c7` 修复：零尺寸 bootstrap 保留自然长度镜像，非零 frame 改用实际主轴，溢出换行进入共享 Flex 分行器并冻结 grow/shrink；三个聚焦断言修复前分别得到负坐标或未换行，修复后二十五项公开布局契约与完整库测试全部通过，当前没有遗留的同类已确认缺陷。

第十二批审计确认 Grid 对重叠同跨度 `Auto` 约束逐项改写轨道，导致相同 cell/span 约束交换声明顺序后产生不同列起点。该批缺陷已由 `b1aefee` 修复：跨轨道贡献按 span 升序分批，同跨度子项基于统一快照登记每轨最大计划增量后再整批写回；聚焦断言修复前正序/反序末列起点分别为 125px/100px，修复后二十六项公开布局契约与完整库测试全部通过，当前没有遗留的同类已确认缺陷。

第十三批审计确认 Grid 子项跨越 `Auto + Fr`、且 span 外还有其他 Fr 竞争剩余空间时，求解器会跳过自然尺寸约束；一百像素容器中的七十像素子项因此只获得六十像素。该批缺陷已由 `9d86578c` 修复：按全局 Fr 权重把 span 外可让份额转入 span 内 Auto，多个约束使用确定性排序和最多 64 轮单调松弛，在不扩大父级容量的前提下满足可转移约束；聚焦断言修复后子项宽度与末轨起点均为 70px，二十七项公开布局契约与完整库测试全部通过，当前没有遗留的同类已确认缺陷。

第十四批审计确认公开 `Grid::justify` 被错误接到单元格内子项对齐，Center 会把百像素容器中的首项放到 5px，而不是把固定列轨组居中后的 25px，Space 系列也会退化为逐项 Stretch。该批缺陷已由 `d81dbe5b` 修复：新增独立的轨道组内容对齐通道，覆盖六种固定轨道分布、Auto-only Stretch，并保留低层单元格内 `with_justify` 兼容语义；二十八项公开布局契约与一百三十五项完整库测试全部通过，当前没有遗留的同类已确认缺陷。

第十五批审计未在 Grid 覆盖全部 Fr 或没有 Auto 可转移的 span/Fr 组合中发现新缺陷。`41158b3f` 新增三项契约，确认混合 span 覆盖全部 Fr 时服从父级容量，纯 Fr 的列/行 span 保持声明权重并把子项收敛到实际单元格；三十一项公开布局契约与一百三十五项完整库测试全部通过，该待核验范围已闭合。

第十六批审计确认 Flex 单行溢出、标准固有主轴和换行超宽行都在进入统一 justify 前把负剩余空间钳为零，使 Center/End 在内容超过实际主轴时退化为 Start。该批缺陷已由 `518adc67` 修复：零尺寸 bootstrap 继续使用零偏移，实际 frame 保留有限负差值并由 Center/End 分别应用半量/全量负偏移；三项聚焦断言修复前均失败，修复后三十四项公开布局契约与一百三十五项完整库测试全部通过，当前没有遗留的同类已确认缺陷。

第十七批审计确认 wrapped Flex 的自然行账本没有消费容器交叉轴正剩余空间，导致默认 Stretch 在单行时也只保留自然高度，多行时同样不扩展行盒。该批缺陷已由 `6fe836a4` 修复：固定 gap 后的剩余空间均分到各行，行起点随前置扩展同步推进，`align_self` 继续只覆盖项内对齐；两项聚焦断言修复前均失败，修复后三十六项公开布局契约与一百三十五项完整库测试全部通过，当前没有遗留的同类已确认缺陷。

第十八批审计确认 wrapped Flex 以累计主轴占用是否大于零判断当前行是否已有项目，零宽首项会使后续满宽项连同 gap 错误留在同一行。该批缺陷已由 `952912e4` 修复：分行器改用索引范围判断项目存在性，零尺寸项目仍参与行收集与 gap 边界；聚焦断言修复前把第二项放在首行 `x=9px`，修复后三十七项公开布局契约与一百三十五项完整库测试全部通过，当前没有遗留的同类已确认缺陷。

第十九批审计确认 Flex 单行与 wrapped 的最终 Stretch 会覆盖自然尺寸阶段已经应用的交叉轴 min/max，使子项在过小容器内压破最小值，或在宽裕容器与扩展行盒内拉破最大值。该批缺陷已由 `bdccced7` 修复：两条路径都在计算 Stretch 候选后通过既有有序交叉轴上下限完成最终钳制，行盒账本保持不变；两个内部聚焦门禁修复前分别得到 10px 而非 20px、20px 而非 12px，修复后内部 Flex 六项、公开布局三十七项与完整库一百三十七项测试全部通过，当前没有遗留的同类已确认缺陷。

第二十批审计确认 wrapped Flex 的交叉轴 End 对齐把负剩余空间钳为零，使高于实际容器的自然行组退化为 Start，末行末端无法贴住容器末端。该批缺陷已由 `9cd3ae5a` 修复：End 直接使用有限交叉轴差值，与 Center、主轴溢出及单行逐项对齐保持一致；聚焦契约修复前首行错误停在 `y=6px`，修复后移动到 `y=-4px` 且末行底边贴住容器底边，公开布局三十八项与完整库一百三十七项测试全部通过，当前没有遗留的同类已确认缺陷。

第二十一批审计确认 wrapped Flex 的 Center/End 行组偏移未区分零交叉轴 bootstrap，会围绕尚不存在的零尺寸对齐范围把自然行组移到负坐标。该批缺陷已由 `af35d11b` 修复：两种偏移只在获得实际交叉轴后启用，bootstrap 固定从自然原点排列并由自然行组撑开输出；聚焦契约修复前 Center 把首行从 `y=6px` 移到 `y=-6.5px`，修复后 Center/End 两种分支与上一批实际溢出门禁全部通过，公开布局三十九项与完整库一百三十七项测试全部通过，当前没有遗留的同类已确认缺陷。

第二十二批审计确认公开 `FlexLayout` 的空子集早返回无条件复制完整 frame，使 `intrinsic_main` 与 `overflow_content` 跳过自然主轴语义；空水平固有布局因而把 100×20px frame 错误记为 100×20px，而非零子项应形成的 0×20px。该批缺陷已由 `382dd1df` 修复：固定尺寸空布局仍占用两条父级分配轴，固有或溢出空布局则只按方向折叠主轴并保留交叉轴；水平、垂直与溢出聚焦契约以及公开布局四十项、完整库一百三十七项测试全部通过，当前没有遗留的同类已确认缺陷。

第二十三批审计确认 RichText 的估算测量缓存没有把宽度约束纳入失效键；同一实例从 400px 缩到 80px 后，测量仍复用 21px 旧高度，而绘制会按新宽度重新折行，可能被父级旧高度裁切，旧行坐标和代码复制区域也可能短暂参与命中。该批缺陷已由 `d91d9831` 修复：宽度变化会重新估算固有高度并清除旧绘制/命中几何，下一次绘制用同宽度真实字体度量重建缓存；聚焦契约以及公开布局四十一项、完整库一百三十七项测试全部通过，当前没有遗留的同类已确认缺陷。

第二十四批审计确认 Notification 在窄窗口中先保留 384px 固定条目宽度，400px frame 无法同时容纳双侧各 24px 留白时，TopRight 条目会贴到左边界 `x=0`，与 Message 及 Placement 的 inset 语义分叉。该批缺陷已由 `646f33de` 修复：宽度先扣除双侧留白再按 384px 封顶，400px frame 得到 `x=24,w=352`，动画后命中边界复用同一条目矩形；聚焦契约与完整库一百三十八项测试全部通过，当前没有遗留的同类已确认缺陷。

第二十五批审计确认 Table 的列区绘制采用 Middle → Left → Right，而 `column_at` 采用 Left → Right → Middle；100px 视口中左右固定列各宽 80px 时，`x=50px` 会命中视觉上已被覆盖的左列索引 0。该批缺陷已由 `b14313ca` 修复：表头、分组表头和表体共享绘制层级，命中按该层级逆序返回最上层右列索引 1；聚焦契约与完整库一百三十九项测试全部通过，当前没有遗留的同类已确认缺陷。

第二十六批审计确认 Table 的列宽调整句柄把所有可见列合并后只按距离选择，没有应用列区绘制层级；100px 视口中左固定列宽 80px、右固定区两列各宽 20px 时，左列和右内列的右边缘都位于 `x=80px`，会命中被覆盖的左列索引 0。该批缺陷已由 `d51d5b0e` 修复：句柄按 Right → Left → Middle 分层查找并仅在同层按距离择优，重合点返回最上层右内列索引 1；聚焦契约与完整库一百四十项测试全部通过，当前没有遗留的同类已确认缺陷。

第二十七批审计确认 Table 选择列先于列区绘制，但动作解析在 `x < 32px` 时无条件优先复选框；100px 视口中 90px 右固定列覆盖选择区的 `x=10..32px` 后，表头 `x=20px` 会在视觉显示右列时错误返回 `ToggleAll`。该批缺陷已由 `cd4e9a95` 修复：动作先解析视觉最上层列，表头和表体重叠点分别返回 `SortColumn(0)` 与 `SelectRow(0)`，未覆盖的 `x=5px` 仍返回 `ToggleAll`；聚焦契约与完整库一百四十一项测试全部通过，当前没有遗留的同类已确认缺陷。

第二十八批审计确认 Table 展开箭头最后绘制，但表体动作仍先处理选择列；24px 极窄视口中行末 32px 展开交互区覆盖选择列时，`x=10px` 会在视觉显示展开控件时错误返回 `ToggleRow(0)`。该批缺陷已由 `52f99f94` 修复：表体先解析物理数据行并优先响应最上层展开控件，同点返回 `ToggleExpand(0)`，表头仍返回 `ToggleAll`，展开内容区保持无展开动作；两项相邻层级契约与完整库一百四十二项测试全部通过，当前没有遗留的同类已确认缺陷。

第二十九批审计确认 Table 有标题分组片段按分组声明顺序覆盖固定区层级；100px 视口中先声明 80px 右固定组、后声明 80px 左固定组时，重叠区的绘制访问顺序为 Right → Left，而 `x=50px` 仍命中右固定列。该批缺陷已由 `625b0c31` 修复：分组片段改为以 Middle → Left → Right 全局列区层级为外层且不分配中间集合，绘制顺序变为 Left → Right 并与命中一致；聚焦契约与完整库一百四十三项测试全部通过，当前没有遗留的同类已确认缺陷。

焦点视觉的模态区分：
- 指针模态：左键点击导航、菜单、按钮及同类 action / selection 控件时，保留逻辑焦点但不绘制额外焦点环
- 键盘模态：使用键盘、语义 `focus` 或 `FocusHandle` 聚焦时，显示焦点提示

Windows Vulkan 真实窗口回归包含两种模态的自动化与像素差异断言。
