## 适用线索

## 权威范围

本组件持有功能能力清单事实：能做、不做、暂缓。具体实现细节与用法不属本组件范围。

## 能做

UIX 提供了一套完整的 App 开发能力：

- **界面**：声明式组件库，含常用控件、响应式布局、样式和主题管理
- **表单**：类型安全的表单，带校验规则，提交即得类型化结果
- **数据展示**：表格、虚拟滚动列表
- **动画**：过渡、关键帧、弹簧动画，入场离场与列表依次入场
- **浮层**：弹窗、抽屉、弹出框、消息、通知，框架管理显示层级和焦点
- **图形**：统一绘图 API 用于自定义绘制，GPU 后端自动选择，无 GPU 时 CPU 回退
- **窗口**：自定义标题栏、多窗口、全屏
- **AI 控制**：显式启用的本机 Agent 控制面（`agent-control` feature），窗口枚举、语义快照、受控动作，仅本机同用户 IPC
- **平台**：系统目录、硬件信息、剪贴板、文件对话框、输入法
- **数据存储**：按需启用的键值存储
- **国际化**：组件文案统一管理，内置中英文

## 不做 · 暂缓

**不做**：网络/同步、WebView 运行时、远程控制（本机 Agent 控制面除外）、远程日志上传、独立 UI 脚本语言。

**暂缓**：移动端 backend。
