## 权威范围

本文持有产品能力范围、不做项和暂缓项。它不单独证明某项能力已在当前版本的全部平台或 feature 组合中交付；公开用法与限制由链接到的使用文档持有，动态完成度由 Gitea 持有。

## 明确不做

- 网络请求、云服务与跨设备同步。
- WebView 或浏览器界面运行时。
- 跨网络远程控制；显式启用的同用户本机 Agent 控制面是唯一例外。
- 远程日志上传；应用若需要上传，必须在 UIX 诊断边界之外自行实现并承担授权与隐私责任。
- 运行期解释执行的独立 UI 脚本语言；uix-lang 是编译期输入，不是运行期脚本环境。

## 暂缓与交付边界

- **移动端 backend**：属于长期产品目标，但当前暂缓，不是 `0.0.3` 交付承诺。
- **当前平台**：`0.0.3` 声明 Windows 与 Linux；macOS 与其他平台的目标定位不等于当前发布支持。
- **发布设施**：签名、分发、自动升级和回滚不由本能力清单承诺，当前定义见[交付与许可](交付与许可.md)。

平台与硬件的公开 API 测试覆盖、当前差距、负责人和阻塞统一由 [仓库状态账目](../../TODO.md) 维护；内部 Adapter、RHI 与驱动执行不建立项目测试。
