## 定位

用 Rust 写的跨平台 App 框架。**全栈**：UI + 应用壳 + 本地 `data`（Settings）；**不含**网络 / 同步。声明式 UI 像 Web，跑原生窗口与绘制，空闲时真正休眠。

- 入口：`use uix::prelude::*`
- 目标：桌面 + 移动端共用同一套上层代码
- 写法 → [`使用.md`](../使用.md)

## 核心原则

**用最少资源，做最好效果。**

这不是口号，是架构决策的第一优先级。每一项功能都须先回答：能不能用更少的内存、更少的 CPU、更少的帧做到同等或更好的结果？

- **运行时**：空闲真休眠阻塞等待，不轮询；逐窗至多一个帧请求；不可呈现时保留状态、暂停帧
- **绘制**：局部状态只更新依赖节点；保留式路径只重绘实际 dirty；脏区合并，清屏与绘制共用引擎实际帧区
- **内存**：字形缓存有界，Picture 离屏按需创建并及时间回收，槽位池自动 compact
- **容错**：失败 typed，终态吸收不忙循环；主循环与托管不依赖真实窗口或 GPU
