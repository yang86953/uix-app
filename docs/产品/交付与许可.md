UIX `0.0.1` 是 `yangyanhui` 持有版权的**专有闭源、仅限获授权内部交付**版本，不向 crates.io 发布，也不公开提供源码或二进制制品；法律边界见 [`LICENSE`](../LICENSE)，交付约束见[首发计划](进度.md#已冻结的内部交付契约)。
