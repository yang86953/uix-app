## 公开发行

UIX 是早期开发中的 Rust 原生应用框架，框架及本次四个发布包按 [MIT](../../LICENSE) 许可发布；
第三方资源遵循 [原始许可和通知](../../THIRD_PARTY_NOTICES.md)。API 与行为可能不兼容变化，
不承诺生产稳定性。

`demo/task-list` 已统一为 [MIT](../../demo/task-list/LICENSE)，但它不包含在本次四个发布包中。

- 源码与版本：[GitHub](https://github.com/yang86953/uix-app) · [v0.0.8 早期预览](https://github.com/yang86953/uix-app/releases/tag/v0.0.8)。
- 公开包：[uix-app 0.0.8](https://crates.io/crates/uix-app/0.0.8)，Rust 库名 `uix_app`。
- 配套包 `uix-derive`、`uix-lang-compiler`、`uix-lang-runtime` 同为 0.0.8，已发布到 crates.io。
- 应用按[快速开始](../使用/入门/快速开始.md)添加依赖，无需私有 Registry 或发布令牌。

公开标签与四个发布包的源码基线为 `26d5fc43c9da94cfc2b138d9f762d620a63b7116`。
main 上之后的文档或开发变更不自动包含在该版本中。

## 平台和验证边界

当前主要面向 Windows 与 Linux；macOS 的交叉检查不等于原生窗口、GPU、输入和系统集成验收，
移动端不属于本次交付。v0.0.8 Release 提供源码，不附带本轮新认证的平台安装包。
工具链跟随最新 stable；发布构建验证为 Rust/Cargo 1.98.1，字体四路径测试与四包打包验证通过。
命名、动态功能、示例等此前定向证据来自 1.96.0，不宣称在新工具链全部重跑或获得全平台认证。

应用需提供可用系统字体或显式 FontBundle。正文不再内置 WenKai，Lucide 仅用于图标；
独立测试字体子集不是运行期默认字体。细节见[字体说明](../../assets/fonts/README.md)。
