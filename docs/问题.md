# 问题

## 状态与入账规则

- 本文件只维护未关闭问题、活跃风险和待裁决边界；已关闭项在验证证据落入测试、测试报告或提交历史后移除。
- 状态流：`待确认 -> 已确认 -> 修复中 -> 待验证 -> 移除`；无法继续时使用 `阻塞`。
- `待确认` 需要直接证据；`已确认` 需要从已知基线完成最小复现；修复后须通过原始复现和至少一个相邻场景。
- 工具、环境、驱动和测试数据限制留在单次报告，不作为产品问题入账；单机或单后端结果不得外推为跨平台结论。

## 活跃问题

当前有 5 项未关闭图形缺陷、2 项待 GUI 复验缺陷和 6 项交付/资源风险。它们共同阻塞 REQ-006 与 P6 production；排期与退出门槛见 [P6.9](进度.md#p69-图形契约整改)。
