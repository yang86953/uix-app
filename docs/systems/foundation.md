# 基础设施系统

> 系统职责：全框架共用的**错误、几何、日志、诊断**。

---

## 1. 定位

最底层；无平台依赖；无 OS 条件编译；Fail Fast。

输入：各域产生的错误、诊断事件和通用几何需求。输出：统一 Error / Result、几何类型、日志与诊断记录。

---

## 2. 几何

Point、Size、Rect、EdgeInsets — 布局、命中、脏区、present damage **共用**，禁止重复定义。

---

## 3. 错误

稳定错误码、结构化 Error、统一 Result。各域向上只暴露框架错误；生产禁止 unwrap/expect。

---

## 4. 日志

自持级别与 Sink（控制台、文件、回调）。帧指标、启动失败等走此通道。

---

## 5. 诊断

错误聚合、重试、panic 转储 — 用于 IO/网络等；UI 热路径保持轻量。

---

## 6. 数据流

失败 → Error → 日志/诊断 → 应用决策。几何 → 平台 / 界面 / 渲染。

---

## 7. 落地要求

| 项 | 要求 |
|----|------|
| 几何 | `Point` / `Size` / `Rect` / `EdgeInsets` 全域复用，不重复定义 |
| 错误 | 平台错误统一映射，不泄漏 OS 原生码 |
| 日志 / 诊断 | UI 热路径保持轻量 |
