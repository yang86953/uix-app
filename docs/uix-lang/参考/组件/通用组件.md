> **接口**：声明 UIX Lang 内置通用组件——Button、Icon、Label、FloatButton、Typography、Divider、Space、ThemeToggle、ButtonGroup、WindowControl、WindowDragRegion。依赖：[标签语法](../../规范/语法.md)、[样式属性参考](../../参考/样式属性.md)。

## 1. Button 按钮

触发操作的按钮；`type` 声明语义样式，`class` / `style` 叠加自定义外观。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `type` | 关键字 | `default` | 语义样式：`default` / `primary` / `danger` / `ghost` |
| `disabled` | 布尔 | `false` | 禁用 |
| `size` | 关键字 | `middle` | 尺寸：`small` / `middle` / `large` |
| `loading` | 布尔 | `false` | 加载态（显示旋转指示并禁用点击） |
| `@click` | 事件 | — | 点击事件绑定 |

`size` 使用确定关键字并映射到公开 `ControlSize`；`loading` 接受布尔简写、字面量或受限表达式。加载态复用既有 Button 旋转器与逐窗动画调度，并拒绝点击；`ButtonGroup` 的直接 Button 子项使用相同映射。

```uix
<Button type="primary" @click="submit">提交</Button>
<Button type="danger" disabled>删除</Button>
<Button size="large" loading={submitting}>处理中</Button>
<Button @click="handleClick" style="padding: 6px 12px;">自定义样式</Button>
```

## 2. Icon 图标

按名称渲染单个 Lucide 字形；**应用可见图标必须使用本组件**，不得用 Unicode / ASCII 符号或普通文本代替。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `name` | 字符串 | — | 图标名称（Lucide 图标集） |
| `size` | 长度 | 继承 | 字形尺寸 |
| `color` | 颜色 | 继承 | 字形颜色 |

```uix
<Icon name="star" size="16px" color="#FF5722" />
<Container direction="row" gap="4px">
  <Icon name="plus" />
  <Button>新建</Button>
</Container>
```

## 3. Label 文本标签

短文本标签，支持多行与文本选择（对应 Rust `label`，是最基础的文本原语）。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `selectable` | 布尔 | `false` | 允许文本选择 |
| `fontSize` | token / 长度 | `body` | 字号（见[样式参考 fontSize](../../参考/样式属性.md#42-fontsize)） |
| `color` | 颜色 | 主题默认 | 文字颜色 |

`selectable` 接受布尔简写、字面量或受限表达式，映射到既有 Label 拖选与复制契约；该属性不属于 `Text` 标签。

`Text` 是不可选中的声明式文本标签。纯文本继续生成普通 `Label`；内容含 `{expr}` 时生成 `DynamicLabel`，保留 `fontSize`、公共样式、`key`、`automationId` 与事件装饰。组件 `State` 由动态闭包在测量、绘制和语义读取阶段取得，更新时只登记该节点的 Paint 失效；`If` 等结构位置读取仍登记根 View reconcile。`Label` 的 `selectable` 交互由自身运行态独占，因此不自动转换为 `DynamicLabel`。

```uix
<Label>普通文本</Label>
<Label selectable fontSize="heading3">可选中的标题文本</Label>
```

## 4. FloatButton 浮动操作按钮

悬浮在页面角落的操作按钮，可带 tooltip、badge 与自定义定位。

`FloatButton` 已进入公开 `uix!` 生成矩阵：`icon` 必填；`description` 与 `tooltip` 接受字符串字面量或受限字符串表达式；`position` 只接受四个确定关键字，缺省时显式映射 `rightBottom`；`badge` 使用单层对象字面量，字段限 `count` 与 `dot`。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `icon` | 图标名 | — | 按钮图标 |
| `description` | 字符串 | — | 展开说明文字 |
| `position` | 关键字 | `rightBottom` | 定位：`leftTop` / `leftBottom` / `rightTop` / `rightBottom` |
| `tooltip` | 字符串 | — | 悬停提示文字 |
| `badge` | 对象 | — | 徽标配置 `{ count, dot }` |
| `@click` | 事件 | — | 点击事件绑定 |

```uix
<FloatButton icon="message" description="反馈" position="rightBottom"
             tooltip="意见反馈" badge={{ count: unread, dot: false }}
             @click="openFeedback" />
```

## 5. Typography 排版

标题、段落、标记、下划线等排版语义文本；文本可复制。

`Typography` 已进入公开 `uix!` 生成矩阵：内容只接受文本与插值，`level` 接受 1~5 字面量或 `u8` 受限表达式，`type` 必须是确定的语义色字面量，`mark`、`underline` 与 `copyable` 接受布尔字面量或受限表达式；语义色在绘制阶段通过当前主题令牌解析。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `level` | 整数 1~5 | — | 标题层级（对应 heading1~heading5 字号） |
| `type` | 关键字 | — | `secondary` / `success` / `warning` / `danger` 语义色 |
| `mark` | 布尔 | `false` | 标记高亮 |
| `underline` | 布尔 | `false` | 下划线 |
| `copyable` | 布尔 | `false` | 显示复制按钮 |

```uix
<Typography level={1}>一级标题</Typography>
<Typography type="danger" mark>删除标记</Typography>
```

## 6. Divider 分割线

分隔内容区块；可带标签文字，可切换虚线。

`Divider` 已进入公开 `uix!` 生成矩阵：标签保持叶子形状，`text` 接受字符串字面量或受限字符串表达式，`dashed` 接受布尔值，`direction` 必须是确定的 `horizontal` / `vertical` 字面量。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `text` | 字符串 | — | 分割线标签文字 |
| `dashed` | 布尔 | `false` | 虚线样式 |
| `direction` | 关键字 | `horizontal` | `horizontal` / `vertical` |

```uix
<Divider text="更多信息" />
```

## 7. Space 弹性间距容器

为子节点提供统一间距，是轻量布局原语（对应 Rust `Space`）。

`Space` 已进入公开 `uix!` 生成矩阵：子节点按源码顺序生成，`direction` 必须是确定的 `horizontal` / `vertical` 字面量，`gap` 接受有限数值、`px` 字面量或受限数值表达式，`wrap` 接受布尔字面量或受限布尔表达式。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `direction` | 关键字 | `horizontal` | 排列方向 |
| `gap` | 长度 | `8px` | 子节点间距 |
| `wrap` | 布尔 | `false` | 超出换行 |

```uix
<Space gap="12px">
  <Button>保存</Button>
  <Button type="ghost">取消</Button>
</Space>
```

## 8. ThemeToggle 主题切换按钮

内置亮色 / 暗色主题切换开关，等价于 `@theme` 切换的快捷控件。

`ThemeToggle` 已进入公开 `uix!` 生成矩阵：标签保持无专有属性的叶子形状，复用现有 `ThemeToggle::new()` 组件；实际主题状态继续由 Provider / 应用配置持有。

```uix
<ThemeToggle />
```

## 9. ButtonGroup 按钮组

同组按钮共享间距与语义样式，视觉上作为整体。

`ButtonGroup` 已进入公开 `uix!` 生成矩阵：只接受保持源码顺序的直接 `Button` 子元素；单项使用 `Single`，多项自动分配 `Left` / `Middle` / `Right` 连体位置。子按钮继续支持 `type`、`disabled`、`block`、`@click`、文本插值与公共样式；动态 `If` / `For` 子树请使用 `Row`，避免运行期数量让静态连体位置失真。

```uix
<ButtonGroup>
  <Button>左</Button>
  <Button>中</Button>
  <Button>右</Button>
</ButtonGroup>
```

## 10. WindowControl 窗口控制

最小化 / 最大化 / 关闭按钮，用于自定义标题栏（对应 Rust `window_chrome` 能力）。

`WindowControl` 已进入公开 `uix!` 生成矩阵：三个显示属性接受布尔字面量或受限布尔表达式，默认均为 `true`；标签生成公开 `window_controls` 组合，由运行时 `window_chrome` 模块继续拥有窗口动作、无障碍语义与默认外观。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `showMinimize` | 布尔 | `true` | 显示最小化 |
| `showMaximize` | 布尔 | `true` | 显示最大化 |
| `showClose` | 布尔 | `true` | 显示关闭 |

```uix
<Container direction="row">
  <WindowControl />
</Container>
```

## 11. WindowDragRegion 窗口拖拽区

把唯一展示子树包装为自定义标题栏的窗口拖拽区域，对应 Rust `window_drag_region` 能力。标签没有专有属性，可使用公共尺寸、布局和自动化属性；不接受事件属性。

`WindowDragRegion` 已进入公开 `uix!` 生成矩阵：只接受一个可渲染直接子节点，编译期直接生成现有 `window_drag_region` 包装器。窗口移动、双击最大化/还原和系统菜单动作继续由运行时 `window_chrome` 模块持有。

可拖拽区不能覆盖 `Button`、`ThemeToggle`、`WindowControl` 等交互控件；这些控件必须作为拖拽区外部的同级节点。

```uix
<Container direction="row" height="48px">
  <WindowDragRegion flexGrow={1} height="48px">
    <Container direction="row" padding="8px">
      <Icon name="box" />
      <Text>UIX Demo</Text>
    </Container>
  </WindowDragRegion>
  <ThemeToggle />
  <WindowControl />
</Container>
```

## 12. Canvas 画布

固定 logical 尺寸的轻量绘制节点，对应公开 Rust `canvas` 组合器。绘制逻辑、状态读取与失效完全由 Rust 侧的绘制函数持有；闭包内读取的 `State` / `Computed` 会自动绑定到该节点的窄 Paint 失效，不形成每帧回调。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `width` | 数字 | — | 必填；logical 宽度（f32） |
| `height` | 数字 | — | 必填；logical 高度（f32） |
| `paint` | 绘制函数 | — | 必填；Rust 侧 `Fn(Rect, &mut PaintContext)` 表达式 |

`Canvas` 是叶组件：不接受子节点与事件属性；公共尺寸、布局与身份属性照常可用（如 `flexGrow`）。`paint` 必须是 Rust 表达式（经 `external` 声明的函数项或闭包），签名由 Rust 编译器在调用点验证。

```uix
// paint 引用 Rust 侧绘制函数；在 Widget 体内使用时经 external 声明。
<Canvas width="590" height="34" paint={draw_waveform} flexGrow={1} />
```
