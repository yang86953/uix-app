# 图表组件

> **当前映射**：Rust 图表文档列出的十二类标签均已登记：`BarChart`、`LineChart`、`PieChart`、`AreaChart`、`ScatterChart`、`FunnelChart`、`Treemap`、`Gauge`、`Heatmap`、`WaterfallChart`、`RadarChart` 与 `ComboChart`。全部是叶组件，编译期取得类型化数据快照；运行时 Chart Module 继续唯一拥有测量、绘制和指针瞬态。

## 类型化数据

```uix
<BarChart data={[BarData('Q1', 120, Color('#1677ff'))]} />
<LineChart data={[LineData('Jan', 100), LineData('Feb', 150)]} />
<PieChart data={[PieData('产品 A', 40, Color('#52c41a'))]} />
<AreaChart data={[LineData('Jan', 100), LineData('Feb', 150)]} fillOpacity="0.3" />
<ScatterChart data={[ScatterData('A', 2.5, 6.3)]} pointStyle="diamond" />
<FunnelChart data={[FunnelData('浏览', 5000), FunnelData('支付', 310)]} showConversionRate />
<Treemap data={[TreemapNode('技术', 45).children([TreemapNode('前端', 20)])]} />
<Gauge value="68" rangeColors={[GaugeRange(0, 100, Color('#52c41a'))]} />
<Heatmap data={[HeatmapCell(0, 0, 12)]} xLabels={['周一']} yLabels={['上午']} />
<WaterfallChart data={[WaterfallData('收入', 500, 'increase')]} />
<RadarChart axes={[RadarAxis('速度', 0, 100)]} series={[ChartSeries('当前', [RadarData(80)])]} />
<ComboChart barSeries={[ChartSeries('销售额', [BarData('Jan', 100, Color('#1677ff'))])]} lineSeries={[ChartSeries('利润率', [LineData('Jan', 20)])]} />
```

`data` 是前述单集合图表的必需表达式：基础三图分别使用 `BarData`、`LineData`、`PieData`，面积图复用 `LineData`，散点图、漏斗图、矩形树图、热力图与瀑布图分别使用 `ScatterData`、`FunnelData`、`TreemapNode`、`HeatmapCell`、`WaterfallData`。`Gauge` 改为要求 `value`，可通过 `GaugeRange` 集合声明色带。`RadarChart` 要求 `RadarAxis` 的 `axes` 与 `ChartSeries<RadarData>` 的 `series`；`ComboChart` 至少要求 `ChartSeries<BarData>` 的 `barSeries` 或 `ChartSeries<LineData>` 的 `lineSeries`。字符串、错配的内联图表数据构造器或子 View 会在宏展开期被拒绝；动态集合的元素类型最终由 Rust 编译器核对。

## 基础属性

| 标签 | 已登记专有属性 |
|---|---|
| `BarChart` | `maxValue`、`showValue`、`barRadius`、`grouped`、`stacked`、`horizontal`、`barGap`、`categoryGap` |
| `LineChart` | `maxValue`、`autoMin`、`showGrid`、`showDots`、`lineWidth`、`dotRadius`、`smooth`、`step` |
| `PieChart` | `donut`、`rose`、`startAngle`、`endAngle`、`total`、`labelVisible` |
| `AreaChart` | `stacked`、`smooth`、`step`、`fillOpacity` |
| `ScatterChart` | `xAxis`、`yAxis`、`pointSize`、`pointStyle` |
| `FunnelChart` | `showConversionRate`、`labelVisible`、`labelPosition`、`align`、`shape`、`gap` |
| `Treemap` | `gap`、`labelVisible` |
| `Gauge` | `value`、`min`、`max`、`rangeColors`、`gaugeType`、`pointerWidth`、`pointerColor` |
| `Heatmap` | `xLabels`、`yLabels`、`calendarMode`、`year`、`cellSize`、`cellGap`、`showValues` |
| `WaterfallChart` | `horizontal`、`xAxis`、`yAxis` |
| `RadarChart` | `axes`、`series`、`shape`、`gridLevels`、`fillOpacity` |
| `ComboChart` | `barSeries`、`lineSeries`、`yAxisLeft`、`yAxisRight` |

十二类图表共享静态 `title` / `subtitle`、布尔 `responsive`、`legend` 以及 `animation` / `interactive` / `brush` / `tooltip` 类型化配置表达式，并继续使用公共 `width` / `height` / 样式 / 自动化属性。`legend` 的静态值为 `top`、`bottom`、`left`、`right`、`none`，也可传入 `LegendPosition` 表达式；其余四项分别接收 `AnimationConfig`、`InteractionConfig`、`BrushConfig` 与 `TooltipConfig`，生成器会克隆声明快照，运行时图表组件继续唯一持有交互瞬态。静态数值必须符合目标 `f32` / `i32` / `usize` 类型；动态数值表达式交由 Rust 类型检查和运行时既有规范化契约处理。

`BubbleData`、ComboSeries 自定义混合类型、热力图自定义色阶、参考线与 `Gauge.format` 尚未登记，不会被降级或忽略。`InteractionConfig.on_click`、`BrushConfig.on_select` 与 `TooltipConfig.render` 回调通过其类型化配置对象进入声明，不新增 UIX 字符串事件语法；其余未登记能力继续使用 [Rust 图表 API](../../../使用/数据展示/图表.md)。
