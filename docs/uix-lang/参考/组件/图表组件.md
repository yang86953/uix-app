# 图表组件

> **当前映射**：首批登记 `BarChart`、`LineChart` 与 `PieChart`。三者都是叶组件，编译期取得类型化数据快照；运行时 Chart Module 继续唯一拥有测量、绘制和指针瞬态。

## 类型化数据

```uix
<BarChart data={[BarData('Q1', 120, Color('#1677ff'))]} />
<LineChart data={[LineData('Jan', 100), LineData('Feb', 150)]} />
<PieChart data={[PieData('产品 A', 40, Color('#52c41a'))]} />
```

`data` 是必需表达式，元素分别为 `BarData`、`LineData`、`PieData`。字符串或子 View 会在宏展开期被拒绝；元素类型最终由 Rust 编译器核对。

## 基础属性

| 标签 | 已登记专有属性 |
|---|---|
| `BarChart` | `maxValue`、`showValue`、`barRadius`、`grouped`、`stacked`、`horizontal`、`barGap`、`categoryGap` |
| `LineChart` | `maxValue`、`autoMin`、`showGrid`、`showDots`、`lineWidth`、`dotRadius`、`smooth`、`step` |
| `PieChart` | `donut`、`rose`、`startAngle`、`endAngle`、`total`、`labelVisible` |

三者共享静态 `title` / `subtitle` 与布尔 `responsive`，并继续使用公共 `width` / `height` / 样式 / 自动化属性。静态数值必须是有限 `f32`；动态数值表达式交由 Rust 类型检查和运行时既有规范化契约处理。

`series`、`legend`、`interactive`、`brush`、`tooltip` 和回调尚未登记，不会被降级或忽略。高级图表能力继续使用 [Rust 图表 API](../../../使用/图表.md)。
