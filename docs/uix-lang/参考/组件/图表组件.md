# 图表组件

[← 返回 UIX Lang 索引](../../README.md)

> **文档角色**：登记参考——持有当前图表标签、类型化数据入口、属性、互斥规则和 capability。
>
> **接口**：声明 UIX Lang 的十二类图表标签、类型化数据入口和共同配置。依赖：[标签语法](../../规范/语法.md)、[事件参考](../事件.md)与 [Rust 图表使用文档](../../../使用/数据展示/图表.md)。
>
> **状态声明**：Rust 图表文档列出的十二类标签均已登记：`BarChart`、`LineChart`、`PieChart`、`AreaChart`、`ScatterChart`、`FunnelChart`、`Treemap`、`Gauge`、`Heatmap`、`WaterfallChart`、`RadarChart` 与 `ComboChart`。全部是叶组件，编译期取得类型化数据快照；运行时 Chart Module 继续唯一拥有测量、绘制和指针瞬态。

## 类型化数据

```uix
<BarChart series={[ChartSeries('2025', [BarData('Q1', 120, Color('#1677ff'))])]} grouped />
<LineChart series={[ChartSeries('CPU', [LineData('Jan', 40), LineData('Feb', 60)])]} />
<PieChart data={[PieData('产品 A', 40, Color('#52c41a'))]} />
<AreaChart series={[ChartSeries('收入', [LineData('Jan', 100), LineData('Feb', 150)])]} fillOpacity="0.3" />
<ScatterChart series={[ChartSeries('实验组', [ScatterData('A', 2.5, 6.3)])]} pointStyle="diamond" />
<ScatterChart bubbleData={[BubbleData('中国', 1.4, 12, 80)]} bubbleScale="0.8" />
<FunnelChart data={[FunnelData('浏览', 5000), FunnelData('支付', 310)]} showConversionRate />
<Treemap data={[TreemapNode('技术', 45).children([TreemapNode('前端', 20)])]} />
<Gauge value="68" rangeColors={[GaugeRange(0, 100, Color('#52c41a'))]} format={format_percent} />
<Heatmap data={[HeatmapCell(0, 0, 12)]} xLabels={['周一']} yLabels={['上午']} colorRange={color_range} />
<WaterfallChart data={[WaterfallData('收入', 500, 'increase')]} />
<RadarChart axes={[RadarAxis('速度', 0, 100)]} series={[ChartSeries('当前', [RadarData(80)])]} />
<ComboChart series={combo_series} />
```

单集合图表使用 `data`：基础三图分别接收 `BarData`、`LineData`、`PieData`，面积图复用 `LineData`，普通散点图、漏斗图、矩形树图、热力图与瀑布图分别接收 `ScatterData`、`FunnelData`、`TreemapNode`、`HeatmapCell`、`WaterfallData`。`BarChart`、`LineChart`、`AreaChart` 与普通 `ScatterChart` 还可改用互斥的 `series`：分别固定为 `Vec<ChartSeries<Vec<BarData>>>`、`Vec<ChartSeries<Vec<LineData>>>`、`Vec<ChartSeries<Vec<LineData>>>` 与 `Vec<ChartSeries<Vec<ScatterData>>>`。气泡图仍使用 `ScatterChart`，但以互斥的 `bubbleData` 精确接收 `BubbleData`，从而让动态集合保持 `Vec<BubbleData>` 编译检查；气泡入口不支持 `series`，`bubbleScale` 只在该入口有效，普通散点的 `pointSize` / `pointStyle` 不适用于气泡载荷。`Gauge` 要求 `value`，可通过 `GaugeRange` 集合声明色带。`RadarChart` 要求 `RadarAxis` 的 `axes` 与 `ChartSeries<RadarData>` 的 `series`；`ComboChart` 接收 `ComboSeries<Vec<LineData>>` 的 `series`，或接收 `ChartSeries<BarData>` 的 `barSeries` / `ChartSeries<LineData>` 的 `lineSeries`，自定义入口与专用入口互斥。字符串、错配的内联图表数据构造器或子 View 会在宏展开期被拒绝；动态集合的元素类型最终由 Rust 编译器核对。

## 基础属性

| 标签 | 已登记专有属性 |
|---|---|
| `BarChart` | `data` / `series`（互斥）、`maxValue`、`showValue`、`barRadius`、`grouped`、`stacked`、`horizontal`、`barGap`、`categoryGap` |
| `LineChart` | `data` / `series`（互斥）、`maxValue`、`autoMin`、`showGrid`、`showDots`、`lineWidth`、`dotRadius`、`smooth`、`step` |
| `PieChart` | `donut`、`rose`、`startAngle`、`endAngle`、`total`、`labelVisible` |
| `AreaChart` | `data` / `series`（互斥）、`stacked`、`smooth`、`step`、`fillOpacity`、`referenceLines` |
| `ScatterChart` | `data` / `bubbleData` / `series`（三选一）、`xAxis`、`yAxis`、`pointSize`、`pointStyle`、`bubbleScale`、`referenceLines` |
| `FunnelChart` | `showConversionRate`、`labelVisible`、`labelPosition`、`align`、`shape`、`gap` |
| `Treemap` | `gap`、`labelVisible` |
| `Gauge` | `value`、`min`、`max`、`rangeColors`、`gaugeType`、`pointerWidth`、`pointerColor`、`format` |
| `Heatmap` | `xLabels`、`yLabels`、`calendarMode`、`year`、`cellSize`、`cellGap`、`showValues`、`colorRange`、`colorStops` |
| `WaterfallChart` | `horizontal`、`xAxis`、`yAxis`、`referenceLines` |
| `RadarChart` | `axes`、`series`、`shape`、`gridLevels`、`fillOpacity` |
| `ComboChart` | `series` / `barSeries` + `lineSeries`（两组入口互斥）、`yAxisLeft`、`yAxisRight`、`referenceLines` |

十二类图表共享静态 `title` / `subtitle`、布尔 `responsive`、`legend` 以及 `animation` / `interactive` / `brush` / `tooltip` 类型化配置表达式，并继续使用公共 `width` / `height` / 样式 / 自动化属性。`legend` 的静态值为 `top`、`bottom`、`left`、`right`、`none`，也可传入 `LegendPosition` 表达式；其余四项分别接收 `AnimationConfig`、`InteractionConfig`、`BrushConfig` 与 `TooltipConfig`，生成器会克隆声明快照，运行时图表组件继续唯一持有交互瞬态。静态数值必须符合目标 `f32` / `i32` / `usize` 类型；动态数值表达式交由 Rust 类型检查和运行时既有规范化契约处理。

`Heatmap colorRange` 接收调用方在 Rust 中预先构造的精确 `(Color, Color)` 表达式并映射两端线性渐变；受限 UIX 表达式不直接书写元组字面量。`colorStops` 接收 `Vec<(f32, Color)>`，位置由既有运行时契约过滤、约束到 `0..=1` 并排序。两者都在生成代码中固定公开类型，错型集合由 Rust 编译器拒绝；同时提供时，运行时优先使用至少两档的 `colorStops`。

`referenceLines` 仅登记到使用高级 `ChartPlaceholder` 且实际调用坐标轴绘制的 `AreaChart`、`ScatterChart`、`WaterfallChart` 与 `ComboChart`，接收 `Vec<(f32, String, LineStyle)>` 并按集合顺序调用既有 `reference_line` builder。基础专用 `BarChart` / `LineChart` 没有该 builder，其余图表不绘制这类参考线，八类无效果配置都会在编译期拒绝。

基础坐标图 `series` 会克隆声明快照并固定收集嵌套泛型；运行时既有 `BarChart` / `LineChart` / `ChartPlaceholder` builder 再取得系列所有权。生成器不把 `data` 与 `series` 交给调用顺序覆盖，也不把 `BubbleData` 伪装成散点多系列；内联数组只接受 `ChartSeries(...)`，其内部数据项的精确类型由生成泛型与 Rust 编译器共同核对。

`Gauge format` 接收类型化格式化器表达式；生成代码克隆声明快照，Rust 核对 `Fn(f32) -> String + Clone + 'static`，运行时 Chart Module 继续通过既有 `Rc` 唯一持有并在绘制中心文本时调用。字符串格式化器会在宏展开期拒绝，不新增 UIX 字符串事件语法。

`ComboChart series` 克隆并固定收集 `Vec<ComboSeries<Vec<LineData>>>`；调用方通过公开 `ComboSeries` builder 配置 `ChartType::Bar` / `Line` / `Area`、`AxisSide` 与 `LineStyle`，运行时继续复用既有分流和绘制契约。内联数组只接受 `ComboSeries(...)` 构造链，错型与互斥入口会在宏展开期拒绝。

`InteractionConfig.on_click`、`BrushConfig.on_select` 与 `TooltipConfig.render` 回调通过其类型化配置对象进入声明；其余未登记能力继续使用 [Rust 图表 API](../../../使用/数据展示/图表.md)。
