## 1. 消息与通知

### Message 全局提示

轻量级操作反馈队列，顶部居中短时出现后消失。

> **当前映射**：已实现。声明标签表示 keyed 声明条目，而不是构建时执行的一次性命令。每个窗口唯一的 `AppFeedbackState` 与自动挂载的 overlay host 共同拥有 Message / Notification 队列；节点首次挂载取得租约，等价 reconcile 幂等更新，卸载释放。同一租约被手动关闭或超时后保持 tombstone，不会因普通重建重复入队；真正卸载后重挂才可再次显示。命令式反馈使用绑定窗口的显式 `AppHandle`，并进入同一逐窗 owner。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `type` | 关键字 | `info` | `info` / `success` / `warning` / `error` |
| `key` | 字符串 | — | 窗口内同类声明条目的必需稳定身份 |
| `content` | 字符串 | — | 提示内容 |
| `duration` | 数字 | `3` | 显示秒数 |
| `closable` | 布尔 | `false` | 允许手动关闭 |
| `@close` | 事件 | — | 类型化关闭事实；普通卸载不触发 |

```uix
<Message key="saved" type="success" content="保存成功" duration={2} />
```

### Notification 通知提醒

右上角弹出式消息队列，支持标题与操作。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `title` | 字符串 | — | 标题 |
| `key` | 字符串 | — | 窗口内同类声明条目的必需稳定身份 |
| `content` | 字符串 | — | 内容 |
| `type` | 关键字 | `info` | 同上 |
| `duration` | 数字 | `4.5` | 显示秒数 |
| `closable` | 布尔 | `false` | 允许手动关闭 |
| `@close` | 事件 | — | 类型化关闭事实；普通卸载不触发 |

`duration` 统一以秒为单位，必须有限且非负；`0` 表示不自动关闭。内容、类型与 closable 更新保持条目 ID 且不重启计时，只有 duration 更新从提交点重启。窗口 teardown 会先使句柄和租约失效，再清理计时器与队列，不等待离场动画。

`@close` 的 `$event` 是拥有型 `FeedbackClosed { key, reason }`；`reason` 为 `FeedbackCloseReason::Manual`、`Timeout` 或 `Programmatic`。普通卸载与窗口 teardown 只释放租约，不发布关闭事实；动态 `duration` 非有限或为负时会记录运行时诊断并安全转为 `0`。

### Alert 警告提示

可关闭的状态消息条，常内嵌于页面。

> **当前映射**：已实现。`message` 是必需字符串字面量或字符串表达式，生成代码只临时借用，运行时组件持有内容；`type` 只接受 `info` / `success` / `warning` / `error`，缺省为 `info`；`closable` 接受布尔简写、字面量或 `bool` 表达式，缺省为 `false`。`@close` 只在运行时确认关闭后触发，并把统一的 `closed` 变更文本作为 `$event` 借用传入处理器；可见性与关闭后的协调状态继续由运行时 `Alert` 拥有。`Alert` 是叶组件，不接受子节点，并要求使用方启用默认包含的 `feedback` capability。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `type` | 关键字 | `info` | `info` / `success` / `warning` / `error` |
| `message` | 字符串 | — | 提示文字 |
| `closable` | 布尔 | `false` | 可关闭 |
| `@close` | 事件 | — | 关闭事件 |

```uix
<Alert type="warning" message="磁盘空间不足" closable />
```

## 2. 浮层

### Modal 模态对话框

焦点陷阱 + 遮罩，阻塞背景交互。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `open` | 绑定 | `false` | 显隐 |
| `title` | 字符串 | — | 标题 |
| `maskClosable` | 布尔 | `true` | 点击遮罩关闭 |
| `footerVisible` | 布尔 | `true` | 底部按钮区显隐（对应 Rust `footer_visible`） |
| `@ok` / `@cancel` | 事件 | — | 确认 / 取消 |

> **Modal 当前映射**：已实现。`open` 可选；出现时必须是 `State<bool>` 表达式，运行时订阅它并在确认、取消、标题栏关闭、遮罩关闭或 Escape 后写回 `false`，未出现时保持默认关闭。`title` 接受字符串字面量或字符串表达式；`maskClosable` 与 `footerVisible` 接受布尔简写、字面量或 `bool` 表达式，缺省均为 `true`。`@ok` 与 `@cancel` 是无额外载荷的同步窄回调；确认仅触发 `@ok`，取消按钮、标题栏关闭、遮罩和 Escape 共享 `@cancel`，进入离场后不会重复触发。普通节点与 `If` / `For` 子树按源码顺序进入内容区。显隐、离场动画、遮罩、焦点恢复、布局和命中继续由运行时 `Modal` 独占，组件要求使用方启用默认包含的 `feedback` capability。

```uix
<Modal open={confirmOpen} title="确认删除" @ok="doDelete" @cancel="closeConfirm">
  <Text>删除后不可恢复，确定继续？</Text>
</Modal>
```

### Drawer 抽屉

从屏幕边缘滑出的浮层面板。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `open` | 绑定 | `false` | 显隐 |
| `placement` | 关键字 | `right` | `left` / `right` / `top` / `bottom` |
| `width` | 长度 | — | 面板宽度 |

> **Drawer 当前映射**：已实现。`open` 可选；出现时必须是 `State<bool>` 表达式，外部更新在下一动画帧驱动正常进退场，标题栏、遮罩或公开关闭路径写回 `false`，离场阶段不再接受新输入或重复关闭。缺省保持关闭。`placement` 只接受 `left` / `right` / `top` / `bottom` 字面量，缺省沿用运行时 `right`；`width` 接受十进制、`px` 字面量或 `f32` 表达式，并专门设置面板宽度，不作为公共 View 布局宽度。普通节点与 `If` / `For` 子树按源码顺序进入内容区。进退场、OverlayStack 登记、方向几何、命中与输入继续由运行时 `Drawer` 独占；组件要求使用方启用默认包含的 `feedback` capability。

```uix
<Drawer open={settingsOpen} placement="right" width="420px">
  <Text>设置内容</Text>
</Drawer>
```

### Popover / Popconfirm / Tooltip

轻量浮层三件套，点击或悬停触发：

| 组件 | 说明 |
|---|---|
| `Popover` | 气泡卡片，支持标题、十二方向、箭头、受控打开与 `click` / `hover` / `focus` 触发 |
| `Popconfirm` | 气泡确认框，带确认 / 取消操作，`@confirm` / `@cancel` 事件 |
| `Tooltip` | 文字提示，支持四方向与悬停、点击、焦点、上下文菜单触发 |

> **Popover 当前映射**：已实现。`content` 是必需字符串字面量或字符串表达式；`title` 可选并接受相同字符串形状。`placement` 可选且只接受 `top` / `topLeft` / `topRight` / `bottom` / `bottomLeft` / `bottomRight` / `left` / `leftTop` / `leftBottom` / `right` / `rightTop` / `rightBottom`，缺省沿用运行时 `top`；`arrow` 接受布尔简写、字面量或表达式，缺省为 `true`；`trigger` 只接受 `click` / `hover` / `focus`，缺省为 `click`。`open` 出现时必须是调用方拥有的 `State<bool>` 表达式：外部更新驱动正常进退场，运行时打开或关闭路径写回同一状态；布尔字面量不具备订阅和写回能力，因此会在编译期被拒绝。忽略源码排版空白后，`Popover` 必须包含且仅包含一个静态直接触发 View；直接 `If` / `For`、可见文本与插值会因触发器身份不稳定而被拒绝，但控制流或插值可放入唯一静态容器内部。显隐、输入触发、定位与边缘翻转、箭头几何、打开绑定、动画、Overlay 和 reconcile 生命周期继续由运行时 `Popover` 独占。组件要求使用方启用默认包含的 `feedback` capability。
>
> **Popconfirm 当前映射**：已实现。`title` 是必需字符串字面量或字符串表达式；`confirmText` / `cancelText` 配置按钮文字，`placement` 只接受 `topLeft` / `top` / `topRight` / `bottomLeft` / `bottom` / `bottomRight`，`arrow` / `icon` 接受布尔值。忽略源码排版空白后必须包含且仅包含一个静态直接 trigger View；直接 `If` / `For`、可见文本与插值会被拒绝，动态内容可放入唯一静态容器内部。真实 trigger 子树独占绘制、焦点、无障碍、业务 `Click` 与 reconcile 身份，包装器只在捕获阶段观察输入并以实际 trigger border-box 测量、命中和定位，不再使用固定 `80×28` 合成触发器。`@confirm` / `@cancel` 是同步无载荷窄回调：确认保留兼容 `Submit(id, "confirm")`；取消覆盖取消按钮、Escape、外部点击、打开态 trigger 重激活与用户焦点离开；编程 `close()` 不触发取消，离场与重复事件不会重复回调。组件要求使用方启用默认包含的 `feedback` capability。
>
> **Tooltip 当前映射**：已实现。`text` 是必需字符串字面量或字符串表达式，生成代码只临时借用，运行时组件持有内容。`placement` 可选且只接受 `top` / `bottom` / `left` / `right` 字符串字面量，缺省沿用运行时 `top`；它声明首选方向，越界时仍由运行时按当前 logical surface 翻转和裁剪。`trigger` 可选且只接受 `hover` / `click` / `focus` / `contextMenu` 字符串字面量，缺省为 `hover`；`contextMenu` 使用右键，`click` 使用主按钮，键盘焦点等价入口继续由运行时处理。动态枚举和未知关键字会在编译期拒绝。忽略源码排版空白后，`Tooltip` 必须包含且仅包含一个静态直接触发 View；直接 `If` / `For` 会因触发器基数不确定而被拒绝，但可放在唯一静态容器内部。可见性、待触发计时、输入、Overlay 和进入/离开过渡继续由运行时 `Tooltip` 独占。组件要求使用方启用默认包含的 `feedback` capability。

```uix
<Popover content="可通过键盘焦点打开" title="帮助" placement="rightTop" arrow trigger="focus" open={helpOpen}>
  <Button>查看帮助</Button>
</Popover>
<Tooltip text="更多操作" placement="bottom" trigger="focus">
  <Button>悬停</Button>
</Tooltip>
<Popconfirm title="确定删除？" placement="bottomRight" @confirm="doDelete" @cancel="cancelDelete">
  <Button type="danger">删除</Button>
</Popconfirm>
```

### FocusTrap 焦点陷阱

Tab 键在子树内循环，模态场景的焦点管理原语。

> **当前映射**：已实现。可选 `active` 接受布尔简写、`true` / `false` 字面量或布尔表达式，声明该作用域当前是否接管焦点循环；省略时沿用运行时默认的 `true`。`FocusTrap` 按源码顺序接收零个或多个普通、`If`、`For` 子节点；编译层只声明稳定焦点作用域与启用事实，不静态猜测后代是否可聚焦。可聚焦后代解析与 Tab 正反向循环继续由运行时 `WidgetTree` 独占；禁用时不选择下一焦点。overlay 的焦点恢复是独立生命周期，不由普通 `FocusTrap` 声明。`FocusTrap` 位于核心组件层，不要求启用 `feedback` capability。

```uix
<FocusTrap active={trapEnabled}>
  <Input value={search} />
  <Button>搜索</Button>
</FocusTrap>
```

## 3. 进度与加载

### ProgressBar 进度条

确定 / 不确定 / 圆形三种形态。

> **当前映射**：已实现。首版与 Rust 统一使用有限 `f32` fraction：`progress=0.0..=1.0`；旧 `percent=0..100` 与未落地的 `status` 不登记。`indeterminate` 独立控制不确定模式，`type` 只控制 line / circle，两种形态都支持确定与不确定模式。静态越界或非有限值在编译期报错；动态越界会按类别归一化，并通过 `input_normalized` / `normalization_reason` 快照字段与类别转换警告保持可观察。确定模式的无障碍值域保持 0～1，不确定模式不发布当前值，只有不确定模式持续注册动画。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `progress` | `f32` 0～1 | `0` | 确定模式 fraction |
| `indeterminate` | 布尔 | `false` | 不确定模式 |
| `type` | 关键字 | `line` | `line` / `circle` |

```uix
<ProgressBar progress={uploadProgress} indeterminate={waitingForTotal} type="line" />
```

### Spin 加载中

旋转指示器，可包裹内容（内容加载期间遮罩）。

> **当前映射**：已实现。`spinning` 接受布尔简写、字面量或 `bool` 表达式，缺省保留运行时 `true`；`text` 接受字符串字面量或字符串表达式，生成代码只临时借用，运行时组件持有提示内容。忽略源码排版空白后，零子节点生成独立加载指示器；存在普通、`If` 或 `For` 子节点时按源码顺序保留完整子树并启用遮罩模式，编译层不猜测动态子树数量。动画相位、延迟计时、重新激活与遮罩绘制继续由运行时 `Spin` 拥有。组件要求使用方启用默认包含的 `feedback` capability。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `spinning` | 绑定 | `true` | 是否旋转 |
| `text` | 字符串 | — | 提示文字 |

```uix
<Spin spinning={loading}>
  <Table data={rows} columns={columns} />
</Spin>
```

## 4. 浮动操作

### FloatButtonGroup 浮动按钮组

一组浮动按钮，展开后子按钮可命中；`trigger`（`click` / `hover`）声明展开方式。

> **当前映射**：已实现。`trigger` 可选且只接受 `click` / `hover`，缺省沿用运行时 `hover`。忽略源码排版空白后，只接受按源码顺序直接列出的静态 `FloatButton` 子元素；每个子按钮继续使用完整 `FloatButton` 属性、公共样式、`key`、`@click` 与 `$event` 映射，生成层通过 `button_views` 保留子 ViewNode 的事件所有权。直接 `If` / `For`、其他元素、可见文本或插值会得到明确编译诊断，不会被静默删除。组父组件只拥有展开触发、布局、命中和过渡，子按钮按自身 WidgetId 拥有业务点击处理器；组件要求使用方启用默认包含的 `feedback` capability。

```uix
<FloatButtonGroup trigger="click">
  <FloatButton icon="edit" description="编辑" @click="editItem" />
  <FloatButton icon="share" description="分享" @click="shareItem($event)" />
</FloatButtonGroup>
```

### FloatButtonBackTop 回到顶部浮动按钮

`scrollY` 超过阈值后显示，点击回到顶部。

> **当前映射**：已实现。该标签是运行时 `BackTop` 的 UIX 别名，不让 `FloatButton` 复制滚动状态所有权；运行时继续使用浮动圆形按钮外观。`scrollY={state}` 绑定 `State<f32>`，点击时写回 `0` 并隐藏；数值字面量提供只读快照。旧 `FloatButtonBackTop::new()` 仅作为 deprecated 迁移门面保留。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `threshold` | 数字 | `400` | 映射到 `visibility_height` |
| `scrollY` | `State<f32>` 绑定 / 数值字面量 | — | 受控滚动位置或只读快照 |
