# 布局组件

[← 返回 UIX Lang 索引](../../README.md)

>
> **接口**：声明 UIX Lang 内置布局组件——表格布局（Row / Col）、Flex 布局（Container）、Grid 布局（Grid）、滚动（ScrollView / VirtualScroll）、面板（Splitter / Affix / BackTop）与应用布局壳（Layout / Sider / Header / Content / Footer）。依赖：[标签语法](../../规范/语法.md)、[样式属性参考](../样式属性.md)。
>

## 1. 表格布局：Row / Col

以行划分横向空间，列在行内按份数（span）分配宽度，适合表单与列表栅格。

### Row

行容器，包裹一组 `Col`。自身不产生布局语义之外的绘制。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `gap` | 长度 | `0` | 列间距 |
| `align` | 关键字 | `stretch` | 交叉轴对齐（`flex-start` / `flex-end` / `center` / `stretch`） |
| `justify` | 关键字 | `flex-start` | 主轴对齐（`flex-start` / `flex-end` / `center` / `space-between` / `space-around`） |
| `class` | 字符串 | — | 样式类 |
| `style` | 字符串 / 对象 | — | 内联样式 |

### Col

列单元，`span` 声明占据份数（总和 24）；`offset` 向右偏移；`order` 调整排列次序。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `span` | 整数 1~24 | `24` | 占据份数 |
| `offset` | 整数 0~24 | `0` | 向右偏移份数 |
| `order` | 整数 | `0` | 排列次序 |
| `sm` / `md` / `lg` / `xl` / `xxl` | 整数 1~24 | — | 响应式断点份数，窗口宽度达标时覆盖 `span` |

**示例**：

```uix
<Row gap="16px">
  <Col span={8}>
    <Text>左侧栏</Text>
  </Col>
  <Col span={16}>
    <Text>主内容区</Text>
  </Col>
</Row>

// 响应式：小屏各占一半，大屏 8 / 16 分栏
<Row gap="16px">
  <Col span={12} lg={8}>...</Col>
  <Col span={12} lg={16}>...</Col>
</Row>
```

## 2. Flex 布局：Container

弹性容器，`direction` 决定主轴方向，子元素按 flex 规则排列，是 UIX 最常用的布局原语（对应 Rust `container`，默认纵向）。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `direction` | 关键字 | `column` | 主轴方向：`column`（纵向）/ `row`（横向） |
| `gap` | 长度 | `0` | 子元素间距 |
| `justify` | 关键字 | `flex-start` | 主轴对齐 |
| `align` | 关键字 | `stretch` | 交叉轴对齐 |
| `flexGrow` / `flexShrink` | 数字 | `0` / `1` | 子元素伸缩比例 |
| `alignSelf` | 关键字 | — | 单个子元素交叉轴覆盖 |
| `padding` / `margin` | 长度 | `0` | 内边距 / 外边距 |
| `bg` | 颜色 | `transparent` | 背景色 |
| `border` | 宽度 + 具体颜色 | — | 边框，如 `1px #d9d9d9` |
| `radius` | 长度 | `0` | 圆角 |
| `w` / `h` | 长度 | `auto` | 固定宽 / 高 |
| `opacity` | 数字 0~1 | `1` | 不透明度 |
| `shadow` | 阴影 | `none` | `none` 或 `x偏移 y偏移 模糊半径 颜色`（见样式参考 [boxShadow](../样式属性.md#93-boxshadow)） |
| `visible` | 布尔 | `true` | 是否参与布局与渲染 |
| `overflow` | 关键字 | `visible` | 内容裁剪：`visible` / `hidden` |

`alignSelf` 复用统一交叉轴关键字；`bg`、`radius`、`w` / `h`、`opacity` 是既有 View 样式入口的短名。静态圆角和尺寸必须是有限非负数值，静态透明度必须位于 0～1；动态表达式由 Rust 类型检查并应遵守同一范围。`visible` 接受布尔简写、字面量或受限表达式，false 时节点保留身份但退出布局、绘制、命中与焦点候选。

`overflow="hidden"` 把直接子树的绘制与命中裁剪到 Container 边界，`visible` 不裁剪；`scroll` / `auto` 不会在 Container 内隐式创建滚动状态，应改用 `ScrollView` 或 `VirtualScroll`。

`border` 使用固定字面量 `宽度 颜色`：宽度必须是有限非负数值，可带 `px`；颜色必须是十六进制、`rgb(...)` 或 `rgba(...)` 具体颜色。`shadow` 使用 `none`，或固定字面量 `x偏移 y偏移 模糊半径 颜色`：两个偏移允许负数，模糊半径必须非负，颜色范围与 `border` 相同。复合值不接受动态表达式，动态场景应使用规范 `style` 属性或 Rust `StyleExt` API，避免运行时猜测字符串分词。

**示例**：

```uix
<Container direction="row" gap="8px" align="center" bg="#f5f5f5"
           radius="8px" w="320px" opacity="0.95" visible={show_toolbar}
           border="1px #d9d9d9" shadow="0 2px 8px rgba(0, 0, 0, 0.15)"
           overflow="hidden">
  <Icon name="star" />
  <Text>标题</Text>
  <Container flexGrow={1} />
  <Button>操作</Button>
</Container>
```

## 3. Grid 布局：Grid + Col

显式轨道网格；`Grid` 声明列 / 行轨道与间距，子元素用 `Col` 的 `span` 或 `gridColumnSpan` / `gridRowSpan` 占据单元格。

| Grid 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `columns` | 轨道列表 | — | 列轨道（如 `1fr 1fr`、`200px 1fr`） |
| `rows` | 轨道列表 | — | 行轨道 |
| `gap` | 长度 | `0` | 行列间距（统一） |
| `colGap` / `rowGap` | 长度 | `0` | 单独控制列 / 行间距 |
| `padding` | 长度 | `0` | 内边距 |

| Col 属性 | 说明 |
|---|---|
| `span` | 占据列数 |
| `gridColumnSpan` / `gridRowSpan` | 跨列 / 跨行数 |

**示例**：

```uix
<Grid columns="1fr 1fr" gap="16px">
  <Col span={1}>
    <Text>卡片 A</Text>
  </Col>
  <Col span={1}>
    <Text>卡片 B</Text>
  </Col>
  <Col span={2}>
    <Text>通栏卡片</Text>
  </Col>
</Grid>
```

## 4. 滚动：ScrollView / VirtualScroll

### ScrollView

滚动容器，内容超出视口时出现滚动条；`overflow` 由容器自身承担（对应 `Style.overflow_content` + 滚动条绘制）。

> **已实现**：`ScrollView` 接受且只接受一个可渲染直接子节点；多个内容节点需显式放入 `Column`、`Container`、`Row` 或 `Grid`。`direction` 必须是编译期关键字，`offset` 必须写成 `offset={scroll_offset}` 并绑定 `State<Point>`。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `direction` | 关键字 | `vertical` | 滚动方向：`vertical` / `horizontal` / `both` |
| `offset` | 绑定 | — | 滚动位置双向绑定（含 x / y） |

### VirtualScroll

虚拟滚动列表：数据量大时只渲染可视区内的行，滚动性能与行数无关。

> **已实现**：`VirtualScroll` 必须声明 `data`、`rowHeight` 和唯一直接 `<For>` 模板。数据表达式只求值一次并由运行时 renderer 按绝对索引物化；`data` 与 `<For ... in>` 必须使用同一表达式。每行只能有一个直接 View 根，多节点需显式放入布局容器。`<For key={...}>` 会生成 `render_keyed`，业务 key 在行构建前同时拥有节点协调与组件私有状态；无 key 时按绝对索引拥有身份，仅适合顺序不可变的数据。滚动偏移、物化范围与测量缓存仍由运行时 `VirtualScroll` 唯一持有。
>
> **行模板作用域**：行根内部可以使用嵌套 `<For>`（数据源可引用当前行字段）、`<If>` 与字符串字面量比较——行 For 的实例路径与逐迭代准备语句会在惰性行工厂闭包内自包含建立；准备语句引用的组件级声明在闭包外克隆遮蔽，组件体后续使用不受影响。`For key` 表达式只允许当前项、可选索引与数字/布尔字面量的纯组合；字符串字面量会被降低为闭包外转换器调用，key 工厂内不可见，需改用数据项的字符串字段。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | 数组 | — | 数据源 |
| `rowHeight` | 长度 | — | 行高（定高虚拟滚动） |
| `item` | 标识符 | 由 `<For>` 声明 | 可选一致性断言；若提供，必须与 `<For>` 当前行变量同名 |

**示例**：

```uix
<VirtualScroll data={logs} rowHeight="32px">
  <For {log} in {logs}>
    <Text>{log.line}</Text>
  </For>
</VirtualScroll>
```

## 5. 面板：Splitter / Affix / BackTop

### Splitter

可拖拽分割面板，两个面板之间一条可调分隔线；支持键盘与指针调整比例。

> **已实现**：`Splitter` 必须恰好包含两个可渲染直接子节点；`direction` 只接受编译期字面量 `horizontal` / `vertical`，`defaultRatio` 字面量在生成期验证为 0~1，动态表达式由运行时夹紧并在非有限值时回退到 `0.5`。拖拽、键盘焦点、比例状态与布局失效仍由公开运行时组件统一拥有。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `direction` | 关键字 | `horizontal` | 分隔方向：`horizontal`（左右分栏）/ `vertical`（上下分栏） |
| `defaultRatio` | 数字 0~1 | `0.5` | 初始比例 |

**示例**：

```uix
<Splitter direction="horizontal" defaultRatio={0.3}>
  <Container>
    <Text>侧边面板</Text>
  </Container>
  <Container>
    <Text>主面板</Text>
  </Container>
</Splitter>
```

### Affix

固钉：滚动越过阈值后将子节点固定在视口指定位置。

> **已实现**：`Affix` 接受且只接受一个可渲染直接子节点；多个内容节点需显式放入 `Container`、`Row`、`Column` 或 `Grid`。`offsetTop` 支持长度字面量或受限数值表达式，`scrollY` 必须写成 `scrollY={scroll_y}` 并绑定 `State<f32>`；生成代码只读取当前快照，状态所有权仍由应用持有，后续值通过根 View 依赖与 reconcile 更新。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `offsetTop` | 长度 | `0` | 固定时距视口顶部距离 |
| `scrollY` | 数字 | — | 当前滚动位置（双向绑定） |

### BackTop

回到顶部按钮：`scrollY` 超过阈值后显示，点击回到顶部。

> **已实现**：`BackTop` 是叶组件，不接受子节点；`threshold` 支持长度字面量或受限数值表达式，`scrollY` 必须写成 `scrollY={scroll_y}` 并绑定 `State<f32>`。运行时组件只克隆状态句柄，外部状态决定可见性，主指针或 Enter / Space 激活时同步写回 `0`。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `threshold` | 数字 | `400` | 显示阈值（滚动距离） |
| `scrollY` | 数字 | — | 当前滚动位置（双向绑定） |

## 6. 应用布局壳：Layout / Sider / Header / Content / Footer

应用级页面骨架：`Layout` 组合侧栏、顶栏、内容与底栏；可嵌套实现二级侧栏。

> **已实现**：`Layout` 默认按 `column` 纵向排列，`direction="row"` 可建立 Sider 与嵌套 Layout 的横向应用壳；方向只接受编译期字面量 `row` / `column`。`Sider` 默认宽度为 200，`Header` / `Footer` 默认高度为 48；公共 `width` / `height` 样式可覆盖节点尺寸。普通布尔属性支持省略 `="true"` 的简写，因此 `collapsible` 与 `collapsible="true"` 等价。五类组件都通过共享 `FlexLayout` 测量和排列有序直接子树。

```uix
<Layout direction="row">
  <Sider collapsible>
    <Text>导航菜单</Text>
  </Sider>
  <Layout>
    <Header>
      <Text>顶栏</Text>
    </Header>
    <Content>
      <Text>主内容</Text>
    </Content>
    <Footer>
      <Text>底栏</Text>
    </Footer>
  </Layout>
</Layout>
```

| 组件 | 说明 |
|---|---|
| `Layout` | 应用布局壳；`direction` 决定子区域排列方向（默认纵向） |
| `Sider` | 侧边栏面板，`collapsible` 属性支持折叠 |
| `Header` | 布局顶部区域 |
| `Content` | 布局主内容区 |
| `Footer` | 布局底部区域 |
