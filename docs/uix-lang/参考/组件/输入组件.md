# 输入组件

[← 返回 UIX Lang 索引](../../README.md)

> **文档角色**：登记参考——持有当前输入组件标签、属性、受控状态、事件、限制和 capability。
>
> **接口**：声明 UIX Lang 内置输入组件——文本与数值输入、选择器、开关与勾选、日期时间与颜色、表单容器。依赖：[标签语法](../../规范/语法.md)、[样式属性参考](../样式属性.md)。
>
> **状态声明**：公开 `uix!` 已映射 `Input`、`InputNumber`、`InputGroup`、`Slider`、`RangeSlider`、`Rate`、`Checkbox`、`Switch`、`Radio`、`Segmented`、`Select`、`Cascader`、`TreeSelect`、`AutoComplete`、`Mentions`、`DatePicker`、`DateRangePicker`、`TimePicker`、`ColorPicker`、`Form`、`FormInputItem`、`FormSelectItem`、`FormCheckboxItem`、`FormRadioItem`、`FormSwitchItem`、`FormSliderItem` 与 `Upload`。Rust 内置能力的权威清单见[组件速查](../../../使用/界面构建/组件速查.md)。

## 1. 文本与数值输入

### Input 文本输入

**映射**：✅ 已映射。`value` 必须是 `State<String>` 表达式；`@change` 可用裸零参数处理器，或通过 `$event` / `$event.value` 接收同一个当前 `&str` 文本载荷。`rows` 与 `maxLength` 接受 `usize` 整数字面量或受限表达式；`rows` 隐含启用多行模式并把最小可见行数钳制到 1。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | 绑定 | — | 文本值（双向绑定） |
| `placeholder` | 字符串 | — | 占位提示 |
| `type` | 关键字 | `text` | `text` / `textarea` / `password` |
| `disabled` | 布尔 | `false` | 禁用 |
| `rows` | 整数 | — | 最小可见行数（隐含启用多行模式） |
| `maxLength` | 整数 | — | 后续用户输入的最大字符数 |
| `@change` | 事件 | — | 值变化事件 |

```uix
<Input value={name} placeholder="请输入名称" @change="onNameChange" />
<Input type="password" placeholder="密码" />
<Input type="textarea" value={goal} rows="2" maxLength="8192" />
```

### InputNumber 数值输入

**映射**：✅ 已映射。`value` 接受实现 `InputNumberValue` 的 `State<T>`；`min`、`max`、`step` 使用 `f64`，`precision` 使用 `u8` 并在运行时归一化到 `0..=15`。字面量会在编译期拒绝反向范围、非正步长和越界精度。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | 绑定 | — | 数值（双向绑定） |
| `min` / `max` | 数字 | — | 取值边界 |
| `step` | 数字 | `1` | 步进 |
| `precision` | 整数 | — | 小数精度 |

### InputGroup 复合输入

**映射**：✅ 已映射。`value` 必须是 `State<String>` 表达式；`addonBefore` 与 `addonAfter` 接受字符串字面量或 `String` 表达式，并与内部 `Input` 共享绘制、命中和双向绑定。

前缀 / 后缀**文本**组合（对应 Rust `addon_before` / `addon_after`）：

```uix
<InputGroup addonBefore="¥" value={amount} addonAfter="元" />
```

### Slider / RangeSlider 滑块

**映射**：✅ 已映射。单值 `Slider` 的 `value` 必须是 `State<f64>` 表达式；`RangeSlider` 使用 `value={{ start: lower, end: upper }}` 分别绑定两个 `State<f64>`。两者的 `min`、`max` 与 `step` 均接受有限数值字面量或 `f64` 表达式。

```uix
<RangeSlider value={{ start: priceMin, end: priceMax }} min="0" max="100" step="5" />
```

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | 绑定 | — | 数值或 `{ start, end }` 区间 |
| `min` / `max` | 数字 | `0` / `100` | 范围 |
| `step` | 数字 | `1` | 步进 |

### Rate 评分

**映射**：✅ 已映射。`value` 必须是 `State<u32>` 表达式；`count` 接受 `usize` 整数或表达式；`allowHalf` 接受布尔简写、布尔字面量或表达式。启用半星后，状态中的一个单位表示半星，例如值 `7` 表示三点五星。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | 绑定 | — | 评分值 |
| `count` | 整数 | `5` | 星数 |
| `allowHalf` | 布尔 | `false` | 半星 |

## 2. 开关与勾选

### Checkbox / Switch

均绑定 `State<bool>`。

**映射**：`Checkbox` ✅ 已映射；`checked` 必须是 `State<bool>` 表达式，`disabled` 接受布尔简写、字面量或表达式。`text` 仅属于 `Checkbox`，接受字符串字面量或 `String` 表达式。`@change` 在勾选状态提交后触发，`$event` / `$event.value` 是当前勾选状态的 `"true"` / `"false"` 文本借用。`Switch` 已映射 `checked` 与 `disabled`，不接受 `text`、`@change` 或子节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `checked` | 绑定 | `false` | 选中态 |
| `disabled` | 布尔 | `false` | 禁用 |
| `text` | 字符串 | — | 勾选旁说明文字（Checkbox） |
| `@change` | 事件 | — | 勾选提交事件（Checkbox） |

### Radio 单选按钮组

**映射**：✅ 已映射。一组互斥选项，`value` 必须绑定 `State<String>` 表达式；`options` 必须引用可迭代的字符串选项数据。当前标签为叶组件，不接受子节点。

```uix
<Radio value={gender} options={genderOptions} />
```

### Segmented 分段控制器

**映射**：✅ 已映射。互斥选项平铺展示，适合少量固定选项；`value` 必须绑定 `State<String>` 表达式，`options` 必须引用可迭代的字符串选项数据。当前标签为叶组件，不接受子节点。

```uix
<Segmented value={view} options={viewOptions} />
```

## 3. 选择器

### Select 下拉选择器

**映射**：✅ 已映射。`options` 引用 Rust 侧可迭代的 `SelectOption::new(label, value)` 数据；单选 `value` 绑定 `State<String>`，声明静态 `multiple` 后绑定 `State<HashSet<String>>`。`searchable` 支持布尔字面量或表达式；`multiple` 会选择绑定状态类型，因此只接受简写、`"true"` 或 `"false"`。`@change` 在选中值提交后触发，可用裸零参数处理器，或通过 `$event` / `$event.value` 接收当前选中值文本借用。当前标签为叶组件，不接受子节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | 绑定 | — | 选中值（支持多选数组） |
| `multiple` | 布尔 | `false` | 多选 |
| `searchable` | 布尔 | `false` | 可搜索 |
| `placeholder` | 字符串 | — | 占位提示 |
| `options` | 数组 | — | `[{ label, value }]` 选项 |
| `disabled` | 布尔 | `false` | 禁用 |
| `@change` | 事件 | — | 选中值提交事件 |

```uix
<Select value={city} options={cityOptions} searchable @change="onCityCommitted()" />
```

```uix
<Select value={cities} options={cityOptions} multiple placeholder="请选择城市" />
```

### Cascader 级联选择器

多层级选项逐列展开。

**映射**：✅ 已映射。`options` 引用 Rust 侧 `Vec<CascaderOption>` 层级树，`value` 必须绑定 `State<CascaderValue>`；路径只有在选择完整叶项后提交。当前标签为叶组件，不接受子节点。

> `CascaderValue` 是本组件登记进 schema 的专属状态值类型，随组件挂接 `tree-widgets` capability；未启用该 feature 时在 state 注解中使用它会在编译期得到定向诊断（见[类型语法](../../规范/语法.md#3-类型语法)）。

| 属性 | 类型 | 说明 |
|---|---|---|
| `options` | 数组 | 层级选项树 |
| `value` | 绑定 | 选中路径数组 |

```uix
<Cascader value={region} options={regionOptions} />
```

### TreeSelect 树形选择器

扁平化展示树节点供选取，语义同 `Tree` 的数据结构。

**映射**：✅ 已映射。`options` 引用 Rust 侧 `Vec<TreeNode>` 层级树，`value` 必须绑定 `State<String>`，其内容为节点稳定 key；展示标题由当前树结构按 key 派生。当前标签为叶组件，不接受子节点。

| 属性 | 类型 | 说明 |
|---|---|---|
| `options` | 表达式 | `Vec<TreeNode>` 层级节点树 |
| `value` | 绑定 | 当前选中节点的稳定 key |

```uix
<TreeSelect value={selectedTreeKey} options={treeNodes} />
```

### AutoComplete / Mentions

- `AutoComplete`：输入时过滤并弹出候选列表，`options` 声明候选。
- `Mentions`：`@` 提及输入，按光标位置触发建议弹层，`suggestions` 声明建议。

**AutoComplete 映射**：✅ 已映射。`options` 引用 Rust 侧 `Vec<String>` 候选，`value` 必须绑定 `State<String>`，输入编辑与候选提交都会写回同一状态；`placeholder` 接受字符串字面量或表达式。当前标签为叶组件，不接受子节点。

```uix
<AutoComplete value={query} options={suggestions} placeholder="请输入" />
```

**Mentions 映射**：✅ 已映射。`suggestions` 引用 Rust 侧 `Vec<String>` 候选，`value` 必须绑定保存完整正文的 `State<String>`；普通编辑与候选提交都会写回完整文本，并只替换光标前的活动 `@` 查询。`placeholder` 接受字符串字面量或表达式。当前标签为叶组件，不接受子节点。

```uix
<Mentions value={message} suggestions={members} placeholder="提及成员" />
```

## 4. 日期时间与颜色

| 组件 | 属性 | 说明 |
|---|---|---|
| `DatePicker` | `value`、`mode`（`date` / `week` / `month` / `quarter`） | 日期选择 |
| `DateRangePicker` | `value`（`{ start, end }`） | 起止日期联动 |
| `TimePicker` | `value` | 小时与分钟分列滚动 |
| `ColorPicker` | `value` | 24 色预设色板 |

**DatePicker 映射**：✅ 已映射。`value` 必须绑定 `State<Date>`；`mode` 是编译期字符串关键字，仅接受 `date`、`week`、`month`、`quarter`，省略时使用 `date`。Week、Month 与 Quarter 模式沿用运行时契约，分别写回命中周期的起点。当前标签为叶组件，不接受子节点。

```uix
<DatePicker value={selectedDate} mode="month" />
```

**DateRangePicker 映射**：✅ 已映射。`value` 必须是同时包含 `start` 与 `end` 的对象，两个字段分别引用 `State<Date>`；生成器按起点、终点顺序绑定现有运行时，缺失、额外字段或普通表达式会在编译期失败。当前标签为叶组件，不接受子节点。

```uix
<DateRangePicker value={{ start: rangeStart, end: rangeEnd }} />
```

**TimePicker 映射**：✅ 已映射。`value` 必须绑定 `State<Time>`，小时与分钟的选择提交、外部状态同步及范围归一化继续由现有运行时负责。当前标签为叶组件，不接受子节点。

```uix
<TimePicker value={selectedTime} />
```

**ColorPicker 映射**：✅ 已映射。`value` 必须绑定 `State<Color>`，预设色板、颜色提交、外部状态同步与弹层生命周期继续由现有运行时负责。当前标签为叶组件，不接受子节点。

```uix
<ColorPicker value={selectedColor} />
```

## 5. 表单容器

### Form 表单

表单容器，字段绑定、校验与联动；字段使用类型化绑定项（`FormInputItem`、`FormSelectItem`、`FormCheckboxItem` 等），与 `model` 配合。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `model` | 绑定 | — | 表单数据模型 |
| `rules` | 函数标识符数组 | `[]` | 全模型校验规则，按声明顺序执行 |
| `@submit` | 事件 | — | 提交事件 |

```uix
<Form model={userForm} rules={[validate_user_form]} @submit="onSubmit">
  <FormInputItem field="name" label="姓名" />
  <FormInputItem field="email" label="邮箱" rules="required,email" />
  <FormSelectItem field="level" label="等级" options={levelOptions} rules="required" searchable placeholder="请选择" />
  <FormCheckboxItem field="accepted" label="协议确认" text="我已阅读并同意" rules="required" />
  <FormRadioItem field="channel" label="通知渠道" options={channelOptions} rules="required" vertical />
  <FormSwitchItem field="notifications" label="启用通知" rules="required" disabled={notificationsLocked} />
  <FormSliderItem field="volume" label="音量" min="0" max="100" step={volumeStep} />
  <Button type="primary" @click="submitForm">提交</Button>
</Form>
```

**Form 类型化映射**：✅ 已映射 `Form`、直接 `FormInputItem`、`FormSelectItem`、`FormCheckboxItem`、`FormRadioItem`、`FormSwitchItem` 与 `FormSliderItem`。`model` 必须绑定 `State<M>`；`field` 必须是可直接投影的 Rust 模型字段名，`label` 独立控制 `FormItem` 展示文本。文本字段 `rules` 严格支持 `required` 与 `email`；选择字段必须以 `options={...}` 绑定可迭代字符串表达式，`rules` 当前支持 `required`，并可声明 `searchable`、`placeholder`、`disabled`。复选字段投影 `bool` 成员，`text` 设置复选框自身说明文字，`rules="required"` 表示必须勾选，并可声明 `disabled`。单选组投影 `String` 成员，必须绑定 `options={...}`，可声明 `groupName`、`disabled`、`vertical` 与 `rules="required"`。开关字段投影 `bool` 成员，支持 `disabled`，且 `rules="required"` 表示值必须为 `true`。滑块字段投影 `f64` 成员，支持 `min`、`max` 与 `step` 的有限数值字面量或 `f64` 表达式，不接受 `rules`；静态反向范围与非正步长在编译期拒绝。

Form 顶层 `rules` 使用编译期函数标识符数组，例如 `rules={[validate_user_form, validate_access]}`；每个 Rust 函数签名为 `fn(&M) -> Result<(), String>`，传入函数名而不是调用结果。字段规则全部通过并组装候选模型后，顶层规则按数组顺序执行；任一失败都会阻止 `State<M>` 写回和 `@submit` 回调。空数组等价于不登记顶层规则；字符串、动态集合、函数调用和其他数组项形态会得到编译诊断。

`@submit` 对应返回 `Result<(), String>` 的类型化 Rust 回调；直接提交按钮必须使用内置 `@click="submitForm"`，由同一 `ModelForm` 统一校验、写回并触发回调。字段必须先于唯一提交按钮。

### Upload 文件上传

本地文件候选队列，管理文件列表与进度；它不提供网络上传、服务端协议或内容安全扫描。

> **当前映射**：已实现。首版 UIX 要求 `files` 绑定调用方拥有的 `State<Vec<UploadFile>>`，稳定身份使用非空且队列内唯一的 `UploadFileId`；运行时只拥有拖放、焦点与列表布局等瞬态 UI 状态。新增、移除与清空先原子写回同一状态，再通过类型化 `UploadChange` 发布事实；应用按 id 更新进度和结果。
>
> `Vec<UploadFile>` 是本组件登记进 schema 的专属状态值类型，随组件挂接 `form-pattern` capability；未启用该 feature 时在 state 注解中使用它会在编译期得到定向诊断（见[类型语法](../../规范/语法.md#3-类型语法)）。
>
> `action` 不进入首版契约：认证、传输、重试、取消与 teardown 由应用服务拥有，使用 `action` 必须得到编译诊断。`accept` 首版只支持空 / `*` / `*/*`、`.ext` / `*.ext` 及 ASCII 逗号分隔的扩展名列表，比较不区分 ASCII 大小写；MIME 模式暂不支持。`multiple=false` 只限制单批候选为一个，`maxCount` 只限制用户新增，不截断外部状态。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `files` | `State<Vec<UploadFile>>` 绑定 | — | 必需的唯一队列真值 |
| `accept` | 扩展名模式字符串 | `*` | 确定性的扩展名过滤 |
| `multiple` | 布尔 | `false` | 多文件 |
| `maxCount` | 整数 | — | 用户新增后的最大队列长度 |
| `maxSize` | 整数 | — | 单文件大小上限 |
| `drag` | 布尔 | `false` | 启用拖放入口 |
| `@change` | 事件 | — | 类型化队列变更事实 |

```rust uix-compile=upload
let upload_files = State::new(Vec::<UploadFile>::new());
let max_upload_size = 10_u64 * 1024 * 1024;

embed(uix!(r#"
<Upload
    files={upload_files}
    accept=".png,*.jpg"
    multiple
    maxCount="8"
    maxSize={max_upload_size}
    drag
    @change="on_upload_change($event)"
/>
"#));
```

`@change` 的 `$event`（以及等价别名 `$event.value`）是 `&UploadChange`，只表达 `Added { ids, files }`、`Removed { ids, files }` 或 `Cleared { files }`；它不是字符串。文件名不参与身份编码。Rust 动态 `accept` 配置调用 `Upload::accept` 并处理 `UploadAcceptError`。被扩展名、大小、文件可读性或 `maxCount` 拒绝的候选通过 `UploadQueueResult::rejected` 返回，不修改状态也不发布变化事实。

队列门禁不保证文件内容可信或路径随后仍有效。应用读取或传输前必须重新处理权限、竞态、格式、大小和内容验证；密码、令牌、网络重试与服务端响应不属于 Upload 组件契约。
