> **状态声明**：事件名与按事件类型的 `$event` 字段登记表均已实现；字段在 Rust 生成前完成编译期校验。

## 事件绑定语法

事件绑定使用 `@事件名="处理器"` 语法（camelCase）；处理器为受限表达式（见[表达式规范](../规范/表达式.md)），可显式接收事件对象 `$event`：

```uix
<Button @click="onClick($event)">点击</Button>
```

## 已登记事件名

| 事件名 | 用途 | 出现组件（示例） |
|---|---|---|
| `@click` | 点击提交 | Button、Menu、ListItem 等通用交互 |
| `@change` | 值变更 | Input、Select、Switch、Rate、Form*Item 等输入类 |
| `@submit` | 表单提交 | Form |
| `@ok` | 模态确认 | Modal |
| `@cancel` | 模态 / 气泡取消 | Modal、Popconfirm |
| `@confirm` | 气泡确认 | Popconfirm |
| `@close` | 关闭 | Drawer、Modal、Notification |
| `@select` | 选择项提交 | Menu、Dropdown、Navigation、Tabs、Segmented 等 |
| `@keyDown` / `@keyUp` | 键盘按下 / 抬起 | 通用可聚焦组件 |
| `@mouseEnter` / `@mouseLeave` | 指针进入 / 离开 | 通用（不提供点击载荷 `$event`） |

事件名与 Rust 语义事件对应关系见[事件使用文档](../../使用/交互与反馈/事件.md)；组件级事件清单以各[组件参考](../参考/组件/布局组件.md)文档为准。

## $event 载荷

当前字段按事件类型登记：

| 事件 | 已登记字段 | 类型与说明 |
|---|---|---|
| `@click` | `$event.x`、`$event.y` | 数字；事件逻辑坐标横轴与纵轴 |
| `@change` | `$event.value` | 字符串；当前变化值 |
| `@select` | `$event.value` | 字符串；当前选择值 |
| `@submit` | `$event.value` | 已登记模型值；当前提交事实 |
| `@close` | `$event.value` | 已登记关闭值；当前关闭事实 |
| `@keyDown` / `@keyUp` | `$event.key`、`$event.code` | 字符串；逻辑键与稳定调试代码 |

访问未登记字段会在生成 Rust 前失败，诊断同时列出该事件的合法字段；字段表为空的事件只能直接传递 `$event`，不能读取成员。
