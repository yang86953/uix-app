## 事件绑定语法

事件绑定使用 `@事件名="处理器"` 语法（camelCase）；处理器为受限表达式（见[表达式规范](../规范/表达式.md)），可显式接收事件对象 `$event`：

```uix
<Button @click="onClick($event)">点击</Button>
```

## 已登记事件名

| 事件名 | 用途 | 出现组件（示例） |
|---|---|---|
| `@click` | 点击提交 | Button、Menu、ListItem 等通用交互 |
| `@change` | 值变更 | Input、Select、Switch、Rate、Form*Item 等输入类 |
| `@submit` | 表单提交 | Form |
| `@ok` | 模态确认 | Modal |
| `@cancel` | 模态 / 气泡取消 | Modal、Popconfirm |
| `@confirm` | 气泡确认 | Popconfirm |
| `@close` | 关闭 | Drawer、Modal、Notification |
| `@select` | 选择项提交 | Menu、Dropdown、Navigation、Tabs、Segmented 等 |
| `@mouseEnter` / `@mouseLeave` | 指针进入 / 离开 | 通用（不提供点击载荷 `$event`） |

事件名与 Rust 语义事件对应关系见[事件使用文档](../../使用/事件.md)；组件级事件清单以各[组件参考](../参考/组件/布局组件.md)文档为准。

## $event 载荷

当前已实现字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `$event.x` | 数字 | 事件逻辑坐标横轴 |
| `$event.y` | 数字 | 事件逻辑坐标纵轴 |

按事件类型登记的完整载荷表（change 的新值、keydown 的 key / code 等）与 `$event.字段` 编译期校验为目标设计，见[变更 · 目标设计](../变更/目标设计.md#设计-7语法小项补齐)。
