# 事件参考

[← 返回 UIX Lang 索引](../README.md)

> **文档角色**：登记参考——持有当前事件名、适用标签和 `$event` 载荷形状；组件参考只补充触发时机与运行行为。
>
> **接口**：声明 UIX Lang 已登记事件绑定和载荷。依赖：[组件规范](../规范/组件.md#7-事件绑定)、[表达式规范](../规范/表达式.md)。导出：[事件使用文档](../../使用/交互与反馈/事件.md)（Rust 语义事件对应关系）。
>
> **状态声明**：本页只列当前登记。事件身份是 `(标签, 事件名)`，同名 `@change` 可以因标签不同而携带不同类型；未列组合在生成 Rust 前拒绝。

## 1. 绑定与作用域

事件绑定使用 `@事件名="处理器"` 语法，事件名为 camelCase，处理器为受限表达式：

```uix
<Button @click="onClick($event.x, $event.y)">点击</Button>
```

`$event` 是处理器作用域专用保留 token。只有当前 `(标签, 事件名)` 登记了载荷时才能使用；它不能进入 computed、action 声明、文本插值或普通属性。无须载荷时应调用零参数处理器。

## 2. 已登记事件名

| 事件名 | 当前用途 | 适用标签示例 |
|---|---|---|
| `@click` | 点击提交 | Button、FloatButton 及登记了公共点击能力的 View |
| `@keyDown` / `@keyUp` | 键盘按下 / 抬起 | 登记了公共键盘能力的可聚焦 View |
| `@mouseEnter` / `@mouseLeave` | 指针进入 / 离开 | 登记了公共指针能力的 View；不提供 `$event` |
| `@change` | 组件值或受控状态已提交变化 | Input、Select、Checkbox、Tabs、Dropdown、Anchor、Pagination、Upload、Calendar、SelectableList、Collapse、ImageGroup 等 |
| `@select` | 菜单稳定 key 已提交 | Menu、Navigation；Tabs 与 Dropdown 不登记该别名 |
| `@submit` | 表单校验通过并提交 | Form |
| `@ok` / `@cancel` | 模态确认 / 取消 | Modal；`@cancel` 也用于 Popconfirm |
| `@confirm` | 气泡确认 | Popconfirm |
| `@close` | 组件确认关闭 | Message、Notification、Alert、Drawer、Modal 等已登记反馈组件 |

完整适用标签以本表和对应组件参考共同闭合：本表决定名称与载荷类别，组件参考决定该标签是否登记、何时建立变化事实。两者冲突时视为文档缺陷，不能自行选择别名。

## 3. `$event` 载荷

### 3.1 公共事件

| `(标签, 事件)` | 直接 `$event` | 可用成员 | 说明 |
|---|---|---|---|
| 公共 `@click` | `&ClickEvent` | `.x`、`.y` | 逻辑坐标；成员投影到点击位置 |
| 公共 `@keyDown` / `@keyUp` | `KeyCode` | `.key`、`.code`、`.mods` | `.key` 为公开键值，`.code` 为稳定调试文本，`.mods` 为 `KeyMod` |
| 公共 `@mouseEnter` / `@mouseLeave` | 不提供 | 无 | 使用零参数处理器 |

键盘处理器是观察器：执行后以 `EventResult::Bubbled` 保留观察事实，继续交付组件自己的键盘处理与父级冒泡。它不会吞掉 Input 的光标导航、选区或文本编辑；父容器可接收输入框未消费的保存组合键。`$event.mods.has_ctrl()` / `has_super()` / `has_shift()` / `has_alt()` 分别判断修饰键，Ctrl/Cmd+S 应同时核对键值与修饰键。

### 3.2 组件事件

| `(标签, 事件)` | 直接 `$event` 载荷 | `$event.value` |
|---|---|---|
| Input `@change` | 当前文本借用 | 同一文本借用 |
| Select `@change` | 当前选中值文本借用 | 同一文本借用 |
| Checkbox `@change` | 当前勾选状态的 `"true"` / `"false"` 文本借用 | 同一文本借用 |
| Menu / Navigation `@select` | 稳定 key 文本借用 | 同一 key 借用 |
| Tabs / Dropdown / Anchor `@change` | 稳定 key 或 href 文本借用 | 同一文本借用 |
| SelectableList / Collapse `@change` | 稳定 id / key 文本借用 | 同一文本借用 |
| Calendar `@change` | `yyyy-mm-dd` 文本借用 | 同一文本借用 |
| ImageGroup `@change` | 当前索引的十进制文本借用 | 同一文本借用 |
| Pagination `@change` | 当前页码或 `page_size=<值>` 文本借用 | 同一文本借用 |
| Upload `@change` | `&UploadChange` | 同一类型化变化事实借用 |
| Form `@submit` | 当前模型 `M` 的提交载荷 | 同一模型载荷 |
| Message / Notification `@close` | `FeedbackClosed` | 同一类型化关闭事实 |
| Alert `@close` | 关闭事实文本借用 | 同一文本借用 |

`$event.value` 是 `@change` / `@select` / `@submit` / `@close` 对**当前实际载荷**的统一别名，不承诺类型为字符串。需要类型化 Upload、Form 或 Feedback 载荷时，直接传递 `$event` 更清晰；最终 Rust 类型由回调签名检查。

未在表中声明载荷的组件事件不得访问 `$event`。访问未知字段会在生成 Rust 前失败，并列出当前 `(标签, 事件名)` 的合法成员；不能把另一组件同名事件的成员推断到当前标签。
