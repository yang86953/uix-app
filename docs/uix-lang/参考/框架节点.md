# 框架节点

[← 返回语言索引](../README.md)

本页维护框架原生识别的应用组装、绘制和结构入口。第三方组件标签由项目加载的库声明登记，框架不维护具体组件的属性表。

## App

`<App>` 根生成应用 builder；构建时选择 `OutputKind::App`，Rust 使用 `uix_app::uix_app!("文件路径")` 读取结果并持有 `.run()` 和生命周期。App 根自动要求 `application` 能力，图形后端仍由目标配置选择。

## 结构入口

`Widget`、`Slot`、`If`、`For`、`Record` 和 `Visual` 的结构、作用域和生成规则由本仓库 [组件语法](../规范/组件.md)、[控制流](../规范/控制流.md) 与 [编译契约](../规范/编译契约.md) 维护。`KernelView` / `KernelHost` / `KernelChildren` 用于已有 Rust 内核的窄桥接，不定义另一套具体控件库。

## Canvas 画布

固定 logical 尺寸的轻量绘制节点，对应公开 Rust `canvas` 组合器。绘制逻辑、状态读取与失效完全由 Rust 侧的绘制函数持有；闭包内读取的 `State` / `Computed` 会自动绑定到该节点的窄 Paint 失效，不形成每帧回调。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `width` | 数字 | — | 必填；logical 宽度（f32） |
| `height` | 数字 | — | 必填；logical 高度（f32） |
| `paint` | 绘制函数 | — | 必填；Rust 侧 `Fn(Rect, &mut PaintContext)` 表达式 |

`Canvas` 是叶组件：不接受子节点与事件属性；公共尺寸、布局与身份属性照常可用（如 `flexGrow`）。`paint` 必须是 Rust 表达式（经 `external` 声明的函数项或闭包），签名由 Rust 编译器在调用点验证。

```uix
<Canvas width="590" height="34" paint={draw_waveform} flexGrow={1} />
```

## FocusTrap 焦点作用域

Tab 键在子树内循环，模态场景的焦点管理原语。

> **当前映射**：已实现。可选 `active` 接受布尔简写、`true` / `false` 字面量或布尔表达式，声明该作用域当前是否接管焦点循环；省略时沿用运行时默认的 `true`。`FocusTrap` 按源码顺序接收零个或多个普通、`If`、`For` 子节点；编译层只声明稳定焦点作用域与启用事实，不静态猜测后代是否可聚焦。可聚焦后代解析与 Tab 正反向循环继续由运行时 `WidgetTree` 独占；禁用时不选择下一焦点。overlay 的焦点恢复是独立生命周期，不由普通 `FocusTrap` 声明。`FocusTrap` 位于核心组件层，不要求启用 `feedback` capability。

焦点作用域的子树由调用方提供；结构节点保留子项顺序，运行时只在可聚焦后代之间移动焦点。
