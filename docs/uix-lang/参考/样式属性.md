## 1. 简介与使用方法

本页描述当前源码；六态样式、主题过渡、min/max 尺寸、百分比 inset、有限 Grid minmax
与窗口断点尚未进入 crates.io 0.0.8。已发布版本与源码联调的区别见[交付与许可](../../产品/交付与许可.md)。

### 1.1 映射状态图例

每个属性条目标注其与 Rust API 的映射状态：

| 标记 | 含义 |
|---|---|
| ✅ 已映射 | Rust `Style` 或 `ViewNode` 已有对应入口（[style](../../../src/ui/theme/style/mod.rs)、[view](../../../src/ui/view/mod.rs)），语义一致 |
| 🚫 明确不支持 | 与 UIX 的 Flex/Grid 布局模型冲突，不属于目标设计；编译器提供专用诊断与替代建议 |

### 1.2 使用方法

样式属性可通过以下四种方式使用：

1. **基础样式类**：

   ```text
   styleName {
     propertyName: propertyValue;
   }
   ```

2. **标签级内联样式**（CSS 字符串形式，语法与样式类块一致）：

   ```text
   <Text style="propertyName: propertyValue;" />
   ```

3. **主题样式定义**：

   ```text
   @theme themeName {
     propertyName: propertyValue;
   }
   ```

4. **引用主题属性**（值中以 `#属性名` 引用）：

   ```text
   styleName {
     propertyName: #themeProperty;
   }
   ```

**优先级**：内联样式 > 样式类 > 主题默认值。

## 2. 布局属性

### 2.1 display

**映射**：✅ 已映射（`Style.display: DisplayMode`）

**语法**：`display: value`

**取值范围**：

- `flex`：弹性布局（默认，UIX 布局引擎主模式）
- `grid`：网格布局
- `none`：隐藏整棵元素子树（不参与布局、绘制、命中及焦点导航），恢复其他 display 值时保留状态与节点身份。

**默认值**：`flex`

**适用元素**：所有元素

**示例**：

```uix
flexContainer {
  display: flex;
  justifyContent: center;
}

<Container class="flexContainer">
  <Text>Flex 容器</Text>
</Container>
```

> 说明：UIX 引擎没有 `block` / `inline` / `inline-block` 模式（元素一律以弹性盒子参与布局）；块级/内联观感由 `direction`、`alignItems` 等控制。

### 2.2 flexDirection

**映射**：✅ 已映射（`Style.flex_direction: FlexDirection`）

**语法**：`flexDirection: value`

**取值范围**：

- `row`：主轴水平，从左到右
- `column`：主轴垂直，从上到下（默认）

**默认值**：`column`

**适用元素**：弹性容器

**示例**：

```uix
toolbar {
  flexDirection: row;
  gap: 8px;
}
```

### 2.3 justifyContent / alignItems

**映射**：✅ 已映射（`Style.justify_content` / `Style.align_items`）

**语法**：`justifyContent: value`、`alignItems: value`

**取值范围**：

- `justifyContent`（主轴）：`flex-start`、`flex-end`、`center`、`space-between`、`space-around`
- `alignItems`（交叉轴）：`flex-start`、`flex-end`、`center`、`stretch`（默认）

**默认值**：`justifyContent: flex-start`、`alignItems: stretch`

**适用元素**：弹性容器

**示例**：

```uix
centeredRow {
  flexDirection: row;
  justifyContent: center;
  alignItems: center;
}
```

### 2.4 gap

**映射**：✅ 已映射（`Style.gap`）

**语法**：`gap: value`

**取值范围**：长度值（如 `8px`、`12px`）

**默认值**：`0`

**适用元素**：弹性容器与网格容器

**示例**：

```uix
spacedList {
  gap: 8px;
}
```

### 2.5 flexGrow / flexShrink

**映射**：✅ 已映射（`Style.flex_grow` / `Style.flex_shrink`）

**语法**：`flexGrow: number`、`flexShrink: number`

**取值范围**：非负数字（如 `0`、`1`、`2`）

**默认值**：`flexGrow: 0`、`flexShrink: 1`

**适用元素**：弹性容器中的子元素

**示例**：

```uix
growPane {
  flexGrow: 1;
}
```

### 2.6 flexWrap

**映射**：✅ 已映射（`Style.flex_wrap: bool`）

**语法**：`flexWrap: true | false`

**默认值**：`false`

**适用元素**：弹性容器

### 2.7 alignSelf

**映射**：✅ 已映射（`Style.align_self: Option<AlignItems>`）

**语法**：`alignSelf: value`

**取值范围**：同 `alignItems`（`flex-start`、`flex-end`、`center`、`stretch`）

**默认值**：无（跟随容器 `alignItems`）

**适用元素**：弹性容器中的子元素

### 2.8 gridTemplateColumns / gridTemplateRows

**映射**：✅ 已映射（`Style.grid_template_columns` / `Style.grid_template_rows: Vec<GridTrack>`）

**语法**：`gridTemplateColumns: value`

**取值范围**：空格分隔的 `100px`、`1fr`、`auto` 或有界 `minmax(min, max)`。
minmax 下界为非负有限 px 或百分比，上界为非负有限 px 或 fr，例如
`minmax(240px, 1fr)`、`minmax(25%, 300px)`。下界超过上界时下界优先。
不支持 auto/fr 下界、auto/百分比上界、repeat、auto-fit/auto-fill 或完整 CSS Grid。
`<Grid columns="…" rows="…">` 与这两个样式属性共用解析入口。

**默认值**：无（Grid 布局需显式声明轨道）

**适用元素**：`display: grid` 容器

**示例**：

```uix
twoColumnGrid {
  display: grid;
  gridTemplateColumns: 1fr 1fr;
  gap: 16px;
}
```

### 2.9 gridColumnGap / gridRowGap

**映射**：✅ 已映射（`Style.grid_column_gap` / `Style.grid_row_gap`）

**语法**：`gridColumnGap: value`、`gridRowGap: value`

**取值范围**：长度值

**默认值**：`0`

**适用元素**：网格容器

### 2.10 gridColumnSpan / gridRowSpan

**映射**：✅ 已映射（`Style.grid_column_span` / `Style.grid_row_span`）

**语法**：`gridColumnSpan: number`、`gridRowSpan: number`

**取值范围**：正整数

**默认值**：`1`

**适用元素**：网格容器中的子元素

### 2.11 position 与 top / right / bottom / left

**映射**：✅ 已映射（`ViewNode::position(PositionMode)` 与逐边 inset；`WidgetTree` 统一求解正常流、包含块、根视口、滚动裁剪、绘制和命中）

**语法**：`position: value`

**取值范围**：`static`、`relative`、`absolute`、`fixed`、`sticky`

**默认值**：`static`

**适用元素**：所有元素

**四边语法**：当前源码接受 `auto`、有限有符号 px、百分比、数值主题 token，以及
由 px/百分比/token 加减组成的有限 `calc()`，如 `left: calc(50% - 12px)`。
默认均为 `auto`；无单位值、乘除、嵌套函数和其它单位仍拒绝。水平边按包含块宽度、
垂直边按高度解析，未定参照保持未约束；真实已分配的 0 或 1px 仍是有效参照。

标签数值属性 `top` / `right` / `bottom` / `left` 与 `width` / `height` 使用相同的数值语法，接受像素字面量与 `f32` 表达式，例如 `<Container style="position: absolute;" left={x.get()} top={y.get()} />`。动态坐标由状态更新驱动重排，绘制、裁剪与命中共享结果；清除某一边使用样式中的 `auto`。

**布局语义**：

- `static` 参与正常流并忽略四边值。
- `relative` 保留正常流槽位，只移动自身视觉、命中和子树；同轴同时声明时 `left` 优先于 `right`、`top` 优先于 `bottom`。
- `absolute` 退出正常流，相对最近的非 `static` 祖先定位；没有定位祖先时使用根客户区。左右或上下同时声明会拉伸对应 border-box 轴。
- `fixed` 退出正常流并相对根客户区定位，不继承祖先滚动与裁剪。
- `absolute` / `fixed` 的自动尺寸按自然内容测量，忽略节点自身的 Flex grow 零 basis；明确宽高与双边拉伸继续生效。内部需要内容尺寸的正常流容器使用 `column_fit` 等固有尺寸布局。
- `sticky` 保留正常流槽位，在最近滚动视口的四边约束内停靠，同时不越过直接父级边界。
- 未声明的轴使用包含块起点；状态伪类或 `setStyle` 的 `auto` 只清除当前边，不影响其他三边。

**示例**：

```uix
absoluteElement {
  position: absolute;
  top: 10px;
  right: 10px;
}
```

> `fixed` 是根视口定位，不替代具备焦点管理、关闭策略与无障碍语义的浮层组件；模态框、弹出菜单等交互表面仍应使用浮层系统。

### 2.12 z-index

**映射**：✅ 已映射（`ViewNode::z_index(i32)`；统一决定同级节点的绘制与命中顺序）

**语法**：`z-index: value`

**取值范围**：整数

**默认值**：`auto`（运行时等价为 `0`）

**适用元素**：所有元素

**示例**：

```uix
modal {
  z-index: 1000;
}
```

### 2.13 float / clear

**映射**：🚫 明确不支持（UIX 不建立 CSS 浮动格式上下文，也不增加 `Style.float` / `Style.clear` 平行布局状态）

**语法**：`float: left | right | none`、`clear: left | right | both | none`

**默认值**：`none`

**适用元素**：块级元素

> 说明：本组属性不属于目标设计。左右贴靠使用 `flexDirection: row` + `justifyContent: space-between` 或 `flexGrow`；重新开始一行使用新的 Row/Column 分组；复杂二维分区使用 Grid 轨道。编译器对规范值和非法值都返回专用诊断，不使用临时规划标记暗示未来引入第二套布局算法。

## 3. 盒模型属性

### 3.1 width / height

**映射**：✅ 已映射（`Style.width` / `Style.height: Option<f32>`）

**语法**：`width: value`、`height: value`

**取值范围**：长度值（如 `100px`、`50%`）或 `auto`

**默认值**：`auto`

`Container` / `Grid` 统一按 **border-box** 解释声明尺寸：宽高已经包含 border 与 padding，不再在外面额外增加边框；margin 不在宽高内。`auto` 时由内容加两层内边界决定，空内容仍保留 border/padding。当前数值 `0` 沿用未指定轴的兼容语义。Flex 分配、shrink 与交叉轴 Stretch 仍依父布局契约执行；这不是绕过父布局的绝对像素锁。

**适用元素**：所有元素

**示例**：

```uix
fullWidth {
  width: 100%;
}
```

### 3.1.1 minWidth / maxWidth / minHeight / maxHeight（当前源码）

四项通过 `StyleLength` 保留单位，作用于 Flex/Grid 与定位的同一尺寸求解。
接受非负有限 px、百分比、数值 token、无单位像素，以及有限加减 `calc()`；
`auto`/`none` 表示不约束。例如 `minWidth: 120px; maxWidth: calc(100% - 24px);`。
calc 可含负项，结果钳到 0；参照未定时含百分比的整体约束暂不生效，纯 px 仍生效。
同轴 min 大于 max 时 min 优先、max 抬高到 min。Rust 对应 `ViewNode` 的
`min_width` / `max_width` / `min_height` / `max_height`，参数可用 `StyleLength`。
这不扩展普通 width/height 的动画单位集合。

**取值范围**：长度值或百分比

**默认值**：`0`

**适用元素**：所有元素

**示例**：

**取值范围**：长度值或百分比

**默认值**：`0`

**适用元素**：所有元素

**映射**：✅ 已映射（`Style.border_color` / `Style.border_width: EdgeInsets`）

**语法**：`borderColor: value`、`borderWidth: value`（四边）或 `borderTopWidth: value` 等单边形式

### 3.5 borderRadius

**映射**：✅ 已映射（单值 → `Style.border_radius: f32`；一至四值 → `Style.border_radius_corners: Option<CornerRadii>`，两种输入是同一属性的不叠加声明）

**语法**：`borderRadius: <len>{1,4}`

**取值范围与展开**（与 CSS 一致，顺序 tl/tr/br/bl）：

- `1` 值：四角同值（保持既有单值语义与标量动画）；
- `2` 值：左上/右下取第一值，右上/左下取第二值；
- `3` 值：左上、右上/左下、右下；
- `4` 值：左上、右上、右下、左下。
- 每个分量为有限非负十进制数、`px` 长度或主题数值 token；相邻半径之和超出边长时由绘制层按全局比例归一。圆角轮廓为直边矩形与各角圆弧约束的交集：单个半径可跨过矩形中线，对角大角的切线区域重叠时两角约束同时生效（如 `80px 0 80px 0`）。虚线/点线的整条折线（含线段中点）轮廓误差不超过 0.5 逻辑像素，以弦高反解采样段数。每角最多 2048 段，整框最多 16384 段虚线；超出资源预算时不绘制该线型并输出诊断，不截断段数后冒充满足误差。普通背景、实线与双线不受此折线预算影响。
- 单值（含显式 `0`）与四值在 class、内联、`setStyle`、`map_style` 与状态差量中互相完整覆盖：任一形式的显式声明使另一形式失效，`map_style` 写回 `with_rounded`（含写回相同旧单值）同样清除四角声明；清空后恢复低层声明。`StyleDiff.border_radius_corners` 为双层 `Option`：外层 `Some` 表示本层显式，内层 `None` 表示显式恢复单值形式。

**迁移说明**：S4 起公开 `Style`/`StyleDiff` 新增 `border_radius_corners` 字段，外部全字段结构体字面量构造需补齐该字段或改用 `..Default::default()`；builder 与字段读写不受影响。

**默认值**：`0`

**适用元素**：所有元素

**示例**：

```uix
roundedCorners {
  borderRadius: 8px;
}

asymmetricCard {
  borderRadius: 16px 16px 4px 4px;
}
```

### 3.6 borderStyle

**映射**：✅ 已映射（`Style.border_style: Option<BorderStyle>`；未声明时采用 `solid`，`none` 仅关闭绘制而保留盒模型边框宽度）

**语法**：`borderStyle: none | solid | dashed | dotted | double`

**默认值**：`solid`

**适用元素**：所有元素

**绘制语义**：`dashed` 与 `dotted` 沿圆角边框完整周长保持连续相位；`double` 使用两道同色描边。

**示例**：

```uix

  borderColor: #colorBorder;
  borderWidth: 3px;
  borderStyle: dashed;

```

## 4. 文本属性

### 4.1 color

**映射**：✅ 已映射（`Style.color: ColorValue`）

**语法**：`color: value`

**取值范围**：颜色值（如 `#000`、`rgb(0,0,0)`、`blue`）

**默认值**：主题默认文本色

**适用元素**：文本元素

**示例**：

```uix
redText {
  color: #ff0000;
}
```

### 4.2 fontSize

字号以逻辑像素中的 em 尺度解析；不等于字形墨迹高度或 ascent−descent 总高度。静态/动态 Text 与 Input/textarea、RichText 基本文本的 normal 行盒统一为最终字号的 1.5 倍。控件覆盖范围、显式叶节点样式与迁移影响见[排版契约](../../使用/界面构建/样式与主题.md#文字度量)。

**映射**：✅ 已映射（`Style.font_size: TypographyToken`，支持 token 名或像素值）

**语法**：`fontSize: value`

**取值范围**：字号 token（`small`、`body`、`large`、`xlarge`、`heading1`~`heading5`）或长度值（如 `14px`）

**默认值**：`body`

**适用元素**：文本元素

**示例**：

```uix
largeText {
  fontSize: 24px;
}

titleText {
  fontSize: heading3;
}
```

### 4.3 fontFamily

**映射**：✅ 已映射（`Style.font_family: Option<FontFamily>`；按声明顺序选择第一个已加载字体族）

**语法**：`fontFamily: value`

**取值范围**：字体名称列表（如 `Arial, sans-serif`）

**默认值**：系统默认字体

**适用元素**：文本元素

**约束**：接受逗号分隔的裸名称或单引号名称（如 `'Segoe UI', Arial, sans-serif`），显式列表会完整覆盖继承列表。名称在已加载的 `FontService` 注册表中按不区分大小写的方式依次解析；`system-ui`、`sans-serif`、`serif`、`monospace`、`cursive`、`fantasy` 使用当前系统字体，全部未命中时也回退到当前系统字体。布局、选择度量与绘制共享同一个最终字体句柄。空分量、空名称、控制字符或非法引号形态会在编译期拒绝；当前不会在绘制阶段按名称即时加载系统字体。

### 4.4 fontWeight

**映射**：✅ 已映射（`Style.font_weight: Option<FontWeight>`；显式 `normal` 可覆盖标题或 `strong` 默认字重）

**语法**：`fontWeight: value`

**取值范围**：`normal`、`bold` 或数字 `100`~`900`

**默认值**：`normal`

**适用元素**：文本元素

**约束**：关键字 `normal`、`bold` 分别对应数值 `400`、`700`；数字必须是 `100`~`900` 内的整数，非法关键字、小数、单位或越界值会在编译期拒绝。运行时保留精确数值；当前单字体面后端将 `100`~`599` 选择为常规面，将 `600`~`900` 选择为合成粗体面，布局几何保持一致。

### 4.5 textAlign

**映射**：✅ 已映射（`Style.text_align: Option<TextAlign>`；显式 `left` 可覆盖继承值）

**适用元素**：块级文本元素

### 4.6 textDecoration

### 5.1 backgroundColor

**映射**：✅ 已映射（`Style.background`，含 hover / focus / active 状态色）

**语法**：`backgroundColor: value`

**取值范围**：颜色值（如 `#fff`、`rgb(255,255,255)`、`transparent`）

**默认值**：`transparent`

**适用元素**：所有元素

**示例**：

```uix
whiteBackground {
  backgroundColor: #ffffff;
}
```

> 状态色：`backgroundColor:hover` / `backgroundColor:focus` / `backgroundColor:active` 形式声明交互状态背景（对应 `Style.background_hover` 等字段）。

### 5.2 backgroundImage

**映射**：✅ 已映射（`Style.background_image: Option<BackgroundImage>`；`none`、本地图片、带角度多色标线性渐变、固定中心双色径向渐变）

**语法**：`backgroundImage: none | url('local/path.png') | linear-gradient([angle-deg,] color [offset%], ...) | radial-gradient(color, color)`

**取值范围与边界**：

- `url()` 路径必须使用单引号或双引号包裹，只接受本地文件路径；空路径、网络 URL、`data:` URI 和多背景层在编译期拒绝。
- 线性渐变支持 2–16 个色标，颜色可用普通颜色值或已登记颜色 token。可选首项为有限 `deg` 角度：`0deg` 向上、`90deg` 向右、默认 `180deg` 向下；负角度和大于一周的角度按 360° 归一。
- 色标可跟 `0%`–`100%` 位置，必须非递减；未写首尾位置补为 0%/100%，内部连续未定位色标在相邻锚点间均分。相同位置产生硬切换，后项在该位置生效；首尾色标外延伸端点颜色。拒绝倒序、非有限、越界、像素位置及超过 16 项，不排序、不截断。
- 径向渐变仍只接受恰好两个颜色，不支持角度、色标位置或复杂形状；不支持多背景层。
- 线性渐变沿通过盒中心的角度方向投影，径向渐变固定从盒中心覆盖到最远角；两者填满背景盒并忽略 `backgroundPosition` / `backgroundRepeat` / `backgroundSize`。
- 声明 `borderRadius` 时，背景色、背景图与渐变都在同一圆角边界（背景盒坐标 + 有效圆角，含跨中线大角）内精确裁剪；本地图片对整层所有与圆角裁切区域相交的瓦片生成盒相对掩码派生位图（跨盒偏移、cover/contain 溢出与 repeat 跨角一致处理；设备换算含 device pixel ratio 与 4096 钳制下的有效缩放），直边部分由矩形裁剪负责；派生缓存按几何键 LRU 有界并在 resize/动画下淘汰回收。子树裁剪（`overflow: hidden`）保持矩形边界，不受圆角影响。
- 本地图片保持固有像素尺寸并复用 `ImageService` 路径缓存；加载失败时只保留背景色，不产生半成品图层。
- 绘制顺序为背景色 → 背景图/渐变 → 边框，`opacity` 统一作用于三个表面图层。

Rust 可用 `BackgroundImage::LinearGradientStops` 和 `GradientStopValue`；直接绘制使用验证后的 `LinearGradient::new` 与 `fill_linear_gradient_stops`。颜色仍在既有非预乘通道空间插值，覆盖率只作用于 alpha。旧双色枚举及 API 保留；全字段 `Style`/`StyleDiff` 字面量需补 `box_shadows`，自定义 `Canvas2D` 需实现新增绘制方法。

**默认值**：`none`

**适用元素**：所有元素

**示例**：

```uix
hero {
  backgroundColor: #101820;
  backgroundImage: url('assets/hero.png');
  backgroundPosition: center;
  backgroundRepeat: no-repeat;
}

hero:hover {
  backgroundImage: linear-gradient(#colorPrimary, rgba(0,0,0,0.5));
}
```

### 5.3 backgroundPosition

**映射**：✅ 已映射（`Style.background_position: Option<BackgroundPosition>`；百分比按背景盒与图片的剩余空间解析）

**语法**：`backgroundPosition: value` 或 `backgroundPosition: x y`

**取值范围**：

- 轴关键字：`left`、`right`、`top`、`bottom`、`center`；两个轴关键字可写为 `top left` 或 `left top`。
- 有限 `px` 长度，允许负值；两个数值严格按 `x y` 顺序。
- `0%` 到 `100%`；`0%` 对齐起点，`100%` 对齐终点，比例作用于背景盒尺寸减图片固有尺寸后的剩余空间。
- 单个水平/垂直关键字补齐另一轴为 `center`；单个数值解释为水平轴并把垂直轴补齐为 `center`。
- 首批不接受关键词与数值混写、无单位长度、越界百分比、`calc()` 或三项以上语法。

**默认值**：`0% 0%`

**适用元素**：所有元素

### 5.4 backgroundRepeat

**映射**：✅ 已映射（`Style.background_repeat: Option<BackgroundRepeat>`；图片按 `backgroundSize` 解析后的尺寸平铺并裁剪到背景盒）

**语法**：`backgroundRepeat: value`

**取值范围**：`repeat`、`repeat-x`、`repeat-y`、`no-repeat`

**默认值**：`repeat`

**适用元素**：所有元素

### 5.5 backgroundSize（S4）

**映射**：✅ 已映射（`Style.background_size: BackgroundSize`；`Auto` 为默认值兼显式恢复关键字）

**语法**：`backgroundSize: auto | cover | contain | <len> | <len>{1,2}`（每轴可为 `auto`、`<n>px` 或 `<n>%`）

**取值范围与语义**：

- `auto`：保持图片固有尺寸（与未声明完全一致，也是显式恢复值）。
- `cover`：等比缩放到完全覆盖背景盒，单侧允许溢出（剩余空间可为负，居中定位对称溢出）。
- `contain`：等比缩放到完整包含在背景盒内，单侧允许留白。
- 显式 `0px` / `0%` 不是 `auto`：任一最终轴为零时不绘制该图片图层，不恢复固有尺寸；图片已经加载也遵守此规则。
- 逐轴尺寸：`px` 为逻辑像素；`%` 参照当前绘制的 border-box（与背景定位共用同一盒）；单轴 `auto` 按另一轴的缩放比例保持固有宽高比（如 1200x800 图在 40px 高下宽为 60），两轴显式时允许非等比拉伸；单值表示宽度、高度按固有比例推导。
- 只作用于图片来源；渐变不受影响。百分比范围 `0%`~`100%`，不接受负值、`em` 等其它单位或三分量。
- 与 `backgroundPosition` / `backgroundRepeat` 组合：定位与平铺几何消费缩放后的瓦片尺寸，负剩余空间沿用既有居中/终点语义。

**迁移说明**：S4 新增公开字段与 `BackgroundSize` / `BackgroundAxisSize` 类型；`Style`/`StyleDiff` 全字段字面量构造需补齐或改用 `..Default::default()`。

**默认值**：`auto`

**适用元素**：所有元素

**示例**：

```uix
hero {
  backgroundImage: url('assets/hero.png');
  backgroundSize: cover;
  backgroundPosition: center;
}

thumb {
  backgroundImage: url('assets/icon.png');
  backgroundSize: auto 40px;
}
```

## 6. 动画与过渡

> `animation` 与 `transition` 均已接入既有逐窗动画调度；Rust 侧 `Animated<T>`、Spring 和动画组用法见[动画](../../使用/动画与异步/动画.md)。

### 6.1 animation

**映射**：✅ `@keyframes` → 组件私有 `Animated<T>` + 逐窗帧调度

**语法**：`animation: name duration timing-function delay iteration-count direction fill-mode`

**取值范围**：

- `name`：动画名称
- `duration`：有限非负时间，支持 `s`、`ms`（如 `1s`、`250ms`）
- `timing-function`：`linear`、`ease`、`ease-in`、`ease-out`、`ease-in-out`
- `delay`：有限非负时间，支持 `s`、`ms`
- `iteration-count`：非负整数或 `infinite`
- `direction`：`normal`、`reverse`、`alternate`、`alternate-reverse`
- `fill-mode`：`none`、`forwards`、`backwards`、`both`

**默认值**：`none 0s ease 0s 1 normal none`

**适用元素**：所有元素

**首批可动画属性**：`width`、`height`、`borderRadius`、`opacity`、`color`、`backgroundColor`

- `@keyframes` 选择器支持 `from`、`to` 和 `0%`～`100%`；同一偏移或同名声明会在编译期拒绝。
- `width` / `height` 只接受有限非负 `px` 或无单位数值，不接受 `auto`、百分比；颜色使用十六进制、`rgb` 或 `rgba` 具体值，不接受主题 token 插值。
- 动画状态按文档根或 `Widget` 私有作用域持久化；`For` 中各实例按实际路径隔离，同一节点 reconcile 不会重启动画。
- `animation` 只能用于基础样式类或静态内联样式。`:hover` / `:disabled` / `:checked` 和 `setStyle` 中启动动画会返回编译期诊断；状态变化的平滑插值由 `transition` 契约负责。

**示例**：

```uix
fadeIn {
  opacity: 0;
  animation: fade 1s ease-in-out 100ms 2 alternate both;
}

@keyframes fade {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}

<Text class="fadeIn">声明式淡入</Text>
```

### 6.2 transition

**映射**：✅ 最终样式目标 → 组件私有 `Animated<T>` 原位 retarget + 逐窗帧调度

**语法**：`transition: property duration timing-function delay`

**取值范围**：

- `property`：`all`、`width`、`height`、`borderRadius`、`opacity`、`color`、`backgroundColor`
- `duration`：有限非负时间，支持 `s`、`ms`
- `timing-function`：`linear`、`ease`、`ease-in`、`ease-out`、`ease-in-out`
- `delay`：有限非负时间，支持 `s`、`ms`

**默认值**：`all 0s ease 0s`

**适用元素**：所有元素

- 首次挂载直接静止在最终样式，不播放入场；同一文档或 `Widget` 作用域、`For` 实例路径和最终 View key 下，目标变化会复用同一 `Animated<T>` 并原位 retarget。
- `all` 只收集首批矩阵中实际参与该节点状态变化的字段；基础样式、已登记的六态差异层和 `setStyle` 完整分支均可提供目标。
- `width` / `height` 必须在基础样式和每个 `setStyle` 完整分支中提供可解析的有限非负目标；颜色接受具体颜色及类型匹配的主题 token。数值 token 遵守对应属性范围，`auto`、百分比尺寸和缺失的完整分支目标仍在编译期拒绝。
- 颜色与数值目标按当前窗口/Provider 有效主题解析。主题或目标在播放中改变时从当前呈现值 retarget；完成后静止，零时长立即完成，卸载取消。此处不改变 `@keyframes` 的主题颜色限制。
- `transition` 配置只能位于基础样式类或静态内联样式；状态分支不得改变配置。同一节点同时声明 `animation` 与 `transition` 会因争用播放生命周期而在编译期拒绝。

**示例**：

```uix
normalAction {
  padding: 6px 12px;
  backgroundColor: #ffffff;
  transition: backgroundColor 200ms ease-out;
}

normalAction:hover {
  backgroundColor: #e6f4ff;
}

<Widget name="HoverAction">
  <Button class="normalAction">自动悬停叠加</Button>
</Widget>

<HoverAction />
```

> 上述示例在 `:hover` 进入和离开时平滑 retarget；`:disabled` / `:checked` 分别读取元素同名事实。`setStyle` 可切换完整目标 class，但过渡配置仍由基础样式统一拥有。

**示例**：

}

### 9.3 boxShadow

**映射**：✅ 已映射（单层 `Style.box_shadow: Option<BoxShadowDef>`；多层 `Style.box_shadows: Option<Vec<BoxShadowDef>>`）

**语法**：`boxShadow: none | h-offset v-offset blur [spread] color [, ...]`

**取值范围**：

- `h-offset`：水平偏移（如 `2px`）
- `v-offset`：垂直偏移（如 `2px`）
- `blur`：非负有限模糊半径（如 `4px`）
- `spread`：可选扩张距离；正值向外扩张、负值向内收缩，省略时为 `0`
- `color`：阴影颜色（如 `rgba(0,0,0,0.2)`）
- 至多八层外阴影，**首项在最上层**，整组绘制于背景色/图层之前；每层独立保留偏移、spread、blur、圆角与既有 opacity/脏区语义。
- `none` 单独出现时清除全部阴影；列表作为同一属性整体替换，退出状态后恢复基础列表。`Container shadow="..."` 同样支持逗号列表，但颜色仍须具体字面量。
- 负 spread 收缩到非正面积时仅略过该层；不支持 inset、列表中混合 none、非有限值或超预算层数。
- Rust 使用 `Style::with_shadows` / `ViewExt::box_shadows` / `StyleDiff::shadows`，空列表显式清除；旧单阴影 builder 会清除多层声明。直接同时填写两个兼容字段时，多层字段优先。非法 Rust 列表诊断后不绘制，不截断为“部分成功”。

**默认值**：`none`

**适用元素**：所有元素

**示例**：

```uix
shadowEffect {
  boxShadow: 0 2px 4px 1px rgba(0,0,0,0.1), 0 8px 16px rgba(0,0,0,0.08);
}
```

### 9.4 visible

**映射**：✅ 已映射（`Style.visible: bool`）

**语法**：`visible: true | false`

**默认值**：`true`

**适用元素**：所有元素

### Text 的布局约束与裁剪

静态 `<Text>字面量</Text>` 与动态 `<Text>{表达式}</Text>` 均在父布局最终分配的内容宽度内折行，并按同一字体、字号与行高重新测量高度。嵌套 Column 无须为每层重复指定宽度；Row 的兄弟项占用空间后按最终槽位宽度重测交叉轴高度。请求宽度不能绕过父级的有限测量上限。

文本字形、选区与装饰的绘制限制在扣除 padding 后的内容框内；零内容尺寸不绘制。固定高度不足时裁剪超出部分，不缩小字号；需要完整显示时应允许自动高度或提供滚动容器。此规则不把全部容器改为 `overflow: hidden`，显式滚动、阴影及浮层仍保留各自边界。

`Label` / `label("…")` 保留既有不自动折行用途；Rust 可用 `Label::new("…").word_wrap(true)` 启用折行。单行需要省略号时使用 `<Text ellipsis>…</Text>` 或 `elided_label`，语义文本仍保存完整原文。
