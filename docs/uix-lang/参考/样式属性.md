## 1. 简介与使用方法

### 1.1 映射状态图例

每个属性条目标注其与 Rust API 的映射状态：

| 标记 | 含义 |
|---|---|
| ✅ 已映射 | Rust `Style` 或 `ViewNode` 已有对应入口（[style](../../../src/ui/theme/style/mod.rs)、[view](../../../src/ui/view/mod.rs)），语义一致 |
| 🚫 明确不支持 | 与 UIX 的 Flex/Grid 布局模型冲突，不属于目标设计；编译器提供专用诊断与替代建议 |

### 1.2 使用方法

样式属性可通过以下四种方式使用：

1. **基础样式类**：

   ```text
   styleName {
     propertyName: propertyValue;
   }
   ```

2. **标签级内联样式**（CSS 字符串形式，语法与样式类块一致）：

   ```text
   <Text style="propertyName: propertyValue;" />
   ```

3. **主题样式定义**：

   ```text
   @theme themeName {
     propertyName: propertyValue;
   }
   ```

4. **引用主题属性**（值中以 `#属性名` 引用）：

   ```text
   styleName {
     propertyName: #themeProperty;
   }
   ```

**优先级**：内联样式 > 样式类 > 主题默认值。

## 2. 布局属性

### 2.1 display

**映射**：✅ 已映射（`Style.display: DisplayMode`）

**语法**：`display: value`

**取值范围**：

- `flex`：弹性布局（默认，UIX 布局引擎主模式）
- `grid`：网格布局
- `none`：隐藏元素（不参与布局与渲染）

**默认值**：`flex`

**适用元素**：所有元素

**示例**：

```uix
flexContainer {
  display: flex;
  justifyContent: center;
}

<Container class="flexContainer">
  <Text>Flex 容器</Text>
</Container>
```

> 说明：UIX 引擎没有 `block` / `inline` / `inline-block` 模式（元素一律以弹性盒子参与布局）；块级/内联观感由 `direction`、`alignItems` 等控制。

### 2.2 flexDirection

**映射**：✅ 已映射（`Style.flex_direction: FlexDirection`）

**语法**：`flexDirection: value`

**取值范围**：

- `row`：主轴水平，从左到右
- `column`：主轴垂直，从上到下（默认）

**默认值**：`column`

**适用元素**：弹性容器

**示例**：

```uix
toolbar {
  flexDirection: row;
  gap: 8px;
}
```

### 2.3 justifyContent / alignItems

**映射**：✅ 已映射（`Style.justify_content` / `Style.align_items`）

**语法**：`justifyContent: value`、`alignItems: value`

**取值范围**：

- `justifyContent`（主轴）：`flex-start`、`flex-end`、`center`、`space-between`、`space-around`
- `alignItems`（交叉轴）：`flex-start`、`flex-end`、`center`、`stretch`（默认）

**默认值**：`justifyContent: flex-start`、`alignItems: stretch`

**适用元素**：弹性容器

**示例**：

```uix
centeredRow {
  flexDirection: row;
  justifyContent: center;
  alignItems: center;
}
```

### 2.4 gap

**映射**：✅ 已映射（`Style.gap`）

**语法**：`gap: value`

**取值范围**：长度值（如 `8px`、`12px`）

**默认值**：`0`

**适用元素**：弹性容器与网格容器

**示例**：

```uix
spacedList {
  gap: 8px;
}
```

### 2.5 flexGrow / flexShrink

**映射**：✅ 已映射（`Style.flex_grow` / `Style.flex_shrink`）

**语法**：`flexGrow: number`、`flexShrink: number`

**取值范围**：非负数字（如 `0`、`1`、`2`）

**默认值**：`flexGrow: 0`、`flexShrink: 1`

**适用元素**：弹性容器中的子元素

**示例**：

```uix
growPane {
  flexGrow: 1;
}
```

### 2.6 flexWrap

**映射**：✅ 已映射（`Style.flex_wrap: bool`）

**语法**：`flexWrap: true | false`

**默认值**：`false`

**适用元素**：弹性容器

### 2.7 alignSelf

**映射**：✅ 已映射（`Style.align_self: Option<AlignItems>`）

**语法**：`alignSelf: value`

**取值范围**：同 `alignItems`（`flex-start`、`flex-end`、`center`、`stretch`）

**默认值**：无（跟随容器 `alignItems`）

**适用元素**：弹性容器中的子元素

### 2.8 gridTemplateColumns / gridTemplateRows

**映射**：✅ 已映射（`Style.grid_template_columns` / `Style.grid_template_rows: Vec<GridTrack>`）

**语法**：`gridTemplateColumns: value`

**取值范围**：轨道列表，每个轨道为固定长度（如 `100px`）或弹性比例（如 `1fr`）

**默认值**：无（Grid 布局需显式声明轨道）

**适用元素**：`display: grid` 容器

**示例**：

```uix
twoColumnGrid {
  display: grid;
  gridTemplateColumns: 1fr 1fr;
  gap: 16px;
}
```

### 2.9 gridColumnGap / gridRowGap

**映射**：✅ 已映射（`Style.grid_column_gap` / `Style.grid_row_gap`）

**语法**：`gridColumnGap: value`、`gridRowGap: value`

**取值范围**：长度值

**默认值**：`0`

**适用元素**：网格容器

### 2.10 gridColumnSpan / gridRowSpan

**映射**：✅ 已映射（`Style.grid_column_span` / `Style.grid_row_span`）

**语法**：`gridColumnSpan: number`、`gridRowSpan: number`

**取值范围**：正整数

**默认值**：`1`

**适用元素**：网格容器中的子元素

### 2.11 position 与 top / right / bottom / left

**映射**：✅ 已映射（`ViewNode::position(PositionMode)` 与逐边 inset；`WidgetTree` 统一求解正常流、包含块、根视口、滚动裁剪、绘制和命中）

**语法**：`position: value`

**取值范围**：`static`、`relative`、`absolute`、`fixed`、`sticky`

**默认值**：`static`

**适用元素**：所有元素

**四边语法**：`top` / `right` / `bottom` / `left` 接受 `auto` 或有限 `px` 长度（可为负值），默认均为 `auto`；百分比、无单位值与 `calc()` 当前会在编译期明确拒绝。

**布局语义**：

- `static` 参与正常流并忽略四边值。
- `relative` 保留正常流槽位，只移动自身视觉、命中和子树；同轴同时声明时 `left` 优先于 `right`、`top` 优先于 `bottom`。
- `absolute` 退出正常流，相对最近的非 `static` 祖先定位；没有定位祖先时使用根客户区。左右或上下同时声明会拉伸对应 border-box 轴。
- `fixed` 退出正常流并相对根客户区定位，不继承祖先滚动与裁剪。
- `absolute` / `fixed` 的自动尺寸按自然内容测量，忽略节点自身的 Flex grow 零 basis；明确宽高与双边拉伸继续生效。内部需要内容尺寸的正常流容器使用 `column_fit` 等固有尺寸布局。
- `sticky` 保留正常流槽位，在最近滚动视口的四边约束内停靠，同时不越过直接父级边界。
- 未声明的轴使用包含块起点；状态伪类或 `setStyle` 的 `auto` 只清除当前边，不影响其他三边。

**示例**：

```uix
absoluteElement {
  position: absolute;
  top: 10px;
  right: 10px;
}
```

> `fixed` 是根视口定位，不替代具备焦点管理、关闭策略与无障碍语义的浮层组件；模态框、弹出菜单等交互表面仍应使用浮层系统。

### 2.12 z-index

**映射**：✅ 已映射（`ViewNode::z_index(i32)`；统一决定同级节点的绘制与命中顺序）

**语法**：`z-index: value`

**取值范围**：整数

**默认值**：`auto`（运行时等价为 `0`）

**适用元素**：所有元素

**示例**：

```uix
modal {
  z-index: 1000;
}
```

### 2.13 float / clear

**映射**：🚫 明确不支持（UIX 不建立 CSS 浮动格式上下文，也不增加 `Style.float` / `Style.clear` 平行布局状态）

**语法**：`float: left | right | none`、`clear: left | right | both | none`

**默认值**：`none`

**适用元素**：块级元素

> 说明：本组属性不属于目标设计。左右贴靠使用 `flexDirection: row` + `justifyContent: space-between` 或 `flexGrow`；重新开始一行使用新的 Row/Column 分组；复杂二维分区使用 Grid 轨道。编译器对规范值和非法值都返回专用诊断，不使用临时规划标记暗示未来引入第二套布局算法。

## 3. 盒模型属性

### 3.1 width / height

**映射**：✅ 已映射（`Style.width` / `Style.height: Option<f32>`）

**语法**：`width: value`、`height: value`

**取值范围**：长度值（如 `100px`、`50%`）或 `auto`

**默认值**：`auto`

**适用元素**：所有元素

**示例**：

```uix
fullWidth {
  width: 100%;
}
```

### 3.2 margin

**映射**：✅ 已映射（`Style.margin: EdgeInsets`）

**语法**：`margin: value` 或 `marginTop: value`、`marginRight: value`、`marginBottom: value`、`marginLeft: value`

**取值范围**：长度值或百分比

**默认值**：`0`

**适用元素**：所有元素

**示例**：

```uix
marginExample {
  margin: 10px 20px;
}
```

### 3.3 padding

**映射**：✅ 已映射（`Style.padding: EdgeInsets`）

**语法**：`padding: value` 或 `paddingTop: value`、`paddingRight: value`、`paddingBottom: value`、`paddingLeft: value`

**取值范围**：长度值或百分比

**默认值**：`0`

**适用元素**：所有元素

**示例**：

```uix
paddingExample {
  padding: 15px;
}
```

### 3.4 borderColor / borderWidth

**映射**：✅ 已映射（`Style.border_color` / `Style.border_width: EdgeInsets`）

**语法**：`borderColor: value`、`borderWidth: value`（四边）或 `borderTopWidth: value` 等单边形式

**取值范围**：颜色值；长度值

**默认值**：`borderColor: none`、`borderWidth: 0`

**适用元素**：所有元素

**示例**：

```uix
borderExample {
  borderColor: #ccc;
  borderWidth: 1px;
```

### 3.5 borderRadius

**映射**：✅ 已映射（`Style.border_radius: f32`）

**语法**：`borderRadius: value`

**取值范围**：长度值（如 `4px`、`8px`）

**默认值**：`0`

**适用元素**：所有元素

**示例**：

```uix
roundedCorners {
  borderRadius: 8px;
}
```

### 3.6 borderStyle

**映射**：✅ 已映射（`Style.border_style: Option<BorderStyle>`；未声明时采用 `solid`，`none` 仅关闭绘制而保留盒模型边框宽度）

**语法**：`borderStyle: none | solid | dashed | dotted | double`

**默认值**：`solid`

**适用元素**：所有元素

**绘制语义**：`dashed` 与 `dotted` 沿圆角边框完整周长保持连续相位；`double` 使用两道同色描边。

**示例**：

```uix
outlinedCard {
  borderColor: #colorBorder;
  borderWidth: 3px;
  borderStyle: dashed;
}
```

## 4. 文本属性

### 4.1 color

**映射**：✅ 已映射（`Style.color: ColorValue`）

**语法**：`color: value`

**取值范围**：颜色值（如 `#000`、`rgb(0,0,0)`、`blue`）

**默认值**：主题默认文本色

**适用元素**：文本元素

**示例**：

```uix
redText {
  color: #ff0000;
}
```

### 4.2 fontSize

**映射**：✅ 已映射（`Style.font_size: TypographyToken`，支持 token 名或像素值）

**语法**：`fontSize: value`

**取值范围**：字号 token（`small`、`body`、`large`、`xlarge`、`heading1`~`heading5`）或长度值（如 `14px`）

**默认值**：`body`

**适用元素**：文本元素

**示例**：

```uix
largeText {
  fontSize: 24px;
}

titleText {
  fontSize: heading3;
}
```

### 4.3 fontFamily

**映射**：✅ 已映射（`Style.font_family: Option<FontFamily>`；按声明顺序选择第一个已加载字体族）

**语法**：`fontFamily: value`

**取值范围**：字体名称列表（如 `Arial, sans-serif`）

**默认值**：系统默认字体

**适用元素**：文本元素

**约束**：接受逗号分隔的裸名称或单引号名称（如 `'Segoe UI', Arial, sans-serif`），显式列表会完整覆盖继承列表。名称在已加载的 `FontService` 注册表中按不区分大小写的方式依次解析；`system-ui`、`sans-serif`、`serif`、`monospace`、`cursive`、`fantasy` 使用当前系统字体，全部未命中时也回退到当前系统字体。布局、选择度量与绘制共享同一个最终字体句柄。空分量、空名称、控制字符或非法引号形态会在编译期拒绝；当前不会在绘制阶段按名称即时加载系统字体。

### 4.4 fontWeight

**映射**：✅ 已映射（`Style.font_weight: Option<FontWeight>`；显式 `normal` 可覆盖标题或 `strong` 默认字重）

**语法**：`fontWeight: value`

**取值范围**：`normal`、`bold` 或数字 `100`~`900`

**默认值**：`normal`

**适用元素**：文本元素

**约束**：关键字 `normal`、`bold` 分别对应数值 `400`、`700`；数字必须是 `100`~`900` 内的整数，非法关键字、小数、单位或越界值会在编译期拒绝。运行时保留精确数值；当前单字体面后端将 `100`~`599` 选择为常规面，将 `600`~`900` 选择为合成粗体面，布局几何保持一致。

### 4.5 textAlign

**映射**：✅ 已映射（`Style.text_align: Option<TextAlign>`；显式 `left` 可覆盖继承值）

**语法**：`textAlign: value`

**取值范围**：`left`、`right`、`center`、`justify`

**默认值**：`left`

**适用元素**：块级文本元素

**约束**：仅接受闭合取值集合；未知值会在编译期拒绝。`left`、`right`、`center` 在有限内容框内对齐；`justify` 只扩展自动换行产生的段落非末行，段落末行与显式换行前一行保持自然宽度。

### 4.6 textDecoration

**映射**：✅ 已映射（`Style.text_decoration: Option<TextDecoration>`；显式 `none` 可覆盖继承值）

**语法**：`textDecoration: value`

**取值范围**：`none`、`underline`、`overline`、`line-through`

**默认值**：`none`

**适用元素**：文本元素

**约束**：仅接受闭合取值集合；未知值会在编译期拒绝。`Label` 与 `Typography` 按最终视觉行绘制装饰，未声明时保留组件既有语义。

### 4.7 lineHeight

**映射**：✅ 已映射（`Style.line_height: Option<LineHeight>`；无单位值按最终字号倍率解析，`px` 为固定逻辑像素）

**语法**：`lineHeight: value`

**取值范围**：数字（如 `1.5`）或长度值（如 `24px`）

**默认值**：`normal`

**适用元素**：文本元素

**约束**：仅接受正有限数值；`0`、负数、百分比、未知单位与非有限值会在编译期拒绝。未声明时保持组件既有 `normal` 行高。

**示例**：

```uix
readableText {
  lineHeight: 1.5;
}

fixedLineBox {
  lineHeight: 24px;
}
```

## 5. 背景属性

### 5.1 backgroundColor

**映射**：✅ 已映射（`Style.background`，含 hover / focus / active 状态色）

**语法**：`backgroundColor: value`

**取值范围**：颜色值（如 `#fff`、`rgb(255,255,255)`、`transparent`）

**默认值**：`transparent`

**适用元素**：所有元素

**示例**：

```uix
whiteBackground {
  backgroundColor: #ffffff;
}
```

> 状态色：`backgroundColor:hover` / `backgroundColor:focus` / `backgroundColor:active` 形式声明交互状态背景（对应 `Style.background_hover` 等字段）。

### 5.2 backgroundImage

**映射**：✅ 已映射（`Style.background_image: Option<BackgroundImage>`；`none`、本地图片、固定方向双色线性/径向渐变）

**语法**：`backgroundImage: none | url('local/path.png') | linear-gradient(color, color) | radial-gradient(color, color)`

**取值范围与边界**：

- `url()` 路径必须使用单引号或双引号包裹，只接受本地文件路径；空路径、网络 URL、`data:` URI 和多背景层在编译期拒绝。
- 渐变必须恰好包含两个颜色，颜色可使用普通颜色值或已登记颜色 token；首批不支持角度、色标位置、三个以上端点或多层。
- 线性渐变固定从上到下，径向渐变固定从盒中心覆盖到最远角；两者填满背景盒并忽略 `backgroundPosition` / `backgroundRepeat`。
- 本地图片保持固有像素尺寸并复用 `ImageService` 路径缓存；加载失败时只保留背景色，不产生半成品图层。
- 绘制顺序为背景色 → 背景图/渐变 → 边框，`opacity` 统一作用于三个表面图层。

**默认值**：`none`

**适用元素**：所有元素

**示例**：

```uix
hero {
  backgroundColor: #101820;
  backgroundImage: url('assets/hero.png');
  backgroundPosition: center;
  backgroundRepeat: no-repeat;
}

hero:hover {
  backgroundImage: linear-gradient(#colorPrimary, rgba(0,0,0,0.5));
}
```

### 5.3 backgroundPosition

**映射**：✅ 已映射（`Style.background_position: Option<BackgroundPosition>`；百分比按背景盒与图片的剩余空间解析）

**语法**：`backgroundPosition: value` 或 `backgroundPosition: x y`

**取值范围**：

- 轴关键字：`left`、`right`、`top`、`bottom`、`center`；两个轴关键字可写为 `top left` 或 `left top`。
- 有限 `px` 长度，允许负值；两个数值严格按 `x y` 顺序。
- `0%` 到 `100%`；`0%` 对齐起点，`100%` 对齐终点，比例作用于背景盒尺寸减图片固有尺寸后的剩余空间。
- 单个水平/垂直关键字补齐另一轴为 `center`；单个数值解释为水平轴并把垂直轴补齐为 `center`。
- 首批不接受关键词与数值混写、无单位长度、越界百分比、`calc()` 或三项以上语法。

**默认值**：`0% 0%`

**适用元素**：所有元素

### 5.4 backgroundRepeat

**映射**：✅ 已映射（`Style.background_repeat: Option<BackgroundRepeat>`；图片按固有尺寸平铺并裁剪到矩形背景盒）

**语法**：`backgroundRepeat: value`

**取值范围**：`repeat`、`repeat-x`、`repeat-y`、`no-repeat`

**默认值**：`repeat`

**适用元素**：所有元素

## 6. 动画与过渡

> `animation` 与 `transition` 均已接入既有逐窗动画调度；Rust 侧 `Animated<T>`、Spring 和动画组用法见[动画](../../使用/动画与异步/动画.md)。

### 6.1 animation

**映射**：✅ `@keyframes` → 组件私有 `Animated<T>` + 逐窗帧调度

**语法**：`animation: name duration timing-function delay iteration-count direction fill-mode`

**取值范围**：

- `name`：动画名称
- `duration`：有限非负时间，支持 `s`、`ms`（如 `1s`、`250ms`）
- `timing-function`：`linear`、`ease`、`ease-in`、`ease-out`、`ease-in-out`
- `delay`：有限非负时间，支持 `s`、`ms`
- `iteration-count`：非负整数或 `infinite`
- `direction`：`normal`、`reverse`、`alternate`、`alternate-reverse`
- `fill-mode`：`none`、`forwards`、`backwards`、`both`

**默认值**：`none 0s ease 0s 1 normal none`

**适用元素**：所有元素

**首批可动画属性**：`width`、`height`、`borderRadius`、`opacity`、`color`、`backgroundColor`

- `@keyframes` 选择器支持 `from`、`to` 和 `0%`～`100%`；同一偏移或同名声明会在编译期拒绝。
- `width` / `height` 只接受有限非负 `px` 或无单位数值，不接受 `auto`、百分比；颜色使用十六进制、`rgb` 或 `rgba` 具体值，不接受主题 token 插值。
- 动画状态按文档根或 `Widget` 私有作用域持久化；`For` 中各实例按实际路径隔离，同一节点 reconcile 不会重启动画。
- `animation` 只能用于基础样式类或静态内联样式。`:hover` / `:disabled` / `:checked` 和 `setStyle` 中启动动画会返回编译期诊断；状态变化的平滑插值由 `transition` 契约负责。

**示例**：

```uix
fadeIn {
  opacity: 0;
  animation: fade 1s ease-in-out 100ms 2 alternate both;
}

@keyframes fade {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}

<Text class="fadeIn">声明式淡入</Text>
```

### 6.2 transition

**映射**：✅ 最终样式目标 → 组件私有 `Animated<T>` 原位 retarget + 逐窗帧调度

**语法**：`transition: property duration timing-function delay`

**取值范围**：

- `property`：`all`、`width`、`height`、`borderRadius`、`opacity`、`color`、`backgroundColor`
- `duration`：有限非负时间，支持 `s`、`ms`
- `timing-function`：`linear`、`ease`、`ease-in`、`ease-out`、`ease-in-out`
- `delay`：有限非负时间，支持 `s`、`ms`

**默认值**：`all 0s ease 0s`

**适用元素**：所有元素

- 首次挂载直接静止在最终样式，不播放入场；同一文档或 `Widget` 作用域、`For` 实例路径和最终 View key 下，目标变化会复用同一 `Animated<T>` 并原位 retarget。
- `all` 只收集首批矩阵中实际参与该节点状态变化的字段；基础静态样式、`:hover` / `:disabled` / `:checked` 差异层和 `setStyle` 完整分支均可提供目标。
- `width` / `height` 必须在基础样式和每个 `setStyle` 完整分支中提供有限非负固定值；颜色必须是十六进制、`rgb` 或 `rgba` 具体值。主题 token、`auto`、百分比和缺失的完整分支目标会在编译期拒绝。
- `transition` 配置只能位于基础样式类或静态内联样式；状态分支不得改变配置。同一节点同时声明 `animation` 与 `transition` 会因争用播放生命周期而在编译期拒绝。

**示例**：

```uix
normalAction {
  padding: 6px 12px;
  backgroundColor: #ffffff;
  transition: backgroundColor 200ms ease-out;
}

normalAction:hover {
  backgroundColor: #e6f4ff;
}

<Widget name="HoverAction">
  <Button class="normalAction">自动悬停叠加</Button>
</Widget>

<HoverAction />
```

> 上述示例在 `:hover` 进入和离开时平滑 retarget；`:disabled` / `:checked` 分别读取元素同名事实。`setStyle` 可切换完整目标 class，但过渡配置仍由基础样式统一拥有。

## 7. 变换属性

### 7.1 transform

**映射**：✅ 已映射（`ViewNode::affine_transform(Transform)`；默认围绕布局帧中心，同一矩阵用于绘制、包围盒与命中逆变换）

**语法**：`transform: value`

**取值范围**：变换函数（`translate()`、`rotate()`、`scale()`、`skew()`）

> `translate()` 接受 px 或无单位固定数值；`rotate()` / `skew()` 接受 `deg`、`rad`、`turn`；`scale()` 接受无单位数值。函数可按源码顺序组合。百分比平移及不可逆矩阵会在编译期明确拒绝；自定义原点由已映射的 `transformOrigin` 属性提供。

**默认值**：`none`

**适用元素**：所有元素

**示例**：

```uix
rotatedElement {
  transform: rotate(45deg);
}
```

### 7.2 transformOrigin

**映射**：✅ 已映射（`ViewNode::transform_origin(TransformOrigin)`；比例与像素值在布局帧确定后解析）

**语法**：`transformOrigin: value`

**取值范围**：长度值或关键字（如 `center`、`top left`）

> 支持 `left` / `right` / `top` / `bottom` / `center`、百分比、px 与无单位固定值；一到两个分量按 CSS 轴语义解析。兼容默认形式的第三个 Z 轴分量，但二维运行时只接受 `0` / `0px`，非零深度会在编译期明确拒绝。

**默认值**：`50% 50% 0`

**适用元素**：所有元素


### 8.2 userSelect

**映射**：✅ 已映射（`ViewNode::user_select(UserSelect)`；`WidgetTree` 解析继承后的实际策略并同步到 `Label`、`Typography` 与 `RichText`）

**语法**：`userSelect: value`

**取值范围**：`auto`、`none`、`text`、`all`

**默认值**：`auto`

**适用元素**：所有元素

> `repeat-x` 只沿水平轴平铺，`repeat-y` 只沿垂直轴平铺，`no-repeat` 只绘制定位产生的一张图片。渐变始终填满背景盒，不进入平铺算法。

**继承与边界**：

- `auto` 保留组件默认能力；`Label` / `RichText` 仍由各自 builder 的 `selectable` 决定，`Typography` 默认可选。
- 祖先 `none` 禁止后代普通拖选、`Ctrl+A` 和普通复制，并清理既有选择；链接、代码复制按钮等非文字选择交互不受影响。
- `text` 为支持文字范围的后代启用选择，但不能覆盖更高祖先的 `none` 或 `all` 边界。
- `all` 选择最近的显式 `all` 子树，并按文档顺序聚合其中可选择文字；嵌套后代不能越过祖先的 `all` 或 `none` 边界。

**示例**：

```uix
selectableCard {
  userSelect: all;
}

<Container class="selectableCard">
  <Text>标题</Text>
  <Typography>正文</Typography>
</Container>
```

**适用元素**：所有元素
