# 反馈组件

[← 返回 UIX Lang 索引](../README.md)

> **接口**：声明 UIX Lang 内置反馈组件——消息与通知（Message / Notification / Alert）、浮层（Modal / Drawer / Popover / Popconfirm / Tooltip / FocusTrap）、进度与加载（ProgressBar / Spin / Skeleton）、浮动操作（FloatButtonGroup / FloatButtonBackTop）。依赖：[标签语法](../标签语法.md)、[样式属性参考](../UIX%20样式属性参考.md)。
>
> **状态声明**：公开 `uix!` 转换器已经可用，但本页组件尚未进入已登记生成矩阵，使用时会得到明确编译错误；这里记录目标设计。Rust 内置能力的权威清单见[组件速查](../../使用/组件速查.md)。

## 1. 消息与通知

### Message 全局提示

轻量级操作反馈队列，顶部居中短时出现后消失。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `type` | 关键字 | `info` | `info` / `success` / `warning` / `error` |
| `content` | 字符串 | — | 提示内容 |
| `duration` | 数字 | `3` | 显示秒数 |

```uix
<Message type="success" content="保存成功" duration={2} />
```

### Notification 通知提醒

右上角弹出式消息队列，支持标题与操作。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `title` | 字符串 | — | 标题 |
| `content` | 字符串 | — | 内容 |
| `type` | 关键字 | `info` | 同上 |
| `duration` | 数字 | `4.5` | 显示秒数 |

### Alert 警告提示

可关闭的状态消息条，常内嵌于页面。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `type` | 关键字 | `info` | `info` / `success` / `warning` / `error` |
| `message` | 字符串 | — | 提示文字 |
| `closable` | 布尔 | `false` | 可关闭 |
| `@close` | 事件 | — | 关闭事件 |

```uix
<Alert type="warning" message="磁盘空间不足" closable />
```

## 2. 浮层

### Modal 模态对话框

焦点陷阱 + 遮罩，阻塞背景交互。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `open` | 绑定 | `false` | 显隐 |
| `title` | 字符串 | — | 标题 |
| `maskClosable` | 布尔 | `true` | 点击遮罩关闭 |
| `footerVisible` | 布尔 | `true` | 底部按钮区显隐（对应 Rust `footer_visible`） |
| `@ok` / `@cancel` | 事件 | — | 确认 / 取消 |

```uix
<Modal open={confirmOpen} title="确认删除" @ok="doDelete" @cancel="closeConfirm">
  <Text>删除后不可恢复，确定继续？</Text>
</Modal>
```

### Drawer 抽屉

从屏幕边缘滑出的浮层面板。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `open` | 绑定 | `false` | 显隐 |
| `placement` | 关键字 | `right` | `left` / `right` / `top` / `bottom` |
| `width` | 长度 | — | 面板宽度 |

### Popover / Popconfirm / Tooltip

轻量浮层三件套，点击或悬停触发：

| 组件 | 说明 |
|---|---|
| `Popover` | 气泡卡片，`content` 声明内容，`trigger`（`click` / `hover`）声明触发方式 |
| `Popconfirm` | 气泡确认框，带确认 / 取消操作，`@confirm` / `@cancel` 事件 |
| `Tooltip` | 文字提示，`text` 声明提示文字 |

```uix
<Tooltip text="更多操作">
  <Button>悬停</Button>
</Tooltip>
<Popconfirm title="确定删除？" @confirm="doDelete">
  <Button type="danger">删除</Button>
</Popconfirm>
```

### FocusTrap 焦点陷阱

Tab 键在子树内循环，模态场景的焦点管理原语。

```uix
<FocusTrap>
  <Input value={search} />
  <Button>搜索</Button>
</FocusTrap>
```

## 3. 进度与加载

### ProgressBar 进度条

确定 / 不确定 / 圆形三种形态。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `percent` | 数字 0~100 | `0` | 进度 |
| `status` | 关键字 | — | `success` / `error` / `active` |
| `type` | 关键字 | `line` | `line` / `circle` |

```uix
<ProgressBar percent={uploadPercent} status="active" />
```

### Spin 加载中

旋转指示器，可包裹内容（内容加载期间遮罩）。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `spinning` | 绑定 | `true` | 是否旋转 |
| `text` | 字符串 | — | 提示文字 |

```uix
<Spin spinning={loading}>
  <Table data={rows} />
</Spin>
```

## 4. 浮动操作

### FloatButtonGroup 浮动按钮组

一组浮动按钮，展开后子按钮可命中；`trigger`（`click` / `hover`）声明展开方式。

### FloatButtonBackTop 回到顶部浮动按钮

`scrollY` 超过阈值后显示，点击回到顶部。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `threshold` | 数字 | `400` | 显示阈值 |
| `scrollY` | 数字 | — | 当前滚动位置（双向绑定） |
