# 输入组件

[← 返回 UIX Lang 索引](../README.md)

> **接口**：声明 UIX Lang 内置输入组件——文本与数值输入、选择器、开关与勾选、日期时间与颜色、表单容器。依赖：[标签语法](../标签语法.md)、[样式属性参考](../UIX%20样式属性参考.md)。
>
> **状态声明**：公开 `uix!` 已映射 `Input`、`InputNumber`、`InputGroup`、`Slider`、`RangeSlider`、`Rate` 与 `Checkbox`；本页其余组件仍会得到明确的规划中编译错误。Rust 内置能力的权威清单见[组件速查](../../使用/组件速查.md)。

## 1. 文本与数值输入

### Input 文本输入

**映射**：✅ 已映射。`value` 必须是 `State<String>` 表达式；`@change` 可用裸零参数处理器，或通过 `$event` 接收当前 `&str` 文本载荷。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | 绑定 | — | 文本值（双向绑定） |
| `placeholder` | 字符串 | — | 占位提示 |
| `type` | 关键字 | `text` | `text` / `textarea` / `password` |
| `disabled` | 布尔 | `false` | 禁用 |
| `@change` | 事件 | — | 值变化事件 |

```uix
<Input value={name} placeholder="请输入名称" @change="onNameChange" />
<Input type="password" placeholder="密码" />
```

### InputNumber 数值输入

**映射**：✅ 已映射。`value` 接受实现 `InputNumberValue` 的 `State<T>`；`min`、`max`、`step` 使用 `f64`，`precision` 使用 `u8` 并在运行时归一化到 `0..=15`。字面量会在编译期拒绝反向范围、非正步长和越界精度。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | 绑定 | — | 数值（双向绑定） |
| `min` / `max` | 数字 | — | 取值边界 |
| `step` | 数字 | `1` | 步进 |
| `precision` | 整数 | — | 小数精度 |

### InputGroup 复合输入

**映射**：✅ 已映射。`value` 必须是 `State<String>` 表达式；`addonBefore` 与 `addonAfter` 接受字符串字面量或 `String` 表达式，并与内部 `Input` 共享绘制、命中和双向绑定。

前缀 / 后缀**文本**组合（对应 Rust `addon_before` / `addon_after`）：

```uix
<InputGroup addonBefore="¥" value={amount} addonAfter="元" />
```

### Slider / RangeSlider 滑块

**映射**：✅ 已映射。单值 `Slider` 的 `value` 必须是 `State<f64>` 表达式；`RangeSlider` 使用 `value={{ start: lower, end: upper }}` 分别绑定两个 `State<f64>`。两者的 `min`、`max` 与 `step` 均接受有限数值字面量或 `f64` 表达式。

```uix
<RangeSlider value={{ start: priceMin, end: priceMax }} min="0" max="100" step="5" />
```

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | 绑定 | — | 数值或 `{ start, end }` 区间 |
| `min` / `max` | 数字 | `0` / `100` | 范围 |
| `step` | 数字 | `1` | 步进 |

### Rate 评分

**映射**：✅ 已映射。`value` 必须是 `State<u32>` 表达式；`count` 接受 `usize` 整数或表达式；`allowHalf` 接受布尔简写、布尔字面量或表达式。启用半星后，状态中的一个单位表示半星，例如值 `7` 表示三点五星。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | 绑定 | — | 评分值 |
| `count` | 整数 | `5` | 星数 |
| `allowHalf` | 布尔 | `false` | 半星 |

## 2. 开关与勾选

### Checkbox / Switch

均绑定 `State<bool>`。

**映射**：`Checkbox` ✅ 已映射，`checked` 必须是 `State<bool>` 表达式，`disabled` 接受布尔简写、字面量或表达式，`text` 接受字符串字面量或 `String` 表达式；`Switch` 🕒 规划中。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `checked` | 绑定 | `false` | 选中态 |
| `disabled` | 布尔 | `false` | 禁用 |
| `text` | 字符串 | — | 勾选旁说明文字（Checkbox） |

### Radio 单选按钮组

一组互斥选项，绑定 `State<String>`；选项由 `options` 数组提供（数据引用）。

```uix
<Radio value={gender} options={genderOptions} />
```

### Segmented 分段控制器

互斥选项平铺展示，适合少量固定选项；选项由 `options` 数组提供。

```uix
<Segmented value={view} options={viewOptions} />
```

## 3. 选择器

### Select 下拉选择器

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | 绑定 | — | 选中值（支持多选数组） |
| `multiple` | 布尔 | `false` | 多选 |
| `searchable` | 布尔 | `false` | 可搜索 |
| `placeholder` | 字符串 | — | 占位提示 |
| `options` | 数组 | — | `[{ label, value }]` 选项 |

```uix
<Select value={city} options={cityOptions} searchable />
```

### Cascader 级联选择器

多层级选项逐列展开。

| 属性 | 类型 | 说明 |
|---|---|---|
| `options` | 数组 | 层级选项树 |
| `value` | 绑定 | 选中路径数组 |

### TreeSelect 树形选择器

扁平化展示树节点供选取，语义同 `Tree` 的数据结构。

### AutoComplete / Mentions

- `AutoComplete`：输入时过滤并弹出候选列表，`options` 声明候选。
- `Mentions`：`@` 提及输入，按光标位置触发建议弹层，`suggestions` 声明建议。

## 4. 日期时间与颜色

| 组件 | 属性 | 说明 |
|---|---|---|
| `DatePicker` | `value`、`mode`（`date` / `week` / `month` / `quarter`） | 日期选择 |
| `DateRangePicker` | `value`（`{ start, end }`） | 起止日期联动 |
| `TimePicker` | `value` | 小时与分钟分列滚动 |
| `ColorPicker` | `value` | 24 色预设色板 |

## 5. 表单容器

### Form 表单

表单容器，字段绑定、校验与联动；字段使用类型化绑定项（`FormInputItem`、`FormSelectItem`、`FormCheckboxItem` 等），与 `model` 配合。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `model` | 绑定 | — | 表单数据模型 |
| `rules` | 数组 | — | 校验规则 |
| `@submit` | 事件 | — | 提交事件 |

```uix
<Form model={userForm} @submit="onSubmit">
  <FormInputItem field="name" label="姓名" />
  <FormInputItem field="email" label="邮箱" rules="required,email" />
  <Button type="primary" @click="submitForm">提交</Button>
</Form>
```

### Upload 文件上传

文件上传队列，管理文件列表与进度。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `files` | 绑定 | — | 文件列表 |
| `accept` | 字符串 | — | 接受的文件类型 |
| `multiple` | 布尔 | `false` | 多文件 |
| `action` | 字符串 | — | 上传目标地址 |
