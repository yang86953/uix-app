# 通用组件

[← 返回 UIX Lang 索引](../README.md)

> **接口**：声明 UIX Lang 内置通用组件——Button、Icon、Label、FloatButton、Typography、Divider、Space、ThemeToggle、ButtonGroup、WindowControl。依赖：[标签语法](../标签语法.md)、[样式属性参考](../UIX%20样式属性参考.md)。
>
> **状态声明**：公开 `uix!` 当前已登记并生成 `Button`、`ButtonGroup`、`Icon`、`Label`、`Divider`、`Space`、`Typography`、`ThemeToggle` 与 `WindowControl`；本页其余组件仍是目标设计，使用时会得到带“通用组件”类别的明确编译错误。Rust 内置能力的权威清单见[组件速查](../../使用/组件速查.md)。

## 1. Button 按钮

触发操作的按钮；`type` 声明语义样式，`class` / `style` 叠加自定义外观。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `type` | 关键字 | `default` | 语义样式：`default` / `primary` / `danger` / `ghost` |
| `disabled` | 布尔 | `false` | 禁用 |
| `size` | 关键字 | `middle` | 尺寸：`small` / `middle` / `large` |
| `loading` | 布尔 | `false` | 加载态（显示旋转指示并禁用点击） |
| `@click` | 事件 | — | 点击事件绑定 |

```uix
<Button type="primary" @click="submit">提交</Button>
<Button type="danger" disabled>删除</Button>
<Button @click="handleClick" class="baseButton">自定义样式</Button>
```

## 2. Icon 图标

按名称渲染单个 Lucide 字形；**应用可见图标必须使用本组件**，不得用 Unicode / ASCII 符号或普通文本代替。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `name` | 字符串 | — | 图标名称（Lucide 图标集） |
| `size` | 长度 | 继承 | 字形尺寸 |
| `color` | 颜色 | 继承 | 字形颜色 |

```uix
<Icon name="star" size="16px" color="#FF5722" />
<Button><Icon name="plus" /> 新建</Button>
```

## 3. Label 文本标签

短文本标签，支持多行与文本选择（对应 Rust `label`，是最基础的文本原语）。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `selectable` | 布尔 | `false` | 允许文本选择 |
| `fontSize` | token / 长度 | `body` | 字号（见[样式参考 fontSize](../UIX%20样式属性参考.md#42-fontsize)） |
| `color` | 颜色 | 主题默认 | 文字颜色 |

```uix
<Label>普通文本</Label>
<Label selectable fontSize="heading3">可选中的标题文本</Label>
```

## 4. FloatButton 浮动操作按钮

悬浮在页面角落的操作按钮，可带 tooltip、badge 与自定义定位。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `icon` | 图标名 | — | 按钮图标 |
| `description` | 字符串 | — | 展开说明文字 |
| `position` | 关键字 | `rightBottom` | 定位：`leftTop` / `leftBottom` / `rightTop` / `rightBottom` |
| `tooltip` | 字符串 | — | 悬停提示文字 |
| `badge` | 对象 | — | 徽标配置 `{ count, dot }` |
| `@click` | 事件 | — | 点击事件绑定 |

```uix
<FloatButton icon="message" tooltip="意见反馈" @click="openFeedback" />
```

## 5. Typography 排版

标题、段落、标记、下划线等排版语义文本；文本可复制。

`Typography` 已进入公开 `uix!` 生成矩阵：内容只接受文本与插值，`level` 接受 1~5 字面量或 `u8` 受限表达式，`type` 必须是确定的语义色字面量，`mark`、`underline` 与 `copyable` 接受布尔字面量或受限表达式；语义色在绘制阶段通过当前主题令牌解析。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `level` | 整数 1~5 | — | 标题层级（对应 heading1~heading5 字号） |
| `type` | 关键字 | — | `secondary` / `success` / `warning` / `danger` 语义色 |
| `mark` | 布尔 | `false` | 标记高亮 |
| `underline` | 布尔 | `false` | 下划线 |
| `copyable` | 布尔 | `false` | 显示复制按钮 |

```uix
<Typography level={1}>一级标题</Typography>
<Typography type="danger" mark>删除标记</Typography>
```

## 6. Divider 分割线

分隔内容区块；可带标签文字，可切换虚线。

`Divider` 已进入公开 `uix!` 生成矩阵：标签保持叶子形状，`text` 接受字符串字面量或受限字符串表达式，`dashed` 接受布尔值，`direction` 必须是确定的 `horizontal` / `vertical` 字面量。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `text` | 字符串 | — | 分割线标签文字 |
| `dashed` | 布尔 | `false` | 虚线样式 |
| `direction` | 关键字 | `horizontal` | `horizontal` / `vertical` |

```uix
<Divider text="更多信息" />
```

## 7. Space 弹性间距容器

为子节点提供统一间距，是轻量布局原语（对应 Rust `Space`）。

`Space` 已进入公开 `uix!` 生成矩阵：子节点按源码顺序生成，`direction` 必须是确定的 `horizontal` / `vertical` 字面量，`gap` 接受有限数值、`px` 字面量或受限数值表达式，`wrap` 接受布尔字面量或受限布尔表达式。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `direction` | 关键字 | `horizontal` | 排列方向 |
| `gap` | 长度 | `8px` | 子节点间距 |
| `wrap` | 布尔 | `false` | 超出换行 |

```uix
<Space gap="12px">
  <Button>保存</Button>
  <Button type="ghost">取消</Button>
</Space>
```

## 8. ThemeToggle 主题切换按钮

内置亮色 / 暗色主题切换开关，等价于 `@theme` 切换的快捷控件。

`ThemeToggle` 已进入公开 `uix!` 生成矩阵：标签保持无专有属性的叶子形状，复用现有 `ThemeToggle::new()` 组件；实际主题状态继续由 Provider / 应用配置持有。

```uix
<ThemeToggle />
```

## 9. ButtonGroup 按钮组

同组按钮共享间距与语义样式，视觉上作为整体。

`ButtonGroup` 已进入公开 `uix!` 生成矩阵：只接受保持源码顺序的直接 `Button` 子元素；单项使用 `Single`，多项自动分配 `Left` / `Middle` / `Right` 连体位置。子按钮继续支持 `type`、`disabled`、`block`、`@click`、文本插值与公共样式；动态 `If` / `For` 子树请使用 `Row`，避免运行期数量让静态连体位置失真。

```uix
<ButtonGroup>
  <Button>左</Button>
  <Button>中</Button>
  <Button>右</Button>
</ButtonGroup>
```

## 10. WindowControl 窗口控制

最小化 / 最大化 / 关闭按钮，用于自定义标题栏（对应 Rust `window_chrome` 能力）。

`WindowControl` 已进入公开 `uix!` 生成矩阵：三个显示属性接受布尔字面量或受限布尔表达式，默认均为 `true`；标签生成公开 `window_controls` 组合，由运行时 `window_chrome` 模块继续拥有窗口动作、无障碍语义与默认外观。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `showMinimize` | 布尔 | `true` | 显示最小化 |
| `showMaximize` | 布尔 | `true` | 显示最大化 |
| `showClose` | 布尔 | `true` | 显示关闭 |

```uix
<Container direction="row">
  <WindowControl />
</Container>
```
