# 展示组件

[← 返回 UIX Lang 索引](../README.md)

> **接口**：声明 UIX Lang 内置展示组件——基础展示（Avatar / Badge / Tag / Card / Descriptions / Skeleton / Empty / ResultView）、数据展示（List / Tree / Table / DataTable / Timeline / Collapse / Calendar / Carousel）、媒体与特殊展示（Image / QRCode / Watermark / RichText）。依赖：[标签语法](../标签语法.md)、[样式属性参考](../UIX%20样式属性参考.md)。
>
> **状态声明**：公开 `uix!` 转换器已经可用；本页 `Skeleton`、`Empty`、`ResultView`、`Tag`、`Card`、`Descriptions` 已进入生成矩阵，其余组件使用时仍会得到明确编译错误。Rust 内置能力的权威清单见[组件速查](../../使用/组件速查.md)。

## 1. 基础展示

### Avatar 头像

图片、文字首字母与方形裁剪。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `src` | 字符串 | — | 图片地址 |
| `text` | 字符串 | — | 文字首字母（无图时） |
| `shape` | 关键字 | `circle` | `circle` / `square` |
| `size` | 长度 | — | 边长 |

### Badge 徽标

数字角标、状态圆点或文字标签，常挂载在图标 / 头像角上。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `count` | 整数 | — | 数字角标（`0` 隐藏，`>99` 显示 99+） |
| `dot` | 布尔 | `false` | 状态圆点 |
| `text` | 字符串 | — | 文字标签 |

```uix
<Badge count={5}>
  <Icon name="bell" />
</Badge>
```

### Tag 标签

可勾选、可关闭、多彩色。

> **当前映射**：已实现。标签正文使用文本与插值子节点；`color` 接受已登记关键字、十六进制字面量或 `Color` 表达式；`closable` / `checkable` 接受布尔值。嵌套元素不受支持。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `color` | 颜色 / 关键字 | — | 标签色 |
| `closable` | 布尔 | `false` | 可关闭 |
| `checkable` | 布尔 | `false` | 可勾选 |

### Card 卡片容器

内置标题与操作项。

> **当前映射**：已实现。`title` 接受字符串字面量或字符串表达式；`actions` 只接受操作项数组表达式，并由 Rust 核对元素类型；直接子节点按源码顺序生成完整 `ViewNode` 子树，支持核心条件与循环控制节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `title` | 字符串 | — | 标题 |
| `actions` | 数组引用 | — | 操作项字符串列表（对应 Rust `actions`） |

```uix
<Card title="用户信息" actions={cardActions}>
  <Text>姓名：张三</Text>
</Card>
```

### Descriptions 描述列表

多列键值对展示。

> **当前映射**：已实现。`data` 必须是拥有所有权、可迭代且元素为公开 `DescriptionsItem` 的 Rust 表达式，数组与 `Vec` 均可；普通 UIX 表达式当前不接受内联对象数组。`columns` 接受大于零的整数字面量或 `usize` 表达式，缺省时显式使用文档默认的一列。`Descriptions` 是叶组件，不接受子节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | `DescriptionsItem` 可迭代表达式 | — | 类型化键值项集合 |
| `columns` | 正整数 / `usize` 表达式 | `1` | 列数 |

### Skeleton 骨架屏

加载占位，矩形 / 圆形 / 文字形态。

> **当前映射**：已实现。`shape` 只接受静态关键字；`width` / `height` 接受有限数值、`px` 字面量或 `f32` 表达式。`Skeleton` 是叶组件，不接受子节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `shape` | 关键字 | `rect` | `rect` / `circle` / `text` |
| `width` / `height` | 长度 | — | 占位尺寸 |

### Empty 空状态

列表无数据时的占位。

> **当前映射**：已实现。`description` / `icon` 接受字符串字面量或字符串表达式；`Empty` 是叶组件，不接受子节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `description` | 字符串 | — | 描述文字 |
| `icon` | 图标名 | — | 自定义图标 |

### ResultView 结果页

success / error / 404 等预设状态页。

> **当前映射**：已实现。`status` 只接受静态关键字；`title` / `extraText` 接受字符串字面量或字符串表达式。`ResultView` 是叶组件，不接受子节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `status` | 关键字 | `success` | `success` / `error` / `info` / `warning` / `404` |
| `title` | 字符串 | — | 标题 |
| `extraText` | 字符串 | — | 辅助文字（对应 Rust `extra_text`） |

## 2. 数据展示

### List 列表

含 header / footer 与 load-more。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | 数组 | — | 数据源 |
| `header` / `footer` | 节点 | — | 首尾区域 |
| `loadMore` | 节点 | — | 加载更多按钮 |

### SelectableList 可选中列表

键盘导航与 active 高亮。

### Tree 树形控件

展开 / 折叠与勾选。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | 数组 | — | 树节点数据 |
| `checkable` | 布尔 | `false` | 节点勾选 |
| `defaultExpandAll` | 布尔 | `false` | 默认全展开 |

### Table 数据表格

排序、选择、固定列与虚拟滚动。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | 数组 | — | 行数据 |
| `columns` | 数组 | — | 列定义 `[{ key, title, width, sortable }]` |
| `rowSelection` | 对象 | — | 行选择配置 |
| `virtual` | 布尔 | `false` | 虚拟滚动（大数据量） |

```uix
<Table data={users} columns={userColumns} />
```

### DataTable 泛型数据表格

任意行类型 + 列绑定渲染（对应 Rust `DataTable`）。

### Timeline 时间轴

含 pending 与 reverse。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `items` | 数组引用 | — | `[{ title, description, color }]`（数据引用） |
| `pending` | 布尔 | `false` | 末尾 pending 节点 |

### Collapse 折叠面板

支持手风琴模式。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `accordion` | 布尔 | `false` | 手风琴（同时只开一个） |
| `activeKeys` | 绑定 | — | 展开面板集合 |

### Calendar / Carousel

- `Calendar`：日历面板，日期选择与月视图导航。
- `Carousel`：走马灯，幻灯片轮播；子节点为各页内容，`autoplay` 声明自动播放。

## 3. 媒体与特殊展示

### Image / ImageGroup

- `Image`：图片组件，点击预览、圆角与加载回退；`src` / `radius` / `fallback`。
- `ImageGroup`：图片组画廊，缩略图与全屏预览。

### QRCode 二维码

标准 QR 编码与纠错等级。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | 字符串 | — | 编码内容 |
| `size` | 长度 | `128px` | 尺寸 |
| `errorLevel` | 关键字 | `M` | 纠错等级 `L` / `M` / `Q` / `H` |

### Watermark 水印

平铺文字覆盖内容区。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `text` | 字符串 | — | 水印文字 |
| `opacity` | 数字 | — | 透明度 |

### RichText 富文本

文本、链接与代码段混合排版。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `content` | 字符串 | — | 富文本内容（行内标记语法） |
| `selectable` | 布尔 | `false` | 可选中 |

```uix
<RichText content="支持 **加粗**、`代码` 与 [链接](https://example.com)" />
```
