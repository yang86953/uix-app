# 展示组件

[← 返回 UIX Lang 索引](../README.md)

> **接口**：声明 UIX Lang 内置展示组件——基础展示（Avatar / Badge / Tag / Card / Descriptions / Skeleton / Empty / ResultView）、数据展示（List / Tree / Table / DataTable / Timeline / Collapse / Calendar / Carousel）、媒体与特殊展示（Image / QRCode / Watermark / RichText）。依赖：[标签语法](../标签语法.md)、[样式属性参考](../UIX%20样式属性参考.md)。
>
> **状态声明**：公开 `uix!` 转换器已经可用；本页 `Avatar`、`Image`、`ImageGroup`、`List`、`Skeleton`、`Empty`、`ResultView`、`Tag`、`Card`、`Descriptions`、`Timeline`、`Calendar`、`Carousel`、`Tree`、`Table`、`QRCode`、`Watermark`、`RichText` 已进入生成矩阵，其余组件使用时仍会得到明确编译错误。Rust 内置能力的权威清单见[组件速查](../../使用/组件速查.md)。

## 1. 基础展示

### Avatar 头像

图片、文字首字母与方形裁剪。

> **当前映射**：已实现。`text` 与 `src` 接受字符串字面量或字符串表达式；图片加载成功时优先显示图片，否则显示 `text`。`shape` 只接受 `circle` / `square`，缺省为 `circle`；`size` 接受正的十进制、`px` 字面量或 `f32` 表达式，缺省保留运行时 `32px`。`Avatar` 是叶组件，不接受子节点；使用 `src` 时要求启用默认包含的 `image-codecs` capability，纯文字头像不依赖该 capability。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `src` | 字符串 | — | 图片地址 |
| `text` | 字符串 | — | 文字首字母（无图时） |
| `shape` | 关键字 | `circle` | `circle` / `square` |
| `size` | 长度 | `32px` | 边长 |

### Badge 徽标

数字角标、状态圆点或文字标签，常挂载在图标 / 头像角上。

> **当前映射**：规划中。`Badge` 的目标运行时契约是可选单 child 的透明装饰器：零 child 保留现有叶组件行为；一个 child 时由 child 决定正常流尺寸，角标在 children 之后锚定其右上角绘制且不扩大布局占位。装饰不参与命中或焦点，事件、状态与 reconcile 身份完整归 child。UIX 接受零或一个逻辑直接 child；多个 child 必须先用 `Container` / `Row` 包成单根，否则编译失败。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `count` | 整数 | — | 数字角标（`0` 隐藏，`>99` 显示 99+） |
| `dot` | 布尔 | `false` | 状态圆点 |
| `text` | 字符串 | — | 文字标签 |

```uix
<Badge count={5}>
  <Icon name="bell" />
</Badge>
```

### Tag 标签

可勾选、可关闭、多彩色。

> **当前映射**：已实现。标签正文使用文本与插值子节点；`color` 接受已登记关键字、十六进制字面量或 `Color` 表达式；`closable` / `checkable` 接受布尔值。嵌套元素不受支持。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `color` | 颜色 / 关键字 | — | 标签色 |
| `closable` | 布尔 | `false` | 可关闭 |
| `checkable` | 布尔 | `false` | 可勾选 |

### Card 卡片容器

内置标题与操作项。

> **当前映射**：已实现。`title` 接受字符串字面量或字符串表达式；`actions` 只接受操作项数组表达式，并由 Rust 核对元素类型；直接子节点按源码顺序生成完整 `ViewNode` 子树，支持核心条件与循环控制节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `title` | 字符串 | — | 标题 |
| `actions` | 数组引用 | — | 操作项字符串列表（对应 Rust `actions`） |

```uix
<Card title="用户信息" actions={cardActions}>
  <Text>姓名：张三</Text>
</Card>
```

### Descriptions 描述列表

多列键值对展示。

> **当前映射**：已实现。`data` 必须是拥有所有权、可迭代且元素为公开 `DescriptionsItem` 的 Rust 表达式，数组与 `Vec` 均可；普通 UIX 表达式当前不接受内联对象数组。`columns` 接受大于零的整数字面量或 `usize` 表达式，缺省时显式使用文档默认的一列。`Descriptions` 是叶组件，不接受子节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | `DescriptionsItem` 可迭代表达式 | — | 类型化键值项集合 |
| `columns` | 正整数 / `usize` 表达式 | `1` | 列数 |

### Skeleton 骨架屏

加载占位，矩形 / 圆形 / 文字形态。

> **当前映射**：已实现。`shape` 只接受静态关键字；`width` / `height` 接受有限数值、`px` 字面量或 `f32` 表达式。`Skeleton` 是叶组件，不接受子节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `shape` | 关键字 | `rect` | `rect` / `circle` / `text` |
| `width` / `height` | 长度 | — | 占位尺寸 |

### Empty 空状态

列表无数据时的占位。

> **当前映射**：已实现。`description` / `icon` 接受字符串字面量或字符串表达式；`Empty` 是叶组件，不接受子节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `description` | 字符串 | — | 描述文字 |
| `icon` | 图标名 | — | 自定义图标 |

### ResultView 结果页

success / error / 404 等预设状态页。

> **当前映射**：已实现。`status` 只接受静态关键字；`title` / `extraText` 接受字符串字面量或字符串表达式。`ResultView` 是叶组件，不接受子节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `status` | 关键字 | `success` | `success` / `error` / `info` / `warning` / `404` |
| `title` | 字符串 | — | 标题 |
| `extraText` | 字符串 | — | 辅助文字（对应 Rust `extra_text`） |

## 2. 数据展示

### List 列表

含 header / footer 与 load-more。

> **List 当前映射**：已实现。`data` 是必需的可迭代字符串表达式，生成层按值取得集合并收集为 `Vec<String>`；`header`、`footer` 与 `loadMore` 当前接受字符串字面量或字符串表达式，并映射到现有 Rust `List` 的字符串槽位。列表通过公开 `View::build` 物化，因此空数据继续使用运行时配置的 Empty 替代；文本省略、测量、绘制、快照与 reconcile 仍由运行时组件独占。`List` 是叶组件，不接受子节点；目标设计中的节点型 header / footer / load-more 插槽仍为规划中，`bordered`、`size` 等本页未登记属性也不会被编译层猜测映射。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | 可迭代字符串表达式 | — | 必需文本数据源 |
| `header` / `footer` | 字符串（当前）/ 节点（目标） | — | 当前映射为首尾文本 |
| `loadMore` | 字符串（当前）/ 节点（目标） | — | 当前映射为加载更多文字 |

### SelectableList 可选中列表

键盘导航与 active 高亮。

> **当前映射**：规划中。`items` 接受拥有型 `SelectableItem` 集合，`active` 绑定调用方拥有的 `State<Option<String>>`，稳定身份使用 `SelectableItem::id`。用户激活先写回同一状态，再通过 `@change` 发布稳定 id；未绑定时保留运行时的非受控初值与键盘导航。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `items` | `SelectableItem` 可迭代表达式 | — | 类型化可选项集合 |
| `active` | `State<Option<String>>` 绑定 | — | 当前稳定 id |
| `@change` | 事件 | — | 已提交激活的稳定 id |

### Tree 树形控件

展开 / 折叠与勾选。

> **当前映射**：已实现。`data` 必须是拥有所有权、可迭代且元素为公开 `TreeNode` 的 Rust 表达式，数组与 `Vec` 均可；`checkable` / `defaultExpandAll` 接受布尔字面量或 `bool` 表达式，缺省均为 `false`。`defaultExpandAll` 只建立首次物化的展开集合，后续用户展开状态由运行时组件拥有。`Tree` 是叶组件，不接受子节点，并要求使用方启用默认包含的 `tree-widgets` capability。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | `TreeNode` 可迭代表达式 | — | 类型化树节点集合 |
| `checkable` | 布尔 | `false` | 节点勾选 |
| `defaultExpandAll` | 布尔 | `false` | 默认全展开 |

### Table 数据表格

排序、选择、固定列与虚拟滚动。

> **当前映射**：已实现。首版只接受拥有型 `TableRow` / `TableColumn` 集合，不生成匿名对象投影；列身份沿用运行时位置索引，因此不登记文档旧有的 `columns.key`。`virtual` 与 `loading` 接受布尔简写、字面量或 `bool` 表达式，并映射到公开运行时配置。`Table` 是叶组件，不接受子节点。`rowSelection` 对象和受控选择事件尚无公开运行时闭环，必须明确拒绝，不能用 `selection(bool)` 冒充。`DataTable` 继续是 Rust-only 泛型能力。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `data` | `TableRow` 可迭代表达式 | — | 类型化行数据 |
| `columns` | `TableColumn` 可迭代表达式 | — | 类型化列定义，位置即首版身份 |
| `virtual` | 布尔 | `false` | 虚拟滚动（大数据量） |
| `loading` | 布尔 | `false` | 加载状态 |

```uix
<Table data={users} columns={userColumns} />
```

### DataTable 泛型数据表格

任意行类型 + 列绑定渲染（对应 Rust `DataTable`）。该泛型投影能力保持 Rust-only，不登记 UIX 标签。

### Timeline 时间轴

含 pending 与 reverse。

> **当前映射**：已实现。`items` 必须是拥有所有权、可迭代且元素为公开 `TimelineItem` 的 Rust 表达式，数组与 `Vec` 均可；`pending` / `reverse` 接受布尔字面量或 `bool` 表达式，缺省时均显式使用 `false`。`Timeline` 是叶组件，不接受子节点。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `items` | `TimelineItem` 可迭代表达式 | — | 类型化时间轴项集合 |
| `pending` | 布尔 | `false` | 末尾 pending 节点 |
| `reverse` | 布尔 | `false` | 反向展示时间轴项 |

### Collapse 折叠面板

支持手风琴模式。

> **当前映射**：规划中。`CollapsePanel` 使用非空稳定 key，未显式设置时兼容取 header；同名 header 必须显式指定不同 key。`activeKeys` 绑定 `State<Vec<String>>` 并成为唯一展开真值，外部失效 key 保持原值而界面不展开。`accordion=true` 把用户产生的新状态归一化为最多一个 key；用户切换先原子写回，再通过 `@change` 发布本次切换的稳定 key。未绑定时继续使用面板 `expanded` 初值与运行时非受控状态。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `accordion` | 布尔 | `false` | 手风琴（同时只开一个） |
| `activeKeys` | `State<Vec<String>>` 绑定 | — | 展开面板稳定 key 集合 |
| `@change` | 事件 | — | 本次切换的稳定 key |

### Calendar / Carousel

- `Calendar`：日历面板，日期选择与月视图导航。
- `Carousel`：走马灯，幻灯片轮播；子节点为各页内容，`autoplay` 声明自动播放。

> **Calendar 当前映射**：已实现 `<Calendar />` 默认交互契约和公共样式、尺寸、自动化属性。日期选择、焦点与月视图导航状态由运行时组件拥有；当前规范尚未登记默认日期、受控绑定、自定义日期格或事件属性，这些名称会继续产生编译期诊断。`Calendar` 是叶组件，不接受子节点。

> **Carousel 当前映射**：已实现。普通子节点与 `If` / `For` 控制流按源码顺序生成幻灯片 View；空或单页声明也保持合法。`autoplay` 接受布尔简写、字面量或 `bool` 表达式，缺省与 `false` 关闭计时器，`true` 采用 Rust 使用文档已登记的三秒间隔。当前页、幻灯片数量、悬停暂停、计时器申请与 reconcile 仍由运行时 `Carousel` 拥有；生成层不复制运行状态。组件要求使用方启用默认包含的 `display` capability。

## 3. 媒体与特殊展示

### Image / ImageGroup

- `Image`：图片组件，点击预览、圆角与加载回退；`src` / `radius` / `fallback`。
- `ImageGroup`：图片组画廊，缩略图与全屏预览。

> **Image 当前映射**：已实现。`src` 是必需字符串字面量或字符串表达式，并要求使用方启用默认包含的 `image-codecs` capability；`width` / `height` 设置组件固有尺寸，接受正的十进制、`px` 字面量或 `f32` 表达式，缺省为 `128px` / `88px`。`alt` 与 `fallback` 接受字符串；`radius` 接受非负有限数值；`preview`、`fit` 与 `lazy` 接受布尔简写、字面量或表达式，缺省分别沿用运行时 `true`、`true` 与 `false`。`Image` 是叶组件，不接受子节点；加载缓存、失败状态、可见性触发、预览 Overlay、命中和失效仍由运行时组件独占。占位 View 与错误 View 工厂继续保持规划中，不会被编译层猜测映射。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `src` | 字符串 | — | 必需图片文件路径；要求 `image-codecs` |
| `alt` | 字符串 | `""` | 替代文字与语义名称 |
| `fallback` | 字符串 | `""` | 加载失败时的回退文字 |
| `width` | 长度 | `128px` | 正的固有宽度 |
| `height` | 长度 | `88px` | 正的固有高度 |
| `radius` | 长度 | `6px` | 非负圆角 |
| `preview` | 布尔 | `true` | 点击或键盘打开窗口内预览 |
| `fit` | 布尔 | `true` | 保持比例居中；`false` 时拉伸填满 |
| `lazy` | 布尔 | `false` | 与可见绘制视口相交后再解析资源 |

> **ImageGroup 当前映射**：已实现。`images` 是必需的可迭代字符串表达式，生成层按值取得集合并收集为 `Vec<String>`，因此同样要求使用方启用 `image-codecs` capability；`startIndex` 接受 `usize` 整数字面量或表达式，缺省保留运行时 `0`，越界值由实际图片数量归一化。`@change` 在运行时完成选择后接收当前索引的十进制文本。`ImageGroup` 是叶组件，不接受 `Image` 子节点；当前索引、焦点、键盘/指针选择、缩略图、预览 Overlay、命中、失效与 reconcile 继续由运行时组件独占，不新增受控 current 状态。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `images` | 可迭代字符串表达式 | — | 必需图片路径集合；要求 `image-codecs` |
| `startIndex` | `usize` | `0` | 首次物化时的图片索引，越界时归一化 |
| `@change` | 事件处理器 | — | `$event` 为当前索引的十进制文本 |

### QRCode 二维码

标准 QR 编码与纠错等级。

> **当前映射**：已实现。`value` 是必需字符串字面量或字符串表达式；`size` 接受十进制、`px` 字面量或 `f32` 表达式，缺省时显式使用文档默认的 `128px`；`errorLevel` 只接受 `L` / `M` / `Q` / `H` 关键字，缺省为 `M`。`QRCode` 是叶组件，不接受子节点，并要求使用方启用默认包含的 `qrcode` capability。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `value` | 字符串 | — | 编码内容 |
| `size` | 长度 | `128px` | 尺寸 |
| `errorLevel` | 关键字 | `M` | 纠错等级 `L` / `M` / `Q` / `H` |

### Watermark 水印

平铺文字覆盖内容区。

> **当前映射**：已实现。`text` 是必需字符串字面量或字符串表达式，生成代码只临时借用，运行时组件持有内容；`opacity` 接受 `0` 到 `1` 的无单位有限字面量或 `f32` 表达式，缺省为 `0.15`，静态越界值会在编译期被拒绝，动态值由运行时归一化。`Watermark` 是叶组件，不接受子节点；平铺几何、绘制、脏区与同步生命周期仍由运行时组件负责。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `text` | 字符串 | — | 必需的水印文字 |
| `opacity` | 数字 | `0.15` | 透明度，范围 `0` 到 `1` |

### RichText 富文本

文本、链接与代码段混合排版。

> **当前映射**：已实现。`content` 是必需字符串字面量或字符串表达式，生成代码只在调用公开 `parse_rich_text` 时临时借用，解析结果和布局生命周期由运行时 `RichText` 持有；`selectable` 接受布尔简写、字面量或 `bool` 表达式，缺省为 `false`。`RichText` 是叶组件，不接受子节点，并要求使用方启用默认包含的 `rich-text` capability。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `content` | 字符串 | — | 富文本内容（行内标记语法） |
| `selectable` | 布尔 | `false` | 可选中 |

```uix
<RichText content="支持 **加粗**、`代码` 与 [链接](https://example.com)" />
```
