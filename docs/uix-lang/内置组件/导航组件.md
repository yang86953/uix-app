# 导航组件

[← 返回 UIX Lang 索引](../README.md)

> **接口**：声明 UIX Lang 内置导航组件——Menu / Navigation / Tabs / Breadcrumb / Steps / Anchor / Dropdown / Pagination。依赖：[标签语法](../标签语法.md)、[样式属性参考](../UIX%20样式属性参考.md)。
>
> **状态声明**：本规范为**目标设计、领先实现**（见 [README](../README.md)）：写应用以 uix-lang 描述 UI，编译时由 uix-app 自动转换为 Rust；当前转换器尚未实现。组件能力与 Rust 内置组件一一对应（权威清单见[组件速查](../../使用/组件速查.md)）。

## 1. Menu 菜单

水平或垂直模式的导航项集合；`mode` 声明方向，`items` 声明菜单数据，`selectedKey` 双向绑定选中项。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `mode` | 关键字 | `vertical` | `vertical` / `horizontal` |
| `items` | 数组 | — | `[{ key, label, icon, children }]` 菜单项 |
| `selectedKey` | 绑定 | — | 当前选中项 key |
| `collapsible` | 布尔 | `false` | 可折叠（垂直模式） |
| `@select` | 事件 | — | 选中事件 |

```uix
<Menu
  mode="vertical"
  items={menuItems}
  selectedKey={current}
  @select="onMenuSelect"
/>
```

## 2. Navigation 侧边栏导航

含标题、菜单项与版本号的完整侧边栏。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `title` | 字符串 | — | 侧栏标题 |
| `items` | 数组 | — | 菜单项（同 Menu） |
| `version` | 字符串 | — | 版本号 |

## 3. Tabs 标签页

内容面板切换；`activeKey` 双向绑定当前页，`type` 支持卡片样式。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `activeKey` | 绑定 | — | 当前面板 key |
| `items` | 数组 | — | `[{ key, label, content }]` |
| `type` | 关键字 | `line` | `line` / `card` |
| `@change` | 事件 | — | 切换事件 |

```uix
<Tabs activeKey={tab} items={tabItems} @change="onTabChange" />
```

## 4. Breadcrumb 面包屑

路径层级导航，`items` 声明 `[{ label, link }]` 序列；末项为当前页。

```uix
<Breadcrumb items={breadcrumbItems} />
```

## 5. Steps 步骤条

引导式流程进度；`current` 双向绑定当前步骤，`items` 声明步骤标题与描述。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `current` | 绑定 | `0` | 当前步骤索引 |
| `items` | 数组 | — | `[{ title, description }]` |
| `direction` | 关键字 | `horizontal` | `horizontal` / `vertical` |

```uix
<Steps current={step} items={stepItems} />
```

## 6. Anchor 锚点导航

页面内跳转链接列表；`items` 声明 `[{ key, title }]`，点击平滑滚动到对应锚点区域。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `items` | 数组 | — | 锚点列表 |
| `offsetTop` | 长度 | — | 滚动定位偏移 |

## 7. Dropdown 下拉菜单

点击弹出选项列表；`items` 声明选项，`trigger`（`click` / `hover`）声明触发方式。

```uix
<Dropdown items={actionItems} @select="onAction">
  <Button>更多</Button>
</Dropdown>
```

## 8. Pagination 分页器

页码跳转与每页条数切换；`current` / `pageSize` 双向绑定，`total` 声明总条数。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `current` | 绑定 | `1` | 当前页 |
| `pageSize` | 绑定 | `10` | 每页条数 |
| `total` | 整数 | `0` | 总条数 |
| `@change` | 事件 | — | 页码变化事件 |

```uix
<Pagination current={page} pageSize={pageSize} total={total} @change="onPageChange" />
```
