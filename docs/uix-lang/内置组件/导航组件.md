# 导航组件

[← 返回 UIX Lang 索引](../README.md)

> **接口**：声明 UIX Lang 内置导航组件——Menu / Navigation / Tabs / Breadcrumb / Steps / Anchor / Dropdown / Pagination。依赖：[标签语法](../标签语法.md)、[样式属性参考](../UIX%20样式属性参考.md)。
>
> **状态声明**：公开 `uix!` 转换器已经可用；本页 `Steps` / `Pagination` / `Breadcrumb` / `Anchor` / `Tabs` 已进入生成矩阵，其余组件使用时仍会得到明确编译错误。Rust 内置能力的权威清单见[组件速查](../../使用/组件速查.md)。

## 1. Menu 菜单

水平或垂直模式的导航项集合；`mode` 声明方向，`items` 声明菜单数据，`selectedKey` 双向绑定选中项。

> **当前映射**：规划中。Menu 与 Navigation 共享拥有型 `MenuItem<K = String>` 树；同一树内 key 全局唯一，动态重复项保留首项并产生可观察诊断。`selectedKey` 绑定调用方拥有的 `State<Option<K>>`，外部无匹配 key 时保持原值并显示无选择；`openKeys: State<Vec<K>>` 只拥有递归子菜单展开状态。`collapsible` 表示含 children 的菜单组可展开/收起，不表示整条侧栏折叠。有效选择先写回状态，再通过 `@select` 发布稳定 key；重复选择不重复发出。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `mode` | 关键字 | `vertical` | `vertical` / `horizontal` |
| `items` | `MenuItem<K>` 可迭代表达式 | — | 类型化菜单树 |
| `selectedKey` | `State<Option<K>>` 绑定 | — | 当前选中项 key |
| `openKeys` | `State<Vec<K>>` 绑定 | — | 展开的子菜单 key |
| `collapsible` | 布尔 | `false` | 子菜单组可展开 / 收起 |
| `@select` | 事件 | — | 选中事件 |

```uix
<Menu
  mode="vertical"
  items={menuItems}
  selectedKey={current}
  @select="onMenuSelect"
/>
```

## 2. Navigation 侧边栏导航

含标题、菜单项与版本号的完整侧边栏。

> **当前映射**：规划中。`Navigation<K>` 是“侧栏外壳 + 受控 Menu”的复合组件，不维护第二份条目或选择状态。`activeKey` / `openKeys` 与 Menu 使用同一状态；整栏 `collapsed: State<bool>` 只归 Navigation，收起时隐藏标题和版本呈现但保留选择与展开状态。`version` 是调用方应用元数据，未设置时不占位；locale 不再提供版本事实。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `title` | 字符串 | — | 侧栏标题 |
| `items` | `MenuItem<K>` 可迭代表达式 | — | 与 Menu 共享的类型化菜单树 |
| `activeKey` | `State<Option<K>>` 绑定 | — | 当前选中项 key |
| `openKeys` | `State<Vec<K>>` 绑定 | — | 展开的子菜单 key |
| `collapsed` | `State<bool>` 绑定 | — | 整条侧栏折叠状态 |
| `version` | 字符串 | — | 调用方应用版本元数据 |
| `@select` | 事件 | — | 已提交选择的稳定 key |

## 3. Tabs 标签页

> **当前映射**：已支持。转换器生成拥有全部静态面板的 `Tabs`，并在编译期拒绝直接 `If` / `For` 面板和未登记的 `type` 属性。

`Tabs` 是标签栏及内容面板子树的唯一生命周期所有者。`items` 只提供 `Tab` 的 `key` / `label` / `icon` 元数据；元素的直接子 View 按源码顺序与 `items` 一一对应。全部面板随 `Tabs` 挂载并保留状态，只有活动面板参与布局和命中。切换时若焦点位于旧面板，焦点进入新面板的首个可聚焦项；没有可聚焦项时退回标签栏。

`activeKey` 必须绑定 `State<String>`。外部 key 没有匹配项时保持原值并进入空选中，不隐式改写为首项，也不生成内容面板；用户切换先写回同一状态，再通过 `@change` 发布稳定 key。首版不登记 `type=line|card`，使用该属性必须得到明确编译诊断，待运行时公开样式枚举后再扩展。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `activeKey` | `State<String>` 绑定 | — | 当前面板稳定 key；无匹配项为空选中 |
| `items` | 表达式 | — | 可迭代 `Tab` 集合，只包含 key / label / icon 元数据 |
| `@change` | 事件 | — | 已提交切换的稳定 key |

```uix
<Tabs activeKey={tab} items={tabItems} @change="onTabChange($event)">
  <AccountPanel />
  <SecurityPanel />
</Tabs>
```

```rust
let tabItems = [
    Tab::new("账户").key("account"),
    Tab::new("安全").key("security"),
];
```

## 4. Breadcrumb 面包屑

路径层级导航；`items` 必须是 Rust 侧拥有型 `BreadcrumbItem` 数组或 `Vec`，生成器会把末项设为当前页。

```uix
<Breadcrumb items={breadcrumbItems} />
```

```rust
let breadcrumbItems = [
    BreadcrumbItem::new("首页").link("/"),
    BreadcrumbItem::new("设置").link("/settings"),
];
```

`BreadcrumbItem::link(...)` 是稳定路径标识；非空链接同时作为 `Change` 语义事件载荷，未设置链接的旧调用方继续回退到标题。运行时组件独占当前项、折叠、键盘与指针交互生命周期，并按稳定链接保持 reconcile 选择；UIX 生成器只收集条目并调用公开 `.last_active()` 契约，不复制内部状态。`Breadcrumb` 是叶组件，不接受子节点；通用 View 属性仍可使用。

## 5. Steps 步骤条

引导式流程进度；`current` 双向绑定当前步骤，`items` 声明步骤标题与描述。

> **当前映射**：已实现。`items` 必须是拥有所有权、可迭代且元素为公开 `Step` 的 Rust 表达式，数组与 `Vec` 均可；`current` 必须绑定 `State<usize>`，用户点击或键盘切换会先写回同一状态，再发出既有索引 `Change` 语义。外部状态更新通过 reconcile 同步，越界索引按当前步骤集合归一化并写回；`direction` 只接受 `horizontal` / `vertical`，缺省为 `horizontal`。`Steps` 是叶组件，不接受子节点，并要求使用方启用默认包含的 `navigation` capability。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `current` | 绑定 | `0` | 当前步骤索引 |
| `items` | 数组 | — | `[{ title, description }]` |
| `direction` | 关键字 | `horizontal` | `horizontal` / `vertical` |

```uix
<Steps current={step} items={stepItems} />
```

## 6. Anchor 锚点导航

页面内跳转链接列表；`items` 必须是 Rust 侧拥有型 `AnchorItem` 数组或 `Vec`。点击或键盘选择会建立 href Change 事实，应用处理器据此驱动自己拥有的 `ScrollView` 或其他滚动容器。

> **当前映射**：已实现。`AnchorItem::new(label, href)` 的非空 `href` 是稳定滚动目标身份；reconcile 按 href 保持当前项，href 序列变化时丢弃已错配的位置缓存，等待调用方重新注入测量结果。`offsetTop` 接受 px 字面量或 `f32` 表达式并映射到公开 `target_offset(...)`；`@change` 接收当前 href 文本。Anchor 只拥有当前项、键盘/指针交互与位置缓存，真实滚动位置和滚动动作仍由应用持有。`Anchor` 是叶组件，不接受子节点，并要求使用方启用默认包含的 `navigation` capability。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `items` | 表达式 | — | 可迭代 `AnchorItem` 集合 |
| `offsetTop` | 长度 / 表达式 | `0` | 滚动定位偏移 |
| `@change` | 事件 | — | 当前 href 变化事实 |

```uix
<Anchor
  items={anchorItems}
  offsetTop={headerHeight}
  @change="scrollToAnchor($event)"
/>
```

```rust
let anchorItems = [
    AnchorItem::new("基本信息", "section-basic"),
    AnchorItem::new("高级设置", "section-advanced"),
];
```

## 7. Dropdown 下拉菜单

点击、悬停、焦点或右键弹出选项列表。

> **当前映射**：规划中。Dropdown 是唯一 trigger View 子树与弹层状态的组合 owner；UIX 必须包含且仅包含一个静态直接 trigger View。`DropdownItem` 使用非空稳定 key，label 只负责显示；旧 label 构造兼容映射 `key=label`，新 UIX 数据要求显式唯一 key。选择通过现有 `Change` 语义和 `@change` 发布稳定 key，不登记 `@select` 别名。`trigger` 只接受 `click` / `hover` / `focus` / `contextMenu`，缺省为 `click`。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `items` | `DropdownItem` 可迭代表达式 | — | 必需的 keyed 选项集合 |
| `trigger` | 关键字 | `click` | `click` / `hover` / `focus` / `contextMenu` |
| `@change` | 事件 | — | 选中项稳定 key |

```uix
<Dropdown items={actionItems} trigger="click" @change="onAction($event)">
  <Button>更多</Button>
</Dropdown>
```

## 8. Pagination 分页器

页码跳转与每页条数切换；`current` / `pageSize` 双向绑定，`total` 声明总条数。

> **当前映射**：已实现。`total` 接受 `usize` 字面量或 Rust 表达式，缺省为 `0`；`current` / `pageSize` 出现时必须分别绑定 `State<usize>`，未绑定时沿用运行时默认值 `1` / `10`。绑定 `pageSize` 会启用每页条数切换入口；用户交互先写回对应状态，再发送既有 `Change` 文本载荷，其中页码为十进制文本，每页条数为 `page_size=<值>`。外部状态更新通过 reconcile 同步，零 `pageSize` 与越界 `current` 会归一化并写回。`Pagination` 是叶组件，不接受子节点，并要求使用方启用默认包含的 `navigation` capability。

| 属性 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `current` | 绑定 | `1` | 当前页 |
| `pageSize` | 绑定 | `10` | 每页条数 |
| `total` | 整数 | `0` | 总条数 |
| `@change` | 事件 | — | 页码变化事件 |

```uix
<Pagination current={page} pageSize={pageSize} total={total} @change="onPageChange" />
```
