> 前置：已按[UIX Lang 快速开始](快速开始.md)配好 `Cargo.toml`。

## 1. 最小骨架

一个 `.uix` 文档：根元素 `<App>` 声明窗口，界面树声明在根内。

```uix
<App title="待办" size="400x500">
  <Text fontSize="heading3">Hello, TODO!</Text>
</App>
```

`App` 根与 `uix_app!` 入口已实现（见[编译契约](../规范/编译契约.md)）；`uix_app!` 返回尚未运行的现有 `App` builder。单个 View 文档仍使用返回 `ViewNode` 的 `uix!`，两种入口的组合方式见[UIX Lang 快速开始](快速开始.md#当前可编译的第一个-view)。

## 2. 用 state 管理数据

状态在 `<Widget>` 内声明：`state="名称: 初始值"`，组件内以 `{名称}` 读取。待办列表的初始值为空数组：

```uix
<Widget name="TodoApp" state="todos: Vec<String> = [], inputText: String = ''">
  <Text>当前有 {todos.length} 条待办</Text>
</Widget>
```

- 数组状态使用 `Vec<String>` 等已登记类型显式注解，初始值 `[]` 对应 Rust `Vec::new()`。
- 读取用属性访问路径：`{todos.length}`、`{todos[0]}`。

## 3. 组合视图：输入框 + 列表 + 按钮

添加待办：`@click` 中 `setState` 用不可变数组操作 `push`；列表用 `<For>` 渲染，删除用索引 `removeAt`：

```uix
<Widget name="TodoApp" state="todos: Vec<String> = [], inputText: String = ''">
  <Container direction="column" gap="16px" padding="16px">

    // 输入区：双向绑定 inputText
    <Container direction="row" gap="8px">
      <Input value={inputText} placeholder="输入待办事项" flexGrow={1} />
      <Button type="primary"
              @click="setState(todos: todos.push(inputText), inputText: '')">
        添加
      </Button>
    </Container>

    // 列表：For 渲染 + 索引删除
    <For {todo} {i} in {todos}>
      <Container direction="row" gap="8px">
        <Text flexGrow={1}>{i}: {todo}</Text>
        <Button @click="setState(todos: todos.removeAt(i))">完成</Button>
      </Container>
    </For>

  </Container>
</Widget>

<App title="待办" size="400x500">
  <TodoApp />
</App>
```

- **双向绑定**：`value={inputText}` 输入框内容直接写回状态。
- **追加**：`todos.push(inputText)` 返回新数组（不可变更新，原数组不变）。
- **删除**：`<For {todo} {i} in {todos}>` 声明索引绑定，`todos.removeAt(i)` 删除当前项。

## 4. 美化界面：样式类

把外观提取为顶层样式类，元素用 `class` 引用：

```uix
// 顶层声明区
appBg {
  backgroundColor: #F5F7FA;
  borderRadius: 12px;
  padding: 20px;
  gap: 12px;
}

todoCard {
  backgroundColor: white;
  borderRadius: 8px;
  padding: 12px 8px;
  gap: 8px;
}

<Widget name="TodoApp" state="todos: Vec<String> = [], inputText: String = ''">
  <Container class="appBg" direction="column">
    <For {todo} {i} in {todos}>
      <Container class="todoCard" direction="row" gap="8px">
        <Text flexGrow={1}>{i}: {todo}</Text>
        <Button @click="setState(todos: todos.removeAt(i))">完成</Button>
      </Container>
    </For>
  </Container>
</Widget>
```

- 样式类语法与[样式属性参考](../参考/样式属性.md)一致：`属性: 值;`。
- 优先级：内联 `style` > 样式类 `class` > 主题默认。

## 5. 主题

```uix
// 声明本主题示例独立生成所需的布局样式类。
appBg {
  // 为示例根布局提供统一内边距。
  padding: 20px;
  // 为示例子元素提供统一间距。
  gap: 12px;
// 结束布局样式类声明。
}

@theme light {
  primaryColor: #2196F3;
  backgroundColor: #F5F7FA;
}

@theme dark {
  primaryColor: #64B5F6;
  backgroundColor: #121212;
}

<Widget name="TodoApp" state="todos: Vec<String> = [], inputText: String = ''">
  // 使用主题背景 token，并以分号闭合内联样式属性。
  <Container class="appBg" style="backgroundColor: #backgroundColor;" direction="column">
    // 使用主题主色 token，并以分号闭合内联样式属性。
    <Button type="primary" style="backgroundColor: #primaryColor;">添加</Button>
  </Container>
</Widget>

<App title="待办" size="400x500" theme="light">
  <TodoApp />
</App>
```

- 样式值中 `#属性名` 引用当前主题属性（与十六进制颜色的区分见[样式与主题 · 主题](../规范/样式与主题.md#42-引用主题属性)）。
- 运行期切换：`@click="setTheme('dark')"`。

## 6. 业务与生命周期由 Rust 接入

UIX Lang 只描述 UI。已登记的同步 action 可组合局部界面状态更新和转发 Rust 回调；持久化、业务校验、异步任务、导航、多窗口及应用生命周期由 Rust 组合根与对应 Systems 持有。这是长期职责边界，不是待补齐的语言缺口，详见[语言边界](../设计/语言边界.md)。`uix!` 生成 `ViewNode`；`uix_app!` 把 `<App>` 根转换为现有 `App` builder，调用方可链式配置 `settings`、`on_start`、Agent 控制等扩展点，并显式决定何时调用 `run()`。

### 从界面练习进入完整应用

本页的局部 `todos` 示例用于学习 UI 语法。需要持久化、后台结果和可恢复的业务状态时，继续运行[任务清单：UIX Lang 与 Rust 的完整应用路径](../../../demo/task-list/README.md)，不要把 Widget 私有数组直接当成应用级领域真值。

该应用仍使用本页的 `Input`、`For` 和条件结构；Rust 组合根通过公开 `State<T>` props 与类型化回调连接真实任务 ID、校验、两页导航、本地后台统计、显式保存和第二次启动恢复。完整源码、依赖与锁文件一起提供，保存失败和关闭回收也属于这条路径，不留给读者自行拼接。示例验证状态和固定来源以其指南为准；不需要进入 Scheme 或可移植模块专题。
