# UIX 语言使用路径

[← 返回语言索引](../README.md)

本页串联框架语言能力，不维护具体控件教程。先按 [编译快速开始](快速开始.md) 打通 `.uix` 文件、build.rs 与 Rust 读取宏。

## 文件与声明

源文件可以声明 Widget、Record、Visual 以及一个输出根。`@import` / `@export` 管理文件可见性；Builder 根据实际导入图登记变更追踪。语法见 [词法](../规范/词法.md)、[语法](../规范/语法.md) 和 [模块系统](../规范/模块系统.md)。

## 参数与状态

Widget 通过 props 接收调用方输入，通过 state 声明自己拥有的界面状态。派生值使用 computed，同步 action 组合局部更新与回调；宿主的业务权限和外部服务不随 Widget 声明转移。详细合同见 [组件声明](../规范/组件.md) 与 [表达式](../规范/表达式.md)。

## 子树与样式

Slot 表达内容插槽，If / For 表达条件与重复子树；稳定身份由相应结构合同维护。样式类与显式字段差异按 [样式规范](../规范/样式与主题.md) 合并，属性语法见 [样式参考](../参考/样式属性.md)。

具体组件通过 [组件库登记](../规范/组件库登记.md) 接入。框架结构规则不暗含某个库的按钮、表格或主题预设。

## Rust 与应用组装

生成 View 的文件选择 `OutputKind::View`；生成 App builder 的文件选择 `OutputKind::App`。Rust 继续持有应用生命周期和实际 `.run()`。渲染函数、外部状态与业务回调在使用位置满足真实 Rust 类型，而不是任意字符串执行。

自定义绘制与焦点作用域等框架入口见 [框架节点](../参考/框架节点.md)。

## 模块与工具

可移植应用模块是独立输出形状，按 [应用模块规范](../规范/应用模块.md) 使用；它不把所有 View 文件自动变成可动态执行程序。CLI 和 [语言服务器](语言服务器.md) 使用项目中的相同组件目录进行检查、查询和诊断。
