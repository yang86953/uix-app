# UIX Lang 快速开始

[← 返回 UIX Lang 索引](../README.md)

> **文档角色**：当前指南——只提供可复制的已登记用法，不定义语言规则或未来能力。
>
> **接口**：声明 UIX 推荐界面描述方式（UIX Lang）的第一个编译期 View 与完整 App——依赖配置、Hello World、计数器及主题示例。依赖：[UIX Lang 语言规范](../README.md)、[语法](../规范/语法.md)。导出：[UIX Lang 教程](教程.md)。
>
> **状态声明**：公开 `uix!` 已支持内嵌源码与 `.uix` 文件并返回 `ViewNode`；完整 `App` 入口与 `@theme` 主题生成已由 `uix_app!` 实现。本页三个示例只使用已登记能力；未登记标签、属性、事件或样式会在编译期拒绝。当前应用、窗口和环境前置条件见[快速开始（Rust 版）](../../使用/入门/快速开始.md)。

## 添加依赖

```toml
[dependencies]
uix-app = { version = "=0.0.8" }
```

UIX 0.0.8 按 MIT 许可公开发布到 crates.io。包名为 uix-app，Rust 导入使用 uix_app；无需私有 Registry 或内部授权。应用保留 Cargo.lock 以记录依赖解析，编译工具链跟随最新 stable。

## 当前可编译的第一个 View

把界面保存为调用 crate 下的 `src/main.uix`，并使用当前已登记的标签：

仓库内的可运行对应项目见 [`demo/uix-lang-demo`](../../../demo/uix-lang-demo/README.md)；该项目由
`.uix` 文件生成界面，并由 Rust 薄入口持有 `App` 与窗口生命周期。

```uix
// 使用当前已登记的纵向容器作为根 View。
<Column gap="8px">
  // 创建当前已登记的文本 View。
  <Text fontSize="heading2">Hello, world!</Text>
  // 创建当前已登记的按钮 View。
  <Button>Continue</Button>
// 结束根 View。
</Column>
```

```rust
// 导入公开 uix! 宏与 ViewNode 类型。
use uix_app::prelude::*;

// 声明由应用组合根调用的界面构造函数。
fn build_view() -> ViewNode {
    // 编译期读取相对 CARGO_MANIFEST_DIR 的 .uix 文件。
    uix!("src/main.uix")
// 结束界面构造函数。
}
```

要点：

- **返回契约**：`uix!` 生成 `ViewNode` 表达式，不负责启动应用或窗口。
- **文件路径**：`.uix` 相对路径以调用 crate 的 `CARGO_MANIFEST_DIR` 为基准。
- **当前根元素**：`uix!` 使用已登记的 View 标签并返回 `ViewNode`；以 `<App>` 为根的文档使用 `uix_app!` 并返回尚未运行的现有 `App` builder。
- **文本插值**：`{expr}` 在 `Text` 内容中即插值；动态内容由文本节点延迟读取，普通状态更新只刷新该文本的绘制，结构条件仍按需 reconcile。

### 根视图背景

`uix!` 生成的普通容器（如 `Column`）本身仍保持透明语义。当生成结果作为窗口根 View 且没有显式背景时，`App` 组合根会应用当前主题的 `BgLayout` 默认值，因此简单界面无需额外补背景即可显示：

```rust
// App 只为未声明背景的窗口根 View 应用主题布局背景。
uix!("src/main.uix")
```

调用方通过 `.bg(...)` 显式声明的背景优先于应用默认值；显式透明色同样会保留。非窗口根的普通 `ViewNode` 不会获得这个应用级默认背景。

## 带交互的完整计数器应用

组件 `state`、事件、`setState` 与 `App` 根均已实现。把下例保存为 `src/counter.uix`，再由 Rust 薄入口调用 `uix_app!("src/counter.uix").run()`：

```uix
<Widget name="Counter" state="count: 0">
  <Container direction="column" gap="16px" padding="24px">
    <Text fontSize="heading1">{count}</Text>
    <Container direction="row" gap="8px">
      <Button @click="setState(count: count - 1)">-1</Button>
      <Button type="primary" @click="setState(count: count + 1)">+1</Button>
    </Container>
  </Container>
</Widget>

<App title="计数器" size="360x200">
  <Counter />
</App>
```

要点：

- **状态**：`state="count: 0"` 声明私有状态，`{count}` 读取，`setState(count: 表达式)` 更新（命名参数）。
- **事件**：`@click="..."` 绑定点击；处理器是[受限表达式](../规范/表达式.md)。
- **样式**：`gap`、`padding` 等直接作属性；复杂样式用样式类（见下）。

## 样式类与主题组成完整应用

样式类、已登记样式属性、`@theme`、`setTheme` 与 `App theme` 已实现；下例可保存为 `.uix` 文件并通过 `uix_app!` 构造应用：

```uix
// 顶层声明区：样式类与主题
baseButton {
  backgroundColor: white;
  borderRadius: 8px;
  padding: 16px;
}

@theme dark {
  primaryColor: #64B5F6;
  backgroundColor: #121212;
}

<App title="样式示例" size="400x300" theme="dark">
  <Container direction="column" gap="12px" padding="20px">
    <Button class="baseButton" type="primary">主题按钮</Button>
    <Button @click="setTheme('light')">切换主题</Button>
  </Container>
</App>
```

- **样式类**：`类名 { 属性: 值; }` 定义在顶层，`class` 属性引用。
- **主题**：`@theme` 定义、`<App theme="...">` 指定、`setTheme('主题名')` 切换（详见[主题](../规范/样式与主题.md)）。

已登记能力具有确定的 Rust 语义映射：UIX Lang 是 Rust 声明式 API 的编译期文本投影。尚未登记的组件属性不进入可复制示例；当前可用性查[参考](../README.md#参考)，未来方案查[设计与变更入口](../README.md#设计指南与变更)。

工具链由共享 `uix-lang-compiler` Compiler System 提供：`uix check [--target auto|view|app|items] file.uix`、`uix fmt file.uix`、`uix compile --target view|app|items file.uix`、`uix query ...`。编辑器语言服务器使用独立二进制 `uix-lang-ls`（或 `uix lsp` 子命令，两者同一实现）：stdio 通信，支持内存 overlay，并在内容与磁盘一致时保留递归 `@import` 检查；启动方式与能力清单见[语言服务器](语言服务器.md)。
