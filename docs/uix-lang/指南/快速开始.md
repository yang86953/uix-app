# UIX 编译快速开始

[← 返回语言索引](../README.md)

本页使用框架自身的 `Canvas` 节点说明文件编译流程，不需要具体组件库。UIX 描述在构建期生成 Rust；普通宏只读取生成文件，不接收旧的内嵌源码字符串。

## 依赖

应用与框架源码目录同级时，Cargo.toml 可写：

```toml
[dependencies]
uix-app = { path = "../uix-app", default-features = false, features = ["ui"] }

[build-dependencies]
uix-app = { path = "../uix-app", default-features = false, features = ["lang-build"] }
```

## 源文件

创建 `ui/main.uix`：

```uix
<Canvas width="120" height="40" paint={paint_sample} />
```

`paint_sample` 是调用方提供的 Rust 函数。Canvas 的属性与限制由本仓库 [框架节点](../参考/框架节点.md#canvas-画布) 维护。

## 构建脚本

创建 `build.rs`：

```rust
fn main() -> Result<(), String> {
    uix_app::lang::build::Builder::from_env()?
        .compile("ui/main.uix", uix_app::lang::build::OutputKind::View)?;
    Ok(())
}
```

Builder 追踪源文件与导入依赖，将生成结果写入 Cargo 的 `OUT_DIR`；不在原源码目录写入生成 Rust。

## Rust 使用

在 `src/main.rs` 中消费生成的 View：

```rust
use uix_app::prelude::*;

fn paint_sample(frame: Rect, context: &mut PaintContext) {
    context.fill_rect(frame, Color::from_rgb(32, 96, 160), None);
}

fn main() {
    let _view: ViewNode = uix_app::uix!("ui/main.uix");
}
```

`cargo check` 可验证这条编译链。示例仅构造 View，不创建窗口；窗口应用将该 View 交给 `App`，并选择 `application` 与目标图形后端。

## 其它输出形状

| 源文件用途 | `OutputKind` | 读取宏 |
| --- | --- | --- |
| View | `View` | `uix!` |
| App builder | `App` | `uix_app!` |
| Record / Visual 等模块项 | `Items` | `uix_items!` |
| 可移植模块 | `Module` | `uix_module!` |

宏路径相对调用 crate 的 `CARGO_MANIFEST_DIR`，并与 build.rs 的声明一致。不存在的生成物不能靠宏在运行时补编译。

## 使用组件库

应用需要外部组件标签时，在项目配置登记候选库，编译器加载其属性与类型声明。框架侧配置和校验见 [组件库登记](../规范/组件库登记.md)；具体控件 API 不在语言编译指南重复维护。

正式交付使用 [按需构建](../../架构/使用方按需编译.md)，动态模块另按 [模块规范](../规范/应用模块.md) 显式启用。
