# 版本策略

[← 返回 UIX Lang 索引](../README.md)

> **接口**：声明 UIX Lang 的语言版本口径与兼容性承诺。依赖：[编译契约](../规范/编译契约.md)。导出：[变更日志](CHANGELOG.md)。

## 版本号

- 语言版本跟随根 crate 版本：当前 **0.0.1**。
- 语言能力变更按语义化版本三要素登记：新增能力（minor）、修复/收窄（patch）、破坏性变更（major）；0.x 阶段以 0.0.1 为基线在[变更日志](CHANGELOG.md)逐条登记。

## 兼容性承诺

1. **已登记能力不静默降级**：已登记的标签、属性、事件、样式属性在相同 capability 配置下保持可用；确需变更时走「废弃期 → 移除」流程，废弃提示必须指向替代入口。
2. **未登记能力编译诊断**：任何未登记或规划中的能力使用时得到带位置与修复建议的编译期诊断，不生成占位 View、不静默回退。
3. **宏入口契约稳定**：`uix!` 永久保持 `ViewNode` 契约；`uix_app!` 永久返回现有 `App` builder（不调用 `.run()`）；`uix_items!` 生成模块级结构体。
4. **语义等价承诺**：语言结构与 Rust 声明式 API 的映射保持语义等价；等价性回归由自动化测试与真窗验收共同覆盖。
5. **目标设计与实现分离**：[目标设计](目标设计.md)内容在实现前不产生兼容性承诺；实现后回填规范正文并在变更日志登记。

## 变更登记流程

1. 规范正文（[规范/](../规范/总览.md)）先行更新为已实现事实。
2. [变更日志](CHANGELOG.md) 登记条目（日期、范围、关联任务/提交）。
3. 更新 [README](../README.md) 摘要与文档地图。
4. 链接检查门禁通过（`python tests/test_check_docs_links.py -q`）。
