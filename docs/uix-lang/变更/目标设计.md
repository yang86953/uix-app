## 背景与动机

本设计建立时，UIX Lang 的组件组合、表达式错误回映、主题和样式状态存在结构性缺口。方案把改动限制在 `uix-derive` 编译期转换 Module（解析、展开与诊断）；伪类和主题 token 只消费既有运行时事实，插槽采用纯编译期展开，不新增运行时契约。

## 设计 1：内容插槽（Slot）

> **实现状态**：已于 2026-08-15 完成并回填[组件规范](../规范/组件.md#61-内容插槽slot)。

### 语法

组件体用 `<Slot />` 占位，调用方子节点按 `slot` 属性归位：

```uix
// 声明 Panel 模板引用的卡片样式类。
panelCard {
  // 为面板内容提供统一内边距。
  padding: 16px;
// 结束卡片样式类声明。
}

// 组件定义：默认插槽 + 具名插槽
<Widget name="Panel" props="title: String">
  // 使用当前文档已声明的面板样式。
  <Container class="panelCard">
    // 展示调用方传入的标题 prop。
    <Text>{title}</Text>
    // 声明唯一默认插槽。
    <Slot />
    // 声明 footer 具名插槽。
    <Slot name="footer" />
  // 结束面板模板容器。
  </Container>
// 结束面板组件声明。
</Widget>

// 调用方：无 slot 属性的子节点 → 默认插槽；slot="footer" → 具名插槽
<Panel title="用户信息">
  // 无 slot 属性的文本进入默认插槽。
  <Text>主体内容…</Text>
  // 带 footer 归位属性的容器进入具名插槽。
  <Container slot="footer">
    // 使用 Text 承载容器中的操作区文字。
    <Text>操作区</Text>
  // 结束 footer 内容容器。
  </Container>
// 结束组件调用根。
</Panel>
```

### 语义契约

- 插槽内容在**调用方作用域**求值（沿用「逐字嵌入、调用处可见」语义，不看见组件私有 state）；编译为组件模板占位处内联调用方子节点代码。
- 组件体可声明零个或一个默认插槽、零个或多个具名插槽。
- 调用方无子节点时占位渲染为空，不报错。
- For 内调用插槽组件：插槽内容在调用方循环体内展开；0.0.1 收口已让有状态组件以完整 key / 位置路径建立逐实例作用域，当前契约以[控制流规范](../规范/控制流.md#3-与组件私有状态的组合)为准。
- 插槽展开不引入运行时机制，纯编译期代码内联。

### 诊断

- 未声明插槽的组件接收子节点：编译期诊断（现有行为保留）。
- 子节点 `slot` 名不存在于组件体声明：编译期诊断，指向子节点位置。
- 组件体重名插槽、重复默认插槽、`slot` 属性非字符串字面量：编译期诊断。

## 设计 2：错误回映与组件封装边界

> **实现状态**：已于 2026-08-15 完成，当前契约见[编译契约](../规范/编译契约.md)与[组件](../规范/组件.md#21-外部依赖external)。

### 2a. 表达式错误定位到 .uix 源

- `uix!` / `uix_app!` 展开时把生成代码写入 `$OUT_DIR/uix-lang-gen/<文档名>.rs` 并 `include!`；生成文件每段表达式前插入 `// [uix-lang] main.uix:12:5` 映射注释。
- Rust 编译错误指向生成文件路径与行号，映射注释可精确回溯 .uix 源位置；生成代码可查看、可调试。
- 生成文件内容确定性（同一输入→同一输出），增量编译稳定；解析期诊断继续使用 SourceSpan 报 .uix 原生位置。
- 稳定 Rust 可达；nightly span API 已记录为否决项。

### 2b. 组件封装边界：external 依赖声明

```uix
<Widget name="SearchBox" props="onSearch: (String)"
           external="debounce, format">
  <Input @change="debounce(onSearch, 300)" />
  <Text>{format(count)}</Text>
</Widget>
```

- 组件体标识符检查：`标识符集 − props − state − computed − 内置操作 − 数据类型构造 − external = ∅`，否则宏内报「未声明的外部符号」（精确位置 + 修复建议）。
- 组件库作者获得可验证封装边界：引用遗漏从 Rust 侧神秘错误变成宏内精确诊断；调用处只需提供声明的符号，可见性仍由 Rust 兑底。
- 保留「调用处可见即可调用」便利：external 显式声明后正常引用。

## 设计 3：数组操作扩展与受限闭包

> **实现状态**：已于 2026-08-15 完成并回填[表达式规范](../规范/表达式.md#数组操作)。

### 操作表

| 操作 | 示例 | 语义 |
|---|---|---|
| `push` | `items.push(v)` | 追加（现有） |
| `removeAt` | `items.removeAt(i)` | 按下标删除（现有） |
| `insertAt` | `items.insertAt(i, v)` | 指定下标插入 |
| `updateAt` | `items.updateAt(i, v)` | 替换指定下标元素 |
| `removeBy` | `items.removeBy(\|it\| it.id == id)` | 按谓词删除首个匹配 |
| `filter` | `items.filter(\|it\| it.done)` | 过滤，返回新数组 |
| `map` | `items.map(\|it\| it.name)` | 映射，返回新数组 |
| `sortBy` | `items.sortBy(\|it\| it.order)` | 稳定升序排序，返回新数组 |
| `find` | `items.find(\|it\| it.id == id)` | 首个匹配，返回 Option |

全部保持不可变更新语义：克隆后修改并返回新数组，调用方绑定不被移动。

### 受限闭包

- 语法：`|参数名| 表达式`——单参数、单表达式，允许捕获调用处符号（自动借用，Rust 兑底）。
- **仅允许出现在数组操作方法参数位置**，其他位置编译期诊断。
- 编译为 `#items.clone().into_iter().filter(...)` 形状；数组元素类型由 Rust 推断。

## 设计 4：派生状态（computed）

> **实现状态**：已于 2026-08-15 完成并回填[组件规范](../规范/组件.md#31-派生值computed)。

```uix
<Widget name="TodoList" state="items: Vec<String> = [], keyword: String = ''"
           computed="filtered: items.filter(|it| it.contains(keyword)),
                     remaining: items.length">
  <Text>剩余 {remaining}</Text>
  <For {it} in {filtered}>…</For>
</Widget>
```

- 语法：`computed="名称: 表达式, …"`；表达式可引用 props、state 与**先声明的 computed**（按声明顺序约束，天然无环）。
- 语义：组件体展开时按声明顺序生成 let 绑定（渲染时求值，无缓存承诺；静态展开天然零运行时开销）；不引入依赖追踪。
- 诊断：引用未声明标识符、后向引用 → 编译期错误。

## 设计 5：主题 token 全量扩展

> **实现状态**：已于 2026-08-15 完成并回填[样式与主题规范](../规范/样式与主题.md#4-主题)。

- `@theme` 白名单从 `primaryColor` / `backgroundColor` 扩展为运行时设计 token 全集（colorText 四级、colorBorder、colorBgContainer 等，实现时逐项对齐 `design_tokens` 实际字段清单）。
- 语法不变：`@theme light { colorText: #333; }` + 样式值 `#colorText` 引用；未知 token 名编译期诊断（闭合契约保留）。

## 设计 6：状态伪类与叠加语义

> **实现状态**：已于 2026-08-15 完成并回填[样式与主题规范](../规范/样式与主题.md#11-状态伪类)。

```uix
baseButton { padding: 8px 12px; backgroundColor: white; }
baseButton:hover { backgroundColor: #e6f4ff; }
baseButton:disabled { opacity: 0.5; }
baseButton:checked { borderColor: #1677ff; }
```

- 语法：`类名:状态 { … }` 状态变体，状态白名单 `:hover` / `:disabled` / `:checked`，与基础类同名同前缀，编译期登记。
- **叠加而非替换**：变体只覆盖声明字段，未声明字段沿用基础类（隐含 extends）——修复现有 `setStyle`「整体替换丢基础样式」的坑。
- 状态来源为运行时既有事实（指针悬停、disabled、checked），不新增运行时契约。
- 编译：hover 变体 → 自动生成样式切换（复用动态样式机制，改叠加语义）；disabled / checked → 按运行时状态选择分支。
- `setStyle` 保留，定位收敛为「自定义动态切换」，文档明确与伪类分工。

## 设计 7：语法小项补齐

> **实现状态**：已于 2026-08-15 完成；条件链、事件载荷、prop 默认值与扩展类型契约分别回填[控制流](../规范/控制流.md)、[事件参考](../参考/事件.md)和[组件规范](../规范/组件.md)。

### 7a. If / ElseIf / Else

```uix
<If {a}>A</If><ElseIf {b}>B</ElseIf><Else>C</Else>
```

- 解析器把相邻 `<ElseIf {c}>` / `<Else>` 与前一个 `<If>` 配对（允许空白与注释间隔，不允许其他元素间隔）；编译为单次短路条件链。
- 孤立 ElseIf / Else、重复 Else → 编译期诊断。

### 7b. 事件载荷登记表

- 文档按事件类型登记 `$event` 字段（click: x / y；change: value；keyDown: key / code 等，对齐[事件参考](../参考/事件.md)）。
- `$event.字段` 编译期校验，未知字段 → 编译期诊断。

### 7c. props 默认值与必填

```uix
// 声明带默认 label 与必填回调的确认按钮组件。
<Widget name="ConfirmButton" props="label: String = '确定', onClick: ()">
  // 点击时调用使用方传入的回调并显示默认或显式标签。
  <Button type="primary" @click="onClick()">{label}</Button>
// 结束确认按钮组件声明。
</Widget>

// 省略有默认值的 label，只传入必填回调。
<ConfirmButton onClick={confirm} />
```

- 语法：`名: 类型 = 默认表达式`（默认表达式限字面量与数据类型构造）；无默认值即必填。
- 调用缺失必填 prop → 编译期诊断（扩展现有 `validate_widget_attributes`）。

### 7d. 状态类型白名单扩展

- `Vec<T>` 支持数组字面量初始值（`['a', 'b']`）与元素类型扩展（number / record）。
- `Option<String>` 支持 `Some('x')` 显式构造。
- Record 字段支持嵌套 record 与集合字段。
