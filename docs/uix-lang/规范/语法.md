# 语法

[← 返回 UIX Lang 索引](../README.md)

> **接口**：声明 UIX Lang 的目标文档结构与元素文法，包括类型、结构化组件成员、Action、Service、App 路由和窗口。依赖：[词法](词法.md)。导出：[表达式](表达式.md)、[组件](组件.md)、[控制流](控制流.md)、[模块系统](模块系统.md)。
>
> **状态声明**：目标契约，分项状态见正文。当前编译器已实现既有元素、字符串 props / state / computed / actions、Record、同步 action、If / For 与模块导入；结构化声明、Enum、Function / Service、异步 action、App 流程仍处于**目标**或**迁移中**。目标示例不可作为当前可编译示例，当前入口见[快速开始](../指南/快速开始.md)。

## 1. 状态标记

| 状态 | 含义 |
|---|---|
| **已实现** | 当前转换器已经登记并有 AOT 消费者证据 |
| **迁移中** | 旧语法已实现，本文冻结替代语法；实现期间两者降低到同一 AST |
| **目标** | 语义和文法已冻结，但当前转换器尚未登记 |

## 2. 目标文档 EBNF

```ebnf
document          := import_decl* declaration* root_element

declaration       := export_decl
                   | style_class
                   | theme_block
                   | record_def
                   | enum_def
                   | function_def
                   | service_def
                   | widget_def

import_decl       := '@import' '(' string_literal
                       (',' string_literal)* ')'
export_decl       := '@export' '(' string_literal
                       (',' string_literal)* ')'

style_class       := class_name '{' style_declaration* '}'
theme_block       := '@theme' identifier '{' theme_declaration* '}'

record_def        := '<Record' name_attr '>' field_decl* '</Record>'
field_decl        := '<Field' name_attr type_attr '/>'

enum_def          := '<Enum' name_attr '>' variant_decl+ '</Enum>'
variant_decl      := '<Variant' name_attr fields_attr? '/>'

function_def      := '<Function' name_attr binding_attr
                       params_attr? returns_attr '/>'

service_def       := '<Service' name_attr binding_attr '>'
                       method_decl+
                     '</Service>'
method_decl       := '<Method' name_attr params_attr? returns_attr
                       error_attr? async_attr? '/>'

widget_def        := '<Widget' name_attr '>'
                       widget_member* node+
                     '</Widget>'
widget_member     := prop_decl
                   | state_decl
                   | computed_decl
                   | action_decl

prop_decl         := '<Prop' name_attr type_attr default_attr? '/>'
state_decl        := '<State' name_attr type_attr value_attr '/>'
computed_decl     := '<Computed' name_attr value_attr '/>'
slot_decl         := '<Slot' name_attr? '/>'

action_decl       := '<Action' name_attr params_attr? returns_attr?
                       async_attr? concurrency_attr?
                     '>' action_block '</Action>'
action_block      := 'do' '{' statement* '}'

app_element       := '<App' app_attribute* lifecycle_event* '>'
                       app_member* app_content
                     '</App>'
app_member        := state_decl
                   | computed_decl
                   | action_decl
                   | window_decl
routes_decl       := '<Routes' initial_attr '>' route_decl+ '</Routes>'
route_decl        := '<Route' name_attr params_attr? '>' node+ '</Route>'
window_decl       := '<Window' name_attr window_attribute* '>'
                       window_member* node+
                     '</Window>'
window_member     := state_decl | computed_decl | action_decl
app_content       := routes_decl | node+

root_element      := app_element | element
element           := '<' tag_name attribute* '>' node* '</' tag_name '>'
                   | '<' tag_name attribute* '/>'
node              := element
                   | text_node
                   | expression_interpolation
                   | view_control_flow
                   | slot_decl
view_control_flow := if_chain | for_element
if_chain          := if_element elseif_element* else_element?
if_element        := '<If' '{' expression '}' '>' node* '</If>'
elseif_element    := '<ElseIf' '{' expression '}' '>' node* '</ElseIf>'
else_element      := '<Else>' node* '</Else>'
for_element       := '<For' '{' identifier '}' ('{' identifier '}')?
                       'in' '{' expression '}'
                       ('key' '=' '{' expression '}')?
                     '>' node* '</For>'
```

状态：元素、属性、样式、主题、Widget、Record、If / For 和既有 App 属性**已实现**；结构化 Field / Prop / State / Computed / Action、Enum、Function、Service、Routes 与 Window 为**目标**。

## 3. 类型语法

```ebnf
type_ref          := primitive_type
                   | semantic_type
                   | identifier
                   | 'Vec' '<' type_ref '>'
                   | 'Option' '<' type_ref '>'
                   | 'Result' '<' type_ref ',' type_ref '>'
                   | 'State' '<' type_ref '>'

primitive_type    := 'String' | 'bool' | 'number' | 'u32'
                   | 'usize' | 'f32' | 'i32' | '()'
semantic_type     := 'Date' | 'Time' | 'Color' | 'Point'
                   | registered_semantic_type
parameter_list    := parameter (',' parameter)*
parameter         := identifier ':' type_ref
```

公共 Prop、State、Action、Function、Service、Route 和 Window 参数必须显式声明类型；Action 内局部 `let` 允许从初始化表达式推断。缺失值使用 `Option<T>`，语言不增加隐式 `null`。

当前编译器已实现基础类型、部分登记语义类型、`State<T>`、特定 `Vec<T>`、`Option<String>` 和 Record；递归通用 `TypeRef`、Enum、通用 Option / Result 为**目标**。

## 4. 结构化组件成员

目标 Widget 以结构化子节点声明输入、状态、派生值与 action，声明必须位于第一个可渲染节点之前：

```uix
// 目标语法：当前尚不可编译。
<Widget name="TodoPage">
  <Prop name="filter" type="TodoFilter" default="TodoFilter.All" />
  <State name="todos" type="Vec<Todo>" value="[]" />
  <Computed name="visible" value="todos.filter(|todo| !todo.completed)" />

  <Action name="load" async="true"
          returns="()" concurrency="drop">
    do {
      // action 语句
    }
  </Action>

  <Column>...</Column>
</Widget>
```

旧 `props`、`state`、`computed`、`actions` 属性为**迁移中**：当前仍是唯一可编译形式；结构化节点实现后，两种表面必须立即降低到同一 AST。`0.0.1` 收口时移除旧解析路径并保留定向迁移诊断。

## 5. Action 语法

```ebnf
statement         := let_statement
                   | assignment
                   | expression_statement
                   | if_statement
                   | match_statement
                   | for_statement
                   | break_statement
                   | continue_statement
                   | return_statement

let_statement     := 'let' identifier '=' expression ';'
assignment        := identifier '=' expression ';'
expression_statement := expression ';'
if_statement      := 'if' expression action_block
                       ('else' (if_statement | action_block))?
match_statement   := 'match' expression '{' match_arm+ '}'
match_arm         := pattern '=>' action_block
for_statement     := 'for' identifier 'in' expression action_block
break_statement   := 'break' ';'
continue_statement:= 'continue' ';'
return_statement  := 'return' expression? ';'
await_expression  := 'await' expression ('within' duration_literal)?
```

当前 `let`、局部赋值、表达式语句、`if / else` 和 `return` **已实现**。参数、返回类型、`match`、Action 内 `for`、`break / continue`、`await`、超时和并发策略为**目标**。

async action 默认 `concurrency="drop"`，可选 `restart` 或 `parallel`。服务 await 的显式结果为 `Ok`、`Err`、`Cancelled`、`TimedOut`；`match` 对 Enum、Option、Result、AwaitOutcome 和 bool 执行穷尽性检查。渲染与 Computed 必须无 Effect；状态更新、服务调用、导航、窗口和反馈只允许出现在 Action 或生命周期入口。

## 6. Function 与 Service

```uix
// 目标语法：当前尚不可编译。
<Service name="todosService" binding="todo_service">
  <Method name="load"
          params="filter: TodoFilter"
          returns="Vec<Todo>"
          error="TodoError"
          async="true" />
</Service>

<Function name="matchesFilter"
          binding="matches_filter"
          params="todo: Todo, filter: TodoFilter"
          returns="bool" />
```

Function 是同步纯扩展；Service 表达有副作用或异步能力。两者在宏调用处编译期绑定 Rust 符号，AOT 生成直接调用，不建立生产字符串服务注册表。Widget `external` 为**迁移中**，最终由 Function、Service 或显式根输入替代。

## 7. App、路由与窗口

```uix
// 目标语法：当前尚不可编译。
<App title="待办" @start="bootstrap()" @shutdown="flushLocal()">
  <Routes initial="Home">
    <Route name="Home"><TodoPage /></Route>
    <Route name="Detail" params="todo: Todo">
      <TodoDetail todo={route.todo} />
    </Route>
  </Routes>

  <Window name="Settings" title="设置">
    <SettingsPage />
  </Window>
</App>
```

路由使用类型化构造器 `navigation.go(Detail(todo: item))`，窗口使用 `windows.open(Settings())`。未知目标、缺失参数和错误参数类型必须在生成前诊断。App、Window、Route 和 Widget 分别拥有明确状态与任务生命周期。

当前 `<App>` 的 `title`、`size`、`theme`、`settings` 和单根 View **已实现**；生命周期事件、App state / action、Routes、Route、Window 和对应内建能力为**目标**。

## 8. 现行可编译文法

迁移期间，当前编译器继续接受以下既有形状：

```ebnf
current_document  := current_declaration* current_root
current_declaration := import_decl | export_decl | style_class
                     | theme_block | current_widget | current_record
current_widget    := '<Widget' name_attr
                       props_attr? state_attr? computed_attr?
                       actions_attr? external_attr?
                     '>' node* '</Widget>'
current_record    := '<Record' name_attr fields_attr '/>'
current_action    := identifier ':' (expression | 'do' current_action_block)
current_action_block := '{' current_statement* '}'
current_statement := let_statement | assignment | expression_statement
                   | if_statement | return_statement
current_root      := element | current_app
```

当前可复制写法以[组件](组件.md)、[快速开始](../指南/快速开始.md)和[教程](../指南/教程.md)中的“已实现”示例为准。目标语法实现前，使用结构化声明、Service、异步 Action、Routes 或 Window 必须得到带位置和计划状态的编译诊断，不生成占位代码。
