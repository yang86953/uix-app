## 1. 受限表达式

表达式是**受限表达式子集**，仅支持以下结构（编译时逐字嵌入 Rust 表达式，三元条件翻译为 `if/else` 表达式）：

| 结构 | 示例 | 说明 |
|---|---|---|
| 标识符路径 | `state.value`、`items` | 属性访问用 `.` |
| 索引 | `items[0].name` | 下标访问 |
| 字面量 | `18`、`'text'`、`true` | 单引号字符串 |
| 数组字面量 | `['female', 'male']`、`[SelectOption('中国', 'cn')]` | 编译为 `vec![...]`；元素任意受限表达式，无尾随逗号 |
| 数据类型构造 | `SelectOption('中国', 'cn')`、`Step('注册').status('finish')` | 见[词法 · 数据类型构造](词法.md#32-数据类型构造)登记表；编译为公开 `new` 与成员链 |
| 算术 | `count + 1`、`total * 0.5` | `+ - * / %` |
| 比较 | `count > 0`、`name == 'UIX'` | `== != < > <= >=` |
| 逻辑 | `a && b`、`!done` | `&& \|\| !` |
| 三元 | `condition ? 'A' : 'B'` | 编译为 Rust `if/else` 表达式 |
| 数组操作 | `todos.push(item)`、`todos.filter(\|it\| !it.done)` | 更新类操作返回新数组；查询类操作返回新值，均不移动调用方数组 |
| 受限闭包 | `items.filter(\|it\| it.active)` | 单参数、单表达式；仅允许作为指定数组操作的参数 |
| 调用 | `onConfirm()`、`formatCount(count)`、`setState(...)` | Rust 侧可见函数、回调 props 与内置操作 |
| 事件上下文 | `$event`、`$event.x` | 仅事件属性处理器可用；载荷由 `(标签, 事件名)` 登记，见[事件参考](../参考/事件.md) |
| 结构属性对象 | `{ count: 7, dot: false }` | 键必须是唯一标识符；通用结构属性不接受嵌套对象，类型化 record 初始值可按字段类型递归嵌套 |

### 数组操作

当前实现：

| 操作 | 示例 | 语义 |
|---|---|---|
| `push` | `items.push(v)` | 克隆后追加并返回新数组 |
| `removeAt` | `items.removeAt(i)` | 克隆后按下标移除并返回新数组 |
| `insertAt` | `items.insertAt(i, v)` | 克隆后在指定下标插入并返回新数组 |
| `updateAt` | `items.updateAt(i, v)` | 克隆后替换指定下标元素并返回新数组 |
| `removeBy` | `items.removeBy(\|it\| it.id == id)` | 克隆后删除首个谓词匹配项并返回新数组 |
| `filter` | `items.filter(\|it\| it.active)` | 基于克隆数组过滤并收集新数组 |
| `map` | `items.map(\|it\| it.name)` | 基于克隆数组映射并收集新数组 |
| `sortBy` | `items.sortBy(\|it\| it.order)` | 克隆后按键稳定升序排序并返回新数组 |
| `find` | `items.find(\|it\| it.id == id)` | 在克隆数组中返回首个匹配项 `Option<T>` |

`removeBy` / `filter` / `map` / `sortBy` / `find` 接受 `|参数名| 表达式` 形状的受限闭包。闭包可读取组件字段、先声明的 computed、`external` 与 Rust 调用点符号；闭包参数建立独立词法作用域且可遮蔽同名组件字段。闭包不带 `move`，元素类型、捕获借用与最终返回类型由 Rust 检查。闭包出现在其他操作或独立表达式位置时，转换器返回定向诊断。

## 2. 标识符来源（编译语义）

文档根表达式中的**字符串字面量**（单引号）由转换器词法翻译为 Rust 双引号字符串，其余标识符由宏调用处的 Rust 作用域解析。Rust 侧的函数、闭包、`use` 导入符号与局部变量皆可直接引用，类型检查与借用检查由 Rust 编译器完成。

组件体引用 Rust 侧符号须在组件定义处经 `external` 声明（见[组件](组件.md#21-外部依赖external)），或由回调 props 显式传入。`$event` 是事件处理器注入的保留 token，不从 Rust 调用处解析，也不能经 `external` 声明。Rust 符号是 UI 到业务 System 的边界，不会被转换成 UIX Lang 内的 Service。

除数组操作参数中的单参数受限闭包外，普通表达式不支持独立闭包、`match`、任意未类型化对象、计算键、spread、对象方法、类型标注或语句。嵌套对象仅在已声明 record 字段约束下可用；局部界面交互可使用组件 `actions` 的 `do { ... }` 语句面。业务判断、异步流程和服务调用必须由 Rust 实现，边界见[语言边界](../设计/语言边界.md)。

```uix
<Text>{state.value}</Text>
<Text>{items.length}</Text>
<Text>{items[0].name}</Text>
<Text>{condition ? 'True' : 'False'}</Text>
```

## 3. 内置操作

| 操作 | 语法 | 说明 |
|---|---|---|
| `setState` | `setState(name: 值)` | 更新当前 Widget 的私有 state 或显式 `State<T>` prop；其他目标拒绝 |
| `setTheme` | `setTheme('主题名')` | 框架内置：生成主题请求通道调用（`dark` 切暗色、其余回亮色），不依赖调用方同名函数 |
| `setStyle` | `setStyle('样式类名')` | 组件内置：替换声明事件的当前 View 动态 class；`setStyle('')` 恢复元素原始 `class`，不依赖调用方同名函数 |

```uix
<Button @click="setTheme('dark')">切换到深色主题</Button>
```

`setStyle` 采用编译期闭合契约：参数必须是单个字符串字面量，非空名称必须引用同一 UIX 文档已声明的样式类；未知类、组件外调用及选择子节点或跨组件目标都会在编译期诊断。调用只改变声明该事件的当前 View，不提供选择器。

`setState` 只能在 Widget 作用域内使用，目标解析与所有权以[组件 · 状态输入与可写绑定](组件.md#22-状态输入与可写绑定)为准。它不会通过名称查找其他 Widget，也不会把普通值 prop 临时提升为状态句柄。

动态 class 层以元素原始 `class` 为初值，调用后整体替换；内联 `style` 始终作为更高优先级作者覆盖层保留。动态值由最近 UIX `Widget` 的私有状态持有，并按组件实例、实际节点 `key` 或稳定位置隔离；同一 key 与节点类型的 reconcile 保留值，key 或类型变化会释放旧值。编译器只生成可达类的类型化 `Style` 分支，不建立运行时字符串注册表。

```uix
normalAction { padding: 6px 12px; backgroundColor: #ffffff; }
hoverAction { padding: 8px 16px; backgroundColor: #e6f4ff; }

<Widget name="HoverAction">
  <Button class="normalAction" style="color: #1677ff;"
          @mouseEnter="setStyle('hoverAction')"
          @mouseLeave="setStyle('')">
    悬停并恢复
  </Button>
</Widget>

<HoverAction />
```

`@mouseEnter` 与 `@mouseLeave` 不提供点击载荷 `$event`；处理器执行后继续把 `PointerEnter`/`PointerLeave` 交给组件自身与父节点。动态分支可使用样式参考中全部已映射字段；布局字段变化会随结构协调触发布局更新，而不局限于颜色重绘。

## 4. 职责边界

| 上下文 | 允许内容 |
|---|---|
| View 属性、文本插值、If / For 数据源 | 读取界面输入和状态，执行展示所需的受限计算 |
| Computed | 只读展示派生，不写状态、不调用业务能力 |
| 同步 action | 更新局部界面状态、调用内置 UI 操作、转发 Rust 回调 |
| Rust 回调 | 业务规则、领域状态转换、I/O、异步、导航和生命周期 |

`match`、`await`、Service、重试、事务和业务 Effect 不作为表达式目标。复杂业务分支应封装在 Rust 函数或 Application System 中，UIX Lang 只读取其结果或触发窄回调。
