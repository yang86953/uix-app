## 1. 命名规范

- **标签名**：PascalCase（如 `<Button>`、`<Container>`、`<Text>`），对应内置或自定义组件名。
- **属性名**：camelCase（如 `class`、`fontSize`）；样式属性名与[样式属性参考](../参考/样式属性.md)一致。
- **样式类名与主题名**：camelCase 或 PascalCase（如 `baseButton`、`featureCard`）。
- **普通标识符**：以字母或 `_` 开头，后续可为字母、数字、`_`、`$`；不能以 `$` 开头。
- **事件上下文 token**：`$event` 是唯一允许以 `$` 开头的保留 token，不是普通标识符。它只在事件属性的处理器表达式中存在，不能出现在文本插值、computed、action 声明或普通属性表达式中。

`do`、`let`、`if`、`else`、`return` 在同步 action 的语句上下文中是关键字；它们不改变普通受限表达式的词法结构。其他 `$name` 形状一律拒绝并提示改用普通标识符；`$event` 的载荷契约见[事件参考](../参考/事件.md)。成员声明块的字符串值仍使用单引号。

**成员块前缀**：`@props`、`@state`、`@computed`、`@actions` 是 `<Widget>` 模板内的保留块前缀，紧跟 `{ }` 声明体（见[语法 · Widget 成员](语法.md#2-widget-成员)）。这四个名称必须整体作为块前缀识别；组件模板文本中的其他 `@name {` 形状保持普通文本语义。

## 2. 注释

- **单行注释**：`//` 至行尾。
- **多行注释**：`/* ... */`，不可嵌套。

```uix
// 单行注释
<Button>点击</Button>
/* 多行注释
   跨行内容 */
```

## 3. 字面量

| 字面量 | 示例 | 说明 |
|---|---|---|
| 字符串 | `'text'` | **统一单引号**（与属性值双引号区分，见下）；文本中出现字面 `{` 时写作 `\{` |
| 数字 | `18`、`1.5`、`100px` | 长度值带单位 |
| 颜色 | `#FF5722`、`rgba(0,0,0,0.1)`、`red` | 与[样式属性参考](../参考/样式属性.md)一致 |
| 布尔 | `true`、`false` | — |

**引号规则**：双引号只用于包裹属性值（`属性名="值"`）；表达式、样式值、指令参数中的字符串字面量统一使用**单引号**（`'...'`），避免与属性值包裹符冲突。

**编译翻译**：表达式中的单引号字符串字面量在编译期由转换器**词法翻译**为 Rust 双引号字符串（`'text'` → `"text"`）；标识符与其余结构逐字嵌入，不做名称解析。

### 3.1 数组字面量

方括号书写按源码顺序排列的元素，编译为 Rust `vec![...]`，元素类型由消费方推断。元素可以是任意受限表达式，包括字符串、数字与数据类型构造链：

```text
options={['female', 'male']}
items={[TimelineItem('创建').description('2026-08-01')]}
```

数组元素之间用逗号分隔，不允许尾随逗号；空数组写作 `[]`。

### 3.2 数据类型构造

下列已登记数据类型可用 `TypeName(位置参数)` 构造，编译为公开 API 的 `TypeName::new(...)` 调用，并可链式调用公开成员方法：

| 类型名 | 公开构造 | 成员链示例 |
|---|---|---|
| `SelectOption` | `SelectOption::new(label, value)` | `SelectOption('中国', 'cn')` |
| `CascaderOption` | `CascaderOption::new(label, value)` | `CascaderOption('浙江', 'zj').children([...])` |
| `TreeNode` | `TreeNode::new(title, key)` | `TreeNode('部门', 'dept').children([...])` |
| `TimelineItem` | `TimelineItem::new(label)` | `TimelineItem('创建').description('2026-08-01')` |
| `Step` | `Step::new(title)` | `Step('注册').status('finish')` |
| `DescriptionsItem` | `DescriptionsItem::new(label, value)` | `DescriptionsItem('姓名', 'Ada')` |
| `BreadcrumbItem` | `BreadcrumbItem::new(title)` | `BreadcrumbItem('导航').active()` |
| `AnchorItem` | `AnchorItem::new(label, href)` | `AnchorItem('基础', '#basic')` |
| `Tab` | `Tab::new(label)` | `Tab('账户').key('account')` |
| `SelectableItem` | `SelectableItem::new(id, text)` | `SelectableItem('sg', '新加坡').disabled()` |
| `CollapsePanel` | `CollapsePanel::new(header, content)` | `CollapsePanel('面板一', '内容一')` |
| `MenuItem` | `MenuItem::from_text(label, key)` | `MenuItem('设置', 'settings').children([...])` |
| `DropdownItem` | `DropdownItem::from_text(label, key)` | `DropdownItem('编辑', 'edit').icon('edit')` |
| `Date` | `Date::new(year, month, day)` | `Date(2026, 8, 10)` |
| `Time` | `Time::new(hour, minute)` | `Time(14, 30)` |
| `Color` | `Color::hex(value)` | `Color('#1677ff')` |
| `Point` | `Point::new(x, y)` | `Point(0.0, 0.0)`（整数参数自动规范化为小数） |

数据构造链中的字符串保持 `&str` 字面量形状；`Step.status` 接受字符串语义值 `'finish'` / `'process'` / `'wait'`，映射公开 `StepStatus` 枚举。未登记的 PascalCase 类型名保持普通 Rust 调用语义，由 Rust 类型检查兑底。

### 3.3 对象字面量

对象字面量仅服务于文档明确登记的结构属性，采用单层、标识符键和受限表达式值：

```text
badge={{ count: 7, dot: false }}
```

普通属性不会猜测目标 Rust 类型。

### 3.4 数据绑定 clone 语义

数据类属性（`options` / `items` / `data` / `images` / `actions` 等）按值 clone 消费调用方绑定，同一个绑定可安全地供多个标签复用，不会移动调用方集合。
