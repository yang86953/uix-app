## 文档边界

框架拥有图形 API、布局引擎、View 树、响应式机制、事件、平台、应用生命周期、语言及工具。具体控件、表单、虚拟列表、组件预设和资源由相应组件库独立维护；本仓库不保留它们的参考页或跨库跳转页。

框架集成接口可以使用组件库作为使用方示例，但编译器的组件登记合同、通用主题和绘制能力以框架自身接口说明，不依赖另一个仓库的文档正文。

## 维护方式

正文与索引随所属框架能力一起修改，内部链接使用仓库相对路径。同一仓库内按主题组织事实，跨库不共享文档入口。示例说明实际依赖和输出形状；代码示例变化按涉及接口验证，纯文字与导航修改检查内容、目标文件和锚点。

当前源码不提供旧 `runtime` 功能开关或旧内嵌 UIX 宏的兼容层。发布、平台和安全边界由 [交付与许可](产品/交付与许可.md) 维护。
