# 产品

> UIX 是什么、做到哪、做什么 / 不做什么。

## 定位

用 Rust 写的跨平台 App 框架。**全栈**：UI + 应用壳 + 本地 `data`（Settings）；**不含**网络 / 同步。声明式 UI 像 Web，跑原生窗口与绘制，空闲时真正休眠。

- 入口：`use uix::prelude::*`
- 目标：桌面 + 移动端共用同一套上层代码
- 写法 → [`使用.md`](使用.md)

## 当前阶段

**Windows 优先**做到生产可用（P6 gate → [`进度.md`](进度.md)）。桌面三端路径已就位但未均验收，移动端未做。交付先 Windows。

平台差异只在 `native` backend；上层只见 trait，禁 `use native::backends::*`。除 `native` 外禁止按 OS 分叉。

## 能力

主路径（写应用）：

| 做 | 说明 |
|----|------|
| 界面 | View + State + 组件 |
| 运行时托管 | Timer、动画、逐窗帧机会、`post_to_ui`、多窗、IME 会话由框架登记 / 清理 |
| 原生路径 | 窗口、输入、布局、绘制、主题、浮层、语义事件；不以 WebView 为运行时 |
| IME | 单行 / 多行；composition → commit。⚠️ 微软拼音真机验证未过（RISK-001），框架托管就绪但门禁待闭合 |
| Settings | KV **opt-in**；默认不 load/save；不进 UI 热路径 |
| 无障碍 v1 | 静态 ARIA + 键盘导航 |
| 图形 | 默认 Vulkan；失败须 **typed** 诊断后回 Software/CPU；禁静默换另一 GPU API |
| CLI | 可选 `AppMode::CLI`（非 GUI 主路径） |

附能力（显式启用；不改变主路径写法）：

| 做 | 说明 |
|----|------|
| 自动化测试 | `test-harness`：稳定 selector、语义 / 边界快照、无窗口 `TestApp`；真窗可经事件驱动 JSON 快照配合系统输入验收 |
| 大模型控制 | 开发预览：本机同用户语义 / 动作协议；双门禁启用后枚举窗口、读语义树、执行动作；空闲无轮询；敏感值不导出。设计 → [架构](架构.md#大模型控制协议)，缺口 → [`进度`](进度.md#附能力不计-p6) |

## 不做 · 暂缓 · 验收策略

| 类 | 项 |
|----|-----|
| **不做** | 网络 / 同步域；读屏桥；跨机器 / 跨用户远程控制服务；任意代码或文件操作；WebView 运行时；手写探活 / 重绘名单；独立 UI 脚本语言（现为 Rust API；无 JSX/模板/DSL） |
| **暂缓** | 移动端 backend；D3D12 完整扩展；Metal `GpuNative`（须图形契约闭合后） |
| **验收策略** | 不把 macOS 真机验收强行等同 Windows gate；Linux/macOS/移动端不计 P6 |

## 运行时与图形

**用最少资源，做最好效果。** 无待办 → 阻塞等待；失效只合并并申请本窗一次帧机会。隐藏/零尺寸或 surface 暂不可用时保留 dirty、暂停视觉帧；遮挡仅由可靠逐窗能力触发，无此能力的 recipe 必须 typed `Unsupported` 并依赖隐藏/最小化/零尺寸生命周期休眠，禁 DWM/帧机会冒充。优先等匹配恢复信号，有界探测须封顶、禁无上限轮询。typed 终端失败保持吸收直到窗口重建，禁 busy loop。窄 damage 须证明坐标与缓冲一致性；未证明则整帧提交优先于带宽猜测。无真实窗口/GPU 时须可测试验证。
