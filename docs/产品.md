## 内容摘要

UIX 是一个**跨平台原生 App 框架**：用 Rust 写一套声明式界面代码，在 Windows / Linux / macOS / 移动端原生窗口上运行。不绑定浏览器，不依赖 Web 技术栈。全栈指 UI + 应用壳 + 本地数据存储，不含网络与同步。

核心差异化：
- **原生绘制**：不套 WebView/Electron，每像素由 GPU 直接渲染
- **纯 Rust**：界面代码就是 Rust，无第二门语言
- **省资源**：空闲真休眠，不做多余绘制，不浪费内存
- **跨平台**：一套代码多平台
