# 产品

> UIX 是什么、做到哪、做什么 / 不做什么。

## 定位

用 Rust 写的跨平台 App 框架。**全栈**：UI + 应用壳 + 本地 `data`（Settings）；**不含**网络 / 同步。声明式 UI 像 Web，跑原生窗口与绘制，空闲时真正休眠。

- 入口：`use uix::prelude::*`
- 目标：桌面 + 移动端共用同一套上层代码
- 写法 → [`使用.md`](使用.md)

## 当前阶段

**Windows 优先**做到生产可用（P6 gate → [`进度.md`](进度.md)）。平台差异只在 `native` backend；上层只见 trait，禁按 OS 分叉（`#[cfg(OS)]` 仅限 `native/`）。

## 能力

主路径（写应用）：

| 做 | 说明 |
|----|------|
| 界面 | View + State + Computed + 组件；单行 / 多行 / 密码 Input、InputNumber、支持单选 / 多选与即时过滤的 Select、Radio、Segmented、Slider、Rate、支持禁用规则与 Date/Week/Month/Quarter 粒度的 DatePicker、双 State 与具名预设的 DateRangePicker、TimePicker、ColorPicker 及 Checkbox / Switch 值可由 State 托管，派生值可重建 / 条件渲染子视图，固定 logical 尺寸的轻量 canvas 可直接记录自定义绘制，24 单元响应式 Grid 按本容器 logical 宽度自动重排，盒模型、颜色、透明度与阴影由统一 View 样式链声明；ConfigProvider 配置继承、统一 Size 系统（Small/Middle/Large）、组件级令牌覆写 |
| 表单 | `Form::field` 链内联声明必填、邮箱、数值范围、字符长度、regex、自定义与字段依赖校验；规则可按 Submit / Change / Blur 激活，整表成功返回 typed `Values`；`Form::list` 以稳定行身份托管动态同构字段并自动请求结构 reconcile；业务校验闭包只属于应用侧模型 |
| 数据展示 | Table 提供表级 / 列级排序交互、可选行复选框、边框样式、左右固定列、双层分组表头、可交互 View 展开行与有界虚拟滚动；独立 `VirtualScroll` 按视口物化普通 View 行；运行态排序方向和选择结果进入结构化快照 |
| 主题 | 暗色 / 亮色主题自动跟随，`ThemeToggle` 一键切换；`DesignTokens` 覆盖色彩、字号、间距、阴影；公开 12×10 主色色板、自定义色板生成、13 阶中性色、功能色阶与数据可视化分类色板 |
| 国际化 | `Locale` / `LocaleProvider` 统一管理 30+ 组件文案，内置 `zh_cn()` / `en_us()` 预设，子树级覆写；组件渲染中通过 `use_locale()` 读取 |
| 剪贴板 | `copy_to_clipboard()` / `read_text_from_clipboard()` 读写系统剪贴板，受框架事件词法作用域托管，无活动事件时 no-op |
| 运行时托管 | Timer、逐窗动画帧机会、`post_to_ui`、多窗、IME 会话由框架登记 / 清理；`Animation<T>` 提供可配置缓动、暂停、重启与一次性完成回调 |
| 浮层 | `Modal::show(\|ctx\| View)` 以普通可交互子树声明内容，`ctx.close()` 只关闭所属 Modal 并保留退出动画；Modal / Drawer / Popover / Message / Notification 以 `AnimationConfig` 分别声明 enter / leave，离场完成后才移出本窗浮层栈；消息与通知逐项自动到期，持有期只登记最近截止时间，不持续申请帧；层级、遮罩与焦点陷阱由框架托管 |
| 窗口外观 | Windows 主窗与副窗可逐窗隐藏系统标题栏；应用用普通 View 自定义标题、图标和控制项，框架提供原生拖动、最小化、最大化 / 还原与安全关闭原语，控制项进入语义树且可自定义无障碍名称，并保留系统缩放边框 |
| 原生路径 | 窗口、输入、布局、绘制、主题、浮层、语义事件；上层客户区尺寸、布局与输入使用 logical 坐标，每窗 drawable 随 DPI 独立变化；不以 WebView 为运行时 |
| IME | 单行 / 多行；系统 composition → commit。Windows 微软拼音真实前台输入已过，框架托管会话与光标矩形，不自造候选管线 |
| Settings | KV **opt-in**；默认不 load/save；不进 UI 热路径 |
| 无障碍 v1 | 21 种 `AccessibilityRole` + `AccessibilityState`（disabled/checked/expanded/selected/value）+ `AriaAttribute`（Label/Description/ValueNow/Min/Max/Level/Placeholder/LiveRegion），组件自带默认 role；焦点陷阱 + Tab 序自动管理；password 字段不导出 |
| 图形 | 默认 Vulkan；logical viewport 与 physical drawable 分离；圆弧等矢量图元共享 Path 录制 / 重放；失败须 **typed**，`DeviceLost` 回收失效资源后有界回 Software/CPU；禁静默换另一 GPU API |
| 诊断 | `core` 层统一错误收集（`Collector`）、崩溃处理（`fatal`——panic → crash dump → `uix_crash.log`）、中间件管道（`LogMiddleware` / `RetryMiddleware`） |
| CLI | 可选 `AppMode::CLI`（非 GUI 主路径） |

附能力（显式启用；不改变主路径写法）：

| 做 | 说明 |
|----|------|
| 自动化测试 | `test-harness`：稳定 selector、语义文本 / 边界快照、无窗口 `TestApp`；真窗可经事件驱动 JSON 快照配合系统输入验收 |
| 大模型控制 | 开发预览：本机同用户语义 / 动作协议；双门禁启用后枚举窗口、读语义树、执行动作；空闲无轮询；敏感值不导出。设计 → [架构](架构.md#大模型控制协议)，缺口 → [`进度`](进度.md#附能力不计-p6) |

## 不做 · 暂缓

| 类 | 项 |
|----|-----|
| **不做** | 网络 / 同步域；读屏桥；跨机器 / 跨用户远程控制服务；任意代码或文件操作；WebView 运行时；手写探活 / 重绘名单；独立 UI 脚本语言（现为 Rust API；无 JSX/模板/DSL） |
| **暂缓** | 移动端 backend；D3D12 完整扩展；Metal `GpuNative`（须图形契约闭合后） |

## 运行时与图形

**用最少资源，做最好效果。** 空闲真休眠阻塞等待；连续工作仍逐轮分发 OS 事件；脏区合并，清屏与绘制共用引擎实际帧区，逐窗至多一个帧请求；不可呈现时保留状态、暂停帧；失败 typed，终态吸收不忙循环；damage 未证明一致性则整帧提交。无真窗/GPU 时可测试验证。
