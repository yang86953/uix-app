# 产品

> UIX 是什么、做到哪、做什么 / 不做什么。

## 定位

用 Rust 写的跨平台 App 框架。**全栈**：UI + 应用壳 + 本地 `data`（Settings）；**不含**网络 / 同步。声明式 UI 像 Web，跑原生窗口与绘制，空闲时真正休眠。

- 入口：`use uix::prelude::*`
- 目标：桌面 + 移动端共用同一套上层代码
- 写法 → [`使用.md`](使用.md)

## 当前阶段

**Windows 优先**做到生产可用（P6 gate → [`进度.md`](进度.md)）。桌面三端（Win / Linux / macOS）路径已就位，未均过生产验收；移动端未做。愿景跨平台，交付先 Windows。

平台差异只在 `native` backend；上层只见 trait，禁 `use native::backends::*`。除 `native` 外禁止按 OS 分叉，新平台只加 backend。

## 能力

| 做 | 说明 |
|----|------|
| 界面 | View + State + 组件；不维护命令式控件树或重绘名单 |
| 运行时托管 | Timer、动画、逐窗帧机会、`post_to_ui`、多窗、IME 会话由框架登记 / 清理 |
| 原生路径 | 窗口、输入、布局、绘制、主题、浮层、语义事件；不以 WebView 为运行时 |
| IME | 单行 / 多行；composition → commit；Windows 生产以系统 IME（含微软拼音）为门禁之一 |
| Settings | KV **opt-in**；默认不 load/save；不进 UI 热路径 |
| 无障碍 v1 | 静态 ARIA + 键盘导航 |
| 自动化测试 | `test-harness` 提供稳定 selector、语义 / 边界快照和无窗口 `TestApp`；真窗可按事件驱动 JSON 快照配合系统输入验收 |
| 大模型控制（开发中） | 所有 UIX 应用共用框架级本机语义 / 动作协议；`agent-control` feature + `.enable_agent_control()` 双门禁、共享动作 / 快照、逐窗 revision、有界 UI 队列 / settle、进程级窗口目录、带随机凭证的 Named Pipe / Unix Domain Socket，以及窗口级 `press_key` / `click_at` 兜底已落地；真窗端到端与跨用户拒绝证据仍待闭合（设计见[架构](架构.md#大模型控制协议)，[`AGENT-R1`](进度.md#未关闭)） |
| 图形 | 默认 Vulkan；失败须 **typed** 诊断后回 Software/CPU；禁静默换另一 GPU API |
| CLI | 可选 `AppMode::CLI`（非 GUI 主路径） |

## 大模型控制目标

面向 Codex 等本机 Agent，UIX 提供一套应用无关的控制机制，而不是让每个应用单独编写控制适配器：内置组件自动暴露语义、状态、边界与支持动作；自定义组件沿用无障碍语义契约；`.automation_id("…")` 仅在业务需要跨版本稳定定位时使用，不是每个节点的必填项。

成功标准是：应用显式启用本机 Agent Bridge 后，大模型能枚举本进程窗口、读取逐窗语义树、执行语义动作、在必要时使用低层输入兜底，并按 revision 等待状态稳定；多窗互不唤醒，空闲时无轮询、无布局 / 绘制 / present。Bridge 默认关闭，仅允许同一 OS 用户经随机会话凭证访问；敏感值不导出、不回显、不记录。

## 不做 · 暂缓 · 验收策略

| 类 | 项 |
|----|-----|
| **不做** | 网络 / 同步域；读屏桥；跨机器 / 跨用户远程控制服务；任意代码或文件操作；WebView 运行时；手写探活 / 重绘名单 |
| **暂缓** | 移动端 backend；D3D12 完整扩展；Metal `GpuNative`（须图形契约闭合后，见进度） |
| **验收策略** | 不把 macOS 真机验收强行等同 Windows gate；Linux/macOS/移动端不计 P6 |

## 运行时与图形

**用最少资源，做最好效果。** 无待处理事件、队列、deadline 或帧机会 → 阻塞等待；失效只合并并申请本窗一次帧机会，有变化才做必要阶段。隐藏、遮挡、零尺寸或 surface 暂不可用时保留 dirty、暂停视觉帧并等待恢复信号，禁止失败忙循环；脏区尽量窄，但 partial present 必须先证明坐标与缓冲一致性。active 交互必须正确；无真实窗口 / GPU 下可被测试验证。
