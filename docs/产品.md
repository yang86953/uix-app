# 产品

> UIX 是什么、做到哪、做什么 / 不做什么。

## 定位

用 Rust 写的跨平台全栈 App 框架：声明式 UI 像 Web，跑的是原生窗口与绘制，空闲时真正休眠。

- 入口：`use uix::prelude::*`
- 目标：桌面 + 移动端共用同一套上层代码
- 不含：网络 / 同步；读屏桥
- 写法 → [`使用.md`](使用.md)

## 当前阶段

**Windows 优先**做到生产可用。Win / Linux / macOS 已编码；移动端未做。愿景是跨平台，交付顺序是先 Windows。

平台差异只在 `native`（上层只见 trait，禁 `use native::backends::*`）。除 `native` 外禁止按 OS 分叉；新平台只加 backend。

## 能力与边界

| 做 | 不做 / 暂缓 |
|----|-------------|
| View + State + 组件；框架托管 Timer / 动画 / `post_to_ui` / 多窗 | 命令式控件树、重绘名单、WebView 运行时 |
| 原生窗口 / 输入 / 布局 / 绘制 / 主题 / 浮层 / 语义事件 | 移动端 backend |
| IME（composition → commit；Windows 以系统 IME / 微软拼音为门禁） | 读屏桥 |
| Settings KV **opt-in**（默认不 load/save，不进热路径） | 网络 / 同步域 |
| 无障碍 v1：静态 ARIA + 键盘 | 把 macOS 真机验收等同 Windows gate |
| 默认 Vulkan；失败 typed → Software/CPU | 静默换另一 GPU API；D3D12 完整扩展 / Metal `GpuNative`（图形契约闭合前） |

## 运行时与图形

**用最少资源，做最好效果。** 无事件 / 失效 / 已注册活动 → 阻塞等待；有变化只做必要阶段，脏区尽量窄；active 交互必须正确。须能在无真实窗口 / GPU 下验证。
