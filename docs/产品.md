## 内容摘要

UIX 是一个**跨平台原生应用框架**。界面推荐使用 uix-lang 描述并在编译时转换为 Rust；运行时不绑定浏览器或 Web 技术栈。产品目标覆盖 Windows、Linux、macOS 与移动端原生窗口，当前 `0.0.3` 发布范围为 Windows 与 Linux，移动端 backend 暂缓。这里的“全栈”仅指 UI、应用壳和本地数据存储，不包含网络与同步。

核心取向：

- **原生绘制**：不使用 WebView 或 Electron 作为界面运行时，由 UIX 图形管线直接绘制到原生窗口。
- **Rust 运行时**：uix-lang 在编译时转换为 Rust，运行期没有 UIX Lang 解释器。
- **资源优先**：无待处理事件、计时器、队列或帧机会时进入休眠，避免固定 tick 和无条件重绘。
- **按需构建**：通过显式 feature 选择控制编译图，再由链接裁剪移除已选能力中的不可达内容。
- **平台收敛**：上层使用统一契约，平台差异收敛在平台与图形边界内；实际平台覆盖仍以交付说明为准。

产品范围覆盖界面组件、类型安全表单、数据展示、动画、浮层、统一图形 API、多窗口、平台能力、键值存储与国际化；各能力的当前入口和限制见[能力与边界](产品/能力.md)。

明确**不做**：网络/同步、WebView 运行时、跨网络远程控制（显式启用的同用户本机 Agent 控制面除外）、远程日志上传、运行期解释执行的独立 UI 脚本语言。
