# 产品

> UIX 是什么、做到哪、做什么 / 不做什么。

## 定位

用 Rust 写的跨平台 App 框架：**全栈**指 UI + 应用壳 + 本地 `data`（Settings），**不含**网络 / 同步。声明式 UI 像 Web，跑原生窗口与绘制，空闲时真正休眠。

- 入口：`use uix::prelude::*`
- 目标：桌面 + 移动端共用同一套上层代码
- 写法 → [`使用.md`](使用.md)

## 当前阶段

**Windows 优先**做到生产可用（P6 gate → [`进度.md`](进度.md)）。Win / Linux / macOS **源码路径已在树中**，不等于三端都已过生产验收；移动端未做。愿景是跨平台，交付顺序是先 Windows。

平台差异只在 `native`（上层只见 trait，禁 `use native::backends::*`）。除 `native` 外禁止按 OS 分叉；新平台只加 backend。

## 能力

| 做 | 说明 |
|----|------|
| 界面 | View + State + 组件；不维护命令式控件树或重绘名单 |
| 运行时托管 | Timer、动画、`post_to_ui`、多窗、IME 会话由框架登记 / 清理 |
| 原生路径 | 窗口、输入、布局、绘制、主题、浮层、语义事件；不以 WebView 为运行时 |
| IME | 单行 / 多行；composition → commit；Windows 生产以系统 IME（含微软拼音）为门禁之一 |
| Settings | KV **opt-in**；默认不 load/save；不进 UI 热路径 |
| 无障碍 v1 | 静态 ARIA + 键盘导航 |
| 图形 | 默认 Vulkan；失败须 **typed** 诊断后回 Software/CPU；禁静默换另一 GPU API |
| CLI | 可选 `AppMode::CLI`（非 GUI 主路径） |

## 不做 · 暂缓 · 验收策略

| 类 | 项 |
|----|-----|
| **不做** | 网络 / 同步域；读屏桥；WebView 运行时；手写探活 / 重绘名单 |
| **暂缓** | 移动端 backend；D3D12 完整扩展；Metal `GpuNative`（须图形契约闭合后，见进度） |
| **验收策略** | 不把 macOS 真机验收强行等同 Windows gate；Linux/macOS/移动端不计 P6 |

## 运行时与图形

**用最少资源，做最好效果。** 无事件 / 失效 / 已注册活动 → 阻塞等待；有变化只做必要阶段，脏区尽量窄；active 交互必须正确。须能在无真实窗口 / GPU 下用测试验证。
