# 产品

## 愿景

**uix-app** 是跨平台（桌面 + 移动端）全栈 App 框架（[#166](决策.md#d166)）：Web 式声明 UI + 原生性能 + 零闲置（[#105](决策.md#d105)）。入口：`use uix::prelude::*;`。

**当前阶段**（[#167](决策.md#d167)）：**Windows 优先**生产可用；桌面三平台已编码；移动端未实现（P7+）。除 `native` 外上层跨 OS 同构。上手 → [`架构 · 应用作者入口`](架构.md#应用作者入口)。

<a id="开发策略"></a>

## 开发策略

| 原则 | 说明 |
|------|------|
| 平台层抹平差异 | 除 `native` 外上层无 OS `#[cfg]` |
| 上层只见 trait | 禁止 `use native::backends::*` |
| 愿景 ≠ 优先级 | [#166](决策.md#d166) 跨平台全栈仍为目标；[#167](决策.md#d167) 只定交付顺序 |

## 需求摘要

| ID | 需求 | 类型 | 优先级 |
|----|------|------|--------|
| <a id="req-001"></a>REQ-001 | 应用作者能从 `uix::prelude::*` 以 View + State + 组合式组件声明原生应用，无需维护命令式 UI 树。 | Functional | Must |
| <a id="req-002"></a>REQ-002 | 框架提供原生窗口、输入、布局、绘制、主题、浮层和语义事件的端到端路径，不以 WebView 作为运行时。 | Functional | Must |
| <a id="req-002a"></a>REQ-002a | 文本输入覆盖单行 / 多行与完整 IME（composition → commit）；Windows 生产以系统 IME（含微软拼音）GUI 证据为 gate 之一。 | Functional | Must |
| <a id="req-003"></a>REQ-003 | 无事件、无失效、无已注册活动工作时，运行时进入阻塞等待；有变化时只执行必要阶段与最小脏区。 | Functional | Must |
| <a id="req-004"></a>REQ-004 | Timer、动画、跨线程 UI 投递、响应式更新和多窗路由由框架登记、唤醒与清理，调用方不维护轮询循环或裸 registry。 | Functional | Must |
| <a id="req-005"></a>REQ-005 | 产品目标覆盖 Windows、Linux、macOS、iOS、Android；当前交付优先完成 Windows 生产可用，其他平台不得要求上层代码分叉。 | Product | Must |
| <a id="req-006"></a>REQ-006 | 图形 API 在初始化期按已编译能力选择并可诊断失败；候选失败时继续回退，终态可使用软件渲染，不进行逐帧探测或任意热切换；运行期失败必须可观察、可恢复且不得报告伪成功，所有 backend 保持 painter order、混合与 offscreen 语义一致。 | Functional | Must |
| <a id="req-007"></a>REQ-007 | Settings 持久化必须显式 opt-in，不默认 load/save，也不进入 UI 热路径。 | Functional | Must |
| <a id="req-008"></a>REQ-008 | 核心行为可在无真实窗口/GPU 的环境中验证，并对平台边界、主循环、事件、布局、绘制和公开 API 提供分层证据。 | Quality | Must |
| <a id="req-009"></a>REQ-009 | 无障碍：组件可提供静态 ARIA 映射与键盘导航；屏幕阅读器平台桥不在当前交付范围，边界待决后另开阶段。 | Functional | Should |

**REQ-006 图形验收细则**：

| 验收 ID | 可观察结果 |

| <a id="ac-gfx-01"></a>AC-GFX-01 | clear、native/CPU draw、Picture/offscreen blit 依 painter order 执行；跨 backend 参考帧一致。 |
| <a id="ac-gfx-02"></a>AC-GFX-02 | initialize/resize/present/device-loss 返回 typed failure；失败帧保留 dirty、不计成功，并可重建或回退到下一合法候选/Software。 |

| <a id="ac-gfx-04"></a>AC-GFX-04 | registry 可为同一 API 声明多个合法 recipe；每项 caps 由独立行为测试证明，API 专用对象不穿透 `native/graphics/<api>`。 |
| <a id="ac-gfx-05"></a>AC-GFX-05 | hybrid fallback 保持 blend/clip/source-crop/scissor 语义并按 damage 上传；unsupported 能力显式拒绝，不以不等价近似冒充支持。 |
| <a id="ac-gfx-06"></a>AC-GFX-06 | EGL/Vulkan/WGL/D3D/Metal 的尺寸、DPR、damage、资源重建与 feature 隔离分别通过契约测试及适用平台真机验证。 |
