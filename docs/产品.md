## 内容摘要

UIX 是一个**跨平台原生 App 框架**：用 uix-lang 描述一套声明式界面（编译时转换为 Rust），目标在 Windows / Linux / macOS / 移动端原生窗口上运行（移动端 backend 暂缓，见[能力与边界](产品/能力.md)）。不绑定浏览器，不依赖 Web 技术栈。全栈指 UI + 应用壳 + 本地数据存储，不含网络与同步。

核心差异化：
- **原生绘制**：不套 WebView/Electron，每像素由 GPU 直接渲染
- **纯 Rust**：界面用 uix-lang 描述，编译时转换为 Rust，运行期无第二门语言
- **省资源**：空闲真休眠，不做多余绘制，不浪费内存
- **按需构建**：使用方只为显式选择且传递必需的能力付出编译与产物成本
- **跨平台**：一套代码多平台

UIX 提供完整的 App 开发能力：界面组件库、类型安全表单、数据展示、动画、浮层、统一图形 API、多窗口、平台能力、键值存储与国际化，完整清单见[能力与边界](产品/能力.md)。

明确**不做**：网络/同步、WebView 运行时、远程控制、远程日志上传、独立 UI 脚本语言。
