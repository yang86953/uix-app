# 产品

> UIX 是什么、做到哪、做什么 / 不做什么。

## 定位

用 Rust 写的跨平台 App 框架。**全栈**：UI + 应用壳 + 本地 `data`（Settings）；**不含**网络 / 同步。声明式 UI 像 Web，跑原生窗口与绘制，空闲时真正休眠。

- 入口：`use uix::prelude::*`
- 目标：桌面 + 移动端共用同一套上层代码
- 写法 → [`使用.md`](使用.md)

## 核心原则

**用最少资源，做最好效果。**

这不是口号，是架构决策的第一优先级。每一项功能都须先回答：能不能用更少的内存、更少的 CPU、更少的帧做到同等或更好的结果？

- **运行时**：空闲真休眠阻塞等待，不轮询；逐窗至多一个帧请求；不可呈现时保留状态、暂停帧
- **绘制**：局部状态只更新依赖节点；保留式路径只重绘实际 dirty；脏区合并，清屏与绘制共用引擎实际帧区
- **内存**：字形缓存有界，Picture 离屏按需创建并及时间回收，槽位池自动 compact
- **容错**：失败 typed，终态吸收不忙循环；主循环与托管不依赖真实窗口或 GPU

## 当前阶段

**Windows 优先**做到生产可用（P6 gate → [`进度.md`](进度.md)）。平台差异只在 `native` backend；上层只见 trait，禁按 OS 分叉（`#[cfg(OS)]` 仅限 `native/`）。

## 能力

主路径（写应用）：

| 做 | 说明 |
|----|------|
| 界面 | View + State + Computed + 组件；单行 / 多行 / 密码 Input、InputNumber、支持单选 / 多选与即时过滤的 Select、Radio、Segmented、Slider、Rate、支持禁用规则与 Date/Week/Month/Quarter 粒度的 DatePicker、双 State 与具名预设的 DateRangePicker、TimePicker、ColorPicker 及 Checkbox / Switch 值可由 State 托管，Navigation / Tabs 可用字符串或枚举 key 双向绑定页面 State，State 与派生值可重建 / 条件渲染子视图，也可保留节点身份切换整棵子树可见性；固定 logical 尺寸的轻量 canvas 可直接记录自定义绘制，24 单元响应式 Grid 按本容器 logical 宽度自动重排，盒模型、颜色、透明度与阴影由统一 View 样式链声明；原始输入、Tab 顺序、无障碍覆写与可失效的 typed `FocusHandle` 均由 View 声明；ConfigProvider 配置继承、统一 Size 系统（Small/Medium/Large）、按组件类型合并令牌补丁及 List / Table 空态 View factory |
| 表单 | `Form::field` 链内联声明必填、邮箱、数值范围、字符长度、regex、自定义与字段依赖校验；规则可按 Submit / Change / Blur 激活，整表成功返回 typed `Values`；文本、选项、布尔、数值、日期、日期范围、时间与颜色字段可通过对应 Input / Select / Radio / Segmented / Checkbox / Switch / InputNumber / Slider / Rate / Picker 绑定方法组合 `FormItem`，自动呈现错误并在提交失败时聚焦首错；日期范围以共享控件绑定两个独立 typed 字段；`Form::list` 以稳定行身份托管动态同构字段并自动请求结构 reconcile；业务校验闭包只属于应用侧模型 |
| 数据展示 | Table 支持 `Vec<String>` 简单行及带唯一业务 key 的泛型行，typed 列可保留确定性文本投影并渲染任意 View；提供表级 / 列级排序交互、可选行复选框、边框样式、左右固定列、双层分组表头、可交互 View 展开行与有界虚拟滚动；typed 行重排后选择与仍在窗口内的单元格子树按 row key 保持，虚拟表只物化视口窗口；独立 `VirtualScroll` 按视口物化普通 View 行；运行态排序方向、row key、View 列与选择结果进入结构化快照 |
| 主题 | 暗色 / 亮色主题自动跟随，`ThemeToggle` 一键切换；`DesignTokens` 覆盖色彩、字号、间距、阴影；公开 12×10 主色色板、自定义色板生成、13 阶中性色、功能色阶与数据可视化分类色板 |
| 国际化 | `Locale` / `LocaleProvider` 统一管理 30+ 组件文案，内置 `zh_cn()` / `en_us()` 预设，子树级覆写；组件渲染中通过 `use_locale()` 读取 |
| 剪贴板 | `copy_to_clipboard()` / `read_text_from_clipboard()` 读写系统剪贴板，受框架事件词法作用域托管，无活动事件时 no-op |
| 运行时托管 | Timer、逐窗动画帧机会、`post_to_ui`、多窗、IME 会话由框架登记 / 清理；`AppState` / `ComponentHandle` 提供跨线程只读快照与队列化交互；`Animated<T>` 为普通 View 属性提供固定时长、typed keyframe 或 Spring 声明式单值过渡，`keyframe!` 可把多项 typed 属性聚合到同一 source / 时钟；支持无空转帧的 deadline 延迟启动、普通固定时长有限 / 无限循环与往返播放、锁外一次性完成回调、opacity / 前景色 / 背景色 / 宽高 / 圆角样式及 visual-only offset / scale 直接绑定、普通 View 一次性挂载进场、keyed 有界离场与 deadline 列表 stagger，以及复用现有 source 登记的有限并行 / 串行 / stagger `AnimationGroup`；`Animation<T>` / `KeyframeAnimation<T>` / `SpringAnimation<T>` 提供底层暂停、重启与一次性完成回调 |
| 浮层 | `Modal::show(\|ctx\| View)` 以普通可交互子树声明内容，`ctx.close()` 只关闭所属 Modal 并保留退出动画；Modal / Drawer / Popover / Message / Notification 以 `AnimationConfig` 分别声明 enter / leave，离场完成后才移出本窗浮层栈；消息与通知逐项自动到期，持有期只登记最近截止时间，不持续申请帧；层级、遮罩与焦点陷阱由框架托管 |
| 窗口外观 | Windows 主窗与副窗可逐窗隐藏系统标题栏；应用用普通 View 自定义标题、图标和控制项，拖动区可组合独立交互子控件，支持拖窗、双击最大化 / 还原及右键原生系统菜单且不改变正文焦点；框架提供最小化与安全关闭原语，控制项以单一具名按钮进入语义树、可自定义普通 / 悬停 / 焦点 / 按压背景，并保留系统缩放边框；`uix-demo` 默认使用该路径作为可运行示例 |
| 原生路径 | 窗口、输入、布局、绘制、主题、浮层、语义事件；上层客户区尺寸、布局与输入使用 logical 坐标，每窗 drawable 随 DPI 独立变化；不以 WebView 为运行时 |
| IME | 单行 / 多行；系统 composition → commit。Windows 微软拼音真实前台输入已过，框架托管会话与光标矩形，不自造候选管线 |
| Settings | KV **opt-in**；`.settings(path)` 才在启动时 load 并注册应用级共享状态，支持字符串与 typed scalar，`settings-serde` 可按 key 读写结构体；修改后显式 save，默认不 load/save，不进 UI 热路径 |
| 无障碍 v1 | 22 种常用 `AccessibilityRole` + 排除角色 `None`，`AccessibilityState` 覆盖 disabled/checked/expanded/selected/value 与输入状态，`AriaAttribute` 支持组件派生和 View 自定义属性；组件自带默认 role，View 可局部覆写；焦点陷阱 + Tab 序自动管理；password 字段不导出 |
| 图形 | 默认 Vulkan；logical viewport 与 physical drawable 分离；圆弧等矢量图元共享 Path 录制 / 重放；失败须 **typed**，`DeviceLost` 回收失效资源后有界回 Software/CPU，可用时把 Vulkan device fault 有界诊断挂入原因链；禁静默换另一 GPU API |
| 诊断 | `core` 层统一错误收集（`Collector`）、完整 typed 原因链文本、崩溃处理（`fatal`——panic → crash dump → `uix_crash.log`）、中间件管道（`LogMiddleware` / `RetryMiddleware`） |
| CLI | 可选 `AppMode::CLI`（非 GUI 主路径） |

## 不做 · 暂缓

| 类 | 项 |
|----|-----|
| **不做** | 网络 / 同步域；读屏桥；跨机器 / 跨用户远程控制服务；任意代码或文件操作；WebView 运行时；手写探活 / 重绘名单；独立 UI 脚本语言（现为 Rust API；无 JSX/模板/DSL） |
| **暂缓** | 移动端 backend；D3D12 完整扩展；Metal `GpuNative`（须图形契约闭合后） |
