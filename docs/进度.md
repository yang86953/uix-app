Windows「生产可用」至少同时满足（细节与证据 → [当前验证证据](#当前验证证据) · [证据矩阵](#平台与后端证据矩阵)）：

4. P0 生产阻塞归零；帧顺序、线程亲和、失败帧 dirty 保留、typed recovery、probe 诊断与 shutdown 均有自动化证据；EGL/Vulkan/DPI 等平台项另须适用平台真机证据。
