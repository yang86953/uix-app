# 进度

> 缺口与未关闭项；落地以源码 / 测试为准。

## 现状

- P0–P5 基线：普通 DeepIdle 已落地；显示节拍、隐藏动画与持续 surface 失败下的零唤醒仍由 RUNTIME-R2 收口
- P6（Windows 生产可用）：未闭合（真实 Vulkan、帧/恢复 GPU 真机、typed 终态收尾、真机 IME/证据）
- 其后：移动端 / 网络·同步 / 读屏桥（先产品裁决）

**P6 gate**（Linux/macOS/移动端不计）：

1. `cargo test --all-targets` 全过  
2. **图形契约闭合**：GFX-R0–R4 全关
3. 失败路径具备 **typed** 诊断；不得静默换 GPU API / 伪成功  
4. 微软拼音（系统 IME）前台 composition → commit 真机过关（RISK-001）  
5. 上层无 OS 分叉  
6. one-shot frame request；隐藏 / 遮挡 / zero extent / 持续失败无 layout、present 或 busy retry

推进：`RUNTIME-R1→RUNTIME-R2`；`GFX-R0→R1→R2→R4→R5→R6`。Metal `GpuNative` / D3D12 扩展不得早于图形契约闭合。
