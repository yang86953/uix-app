# 进度

> 缺口与未关闭项；落地以源码 / 测试为准。

## 现状

- P0–P5 基线：普通 DeepIdle、逐窗 one-shot fallback、最小化 / 零尺寸 / `Hidden` 动画零唤醒与 surface 失败有界恢复已落地；Windows `WM_SHOWWINDOW` 已接逐窗真实隐藏 / 显示，Wayland `wl_surface.frame`、Windows DWM 与 macOS `NSWindow.displayLink` 显示机会已接入；Windows D3D11 bitblt 与 macOS AppKit 逐窗遮挡休眠已闭环，Windows 其余 recipe / Wayland 遮挡信号仍由 RUNTIME-R2 收口
- P6（Windows 生产可用）：未闭合（真实 Vulkan、帧/恢复 GPU 真机、typed 终态收尾、真机 IME/证据）
- 大模型控制：`uix.agent.v1`、`agent-control` feature + `.enable_agent_control()` 双门禁、共享语义动作 / 节点快照、单选 selection / `select`、逐窗 revision / `presented_revision`、有界命令队列 / settle、进程级 Bridge、窗口级 `press_key` / `click_at`，以及带 discovery / 随机 token 认证的 Named Pipe / Unix Domain Socket 已落地；真窗端到端与跨用户拒绝证据尚未闭合（`AGENT-R1`）
- UI 回调所有权：`Form` validator 已改为命名 key + 应用侧 `FormValidatorTable`；`Table` expand renderer 与 `VirtualScroll` item renderer 已进入逐组件 render-handler 表并随 reconcile / remove / root reset 清理；组件 struct 不再保存这三类业务闭包
- 其后：移动端 / 网络·同步 / 读屏桥（先产品裁决）

**P6 gate**（Linux/macOS/移动端不计）：

1. `cargo test --all-targets` 全过  
2. **图形契约闭合**：GFX-R0–R4 全关
3. 失败路径具备 **typed** 诊断；不得静默换 GPU API / 伪成功  
4. 微软拼音（系统 IME）前台 composition → commit 真机过关（RISK-001）  
5. 上层无 OS 分叉  
6. one-shot frame request；隐藏 / 遮挡 / zero extent / 持续失败无 layout、present 或 busy retry

推进：`RUNTIME-R2`；`GFX-R0→R1→R2→R4→R5→R6`。Metal `GpuNative` / D3D12 扩展不得早于图形契约闭合。
