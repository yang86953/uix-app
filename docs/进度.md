# 进度

> 这里只保留活跃差距。Windows P6 交付基线已闭合；产品范围见[产品](产品.md)，运行时与图形契约见[架构](架构.md)。

## 更小 · 更快 · 更稳

功能面已收敛。后续只围绕三个方向：

- **更小**：缩小内存占用。当前 ~100MB RSS 中 GPU 驱动/交换链占比过半不可控，其余来自字形缓存、CPU 中转缓冲、Picture 离屏池、槽位数组膨胀。目标是逼近同体量 GPU-only 框架的内存水平。
- **更快**：降低每帧耗时。当前瓶颈在 CPU→GPU 中转（文字光栅化上传、圆角 SDF、阴影模糊）和首帧 layout 尖峰。目标是稳定 60Hz。
- **更稳**：跨平台真机矩阵闭环。当前仅 Windows Vulkan/NVIDIA 验证；Wayland、macOS、AMD、Intel 均未覆盖。Agent 安全在 Linux/macOS 上缺异 uid 拒绝路径。

具体方案由云端自行规划。
