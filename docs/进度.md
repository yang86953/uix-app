# 进度

> 当前重心：**Windows 生产可用（P6）**。契约见[架构](架构.md)；Linux / macOS / 移动端 / Agent 不计本 gate。

## 目标

把 Windows 桌面路径做到可交付生产：默认 Vulkan 真机可用、失败 typed、系统 IME（微软拼音）过关、**空闲真休眠 / 遮挡可停帧**、无 busy retry。上层无 OS 分叉。

**未闭合。** 基线（P0–P5）：DeepIdle、逐窗 one-shot、隐藏 / 最小化零唤醒、D3D11 bitblt 遮挡休眠、`TerminalFailure` 吸收态已落地。**默认 Vulkan 等非 bitblt recipe 的逐窗遮挡停帧尚未接上**（见 RUNTIME-R2）——直接威胁 gate「最少资源 / 无 busy 视觉」。

### Gate（仅 Windows）

1. `cargo test --all-targets` 全过
2. 图形契约生效（[架构·图形](架构.md#图形-api与帧提交硬约束)）；下表图形证据关完
3. 失败 **typed**；禁静默换 GPU API / 伪成功
4. 微软拼音 composition → commit 真机过关（RISK-001）
5. 上层无 OS 分叉
6. one-shot；隐藏 / **遮挡** / zero extent / 持续失败无 layout、present 或 busy retry（含默认 Vulkan 路径的遮挡停帧或诚实的 typed unsupported + 生命周期休眠）

### 推进顺序

`RISK-001`∥`GFX-R0`∥`RUNTIME-R2（Win 遮挡）` → `GFX-R2` → `BUG-002` → `GFX-R5` →（正确性后）`GFX-R6`。  
`GFX-R1` 圆角 Additive：先裁决（接受 NotImplemented 或排入本 gate）。Metal / D3D12 扩展不进本 gate。
