## 公开 API 对账

`使用指南/` 中已落地示例继续由外部 consumer 编译；以下目标写法仍以 `text` fence 明示，不能当成当前公开 API。

| 优先级 | ID | 目标 / 当前差距 | 下一动作 |
|--------|----|-----------------|----------|
| P1 | API-R2 | 固定时长单值 `Animated<T>`、有限 / 无限循环与往返播放已落地并复用逐窗 frame registration；Spring、`keyframe!`、`AnimationGroup`、延迟 / 回调、View 属性快捷绑定与 stagger 仍是设计目标 | 用 deadline registration 实现延迟而不申请空转动画帧；回调继续留在 `Animation<T>` 底层，再评估 Spring / 编排 |
| P1 | API-R3 | `FormItem` 声明式字段、错误展示与首错聚焦链尚未落地；当前使用 `Form::field` 和调用方组合 | 在现有 typed `Values`、触发策略和焦点句柄上增加 View 组合层，保持业务校验留在应用侧 |
| P1 | API-R4 | Table 任意 View 单元格与泛型行数据尚未落地；当前 `TableRow = Vec<String>` | 先定义行身份、虚拟化复用和快照边界，再增加列级 render port，避免闭包捕获破坏增量更新 |
| P2 | API-R5 | Settings 类型化标量 / 结构体读写尚未落地；当前仅字符串 KV | 在 opt-in load/save 与 UI 热路径外实现 typed codec 和错误模型，不改变默认零 I/O |
| P2 | API-R6 | Navigation / Tabs 的 State 路由绑定与枚举 key 尚未落地；Navigation 第二个 item 参数仍是 icon，Tabs `active_key` 只读，变化载荷为字符串 key | 基于现有 State View 派生定义受控 key 与快照边界；不新增内置路由器 |
