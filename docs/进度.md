# 进度

## 公开 API 对账

`使用指南/` 中带 `uix-compile` 的示例对应已落地公开 API；以下目标写法仍以 `text` fence 明示，不能当成当前公开 API。

| 优先级 | ID | 目标 / 当前差距 | 下一动作 |
|--------|----|-----------------|----------|
| P1 | API-R2 | 固定时长单值 `Animated<T>`、deadline 延迟启动、有限 / 无限循环与往返播放已落地并复用逐窗 registration；Spring、`keyframe!`、`AnimationGroup`、回调、View 属性快捷绑定与 stagger 仍是设计目标 | 回调继续留在 `Animation<T>` 底层；下一片先定义 Spring 的收敛、暂停与逐窗调度边界，再决定是否进入公开面 |
| P1 | API-R3 | Input、Select、Radio、Segmented、Checkbox、Switch、InputNumber、Slider 与 Rate 已可通过 `FormModel` 绑定对应 typed State，组合 `FormItem`、OnChange / OnBlur 校验、内联错误与提交首错聚焦；其他 typed 组件仍由调用方组合 | 为 Date / Time / Color 增加稳定表单文本投影并接入现有 controlled Picker，保持日期归一与颜色表示由值类型负责 |
| P1 | API-R4 | Table 任意 View 单元格与泛型行数据尚未落地；当前 `TableRow = Vec<String>` | 先定义行身份、虚拟化复用和快照边界，再增加列级 render port，避免闭包捕获破坏增量更新 |
| P2 | API-R5 | Settings 类型化标量 / 结构体读写尚未落地；当前仅字符串 KV | 在 opt-in load/save 与 UI 热路径外实现 typed codec 和错误模型，不改变默认零 I/O |
| P2 | API-R6 | Navigation / Tabs 的 State 路由绑定与枚举 key 尚未落地；Navigation 第二个 item 参数仍是 icon，Tabs `active_key` 只读，变化载荷为字符串 key | 基于现有 State View 派生定义受控 key 与快照边界；不新增内置路由器 |

## 其他活跃差距

| 类 | 项 | 依赖 / 边界 |
|----|-----|------|
| 跨平台 / 多硬件 | Wayland fault / resize / parity / occlusion v6+、macOS / Wayland 真机；GFX-R5 AMD / Intel 多 vendor 矩阵（NVIDIA 已闭合） | 仍需对应平台与硬件环境 |

| 暂缓 | 移动端 backend；Metal `GpuNative` / D3D12 完整扩展 | 另行立项 |
