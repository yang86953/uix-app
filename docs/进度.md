| 优先级 | ID | 目标 / 当前差距 | 下一动作 |
|--------|----|-----------------|----------|
| P1 | API-R2 | 固定时长、typed 单值 / `keyframe!` 多属性聚合 keyframe、Spring `Animated<T>`、deadline 延迟启动、普通固定时长有限 / 无限循环与往返播放、锁外一次性完成回调、opacity / 前景色 / 背景色 / 宽高 / 圆角 typed View 绑定，以及有限 `AnimationGroup::parallel` / `sequential` / `stagger` / `delay` 已落地并复用逐窗 registration；通用 offset / scale transform 仍是设计目标 | 下一片先定义 View transform 对 layout / paint / hit-test / semantics / damage 的统一契约，再决定是否落地 offset / scale；禁止仅改 canvas 的视觉假实现 |
