## 公开 API 对账

`使用指南/` 中带 `uix-compile` 的示例对应已落地公开 API；以下目标写法仍以 `text` fence 明示，不能当成当前公开 API。

| 优先级 | ID | 目标 / 当前差距 | 下一动作 |
|--------|----|-----------------|----------|
| P1 | API-R2 | 固定时长、typed 单值 / `keyframe!` 多属性聚合 keyframe、Spring `Animated<T>`、deadline 延迟启动、普通固定时长有限 / 无限循环与往返播放，以及有限 `AnimationGroup::parallel` / `sequential` / `stagger` / `delay` 已落地并复用逐窗 registration；声明式回调与 View 属性快捷绑定仍是设计目标 | 下一片实现 `Animated<T>` 声明式完成回调，复用底层一次性 callback 且不扩大到跨线程直接执行 UI 闭包 |
| P2 | API-R5 | Settings 类型化标量 / 结构体读写尚未落地；当前仅字符串 KV | 在 opt-in load/save 与 UI 热路径外实现 typed codec 和错误模型，不改变默认零 I/O |
| P2 | API-R6 | Navigation / Tabs 的 State 路由绑定与枚举 key 尚未落地；Navigation 第二个 item 参数仍是 icon，Tabs `active_key` 只读，变化载荷为字符串 key | 基于现有 State View 派生定义受控 key 与快照边界；不新增内置路由器 |
