# 进度

> 当前重心：**Windows 生产可用（P6）**。契约见[架构](架构.md)；Linux / macOS / 移动端 / Agent 不计本 gate。

## 目标

把 Windows 桌面路径做到可交付生产：默认 Vulkan 真机可用、失败 typed、系统 IME（微软拼音）过关、**空闲真休眠/遮挡可停帧**、无 busy retry。上层无 OS 分叉。

**未闭合。** 已落地：DeepIdle、连续工作轮次 OS 事件公平分发、逐窗 one-shot、清屏 / 绘制按 `FrameReady` 实际帧区同步、隐藏/最小化零唤醒、D3D11 bitblt 遮挡休眠、其余 Windows recipe typed `Unsupported` + 生命周期休眠、默认 Vulkan PixelUpload 真窗 present、结构化 adapter 诊断与 resize / readback / present 真机路径、主题切换 / resize 前台 compositor capture、RTX 4070 Ti SUPER 上单窗 15 分钟 153946 轮 resize / present（handle 550→557，峰 566）、同 UI 线程 Vulkan 共享 device + 逐窗 surface，双窗 15 分钟 61933 轮交替 resize / present（handle 773→779，峰 790）、共享 DeviceLost 向 peer typed 传播且 replacement 不复用旧 device、最小化/恢复、Vulkan device-lost teardown → 同 surface rebuild、DeviceLost 有限恢复 → Auto 下一 recipe → Software/GDI 同帧提交与失败终态、`TerminalFailure` 吸收态、Windows Per-Monitor V2 词法作用域（恢复宿主线程）、logical input / resize → shared physical drawable（含 Vulkan 创建/重建）且引擎保留精确 logical extent、`WM_DPICHANGED` 建议矩形路由、GDI full / partial `StretchBlt` 像素采样（本机 DPI=96）、微软拼音真实前台 composition → commit、前台系统 Tab + Modal focus trap / 隐藏恢复组合。

**已文档化（本次补齐）：** `canvas()`、`.padding_h()`/`.padding_v()`/`.margin()`/`.shadow()`/`.opacity()`、`ConfigProvider`、组件 Size 系统、令牌覆写、`Computed::map_opt()`、`show()`、`Color::hex()`/`.with_alpha()`、`PaintContext` 完整速查、事件 API、`TestApp`、`Locale`/`LocaleProvider`/`zh_cn()`/`en_us()`、剪贴板、`ThemeToggle`、`Navigation`/`NavGroup`/`NavItem`/`SharedActive`、`FocusTrap`、`OverlayKind`/`OverlayEntry`、`ComponentHandle`/`AppState`、`AccessibilityRole`/`State`/`AriaAttribute`、Widget trait 契约、Manager 系统、事件系统（SystemEvent 28 种/SemanticEvent/HandlerTable）、SnapshotFields/SelectionSnapshot。

### Gate（仅 Windows）

1. `cargo test --all-targets` 全过
2. 图形契约生效（[架构·图形](架构.md#图形-api与帧提交硬约束)）；下表图形证据关完
3. 失败 **typed**；禁静默换 GPU API / 伪成功
4. 微软拼音 composition → commit 真机过关
5. 上层无 OS 分叉
6. one-shot；隐藏 / **遮挡** / zero extent / 持续失败无 layout、present 或 busy retry（含默认 Vulkan 路径的遮挡停帧或诚实的 typed unsupported + 生命周期休眠）
