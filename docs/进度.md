# 进度

> 缺口与未关闭项；落地以源码 / 测试为准。契约见[架构](架构.md)。按产品交付分层：先 P6（Windows），三端债与附能力不计 P6。

## 现状

- **P0–P5**：DeepIdle、逐窗 one-shot、隐藏 / 最小化零唤醒、三端显示机会、Win D3D11 / macOS 遮挡休眠、`TerminalFailure` 吸收态已落地
- **P6**（Windows 生产可用）：未闭合（真机 Vulkan / 恢复、Software 终态 present、微软拼音）
- **其后**：移动端（暂缓）；网络 / 同步 / 读屏桥保持[产品·不做](产品.md#不做--暂缓--验收策略)

**P6 gate**（Linux/macOS/移动端不计）：

1. `cargo test --all-targets` 全过
2. **图形契约闭合**：架构·图形硬约束生效；下表 P6 图形证据关完
3. 失败路径 **typed** 诊断；不得静默换 GPU API / 伪成功
4. 微软拼音前台 composition → commit 真机过关（RISK-001）
5. 上层无 OS 分叉
6. one-shot；隐藏 / 遮挡 / zero extent / 持续失败无 layout、present 或 busy retry

推进：`RUNTIME-R2`（Win 部分）→ `GFX-R0→R1→R2` → 真机矩阵 `R5→R6`。Metal / D3D12 不得早于图形契约闭合。
