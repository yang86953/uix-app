# 进度

> **接口**：本文档组件是进度文档的路由索引，记录当前交付状态和活跃差距。依赖：[产品](产品.md)（需先了解目标）、[架构](架构.md)（需了解分层）。导出：按分类路由到 `进度/` 下的各文档组件。

## 适用线索

当需要了解"当前做到哪了、还差什么、瓶颈在哪"时，从本文档进入。

## 权威范围

本文档及 `进度/` 子目录下的文档组件共同构成 UIX 的交付真相。以下事实以本组件为准：

- 版本发布状态与交付物清单
- 功能逐项实现状态与证据
- 组件稳定性与已知缺陷
- 性能基线与优化方向
- 平台工程与运行保障进度
